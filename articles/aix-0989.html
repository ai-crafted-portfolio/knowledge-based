目的

システム内のすべての論理プロセッサーのパフォーマンス統計を収集し、表示します。

構文

mpstat [{ -d | -i | -s | -a | -h | -v | -E }] [ -w ] [ -O オプション ] [ -@ wparname] [ interval [ count ]]

mpstat [-X [-o filename]] [interval [count]]

制約事項: wparname パラメーターは、 ワークロード・パーティション内で使用するように制限されています。

説明

mpstat コマンドは、システム内のすべての論理プロセッサーのパフォーマンス統計情報を収集して表示します。 ユーザーは、統計情報が表示される回数、および、データが更新されるインターバルの両方を定義できます。

interval パラメーターは、各レポートの間隔を秒で指定します。 interval パラメーターを指定しない場合、mpstat コマンドは、システム起動時以降の統計を含む単一のレポートを生成して終了します。 count パラメーターは、interval パラメーターと一緒に指定する必要があります。 count パラメーターを指定すると、その値によって、生成されるレポートの数と間隔 (秒数) が決まります。 count パラメーターなしで interval パラメーターを指定すると、レポートは連続して生成されます。 count パラメーターに、ゼロの値を指定しないでください。

オプションが指定されない mpstat コマンドは、ブート時以降のすべての論理プロセッサーのパフォーマンス統計を含む単一のレポートを生成します。

mpstat コマンドが呼び出されると、統計の 2 つのセクションが表示されます。 最初のセクションにはシステム構成が表示されます。 これは、コマンドが開始されたとき、さらに、システム構成が変更されるたびに表示されます。 2 番目のセクションでは使用率の統計情報が表示されます。 これは一定のインターバルで表示され、さらに、 これらのメトリックの値が前のインターバルからの差分を生じているときにいつでも表示されます。

以下の情報が、システム構成のセクションに表示されます。
lcpu
オンライン論理プロセッサーの数を示します。
ent
処理装置内のライセンス済み処理キャパシティーを示します。 この情報は、区画タイプが共有である場合にのみ表示されます。
モード
区画プロセッサー・キャパシティーに上限が定められているか、あるいは上限が定められておらず、共有プールからのアイドル・サイクルを消費できるかを示します。 専用 LPAR には上限が定められているか、またはドネーションです。
rset
WPARに関連付けられているリソース・セット・タイプ (通常または排他) を示します。 この情報は、 WPARに関連付けられたリソース・セットがある場合にのみ表示されます。

(デフォルト、 -a フラグ) マイナー・ページ・フォールト (IO のないページ・フォールト)。

(-a, -d フラグ) 不足ロード・バランシングによるマイグレーションの数。

(-a, -d フラグ) スケジューリング・アフィニティー・ドメイン 4 を持つ同じ CEC またはプレーン内の異なる MCM 上のスレッド再ディスパッチの割合。

(-a, -d フラグ) この論理プロセッサー上のローカル・スレッド・ディスパッチの割合。

(-a, -d フラグ) この論理プロセッサー上のニア・スレッド・ディスパッチの割合。

(デフォルトのみ) 論理プロセッサー親和性。 スケジューリング親和性ドメイン 3 の内の論理プロセッサーの再ディスパッチのパーセンテージ。

(デフォルト、 -a フラグ) システム・コールの数。

(デフォルト、 -a フラグ、 -v フラグ) ユーザー・レベル (アプリケーション) で実行中に発生した物理プロセッサー使用率。

(デフォルト、 -a フラグ、 -v フラグ) システム・レベル (カーネル) で実行中に発生した物理プロセッサー使用率。

(デフォルト、 -a フラグ、 -v フラグ) 論理プロセッサーがアイドル状態であった時間のうち、未解決のディスク入出力要求があった時間の割合。

-v フラグが使用される場合、使用率は仮想プロセッサーに基づきます。

id
(デフォルト、 -a フラグ、 -v フラグ) 論理プロセッサーがアイドル状態で、未処理のディスク入出力要求がなかった時間の割合。

-v フラグが使用される場合、使用率は仮想プロセッサーに基づきます。

(デフォルト、 -a フラグ、 -h フラグ、 -v フラグ) 消費された物理プロセッサーの数または割合。 共有区画と専用区画の両方で表示されます。 専用区画のデフォルトのフラグの場合、ドネーションと同時マルチスレッド化の両方が使用不可のときには表示されません。

cpuid U 行の pc は、未使用の物理プロセッサーの数を表します。

(デフォルト、 -a フラグ) 論理プロセッサーによって消費されたライセンス済みキャパシティーのパーセンテージ。 「ALL CPU」行の %ec は、消費されたライセンス済みキャパシティーのパーセンテージを表します。 このデータを計算する基になる時間基準が変動する場合があるため、ライセンス済みキャパシティーのパーセンテージが 100% を超えることがあります。 この超過はサンプリング間隔が短い場合にのみ目立ちます。 この属性は共有区画でのみ表示されます。
ilcs
(-a, -d, -h フラグ) 共用区画にのみ表示される、非自発的な論理プロセッサー・コンテキスト・スイッチの数。 -h フラグおよび -a フラグの場合は、専用区画にも表示されます。
vlcs
(-a, -d, -h フラグ) 任意の論理プロセッサー・コンテキスト・スイッチの数。 共有区画でのみ表示されます。 -h フラグおよび -a フラグの場合は、専用区画にも表示されます。
lcs
(デフォルト) 論理プロセッサーのコンテキスト・スイッチの総数。 共有区画でのみ、または専用区画のドネーションの場合にのみ表示されます。
%idon
(-a, -h フラグ) アイドル・サイクルを明示的に提供している間に発生した物理プロセッサー使用率を示します。 ドネーションを行っている専用区画でのみ表示されます。
%bdon
(-a, -h フラグ) ビジー・サイクルの提供中に発生した物理プロセッサー使用率を示します。 ドネーションを行っている専用区画でのみ表示されます。
%istol
(-a, -h フラグ) ハイパーバイザーがアイドル・サイクルをスチールしている間に発生した物理プロセッサー使用率を示します。 専用区画でのみ表示されます。
%bstol
(-a, -h フラグ) ハイパーバイザーがビジー・サイクルをスチールしている間に発生した物理プロセッサー使用率を示します。 専用区画でのみ表示されます。
%nsp
(-a, -d フラグ) 現在の平均プロセッサー速度を公称速度のパーセンテージで示します。 ハードウェアで Scaled Processor Utilization Resource Register (SPURR) が使用されている場合のみ表示されます。
vcpu
(-v フラグ) 仮想プロセッサー ID を表示します。
lcpu
(-v フラグ) 論理プロセッサー ID を表示します。
pbusy
(-v, -E フラグ) 物理プロセッサーがビジーである物理時間の割合を示します。
VTB
(-v フラグ) 仮想プロセッサーにかかった時間をミリ秒単位で示します。
physc
(-E フラグ) 論理プロセッサーによって使用されている物理プロセッサーの数を示します。
freq
(-E フラグ) 動作周波数を GHz 単位で表示します。
scaled physc
(-E フラグ) SPURR に基づいて論理プロセッサーが使用する物理プロセッサーの数を表示します。

mpstat コマンドは、区画内のすべての論理プロセッサーについて、上記のすべての統計情報を表示します。 共有区画を実行しているときに、ライセンス済み処理キャパシティーがすべて消費されていない場合、cpuid U の特殊プロセッサー行を表示できます。

また、 mpstat コマンドは、パーティション全体の使用率を示す cpuid ALL を持つ特殊なプロセッサー行も表示します。 該当の行では、ライセンス済みキャパシティーを超える現行の物理プロセッサー消費量を伴う上限なし区画の場合を除き、そのパーセンテージは、ライセンス済み処理キャパシティーに関連します。 専用区画の場合、ライセンス済み処理キャパシティーは物理プロセッサーの数です。 また、 WPAR の場合は、 -s または -@ フラグが使用されている場合にのみ、関連するリソース・セットに存在するプロセッサーがアスタリスク (*) で示されます。

-s フラグを指定すると、 mpstat コマンドは 同時マルチスレッド化 使用率を報告します (使用可能な場合)。 このレポートは、仮想プロセッサー・エンジンの使用率、および仮想プロセッサー・エンジンと関連付けられた各スレッド (論理プロセッサー) の使用率を表示します。

mpstat が専用区画で実行されていて、 同時マルチスレッド化 が有効になっている場合、スレッド (論理プロセッサー) 使用率のみが表示されます。

mpstat がインターバル・ベース・モードで実行されている場合は、1 秒当たりに計算された平均値になります。

フラグ

項目
説明
-a すべての統計情報を表示します。
-d AIXスレッドの詳細なアフィニティとマイグレーション統計、および論理プロセッサのディスパッチ統計を表示します。
-i 詳細な割り込み統計情報を表示します。
-s 同時マルチスレッド化 スレッド使用率を表示します。このフラグは、 mpstat が 同時マルチスレッド化 対応区画で実行されている場合にのみ使用可能です。
-h 専用区画のスチールされた統計情報およびドネーションの統計情報とともに、pc およびプロセッサー・スイッチを表示します。
-w 幅の広い列出力を表示し、幅の広い出力モードに切り替えます。 デフォルトは、80 列出力モードです。
@ wparname 指定された WPARの統計情報を表示します。
-O オプション コマンド・オプションを指定します。

-O options=value ...

以下はサポートされるオプションです。

  • sortcolumn = mpstat コマンド出力内のメトリックの名前
  • sortorder = [asc|desc］
  • topcount = mpstat コマンドのソートされた出力に表示される CPU の数
-X XML 出力を生成します。 デフォルトのファイル名は mpstat_DDMMYYHHMM.xml です。ただし、ユーザーが -o オプションを使用して別のファイル名を指定する場合を除きます。
-o XML 出力のファイル名を指定します。
-v 仮想プロセッサー・レベルでの使用率統計を表示します。
注: -v フラグは、 POWER8 プロセッサー以降でのみ使用可能です。
-E SPURR 対応プロセッサーにおける SPURR ベースの使用状況メトリックを表示します。
注:
  1. -a、 -d、および -i フラグは、暗黙的にワイド・カラム出力をオンにします。
  2. WPAR内で、 -@ フラグはすべてのプロセッサーの統計情報を報告します。
  3. WPAR 内に表示されるプロセッサー統計は、常にシステム全体に適用されます。
  4. -o オプションのみが -X オプションと一緒に使用できます。

パラメーター

項目
説明
間隔 反復の間のインターバルを指定します。 interval を指定しなかった場合、 メトリックに関して 1 つのスナップショットだけ (実際には、 システムが開始されたとき以降の値を報告します) が表示されます。 interval が指定された場合、ツールはその時間だけ待ってから、データの最初のセットを印刷します。 データのそれぞれのセットの後には、分離行と、各列の平均値が入っている行 (プロセッサーは除く。これは ALL によって置換される) が続き、その後に空の行が続きます。
count 反復の回数を指定します。 interval が指定され、 count が指定されていない場合、 mpstat は無限に実行されます。 interval を指定せずに count を指定することはできません。

例

  1. 使用率メトリックのデフォルトのセットを表示するには、次のコマンドを入力します。
    mpstat 1 1
  2. 使用率メトリックのデフォルトのセットを広幅の表示モードで表示するには、次のコマンドを入力します。
    mpstat –w 1 1
  3. 詳細なディスパッチ & 親和性メトリックを表示するには、次のコマンドを入力します。
     mpstat –d 1 1
  4. 詳細な割り込みレポートを表示するには、次のコマンドを入力します。
    mpstat –i 1 1
  5. すべての統計情報を表示するには、次のコマンドを入力します。
    mpstat –a 1 1
  6. 同時マルチスレッド化 の使用率を確認するには、次のコマンドを入力します。
    mpstat –s 1 1
  7. WPARのすべてのプロセッサー・メトリックを表示するには、次のコマンドを入力します。
    mpstat -@ wparname
    注: WPAR のすべてのプロセッサー・メトリックを WPAR内で表示するには、次のコマンドを入力します。
    mpstat -@
  8. 列 cs のソートされた出力を表示するには、次のコマンドを入力します。
    mpstat -d -O sortcolumn=cs
  9. 最上位 10 CPU のリストを表示するには、次のコマンドを入力します。
    mpstat -a -O sortcolumn=min,sortorder=desc,topcount=10
  10. 仮想プロセッサーに基づくメトリックを表示するには、次のコマンドを入力します。
    mpstat –v
