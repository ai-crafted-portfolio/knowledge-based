目的

XKB キーボード記述をプリントします。

構文

xkbprint [ -? | -ヘルプ ] [ -色 ] [ -ドフツ ] [ -ディフス ] [ -エプス ] [ -適合 ] [ -フル ] [ -グリッド 解決策 ] [ -if FontName ] [ -ラベル タイプ ] [ -lc (L) ロケール ] [ -level1 ] [ -level2 ] [ -lg (L) グループ ] [ -ル レベル ] [ -モノ ] [ N 数値 ] [ -nkg 数値 ] [ -npk 数値 ] [ - ファイル ] [ -R ディレクトリー [ -ピクト 対象] ] ソース [ OutputFile ]

説明

xkbprintコマンドは、Sourceで指定されたXKBキーボード記述の印刷可能な、またはカプセル化されたPostScript記述を生成する。 Source は、 コンパイルされたキーマップの .xkm ファイルであり、 形状の記述または X ディスプレイの指定が入っています。 OutputFile が指定されると、xkbprint はそれに書き込みます。 指定されないと、xkbprint は出力ファイルを作成し、 要求されたフォーマットに応じて ソース・ファイルの拡張子を .ps または .eps に置き換えます。 ソースが非ローカル X ディスプレイの場合。例えば、:0xkbprint は、表示仕様に適切な接頭部を付加し、コロンを - (ダッシュ) に置き換えます。 ローカル・ディスプレイの場合、 xkprint は以下を使用します。server-nここで、 n は表示の番号です。

フラグ

項目
説明
-? | -ヘルプ 使用方法メッセージを出力します。
-色 形状ファイルに指定されているカラーを使ってプリントします。 デフォルトでは、 xkbprint は、 キーボード・イメージを単色でプリントします。
-dflts 存在していないコンポーネント (キーなど) のデフォルト名を算出しようとします。
-差分 (-diffs) 明示的にバウンドされたシンボルだけをプリントします。
-ープ音 カプセル化された PostScript ファイルを生成します。
適合 キーボード・イメージをページに適合させます。これはデフォルトです。
-full キーボードをフルサイズでプリントします。
-grid 分解能 キーボード上に Resolutionmm で格子をプリントします。
-もし FontName 指定された出力ファイルにダンプする、または出力ファイルが指定されていない場合は fontName.pfaにダンプする、内部 PostScript タイプ 1 フォントを指定します。 内部フォントがダンプされない場合、キーボード記述はプリントされません。
-label タイプ キーにプリントするラベルを指定します。 有効な値は次のとおりです。
  • none
  • name
  • コード
  • 記号
-lc ロケール KeySyms を解決するロケールを指定します。
-level1 レベル 1 PostScriptを生成します。
-level2 レベル 2 PostScriptを生成します。
-lg グループ キーボード・グループにシンボルをプリントします。 Group から始めます。
-ll レベル シフト・レベル Level からシンボルをプリントします。
モノ キーボードのイメージを単色で生成します。 これはデフォルトです。
-n 数値 プリント部数 (Number) です。
-nkg 数値 Number キーボード・グループのシンボルをプリントします。
-npk 数値 各ページにプリントするキーボード・イメージの数 Number を指定します。 EPS ファイルの場合、 これはプリントするキーボード・イメージの合計を指定します。
-o ファイル 出力を File へ書き込みます。
-R ディレクトリー ルート・ディレクトリーとして、 Directory を使用します。 すべてのパス名は、 Directory に関連して解釈されます。
-pict 対象 可能な場合、キー・シンボル名の代わりに絵文字の使用を制御します。 Which の有効な値は以下のとおりです。
  • all
  • none
  • common (デフォルト)。
-同期 X 要求を強制的に同期します。
-w レベル 警告レベルを設定します。
  • 0 はすべての警告を無効にします。
  • 10 はすべての警告を有効にします。
