目的

すべてのチューナブル・パラメーターをデフォルト値にリセットします。

構文

チューニング・デフォルト [ - [-K (K)] | P- ]

説明

tundefault コマンドは、すべてのチューニング・コマンド (ioo、 vmo、 schedo、 no、 nfso、および raso) を -D フラグ付きで開始します。 これは、-rが指定されていない限り、BosbootとReboot タイプのパラメー タ、およびデフォルト値よりも大きな値に設定されたIncrementalタイプのパラメータを除 く、すべてのAIX調整可能パラメータをデフォルト値にリセットする。 パラメーターを変更できない場合は、エラー・メッセージが 表示されます。

フラグ

項目
説明
-K 次のライブ・アップデート操作まで、チューナブル・パラメーターのデフォルト値へのリセット操作を据え置きます。 -r フラグが指定されると、tundefault コマンドは、nextboot ファイルおよび nextliveupdate ファイルに指定されたチューナブル・パラメーターをすべて、そのデフォルト値にリセットします。 -r フラグは、/etc/tunables/nextboot ファイルのスタンザを消去し、必要に応じて、bosboot 操作を実行するよう指示し、変更内容を適用するにはリブート操作が必要であることを示す警告メッセージを表示します。 -K フラグは、/etc/tunables/nextliveupdate ファイルのスタンザとチューナブル・パラメーターのデフォルト値を nextliveupdate ファイルに追加します。 この更新済み nextliveupdate ファイルは、次のライブ・アップデート操作に使用されます。
-p 変更内容を永続的にします。すべてのチューナブル・パラメーターをデフォルト値にリセット し、/etc/tunables/nextboot ファイルを更新します。
-r デフォルト値へのリセットを次のリブートまで据え置きます。 これにより /etc/tunables/nextboot ファイルのスタンザが消去されて、必要に応じて bosboot を提案し、リブートが必要なことを警告するメッセージを表示します。

チューナブル・パラメーターのタイプ

項目
説明
Dynamic 任意の時点で変更できます。
Static 変更できません。
Reboot リブート・シーケンス時にのみ変更できます。
Bosboot bosboot を実行してマシンをリブートした場合にのみ変更できます。
Mount 変更内容は、今後マウントされるファイルシステムまたはディレクトリーについてのみ 有効です。
Incremental ブート時を除いて、増分できます。
Connect 変更内容は、将来のソケット接続についてのみ有効です。

例

  1. すべてのチューナブル・パラメーターを永続的にそのデフォルト値にリセットするには、次のコマンドを入力します。
    tundefault -p

    チューニング・コマンドを起動するときに、すべてのコマンドに -Dp フラグ が付きます。 これにより、すべてのチューナブル・パラメーターをデフォルト値にリセットし ます。 さらに、 /etc/tunables/nextboot ファイルを更新し ます。 このコマンドは、すべてのチューナブル・パラメーターを完全に永続的にデフォルト値にリセ ットします。

  2. すべてのチューナブル・パラメーターの設定を次のリブートまで据え置くには、次のコマンドを入力します。
    tundefault -r
    このコマンドは、-Dr フラグを付けてすべてのチューニング・コマンドを呼び出します。 これにより、 /etc/tunables/nextboot ファイルの スタンザを消去し、必要に応じて、bosboot を提案し、 変更内容を有効にするにはリブートが必要なことを警告します。
  3. すべてのチューナブル・パラメーターの設定を次のリブートおよび次のライブ・アップデート操作まで据え置くには、次のコマンドを入力します。
    tundefault -r -K
    このコマンドは、-DrK フラグを付けてすべてのチューニング・コマンドを呼び出します。 このコマンドは、/etc/tunables/nextboot ファイルのスタンザを消去し、必要に応じて、bosboot 操作を提案し、変更内容を有効にするにはリブートが必要なことを警告します。 また、次のライブ・アップデート操作のためのチューナブル・パラメーターにデフォルト以外の値が設定されていた場合、このコマンドは、スタンザとデフォルト値を /etc/tunables/nextliveupdate ファイルに追加します。

ファイル

項目
説明
