目的

ドメインネームシステム（DNS）検索ユーティリティ。

構文

dig[@server] [-b address] [-c class] [-f file] [-k keyfile] [-m] [-p port#] [-q name] [-t type] [-v] [-x addr] [-y[hmac:] Keyname:secret] [-4] [-6][name][type][class][queryopt...]

dig [-h]

dig[global-queryopt...][query...]

説明

Domain Information Groper (dig) コマンドは、ドメインネームシステム (DNS) のネームサーバーを調べるための柔軟なツールである。 DNS ルックアップを実行し、照会されたネーム・サーバーから返された応答を表示します。 ほとんどのDNS管理者は、DNSの問題のトラブルシューティングに「digコマンドを使用する。

digコマンドは通常、コマンドライン引数とともに使用されるが、ファイルからルックアップ要求を読み込むバッチモードもある。 -hフラグを使うと、コマンドライン引数とオプションの簡単な要約が表示される。 digコマンドのBIND9実装では、コマンドラインから複数の検索を発行することができる。 特定のネームサーバーに問い合わせるように指示されない限り、「digコマンドは「/etc/resolv.confファイルにリストされている各サーバーを試行する。 使用可能なサーバーアドレスが見つからない場合、「digコマンドはローカルホストに問い合わせを送る。 コマンドライン引数やオプションを指定しない場合、「digコマンドはルートに対して「NSクエリーを実行する。

${HOME}/.digrc ファイルを通じて、 dig コマンドのユーザーごとのデフォルトを設定することができる。 digコマンドはこのファイルを読み込み、コマンドライン引数の前にあるオプションを適用する。 -rオプションは、予測可能な動作が必要なスクリプトではこの機能を無効にする。

IN」と「CHクラス名は、「IN」と「CHトップレベルドメイン名と重複している。 これらのハイレベル・ドメインを調べる際には、「-t」と「-cオプションでタイプとクラスを指定するか、「-qオプションでドメイン名を指定するか、「IN」と「CH名前を指定する。

IDN サポート

digコマンドが国際化ドメイン名（IDN）をサポートして構築されている場合、非ASCIIドメイン名を受け入れ、表示することができる。 digコマンドは、DNSサーバーにリクエストを送信したり、サーバーからの応答を表示したりする前に、ドメイン名の文字エンコードを変換する。 IDNサポートをオフにするには、'+idninと'+idnoutパラメーターを使うか、'IDN DISABLE環境変数を定義する。

例

次のコマンドは「digコマンドの使い方を示している：

ここで:
サーバー
照会するネームサーバーの名前または IP アドレス。 サーバーには、ドット付き10進数表記のIPv4アドレスか、コロン区切り表記のIPv6アドレスを指定する。 与えられたserver引数がホスト名の場合、'digコマンドはネームサーバーに問い合わせる前にその名前を解決する。 server引数が与えられない場合、'digコマンドは'/etc/resolv.confファイルを参照する。 アドレスが見つかれば、「digコマンドはそのアドレスのネームサーバーに問い合わせる。 -4または「-6オプションのいずれかが使用されている場合、 対応するトランスポートのアドレスのみが試行される。 使用可能なアドレスが見つからなかった場合、「digコマンドはローカルホストに問い合わせを送る。 応答するネームサーバーからの応答が表示されます。
name
検索するリソースレコードの名前。
type
必要なクエリのタイプを示す。 例えば、'ANY、'A、'MX、'SIGなど。 type 引数の値には、任意の有効な照会タイプを指定できます。 type引数が与えられない場合、'digコマンドは 'Aレコードを検索する。
