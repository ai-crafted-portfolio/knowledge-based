目的

システムの最小および最大機密ラベルを設定します。

構文

setsyslab

説明

setsyslab コマンドは、システムの最小機密ラベル (SL)、最大 SL、最小保全性ラベル (TL)、および最大 TL を設定します。 SL および TL の値は、/etc/security/enc/LabelEncodings ラベル・エンコード・ファイルから取り出されます。

セキュリティー

setsyslab コマンドは特権コマンドです。 以下の許可を持つユーザーのみが、コマンドを正常に実行できます。

項目
説明
aix.mls.system.label.write システム・ラベルを設定する場合に必要です。

アクセスされるファイル:

項目
説明
モード File
r /etc/security/enc/LabelEncodings

例

  1. システム・ラベルを設定するには、以下のコマンドを入力します。
    setsyslab

ファイル

項目
説明
/usr/sbin/setsyslab setsyslab コマンドが入っています。
/etc/security/enc/LabelEncodings システム・デフォルトのラベル・エンコード・ファイル。
