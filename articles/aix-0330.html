目的

特定の条件のファイルシステムをモニターします。

構文

新しいファイルシステム条件を追加またはモニターするには、以下の構文を使用します。
ctmonfs -a -n condition_name -f <fsname> -c <condition_type[,attr=value,...]> [-b <action_name> ] 
[-k <action_type[,attr=value,...]> [-i <interval>] [-m 0|1] [-e 0|1]
ファイルシステム条件の属性を変更するには、以下の構文を使用します。
ctmonfs -u -n condition_name [-f <fsname>] [-c <attr=value,...>] [-b|-B <action_name> ] 
[-k <attr=value,...>] [-i <interval>] [-m 0|1] [-e 0|1]
ファイルシステム条件を削除するには、以下の構文を使用します。
ctmonfs -r -F | -n condition_name
特定のファイルシステム条件をリストするか、すべてのファイルシステム条件をリストするには、以下の構文を使用します。
ctmonfs -l [-n condition_name]

説明

特定の条件のファイルシステムをモニターするには、ctmonfs コマンドを使用します。 条件は、ファイルシステムのモニターが必要となる基準を定義します。 アクションは、条件が発生したときに実行する必要があるコマンドを定義します。 アクションの指定は不要ですが、アクションの優先順位に従って実行する必要があるアクションを指定することもできます。 アクションの優先順位が指定されない場合、アクションは指定された順序で実行されます。 アクションを指定しない場合、アクションを実行せずに条件がトレース・ファイルに記録されます。 それぞれの条件またはアクションは、条件またはアクションの追加データを定義する属性から構成されます。

次の条件タイプがサポートされています。

fsspace
ファイルシステムのフリー・スペースをモニターします。 fsspace 条件タイプには以下の属性が含まれています。
method
ファイルシステム・スペースをモニターする方法を指定します。 有効な値は以下のとおりです。
free_percent
残りのスペースの合計のパーセントによってファイルシステムをモニターします。
free_space
残りのスペースの単位 (MB) によってファイルシステムをモニターします。
threshold_free_percent
ファイルシステムのフリー・スペースまたは残りのスペースの条件について、しきい値のパーセンテージ値を指定します。 つまり、条件が真となるのはフリー・スペースのパーセントがこの値以下となる場合です。
注: この属性は、 method 属性が free_percentに設定されている場合にのみ有効です。
threshold_free_space
ファイルシステムのフリー・スペース条件について、しきい値を MB で指定します。 つまり、条件が真となるのはフリー・スペースがこの値以下となる場合です。
注: この属性は、 method 属性が free_spaceに設定されている場合にのみ有効です。
rearm_value
条件が真の場合に threshold_free_percent 値または threshold_free_space 値の評価を停止し、rearm_value 属性値の評価を開始します。 リアーム条件は、 free_percent 値または free_space 値がこの値以上になると true になります。
注: rearm_value 属性はオプションです。 さらに、rearm_value 属性と rearm_waittime 属性は同時には使用できません。 rearm_value 属性が指定された場合、rearm_waitime 属性を指定してはなりません。
rearm_waittime
条件が真の場合に threshold_free_percent 値または threshold_free_space 値の評価を停止し、rearm_waittime 属性に指定されている時間の経過後にファイルシステムのモニターを再開します。 つまり、ファイルシステムのモニターは rearm_waittime 属性に指定されている期間だけ中断されます。
注: rearm_waittime 属性はオプションです。 さらに、rearm_value 属性と rearm_waittime 属性は同時には使用できません。 rearm_waittime 属性が指定された場合、rearm_value 属性を指定してはなりません。

次のアクション・タイプがサポートされています。

useraction
ユーザー・スクリプトまたは実行可能ファイルを開始します。 useraction アクション・タイプには以下の属性が含まれています。
パス
実行可能ファイルの名前を指定します。
優先
アクションの優先順位を指定します。 有効な値は正整数です。 数値が小さくなるほど優先順位が高くなります。 値 0 は、優先順位が指定されないことを意味します。

ctmonfs コマンドで指定される構成設定は /var/ct/cfg/fsmon.cfg ファイルに保存されます。 デフォルトでは、/var ファイルシステムは、関連付けられた useraction タイプを使用して fsspace 条件についてモニターされます。 fsspace 条件が真になった場合、デフォルトのスクリプトが呼び出されて /var/ct ディレクトリー内の不要なファイルが消去されます。

フラグ

-a
ファイルシステムをモニターするためのファイルシステム条件を作成します。
-u
既存のファイルシステム条件を変更します。
-r
ファイルシステム条件を削除します。 -F フラグが指定された場合、すべてのファイルシステム条件が削除されます。
-l
すべてのファイルシステム条件をリストします。 -n フラグを指定した場合、特定のファイルシステム条件のみがリストされます。
--n 条件名
ファイルシステム条件の固有の名前を指定します。 この名前を使用して、ファイルシステム条件をリスト、変更、または削除することができます。
--f fsname
モニターするファイルシステムの名前を指定します。
-条件タイプ
モニター対象となる条件タイプを指定します。 condition_type パラメーターは、条件タイプと、その後ろのコンマで区切られている属性で構成されます。 属性値を変更するには、-u オプションを使用して、変更する必要がある属性を指定します。
--b アクション名
アクションの固有の名前を指定します。 アクション名は、アクションの変更または削除に使用できます。
--B アクション名
指定したアクションを削除します。
--k action_type
条件が真になったときに実行する必要があるアクションを指定します。 action_type パラメーターは、アクション・タイプと、その後ろのコンマで区切られている属性で構成されます。 アクション・タイプの属性を変更するには、-u オプションを使用して、変更する必要がある属性を指定します。
注: 新規ファイル・システム条件の作成時に定義できるアクションは 1 つのみです。 条件にアクションを追加するには -u フラグを使用します。 条件にアクションが構成されない場合、条件が真になったときにイベントがトレース・ファイルに記録されます。
--i 間隔
条件が評価される間隔を秒単位で指定します。
-m [0|1]
ファイルシステムのモニターを有効または無効にします。 有効な値は次のとおりです。
1
ファイルシステムのモニターを有効にします。
0
ファイルシステムのモニターを無効にします。
-e [0|1]
エラー・ロギングを有効または無効にします。 有効な値は次のとおりです。
1
条件が真になったときにエラー・ログ・エントリーが作成されます。
0
条件が真になったときにエラー・ロギングが無効になります。

終了状況

0
コマンドは正常に完了しました。
1
エラーが発生しました。

例

  1. ファイルシステムのすべてのモニター条件をリストするには、次のコマンドを入力します。
    ctmonfs -l
  2. ファイルシステム・スペース (fsspace) をモニターし、フリー・スペース・パーセンテージが 10% より小さいときに /tmp/mycleanup コマンドを実行するには、次のコマンドを入力します。
    ctmonfs -a -n "var mon" -f "/var" -c "fsspace,method=free_percent,threshold_free_percent=10" 
-b "run cleanup" -k "useraction,path=/tmp/mycleanup" -i 1800 -m 1 -e 1
  3. 条件が評価される間隔を変更するには、次のコマンドを入力します。
    ctmonfs -u -n "var mon" -i 900
  4. 既存のアクション (run cleanup) のパス属性値を変更するには、次のコマンドを入力します。
    ctmonfs -u -n "var mon" -b "run cleanup" -k "path=/tmp/varcleanup"
  5. アクションを削除するには、次のコマンドを入力します。
    ctmonfs -u -n "var mon" -B "run cleanup"
  6. ファイルシステム条件を削除するには、次のコマンドを入力します。
    
ctmonfs -r -n "var mon"
  7. 既存のアクション (run cleanup) の優先順位を設定または変更するには、次のコマンドを入力します。
    ctmonfs -u -n "var mon" -b "run cleanup" -k "priority=1"

場所

/opt/rsct/bin/ctmonfs
ctmonfs コマンドが入っています。

ファイル

/var/ct/cfg/fsmon.cfg
ファイルシステムをモニターするための構成設定が入っています。
