目的

ファイルのアクセス制御情報を設定します。

構文

aclput [ -i inAclFile ] [ -R ] [ -t acl_type ] [ -v ]FileObject

説明

aclput コマンドは、 FileObject パラメーターで指定されたファイル・オブジェクトのアクセス制御情報を設定します。 -i フラグが指定されていない限り、このコマンドはアクセス制御情報を標準入力から読み取ります。

注: 標準入力から読み取る場合は、入力がアクセス制御情報の予期される形式と一致している必要があります。一致していない場合は、エラー・メッセージが表示されます。 セッションを完了させるには、Ctrl-D キー・シーケンスを使用してください。

アクセス制御リスト

アクセス制御リストは、ファイルシステム・オブジェクトに対する保護の中核を形成します。 各ファイル・システム・オブジェクトは、オブジェクトへのアクセス権限を定義する ACL と呼ばれる 1 つのデータに一意的に関連付けられます。 ACL は、複数のアクセス制御項目 (ACE) で構成される場合があります。各 ACE は、ユーザーに対して 1 つの特定のアクセス権限のセットを定義します。 一般的には、ACE は、識別 (この ACE の適用対象ユーザー) およびアクセス権限 (読み取り許可、書き込み 否認) などの情報から成ります。 なお、ACE は、継承フラグ、および アラーム・フラグと監査フラグなどの情報を取り込む場合も あります。 ACL データのフォーマットおよび制約は、ACL データが定義されている ACL タイプによってまったく 異なります。 AIXでは、オペレーティング・システム上に複数のACLタイプが存在する。 ファイル・システム・インスタンスによってサポートされる ACL のリストは、そのファイル・システム・インスタンスの物理ファイル・システム実装によって異なります。

-i inAclFile アクセス制御情報の入力ファイルを指定します。 InAclFileパラメータで指定されたファイルのアクセス制御情報が正しくない場合、それをファイルに適用しようとすると、入力ファイルにアスタリスクで始まるエラーメッセージが追加される。
注: ACL 情報のサイズは、ACL タイプによって異なります。
-R ACL をこのディレクトリーとその子ファイル・システム・オブジェクトに再帰的に適用します。
-t ACL_type 表示される ACL 情報の ACL タイプを指定します。 オプションが指定されていない場合、元の ACL タイプの実際の ACL データが表示されます。 サポートされる ACL タイプは ACLX および NFS4 です。
-v 詳細オプション。 このオプションでは、多くのコメント行が ACL データ表示の一部として 表示されます。 このコメントは、複雑な ACL タイプの詳細を理解するのに役立つ場合があります。

例

  1. 標準入力からの情報を使用して状況ファイル用のアクセス制御情報を設定するには、次のように入力します。
    aclput status
attributes: SUID
    そして、Ctrl-D キー・シーケンスを押して、セッションを終了します。
  2. acldefs ファイルに格納されている情報を使用して status ファイル用のアクセス制御情報を設定するには、次のように入力します。
    aclput -i acldefs status
  3. plans ファイルに使用したものと同じ情報を使用して status 用のアクセス制御情報を設定するには、次のように入力します。
    aclget plans | aclput status
  4. plans ファイルのアクセス制御情報の編集版を使用して status ファイルのアクセス制御情報を設定するには、2 つのコマンドを入力する必要があります。 最初に、次のように入力します。
    aclget -o acl plans
    これにより、plans ファイル用のアクセス制御情報が acl ファイルに格納されます。 任意のエディターを使用して、 acl ファイル内の情報を編集します。 その後で、次のように入力します。
    aclput -i acl status
    この 2 番目のコマンドは、acl ファイル内のアクセス制御情報を取り出して、それを status ファイルに入れます。
