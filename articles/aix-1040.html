目的

nimclientコマンドは、NIMクライアントからネットワーク・インストレーション・マネージメント（NIM）操作を実行できるようにする。

構文

NIMマスターのプッシュ権限を有効または無効にするには
nimclient { -p } | { -P }
NIMマスタープッシュ操作で暗号化認証を有効または無効にするには
nimclient { -c } | { -C }
NIM環境に関する情報を掲載するには
nimclient -l LsnimParameters
NIMマスターの日時を設定するには
nimclient -d
NIMオペレーションを実行するには
nimclient -o Operation [ -a Attribute=Value  ] ...

説明

nimclient コマンドは、NIM クライアントのワークステーションで NIM リソースを取り出すために使用します。 このコマンドを使用すると、NIM マスター・サーバーでワークステーションをインストールおよびカスタマイズする機能を使用可能にしたり使用不可にしたりできます。 nimclientコマンドは、利用可能なNIMリソースのリストを生成したり、すでにクライアントに割り当てられているNIMリソースを表示したりするのに使用できる。 nimclientコマンドに「-oフラグを付けると、限定されたNIM操作を実行できる。

マスターから
特定の操作に有効な属性のリストを取得するには、'lsnim -q Operation -t Typeコマンドを使用する。
クライアントから
特定の操作に有効な属性のリストを取得するには、'nimclient -l -q Operation -t Typeコマンドを使用する。

-C SSL 認証を使用不可にし、NIM マスター・プッシュ操作の際に標準の nimsh セキュリティーを使用します。
-d クライアントの日時をマスターの日時に設定します。
-e デュアル・スタック・モードをサポートするように NIM クライアント環境を構成します。これは、単一のインターフェース定義による IPv4 および IPv6 プロトコルの実装を意味します。
注：デュアルスタック環境を設定する前に、「autoconf6コマンドを実行し、「ndpd-hostデーモンを起動する。
-l Lsnimパラメータ 指定した 'lsnimパラメータを使用して、マスター上で 'lsnimコマンドを実行する。 このオプションで使用するすべてのパラメータは、「lsnimコマンドの構文規則に従わなければならない。 一部の「lsnim構文では、NIMオブジェクト名を使用する必要がある。 ご使用のマシンの NIM 名は、 /etc/niminfo ファイルで調べてください。
注記: から 7.3AIX®、テクノロジーレベル3において、NIMオブジェクトタイプ向けに新しい customer オブジェクトタイプが導入されます。 NIM customer オブジェクトタイプの導入に伴い、` nimclient -l command`は現在の customer オブジェクトグループに属するリソースのみを表示します。 NIMオブジェクトタイプの詳細については、コマンド nim ページのフラグ -t を参照してください。
-o Operation 指定された操作を行います。 以下は可能な操作である：
allocate
リソースを割り当てて使用できるようにします。
bos_inst
BOS インストールを実行します。
change
オブジェクトの属性を変更します。
check
NIM オブジェクトの状況を検査します。
cust
ソフトウェアのカスタマイズを実行します。
deallocate
リソースの割り当てを解除します。
diag
この操作により、マシンは診断イメージをブートできるようになる。
maint_boot
この操作により、マシンをメンテナンスモードで起動できるようになる。
reset
オブジェクトの NIM 状態をリセットします。
showres
NIM リソースの内容を表示します。
-p -pフラグは、NIMマスターがコマンドをプッシュできるようにする。
-P コマンドをプッシュするためのNIMマスターの権限を削除する。
注: マスターは、-F フラグを使用してこの制限を変更できます。
注： この nimclient -l -POt standalone コマンドの出力には、NIMマスターがスタンドアロンのNIMオブジェクトに対して実行できる操作が表示されます。 クライアントは、この nimclient -l -POt standalone コマンドで指定されたすべての操作を実行できません。 クライアントは、この nimclient -o <Operation> コマンドを使用して、有効な操作の限定されたセットを実行できます。 コマンド nimclient --? を使用すると、有効な操作の一覧を確認できます。

セキュリティー

アクセス制御
nimclientコマンドを実行するには、root権限が必要です。
RBCAユーザー
RBACユーザーに注意：このコマンドは特権操作を実行することができます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. plutoこのマシンの NIM 名が である場合、このマシンで利用可能なすべての NIM リソースを一覧表示するには、次のコマンドを入力してください：
    nimclient -l -L pluto
  2. plutoこのマシンの NIM 名が である場合に、このマシンで利用可能なすべての共有製品オブジェクトツリー（SPOT）を一覧表示するには、次のコマンドを入力してください：
    nimclient -l -L -t spot pluto
  3. このマシンから実行される可能性のある操作を一覧表示するには、次のコマンドを入力してください：
    nimclient -l -p -s pull_ops
  4. NIMマスターがクライアント上でローカルにコマンドを実行できないようにするには、次のコマンドを入力してください：
    nimclient -P
  5. dept_bundleimagesmyspot次のコマンドを入力して、という名前のスポットリソース、という名前のリソース lpp_source 、およびという名前のinstallpバンドルファイルを割り当てます：
    nimclient -o allocate -a spot=myspot -a lpp_source=images \
-a installp_bundle=dept_bundle
  6. 必要なリソースが割り当てられた後、以下のコマンドを入力してベースシステムのインストールを実行します：
    nimclient -o bos_inst
  7. imagesadtスタンドアロンクライアントから、インストール可能オプションのイメージが lpp_source に含まれるソフトウェア製品を lpp_source 割り当ててインストールするには、次のコマンドを入力します：
    nimclient -o allocate -a lpp_source=images
    そして次のコマンドを入力する：
    nimclient -o cust -a filesets="adt"
  8. bundle3imagesadtスタンドアロンクライアントから、インストール可能オプションのイメージが lpp_source に、インストール可能オプションの名前が installp_bundle に含まれるように、ソフトウェア製品を lpp_source 割り当ててインストールするには、次のコマンドを入力します：
    nimclient -o allocate -a lpp_source=images \
-a installp_bundle=bundle3
    次のコマンドを入力します。
    nimclient -o cust
  9. updt_imagesIX12345lpp_source にある APAR に関連するすべてのファイルセットの更新プログラムをインストールするには、次のコマンドを入力してください：
    nimclient -o allocate -a lpp_source=updt_images
nimclient -o cust -afixes=IX12345
  10. lpp_source1lpp_sourceIX12345 スタンドアロンの NIM から、 にある APAR のライブアップデートを実行するには、次のコマンドを入力します
    nimclient -o allocate -a lpp_source=lpp_source1
nimclient -o cust -a live_update=yes -a filesets=IX12345
  11. lpp_sourceupdt_images 以下のコマンドを入力して、クライアントにインストールされているすべてのソフトウェアを、からの最新の更新プログラムで更新してください：
    nimclient -o allocate -a lpp_source=updt_images
nimclient -o cust -afixes=update_all
  12. spot1以下のコマンドを入力して、という名前の SPOT リソースを使用して、システムがメンテナンスモードで起動するように設定します：
    nimclient -o maint_boot -a spot=spot1
    このコマンドはメンテナンスブート操作を設定しますが、ネットワークブートはローカルで開始する必要があります。
  13. script1設定スクリプトの内容を表示するには、次のコマンドを入力してください：
    nimclient -o showres -a resource=script1
  14. bosinst_data1リソース bosinst.data の内容を表示するには、次のコマンドを入力してください：
    nimclient -o showres -a resource=bosinst_data1
  15. machine1machine1NIMクライアントマシンから、そのマシンに現在インストールされているものに関連するすべてのファイルセット lpp_source1 を一覧表示するには、 lpp_source 次のコマンドを入力してください：
    nimclient -o showres -a resource=lpp_source1
    reference 属性は、nimclient コマンドによって自動的に提供されます。
  16. lpp_source1lpp_source 以下のコマンドを入力して、ソフトウェアによって修正されたすべての問題を表示してください：
    nimclient -o showres -a instfix_flags="T" -a resource=lpp_source1
  17. client_imageslpp_source を使用して、NIM client_bundle installp_bundle にリストされているファイルセットをインストールし、インストール操作中にこれらのリソースを自動的に割り当てるには、次のコマンドを入力します
    nimclient -o cust -a installp_bundle=client_bundle \
-a lpp_source=client_images
  18. client_grp以下のコマンドを入力して、という名前の NIM リソースグループから、該当するすべてのリソースを自動的に割り当てながら、ベースシステムのインストールを実行します：
    nimclient -o bos_inst -a group=client_grp
  19. マスター上でデフォルトのリソースグループとして定義された NIM グループから、適用可能なすべてのリソースを自動的に割り当てながら、ベースシステムのインストールを実行するには、次のコマンドを入力します
    nimclient -o bos_inst
  20. SSL の証明書をコピーし、 SSL 認証を有効にするには、次のコマンドを入力してください：
    nimclient -c
    注：このコマンドオプションを使用する前に、NIMクライアントにOpenSSLをインストールしておく必要がある。
  21. デュアルスタック環境を設定するには、次のコマンドを入力してください：
    nimclient -e  en0
