目的

クライアント・マシンを特定のサーバーに割り当てます。

構文

/usr/sbin/ypset [ -V1 ] [ -d Domain ] [ -h Host ] Server

説明

ypset コマンドは、クライアント上の ypbind デーモンをサーバーの ypserv デーモンへ割り当てます。 バインド デーモンは、 サーバー パラメーターで指定されたサーバーに移動し、 ドメイン パラメーターで指定されたドメインの ネットワーク情報サービス (国家情報院) サービスを取得します。 バインド デーモンは、サーバー上の Ypserv デーモンから 国家情報院 サービスを取得します。

割り当てが設定されると、 クライアント・プロセス (ypcat コマンドや ypwhich コマンドなど) によって ドメインのための割り当てを得ようとするまで、検査は行われません。 バインドが失敗に終ると (指定されたサーバーがダウンしたり、ypserv デーモンを実行しない場合)、再び ypbind デーモンは 同じドメインのためにバインドを試みます。

Server パラメーターには名前またはインターネット・プロトコル (IP) のアドレスのどちらかを指定してください。 名前を指定すると、 セット コマンドは 国家情報院 サービスを使用して、名前を IP アドレスに解決しようとします。 これは、コンピューター上で、問題となっているドメインのための有効な割り当てが現在行われているときのみ働く機能です。 ほとんどの場合、サーバーを IP アドレスとして指定することになります。

ローカル・ネットワーク上の複数のホストが 国家情報院 サービスを提供している場合、 バインド デーモンは別のホストに再バインドすることができます。 サーバーがダウンしたり ypserv デーモンを実行していないとき、ypbind デーモンはクライアントを他のサーバーへ再バインドします。 このようにして、ネットワーク情報サービスは、使用可能な 国家情報院 サーバー間で負荷のバランスを取ります。

下記の場合には ypset コマンドを使います。

  • ブロードキャストをサポートしません。
  • ブロードキャストをサポートしますが、 国家情報院 サーバーはありません。
  • 特定の 国家情報院 サーバー上にのみ存在するマップにアクセスします。

ypset を使用する代替方法は、/var/yp/binding/domain_name/ypservers ファイルを使用することです。 このファイル (存在する場合) は、1 回線につき 1 台のサーバーをバインドしようとする NIS サーバーのリストを含んでいるはずです。 ypbind デーモンが ypservers ファイルにある どのサーバーにもバインドできない場合は、ypset によって指定されているサーバーを使用しようとします。 失敗する場合は、サブネット上で NIS サーバーを求めてブロードキャストします。

フラグ

表 1. フラグ
項目
説明
-d ドメイン デフォルト・ドメイン以外のドメインを指定します。
-h ホスト ローカル・ホストの代わりに指定されたホスト上に、ypbind デーモンのための割り当てを設定します。 ホストは名前として、または IP アドレスとして指定できます。
-V1 (旧) バージョン 1 国家情報院 プロトコル用に指定されたサーバーをバインドします。

例

特定のドメイン内のホスト上でバインドされるサーバーを設定するには、下記のように入力します。

ypset -d ibm -h venus mars

この例では、 セット コマンドにより、以下の名前のホストが作成されます。venus指定されたサーバーにバインドします。mars.
