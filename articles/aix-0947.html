目的

指定された CPU およびメモリー領域を含む rset を作成し、この rset をシステム・レジストリーに入れます。

構文

mkrset -c CPUlist [ -m MEMlist ] rsetname

説明

mkrset コマンドは、CPU および/またはメモリー領域の指定のセットを持つ rset または排他的 rset (xrset) を作成して、システム・レジストリーに入れます。 rset 名はレジストリー内に存在しないものにしてください。 rset のオーナー ID およびグループ ID は、 コマンド発行者のオーナー ID およびグループ ID に設定されます。 rset に関して、オーナーは読み取り/書き込み許可、グループとその他のユーザーは読み取り許可が与えられます。 mkrset コマンドを使用して xrset を作成すると、システム上の対応する CPU の状態が排他モードに変更されます。 xrset の作成には root 権限が必要です。

フラグ

項目
説明
-c rset に含める CPU のリスト。 これは、1 つ以上の CPU または CPU 範囲にすることができます。
-m rset に含めるメモリー領域のリスト。 これは、1 つ以上のメモリー領域または範囲にすることができます。

パラメーター

項目
説明
セット名 システム・レジストリーに入れる rset の名前。 名前は、"/" (スラッシュ) で区切られた namespace と rsname で構成されます。 namespace および rsname はどちらも最大 255 文字まで含むことができます。 rset 名の文字セット制限についての追加情報は、rs_registername() サービスを参照してください。

セキュリティー

ユーザーは、root 権限か CAP_NUMA_ATTACH および CAP_PROPAGATE を使用する能力を持っていなければなりません。

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. CPU 0 から 7 が含まれ、 名前が test/cpus0to7 の rset を作成するには、次のように入力します。
    mkrset -c 0-7 test/cpus0to7
  2. CPU 1、3、5、6、7、10 が含まれ、 名前が test/lotsofcpus の rset を作成するには、 次のように入力します。
    mkrset -c 1 3 5-7 10 test/lotsofcpus

ファイル

項目
説明
/usr/bin/mkrset mkrset コマンドが入っています。
