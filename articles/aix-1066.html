目的

nxstat コマンドは、GZIP 機能を実装可能なオンチップ・ハードウェア・アクセラレーターの使用統計を表示します。

構文

nxstat { -S [ -v ] | [ -A -U -W -T ] [ -a accel_type ] [ -u unit_index ] [ -w window_index ] [ -t window_type ] interval [ count ] }

説明

AIX® の論理パーティション上のアプリケーションは、 zlibNX ライブラリを使用してGZIPアクセラレータとの通信チャネルを開きます。 この通信チャネルは、ウィンドウとも呼ばれます。 通信チャネルの種類に関する詳細については、 「Nestアクセラレータ 」のセクションを参照してください。

ウィンドウごとの低レベル使用統計には、システム管理者には重要でないデータが大量に含まれている場合があります。 nxstat コマンドは、コマンドで指定したオプションと引数に基づいて、特定のアクセラレーター・タイプまたは特定のハードウェア・アクセラレーター・ユニットのグローバル使用統計を提供するように、使用統計を集約できます。

使用状況の統計情報には、各集計レベルごとに以下の値が、ウィンドウの種類および対応するクレジットとともに表示されます：
表 1. 利用統計値
値
説明
オープンの数 ウィンドウに対する開閉操作の回数。
バイト数 ハードウェアアクセラレータユニットによって処理されたバイト数。
フォールト ハードウェアアクセラレータユニットが検出したページフォルトの数。
イントロ 完了割り込みの数。 この値は、アクセラレーター操作用のオプションです。

アクティブなGZIP操作の完了を待機するカーネルサービスは、スレッドをブロックする前に、まず少し completion の間待機します。 Polls 値と Waits 値の合計数は、ポーリング・フェーズの効率性と有用性に関する洞察を提供します。

nxstat コマンドは、特定の時間間隔中の特定のアクセラレーター・タイプの使用統計を集約します。 nxstat コマンドは、連続する時間間隔についてのアクセラレーター使用統計も表示することができます。 フラグ -A、-U、-T、および -W で集約レベルが決まります。 複数のフラグを指定した場合（たとえば、 -AU flag）、コマンド nxstat は両方の集計レベルに関する使用統計を表示します。 , -u, -t, および -w フラグは -a、統計データをアクセラレータユニット、ウィンドウ、ウィンドウタイプなどの特定のオブジェクトに限定するために使用されます。

フラグ

表2. フラグ
項目
説明
-S 利用可能なアクセラレータの種類を表示します。
-v

この -v フラグを指定すると、詳細な出力が表示されます。

この -S-v フラグを指定すると、Nest Accelerator (NX) の GZIP 設定に関する詳細情報が表示されます。 以下の詳細が表示されます：
  • パーティションがアクセスできるアクセラレータユニットの数。
  • パーティションに割り当てられたサービス品質（ QoS ）クレジットとデフォルトクレジットの合計数。
  • QoS およびデフォルトのウィンドウの現在の数。
-A 特定アクセラレーター・タイプの使用統計を表示します。 これはデフォルト・オプションです。
-U 特定ハードウェア・アクセラレーター・ユニットの使用統計を表示します。
-T 特定ウィンドウ・タイプの使用統計を表示します。
-W 各ウィンドウの使用統計を表示します。
-a 使用統計を表示するアクセラレーター・タイプを指定します。 GZIP アクセラレーターの -a フラグ値は 0 です。 現在、 -a フラグでサポートされている値は 0 のみです。 したがって、 -a フラグを指定しない場合は、デフォルト値の 0 が適用されます。
-u 使用統計を表示するアクセラレーター・ユニットを指定します。 このフラグ -u は、必ず フラグ -U と組み合わせて指定してください。 このフラグのアクセラレーター・ユニット索引値は、ゼロからアクセラレーター・ユニット数マイナス 1 までの数値です。 たとえば、 AIX という論理パーティションが3つのアクセラレータ・ユニットにアクセスできる場合、このフラグに指定できる有効な値は0、1、および2となります。

この -u フラグが フラグ -U と共に指定されていない場合、この nxstat コマンドは、論理パーティションがアクセス可能なすべてのハードウェアアクセラレータユニットのデータを表示します。
-w 使用統計を表示する特定ウィンドウを指定します。 論理区画から n 個のウィンドウにアクセス可能な場合、ウィンドウには 0 から n-1 までの番号が付けられます。 -W フラグを指定する場合にのみ -w フラグを指定できます。
-t 使用統計を表示する特定ウィンドウ・タイプ (Quality of Service (QoS) の場合は 0、デフォルトの場合は 1) を指定します。 -T フラグを指定する場合にのみ -t フラグを指定できます。
注：、 -u -w、および -t フラグは、互いに排他的です。
Interval 使用統計を収集する必要のある時間間隔 (秒) を指定します。 このフラグは必須です。 デフォルトでは、カーネル・サービスは 2 秒ごとに使用統計を収集するため、有用なデータを表示するには、2 秒より長い時間間隔を指定する必要があります。
カウント 使用統計を表示する、連続する時間間隔の数を指定します。 デフォルト値は 1 です。

  • すべてのアクセラレータタイプおよびすべてのウィンドウタイプに関する総使用統計を表示するには、次のコマンドを実行してください：
    nxstat 10 4
    次の例に示すような出力が表示されます。
