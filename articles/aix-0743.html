“注: これは System V Print Subsystem コマンドです。”

目的

(BSD) ライン・プリンター制御を提供します。

構文

/usr/ucb/lpc [ Command [ Parameter .. :NONE.

説明

lpc コマンドは、 プリンターの操作を制御します。 複数のプリンターを制御することもできます。 lpc コマンドを使用して、 プリンターを始動または停止したり、 プリンターのスプール・キューを使用不可または使用可能にしたりできます。 また、キュー内のジョブの順序を配列し直したり、 スプール・キューまたはプリンター・デーモンを含む各プリンターの状況を表示することもできます。

lpc -? を入力した場合は、コマンド使用方法メッセージが表示され、0 が戻されます。

パラメーターを指定しないと、 lpc コマンドは対話式に実行され、以下のプロンプトが出されます。lpc>. パラメーターを指定すると、 lpc コマンドは最初のパラメーターを実行する コマンド として解釈します。後続の各パラメーターは、そのコマンドの パラメーター と見なされます。 標準入力をリダイレクトして、 lpc コマンドはファイルから Command を読み取ることができます。

Command は、間違えようのないサブストリングに省略できます。

“注: printer パラメーターはプリンター名 (lw) で指定されます。 lpr または lpq の指定方法とは異なります (-Plw ではない)。”

項目
説明
? [ コマンド..]  
help [ コマンド ..] パラメーター・リストで指定された各コマンドか、 パラメーターが指定されない場合は認識されたコマンドのリストにあるコマンドの簡略説明を表示します。
abort [ all | [ Printer .. :NONE. ローカル・ホスト上のアクティブのスプーリング・デーモンを即時に終了し、 (新しいデーモンが lpr によって開始しないようにして) 指定されたプリンターの印刷を使用不可にします。 abort コマンドは特権ユーザーだけが使用できます。
clean [ all | [ Printer .. :NONE. ローカル・マシンの指定されたプリンター・キューから、 デーモンがスプール・ディレクトリーに作成したすべてのファイルを除去します。 clean コマンドは特権ユーザーだけが使用できます。
disable [ all | [ Printer .. :NONE. 指定されたプリンター・キューをオフにします。 これにより、 lpr がキューに新規のプリンター・ジョブを入れないようにします。 disable コマンドは特権ユーザーだけが使用できます。
down [ all | [ プリンター.. ]] [ メッセージ ] 指定されたプリンター・キューをオフにし、 印刷を使用不可にして、 Message をプリンター状況ファイルに書き込みます。 メッセージは引用される必要はありません。 残りのパラメーターは、 echoのように扱われます。 これは通常、 プリンターをダウンさせ、 その理由を知らせるために使用されます (lpq は、 status コマンドと同様、 プリンターがダウン状態にあることを示します)。
enable [ all | [ プリンター.. :NONE. リストされたプリンターのローカル・キューのスプーリングを使用可能にして、 lpr が新規ジョブをスプール・キューに入れられるようにします。 enable コマンドは特権ユーザーだけが使用できます。
exit lpc を終了します。
quit lpc を終了します。
restart [ all | [ プリンター.... :NONE. 新規のプリンター・デーモンの開始を試みます。 これは、異常条件のためにデーモンが、 キューにジョブを残したまま予期せずに終了するときに使用できます。 このコマンドはだれでも実行できます。
start [ all | [ プリンター... :NONE. 印刷を使用可能にし、 リストされたプリンターのスプーリング・デーモンを開始します。 start コマンドは特権ユーザーだけが使用できます。
status [ all | [ プリンター...]] ローカル・マシン上のデーモンおよびキューの状況を表示します。 このコマンドはだれでも実行できます。
stop [ all | [ プリンター... :NONE. ジョブが完了し、印刷が使用不可になった後、 スプーリング・デーモンを停止します。 stop コマンドは特権ユーザーだけが使用できます。
topq プリンター [ Job#...] [ User...] Job# によって指定された印刷ジョブ、 または User に属するジョブをプリンター・キューの上部 (ヘッド) に移動します。 topq コマンドは特権ユーザーだけが使用できます。
up [ all | [ プリンター...]] すべて使用可能にし、 新規のプリンター・デーモンを開始します。 down の効果を取り消します。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。
