目的

リソース・レコード (RR) を生成します。

構文

dnssec-dsfromkey [ -1 | -2 | -a アルゴリズム ] [ -C ] [-T ttl] [-v レベル] [-K ディレクトリー] {keyfile}

dnssec-dsfromkey [ -1 | -2 | -a アルゴリズム ] [ -C ] [-T ttl] [-v level] [-c class] [-A] {-f file} [dnsname]

dnssec-dsfromkey [ -1 | -2 | -a アルゴリズム ] [ -C ] [-T ttl] [-v level] [-c class] [-K directory] {-s} {dnsname}

dnssec-dsfromkey [-h | -V ]

説明

dnssec-dsfromkeyコマンドの'-Cオプションは、委任署名者(DS)のリソースレコード署名(RR)または子譲 渡署名者(CDS)のRRを表示する。 デフォルトでは、鍵署名鍵（KSK）、すなわち257のフラグを持つ鍵のみが「DSレコードに変換される。 -Aオプションには、DSレコードに変換するための、256個のフラグを持つゾーン 署名鍵(ZSK)を含める。 DS レコードへの変換には、取り消された鍵は含まれません。 入力キーは以下の方法で指定できる：
  • デフォルトでは、「dnssec-dsfromkeyコマンドは、「dnssec-keygenコマンドで生成された 「Knnnn.+aaa+iiiii.key形式のファイル名を持つ鍵ファイルを読み込む。
  • -fオプションを指定した場合、'dnssec-dsfromkeyコマンドはゾーンファイル、または'DNSKEYレコードのみを含むことができる部分ゾーンファイルからキーを読み込む。
  • -sオプションをつけると、「dnssec-dsfromkeyコマンドは「dnssec-keygen -Cコマンドによって生成された「keyset-ファイルを読み込む。

フラグ

-1
このオプションは、「-a SHA1アルゴリズム値の省略形である。
-2
このオプションは、「-a SHA-256アルゴリズム値の省略形である。
-a アルゴリズム

DNSKEYレコードを'DSレコードに変換する際に使用するダイジェストアルゴリズムを指定する。 このオプションを複数回使用すると、各「DNSKEYレコードに対して複数の「DSレコードを作成することができる。

algorithmの値は'SHA-1、'SHA-256、'SHA-384いずれかでなければならない。 これらの値は大/小文字を区別せず、ハイフンは省略できます。 デフォルト値は「SHA-256である。

-A
DSレコードの生成にZSKを含める必要があることを示す。 このオプションを指定しないと、'KSKフラグが設定されているキーのみが'DSレコードに変換されて印刷される。 このフラグは、'-fフラグも使用している場合にのみ有効である。
-c class
ドメインネームシステム（DNS）クラスを指定します。 デフォルト値はINです。 このフラグは、'-fフラグまたは'-sフラグも使用している場合にのみ有効である。
-C
DSレコードの代わりに'CDS生成する。
-ffile

このモードでは、'dnssec-dsfromkeyコマンドの最終引数dnsnameは、 プライマリファイルが読み込めるゾーンのDNSドメイン名となる。 ゾーン名が file 引数の値と同じ場合は、 file 引数を省略できます。

file引数の値が'-（ハイフン）の場合、ゾーンデータは標準入力から読み込まれる。 その後、 dig コマンドの出力を入力として使用できます。 次に例を示します。
dig dnskey example.com | dnssec-dsfromkey -f - example.com
-h
使用法情報を印刷します。
-K ディレクトリー
BIND 9 を指定して、指定されたディレクトリー内の鍵ファイルまたは keyset- ファイルを検索します。
-s
dnssec-dsfromkeyコマンドの最後のdnsname引数が、'keyset-ファイルを見つけるために使われる DNSドメイン名になる。
-T トル
DS レコードの存続時間 (TTL) を指定します。 デフォルトでは、TTL は省略されています。
-v レベル
デバッグのレベルを設定します。
-V
バージョン情報を印刷します。

例

Kexample.com.+003+26160キー・ファイルから「SHA-256 DS RRビルドするには、以下のコマンドを入力する：
dnssec-dsfromkey -2 Kexample.com.+003+26160
次の例に示すような出力が表示されます。
example.com. IN DS 26160 5 2 3A1EADA7A74B8D0BA86726B0C227AA85AB8BBD2B2004F41A868A54F0C5EA0B94

ファイル

鍵ファイルは、 dnssec-keygen コマンドによって生成された鍵 ID Knnnn.+aaa+iiiii または完全ファイル名 Knnnn.+aaa+iiiii.keyによって指定できます。

キーセットの名前は、ディレクトリ名、文字列「keyset-、dnsnameから作られる。

注: 鍵ファイルが存在する場合でも、 「ファイルが見つかりません」というエラーが返されることがあります。
