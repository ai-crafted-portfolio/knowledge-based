目的

指定した物理または仮想ファイバーチャネル（FC）デバイスドライバが収集した統計情報を表示します。

構文

fcstat [ -z [ -d | -c ]| -d | -e [ -d | -c ]| -c ] デバイス名

fcstat -t 間隔 [ -p プロトコル ] Device_Name

fcstat-l 持続時間 [ インターバル ] デバイス名

説明

fcstat コマンドは、指定した物理または仮想FCデバイスドライバーが収集した統計情報を表示します。 デバイス汎用統計情報に加えて、デバイス固有の統計情報を表示するように指定することもできます。 フラグを指定しない場合、 fcstat コマンドはデバイス一般統計情報のみを表示します。 fcstat コマンドは、以下の手順を使用して統計を収集します。
  1. fcstat コマンドのメッセージカタログを開き、パラメータのリストをチェックする。
  2. Object Data Manager ( ODM ) データベースにアクセスして、選択したアダプタに関連する情報を取得します。
  3. 選択したアダプタのポートに関連する情報を ODM データベースにアクセスします。
  4. アダプタの統計情報を開き、アクセスする。
  5. -z フラグが指定されている場合は、一部の統計情報をリセットする。
  6. 統計と終了を報告する。

無効な Device_Name が指定された場合、 fcstat コマンドは、 ODM データベース内でデバイスが見つからないことを示すエラー・メッセージを返します。

指定された Device_Nameがネットワークに接続されていない（つまり、リンクがダウンしている）場合、 fcstat コマンドは診断モードでデバイスを開いて統計情報を報告します。 fcstat コマンドは、 -d フラグを使用して、デバイスを診断モードで開きます。 リンクがダウンし、デバイスが非診断モードでオープンされている場合、 fcstat コマンドは出力の生成を遅らせる。 -c フラグを使用して、この遅延をなくすことができます。 デバイスがすでにオープンされており、 fcstat コマンドが -d フラグ付きで開始された場合、デバイスのオープン操作は EACCESS エラーで失敗する。

fcstat 、指定された Device_Nameから統計情報を抽出できなかった場合、 fcstat 、 ODM データベースから抽出した情報を報告する。

fcstat コマンドを使用すると、 -t フラグを使用して、トラフィック統計の時系列レポートを継続的に生成できます。 -t フラグの Interval パラメーターは、各レポート間の時間間隔を秒単位で指定します。 Interval パラメーターの値としてゼロを指定すると、 fcstat コマンドは単一のレポートを作成します。 各レポートでは、1 行に 1 つのトランスポート・プロトコル (TP) のトラフィック統計が出力されます。 アダプタが多数の TP をサポートしている場合、各プロトコルの統計は別々の行に表示される。 特定の TP の時系列レポートを生成するには、 -p フラグの Protocol パラメータを使用して TP を指定します。

fcstat コマンドを使用すると、以下の統計情報の時系列レポートを作成できます：
  • Read Reqs(K)
    読み取りまたは入力要求の数を千単位で示す。
    Write Reqs(K)
    書き込みまたは出力要求の数を示す。
    Read(GB)
    読み込まれた入力バイト数をギガバイト単位で示す。
    Write(GB)
    書き込まれる出力バイト数をギガバイト単位で示す。

-l フラグを指定すると、 fcstat コマンドは、物理または仮想 FC アダプタの I/O コマンドのレイテンシを指定した期間（秒）表示します。 オプションのintervalパラメータ（ -l フラグ付き）は、各レポート間の時間間隔を秒単位で指定する。 時間間隔が指定されない場合、各レポートのデフォルト間隔は3秒である。

I/Oコマンドのレイテンシ統計は以下の特性を持つ：
  • 外部SAN時間、アダプタ時間、VIOS時間、およびハイパーバイザ時間を表示します。
  • 1つのI/Oコマンドにかかる最大時間を表示します。
  • 正常終了（リード、ライト）I/O、エラーI/O、およびタイムアウトI/Oのレイテンシ統計を表示する。
  • FC ポートに設定されているプロトコルのレイテンシ統計を表示します。
    注:
    1. VIOS時間とハイパーバイザー時間は、仮想環境でのみ適用されます。
    2. NVME プロトコルでは、タイムアウトコマンドの統計は表示されません。
    3. 送信元または送信先のCEC（Consumer Electronics Control）ファームウェアレベルが1020未満の場合、LPM中の仮想クライアントの待ち時間統計は適切ではありません。

フラグ

項目
説明
-c デバイスが非診断モードでオープンされ、リンクがダウンしている場合に、出力を生成する遅延を削除する。
-d 診断モードでアダプタを開き、統計情報を表示します。
-e ドライバ統計、リンク統計、 FC4 タイプ、および重要なスモールフォームファクタプラガブル（SFP）パラメータなど、デバイス固有の統計情報を含む統計情報を表示します。
-l I/Oコマンドのレイテンシーを表示します。
-p Protocol パラメータで指定された特定の TP のトラフィック統計の時系列レポートを表示します。
-t トラフィック統計の時系列レポートを、 Interval パラメータで指定した 2 つの連続レポート間の時間間隔を空けて連続的に表示します。
-z 一部の統計情報を初期値にリセットします。 このフラグを発行できるのは、特権ユーザーだけである。

パラメーター

項目
説明
Device_name FCデバイス名を示す。 例: fcs0。
期間 I/Oコマンドのレイテンシが収集され表示される時間を秒単位で示す。 Durationは -l フラグで指定しなければならない。
間隔 -t または -l フラグによって生成される2つのレポート間の時間間隔を秒単位で示す。 時間間隔の有効な値は正の整数である。 -l 、 Intervalはオプション。
プロトコル -p フラグの特定の TP を示す。 プロトコルの有効な値は scsi と nvme です。

統計フィールド

注: アダプターによっては、特定の統計情報をサポートしない場合があります。 サポートされていない統計フィールドの値は常に 0 である。 アスタリスク（*）の記号が付いたパラメータは、 –z フラグを付けて fcstat コマンドを使用すると、すべて初期値にリセットされる。
