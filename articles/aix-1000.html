目的

DNS 構成ファイルの構文を検査します。

構文

named-checkconf [-chjlvz] [-p [-x ]] [-t ディレクトリ] ファイル名

説明

named-checkconf コマンドは、 named.conf 構成ファイルの構文を検査しますが、セマンティクスは検査しません。 named.conf 構成ファイルとそれに含まれるすべてのファイルが解析され、構文エラーがないか検査されます。 ファイルが指定されていない場合、デフォルトで /etc/named.conf ファイルが読み取られます。

注意：'namedデーモンは、いくつかのファイル（'rndc.keyや'bind.keys)など）を別々のパーサーコンテキストで読み込む。 named-checkconfコマンドはこれらのファイルを自動的にチェックしない。 これらのファイルに設定エラーがあると、たとえ 'named-checkconfコマンドが成功しても、'namedデーモンが失敗する可能性がある。 しかし、これらのファイルに対して明示的に'named-checkconfコマンドを実行することができる。

フラグ

項目
説明
-h 使用状況の要約を表示して終了する。
-j ゾーンファイルのロード中に、ジャーナルが存在すればそれを読み込む。
-l すべての構成済みゾーンをリストします。 出力の各行には、ゾーン名、クラス (例えば、IN)、ビュー、およびタイプ (例えば、1 次または 2 次) が含まれます。
-c コア構成のみを検査することを示します。 このフラグはプラグイン・モジュールのロードを抑止するため、プラグイン・ステートメントのすべてのパラメーターは無視されます。
-i 非推奨オプションに関する警告メッセージを無視する。
-p エラーが検出されなかった場合は、 named.conf 構成ファイルおよび組み込まれたファイルを正規形式で印刷します。 -xオプションも参照。
-t ディレクトリ 設定ファイルに含まれるディレクティブが処理されるように、ルートディレクトリを指定されたディレクトリに変更します。
-v named-checkconf プログラムのバージョンを出力して終了します。
-x 正規形式で構成ファイルを印刷するときに、共有秘密鍵を疑問符のストリング (?) に置き換えることによって、共有秘密鍵を覆い隠します。 このフラグを使用すると、 named.conf 構成ファイルおよび関連ファイルの内容を共有することができます。 例えば、個人情報を含まないバグレポートの提出などです。 このオプションは、 -p フラグなしでは使用できません。
-z named.conf設定ファイルにあるマスターゾーンファイルをチェックし、ロードする。
ファイル名 チェック対象の構成ファイル名を指定します。 指定しない場合、デフォルト値は /etc/named.confです。

終了状況

項目
説明
0 正常に完了したことを示します。
1 エラーを表します。
