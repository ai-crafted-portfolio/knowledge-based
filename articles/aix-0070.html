目的

キーワード検索でコマンドを見つけます。

構文

apropos [ -M PathName ] キーワード ...

説明

アポス コマンドは、 キーワード パラメーターによって指定されたキーワードS のいずれかがタイトルに含まれているマニュアル・セクションを表示します。 apropos コマンドは各ワードを別々のワードと見なし、大文字と小文字を区別しません。 他のワードの一部となっているワードも表示されます。 例えば、次の単語を検索するとします。compileアポス コマンドは、そのワードのすべてのインスタンスも検出します。compiler.キーワードを含むデータベースは /usr/share/man/whatisで、最初に catman -w コマンドで生成する必要がある。

apropos コマンドの出力が名前とセクション番号で始まっている場合は、man Section Title を入力できます。 例えば、 アポス コマンドの出力が以下のようになっているとします。 printf(3)、次のように入力できます。man 3 printfprintf サブルーチンのマニュアル・ページを取得します。

apropos コマンドは、-k オプションを指定した man コマンドを使用するのと同じです。

“注 /usr/share/man/whatis catman -w コマンドを使って HTML ライブラリからデータベースを構築する場合、セクション 3 はセクション 2 または 3 と同等です。 セクションの詳しい説明については、man コマンドを参照してください。”

フラグ

項目
説明
-M PathName 代替検索パスを指定します。 検索パスはコロンで区切られたディレクトリーのリストで、PathName パラメーターで指定します。

例

  1. 単語が含まれているマニュアル・セクションを検索するには、以下のようにします。passwordタイトルに次のように入力します。
    apropos password
  2. 単語が含まれているマニュアル・セクションを検索するには、以下のようにします。editorタイトルに次のように入力します。
    apropos editor
