目的

ネットワーク・インストール管理 (NIM) 環境に関する情報を表示します。

構文

サポートされる NIM クラス、サブクラス、またはタイプのリストを表示する

Lsnim { P-| -P} [ 「-c」クラス| -S (S)]

事前定義された NIM 情報を表示する

Lsnim { P-| -P} [ 「-c」クラス| -sサブクラス| Tタイプ] [ - | [ - ] | -O (O)] [ -Z]

または

lsnim { -p| -P}[ -a 属性 ].. [ -Z]

操作に必要な属性を表示する

Lsnim Tタイプ -Q (Q)操作

カスタマイズされたすべての NIM オブジェクトの情報を表示する

Lsnim [ 「-c」クラス| -sサブクラス| Tタイプ] [ - | [ - ] | -O (O)] [ -Z]

または

lsnim [ -a属性 ].. [ -Z]

特定の NIM オブジェクトの情報を表示する

lsnim[ -l | -O|-a 属性 ..][ -Z]ObjectName

または

lsnim[-q操作] ObjectName

特定の NIM マシンに使用可能なリソースの情報を表示する

lsnim -L [ -s サブクラス | -t タイプ ] オブジェクト名

NIM グループの情報を表示する

lsnim -g | -m [ -a 属性 | -c クラス | -L | -l | -s サブクラス | -t タイプ ] GroupObjectName

説明

lsnim コマンドは、NIM 環境の情報を表示します。 この情報は、事前定義とカスタマイズの 2 つの基本カテゴリーに分類されます。

事前定義情報は、NIM によって事前設定された値からなり、ユーザーが変更することはできません。 事前定義情報の例は次のとおりです。

  • NIM によってサポートされるオブジェクトのタイプ
  • NIM がオブジェクトを編成するためのクラスおよびサブクラス
  • NIM オブジェクトに対して実行できる操作。
  • ユーザーが入力することができる属性

通常、NIM はこの情報を使用して操作中の決定を行います。 -p または -P フラグを使用すると、 事前定義情報を表示できます。 -p フラグを指定するとデフォルトの値が表示され、 -P フラグを指定するとヘルプ情報が表示されます。

カスタマイズ情報は、ユーザーが入力または変更した値から作成されます。 この情報は、NIM が動作する物理環境を表します。 カスタマイズ情報に関する部分は、 グループ化されてオブジェクト を形成します。 オブジェクトは、NIM データベース内でオブジェクト型とクラス別に編成されます。 オブジェクト・タイプの例をいくつか示します。diskless,pagingおよびstandalone. オブジェクト・クラスの 2 つの例を以下に示します。machinesおよびnetwork.

例えば、NIM 環境の一部であるスタンドアロン・ワークステーションは、 固有のオブジェクトで表されます。 このオブジェクトは NIM によって次のものとして分類されます:standalonemachinesオブジェクト、ここでstandaloneオブジェクト・タイプを表します。machinesオブジェクト・クラスを表します。 フラグを指定せずにコマンド・ラインに lsnim コマンドを入力すると、 カスタマイズされたすべてのオブジェクト情報が表示されます。

また、lsnim コマンドを使用すると、 カスタマイズされたオブジェクト間の関係を表示できます。 固定する オブジェクトを選択してから (Objectname パラメーターで指定)、 -c、 -s、 または -t フラグを指定して必要な関係を選択します。 表示される情報は、 固定したオブジェクト型とクラスに応じて異なります。 例えば、spot というタイプのオブジェクトを選択すると、 次に示すような関係を表示されます。

  • SPOT (Shared Product Object Tree) リソースを使用する マシン。
  • SPOT リソースにアクセスできる ネットワーク。

関係が表示されない場合は、 lsnim コマンドはフラグを表示します。 このフラグを使用すると、通常は表示される出力にフィルターをかけることができます。 -a、 -c、 -O、 -s、 または -t フラグを使用すると、 表示される情報の量を制限することができます。

-c クラス NIM オブジェクト・クラスを指定します。 Objectname パラメーターを指定しないでこのフラグを使用すると、 そのクラスのオブジェクトの情報だけが表示されるように、情報にフィルターがかけられます。

-t タイプ NIM オブジェクト型を指定します。 Objectname パラメーターを指定しないでこのフラグを使用すると、 そのタイプのオブジェクトの情報だけが表示されるように、 情報にフィルターがかけられます。
-Z 情報をコロンで区切ったフォーマットで表示します。

セキュリティー

アクセス制御: lsnim コマンドを実行するには、 ユーザーは root 権限を持っていなければなりません。

例

  1. NIM オブジェクト・クラスのリストを表示するには、次のように入力します。
    lsnim -p
  2. NIM サブクラスのリストを表示するには、次のように入力します。
    lsnim -p -S
  3. システムの NIM オブジェクト・タイプのリストを表示するには、 machinesオブジェクト・クラス、入力:
    lsnim -p -c machines
  4. NIM オブジェクト・タイプに関するヘルプ情報を表示するには、 machinesオブジェクト・クラス、入力:
    lsnim -P -c machines
  5. 名前付き NIM 属性に関する詳細情報を表示するには、次のように入力します。 lpp_sourceおよびRstate次のように入力します。
    lsnim -p -a lpp_source -a Rstate
  6. 以下に対して実行できる操作を表示します。 pagingオブジェクト・タイプ、入力:
    lsnim -p -t paging -O
  7. 実行に必要な情報を表示するには、以下のようにします。 bos_instオブジェクトに対する操作 standaloneオブジェクト・タイプ、入力:
    lsnim -t standalone -q bos_inst
  8. カスタマイズされたすべてのオブジェクトに関する情報を表示するには、以下のようにします。 disklessオブジェクト・タイプ、入力:
    lsnim -t diskless
  9. カスタマイズされたオブジェクトをすべて表示するには、以下のようにします。 networksオブジェクト・クラス、入力:
    lsnim -c networks
  10. 次の名前の NIM オブジェクトに関する詳細情報を表示するには、次のようにします。altoid次のように入力します。
    lsnim -l altoid
  11. 名前付きオブジェクト間の関係を表示するには、以下のようにします。altoidおよびすべての NIM リソースを入力します。
    lsnim -c resources altoid
  12. 適用できる操作のリストを表示するには、以下のようにします。altoid次のように入力します。
    lsnim -O altoid
  13. 使用可能なリソースのリストを表示するには、以下のようにします。altoid次のように入力します。
    lsnim -L altoid
  14. マシン・グループのメンバーを表示するにはMacGrp1状態およびグループ除外状況の場合は、次のように入力します。
    lsnim -g MacGrp1
  15. リソース・グループのメンバーに関する基本情報を表示するResGrp1次のように入力します。
    lsnim -m ResGrp1
  16. マシン・グループのメンバーの詳細リストを表示するMacGrp1非表示の NIM 内部情報があれば、次のように入力します。
    lsnim -m -Fl MacGrp1
  17. マシン・グループのすべてのメンバーを表示するMacGrp1スポットが割り振られている場合は、次のように入力します。
    lsnim  -ma spot MacGrp1
