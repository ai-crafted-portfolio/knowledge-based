目的

オブジェクト・データ・マネージャー (ODM) データベースに格納された、キーボード属性を変更します。

構文

chhwkbd [ -d 遅延 ] [ -r 繰り返し ] [ -c ClickerVolume ] [ -a AlarmVolume ] [ -m [ "KR" | "JP" | "TW"  ] ] [ -t [ 「nonum」 ] ]

説明

chhwkbd ODM データベースに格納されている次のキーボード属性を変更します。

  • 反復の遅延
  • 反復率
  • クリッカー・ボリューム
  • アラーム・ボリューム
  • 韓国語、日本語、および中国語のキーボード ID
  • 数字パッド・エミュレーションの使用可能/使用不可

キーボード属性の変更は、システム再起動時に有効になります。

System Management Interface Tool (SMIT) の smit chgkbd 高速パスを使用して、このコマンドを実行することもできます。

フラグ

項目
説明
-a AlarmVolume 指定した値にアラーム・ボリュームを設定します。 AlarmVolume 変数の値は、次のように定義されています。
0
オフ
1
低
2
中
3
高
-c ClickerVolume 指定した値にクリッカー音量を設定します。 ClickerVolume 変数の値は、次のように定義されています。
0
オフ
1
低
2
中
3
高
-d 遅延 指定した値にキーボードの反復遅延を設定します。 Delay 変数には、250、500、750、または 1000 ミリ秒の値を設定できます。 デフォルト値は 500 ミリ秒です。
-m ["KR" | "JP" | "TW" ] 次のキーボードについて拡張キーボード識別を可能にします。
"KR"
韓国語キーボード
"JP"
日本語キーボード
"TW"
中国語キーボード

拡張キーボード識別を除去するには、値を指定しないで -m フラグを使用してください。

“注意：このフラグは、IBM RS/6000106キーキーボードまたはIBM PS/2キーボードまたは同等のキーボードがワークステーションに取り付けられている場合にのみ有効である。”

SMIT を使用してロケールを選択すると、-m フラグは自動的に設定されます。
-r 反復 指定した値に反復速度を設定します。 Repetition 変数には、2 以上 30 以下の整数を設定できます。 デフォルト値は、11 字/秒です。
-t [「nonum」] 数字パッド・エミュレーションを使用可能または使用不可にします。 数字パッド・エミュレーションを使用可能にするには、"nonum" パラメーターを指定します。 数字パッド・エミュレーションを使用不可にするには、値を指定しないで -t フラグを使用してください。
“注:
  1. このフラグは、 IBM PS/2 キーボードまたは同等のキーボードがワークステーションに接続されている場合にのみ有効です。
  2. 「nonum」は、数字キーパッドがないことを意味します。
”

例

  1. キーボード反復遅延速度を 250 ミリ秒に変更するには、次のように入力します。
    chhwkbd  -d 250
  2. キーボード反復速度を 1 秒当たり 30 文字に変更するには、次のように入力します。
    chhwkbd  -r 30
