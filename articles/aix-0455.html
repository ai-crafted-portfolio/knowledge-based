目的

現在のオペレーティング・システム・レベルのセキュリティ暫定修正が利用可能かどうかをチェックする。

構文

emgr_check_ifixes
emgr_check_ifixes -D [ -d aixlevel:fw | -c NIM_clients ] [ -P path ]

説明

emgr_check_ifixes コマンドは、現在のオペレーティング・システム・レベルに対応するセキュ リティ暫定修正が利用可能かどうかを調べます。 また、 emgr_check_ifixes コマンドは、セキュリティー・アドバイザリーの署名を検証し、指定されている場合は特定のパスにインテリム・フィックスをダウンロードします。

フラグ

表 1. フラグ
項目
説明
-D 利用可能な暫定修正プログラムをダウンロードします。
-d エクスレベル:FW システムの AIX レベルとファームウェア・レベルを指定する。
-c NIM_クライアント NIMクライアントの名前を指定する。
-P パス 暫定修正をダウンロードするパスを指定します。 デフォルト・パスは /tmp/ifix_$PIDです。

例

  1. 現在のオペレーティング・システム・レベルのセキュリティ暫定修正が利用可能かどうかを確認するには、以下のコマンドを入力します：
    emgr_check_ifixes
  2. 現在のオペレーティング・システム・レベルのセキュリティ暫定修正が利用可能かどうかを確認し、バッチ・モードで暫定修正をダウンロードするには、以下のコマンドを入力します：
    emgr_check_ifixes -D -P /tmp
  3. 特定の AIX およびファームウェア・レベルのセキュリティ暫定修正プログラムが利用可能かどうかを確認するには、以下のコマンドを入力します：
    emgr_check_ifixes -d 7300-01-01-2246:VL950_098
  4. NIMクライアントのセキュリティ暫定修正の有無を確認するには、NIMサーバーから、クライアント名をカンマまたはスペースで区切って、次のコマンドを入力します：
    emgr_check_ifixes -c “nim_client1 nim_client2”
    emgr_check_ifixes -c “nim_client,nim_client2”
