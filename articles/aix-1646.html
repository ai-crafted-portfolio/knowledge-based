目的

X Window System 用の UIM/X ユーザー・インターフェース管理システムを始動します。

構文

uimx [ -dir Path ] [ -file FileName ] [ -workspace Name ] [ -xrm オプション ]

説明

uimx コマンドは、X Window System の UIM/X ユーザー・インターフェース管理システムを始動します。 このコマンドは Motif 1.2 をサポートし、グラフィカル・ユーザー・インターフェース (GUI) 開発用の完全なプログラミング環境を提供します。 UIM/X は、C と C++ の両方でオブジェクト指向プログラミングをサポートします。

UIM/X は、Xt リソース構文を使用してインターフェースとプロジェクトを記述するテキスト・ファイルを保管しロードします。 また、UIL ファイルもロードします。 UIM/X は、C、C++、および UIL コードを生成します。 また、アプリケーションの makefile、メッセージ・カタログ、およびリソース・ファイルも生成します。

UIM/X には、組み込み C インタープリターと、以下のツールやエディターが含まれています。

  • Motif ウィジェットのパレット
  • 複雑なウィジェット階層を参照するための ウィジェット・ブラウザー
  • インターフェースを描画するための WYSIWYG レイアウト・エディター
  • ウィジェット・プロパティーの初期値を設定するためのプロパティー・エディター。初期値はリテラル値または C 式にすることができます。
  • コールバック・コードを入力するための コールバック・エディター
  • イベント・エディター、アクション・エディター、および変換エディター
  • メニューおよびメイン・ウィンドウ・エディター
  • インターフェース用に生成されたコードを編集するための 宣言エディター
  • 生成されたメインプログラムおよび Make ファイルを編集するための プログラム・レイアウト・エディター。このエディターを使用すると、メイン・イベント・ループに直接アクセスできます。

UIM/X は、2 つの演算モード (設計とテスト) をサポートします。 テスト・モードでは、組み込み C インタープリターを使用してアプリケーションの振る舞いをテストできます。 設計モードでは、C インタープリターは種々の UIM/X エディターに入力するコードの妥当性を検査します。

UIM/X は、X と Motif を使用してプログラミング・タスクを単純化する関数の便利なライブラリーを提供します。

フラグ

項目
説明
ディレクトリー パス UIM/X の、パスへの現行ディレクトリーを設定します。
ファイル FileName 既存のプロジェクト、インターフェース、または FileName という名前のパレット・ファイルをロードします。 FileName には、絶対パス名現行ディレクトリーと関連するパス名、 または -dir 値と関連するパス名を含めることができます。
ワークスペース 名前 UIM/X を name という名前の対応する CDE ワークスペースにロードします。
XRM オプション 別の場合にはリソース・ファイルに書き込むこともあるリソース仕様 (options) を入力できるようにします。

セキュリティー

アクセス制御: 任意のユーザー

アクセスされるファイル: なし

例

UIM/X を始動するには、次のように入力します。

uimx
