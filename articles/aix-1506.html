目的

アクティブな ワークロード・パーティションを非アクティブにします。

構文

/usr/sbin/stopwpar [ -h | -F ] [ -r ] [ -t 秒 | -N ] [ -v ] WparName

説明

stopwpar コマンドは、実行中の ワークロード区画を非活動化します。 これには、以下のタスクの停止が含まれます。
  • ワークロード・パーティション内で実行中のプロセスの停止。
  • ワークロード・パーティションの WLM クラスのアンロード (ある場合)。
  • ワークロード・パーティションの IP アドレスの非アクティブ化 (ある場合)。
  • ワークロード・パーティションのファイル・システムをアンマウントします (存在する場合)。
  • システム ワークロード・パーティションを再始動しています。
  • アプリケーション ワークロード・パーティションを削除しています。
stopwpar コマンドは、以下の状況では失敗します。
  • 指定された ワークロード・パーティション は存在しません。
  • kill コマンドで 1 つ以上のプロセスを停止できません (強制的に実行するには、 -F フラグを使用します)。
  • 1 つ以上のファイルシステムをアンマウントできません (強制するには、 -F フラグを使用します)。

フラグ

項目
説明
-F ワークロード・パーティション を強制的に停止し、実行中のプロセスをより積極的にシグナル通知して、リモート・ファイル・システムをアンマウントします。 プロセスを停止できない場合、 ワークロード区画 は Broken 状態のままになり、再始動できません。
-h ハード・ストップを使用して、 ワークロード・パーティション サブシステムに終了をシグナル通知します。 ハード・ストップ使用時の、デフォルトのタイムアウト値は 60 秒です。
-N タイムアウトなしにシャットダウン/停止が完了することを指定します。
-r すべての停止操作が完了した後、 ワークロード・パーティション を再始動します。 これは、 stopwpar コマンドの後に startwpar コマンドを呼び出すのと同等です。 このフラグは、アプリケーション ワークロード・パーティションには無効です。
-t 秒 コマンドが失敗し、プログラムが終了するまでに、シャットダウン/停止が完了するのを待つタイムアウトの長さ (秒数) を指定します。 デフォルトは、シャットダウン/停止が完了しなかった場合に、600 秒後の失敗です。
-v 詳細出力を表示することを指定します。

パラメーター

項目
説明
WparName 停止する ワークロード・パーティション の名前。 このパラメーターは、コマンド・ラインの最後のパラメーターでなければなりません。

セキュリティー

アクセス制御: システム ワークロード・パーティションに対してこのコマンドを実行できるのは、root ユーザーのみです。 アプリケーション ワークロード・パーティションの場合、 ワークロード・パーティション (または root) の作成者のみがこのコマンドを実行できます。

例

  1. ロイという名前の ワークロード・パーティション を停止するには、次のように入力します。
    stopwpar roy
  2. 85 秒後に ピント と呼ばれる ワークロード・パーティション のシャットダウン処理を中止するには、次のように入力します。
    stopwpar -t 85 pinto
