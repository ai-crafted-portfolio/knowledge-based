目的

ワークロード・パーティションを除去します。

構文

/usr/sbin/rmwpar [ -F ] [ -p ] [ -s ] [ -v ] WparName

説明

rmwpar コマンドは、以下のタスクを含むシステムから、指定された ワークロード区画 を削除します。
  • システムの ワークロード・パーティション ・データベースから ワークロード・パーティションの構成データを除去する
  • ワークロード・パーティションのファイル・システムの削除 ( -p フラグを指定しない場合)
  • ワークロード・パーティションのワークロード・マネージャー (WLM) プロファイルの除去
-F フラグを指定しない場合、rmwpar コマンドは操作のいずれかの部分で最初の障害が起こった時点で停止します。 -F フラグを指定した場合は、rmwpar コマンドは可能な限り多くの除去対象を除去します。 指定された ワークロード・パーティション がアクティブな場合、 -s フラグまたは -F フラグを指定しない限り、 rmwpar コマンドは失敗します。

フラグ

項目
説明
-F rmwpar コマンドが大部分の障害をオーバーライドまたは無視する必要があることを指定します。 これは、切断された ワークロード・パーティションを強制的に除去するために使用できます。 このフラグは -s フラグを暗黙指定します。
-p ワークロード・パーティションに割り当てられている保存除去を除去します。 論理ボリュームまたは既存の論理ボリューム内のサブディレクトリーである構成済みローカル・ファイルシステムは、空にされたり除去されたりすることはありません。 このフラグは、システム ワークロード・パーティション 専用です。 このフラグは、rootvg ワークロード区画では使用できません。 このフラグを使用して保存されるファイルシステムは、m に接続される新規 ワークロード・パーティション を作成するために、次のコマンドで使用できます。
mkwpar -p
-s ワークロード・パーティションを停止します。 このフラグは、rmwpar コマンドの前に stopwpar コマンドを呼び出すことと同等です。 1 つのステップで ワークロード・パーティション をシャットダウンして削除するには、このフラグを使用します。 rmwpar コマンドが -F フラグを指定して実行された場合、 stopwpar コマンドは -F フラグを指定して実行できます。 -s フラグまたは -F フラグが指定されていないアクティブな ワークロード・パーティション に対して rmwpar コマンドを実行すると、 rmwpar コマンドは失敗します。
-v 詳細モード。

セキュリティー

アクセス制御: root ユーザーのみがこのコマンドを実行できます。

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. 「roy」という ワークロード・パーティション を除去するには、次のように入力します。
    rmwpar roy
  2. 「roy」という ワークロード・パーティション を停止して除去し、そのファイル・システム上のデータを保持するには、次のように入力します。
    rmwpar -p -s roy
