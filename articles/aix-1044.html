目的

ネットワーク・インストール管理 (NIM) クライアント・パッケージを構成します。

構文

NIMクライアントパッケージを設定するには、次のコマンドを入力してください：
niminit { -a name=Name -a pif_name=Pif -a master=Hostname } [ -a master_port=PortNumber ] [ -a registration_port=PortNumber ] [ -a cable_type=CableType | -a ring_speed=Speed ] [ -a iplrom_emu=Device ] [ -a platform=PlatformType ] [ -a netboot_kernel=NetbootKernelType ] [ -a adpt_add=AdapterAddress ] [ -a is_alternate= yes | no ] [ -a connect=value ] [ -a vlan_tag=value ] [ -a vlan_pri=value ] [ -c ]
ファイルを /etc/niminfo 再構築するには、次のコマンドを入力してください：
niminit { -a name=Name -a master=Hostname -a master_port=PortNumber }

説明

この niminit コマンドは、コマンド nimclient を使用する前に、NIMクライアントパッケージの設定を行います。 niminit コマンドが必要な属性を受け取ると、 niminit コマンドを実行するマシンを表す新しいマシン・オブジェクトが作成される。 niminit コマンドが正常に完了すると、 niminit コマンドを実行したマシンは NIM 環境に参加できるようになる。

NIMクライアント・パッケージが設定されたら、 niminit コマンドを実行して、クライアント上の /etc/niminfo ファイルを再構築することができます。 /etc/niminfo ファイルは niminit コマンドで使用される。 ユーザーが意図せずファイルを削除した場合、 /etc/niminfo ファイルを再構築しなければならない。

niminit alternate_master 。 is_alternate 属性が yesに設定されている場合。 alternate_master オブジェクトを設定する前に、 bos.sysmgt.nim.master ファイルセットをインストールする必要があります。 alternate_master オブジェクトが設定された後、 alternate_master オブジェクトが登録されているプライマリシステムは、このマシン上で alternate_master オブジェクトの操作を実行することができる。

フラグ

属性の説明
-a niminit 、最大5つの属性を指定する。 このフラグは -a 、後続する「 attribute=value 」の各ペアの前に置かれます：
name= 名前
NIMがワークステーションを識別するために使用する名前を指定します。 この値は必須です。
pif_name=ピフ
すべての NIM コミュニケーションのネットワーク・インターフェースの名前を定義します。 この値は必須です。
master=ホスト名
NIM マスターのホスト名を指定します。 クライアントはこのホスト名を Internet Protocol (IP)アドレスに解決しなければならない。 この値は必須です。
master_port=ポート番号
NIM 通信に使用する nimesis デーモンのポート番号を指定します。
cable_type=ケーブルタイプ
イーサネット・ケーブル・タイプを指定します。 pif_name 。 CableType 値を指定しなければならない。 有効な値は、 bnc、 dix、および N/A です。
ring_speed=スピード
速度をMbps単位で指定する。 pif_name 属性がトークンリングネットワークを参照する場合、 Speed 値を指定しなければならない。 有効な値は 4と 16 である。
iplrom_emu=デバイス
読み取り専用メモリ（ROM）エミュレーション・イメージを含むデバイスを指定します。 ROMエミュレーション・イメージは、ネットワーク・インターフェイス経由での起動を内部でサポートしていないモデルに必要です。
platform=プラットフォームタイプ
クライアントのマシンタイプに対応するプラットフォームを指定する。 platform=attribute が指定されていない場合は、デフォルトの chrp プラットフォームが使用されます。 対応プラットフォームは以下の通り：
chrp
PowerPC CHRP（Common Hardware Reference Platform）アーキテクチャベースのマシン。
rs6k
マイクロ・チャネル・ベースのユニプロセッサー・モデル AIX 5.1 およびそれ以前のモデル。
rs6ksmp
マイクロ・チャネル・ベースの対称型マルチプロセッサ・モデル AIX 5.1 およびそれ以前のモデル。
rspc
PowerPC のPCIバスベースのユニプロセッサ・マシン。 AIX 5.1 およびそれ以前のマシン。
rspcsmp
PowerPC PCIバスベースの対称型マルチプロセッサ・マシン。 AIX 5.1 およびそれ以前。
adpt_add= アダプター ・アドレス
ネットワーク・アダプターに対応するハードウェア・アドレスを指定します。
 
registration_port=ポート番号
NIMクライアントの登録に使用するポート番号を指定します。
注:
  • コマンドラインでポート番号を指定しない場合、NIM用の /etc/services ファイルにあるポート番号が使用される。 /etc/services ファイルに NIM ports、 nim 、 nimreg のエントリーがない場合、 master_port 属性には1058、 registration_port 属性には1059のデフォルト値が使用される。
  • master_port 属性と registration_port 属性に使用される値は、NIMマスターが使用する値と一致しなければならない。 NIMマスターが使用する値を表示するには、NIMマスター上でコマンド lsnim -l master を実行する。
netboot_kernel=NetbootKernelType
ネットワーク経由でクライアントを起動する際に使用するカーネルの種類を指定します。 以下の値は、 netboot_kernel 属性値です：
UP
ユニプロセッサ・マシン用カーネル。 この値はデフォルト値です。
MP
マルチプロセッサ・マシン用カーネル。
is_alternate= [ はい ｜ いいえ ]
alternate_master オブジェクトとして設定するには、 is_alternate= attributeを yesに設定する。
connect=価値
NIMクライアントがNIMコマンドのリモート実行に使用する通信サービスを指定する。 この値の選択肢は、「 shell 」と rsh 「 nimsh 」です。 デフォルト設定は connect= shell。 connect= 値はオプション。 is_alternate=attribute が yes に設定されている場合、 nimsh がデフォルト設定となり、これが唯一の有効な値となります。 is_alternate 属性はオプションです。
vlan_tag=価値
VLAN タグ付けに使用する仮想論理エリア・ネットワーク (VLAN) の ID を指定します。 IDは、イーサネット・フレームが属するVLANを識別する。 このIDによって、ネットワーク管理者は、ネットワークをサブネットに割り当てるのではなく、クライアントの通信を論理的に整理することができる。 VLAN タグ付けの値は NIM によって、クライアントのネットワーク・ブートを実行するために使用されます。 VLAN タグ通信の構成は、値を使用する前に NIM の外部で処理する必要があります。 vlan_tag オプションの値域は 0-4094である。
vlan_pri=価値
VLAN タギングに使用する VLAN プライオリティを指定します。 優先度値は、VLANタグとともに、そのイーサネットフレームが属するVLANを特定するために使用されます。 優先順位によって、ネットワーク管理者はネットワークをサブネットに割り当てるのではなく、クライアントの通信を論理的に整理することができる。 VLAN タグ付けの値は NIM によって、クライアントのネットワーク・ブートを実行するために使用されます。 VLAN タグ通信の構成は、値を使用する前に NIM の外部で処理する必要があります。 vlan_pri オプションの値の範囲は0-7である。
-c NIMマスターのプッシュ操作中に、Secure Sockets Layer（ SSL ）認証を有効にします。
注: nimconfig -c コマンドを使用して、NIMマスタにOpen Secure Sockets Layer ( OpenSSL ) 証明書を設定する。

セキュリティー

アクセス制御
niminit コマンドを実行するには、root権限が必要です。
RBACユーザー
RBACユーザーに注意： このコマンドは特権操作を実行することができます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、 セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては lssecattr コマンドまたは getcmdattr サブコマンドを参照してください。

例

  1. BOOTP 対応の初期プログラムローダー (IPL) ROM を搭載し、NIM 環境内で「scuba」として認識される必要があるマシン上で、NIM クライアントパッケージを設定するには、次のコマンドを入力します
    niminit -a name=scuba -a pif_name=en0 -a cable_type=bnc \
-a master=manta

    ここで、 en0 はプライマリー・インターフェイスで、イーサネット・ケーブルのタイプは bnc。 このコマンドでは、ネットワークインストール通信のために、NIMマスターのホスト名として を指定し manta 、 ディレクトリ /etc/services にあるNIMポートを使用して、マシンがNIMマスターと通信することも指定します。

  2. NIMマスターのホスト名として、ポート番号として 1058 を指定 superman して、削除されたファイルを /etc/niminfo 再構築するには、次のコマンドを入力してください：
    niminit -a name=robin -a master=superman -a master_port=1058
  3. PowerPC のPCIバスベースのユニプロセッサシステムで、BOOTP対応のIPL ROMを搭載し、NIM環境内で として starfish 認識される必要があるマシン上で、 AIX5.1 およびそれ以前のバージョンのNIMクライアントパッケージを設定するには、次のコマンドを入力します
    niminit -a name=starfish -a pif_name=en0 -a cable_type=dix \
-a master=whale -a master_port=1058 -a platform=rspc

    en0 はプライマリー・インターフェイスで、イーサネット・ケーブルのタイプは dix。 このコマンドでは、NIMクライアントパッケージが、NIMマスターのホスト名として、ポート番号として1058を使用して whale 、NIMマスターと通信することも指定されています。

  4. NIM 環境内で bluefish として認識される必要があるマシン上で NIM クライアントを設定するには、次のコマンドを入力します：
    niminit -a name=bluefish -a pif_name=at0 -a master=redfish \
-a master_port=1058
    ここで、 at0 はプライマリー・インターフェースである。 このコマンドでは、NIMクライアントがNIMマスターと通信する際、NIMマスターのホスト名として を指定し redfish 、ポート番号として1058を使用することも指定しています。
    注： 非同期転送モード（ATM）ネットワーク・インターフェースはネットワーク経由でのブートをサポートしないので、クライアントのサブネットに対応する汎用ネットワーク・オブジェクトがすでに定義されている場合、この操作はNIMマスタ上でマシン・オブジェクトを定義する。
  5. PowerPC のPCIバスベースの対称型マルチプロセッサシステムであり、BOOTP対応のIPL ROMを搭載し、NIM環境内で として jellyfish 認識される必要があるマシン上で、 AIX5.1 およびそれ以前のバージョン用のNIMクライアントを設定するには、次のコマンドを入力します
    niminit -a name=jellyfish -a pif_name=en0 -a cable_type=dix \
-a master=whale -a master_port=1058 -a platform=rspcsmp

    en0 はプライマリー・インターフェイスで、イーサネット・ケーブルのタイプは dix。 このコマンドでは、NIMクライアントがNIMマスターと通信する際、NIMマスターのホスト名として を指定し whale 、ポート番号として1058を使用することも指定しています。

  6. IPL ROM エミュレーションを使用しているマシン上で、NIM 環境において octopus として認識される必要がある場合、デバイス /dev/fd0 ・ディレクトリ内の NIM クライアント・パッケージを設定するには、次のコマンドを入力します
    niminit -a iplrom_emu=/dev/fd0 -a name=octopus -a pif_name=tr0 \
-a ring_speed=16 -a master=dolphin -a master_port=1700 \
-a registration_port=1701

    ここで、 tr0 はプライマリー・インターフェイスで、リング・スピードは16である。 このコマンドはまた、NIMマスタのホスト名として dolphin 、クライアント通信用に1700、クライアント登録用に1701のポート番号を使用して、マシンがNIMマスタと通信することを指定する。

  7. en0NIM 環境で「octopus」という名前で知られるマシンを NIM マスター dolphinalternate_master のオブジェクトとして設定し、インターフェースを介して通信を行うには、次のコマンドを入力します：
    niminit -a is_alternate=yes -a name=octopus -a pif_name=en0 \ 
-a cable_type=bnc -a master=dolphin
  8. SSL の証明書をコピーし、クライアントの初期化時に SSL 認証を有効にするには、次のコマンドを入力してください：
    niminit -a name=octopus -a master=dolphin -a connect=nimsh -c -v
    注： NIM通信については、NIMマスターの初期化時の SSL キーおよび証明書の設定は、Technology Level 2以降の AIX® 7.3 でサポートされています。
