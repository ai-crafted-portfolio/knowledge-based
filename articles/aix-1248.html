目的

システム ワークロード・パーティションを停止して再始動します。

制約事項: rebootwpar コマンドは、アプリケーション・ ワークロード・パーティションでは実行できません。

構文

リブート・パラメーター [ -F | -h ] [ -N | -t seconds ] [ -v ] WparName

説明

rebootwpar コマンドは、 ワークロード・パーティションを停止して再始動します。

フラグ

項目
説明
-F 強制停止を指定します。
-h ハード・ストップを指定します。
-N 停止のタイムアウトがないことを指定します。
-T seconds 停止のタイムアウト (秒) を指定します。
-v 詳細モード。
WparName ワークロード区画名を指定します。

セキュリティー

アクセス制御: root ユーザーのみがこのコマンドを実行できます。

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

例

"MyWpar", というワークロードパーティションを再起動するには、次のように入力する：

rebootwpar MyWpar
