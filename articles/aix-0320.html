目的

クラスター管理グループを定義します。

構文

グループを定義するには、次のようにします。

ctadmingroup [-h] [-TV] グループ名

グループを除去するには、次のようにします。

ctadmingroup-u [-h] [-TV] [グループ名］

説明

ctadmingroup コマンドは、クラスター管理グループを定義するために使用します。 このコマンドはトレース・ファイルのグループ所有権を設定します。従って、クラスター管理グループに属するユーザーには、Reliable Scalable Cluster Technology (RSCT) サブシステムが作成したトレース・ファイルを調べるアクセス権があります。 ctadmingroup は、既存のトレース・ファイルを新しい許可およびグループ所有権に変更します。 ctadmingroup コマンドの実行後に作成されるトレース・ファイルには、新しい許可が含まれています。 このコマンドは、指定されたグループを作成することもしなければ、ユーザーをグループに追加することもしません。単に、このグループのユーザーにトレース・ファイルへのアクセスを与えるのみです。

以下を指定して ctadmingroup コマンドを実行するとします。
  • 別のグループ名、指定された新しいグループがクラスター管理グループとなり、前のグループに置き換わります。
  • フラグ・オプション なし、またはパラメーターなし、クラスター管理グループのグループ名と ID を表示します。 クラスター管理グループが定義されていない場合は、このコマンドは何の出力も出しません。
  • -u flagオプション。クラスター管理グループを除去します。 グループが除去された後は、そのグループに属するユーザーはトレース・ファイルを調べることができなくなる可能性があります。 クラスター管理グループが定義されていない場合は、このコマンドは何の出力も出しません。

セキュリティー・サブシステムのトレース・ファイルのロケーションが構成可能である。 トレース・ファイルの場所を判別するために、 ctadmingroup コマンドは、 /var/ct/cfg/ctcasd.cfg ファイル (存在する場合) および /opt/rsct/cfg/ctcasd.cfg ファイルに情報を要求します。

パラメーター

グループ名
クラスター管理グループの名前を指定します。 このグループは、グループ・データベース (例えば、/etc/group) に存在している必要があります。

フラグ

-u
クラスター管理グループを除去します。 グループが除去された後は、そのグループに属するユーザーはトレース・ファイルを調べることができなくなる可能性があります。 クラスター管理グループが定義されていない場合は、このコマンドは何の出力も出しません。
-h
コマンドの使用方法の文を標準出力に書き込みます。
-T
標準エラーにコマンドのトレース・メッセージを書き込みます。 これはソフトウェア・サービス組織専用です。
-V
コマンドの詳細メッセージを標準出力に書き出します。

ファイル

/etc/group
グループ・データベース。
/var/ct/cfg/ctgroups
管理グループ名を格納し、対応するグループ ID をキャッシュに入れます。
/var/ct/cfg/ctcasd.cfg
クラスター・セキュリティー構成ファイルの 1 次ロケーション (セキュリティー・サブシステムのトレース・ファイルのロケーションを含む)。
/opt/rsct/cfg/ctcasd.cfg
クラスター・セキュリティー構成ファイルの 2 次ロケーション。 /var/ct/cfg/ctcasd.cfg ファイルが存在しない場合、 ctadmingroup コマンドはこのファイルから情報を要求します。

終了状況

0
コマンドが正常に実行されました。
1
コマンド・ラインに指定されたグループ名がグループ・データベースにありません。
2
内部エラーが発生しました。
3
コマンド・ラインに指定されたフラグ・オプションが正しくありません。
4
コマンド・ラインに指定されたオペランドが正しくありません。

セキュリティー

root ユーザーのみがこのコマンドを実行できます。

標準出力

-h flagオプション を指定すると、このコマンドの使用方法のステートメントが標準出力に書き込まれます。 詳細メッセージはすべて、標準出力に書き込まれます。

標準エラー

トレース・メッセージはすべて、標準エラーに書き込まれます。

制約事項

コマンドが実行された後、グループ名とグループ ID のマッピングが変更される場合、予期しない結果が発生します。

実行の特性

このコマンドは、 Reliable Scalable Cluster Technology (RSCT) AIX® のファイル・セットLinux® のパッケージの一部です。

場所

/opt/rsct/bin/ctadmingroup

例

  1. クラスター管理グループの名前と ID を表示するには、次の入力をします。
    ctadmingroup
