目的

個々のセキュリティー・パッチおよび暫定修正をダウンロードします。

構文

emgr_download_ifix [-L download_link] [-P path]

説明

emgr_download_ifix コマンドは、指定された HTTP リンクから、現在のオペレー ティング・システム用の個別のセキュリティ・パッチと暫定的な修正プログラムを ダウンロードする。

注: /tmp ディレクトリーに十分なスペースがないと、 emgr_download_ifix コマンドが失敗する場合があります。 このコマンドを使用する前に、 /tmp ディレクトリーに十分なスペースがあることを確認してください。

フラグ

-L ダウンロードリンク
中間修正のダウンロードに使用する HTTP リンクを指定します。
-P パス
セキュリティー暫定修正をダウンロードするためのパスを指定します。 デフォルト・パスは /tmp/ifix_$PIDです。

例

  1. games_ifix 暫定修正とそのシグニチャーを /tmp/games ディレクトリーにダウンロードするには、次のコマンドを入力します。
    emgr_download_ifix -L https://aix.software.ibm.com/aix/efixes/security/games_ifix.tar -P /tmp/games
