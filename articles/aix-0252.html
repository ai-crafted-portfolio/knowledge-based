目的

Server Message Block (SMB) クライアント・マウント・ポイントのマウント・オプション、サーバー名、共有名、または資格情報が変更されます。

構文

chsmbcmnt -f MountPoint [-d RemoteShare] [-h ServerName] 
-c user [-p password] [-m MountTypeName] 
[-A|-a] [-I|-B|-N] 
[-t {rw|ro}] [-u uid] [-g gid] [-x fmode] 
[-w wrkgrp] [-V {2.1|3.0.2|auto}] [-S {enabled|required}] 
[-D {desired|required|disabled}] [-E {desired|required|disabled}] [-s spn]

説明

chsmbcmnt コマンドは、/etc/filesystems ファイル内で定義されている SMB クライアント・マウント・ポイントのマウント・オプション、サーバー名、共有名、またはクリデンシャルを変更します。 SMB share はマウントされていなければ、/etc/filesystems ファイルの変更後にマウントされます。 SMB share が既にマウントされている場合、このコマンドは SMB share をアンマウントして新規オプションで再マウントを試み、/etc/filesystems ファイルは変更されます。 SMB share がまだ /etc/filesystems ファイルに定義されていない場合は、エラーが返されます。

すべてのマウント・オプション (-t, -u, -g, -x, -w, -V, -S, -D, -E) のデフォルト値は、 mount コマンドと同じです。

フラグ

-a
これは、/etc/filesystems ファイル内の SMB クライアント・マウント・ポイントの新規 SMB クライアント・ファイルシステム・エントリーをシステム再始動後に自動的にマウントしてはならないことを指定します。 これがデフォルト設定です。
-A
これは、/etc/filesystems ファイル内の SMB クライアント・マウント・ポイントの新規 SMB クライアント・ファイルシステム・エントリーをシステム再始動後に自動的にマウントしなければならないことを指定します。
-B
これは、/etc/filesystems ファイル内の SMB クライアント・ファイルシステム・エントリーを変更し、指定のフラグとパラメーターを使用することで SMB クライアント・ファイルシステムの再マウントを試みます。 これがデフォルト設定です。
--c ユーザー
これは、SMB share にアクセスするために使用されなければならないユーザー名を指定します。
-d RemoteShare
これは、マウントされなければならない SMB サーバー上の共有名を指定します。
-D {desired|required|disabled}
これは、SMB クライアント・ファイルシステムでセキュア・ダイアレクト・ネゴシエーション機能が必要であるかどうかを指定します。 SMB Dialect 3.0.2 は、セキュリティー低下攻撃に対して SMB クライアントを保護するためにセキュア・ダイアレクト・ネゴシエーションを実施します。 有効な値は、desired、required、および disabled です。
-E {desired|required|disabled}
これは、SMB クライアント・ファイルシステムでデータ暗号化機能が必要であるかどうかを指定します。 有効な値は、desired、required、および disabled です。
-f MountPoint
これは、SMB share がマウントされなければならない場所となるパス名を指定します。
-ギド
これは、SMB クライアント・マウント・ポイントにあるファイルに割り当てられるグループ ID を指定します。 デフォルト値は 0 です。
-h ServerName
これは、リモート・ホストまたは SMB サーバーの名前を指定します。 この引数は、ホスト名、 IP アドレス、または完全修飾ドメイン・ネームとして指定できます。
-I
これは、/etc/filesystems ファイル内の SMB クライアント・ファイルシステム・エントリーを変更しますが、ディレクトリーの再マウントは行いません。
-m MountTypeName
これは、/etc/filesystems ファイルに追加される SMB クライアント・ファイルシステム・エントリーのマウント・タイプを定義します。 マウント・タイプは、 mount コマンドの -t フラグを使用して、特定のファイルシステムをマウントできるかどうかを決定します。 デフォルトでは、マウント・タイプの値は /etc/filesystems ファイルに追加されません。
-N
指定されたオプションを使用してディレクトリーをマウントしますが、/etc/filesystems ファイルは変更しません。
-パスワード
これは、特定 SMB サーバー上の特定ユーザーに対するアクセス権限を付与するために使用されるパスワードを指定します。 特定の資格情報 (サーバー名、ユーザー名、およびパスワード) が smbcred ファイルに追加されます。 パスワードは暗号化されます。 -p オプションが指定されず、資格情報が smbcred ファイルに存在しない場合は、パスワードの指定を求めるプロンプトがコマンド・ラインで出され、資格情報が smbcred ファイルに追加されます。 サーバーまたはユーザーのクリデンシャルが smbcred ファイルに既に存在する場合、このコマンドは、smbcred ファイル内のクリデンシャルを、このオプションを使用して指定された新しいクリデンシャルで変更します。
-スプーン
SMB クライアントのマウント・ポイントで使用する必要がある サービス・プリンシパル名 (SPN) を指定します。 spn パラメーターの形式は cifs/<smbServerHostName>です。ここで、 smbServerHostName は、SMB サーバーの完全修飾ドメイン名 (FQDN)、または Kerberos が SMB サーバーとして解決する名前です。 デフォルトでは、SPN は SMB クライアント・ファイルシステムによって cifs/<smbServerHostName>として自動的に構成されます。
-t {rw|ro}
これは、SMB クライアント・ファイルシステムを読み取り専用としてマウントする必要があるかどうかを指定します。
--u uid
これは、マウント・ポイントにおいてファイルに割り当てられるユーザー ID を指定します。
--x fモード
これは、マウント・ポイントにおいてファイルに割り当てられる所有者、グループ、および他の許可ビットを指定します。
--w wrkgrp
SMB サーバーが属しているワークグループを指定します。
-V {2.1|3.0.2|auto}
SMB サーバーとの通信に使用される SMB プロトコルのバージョンが指定されます。 有効な値は、2.1、3.0.2、および auto です。
-S {enabled|required}
これは、SMB クライアント・ファイルシステムが SMB サーバーとの通信にデジタル署名を必要とするかどうかを指定します。 有効な値は enabled と required です。

終了状況

0
コマンドは正常に完了しました。
>0
エラーが発生しました。

例

  • /mnt マウント・ポイントで定義されている SMB クライアント・マウント・ポイントのユーザー名を user1 に変更するには、以下のコマンドを入力します。
    chsmbcmnt -f /mnt -c user1
  • /etc/filesystems ファイル内の SMB クライアント・ファイルシステム・エントリーを変更し、変更したオプションで SMB クライアント・ファイルシステムを再マウントするには、以下のコマンドを実行します。
    chsmbcmnt -f /mnt -S enabled -E disabled
    このコマンドは、 signing パラメーターを enabled に設定し、 encryption パラメーターを disabledに設定して、 /etc/filesystems ファイル内の /mnt マウント・ポイントの SMB クライアント・ファイルシステム・エントリーを変更してから、ファイルシステムの再マウントを試みます。 マウント操作が失敗すると、このコマンドは mount コマンドの出力を表示します。 /etc/filesystems ファイル内の変更内容は保持されます。

場所

/usr/sbin/chsmbcmnt

ファイル

/etc/smbcred
ここに SMB クライアント・ファイルシステムの資格情報が格納されます。
/etc/filesystems
これは、マウント・ポイントが含まれている SMB クライアント・ファイルシステム・エントリーを保管します。
