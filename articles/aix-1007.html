目的

ホストシステム上で IPv6 のネイバーディスカバリ機能を処理する、ホスト用のネイバーディスカバリプロトコル（NDP）デーモン。

構文

ndpd-host [ -d ] [ -v ] [ -t ] [ -S ] [ -c conffile ] [ -r [ ValidLifetime PreferredLifetime ] ] [ -g ]

説明

この ndpd-host コマンドは、ルーター検出、プレフィックス検出、パラメータ検出、リダイレクトなど、カーネル以外の処理におけるネイバーディスカバリプロトコル（NDP）の機能を管理します。 ndpd-host コマンドは、デフォルト・ルーター、デフォルト・インターフェース、およびデフォルト・インターフェース・アドレスを含むデフォルト経路を処理します。 ただし、ndpd-host コマンドは、ホストで送信された静的なデフォルト経路を上書きすることはありません。 デーモンが停止されると、デーモンは、存続期間中に作成された接頭部アドレスおよび経路をクリーンアップします。

インターフェース

この ndpd-host コマンドは、IEEEおよびCTIのポイント・トゥ・ポイント・インターフェースを認識します。 この ndpd-host コマンドは、アクティブなインターフェース上でリンクローカルアドレスを持つパケットの送受信を行い、インターフェースの状態変化を検知します。 インターフェースがダウンしたり、リンクローカルアドレスを失ったりした場合、そのインターフェースでのNDP処理は停止され、インターフェースがアップすると再開されます。

IEEE インターフェースは、autoconf6 コマンドを使用して構成されます。 pppd ポイント・トゥ・ポイント・プロトコル（PPP）インターフェースの設定は、daemon を使用して行います。 トークン・ネゴシエーションはリンク・ローカル・アドレスを定義します。 CTI が構成されたトンネルを介して Router Advertisement (ルーター通知) を送信するためには、 ローカルおよびリモートのリンク・ローカル・アドレスを持っていなければなりません。

この ndpd-host デーモンは、RFC 4941 に準拠して一時アドレスを生成します。 特定のプレフィックスやインターフェースに対して一時アドレスの生成を有効または無効にするには、ファイル形式 tempaddr.conf でデーモンを設定できます。 -r オプションを使用して、一時アドレスの優先かつ有効な存続期間をデフォルトで設定できます。

注： すべてのアップのポイント・ツー・ポイント・インターフェースについて、デーモンは ndpd-host ローカルアドレス用のローカルルートを lo0 設定します。

フラグ

表 1. フラグ
項目
説明
-cコンフィル SEND 構成ファイルを指定します。 デフォルトでは、/etc/ndpd/ndpdh.cnf ファイルが構成ファイルとして使用されます。 SEND オプションを使用可能にするには、clic.rte ファイルセットと OpenSSL をインストールする必要があります。
-d デバッグ出力を有効にします。これには、例外状態の報告や状態ダンプが含まれます。
-g 初期化時に、デーモンが ndpd-host すべての静的なグローバル IPv6 アドレスを保持できるようにします。
-r [ ValidLifetime PreferredLifetime ] 一時アドレス生成を使用可能にします。 -r フラグを使用すると、オプションとして、生成された一時アドレスに対して デフォルトの有効かつ優先の存続期間を指定できます。 デフォルトでは、このフラグが無指定の場合は一時アドレスは生成されません。
-S グローバルな IPv6 アドレスに対して、RFC 7217に基づく安定したアドレス生成を設定します。 これにより、RFC 7217 アルゴリズムを使用して、安定したランダムなグローバル IPv6 アドレスが生成されることが保証されます。これにより、ハードウェア由来の識別子が漏洩するのを防ぎ、システムの再起動後もアドレスの安定性が維持されます。
-t 各ログにタイムスタンプを追加します。
-v 関連するすべてのイベントを と コンソールの両 daemon.info 方に記録します。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

ファイル

表3。 ファイル
項目
説明
/etc/ndpd/ndpdh.cnf SEND に関連する設定ファイルの保存場所を指定します。
/etc/ndpd/cgaparams.sec SEND オプションを使用する各インターフェースごとに、その構成を指定します。

/etc/ndpd/tempaddr.conf ルーターの接頭部の一時アドレスの生成を拒否または許可するかを指定します。 この -r フラグを指定してデーモンを ndpd-host 起動すると、ファイルの内容は読み取り専用になります。
