目的

パッケージのフォーマットを変換します。

構文

pkgtrans [ -i -o -n -s] [ -z Blocksize] Device1 Device2 [ Pkginst1 [ Pkginst2 [...]]]

説明

pkgtrans コマンドは、 あるフォーマットから別のフォーマットにインストール可能パッケージを変換します。 以下の変換を行います。
  • ファイルシステム・フォーマットからデータ・ストリームへ
  • データ・ストリームからファイルシステム・フォーマットへ

cshから pkgtrans を実行することはできません。

フラグ

表 1. フラグ
項目
説明
-i pkginfo ファイルと Pkgmap ファイルをコピーします。 パッケージ・カテゴリーがセット・インストール・パッケージ (SIP) を表す "set" として 定義されている場合 (setinfo ファイル・フォーマットを参照)、 そのパッケージの setinfo ファイルもコピーされます。
-o 宛先デバイスにある同一インスタンスを上書きします。 パッケージ・インスタンスが存在する場合は上書きされます。
-n パッケージの新規インスタンスを宛先デバイス上に作成します。 パッケージ・インスタンスが宛先デバイスに存在する場合、そのパッケージ・インスタンスは変更されずに残り、新規インスタンスが作成されます。 新規インスタンスには、既存のインスタンスと区別するために付加されたシーケンス番号があります。 例えば、宛先デバイスに既にパッケージ Xのインスタンスが含まれているとします。 -n フラグを指定した pkgtrans を使用して、パッケージ X の新規インスタンスをデバイスに書き込む場合、パッケージ X の既存のインスタンスは宛先デバイス上に残り、 X.2と呼ばれる新規インスタンスをデバイス上に作成できます。 -n フラグを指定して pkgtrans を再度実行すると、 X.3という 3 番目のインスタンスが作成されます。
-s パッケージをファイル・システムとしてではなく、データ・ストリームとして Device2 に書き込む必要があることを示します。 デフォルトの振る舞いでは、Device2 がファイルシステム・フォーマットで 書き込まれます。
-z BlockSize カートリッジ・テープへの転送時に使用するブロック・サイズを示します。 -z フラグを使用してテープに書き込まれ、512 以外の値を持つパッケージは、常にブロック・サイズ 32768 を使用して読み取られます。 したがって、カートリッジ・テープから読み取る場合には、-z フラグは適用できません。
Device1 ソース・デバイスを指定します。 標準入力から読み取られるデータ・ストリーム形式のパッケージを指定する - (ハイフン) を指定できます。 このデバイス上のパッケージまたはパッケージは翻訳され、 Device2に配置されます。 Device1 が通常のファイルまたはディレクトリーである場合、 相対パス名ではなく絶対パス名を使用しなければなりません。
Device2 宛先デバイスを指定します。 データ・ストリーム形式で標準出力に書き込まれるパッケージを指定する-(ハイフン) を使用できます。 変換されたパッケージはこのデバイスに入ります。 Device2 が通常のファイルまたはディレクトリーである場合、 相対パス名ではなく絶対パス名としてこれを指定しなければなりません。
プッギンスト Device1 上のどのパッケージを変換する必要があるかを指定します。 トークン all を使用して、すべてのパッケージを示すことができます。 Pkginst.* (Pkginst.*) パッケージのすべてのインスタンスを示すために使用できます。 パッケージが定義されていない場合、プロンプトによってデバイス内のすべてのパッケージが 示され、どれを変換するのか尋ねられます。 セットがデータ・ストリーム形式に転送される場合、 Pkginst 引数は SIP で始まり、その後に、SIP の setinfo ファイルにリストされているパッケージが、そのファイルに出現する順序で続く必要があります。
注: デフォルトでは、パッケージのインスタンスが宛先デバイスに存在する場合、 pkgtrans はそのパッケージのインスタンスを転送しません。 このパッケージのインスタンスが存在する場合、 -n フラグを使用すると新規インスタンスが作成されます。 -o フラグを使用すると、同じインスタンスが存在する場合は上書きされます。 いずれにしてもデータ・ストリーム全体が上書きされるため、宛先デバイスがデータ・ストリームである場合は、これらのフラグはどちらも有用ではありません。

例

  1. ドライブ Device 上にあるすべてのパッケージを翻訳し、その翻訳を /tmpに入れるには、次のように入力します。
    pkgtrans Device /tmp all
  2. tmp 内の pkg1 および pkg2 を変換し、それらをデータ・ストリーム形式の Device に配置するには、次のように入力します。
    pkgtrans -s /tmp Device pkg1 pkg2
