目的

1 つ以上のノードをピア・ドメイン定義に追加します。

構文

addrpnode [-c] [-h] [-TV] node_name1 [node_name2 ...]
addrpnode [-c] { -f │ -F { file_name │ "-" } } [-h] [-TV] [-M]
addrpnode [-c] [-h] [-TV] node_name1 [@host_name1] [node_name2 [@host_name2] …]

説明

addrpnode コマンドを実行する前に:

適切なセキュリティー環境をセットアップするには、 ピア・ドメインに追加する各ノードで preprpnode コマンドを実行します。

addrpnode コマンドは、指定されたノードを、addrpnode コマンドが実行されるオンライン・ピア・ドメインに追加します。 このコマンドは、それらの新規ノードが追加されるピア・ドメインに対してオンラインになっているノードで実行しなければなりません。 1 つのノードを複数のピア・ドメインに定義できますが、オンラインにできるのは、1 つのピア・ドメインのみです。 ピア・ドメインに 1 つ以上のノードを追加するためには、半数を上回るノードがオンラインでなければなりません。

ノードの 1 つにエラーが発生しても addrpnode コマンドの継続を可能にするには、-c フラグを使用します。

addrpnode コマンドは、 追加されたノードをピア・ドメインでオンラインにしません。 これを行うには、startrpnode コマンドを使用します。

フラグ

-c
少なくとも 1 つのノードをピア・ドメインに追加できる間は、コマンドの処理を続行します。

デフォルトでは、いずれかのノードで addrpnode コマンドが失敗すると、すべてのノードで失敗します。 -c フラグを指定するとこの動作がオーバーライドされ、 addrpnode コマンドは 1 つのノードで失敗しても残りのノードで実行されます。

-f | -F { ファイル名 | "-" }
ファイルまたは標準入力からノード名を読み取ることを指定します。

ファイルからノード名を読み取るには、 -f file_name または -F file_name を使用します。 -f "-" または -F "-" を使用して、 STDIN を入力ファイルとして指定します。

注:
  • 1 行につき 1 つのノード名を指定します。 コマンドは、ノード名の左側のブランク文字があっても無視します。
  • 番号記号 (#) を使用して、行の残りの部分 (または # が 1 桁目にある場合は行全体) がコメントであることを示します。
デフォルトでは、file_name にリストされるノードはすべて、以下のようになります。
  • グループ・サービスのグループ・リーダー候補ですか?
  • クォーラム決定に使用されます。
  • ピア・ドメイン・タイ・ブレーカー・メカニズムにアクセスできます。
ノード特性をカスタマイズするには、アットマーク (@) 制御文字を使用し、その後で以下の特殊文字のうち 1 つ以上を付けます。
P | p
ノードがグループ・サービスのグループ・リーダー候補であることを指定します。
Q | q
ノードがクォーラム・ノードであることを指定します。
B｜b
ノードがピア・ドメイン・タイ・ブレーカー・メカニズムにアクセスすることを指定します。 B または b は、クォーラム・ノードにのみ指定できます。
!
ノードが特定の特性を持っていないことを指定します。 例えば、!Q は、ノードがクォーラム・ノードでないことを指定します。
ノードの特性をカスタマイズする場合、以下を考慮してください (ここで x は P、Q、または B です)。
  • 1 行につき 1 つの @ 制御文字のみを使用し、その後にノード名の直後およびコメントの前に 1 つ以上の特殊文字を続けます。
  • ノードには !QB を指定しないでください。指定すると、エラーになります。
  • ノード番号を使用する場合は、ノード名の後でコメントの前にそれを追加してください。 ノード番号は、ノード特性の指定の前にも後ろにも付けることができます。
  • 1 つ以上のノードに x が指定され、どのノードにも が指定されていない場合、 x が指定されていないノードの値は !xであると想定されます。
  • 1 つ以上のノードに !x を指定し、いずれのノードにも x を指定しない場合は、!x が指定されていないノードには、値 x が指定されているものと想定されます。
  • x と !x を同じノード・ファイル内の異なるノードに指定する場合は、ファイル内のすべてのノードに x または !x が指定されている必要があります。
-h
コマンドの使用方法の文を標準出力に書き込みます。
-M
新しいノードのセキュリティー・コンプライアンス・モードがドメインと一致しているかどうかを検証します。 モードが一致しない場合、ノードは追加されません。 -M オプションが指定されておらず、ノードがドメインと互換性のある鍵タイプを使用している場合、ノードが追加され、その準拠モードがドメインと一致するように更新されます。
-T
標準エラーにコマンドのトレース・メッセージを書き込みます。 これはソフトウェア・サービス組織専用です。
-V
コマンドの詳細メッセージを標準出力に書き込みます。

パラメーター

node_name1 [node_name2 ... ]
ピア・ドメイン定義に追加するノードを 1 つ以上指定します。 ノード名は IP アドレスか、DNS ホスト名の長いものまたは短いものです。 ノード名は IP アドレスに解決する必要があります。
node_name1[@host_name1] [node_name2[@host_name2] ...]

ノード名ならびにノードごとのホスト名を使用して、RPD に追加する必要があるノードを指定します。 node_name1 パラメーターはラベルに対応しますが、host_name1 パラメーターは IP アドレスあるいは DNS ホスト名のロング・バージョンまたはショート・バージョンです。 ホスト名は、連絡を取れるか、ping できる有効な値でなければなりません。

HostName パラメーターが指定されておらず、Name パラメーターのみが addrpnode コマンドに指定されている場合、HostName パラメーターは Name パラメーターとして設定されます。 この場合、Name パラメーターは、IP アドレスあるいは DNS ホスト名のロング・バージョンまたはショート・バージョンに解決される必要があります。

既存のピア・ドメインにノードを追加するには、次のコマンドを使用します。
addrpnode node_name3@host_name3
addrpnode -f /home/nodelst コマンドを実行することもできます。ここで、 /home/nodelst のノード名は node_name3@host_name3.in.ibm.comです。

セキュリティー

addrpnode コマンドのユーザーには、 IBM.PeerDomain リソース・クラスおよび IBM.PeerNode リソース・クラス。 これは、追加する各ノードで preprpnode コマンドを実行するとセットアップされます。 preprpnode コマンドを使用して、そのピア・ドメイン内でオンラインになっているすべてのノードの名前を指定してください。 これにより、追加されるノードに対して操作を実行するのに必要な権限がそれらのオンライン・ノードに与えられます。

環境変数

CT_CONTACT
Resource Monitoring and Control (RMC) デーモンとのセッションが発生するシステムを決定します。 CT_CONTACT をホスト名または IP アドレスに設定すると、コマンドは指定されたホストの RMC デーモンにアクセスします。 CT_CONTACT を設定しないと、コマンドは、そのコマンドが実行されているローカル・システムの RMC デーモンにアクセスします。 RMC デーモン・セッションのターゲットおよび管理有効範囲によって、処理されるリソース・クラスまたはリソースが決定されます。
CT_IP_AUTHENT
CT_IP_AUTHENT 環境変数が存在する場合、RMC デーモンは、IP ベース・ネットワーク認証を使用して、CT_CONTACT 環境変数が設定されている IP アドレスで指定されたシステム上の RMC デーモンにアクセスします。 CT_CONTACT が IP アドレスに設定されている場合のみ、CT_IP_AUTHENT が意味を持ちます。CT_IP_AUTHENT はドメイン・ネーム・システム (DNS) サービスに依存しません。

制約事項

このコマンドは、新規ノードを追加するピア・ドメイン内でオンラインになっているノード上で実行しなければなりません。

実行の特性

このコマンドはAIX用のReliable Scalable Cluster Technology(RSCT)ファイルセットの一部です。

標準入力

-f "-" または -F "-" フラグを指定すると、このコマンドは標準入力から 1 つ以上のノード名を読み取ります。

標準出力

-h フラグが指定されると、コマンドの使用状況のステートメントが標準出力に書き出されます。 詳細メッセージはすべて、標準出力に書き込まれます。

標準エラー

トレース・メッセージはすべて、標準エラーに書き込まれます。

例

  1. ノード'node_name2と'node_name3ピアドメイン'ApplDomain'に追加するには、ピアドメイン'ApplDomain'に'node_name1がすでに定義され、オンラインになっている場合、'node_name1でコマンドを実行する：
    addrpnode node_name2 node_name3
  2. ピアドメインApplDomainにノード'node_name2と'node_name3'とホスト名を追加するには、'node_name1がすでに定義され、ピアドメインApplDomain上でオンラインになっている場合、'node_name1でコマンドを実行する：
    addrpnode node_name2@host_name2 nodeC_name3@host_name3

ロケーション

/opt/rsct/bin/addrpnode
