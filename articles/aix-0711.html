目的

システムモデル（MTM 値）に加え、OS レベル、ファームウェアレベル、またはその両方に基づいて、 IBM Fix Level Recommendation Tool（FLRT）サーバーからサポートとライフサイクル情報を取得します。

構文

life_cycle_data [ [ -L OSlevel | -F fw ] : -M MTM ] | [ -c client ] ]

説明

life_cycle_data コマンドは、 IBM FLRT サーバーからサポート情報とライフサイクル情報を取得する。 システムモデルに加えて、OSレベル、ファームウェアレベル、またはその両方を入力することができます。 入力がない場合、 life_cycle_data コマンドは、OSレベル、ファームウェア・レベル、およびシステム・モデルをシステムから自動的に収集する。

フラグ

表 1. フラグ
項目
説明
-L OSレベル システムの AIX、VIOSレベルを指定する。
-F エフダブリュー システムのファームウェア・レベルを指定する。
-M MTM システムモデルを指定する。
-c クライアント Network Installation Manager (NIM)クライアントの名前を指定する。

例

  1. 現在のシステムのサポートとライフサイクル情報をチェックするには、以下のコマンドを入力する：
    life_cycle_data
  2. AIX /VIOS OSレベルとMTMレベルに基づいてサポートとライフサイクル情報を確認するには、次のコマンドを入力します：
    life_cycle_data -L 7300-01-01-2246 -M 8286-42A
    注意： サービスパック（SP）が 00 であるOSレベルを指定した場合、 life_cycle_data コマンドは、 eSupport サーバーに対してOSレベルを検証する際に、4番目のフィールドを無視します。 eSupport サーバーには、SP 00 のサブレベルは表示されていない。 つまり、システムの AIX レベルが 7300-03-00-2446 として指定されている場合、 eSupport サーバーによって 7300-03-00 として扱われる。
  3. ファームウェアとMTMレベルに基づくサポートとライフサイクル情報を確認するには、以下のコマンドを入力する：
    life_cycle_data -F VL950_098 -M 8286-42A
  4. AIX /VIOS OSレベル、ファームウェア、MTMレベルに基づくサポートとライフサイクル情報を確認するには、以下のコマンドを入力します：
     life_cycle_data -L 7300-01-01-2246 -F VL950_098 -M 8286-42A
  5. NIMクライアントのサポートおよびライフサイクル情報を確認するには、NIMサーバーから以下のコマンドを入力する：
    life_cycle_data -c "nim_client1 nim_client2"

or

life_cycle_data -c "nim_client1,nim_client2"
