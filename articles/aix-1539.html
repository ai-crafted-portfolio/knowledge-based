目的

グローバル・システムと ワークロード・パーティションの間でソフトウェアを同期化します。

構文

共有 WPAR 同期

/usr/sbin/syncwpar [ [ -a ] [ -i ] | [ -F ] [ -r ] ] [ -p ] [ -v ] [ -X ] { -A | -f wparnamesfile | WPAR 名 }

切り離された WPAR 同期

/usr/sbin/syncwpar -D [ -d デバイス ] [ -p ] [ -v ] [ -X ] { -A | -f wparnamesfile wparname }

切り離された WPAR 暫定修正操作

/usr/sbin/syncwpar -D { -E < path to fix> | -R < ifix label>} { -A | -f wparnamesfile | wparname }

バージョン管理された WPAR デバイス・データの同期

/usr/sbin/syncwpar -c ワーパルネーム

説明

syncwpar コマンドは、グローバル共用パーツ (通常は /usr および /opt) にインストールされているソフトウェアを ワークロード区画 root パートと同期化します。

-D フラグを指定すると、 syncwpar コマンドは、書き込み可能な /usr ディレクトリーを使用して、切り離された ワークロード・パーティション (WPAR) にあるシステム・ソフトウェアをリカバリーします。 これはグローバル環境のシステム・ソフトウェアから分岐しています -D フラグを指定しない場合、 syncwpar コマンドは、読み取り専用 /usr ディレクトリーを持つ共有 WPAR 上でのみ実行されます。

注意： syncwparコマンドは、AIX 5.2またはAIX 5.3バージョンのWPAR のソフトウェア・レベルの同期には使用できない。 バージョン管理された WPAR 内のソフトウェアは、グローバル環境内のソフトウェアから独立しています。

syncwpar コマンドは、 WPAR 名 パラメーターを指定した場合は単一の WPAR で動作し、 -f wparnamesfile パラメーターを使用して WPAR 名 パラメーターを指定した場合は WPAR のリストで動作し、 -A フラグを指定した場合はすべてのシステム WPAR で動作します。

制約事項: アプリケーション ワークロード・パーティション での syncwpar コマンドの実行は制限されています。
注: syncwpar コマンドを実行してバージョン 6 ワークロード・パーティションを同期化すると、バージョン 7 グローバル・システムでは、 syncwpar コマンドによって migwpar コマンドが呼び出され、ワークロード・パーティションが移行されます。

フラグ

項目
説明
-a 追加のインストールのみを行います。 installp ファイルセットのレベルを下げません (つまり、アンインストール、リジェクト、強制上書き)。 -r フラグと一緒の場合は無効です。
-c 指定されたバージョン管理された ワークロード・パーティション内の事前定義ストレージ・デバイス・データを同期化します。 デバイス・データを同期化するのに、-d のデバイス・フラグは不要です。 デバイス・データの同期は、WPAR でストレージ・デバイスを構成するときの問題を解決するのに役立ちます。
-D 書き込み可能な /usr ディレクトリーを持つ、切り離されたシステム ワークロード・パーティション 内のソフトウェアを同期化します。 デフォルトでは、読み取り専用の /usr ディレクトリーを持つ共用システム ワークロード・パーティション のみでソフトウェアを同期化します。
-i installp ファイルセットのみを更新します。 -r フラグと一緒の場合は無効です。
-F RPM ファイルを強制的にコピーします。 -i フラグと一緒の場合は無効です。
-r RPM ファイルのみを更新します。 -i フラグと一緒の場合は無効です。
-p 操作をプレビューします。 実際には同期を行いません。
-v 冗長モードを指定します。
-X 必要かつ可能ならば、ファイルシステムを拡張します。
-A 使用可能なすべてのシステム ・ワークロード・パーティション をグローバル・システムと同期化します。
-f wparnamesfile パラメーターに ワークロード・パーティション のリストを含むファイルを指定します。
-d 特定のソフトウェア・インストール・ディレクトリーを使用して、切り離された WPAR wpar内のソフトウェアを同期化します。 -d フラグは、-D フラグと一緒に使用されるときのみ有効です。
  • -d フラグが指定されると、 ディレクトリー内のイメージは基本インストールの適用またはデタッチ WPAR への更新に使用されます。 指定された位置にあるインストール・イメージまたは更新イメージは、グローバル・システムをインストールまたは更新するために最後に使用したイメージと同じであるため、結果として得られるソフトウェア・レベルが一致していることは重要です。
  • -d フラグが指定されないと、 同期はデタッチ WPAR 内のソフトウェアのレベルをリジェクトまたはコミットします。
-R 指定した暫定修正を WPAR から除去します。 この引数は、除去する必要のある ifix パラメーターのラベルです。 このフラグは、切り離されたシステム ワークロード・パーティションに対してのみ有効です。
-E 指定された暫定修正を、切り離されたシステムの ワークロード・パーティションにインストールします。 この引数は、ifix パラメーターへの絶対パスです。 このフラグは、切り離されたシステム ワークロード・パーティションに対してのみ有効です。

パラメーター

項目
説明
wparnamesファイル ワークロード・パーティション 名のリストを含むファイルを指定します。
ワーパルネーム ワークロード・パーティションの名前を指定します。
装置 デバイスの名前を指定します。

セキュリティー

アクセス制御: root ユーザーのみがこのコマンドを実行できます。

例

  1. ワークロード区画 mywpar上のすべてのソフトウェアを同期化するには、次のコマンドを入力します。
    syncwpar mywpar
  2. すべての WPARを同期化するには、グローバル環境で次のコマンドを入力します。
    # syncwpar -A
  3. mywpar という名前の WPAR を同期化し、ファイルシステムを自動的に拡張するには、次のコマンドを入力します。
    # syncwpar -X mywpar
  4. /mysw ソフトウェア・インストール・ディレクトリーを使用して、 privatewpar という名前の切り離された WPAR 内のソフトウェアを同期化するには、次のコマンドを入力します。
    # syncwpar -D -d /mysw privatewpar
  5. myfix.epkg.Z 暫定修正をすべての切り離されたシステム ワークロード・パーティションにインストールするには、次のコマンドを入力します。
    # syncwpar -D -E /tmp/myfix.epkg.Z -A
  6. myfix というラベルの暫定修正を、切り離されたすべてのシステム・ ワークロード・パーティションから除去するには、次のコマンドを入力します。
    # syncwpar -D -R myfix -A
