目的

IANA（Internet Assigned Numbers Authority）の最新のオルソンタイムゾーンデータベースを使用して、 AIX® システムのタイムゾーンデータベースを更新する。

構文

tzupg.pl

説明

tzupg.pl コマンドは、 IANA からの最新の Olson time zone database に基づいて、 AIX システムのタイムゾーン情報を更新する。 このコマンドは、グローバル・タイムゾーン定義の最新の変更がシステムに反映されるようにします。 tzupg.pl ツールは、オンラインとオフラインの両方のアップデートをサポートしています。 デフォルトでは、現在インストールされているタイムゾーン・データベースのバージョンが表示されます。
注： tzupg.pl コマンドを実行するには、root または superuser 権限が必要です。

例

tzupg.pl ツールはメインメニューを表示し、メインメニューから以下のオプションを選択するよう促します：
$ tzupg.pl
<><><><><><><><><><>-- ------------------ --<><><><><><><><><><>
<><><><><><><>-- TZ AUTOMATION TOOL (Ver:xxxxx) --<><><><><><><>
<><><><><><><><><><>-- ------------------ --<><><><><><><><><><>
 
****> MAIN MENU <*****************
Select an option:
1. Update the timezone database
2. Update the timezone database offline
3. Print the updated zones
4. Exit from the tool
 
Enter your choice (1/2/3/4):
注:
タイムゾーンデータベースの更新
タイムゾーン・データベースの更新処理を開始する。 更新するバージョンを選択するプロンプトが表示されます。
タイムゾーンデータベースの更新（オフライン）
システムがインターネットに接続されていないときにタイムゾーンデータベースを更新する。
更新されたゾーンの印刷
AIX システムの以前のタイムゾーン・データベースと比較して更新されたタイムゾーンを表示します。
ツールを終了します
tzupg.pl ツールを終了する。
