目的

iSCSI ターゲット・データを追加します。

構文

mkiscsi-lAdapterName-gstatic-tTargetName-nPortNumber-i IPアドレス [-p パスワード ] [-uUserName ]

mkiscsi-lAdapterName-gauto-tTargetName-p パスワード-uUserName ]

mkiscsi -l AdapterName -g グループ -f FileName

説明

mkiscsi コマンドは、 iSCSI ターゲット・データを ODMに追加します。 ODM には 2 つのカテゴリーのデータが保管されています。 1つ目は、静的に設定された「iSCSIターゲットに対するもので、「AIX」がターゲットを発見するためには、関連する「iSCSIターゲットの情報（ターゲット名、IPアドレス、ポート番号など）がすべて指定されている必要がある。 iSCSI ターゲット・データの 2 つ目のカテゴリーは iSCSI ターゲット・デバイスのためのもので、 それは自動的に構成可能ですがホストの認証 (パスワードなど) が必要です。 これらの 2 つのカテゴリーの iSCSI ターゲット・データは、 -g フラグで指定された static グループと auto グループにそれぞれ関連付けられます。

フラグ

項目
説明
-f FileName そこから iSCSI ターゲット情報を読みとってそれから ODM へ置かれるファイル名を指定します。
-g グループ この iSCSI ターゲットが関連付けられるグループを指定します。 有効なグループは、 static と autoの 2 つです。 static グループは、このホストから自動的にディスカバーできない iSCSI ターゲット用です。それらに関連するすべての iSCSI ターゲット情報 (ターゲット名、IP アドレス、ポート番号など) を指定する必要があります。 auto グループは、自動的にディスカバーされるが、パスワードなどの認証情報を必要とする iSCSI ターゲット用です。
-i IP アドレス iSCSI ターゲットの IP アドレスを指定します。
-l AdapterName この iSCSI ターゲットに接続される iSCSI TCP/IP Offload Engine (TOE) アダプターのアダプター名を指定します。 これはまた iSCSI ソフトウェア・ソリューション・デバイス用の iSCSI プロトコル・デバイスを指定することもできます。
-n NewPortNumber iSCSI ターゲットがアクセスされる対象のポート番号を指定します。 デフォルトのポート番号は 3260 です。
-p パスワード この iSCSI ターゲットの新規パスワードを指定します。
-t TargetName iSCSI ターゲット名 (例えば、iqn.sn9216.iscsi-hw1) を指定します。
-u UserName ログイン時に使用できるチャレンジ・ハンドシェーク認証プロトコル (CHAP) ユーザー名を指定します。 この値は、CHAP パスワードが指定されている場合にのみ使用されます。 CHAP ユーザー名が指定されていない場合、iSCSI イニシエーターは、CHAP ユーザー名にローカル iSCSI 修飾名 (iSCSI デバイスの initiator_name 属性で指定) を使用します。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

セキュリティー

mkiscsi コマンドは、root によってのみ実行可能です。

例

  1. 静的に構成された 1 つの iSCSI ターゲットを追加するには、次のコマンドを入力します。
    mkiscsi -l ics0 -g static -t iqn.sn1234.iscsi_hw1
  2. ファイル /etc/iscsi/targetshwからすべてのエントリーを追加するには、次のコマンドを入力します。
    mkiscsi -l ics0 -g static -f /etc/iscsi/targetshw

場所

/usr/sbin/mkiscsi
