目的

ファイルの行の分割に役立ちます。

構文

カット {  -b リスト [  N ] |  「-c」 リスト |  「-f」 リスト [  -s ] [  -d 年 キャラクター ] } [ ファイル ... ]

説明

cut コマンドは、ファイルの各行から、バイト、文字、フィールドをカットして、これらを標準出力に書き出します。 File パラメーターを指定しないと、cut コマンドは標準入力を読み取ります。

-b、 -cのいずれかを指定する必要があります。 または -f フラグを指定します。 List パラメーターには、コンマ、ブランク、またはハイフンで区切られた整数番号の (昇順の) リストを指定します。 ハイフン・セパレーターは範囲を示します。 バイト、文字、またはフィールドを参照する List パラメーターの入力例を以下に示します。

1,4,7
1-3,8
-5,10
3-

ここで-51 番目から 5 番目までの短い形式です。3-3 番目から最後までの短い形式です。

cut コマンドでフィールドをカットする場合、 List パラメーターに指定したフィールド長を、フィールド別または行別に変更できます。 タブ文字などのフィールド区切り文字の位置が、フィールドの長さを決定します。

grep コマンドを使用してファイル全体を水平方向にカットし、paste コマンドを使用してファイルを再度まとめることができます。 ファイル内の列の順序を変更するには、cut コマンドと paste コマンドを使用します。

フラグ

項目
説明
-b リスト バイト位置を指定します。 これらのバイト位置は、 -n フラグも指定されていない限り、マルチバイト文字境界を無視します。
-c リスト 文字位置を指定します。 例えば、次のように指定すると、-c 1-72,cut コマンドは、ファイルの各行の最初の 72 文字を書き出します。
-d 文字 -f フラグを指定すると、 Character 変数で指定した文字をフィールド区切り文字として使用します。 スペース文字のように、 シェルに対して特殊な意味を持つ文字は、引用符で囲まなければなりません。
-f リスト ファイル内で区切り文字で区切られると想定される一連のフィールドを指定します。デフォルトではタブ文字が区切り文字です。 例えば、次のように指定すると、-f 1,7,cut コマンドは、各行の最初と 7 番目のフィールドのみを書き出します。 行にフィールド区切り文字が含まれていない場合、 -s フラグを指定しない限り、 cut コマンドはそれらをそのまま渡します (表の副見出しに役立ちます)。
-n マルチバイト文字の分割を抑制します。 -b フラグと一緒にのみ使用してください。 文字の最後のバイトが -b フラグの List 変数で指定された範囲内にある場合は、その文字が書き込まれます。それ以外の場合は、その文字は除外されます。
-s 区切り文字が含まれていない行を抑制します。 -f フラグと一緒にのみ使用してください。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 すべての入力ファイルが正常に出力されました。
>0 エラーが発生しました。

例

  1. ファイルの各行の複数のフィールドを表示するには、次のように入力します。
    cut  -f 1,5 -d : /etc/passwd
    この例では、システムのパスワード・ファイルのログイン名のフィールドと完全ユーザー名のフィールドが表示されます。 これらは 1 番目と 5 番目のフィールドです (-f 1,5) コロンで区切られています (-d :).

    例えば、/etc/passwd ファイルの内容が以下のような場合、

    su:*:0:0:User with special privileges:/:/usr/bin/sh
daemon:*:1:1::/etc:
bin:*:2:2::/usr/bin:
sys:*:3:3::/usr/src:
adm:*:4:4:System Administrator:/var/adm:/usr/bin/sh
pierre:*:200:200:Pierre Harper:/home/pierre:/usr/bin/sh
joan:*:202:200:Joan Brown:/home/joan:/usr/bin/sh
    cut コマンドによる出力は以下のようになります。
    su:User with special privileges
daemon:
bin:
sys:
adm:System Administrator
pierre:Pierre Harper
joan:Joan Brown
  2. ブランクで区切られたリストを使用してフィールドを表示するには、次のように入力します。
    cut -f "1 2 3" -d : /etc/passwd
    cut コマンドによる出力は以下のようになります。
    su:*:0
daemon:*:1
bin:*:2
sys:*:3
adm:*:4
pierre:*:200
joan:*:202

ファイル

項目
説明
/usr/bin/cut cut コマンドが入っているファイルです。
