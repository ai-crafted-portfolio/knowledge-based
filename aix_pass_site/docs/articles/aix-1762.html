目的

NFS/TFTP でアクセスするフォント・ディレクトリーをフォント・パスに追加します。

構文

x_add_nfs_fpe ホスト・ディレクトリー・メソッド位置 TypeName

説明

x_add_nfs_fpe コマンドは、選択したネットワーク・タイプ名のフォント・パスにフォント・パス・エレメントを追加 します。 このフォント・ディレクトリーには、ネットワーク・ファイルシステム (NFS) またはトリビアル・ファイル転送プロトコル (TFTP) を使ってアクセスします。

項目
説明
Host フォント・ディレクトリーにアクセスするためのシステム名を指定します。
directory フォントが入っているディレクトリーへの絶対パスを指定します。
メソッド (method) 次のいずれかを指定nfsまたはtftpフォントにアクセスするために使用されます。
位置 このエレメントを挿入するフォント・パス内の位置を指定します。
TypeName ネットワーク・タイプの名前を指定します。 ネットワーク・タイプごとに、1 つ以上のフォント・パス・エレメントからなるフォント・パスがあります。 フォント・パス要素が追加されるネットワーク・タイプの名前を指定するか, あるいは次の指定によってフォント・パス要素をすべてのネットワーク・タイプ名に追加することを選択してください。Allフォント・パス・エレメントが追加された場合Allネットワーク・タイプの場合は、各フォント・パスの末尾に配置されます。

セキュリティー

アクセス制御 : root ユーザーだけが、このコマンドに実行 (x) アクセスできるようにしてください。

例

フォントを追加するには /usr/lib/X11/fonts/100dpiネットワーク・タイプにx_st_mgr.ether次のように入力します。

x_add_nfs_fpe cedar /usr/lib/X11/fonts/100dpi nfs Last \ x_st_mgr.ether

このフォント・パス・エレメント/usr/lib/X11/fonts/100dpiネットワーク・タイプのフォント・パスの末尾に追加されます。x_st_mgr.etherフォント・ディレクトリーはホスト上にあります。cedarこれには、 NFSを使用してアクセスします。

ファイル

項目
説明
/usr/lpp/x_st_mgr/bin/x_add_nfs_fpe x_add_nfs_fpe コマンドが入っています。
/etc/x_st_mgr/ether.cf ネットワーク・タイプ x_st_mgr.ether 構成ファイル (サンプル) が入っています。
