目的

ノード上またはコントロール・ワークステーション上のトポロジー・サービス・オプションを制御します。

構文

hatsoptions [-s] [-d]

説明

このコマンドを実行する前に、環境変数 HB_SERVER_SOCKET を、トポロジー・サービス・サブシステムが使用する UNIX ドメイン・ソケットの場所に設定する必要があります。 以下のステートメントを使用できます。
export HB_SERVER_SOCKET=/var/ha/soc/hats/server_socket.partition name
あるいは、変数 HA_SYSPAR_NAME をパーティション名に設定することもできます。

このコマンドを正常に実行するには、トポロジー・サービス・デーモンが実行されている必要があります。

hatsoptions トポロジー・サービスのいくつかのオプションを制御するために使用できます。 オプション -s は、明らかに遅延しているメッセージを拒否するようにトポロジー・サービス・デーモンに指示します。 これは、大規模システム構成で使用できます。大規模システム構成では、ネットワーク内、または送信側ノードと受信側ノードでメッセージが遅延することがあります。 このオプションは、 時刻機構 (TOD) がすべてのノードとコントロール・ワークステーションにわたって同期化されている場合にのみ使用します。 そうしないと、送信側の時刻機構が受信側より遅れている場合に、メッセージが誤って廃棄される可能性があります。

オプション -d は、明らかに遅延しているメッセージを拒否しないようにトポロジー・サービス・デーモンに指示します。 これはデフォルトです。

フラグ

-s
明らかに遅れているメッセージをリジェクトするようにトポロジー・サービス・ デーモンに命令します。
-d
明らかに遅れているメッセージをリジェクトしないようにトポロジー・サービス・ デーモンに命令します (これがデフォルトです)。

セキュリティー

このコマンドを実行するには、 root 特権が必要です。

終了状況

0
コマンドの正常終了を示します。
1
コマンドが失敗したことを示します。

環境変数

HB_SERVER_SOCKET
この環境変数は、このコマンドを実行する前に設定する必要があります。 これは、トポロジー・サービス・クライアントがトポロジー・サービス・デーモンに接続するために使用する UNIX ドメイン・ソケットのロケーションに設定する必要があります。 この環境変数は、 /var/ha/soc/hats/server_socket.partition nameに設定する必要があります。
HA_SYSPAR_NAME
HB_SERVER_SOCKET を設定しなかった場合は、HA_SYSPAR_NAME を区画名に設定 する必要があります。

制約事項

このコマンドは、ピア・ドメインでのみ有効です。

標準出力

-h フラグが指定されている場合は、このコマンドの使用方法の説明文が標準出力に書き込まれます。 詳細メッセージはすべて、標準出力に書き込まれます。

標準エラー

このコマンドは、エラー・メッセージを (必要に応じて) 標準エラーに書き込みます。

例

ローカル・ノード上でトポロジー・サービス・デーモンに命令して、明らかに遅れている メッセージを廃棄するには、次のように入力します。
export HA_SYSPAR_NAME=partition1
 
/opt/rsct/bin/hatsoptions -s

ロケーション

/opt/rsct/bin/hatsoptions
hatsoptions コマンドが入っています。

ファイル

/var/ha/soc/hats/server_socket.区画名
