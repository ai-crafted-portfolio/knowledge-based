目的

フォーマットされたメッセージのリストを作成します。

構文

モール [ -形式 FormFile ] [ -フォルダー +フォルダー ] [ -moreproc コマンド | -nomoreproc [ ベル | -ノベル ] [ -クリア | -消去しない ] ] [ -長さ 数値 ] [ -幅 数値 ]

説明

mhl コマンドはメッセージのフォーマットされたリストを作成します。 コマンドは、通常、以下を介して開始されます。showproc:プロファイル項目を使用するか、他の MH コマンドの -showproc フラグを使用します。 メッセージを表示するときには、mhl コマンドはフォーマット・ファイルに示された指示を使用します。 複数のメッセージを指定すると、mhl コマンドはメッセージの各画面を表示する前にプロンプトを表示します。

-nomoreproc フラグが指定されると、mhl コマンドは、次のメッセージを見るために Return キー (Ctrl-D キー・シーケンスも可) を押すように求めるプロンプトを出します。 現在のメッセージの出力を停止し、次のメッセージのプロンプトを表示するには、Ctrl-D キー・シーケンスを押します。 このコマンドの出力を停止するには、QUIT キー・シーケンスを押します。

“注: mhl コマンドを使用するには、現行ディレクトリーで作業するフォルダーを作成する必要があります。”

フラグ

項目
説明
-ベル 各ページの終わりでベルを生成します。 -nomoreproc フラグが指定されている場合、またはmoreproc:プロファイル・エントリーは定義されていますが、空です。 -bell フラグがデフォルトです。
-clear 出力装置がディスプレイの場合、各ページの後で画面をクリアします。 mhl コマンドは $TERM 環境変数を使用して、ディスプレイの種類を決定します。 出力装置がディスプレイでない場合、-clear フラグは、 各メッセージの最後に用紙送り文字を挿入します。 このフラグは、以下の場合にのみ mhl コマンドに影響します。moreproc:プロファイル項目が定義されていますが、空です。
-folder +フォルダー mhl.format ファイルに使用するフォルダーを識別します。MessageName:項目。 デフォルトは、$mhfolder 環境変数の値です。
-フォーム FormFile 代替出力フォーマットが入っているファイルを指定します。 デフォルトのフォーマットは、UserMHDirectory/mhl.format ファイルに記述されています。 このファイルが存在しないと、mhl コマンドは /etc/mh/mhl.format ファイルに記述されているシステムのデフォルト・フォーマットを使用します。
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。

“注: MH の場合は、このフラグ名を省略することはできません。”
-length 数値 出力用に画面の長さを設定します。 デフォルトは、$TERM 環境変数に示される値です。 この値が適切でない場合、デフォルトは 40 行になります。
-moreproc コマンド 以下の値の代わりに Command 変数の値を使用します。moreproc:$HOME/.mh_profile ファイルに指定されているエントリー。
-nobell (-nobell) 各ページの終わりでベルを抑制します。 このフラグは、出力デバイスがディスプレイであるか、 -nomoreproc フラグが使用されているか、または以下のいずれかの場合にのみ、 mhl コマンドに影響します。moreproc:プロファイル項目が定義されていますが、空です。
-ノクリア 出力装置がディスプレイのとき、各ページの最後で画面をクリアしません。 出力装置がディスプレイでない場合、-clear フラグは、各メッセージの最後に書式送り文字を挿入しません。 このフラグは、 -moreproc フラグが使用されている場合のデフォルトです。moreproc:項目が定義されていますが、空です。
-ノモレプロック これは、moreproc:空の値として入力します。
-width 数値 出力用に画面の幅を設定します。 デフォルトは、$TERM 環境変数に示される値です。 この値が適切でなければ、デフォルトは 80 文字です。

プロファイル・エントリー

次のエントリーが、UserMHDirectory/.mh_profile ファイルにあります。

項目
説明
moreproc: ユーザーと通信する対話式プログラムを指定します。

例

  1. メッセージをリストする5inbox フォルダーで、ディレクトリーを inboxに変更します。
    cd /home/mickey/Mail/inbox
    それから、次のように入力します。
    /usr/lib/mh/mhl 5
    次のように表示されます。
    --- Using template MHL.FORMAT ---
Date:
   
To:
cc:
   
From:
Subject:
   
Message Text
  2. 複数のメッセージを表示するには、次のように入力します。
    /usr/lib/mh/mhl 5 6 7

ファイル

項目
説明
$HOME/.mh_profile MH ユーザー・プロファイルが入っています。
/etc/mh/mhl.format デフォルトの MH メッセージ・テンプレートを定義します。
ユーザーMHDディレクトリ/mhl.format ユーザーのデフォルトのメッセージ・テンプレートを指定します。 (これが存在する場合、デフォルトの MH メッセージ・テンプレートはオーバーライドされます。)
/usr/lib/mh/mhl mhl コマンドが入っています。
