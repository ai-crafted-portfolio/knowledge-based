目的

ユーザー・ボリューム・グループと、そのグループのすべてのコンテナーとファイルを復元します。

構文

restvg [ -b Blocks ] [ -d FileName ][ -f Device ] [ -l ] [ -q ] [ -r ] [ -s ] [ -n ] [ -P PPsize ] [ -S ] [ DiskName ... ]

説明

restvgコマンドは、「ブグネーム /tmp/vgdata/vgname/vgname.dataファイルで指定されたユーザー・ボリューム・グループとそのすべてのコンテナおよびファイルをリストアする。 /tmp/vgdata/vgname/vgname.dataファイルは、'savevgコマンドで作成されるバックアップイメージに含まれている。

restvg コマンドはユーザー・ボリューム・グループを復元します。 bosinstallルーチンは、ルート・ボリューム・グループ（rootvg）を再インストールする。 restvgコマンドがバックアップイメージの rootvg ボリュームグループに遭遇した場合、 'restvgコマンドはエラーで終了する。

/tmp/vgdata/vgname/vgname.dataファイルの'logical_volume_policyスタンザの'EXACT_FITフィールドにyes値が指定されている場合、'restvgコマンドはマップファイルを使用して、各論理ボリュームの物理パーティションの配置を保持する。 ターゲット・ディスクは、'vgname.dataファイルの'source_disk_dataスタンザで指定されたソース・ ディスクと同じサイズか、それ以上でなければならない。
注:
  • バックアップ・イメージのファイルを見るには、'restoreコマンドに '-Tフラグを付ける。
  • バックアップ・イメージから個々のファイルを復元するには、「restoreコマンドに「-xフラグを付ける。
  • ボリュームグループで「varyonvgコマンドを実行すると、論理トラックグループ（LTG）サイズがディスクの共通最大転送サイズに設定される。

-f device バックアップ・メディアのデバイス名を指定します。 デフォルトは /dev/rmt0です。
-l ボリューム・グループ・バックアップに関する有効な情報を表示します。

このフラグには、-f device フラグが必要です。 このフラグを指定すると、'restvgにボリューム・グループ、バックアップが作成された日付と時刻、バックアップされたシステムからのuname出力、oslevel、推奨メンテナンスと技術レベル、バックアップ・サイズ（メガバイト単位）、バックアップ縮小サイズ（メガバイト単位）などの情報が表示される。 圧縮サイズは、すべてのファイルシステム上のデータのサイズです。 フルサイズは、各ファイルシステムの合計サイズです (未使用 + データ)。 lsvg -l vgname -lフラグは、バックアップされたボリュームグループの論理ボリュームと ファイルシステム情報も表示する。
-n 既存の MAP ファイルが無視されることを指定します。 -nフラグは、「vgname.dataファイルのlogical_volume_policyスタンザ中の 「EXACT_FITフィールドの値を上書きする。
-P PPサイズ それぞれの物理区画のメガバイト数を指定します。 指定されない場合、'restvgは、リストアされる最大のディスクに依存するPPsizeの最適な値を使用する。 PPsizeの値が'vgname.dataファイルで指定されたサイズと同じでない場合、各論理ボリュームのパーティション数は新しいPPsizeに従って変更される。

指定されたPPsizeの値が適切なディスクサイズの値より小さい場合、大きい方のPPsizeが使用される。

指定されたPPsizeの値が適切なディスクサイズの値よりも大きい場合、指定された大きい方のPPsizeの値が使用される。
-q ボリューム・グループ・イメージの復元前に通常のプロンプトを表示しないように指定します。 このフラグを指定しないと、プロンプトがボリューム・グループ名とターゲット・ディスク・デバイス名を表示します。
-r ボリュームグループ構造のみを再作成します。 -rフラグを指定すると、'restvgコマンドはファイルやデータをリストアすることなく、バックアップからボリュームグループ、論理ボリューム、ファイルシステムを（指定されたバックアップFileNameまたはDevice に対して）作成することができます。 この機能は、データの復元にサードパーティ製ソフトウェアを使用し、すべてのAIX論理ボリューム構造を必要とするユーザーにとって便利である。
注: -r フラグは、 -f Device フラグまたは -d FileName フラグと一緒に使用できます。 この制限は、'restvgコマンドがボリュームグループの論理ボリューム構造を再作成するために必要なすべての情報を取得するために、バックアップイメージまたは'vgname.dataファイルを必要とするためです。
-s 論理ボリュームをファイルシステムにおさまるようにできるだけ小さいサイズで作成するように指定します。 このサイズは、'ブグネーム vgname.dataファイルの'lv_dataスタンザ内の'LV_MIN_LPSフィールドの値で指定される。

-sフラグは、'vgname.dataファイルの'logical_volume_policyスタンザにある'SHRINKと'EXACT_FITフィールドの値を上書きする。 -s フラグを指定すると、 SHRINK=yes および EXACT_FIT=no の値を指定した場合と同じ結果を得ます。
-S

ターゲット物理ボリュームは、ソース物理ボリュームと同じ暗号化ポリシーを持つ必要があることを指定します。 ソース物理ボリュームの少なくとも1つが暗号化されている場合、ソース物理ボリュームは暗号化されているとみなされる。 ただし、すべての対象物理ボリュームが暗号化されている場合、それらの物理ボリュームは暗号化されていると見なされます。

ソース物理ボリュームが暗号化されておらず、ターゲット物理ボリュームが暗号化されている場合、コマンド restvg はターゲット物理ボリュームの暗号化を無効化するよう要求します。 ソース物理ボリュームが暗号化されており、ターゲット物理ボリュームが暗号化されていない場合、コマンド restvg はターゲット物理ボリュームの暗号化を有効にするよう要求します。

注:
  • restvgコマンドに「-Sフラグを付けた場合、すべての認証タイプのうち、パスフレーズとPKS認証タイプはユーザー・ボリューム・グループでのみ復元されます。 ユーザー・ボリューム・グループの復元が完了した後で、他の認証タイプを追加することができます。
  • 暗号化ポリシーは、パスフレーズ認証およびプラットフォームキーストア（PKS）暗号化認証方式に適用されます。
  • ボリュームグループのバックアップイメージに、パスフレーズのみで暗号化された物理ボリュームが含まれている場合、この restvg -S コマンドは対象の物理ボリュームから追加の暗号化方式を削除しません。 ターゲット物理ボリュームがキーファイル、キーサーバー、その他の暗号化メカニズムなどの方法を使用して暗号化されている場合、これらの追加の暗号化方法はターゲット物理ボリューム上に残ります。

例

  1. /dev/rmt1デバイスから「hdisk2」および「hdisk3ディスクにボリューム・グループ・ イメージを復元するには、以下のコマンドを入力する：
    restvg -f/dev/rmt1 hdisk2 hdisk3
  2. /mydata/myvgファイルに保存されているボリューム・グループ・イメージを、バックアップ・イ メージ内の「vgname.dataファイルで指定されているディスク上にリストアするには、以下のコ マンドを入力する：
    restvg -f/mydata/myvg
  3. vgname.dataファイル「/home/my_dir/my_vg.data使用して、ファイルをリストアせずにボリュームグループの論理ボ リューム構造を再作成するには、次のコマンドを入力します：
    restvg -r -d /home/my_dir/my_vg.data
    注：'vgname.dataファイルは、'mkvgdataコマンドを使用してボリューム・グループ用に作成することができる。
  4. /dev/rmt0テープ上にあるボリューム・グループ・バックアップ内の「vgname.dataファイルを使用して、ファイルをリストアせずにボリューム・グループの論理ボリューム構造を再作成するには、次のコマンドを入力します：
    restvg -r -f /dev/rmt0
  5. /dev/rmt0テープにバックアップされたボリューム・グループに関するボリューム・グループ情報を表示するには、次のコマンドを入力する：
    restvg -l -f /dev/rmt0
  6. /dev/usbms0デバイスから、バックアップ・イメージ内の「vgname.dataファイルで指定さ れているディスク上にボリューム・グループ・イメージを復元するには、以下のコマンドを 入力します：
    restvg -f /dev/usbms0
    注：ボリューム・グループのバックアップの詳細については、「listvgbackupコマンドを参照のこと。 ボリューム・グループのバックアップから個々のファイルをリストアするには、「restorevgfilesコマンドを参照のこと。
