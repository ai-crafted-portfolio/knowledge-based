目的

特権ファイルにアクセスできるように、特権エディターを提供します。

構文

pvi [ -l ] [ -R ] [ -w Number ] [ -c | + [ Subcommand ] ] [ File ]

説明

pvi コマンドは、 vi エディターの特権バージョンである pvi エディターを呼び出して、 File パラメーターで指定されたファイルを編集します。 一度に 1 つのファイルのみを開くことができます。そのファイルは、特権ファイル・データベースで定義されたセキュリティー属性を持っていなければなりません。 エディターでファイルを表示できるのは、少なくとも 1 つの権限が、そのファイルの readauths 属性または writeauths 属性の権限の少なくとも 1 つと一致する場合のみです。 その場合にバッファーの内容の変更が可能になります。 エディターを使用してファイルに書き込むことができるのは、少なくとも 1 つの権限がファイルの writeauths 属性の権限の少なくとも 1 つと一致する場合のみです。 pvi コマンドによってオープンされたファイルは、オープン元と同じパスにしか書き込むことができません。

pvi エディターの開始と終了はコマンド・モードで行いますが、テキストを追加または変更するには、テキスト入力モードに切り替える必要があります。 テキスト入力モードを開始するサブコマンドについては、 テキスト入力モード を参照してください。 いずれかの :w コマンドを使用してテキストをファイルに保存し、 :q コマンドを使用して pvi エディターを終了することができます。

この pvi コマンドで開始されるフルスクリーン表示エディターは、ex エディターを基にしています。 pvi エディターの中で ex サブコマンドを実行できます。 サブコマンドは表示画面上のカーソル位置で機能します。

pvi エディターは、編集中のファイルのコピーを編集バッファーに作成します。 ファイルの内容は変更を保管しない限り変更されません。

注: vi エディターには、 pvi エディターでは使用できないいくつかの機能があります。 vi エディター上の情報を参照する場合、-r フラグ、-t フラグ、シェル・エスケープ、ユーザー定義マクロ、キー・マッピング、および vi オプションの永続設定は pvi エディターではサポートされないことを知っている必要があります。 一度に開くことができるバッファーは 1 つのみです。また、ファイルは開いたときと同じパスにのみ書き込むことができます。
エディターの制限

pvi エディターで扱える文字数には次の上限があります (1 バイト文字の数)。

  • グローバル・コマンド・リスト当たり 256 文字
  • 1 つのシェル・エスケープ・コマンドには 2048 文字まで。
  • 1 つの文字列値オプションには 128 文字まで。
  • 1 つのタグ名には 30 文字まで。
  • 524,230 行が暗黙的に強制される。
  • 合計 2048 文字で 128 マップ・マクロ。
編集モード

pvi エディターの操作モードは次のとおりです。

項目
説明
command mode pvi エディターはコマンド・モードで開始されます。 テキスト入力モードでテキストを訂正するサブコマンドを除くすべてのサブコマンドを呼び出すことができます。 サブコマンドの説明を表示するには、「 pvi エディターのサブコマンド」のトピックを参照してください。 コマンド・モードから呼び出すことができないサブコマンドを識別するには、「入力モードでのテキストの変更」を参照してください。 サブコマンドおよびその他のモードが終了すると、pvi エディターはコマンド・モードに戻ります。 1 つのサブコマンドを取り消すには、Esc キーを押します。
text input mode テキストの追加または変更のために許可されているコマンドを使用すると、pvi エディターはテキスト入力モードに入ります。 テキスト入力モードを開始するサブコマンドのリストについては、「ファイルへのテキストの追加」、およびコマンド・モードからテキストを変更するサブコマンド、 C サブコマンド、および cx サブコマンドを参照してください。 これらのサブコマンドの 1 つを入力した後、テキスト入力モードで機能するサブコマンドのいずれかを使用してテキストを編集することができます。 サブコマンドのリストを表示するには、「pvi エディターのサブコマンド」のトピックを参照してください。 テキスト入力モードからコマンド・モードに戻るには、Esc キーを押すか (通常の終了の場合)、または Ctrl + C キーを押します (INTERRUPT シグナルを作成する場合)。
last line mode 一部のサブコマンドは、画面の下部に表示される行に入力を読み取ります。 これらのサブコマンドには、接頭部がコロン (:)、スラッシュ (/)、および疑問符 (?) のサブコマンドが含まれます。 最初の文字を入力すると、 pvi エディターはカーソルを画面の下部に置き、残りのコマンド文字を入力できるようにします。 サブコマンドを実行するには、Enter を押します。 サブコマンドを取り消すには、Ctrl + C を押して、INTERRUPT シグナルを作成します。 コロン (:) を使用して最終行モードに入った場合、以下の文字は、カウントを指定するコマンドで使用すると特殊な意味を持ちます。
%

$
最終行
.

pvi エディターのカスタマイズ

vi エディター・オプションの設定の指示に従って、 pvi エディターを一時的にカスタマイズすることができます。

pvi エディターのサブコマンド
pvi エディターに適用できる vi エディター・サブコマンドに関する情報は、以下のリストにあります。
  • vi 一般サブコマンド構文。
  • vi 画面を調整するためのサブコマンド。
  • vi エディターを使用したテキストの編集。
  • vi エディターを使用したファイルの操作。
  • vi エディターの中断と終了を行うためのサブコマンド。

セキュリティー

アクセス制御:
このコマンドは、すべてのユーザーに実行 (x) アクセス権を付与します。
役割ベースのアクセス制御
このコマンドは、ユーザーが readauths または特権ファイル・データベース内の writeauths 権限リストの権限と一致する権限を持っている場合に、ファイルに対する読み取り権限を付与します。 このコマンドは、ユーザーが特権ファイル・データベース内の writeauths 権限リストにある権限と一致する権限を持っている場合にのみ、ファイルに対する write 権限を付与します。
アテンション RBAC ユーザー
RBAC ユーザーへの注意: このコマンドは特権操作を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. 特権エディターを呼び出して plans ファイルを編集するには、次のように入力します。
    pvi plans
    このコマンドは pvi エディターをコマンド・モードに置きます。 テキストを追加または変更するには、テキスト入力モードを入力するか、コマンド・モードで受け入れられるコマンドを使用する必要があります。
  2. pvi エディターで作成したテキストを保存するには、Esc を押してテキスト入力モードを終了してから、次のように入力します。
    :w
  3. テキスト入力モードの pvi エディターを終了するには、Esc を押してコマンド・モードに入ってから、次のように入力します。
    :q!
    エディターが既にコマンド・モードになっている場合は、終了 (q!) コマンドを出す前に Esc を押す必要はありません。
