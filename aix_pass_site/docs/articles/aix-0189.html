目的

定義済み属性のデフォルト値を変更します。

構文

chdef[-a 属性 = 値 -c クラス -s サブクラス -t タイプ]

chdef [-H ]

chdef [-h］

説明

chdef コマンドは指定されたデバイス・タイプの事前定義属性のデフォルト値を変更します。 変更されたデフォルト値は、指定されたリスト内、または指定された属性の値の範囲内になければなりません。また、明示的なリストまたは範囲の値をもつ属性のみを変更できます。 属性のデフォルト値を使用して現在構成されている、同じクラス、サブクラス、およびタイプのデバイスの場合、デバイスのデフォルト値の変更は、リブートするか、またはその後で構成解除と構成操作が行われるまでは有効になりません。 これは chdef コマンドが同じクラス、サブクラス、およびタイプのあらゆるデバイスを変更することを除き、-P オプションを指定して chdev コマンド操作を実行することに似ています。
注: chdef コマンドの実行後に bosboot コマンドを実行することをお勧めしますが、必須ではありません。

フラグ

項目
説明
-a 属性 = 値 新規のデフォルト値を設定する場合に使用するデバイス属性値ペアを指定します。 Attribute=Value 変数は 1 つの attribute=value ペアの指定に使用できます。
-c クラス デバイス・クラスを指定します。
-h コマンドの使用メッセージを表示します。
-H 出力される列の上にヘッダーを表示します。
-s サブクラス デバイスのサブクラスを指定します。
-t タイプ 定義済みデバイスのオブジェクト・クラスからデバイスのタイプを指定します。

セキュリティー

アクセス制御

特権制御: root ユーザーのみに、このコマンドの実行 (x) 権限があります。

イベントの監査

イベント
情報
デフォルトの DEV_DEFAULT デバイスのコマンド・ライン

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

例

  1. scsd ディスクの hcheck_interval 属性のデフォルト値を 0 から 3 に変更するには、次のように入力します。
    chdef -a hcheck_interval=3 -c disk -s scsi -t scsd
  2. scsd ディスクの hcheck_interval 属性のデフォルト値をデフォルトの 0 に戻すには、次のように入力します。
    chdef -a hcheck_interval=0 -c disk -s scsi -t scsd
  3. デフォルト値を変更したすべての属性をヘッダー付きでリストするには、次のように入力します。
    chdef -H
