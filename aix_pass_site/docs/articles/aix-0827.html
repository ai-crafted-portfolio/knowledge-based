目的

指定されたメディア上の ワークロード・パーティション ・バックアップの内容をリストします。

構文

lssavewpar [ -b ブロック ] [ -f デバイス ] [ -a ] [ -c ] [ -D ] [ -l | -L | -M | -N ] [ -V ]

説明

lssavewpar コマンドは、テープ、ファイル、CD、USB フラッシュ・ドライブ、または DVD からの ワークロード区画 バックアップの内容をリストします。

フラグ

項目
説明
-a -b フラグで定義されたように、テープ・バックアップの物理ブロック・サイズを検査します。 バックアップの読み取りの必要に応じて、ブロック・サイズを変更できます。 -a フラグが有効なのは、テープ・バックアップが使用された場合のみです。
-b ブロック blocks パラメーターによって定義されたように、1 回の入力操作で読み取る 512 バイト単位のブロック数を指定します。 blocks パラメーターが指定されない場合、読み取るブロックのデフォルト値は 100 です。 -b フラグが有効なのは、テープ・バックアップが使用されている場合だけです。
-c コロンで区切られた出力を生成します。 -c フラグを指定するのは、-l、-L、-M、および -N フラグを併用する場合のみです。
-D デバッグの出力を生成します。
-f デバイス バックアップ (ファイル、テープ、CD、またはその他のソース) を含むデバイスを device パラメーターで定義されたように指定します。 -f フラグを指定しない場合は、デフォルト・デバイス名は /dev/rmt0 です。
-l ワークロード・パーティション ・バックアップに関する情報を表示します。

ボリューム・グループ、バックアップ作成日時、バックアップ・システムの uname 出力、オペレーティング・システム・レベル、保守レベルまたはテクノロジー・レベル、バックアップ・サイズ (メガバイト)、バックアップ圧縮サイズ (メガバイト) などの情報を表示します。 圧縮サイズは、すべてのファイルシステム上のデータのサイズです。 フルサイズは、各ファイルシステムの合計サイズです (未使用 + データ)。 -l フラグは、バックアップされた ワークロード・パーティションの論理ボリュームとファイルシステムの情報も表示します。 -l フラグを指定する場合は、-f フラグも指定する必要があります。 -l フラグは、-L、-M、および -N フラグと同時に指定することはできません。
-L ワークロード・パーティション ・バックアップに関する lpp ファイル・セット情報のみを表示します。

-L フラグを指定する場合は、-f デバイス・フラグも指定する必要があります。 -l フラグは、-L、-M、および -N フラグと同時に指定することはできません。
-M バックアップに組み込まれている、書き込み可能な namefs によりマウントしたすべてのファイルシステムに関する情報をリストします。 情報は、以下の形式で表示されます。
Mount_Device Blocks   Blocks_Free   Blocks_Used   Mount_Point
Blocks および Blocks_Free フィールドは、マウント済みファイルシステム内に存在する 512 バイト・ブロックおよび空き 512 バイト・ブロックの数を示します。 Blocks_Used は、WPAR からマウントされるマウント済みファイルシステムの部分で使用されている、512 バイト・ブロックの数を示します。 -M フラグは、-l、-L、および -N フラグと同時に指定することはできません。
-N バックアップに組み込まれている、NFS によりマウントしたすべてのファイルシステムに関する情報をリストします。 情報の形式は次のとおりです。
RemoteHost HostFilesystem   Blocks   Blocks_Free   Blocks_Used
このBlocksおよびBlocks_Freeリモート・ファイルシステム内の 512 バイト・ブロックの数およびフリー 512 バイト・ブロックの数を記述します。 このBlocks_UsedWPARからマウントされたリモート・ファイルシステムの部分で使用される 512 バイト・ブロックの数を記述します。 -N フラグは、-l、-L、および -M フラグと同時に指定することはできません。
-V テープ・バックアップを検証します。

-f フラグは -V フラグと一緒に指定する必要があります。 このフラグは、磁気テープ装置の場合にのみ有効です。 -V フラグにより、ボリューム・グループ・バックアップ上の各ファイルのヘッダーの読み易さを検証し、 発生したエラーを stderr ファイルに出力します。

例

  1. デフォルト・デバイス /dev/rmt0にある ワークロード・パーティション ・バックアップの内容をリストするには、次のコマンドを使用します。
    lssavewpar
  2. デバイス /dev/cd1 上のシステム・バックアップの内容をリストするには、次のコマンドを使用します。
    lssavewpar -f /dev/cd1
  3. /dev/rmt0にある ワークロード・パーティション ・バックアップ・テープに関する、コロンで区切られた lpp 情報を表示するには、次のコマンドを使用します。
    lssavewpar -Lc -f /dev/rmt0
  4. 次の場所にあるバックアップに関するボリューム・グループおよび一般バックアップ・データをリストします。/tmp/mybackup次のコマンドを使用します。
    lssavewpar -l -f /tmp/mybackup
  5. /dev/rmt0の ワークロード・パーティション ・バックアップ・テープ上の各ヘッダーの読みやすさを検査するには、次のコマンドを使用します。
    lssavewpar -V -f /dev/rmt0
  6. デバイス /dev/usbms0 上のシステム・バックアップの内容をリストするには、次のコマンドを使用します。
    lssavewpar –f /dev/usbms0
