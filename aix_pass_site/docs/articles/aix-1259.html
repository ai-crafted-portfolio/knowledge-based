目的

パターンを C 言語の char 宣言にコンパイルします。

構文

regcmp [ - ] ファイル [ File ...]

説明

regcmp コマンドは、 File 内のパターンをコンパイルし、出力を File.i ファイルに入れます。 または、 - オプションが指定されている場合は File.c ファイル。 コンパイル結果のパターンは、char 宣言として初期化されます。 File の各エントリーは、後に 1 つまたは複数のブランクと " " (二重引用符) で囲まれたパターンが続く C 変数名でなければなりません。

regcmp コマンドの出力は、C ソース・コードです。 コンパイル結果の File.i ファイルは C プログラムに含めることができ、また、コンパイル結果の File.c ファイルは、cc コマンドへのファイル・パラメーターとして使用できます。

C 言語プログラムが regcmp コマンドの出力を使用する場合は、regex サブルーチンを使ってそれを文字列に適用しなければなりません。

たいていの場合、regcmp コマンドは C 言語プログラム内で regcmp サブルーチンを使う必要をなくすので、実行時間およびプログラム・サイズの節約になります。

フラグ

項目
説明
- 出力を File.c ファイルに配置します。 デフォルトでは、出力は File.i ファイルに配置されます。

例

  1. stdin1 内のパターンと stdin2内のパターンをコンパイルするには、次のように入力します。: 
    regcmp stdin1 stdin2
    これにより、stdin1.iおよびstdin2.iファイルのみ。
  2. 作成するにはstdin1.cおよびstdin2.c次のように入力します。
    regcmp - stdin1 stdin2
    注: 同じことを前提としています。stdin1およびstdin2両方の例でファイルが使用されています。stdin1.iおよびstdin1.cファイルは同じであり, 結果として作成されるstdin2.iおよびstdin2.cファイルは同一です。

ファイル

項目
説明
/usr/ccs/bin/regcmp regcmp コマンドが入っています。
