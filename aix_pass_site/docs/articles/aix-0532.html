目的

メッセージを転送します。

構文

forw [ + Folder ] [ -draftfolder +Folder | -nodraftfolder ] [ Message ] [ -draftmessage Message ] [ -digest Name [ -issue Number ] [ -volume Number ] ] [ -form FormFile ] [ -editor Editor | -noedit ] [ -whatnowproc Program | -nowhatnowproc ] [ -filterFile] [ -annotate [ -inplace | -noinplace ] | -noannotate ] [ -format| -noformat ] [ -help ]

説明

forw コマンドは、メッセージを転送するためのインターフェースを始動します。 デフォルトでは、forw コマンド・インターフェースは次のように機能します。

  • UserMhDirectory/draft ファイルをオープンして、 編集できるようにします。
  • /etc/mh/mhl.forward ファイルに定義されたテンプレートに従って、 転送情報を入力するよう求めるプロンプトを表示します。
  • 転送されたメッセージに付随する必要がある追加のテキストを入力するようユーザーにプロンプトを出します。

UserMhDirectory/draft ファイルの編集を終了するには、Ctrl-D シーケンスを押します。 forw コマンドは、現行フォルダーの現行メッセージを draft ファイルに追加します。 複数のメッセージを追加したい場合は、Messages パラメーターを使用します。

注: 送信時にメッセージを識別できるように、 メッセージのヘッダーと本文の間にダッシュだけの行またはブランク行を 1 行入れておく必要があります。

エディターの終了時に、forw コマンドは「What Now?」というプロンプトを始動します。 使用可能な whatnow サブコマンドのリストを表示するには、Enter キーを押します。 サブコマンドを使うと、メッセージの編集を続けたり、メッセージを表示したり、メッセージの後処理を指示したり、forw コマンドの処理を終了できます。

forw コマンドに -form フラグを指定すると、転送するメッセージのフォーマットを変更できます。 デフォルトでは、コマンドはUserMhDirectoryの/forwcompsファイルにあるデフォルトのメッセージ・フォーマットを使用します。 独自の forwcomps ファイルを定義していない場合は、/etc/mh/forwcomps ファイルが使用されます。

元のメッセージに転送情報を注釈として付けるには、-annotate フラグを使用します。 確実に注釈を付けるには、forw コマンド・インターフェースが終了する前に、転送する注釈を送信します。

注: -annotate フラグは、同じドラフトで forw コマンドを複数回実行しても保持されません。

フラグ

表 1. フラグ
項目
説明
-annotate 転送するメッセージに次の注釈を付けます。
Forwarded: Date
Forwarded: Addresses

-inplace フラグを使用して、所定の位置にアノテーションを強制します。 このフラグを使用すると、注釈付きメッセージに対するリンクが保存されます。
-digest 名前 ダイジェスト機能を使って、新しく発行する Name 変数で指定したダイジェストを作成します。 forw コマンドは、 components ファイル内のフォーマット・ストリングを ( repl コマンドで使用されるのと同じフォーマット・ストリング・メカニズムを使用して) 展開し、標準ダイジェスト・カプセル化アルゴリズムを使用してドラフトを作成します。 ドラフトの構成が終わると、forw コマンドはダイジェストのボリュームと発行のエントリーを書き出し、エディターを始動します。

-formフラグを指定しない限り、'forwコマンドはUserMhDirectoryの/digestcompsファイルのフォーマットを使用する。 このファイルが存在しない場合、コマンドは、 /etc/mh/digestcomps ファイルで指定されているデフォルトを使用します。
-draftfolder + folder 指定したフォルダーにドラフト・メッセージを入れます。 このフラグを指定しないと、forw コマンドはメッセージ・ハンドラー (MH) プロファイル内の情報に従ってデフォルトのドラフト・フォルダーを選択します。 +Folder を指定しないと、Current-Folder が使用されます。 $HOME/.mh_profile ファイルにデフォルトのデフォルト・フォルダーを定義できます。
注: -draftfolder +Folder の後に Message パラメーターが続く場合、これは -draftmessage フラグを指定するのと同じです。
-draftmessage メッセージ ドラフト・メッセージを指定します。 -draftmessage フラグを指定せずに -draftfolder を指定した場合のデフォルト・メッセージは new です。
-editor editor メッセージを作成するための初期エディターを指定します。
-filter ファイル 転送する各メッセージのフォーマットを再設定して、ドラフト・メッセージに入れます。 -filter フラグは、 mhl コマンドで使用されるフォーマットを受け入れます。
+ folder 転送するメッセージが入っているフォルダーを指定します。 フォルダーを指定しないと、Current-Folder が使用されます。
-form FormFile forw コマンド出力を、 FormFile 変数で指定された形式で表示します。 forw コマンドは、指定されたファイル内の各行をフォーマット文字列として扱います。 -digest フラグも指定されている場合、 forw コマンドは、 File 変数で指定された形式をダイジェストの形式として使用します。 -digest フラグを指定して -form フラグを指定しないと、ダイジェスト・フィルター・ファイルがフォーマットのデフォルトになります。
-format mhl コマンドとデフォルトのフォーマット・ファイルを使って、転送する各メッセージのフォーマットを再設定し、ドラフト・メッセージに入れます。 UserMhDirectory/mhl.forward ファイルがある場合は、その中にデフォルトのフォーマットが入っています。 このファイルがない場合は、 /etc/mh/mhl.forward ファイルにデフォルトのフォーマットが入っています。
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。
注: MH の場合は、このフラグ名を省略することはできません。
-inplace 強制的に適切な注釈を付けて、注釈付きメッセージとのリンクを保存します。
-issue 番号 ダイジェストの発行番号を指定します。 デフォルトのissue番号は、UserMhDirectoryの/contextファイルの'DigestName-issue-listエントリーの現在の値より1つ大きい。
Message メッセージを指定します。 複数のメッセージ、メッセージの範囲、または単一メッセージを指定できます。 メッセージの指定には、次の参照を使用します。
Number
メッセージ番号。
sequence
ユーザーが指定するメッセージ・グループ。 認識される値には以下のものが含まれます。
all
フォルダー内のすべてのメッセージ。
cur または . (ピリオド)
現行メッセージ。 これはデフォルトです。
first
フォルダー内の最初のメッセージ
last
フォルダー内の最後のメッセージ
new
作成された新しいメッセージ。
next
現行メッセージの次のメッセージ
prev
現行メッセージの直前のメッセージ

デフォルトのメッセージは、現行フォルダー内の現行メッセージです。 複数のメッセージを指定すると、転送された最初のメッセージが現行メッセージになります。 フォルダーを指定すると、指定したフォルダーが現行フォルダーになります。
-noannotate 元のメッセージに注釈を付けません。 このフラグはデフォルトです。
-nodraftfolder ドラフトを UserMhDirectory/draft ファイルに入れます。
-noedit 初期編集を抑制します。
-noformat 転送するメッセージを再フォーマットしません。 このフラグはデフォルトです。
-noinplace 適切な注釈付けを強制しません。 このフラグはデフォルトです。
-nowhatnowproc forw コマンドの対話式処理を行いません。 このフラグを指定すると、編集は行われません。
-volume 番号 ダイジェストのボリューム番号を指定します。 デフォルトのボリューム番号は、 UserMhDirectoryの/contextファイルの「DigestName「-volume-listエントリーの現在の値である。
-whatnowproc プログラム 指定されたプログラムを始動して、転送作業を補助します。
注: Programに whatnow コマンドを指定すると、 forw コマンドは、ファイル名 whatnowのプログラムではなく、内部 whatnow プロシージャーを開始します。

以下のエントリーが UserMhDirectory/.mh_profile ファイルに入力されます。

表 2. プロファイル・エントリー
項目

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. 現在のメッセージを別のユーザーに転送するには、以下のように入力します。
    forw
    システムは、ヘッダー・フィールドへの情報の入力を求めるプロンプトを表示します。 フィールドをスキップするには、 Enter キーを押します。 情報を入力してくださいTo:分野。 システムは次のように応答します。
    ---------Enter initial text
    転送されたメッセージのテキストの前に表示するテキストを入力し、Ctrl-D キー・シーケンスを押します。 転送されたメッセージのテキストが表示され、メッセージを転送するための What now? プロンプトの後に What now? Enter send というプロンプトが表示されます。
  2. inbox フォルダーから メッセージを転送するには 5 、次のように入力します。
    forw    +inbox   5
