目的

ユーザーにメッセージの着信を通知します。

構文

rcvtty [ コマンド ]

説明

rcvtty コマンドは、メールが受信されたことを示すメッセージをユーザーに送信します。 rcvtty コマンドを始動させるのは、ユーザーではありません。 rcvtty コマンドは、.maildelivery ファイルの中に置かれます。

フラグ

項目
説明
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。
注: MH の場合は、このフラグ名を省略することはできません。

ファイル

項目
説明
$HOME/ $ HOME/.mh_profile MH ユーザー・プロファイルが入っています。
