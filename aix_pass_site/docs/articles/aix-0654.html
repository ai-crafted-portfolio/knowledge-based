目的

切り離された ワークロード・パーティションでソフトウェア・インストール・タスクを実行します。

構文

/usr/sbin/inuwpar [ -d ディレクトリー | -D ] [ -G ] { -A | -f wparnamesfile | -w wparname, ...} コマンド名 [ オプション ... ]

説明

イヌワル コマンドは、すべての切り離された ワークロード・パーティション (WPAR) または指定された切り離された WPAR 上で、ソフトウェア・インストール・タスクまたは保守タスクを実行します。 切り離された ワークロード・パーティション とは、書き込み可能 /usr ファイル・システムを持つシステム ワークロード・パーティション 、またはグローバル環境と共有されない書き込み可能 /opt ファイル・システムのことです。

イヌワル コマンドは、以下の方法で指定できる ワークロード・パーティション 上で動作します。
  • -w (W) フラグによって指定される、 ワークロード・パーティション のコンマ区切りリスト。
  • 「-f」 フラグで指定されたファイル内の ワークロード・パーティション のリスト (1 行に 1 つ)。
  • すべての切り離されたシステム ワークロード・パーティション ( -A フラグを指定した場合)。
-G フラグを指定すると、inuwpar はグローバル環境でインストール・コマンドを最初に実行します。
制約事項: アプリケーションで イヌワル コマンドを実行することはできません ワークロード・パーティション。 コマンドに再配置パスが指定されていない限り、読み取り専用 /usr および /opt ファイル・システムを持つ共用システム ワークロード・パーティション で イヌワル コマンドを正常に実行することはできません。

-d 年 フラグまたは -D フラグを指定せず、 コマンド名 コマンドのオプションに -d 年 ディレクトリー オプションが含まれている場合、 イヌワル コマンドは、そのディレクトリーをコマンドのインストール・デバイスとして ワークロード・パーティション 環境にマウントしようとします。

イヌワル コマンドで使用できるすべてのインストール・コマンドについては、 パラメーター のセクションを参照してください。

フラグ

項目
説明
-A 切り離されたすべてのシステム ワークロード・パーティションにインストール・コマンドを適用します。
-d ディレクトリー インストール・ディレクトリーがアクセス可能な WPAR 内のディレクトリーを指定します。 デフォルトでは、ディレクトリーはインストール・コマンドから WPAR ファイル・システム内の一時ディレクトリーにマウントされます。 インストール・コマンドのオプションに -d directory オプションが含まれている場合、このディレクトリーがコマンドのインストール・ディレクトリーとして使用されます。
-D インストール・コマンドで使用されるディレクトリーが WPAR ファイル・システム内でアクセス可能であることを指定します。
「-f」 wparnamesfile インストール・コマンドが適用される、切り離された ワークロード・パーティション のリストを含むファイルを指定します。
-G グローバル環境および切り離されたシステム ワークロード・パーティション内でインストール・コマンドを実行します。
-w (W) WPAR 名,... インストール・コマンドが適用される 1 つ以上の切り離された ワークロード・パーティション を指定します。

パラメーター

項目
説明
コマンド名 実行するインストール・コマンドを指定します。 次のインストール・コマンドを指定できます。
  • ジェンインストール
  • install_all_updates
  • installp
  • 本能
  • update_all
オプション インストール・コマンドと一緒に使用されるオプションを指定します。

終了状況

項目
説明
0 コマンドは、該当するすべての ワークロード・パーティションで実行できました。 終了値は、すべての ワークロード・パーティション で実行されたコマンドの戻りコードが必ずしも 0 であったことを意味するものではありません。
>0 エラーが発生しました。

例

  1. グローバル環境の /mydev ディレクトリーおよび切り離されたすべての ワークロード・パーティションから、 bos.games ファイル・セットとそのすべての必須ソフトウェアをインストールするには、次のコマンドを入力します。
    inuwpar -G -A installp -qaXd /mydev bos.games
  2. グローバル環境の /mydev ディレクトリー、および /tmp/wparlist ファイルにリストされている ワークロード区画 から、 bos.games ファイル・セットとそのすべての必要条件ソフトウェアをインストールするには、次のコマンドを入力します。
    inuwpar -G -f /tmp/wparlist installp -qaXd /mydev bos.games
  3. ワークロード・パーティション wpar1 および wpar5の /マイデフ ディレクトリーから、フィックス IX38794 に関連付けられているすべてのファイル・セットをインストールするには、次のコマンドを入力します。
    inuwpar -w wpar1,wpar5 instfix -k IX38794 -d /mydev
  4. インストールされているソフトウェアを、切り離されたすべての ワークロード・パーティション内の /マイデフ ディレクトリーから最新レベルに更新するには、次のコマンドを入力します。
    inuwpar -A install_all_updates -d /mydev
