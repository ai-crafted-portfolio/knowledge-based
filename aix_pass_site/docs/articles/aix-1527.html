目的

suspendvsd - 使用可能な仮想共有ディスクを非アクティブにします。

構文

suspendvsd {-a | vsd_name...}

説明

suspendvsd コマンドは、 指定された仮想共有ディスクをアクティブ状態から延期状態に移行します。 ディスクは引き続き使用可能です。 仮想共有ディスクが活動状態の時にアクティブであった読み取りおよび書き込み要求は、 中断され保持されます。 後続の読み取りおよび書き込み操作も保持されます。 仮想共有ディスクが延期状態の場合、このコマンドは、 仮想共有ディスクを延期状態のままにします。

このコマンドは、System Management Interface Tool (SMIT) を使用して実行できます。 SMIT を使用するには、以下のように入力します。

smit vsd_mgmt

そして、「Suspend a Virtual Shared Disk (仮想共有ディスクを中断)」オプションを選択します。

通常の環境では、このコマンドを発行すべきではありません。 リカバリー可能仮想共有ディスク・サブシステムがこのコマンドを使用して、 共有ディスクを 制御された方法で管理します。 このコマンドを 発行する場合、結果は予測不能です。

フラグ

-a
アクティブ状態の仮想共有ディスクがすべて 中断されることを指定します。

パラメーター

VSAM 名
仮想共有ディスクを指定します。 仮想共有ディスクがアクティブ状態でない場合は、 エラー・メッセージが表示されます。

セキュリティー

このコマンドを実行するには、root 権限が必要です。

終了状況

0
コマンドの正常終了を示します。
nonzero
エラーが発生したことを示します。

制約事項

このコマンドは、ピア・ドメインでオンラインのノードから実行する必要があります。 オンラインのピア・ドメインに移動するには startrpdomain コマンドを使用します。 既存のピア・ドメイン内で、オンラインの特定ノードに移動するには startrpnode コマンドを使用します。 RSCT ピア・ドメインの作成と管理の詳細については、「RSCT: Administration Guide」を参照してください。

通常の環境では、このコマンドを発行すべきではありません。 リカバリー可能仮想共有ディスク・サブシステムがこのコマンドを使用して、 共有ディスクを 制御された方法で管理します。 このコマンドを 発行する場合、結果は予測不能です。

標準出力

現行の RVSD サブシステム実行レベル。

例

仮想共有ディスク vsd1vg1n1 をアクティブ状態から延期状態に移行するには、 次のように入力します。
suspendvsd vsd1vg1n1

場所

/opt/rsct/vsd/bin/suspendvsd
