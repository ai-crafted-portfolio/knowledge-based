目的

ドラフトの後処理のためのプロンプト・インターフェースを開始します。

構文

Whatnow [ {  -draftfolder +フォルダー |  -nodraftfolder | ファイル } {  -draftmessage  メッセージ |  ファイル } ] [  -エディター 編集者 |  -noedit (編集不可) ] [  -prompt ストリング ]

説明

whatnow コマンドは、メッセージの後処理用のインターフェースを提供します。 デフォルトでは、インターフェースは現行ドラフト・メッセージ上で操作されます。 whatnow コマンドを入力すると、ユーザーはこのインターフェースに入ることができ、システムは下記のプロンプトを戻します。

What now?

インターフェース内では、 whatnow サブコマンドを使用してメッセージ・ドラフトを操作することができます。 サブコマンドのリストを表示するには、次の画面で Enter キーを押します。What now?できます。 インターフェースを終了するには、q.

-draftfolder フラグが指定されていない場合、またはDraft-Folder:$HOME/.mh_profile ファイル内のエントリーが未定義の場合、 whatnow コマンドは MH ディレクトリーで draft ファイルを検索します。 -draftfolder +Folder フラグの後にメッセージを指定すると、-draftmessage フラグを指定した場合と同じになります。

whatnow コマンドのデフォルト・エディターを変更するには、 -editor フラグを使用するか、Editor:エントリをUserMhDirectory/.mh_profileファイルに追加します。

“注: comp, dist, forw, または repl コマンドは、 whatnow コマンドと同じインターフェースを使用します。”

フラグ

項目
説明
-draftfolder +フォルダー メッセージの入っているフォルダーを指定します。 デフォルトでは、システムは UserMhDirectory/draft ファイルを使用します。 -draftfolder +folder フラグの後にメッセージを指定すると、-draftmessage フラグを使用した場合と同じになります。
-draftmessage メッセージ ドラフト・メッセージを指定します。
-editor エディター editor 変数の値がメッセージの構成または改訂用の初期エディターであることを指定します。
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。

“注: MH の場合は、このフラグ名を省略することはできません。”
ファイル ユーザーが選択したドラフト・ファイル。
message メッセージを指定します。 以下の参照を使ってメッセージを指定します。
Number
メッセージ番号。
cur または 。 (ピリオド)
現行メッセージ。 これはデフォルトです。
first
フォルダー内の最初のメッセージ
last
フォルダー内の最後のメッセージ
次へ
現行メッセージの次のメッセージ
prev
現行メッセージの直前のメッセージ。
-ノドラフトフォルダー
ドラフトを UserMhDirectory/draft ファイルに入れます。
-noedit (編集しない)
初期編集を抑制します。
-prompt 文字列
指定した文字列をプロンプトとして使用します。 デフォルトのストリングは次のとおりです。What now?.

whatnow サブコマンド

whatnow サブコマンドを使用すると、メッセージの編集、メッセージの後処理の制御、または whatnow コマンドの処理の終了を行うことができます。

項目
説明
display [フラグ] 再配布または応答されるメッセージを表示します。 リスト・プログラムに有効な flags パラメーターを 指定することができます。 (以下を使用します。lproc:デフォルトのリスト・プログラムを設定するための $HOME/.mh_profile ファイル内のエントリー。) リスト・プログラムに無効なフラグを指定した場合には、whatnow コマンドはドラフトのパス名を渡しません。
編集 [commandstring] commandstring パラメーターでメッセージ用のエディターを指定します。 エディターおよびそのエディターに有効なフラグを指定することができます。 エディターを指定しない場合、 whatnow コマンドは、以下によって指定されたエディターを使用します。Editor:エントリをUserMhDirectory/.mh_profileファイルに追加します。 お客様のEditor:項目が未定義の場合、 whatnow コマンドは、直前の編集セッションで使用されたエディターを開始します。
list [フラグ] ドラフトを表示します。 リスト・プログラムに有効な flags パラメーターを 指定することができます。 (デフォルトのリスト・プログラムを指定するには、デフォルトを設定します。lproc:$HOME/.mh_profile ファイル内のエントリー。) リスト・プログラムに無効なフラグを指定した場合は、whatnow コマンドはドラフトのパス名を渡しません。
push [フラグ] バックグラウンドでメッセージを送信します。 send コマンドに有効なフラグを指定することができます。
quit [削除] whatnow セッションを終了します。 -delete フラグを指定した場合は、whatnow コマンドはドラフトを削除します。 そうしない場合は、whatnow コマンドはドラフトを保管します。
refile [flags] +フォルダー                     指定したフォルダー内にドラフトをファイルし、前に指定したフォーマットの新規ドラフトを提供します。 fileprocとして機能するコマンドに有効な任意の flags パラメーターを指定できます。 (デフォルトを設定できます。fileproc:$HOME/.mh_profile ファイル内のエントリー。)
send [フラグ] メッセージを送信します。 send コマンドに有効なフラグを指定することができます。
誰 [フラグ] メッセージの送信先のアドレスを表示します。 whom コマンドに有効なフラグを指定することができます。

プロファイル・エントリー

以下のエントリーが UserMhDirectory/.mh_profile ファイルに入力されます。

項目
説明
Draft-Folder: ドラフトを入れるデフォルトのフォルダーを設定します。
Editor: デフォルトのエディターを設定します。
fileproc: メッセージをリファイルするプログラムを指定します。
LastEditor-next: LastEditor 変数で指定したエディターの終了後に使用するエディターを指定します。
lproc: メッセージの内容をリストするのに使用するプログラムを指定します。
Path: UserMhDirectoryを指定します。
sendproc: メッセージの送信に使用するプログラムを指定します。
whomproc: メッセージの送信先となるユーザーを判別するのに使用するプログラムを指定します。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. メッセージに応答するときに元のメッセージを表示するには、以下のように入力します。What now?prompt:
    display
    システムは元のメッセージを表示します。 dist または repl コマンド以外のコマンドから display サブコマンドを入力すると、表示すべき代替メッセージがないことを示すシステム・メッセージを受け取ります。
  2. ドラフト・メッセージを編集するには、以下のようにします。viエディターで、以下を入力します。What now?prompt:
    edit vi
  3. .mh_profile ファイルに指定されているデフォルトのエディターでドラフト・メッセージを編集するには、以下のように入力します。What now?prompt:
    edit
  4. 作成したドラフト・メッセージの内容をリストするには、以下のように入力します。What now?prompt:
    list
    構成中のドラフト・メッセージが表示されます。
  5. ドラフト・メッセージをバックグラウンドで送信し、シェル・プロンプトを即時に表示するには、以下のように入力します。What now?prompt:
    push
    ドラフト・メッセージが送信され、即座にシェル・プロンプトを受け取ります。
  6. ドラフト・メッセージの作成を終了してファイルに保存し、後でメッセージの作成を終了できるようにするには、以下のように入力します。What now?prompt:
    quit
    システムは、次のようなメッセージで応答します。
    whatnow: draft left on /home/dale/Mail/draft
    この例では、ユーザーdaleのドラフト・メッセージは、 /home/dale/Mail/draft ファイルに保管されます。
  7. ドラフト・メッセージの作成を終了し、メッセージを削除するには、以下のように入力します。What now?prompt:
    quit -delete
    ドラフト・メッセージが削除されると、シェル・プロンプトが表示されます。
  8. 作成中のドラフト・メッセージを送信前にファイリングするには、以下の場所に入力します。What now?prompt:
    refile +tmp
    システムは、次のようなメッセージで応答します。
    Create folder "home/dale/Mail/tmp"?
    この例では、以下のように応答します。yes、ドラフト・メッセージはユーザーにファイリングされます。dale' s フォルダーtmp.
  9. 作成したドラフト・メッセージを送信するには、以下のように入力します。What now?prompt:
    send
    メッセージが送信されるとシェル・プロンプトが表示されます。
  10. ドラフト・メッセージ内のすべてのアドレスがメール配信システムによって認識されることを確認するには、以下のように入力します。What now?prompt:
    whom
    システムは、次のようなメッセージで応答します。
    jeanne... User unknown
dale@venus... deliverable
    この例では、メール配信システムはdale@venus正しいアドレスとして認識されませんでした。jeanne正しいアドレスとして使用できます。
