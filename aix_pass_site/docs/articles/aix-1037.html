目的

NIM リソースを更新し、NIM クライアントをカスタマイズします。

構文

nim_update_all [ -d 装置 ] [ -l lpp_source リソース ] [ -s スポット・リソース ] [ -B ] [ -u ] [ -v ] クライアント・オブジェクト

説明

nim_update_all コマンドは、NIM 環境内のインストール・リソースおよびクライアントを更新します。 さまざまなフラグを使用することによって、どの NIM リソースを更新するかを指定したり、NIM クライアントの更新機能を使用不可にしたりできます。 nim_update_all コマンドは、以下のタスクを実行して NIM 環境を更新します。
  • 環境変数 NIM_LICENSE_ACCEPT=yes をエクスポートします。
    • 更新インストール中にソフトウェア使用条件を受け入れるために使用。
  • 変数項目 NSORDER=local, bind を /etc/environmentに追加します。
    • ホストが /etc/hostにのみ存在する場合に、ネーム・レゾリューションに必要です。
  • メディアから更新レベル情報を取得します。
    • デフォルトのメディア・ロケーションは /dev/cd0です。
    • メディアの場所は、 -d フラグを使用して変更できます。
  • lpp_source、 spot、および mksysb リソースを更新します。
    • lpp_source リソース名は、 -l フラグを使用して指定できます。
    • spot リソース名は、 -s フラグを使用して指定できます。
    • mksysb リソース名は、 basic_res_grp リソース・グループに含まれる mksysb リソースから取得されます。 mksysb リソースの更新を無効にするには、 -B フラグを指定します。
  • NIM クライアントに対して update_all 操作を実行します。
    • クライアント・オブジェクトが指定されている場合、指定されたクライアントが更新されます。
    • クライアント・オブジェクトが指定されていない場合は、既存のすべての NIM クライアントが更新されます。
    • -u フラグを使用すると、クライアントは更新されません。

フラグ

項目
説明
-d 装置 このコマンドの実行中に使用する更新イメージの絶対パス・ロケーションを指定します。 デフォルトでは、 device は /dev/cd0です。
-l lpp_source リソース 更新する lpp_source resource のオブジェクト名を指定します。 デフォルトでは、リソース名は basic_res_grpから取得されます。
-s spot リソース 更新する spot resource のオブジェクト名を指定します。 デフォルトでは、リソース名は basic_res_grpから取得されます。
-B basic_res_grpに含まれているバックアップ・イメージの更新を無効にします。
-u クライアント・オブジェクトの更新機能を使用不可にします。
-v コマンド実行時の詳細デバッグ出力を有効にします。 セキュリティー

ロケーション

/usr/sbin/nim_update_all

終了状況

成功するとゼロ (0) を戻します。

セキュリティー

アクセス制御: nim_update_all コマンドを実行するには、root 権限が必要です。

例

  1. デバイス /dev/cd2にある更新イメージを使用して、basic_res_grp リソース・グループに含まれるインストール・リソース 520lpp_res (lpp_source)、 520spot_res (spot)、および master_sysb (mksysb) を更新し、NIM 環境のすべてのクライアントを更新するには、次のように入力します。
    nim_update_all -d /dev/cd2
  2. インストール・リソース lpp1 (lpp_source)、 spot1 (spot) を更新し、デバイス /dev/cd0にある更新イメージを使用して mksysb イメージの更新を使用不可にし、NIM 環境でクライアント・オブジェクト machine1 を更新するには、次のように入力します。
    nim_update_all -l lpp1 -s spot1 \
           -B machine1
  3. デバイス /dev/cd0にある更新イメージを使用して、インストール・リソース 520lpp_res (lpp_source)、 520spot_res (spot) を更新し、basic_res_grp リソース・グループに含まれる mksysb イメージの更新を無効にし、NIM 環境のクライアントの更新を無効にするには、次のように入力します。
    nim_update_all -B -u
