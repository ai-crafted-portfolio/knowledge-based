目的

システムからパッケージまたはセットを除去します。

構文

インストール済みソフトウェア・パッケージを削除するには
pkgrm [ -n] [ -a Admin] [-P Path ] [ Pkginst1 [ Pkginst2 [. . .]]]
スプール・デバイスからソフトウェア・パッケージを削除するには
pkgrm -s Spool [ Pkginst]

説明

pkgrm 以前にインストールされたパッケージまたは部分的にインストールされたパッケージまたはセットをシステムから削除します。 パッケージは、個別にインストールできる、関連するファイルおよび実行可能ファイルの集合です。 セットはセット・インストール・パッケージ (SIP) と呼ばれる特殊目的のパッケージと、 そのセットのメンバーである 1 つまたは複数のパッケージのコレクションからなります。

pkgrm は、コマンド・ラインにリストされたすべてのパッケージが システムに含まれているかどうかを検査します。 リストされているパッケージのいずれかが存在しない場合、システムに対する変更は行われません。つまり、リストされているパッケージはいずれも削除されません。

また、除去されるパッケージに他のパッケージが依存しているかどうかを判別するための検査も行われます。 依存関係が存在する場合に実行されるアクションは、 Admin ファイルで定義されます ( -a フラグを参照)。

このコマンドのデフォルト状態は対話モードです。このモードでは、 行われるアクションを管理者が確認できるように、処理中にプロンプト・メッセージが出されます。 -n フラグを使用すると、非対話式モードを要求することができます。

-s フラグを使用すると、スプールされたパッケージを除去するディレクトリーを 指定できます。

フラグ

表 1. フラグ
項目
説明
-n 非対話式モードを使用可能にします。 対話の必要がある場合には、このコマンドは終了します。 このフラグを使用するためには、コマンドを起動するときに少なくとも 1 つは パッケージ・インスタンスを指定する必要があります。
-a 管理者 デフォルトの管理ファイルの代わりに使用される、 インストール先の管理ファイル Admin を定義します。 [ Admin ファイルの形式の説明については、 admin ファイルの形式を参照してください。] "none" というトークンを指定すると、admin ファイルの使用がオーバーライドされ、 ユーザーとの対話が強制されます。 絶対パス名を指定しない限り、pkgrm は /var/sadm/install/admin ディレクトリー からファイルを探します。 デフォルトでは、そのディレクトリー内のファイル default が使用されます。
-P パス 指定されたパッケージを、代替ルート・ディレクトリー・パスから除去します。
-s スプール 指定された 1 つ以上のパッケージをディレクトリー Spoolから除去します。
プッギンスト パッケージまたはセット名の省略形を指定するために使用される短ストリングを定義します。 ( package instance という用語は大まかに使用されます。インスタンス ID が含まれていないものも含め、 Pkginstのすべてのインスタンス化を指します。)

Pkginst で SIP が指定されている場合、セットのメンバーであるすべてのインストール済みパッケージと SIP 自体が、依存関係の逆順で削除されます。

パッケージのすべてのインスタンスを示すには、「Pkginst.*」を指定し、示されているようにコマンド行を単一引用符で囲み、シェルが "*" 文字を解釈しないようにします。 ソース・メディアで使用可能なすべてのパッケージを参照するには、"all" というトークン を使用してください。
