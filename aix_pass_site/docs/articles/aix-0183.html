目的

Capacity Upgrade on Demandを管理します。

構文

chcod [ -rResourceType - nNbrResources ] [-cCustomerInfo ][ -mMailAddr ][-h ]

説明

chcod コマンドは、 Capacity Upgrade on Demand、または CUoDを管理します。 CUoDは、プロセッサーなどのResourceTypeを、最初に認可された数よりも多く認可することを可能にする。 追加リソースは、それらが利用可能で、システムがそのResourceTypeの CUoDをサポートしていれば、有効にすることができる。 一度に管理できる ResourceType は 1 つだけです。 ResourceTypes の数の変更は、 次のシステム・ブート後に有効になります。 CUoD管理には、CUoDをサポートするResourceTypeの現在の数を表示すること、システム上のResourceTypeの数を監視すること、および適切に通知することも含まれる。 通知は月ベースで行われますが、 NbrResources が変更された場合にも随時行われます。

通知は、エラー・ロギング形式ですが、オプションで電子メールが送信されます。 項目は、指定の ResourceType が変更される度に、 また月ベースでシステム・エラー・ログ内に作成されます。 エラー・ログには CustomerInfo テキストが入っています。 MailAddr で電子メール・アドレスを指定すると、MailAddr に送られた電子メール・メッセージ経由でも通知されます。 メッセージの本文には CustomerInfo テキストが入っています。 CustomerInfo と MailAddr の両方を指定すると、 エラー・ロギングと電子メールの両方で通知を受けることができます。

フラグが指定されていない場合、chcodは、CustomerInfo、MailAddr、システムのモデル名とシリアル番号、およびCUoDをサポートしているResourceTypeの NbrResourcesの現在の値を表示します。

注記： IBM p650以降のモデル（すべてのPOWER4システム）では、CUoDはHardware Management Console（HMC）で管理されます。

フラグ

項目
説明
-c CustomerInfo エラー・ログを含めるテキスト・ストリングを指定します。 この文字列は、送信された任意の電子メールの本文にも入っています。 CustomerInfo は、255 文字を超えてはなりません。 ブランクを文字列に含めることはできません。 いったん CustomerInfo が指定されると、それ以後 chcod を使用する場合に -c フラグを指定する必要はなくなりますが、それを変更するオプションはあります。 CustomerInfoは、英数字といずれかで構成される。 (ピリオド)、 、 (コンマ)、 - (ハイフン)、 ( (左括弧)、または ) (右括弧)。
-h 使用法のメッセージを表示します。
-m MailAddr 電子メールの送信先の電子メール・アドレスを指定します。 MailAddr は、255 文字を超えてはなりません。 MailAddr が "" (ブランク・ストリング) を指定してリセットされると、エラー・ロギングのみが CUoD サポートを持つリソースをモニターします。 該当する電子メール・アドレスに通知を送信してほしい場合は、 システムに電子メールを構成する必要があります。
-n NbrResources システム上で許可される ResourceTypes の数を指定します。 この数はゼロまたはそれ以上でなければなりません。 0 の場合、 CUoD は、指定された ResourceTypeに対して使用不可になります。 -n を指定する場合は、-r も指定する必要があります。
-r ResourceType システム上で使用可能にされ、モニターされる ResourceType (例えば、 プロセッサーの場合は proc) を指定します。 システムはResourceTypeの CUoDをサポートしなければならない。 -r を指定する場合は、-n も指定する必要があります。

例

  1. プロセッサーに対して CUoD を開始するには、次のように入力します。
    chcod -r proc -n 10 -m"someone@ibm.location.com" -c"Jane_Doe-Customer_Number_999999-(111)111-1111"
  2. CustomerInfo を変更するには、次のように入力します。
    chcod -c"Jane_Doe-Customer_Number_999999-(222)222-2222"
  3. 電子メール形式の通知を停止するには、次のように入力します。
    chcod -m""
  4. CUoD サポートを持つリソースの現行値を表示するには、次のように入力します。
    chcod
    以下のようなメッセージが表示されます。
    Current CustomerInfo = Jane_Doe-Customer_Number_999999-(222)222-2222
Current MailAddr = someone@ibm.location.com
Current model and serial number = IBM,7043-150 000974934C00
Current number of authorized processors = 10 of 12 installed on system
