目的

指定されたサーバーおよびユーザー項目の /etc/cifs_fs/cifscred ファイルに保管されている CIFS 資格情報を除去します。

構文

rmcifscred -h RemoteHost -u ユーザー

説明

rmcifscred コマンドは、サーバー名とユーザー名を入力として使用します。 この入力に /etc/cifs_fs/cifscredにリストされている資格情報が含まれている場合、その資格情報は削除されます。 その後は、特定のユーザーが特定のサーバーにマウントする場合、パスワードの入力が必要となります。

フラグ

項目
説明
-h RemoteHost リモート・ホスト (CIFS サーバー) の名前を指定します。 これは、ホスト名、IP アドレス、または完全修飾ドメイン名として指定することができます。
-u ユーザー 指定されたサーバーの資格情報を cifscred ファイルから削除するユーザー名を指定します。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

例

  1. server1にマウントする user1 の /etc/cifs_fs/cifscred に保管されている資格情報を削除するには、次のように入力します。
    rmcifscred -h server1 -u user1

場所

/usr/sbin/rmcifscred

ファイル

項目
説明
/etc/cifs_fs/cifscred CIFS 証明書を保管します。
