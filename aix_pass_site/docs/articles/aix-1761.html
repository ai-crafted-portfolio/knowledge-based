目的

ネットワーク・フォント・サーバーをフォント・パスに追加します。

構文

x_add_fs_fpe ホスト・ポート位置 TypeName

説明

x_add_fs_fpe コマンドは、フォント・サーバーがフォントにアクセスできるように、選択したネットワーク・タイプ名のフォント・パスにフォント・パス・エレメントを追加します。

項目
説明
Host フォント・サーバーが存在するシステムの名前を指定します。
ポート フォント・サーバー・ポートの番号を指定します。 この番号は /etc/services ファイルにある番号でなければならず、10 進数で指定します。
位置 このエレメントを挿入するフォント・パス内の位置を指定します。
TypeName ネットワーク・タイプの名前を指定します。 ネットワーク・タイプごとに、1 つ以上のフォント・パス・エレメントからなるフォント・パスがあります。 フォント・パス要素が追加されるネットワーク・タイプの名前を指定するか, あるいは次の指定によってフォント・パス要素をすべてのネットワーク・タイプ名に追加することを選択してください。Allフォント・パス・エレメントが追加された場合Allネットワーク・タイプは, 各フォント・パスの終わりに入れられます。

セキュリティー

アクセス制御 : root ユーザーだけが、このコマンドに実行 (x) アクセスできるようにしてください。

例

ネットワーク・タイプのフォント・パスの先頭にフォント・サーバーを追加するにはx_st_mgr.ether次のように入力します。

x_add_fs_fpe winter 7500 1 x_st_mgr.ether

この例では、ホスト上のフォント・サーバーwinterネットワーク・タイプのフォント・パスの先頭に追加されましたx_st_mgr.etherフォント・サーバー・ポートは次のとおりです。7500.

項目
説明

/etc/x_st_mgr/ether.cf ネットワーク・タイプ x_st_mgr.ether 構成ファイル (サンプル) が入っています。
