目的

日付を解析して再設定します。

構文

dp [ -form ファイル | -format ストリング ] [ -width 数値 ] 日付

説明

dp コマンドは、日付を解析して再設定します。 dp コマンドをユーザーが始動することはできません。 dp コマンドは他のプログラムから、その絶対パス名 (通常は、/usr/lib/mh/dp) で呼び出されます。

dp コマンドは、日付として指定された個々のメールのヘッダー文字列を解析し、その文字列を再設定しようとします。 dp コマンドのデフォルトの出力フォーマットは ARPA RFC 822 標準です。 解析できない個々の文字列に対して、dp コマンドはエラー・メッセージを表示します。

パラメーター

項目
説明
Date 解析される日付を指定します。

フラグ

項目
説明
-form ファイル Date パラメーターで指定されたデータを、File 変数によって記述された代替表示方法に再設定します。
-format ストリング Date パラメーターで指定されたデータを、String 変数によって記述された代替表示方法に再設定します。 デフォルトのフォーマット文字列は次のとおりです。
%<(nodate{text})error:%{text}%|%(putstr(pretty{text}))%>
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。

“注: メッセージ・ハンドラー (MH) の場合、このフラグ名は完全な形で指定しなければなりません。”
-width 数値 日付とエラー・メッセージを表示するのに dp コマンドが使用する桁の最大数を設定します。 デフォルトはディスプレイの幅です。

ファイル

項目
説明
HOME/.mh_profile MH ユーザー・プロファイルが入っています。
/etc/mh/mtsta担当者 MH コマンド定義が入っています。
