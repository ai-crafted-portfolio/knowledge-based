目的

外部システムからドメイン・ネーム・サーバー・キー (DNSKEY) レコードをインポートして、レコードを管理できるようにします。

構文

dnssec-importkey [-K ディレクトリー] [-L ttl] [-P date/offset] [-P sync date/offset] [-D date/offset] [-D sync date/offset] [-h] [-v level] [-V] {鍵ファイル}

dnssec-importkey {-f filename} [-K ディレクトリー] [-L ttl] [-P date/offset] [-P sync date/offset] [-D date/offset] [-D sync date/] [-h] [-v レベル] [-V] [dnsname]

説明

dnssec-importkey コマンドは、公開 DNSKEY レコードを読み取り、 .key/.private ファイルのペアを生成します。 DNSKEYレコードは既存の'.keyファイルから読み込まれ、その場合、対応する'.privateファイルが生成される。 他のファイルから読み込んだり、標準入力から読み込んだりすることもできるが、その場合は「.key」と「.private両方のファイルが生成される。

新しい .private ファイルには秘密鍵データが含まれていないため、署名には使用できません。 しかし、'.privateファイルを使えば、キーの公開時間（-Pフラグ）と削除時間（-Dフラグ）を設定することができる。 公開鍵は、真の秘密鍵がオフラインで保存されている場合でも、「DNSKEYリソース・レコード・セット（RRset）への追加と削除をスケジュール通りに行うことができる。

フラグ

-f Filename

ゾーン・ファイル・モードを示します。 filename引数には、公開鍵ファイル名ではなく、ゾーン・プライマリ・ファイルの ドメイン・ネーム・システム(DNS)名を指定することができる。 ドメイン・ネームが filenameと同じ場合は、引数を省略できます。

filename が -に設定されている場合、ゾーン・データは標準入力から読み取られます。

-h

使用法メッセージを表示して終了します。

-K ディレクトリー

キー・ファイルを置くディレクトリを設定する。

-L トル

.keyファイルが 'DNSKEY RRset ファイルに追加されたときに使用されるデフォルトの TTL (time-to-live) を設定する。 この TTL は、鍵がゾーンにインポートされるときに使用されます。 DNSKEY RRset存在する場合、既存のTTLが優先される。 デフォルトのTTLを'0または'noneに設定した場合、TTLは'.keyファイルから削除される。

-V

バージョン情報を印刷します。

-v レベル

デバッグのレベルを設定します。

タイミング・フラグ

日付は、'YYYYMMDD、'YYYYMMDDHHMMSS（キーファイルの中で使われる形式）、'Day Mon DD HH:MM:SS YYYY（'dnssec-settime -pコマンドで表示される形式）、UNIXエポックタイム（'dnssec-settime -upコマンドで表示される形式）、またはリテラル'nowで表すことができます。

引数が'+(プラス)または'-(マイナス)で始まる場合、現在時刻からのオフセットとして解釈される。 オフセットの後に接尾辞「y、「mo、「w、「d、「h、「miいずれかが続く場合、オフセットは、年（うるう年を無視し、365日の24時間として定義される）、月（30日の24時間として定義される）、週、日、時、分の単位で計算される。 接尾部がない場合、オフセットは秒単位で計算されます。 明示的に日付が設定されないようにするには、'none、'never、または'unsetを使用する。 以下の書式はすべて大文字と小文字を区別しない：

-D 日付/オフセット
鍵を削除する必要がある日付を設定します。 その日付を過ぎると、キーはゾーンに含まれなくなります。 しかし、キーリポジトリには残るかもしれない。
-D sync 日付/オフセット
秘密鍵と一致する CDS および CDNSKEY レコードを削除する必要がある日付を設定します。
-P 日付/オフセット
鍵をゾーンに公開する必要がある日付を設定します。 その日付を過ぎると、キーはゾーンに組み込まれますが、ゾーンの署名には使用されません。
-P sync 日付/オフセット
秘密鍵と一致する CDS および CDNSKEY レコードをゾーンに公開する必要がある日付を設定します。

ファイル

鍵ファイルは、「dnssec-keygenコマンドによって生成される鍵識別名「Knnnn.+aaa+iiiiiまたは完全なファイル名「Knnnn.+aaa+iiiii.key定義される。
