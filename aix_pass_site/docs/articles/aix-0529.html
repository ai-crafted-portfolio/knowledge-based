目的

ピア・ドメインを強制的にオフラインにします。

構文

forcerpoffline [-h] ドメイン名

説明

重要: このコマンドは、細心の注意を払って使用してください。

forcerpoffline コマンドは、ノードがオンライン保留状態にあり、 startrpdomain コマンドを使用してオンラインにすることができない場合にのみ使用する必要があります。 このシナリオは、ドメインがクォーラムで動作している場合にノードをオンラインにしようとすると発生する可能性があります。 ノードがオンライン保留状態のままになっている理由が不明な場合は、 forcerpoffline コマンドを使用する前に ctsnap コマンドを実行してください。 forcerpoffline コマンドを実行すると、構成リソース・マネージャー・サブシステム (IBM.ConfigRM) および RMC サブシステム (ctrmc) がリサイクルされます。

パラメーター

ドメイン名
オフラインにする定義済みのピア・ドメインに対して名前を指定します。

フラグ

-h
コマンドの使用方法の文を標準出力に書き込みます。

ファイル

/var/ct/cfg/current_cluster ファイルと /var/ct/cfg/default_cluster ファイルが変更されます。

標準出力

-h フラグを指定すると、このコマンド使用状況ステートメントが標準出力に書き込まれます。

終了状況

0
コマンドは正常に実行されました。
1
潜在的な RMC エラーのためコマンドが強制終了しました。
2
コマンド・スクリプト内の潜在的なエラーのためコマンドが強制終了しました。
3
ユーザーが無効なフラグを指定したためコマンドが強制終了しました。
4
ユーザーが無効なパラメーターを指定したためコマンドが強制終了しました。
5
ユーザー・エラー (存在しないドメイン名の指定など) のためコマンドが強制終了しました。

セキュリティー

このコマンドを実行するには、 root 権限が必要です。

実行の特性

このコマンドは、 Linux®、Solaris、および Windows 用の AIX® および rsct.basic-3.1.0.0-0.プラットフォーム.rpm パッケージの rsct.basic.rte ファイルセットの一部です。ここで、 プラットフォーム は i386、 ppc、 ppc64、 s390、または x86_64です。

場所

/opt/rsct/bin/forcerpoffline
