目的

2 つのファイルの内容を比較し、異なっている最初の文字を 報告します。

構文

cmp [ -l | -s ] File1 File2

説明

cmp コマンドは File1 パラメーターと File2 パラメーターにより指定されたファイルを比較して、その結果を標準出力に書き出します。 File1 または File2 パラメーターに - (負符号) を指定すると、 cmp コマンドは、そのファイルの標準入力を読み取ります。 標準入力から読み取ることができる ファイルは 1 つだけです。 デフォルトの状態で、パラメーターに指定されたファイルが同じである場合、cmp コマンドは何も表示しません。 指定したファイルに違いがある場合は、cmp コマンドは最初に違いが発生した位置で、バイトと行番号を表示します。 -l フラグを指定した場合、および一方のファイルがもう一方のファイルの初期サブシーケンスである場合 (つまり、違いを発見しないまま cmp コマンドが片方のファイルのファイル終了文字を読み取った場合) は、cmp コマンドはこのことを記録します。 通常は、cmp コマンドを使ってテキスト以外のファイルを比較 し、diff コマンドを使ってテキスト・ファイルを比較します。

フラグ

項目
説明
-l (小文字の L) 違いがあるたびに、バイト番号を 10 進で、違いのある部分のバイトを 8 進で表示します。
-s 終了値のみを返します。 0 は同一ファイル、1 は異なるファイル、2 はアクセス不能または検索不可のオプションを示します。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 2 つのファイルは同じです。
1 2 つのファイルは異なっています。 この値は、一方のファイルが他方のファイルの初期サブシーケンスである (一方のファイルが他方の最初の部分と同じ) 場合でも示されます。
>1 エラーが発生しました。

例

  1. 2 つのファイルが同一かどうかを判別するには、次のように入力します。
    cmp prog.o.bak prog.o
    これは比較します prog.o.bakおよび prog.o. ファイルが同一の場合、メッセージは表示されません。 ファイルが異なる場合は、違いのあった最初の場所が表示されます。例を以下に示します。
    prog.o.bak prog.o differ: char 4, line 1
    メッセージ・cmp: EOF on prog.o.bakの最初の部分が表示されます。prog.o次と同一であるprog.o.bakには追加のデータがあります。prog.o.
  2. 異なるバイトの各ペアを表示するには、次のように入力します。
    cmp  -l prog.o.bak prog.o
    これによって 2 つのファイルが比較され、違いがある部分のバイト番号 (10 進) と相違するバイトの内容 (8 進) が表示されます。 例えば、5 番目のバイトが 8 進数 101 の場合、prog.o.bakおよび 141prog.ocmp コマンドは、次のように表示します。
    5 101 141
  3. メッセージを書き込まずに 2 つのファイルを比較するには、次のように入力します。
    cmp  -s prog.c.bak prog.c
    これにより、以下の終了値が得られます。0ファイルが同一の場合は、値は次のようになります。1異なる場合、または以下の値2エラーが発生した場合。 このフォーマットのコマンドは通常、シェル・プロシージャー内で使われます。 次に例を示します。
    if cmp  -s prog.c.bak prog.c
    then
    echo No change
    fi
    この部分的なシェル・プロシージャーは、No change2 つのファイルが同一の場合。
