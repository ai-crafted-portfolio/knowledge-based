目的

更新された 国家情報院 マップをコピーするように ネットワーク情報サービス (国家情報院) ワーカー・サーバーにプロンプトを出します。

構文

/usr/sbin/yppush [ -v ] [ -d ドメイン ] MapName

説明

/usr/etc/yp ディレクトリーから発行される yppush コマンドは、更新された NIS マップのコピーを作成するように Network Information Services (NIS) ワーカー・サーバーにプロンプトを出します。 MapName 変数を使って、ワーカー・サーバーへ転送されるマスター・サーバーのマップを指定します。 プロンプトを出す必要があるサーバーのリストを取得するために、 プッシュ コマンドは、 ドメイン パラメーターまたは現在のデフォルト・ドメインで指定された Ypserver マップを読み取ります。 プロンプトが出されると、各ワーカー・サーバーは ypxfr コマンドを使って、マップをコピーし、自分のデータベースへ返送します。

System Management Interface Tool (SMIT) を使用して、このコマンドを実行できます。 SMIT を使用するには、次のように入力します。

smit yppush
注: システムで 国家情報院 プロトコルのバージョン 1 を使用している場合、 YpXFR コマンドは転送エージェントではありません。

フラグ

表 1. フラグ
項目
説明
-d ドメイン デフォルト・ドメイン以外のドメインを指定します。 指定したドメインのマップは、存在している必要があります。
-v 各サーバーが呼び出されるたびにメッセージを表示し、その次に、バージョン 2 プロトコルを使っている場合は、各サーバーの応答ごとにメッセージを 1 つ表示します。 このフラグが省略されると、コマンドはエラー・メッセージだけを表示します。
注: バージョン 1 の 国家情報院 プロトコルでは、メッセージは表示されません。 バージョン 1 を使用するシステムでは、yppoll コマンドを使って転送が行われたことを検査してください。

例

  1. 別のドメインからワーカー・サーバーにマップをコピーするには、次のように入力します。
    /usr/sbin/yppush -d atlantis netgroup
    この例では、 プッシュ コマンドは以下のものをコピーします。netgroupからのマップatlantisします。
  2. 各ワーカー・サーバーを呼び出す プッシュ コマンドの進行中状況を表示するには、次のように入力します。
    /usr/sbin/yppush -v -d atlantis netgroup
    この例では、 プッシュ コマンドは進行中のメッセージをコピーしながら表示します。netgroupからのマップatlantisネットワークの各ワーカー・サーバーにドメインを追加します。
