目的

timed デーモンに関する情報を戻します。

構文

timedc [ サブコマンド [ パラメーター ...]]

説明

timedc コマンドは timed デーモンの操作を制御します。 timedc コマンドは以下を実行します。

  • ネットワーク上のさまざまなマシンのクロックの差を測定します。
  • マスター・タイム・サーバーのロケーションを検索します。
  • timed デーモンが受信したメッセージのトレースを使用可能または使用不可にします。
  • デバッグ。

変数を何も指定しなければ、timedc コマンドは対話モードを想定し、標準入力からのサブコマンドを求めるプロンプトを表示します。 変数を指定すると、timedc コマンドは最初の変数をサブコマンドとして解釈し、残りの変数をサブコマンドに対するパラメーターとして解釈します。 timedc コマンドがファイルからサブコマンドを読み取ることができるように、標準入力をリダイレクトすることができます。

変数

timedc コマンドが認識するサブコマンドは以下のとおりです。

項目
説明
? [ Parameter ... ] パラメーター・リストに指定された各変数の簡単な説明を表示します。 ? サブコマンドは対話モードでのみ機能します。 変数を指定しなければ、? サブコマンドは timedc コマンドが認識するサブコマンドのリストを示します。
clockdiff ホスト ... ホスト・コンピューターのクロックと変数で指定されたコンピューターのクロックとの時間差を計算します。
選択 ホスト ... 指定されたホスト上の timed デーモンがその選択タイマーをリセットし、timed マスター・サーバーが使用可能になるように要求します。 ホストは、4 つまで指定することができます。 timed マスター・サーバーが使用できなくなっていると、指定したホスト上の timed デーモンは、新しい timed マスター・サーバーになることを要求します。

指定するホストは、-M フラグによりサブマスター・モードで timed デーモンを実行していなければなりません。
help [ パラメーター ...] パラメーター・リストに指定された各サブコマンドに関する簡単な説明を表示します。 変数を指定しなければ、help サブコマンドは timedc コマンドが認識するサブコマンドのリストを示します。
msite マスター・サイトの位置を見つけます。
quit timedc コマンドを終了します。
トレース { on | off } timed デーモンへの入力メッセージのトレースを使用可能または使用不可にします。 メッセージは /var/adm/timed.log ファイル内に保持されます。

他のコマンドを使って、timed デーモンを検査したりデバッグしたりすることができます。 これらのコマンドを見付けるには、help コマンドを使用します。

timedc コマンドを使用すると、以下のエラー・メッセージが発生することがあります。

項目
説明
Ambiguous command 省略形が複数のコマンドに一致します。
Invalid command 一致するコマンドが見つかりません。
Privileged command コマンドは root ユーザーしか実行できません。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. ローカル・ホスト間の時差を表示するには、以下のようにします。saharaおよびリモート・ホストsandy次のように入力します。
    timedc clockdiff sandy
    出力は以下のようになります。
    time on sandy.austin.century.com is 37904247 ms ahead of time on
sahara.austin.century.com
  2. timed デーモンのクライアント・ロケーションを表示するには、以下のように入力します。
    timedc msite
    出力は以下のようになります。
    client timed daemon runs on bupu.austin.century.com
