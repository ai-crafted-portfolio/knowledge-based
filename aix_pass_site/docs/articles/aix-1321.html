目的

システムの構成を変更して、実行中の NFS デーモンを停止させます。

構文

/usr/sbin/rmnfs [ -I (I) | -N (N) | -B ]

説明

rmnfs コマンドは、システムの再始動時に /etc/rc.nfs ファイルが実行されないように、 システムの現行構成を変更します。 また、コマンドに現在実行中の NFS デーモンを停止するように指示できます。

フラグ

項目
説明
-B inittab ファイル内のエントリーを除去して、現在実行中の NFS デーモンを停止します。 このフラグはデフォルトです。
-I inittab 内の、システム再始動時に NFS デーモンを始動するエントリーを除去します。
-N inittab ファイルを変更せずに即座に NFS デーモンを停止させます。

例

すべての NFS デーモンを即座に停止させるには、以下のように入力します。

rmnfs -N

このコマンドは inittab ファイルを変更しません。
