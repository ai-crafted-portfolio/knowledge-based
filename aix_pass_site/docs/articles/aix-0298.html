目的

Common Operating System Image (COSI) のクローンを作成します。

構文

CPCOSI 「-c」 コSI [-S (S) サーバー] [- 所在地] [-v (V)] コSI

説明

cpcosi コマンドは、共通オペレーティング・システム・イメージ (COSI) を複製します。 COSI は、システムが機能している状態にするために必要なすべてのソフトウェアを含むリポジトリーです。 mkcosi コマンドは COSI を作成します。

cpcosi コマンドは共通イメージを取り、その重複コピーを作成しようとします。 コピーされたバージョンは、 -l フラグで指定された場所に保管されます。 -l フラグが指定されていない場合は、元の共通イメージのロケーションが代わりに使用されます。 -S フラグが指定されている場合、クローン共通イメージはその特定のサーバーに保管されます。 -S フラグは、 cpcosi コマンドの呼び出し元によって管理されるマシンを指す必要があります。 クローンの命名規則は、 _X{count}の接尾部が付いた元の共通イメージ名です。ここで、 count は、共通イメージがクローン作成されるたびに増分される数値です。

共通イメージは、そのクローンを作成する前に、システム上に存在していなければなりません。 mkcosi コマンドを使用して、共通イメージを作成します。 lscosi コマンドは、環境内に存在するすべての共通イメージをリストします。 lscosi コマンドは、システム上に存在する bos.sysmgt.nim.master ファイルセットに依存します。

フラグ

項目
説明
-c クローンを作成する COSI を指定します。
-l ロケーション COSI を保管するロケーションへの絶対パス名を指定してください。
-S サーバー COSI イメージがあるマシンの名前を指定します。
-v cpcosi コマンドの実行時に詳細デバッグ出力を有効にします。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

セキュリティー

アクセス制御: cpcosi コマンドを実行するには、root 権限が必要です。

例

  1. cosi1 という名前の COSI から、cosi2 という名前の COSI のクローンを作成するには、次のように入力します。
    cpcosi -c cosi1 cosi2
    上記の例ではロケーション・パスが指定されていないため、 cosi1 が /export/cosi1に保管されている場合、複製された COSI は /export/cosi2に配置されます。

場所

/usr/sbin/cpcosi

ファイル

項目
説明
/etc/niminfo NIM により使用される変数が入っています。
