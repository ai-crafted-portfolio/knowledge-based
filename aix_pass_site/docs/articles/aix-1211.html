目的

スプールされた印刷ジョブを保持し、解放します。

構文

qhld [ -r ] { -#JobNumber [ -PQueue ] | -PQueue | -uUser [ -PQueue ]}

説明

qhld コマンドは、印刷ジョブをスプール状態で保持します。 保持するジョブは、ジョブ番号、キュー名、またはユーザー名で指定します。 -r フラグを指定すると、印刷ジョブの保持が解除されます。

qstatus は、重複した 3 桁のジョブ番号を示して、ローカル・キューの管理を向上させるように拡張されています。 -W フラグを enq、qchk、lpstat、および lpq 状況コマンドと共に使用して、ジョブ番号の桁数をさらに多くして表示することができます。

キュー表示が重複した 3 桁のジョブ番号を示す場合は、qchk -W を使用してさらに高い精度でジョブ番号をリストしてください。 その後で特定ジョブを保持することができます。

例:qchkジョブ番号を表示する123その間に二度qchk -Wジョブ番号を表示します。1123および2123. ジョブ番号 2123 を保留したい場合は、次のように指定します。qhld -# 123により、 qdaemon は、内部リストで最初に見つかった一致するジョブ番号を保持します。1123. qstatus -W が提供する追加情報を持つことで、特定のジョブ番号を保持することができる。

フラグ

項目
説明
-#ジョブ番号 保持する印刷ジョブの番号を指定します。
-P待ち行列 保持する印刷キューを指定します。
-r 番号、キュー、またはユーザー名で印刷ジョブを解放します。
-ウーユーザー 保持する印刷ジョブが属するユーザーの名前を指定します。

セキュリティー

アテンション RBAC ユーザー: このコマンドは特権操作を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

例

  1. 印刷ジョブ番号を保留する 300次のように入力します。
    qhld -#300
  2. キューにあるすべての印刷ジョブを保留する lp0次のように入力します。
    qhld -P lp0
  3. ユーザーに属するすべてのジョブを保留する fred次のように入力します。
    qhld -u fred
  4. ジョブ番号を解放する300次のように入力します。
    qhld -#300 -r
  5. キュー上のすべてのジョブを解放します。lp0次のように入力します。
    qhld -Plp0 -r
  6. ユーザーに属するすべてのジョブを解放します。fred次のように入力します。
    qhld -u fred -r
