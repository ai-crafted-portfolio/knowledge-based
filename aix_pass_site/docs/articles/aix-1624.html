目的

三目並べゲームを開始します。

構文

ttt [ -e ] [ i ]

説明

ttt コマンドは、三目並べゲームを開始します。 このバージョンは学習をしますが、その速度は早くありません。 プログラムは、ゲームを完全にマスターするまでに、80 ゲームぐらいは負けるでしょう。 ゲームを開始すると、プロンプトが出されます。Accumulated knowledge? (Yes or No). 入力y以前のゲームから得た知識をコンピュータに提供します

ユーザーは常に X で、相手は常に O です。 最初の 1 手を打つか、パスします。 合格するには、プロンプトが出されたら Enter キーを押しますYour move?ゲームの始めにです 最初に 1 行で 3 つ取った側がゲームに勝ちます。 次に例を示します。

new game

456

この例では、ユーザーは最初に 1 の場所に X を置きました。 コンピューターは 2 の場所に O を置きました。 ゲームは、斜めの行 (1,5,9) にユーザーが 3 つ置くまで続きました。 ゲームはユーザーが止めるまで繰り返します。 ゲームを終了するには、中断キー（Ctrl-C）またはファイル終了キー（Ctrl-D）を押します。

フラグ

項目
説明
-e 学習速度を上げます。
-i ゲームの開始前に指示を表示します。

ファイル

項目
説明
$HOME/ttt.a 学習ファイルの位置を指定します。
/usr/games システムのゲームの位置を指定します。
