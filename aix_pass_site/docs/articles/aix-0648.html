目的

inusave コマンドで保管されたファイルを回復します。

構文

インウレシブ ProductName [ OptionList ]

説明

inurecv コマンドは、inusave コマンドで保管したファイルおよびアーカイブ構成要素ファイルを回復します。 このコマンドは、INUSAVEDIR 環境変数で指定されたディレクトリー内の update.list ファイルと archive.list ファイルを使用します。 inurecv コマンドは、プログラムが提供するインストール・プロシージャーまたは更新プロシージャーによって保管されたファイルを回復します。

inurecv コマンドは、拒否されたプログラムのファイルまたはクリーンアップする必要があるプログラムのファイルを回復するために、 主として installp -r コマンドと installp -C コマンドによって呼び出されます。

inurecv コマンドは、ルート、/usr、/usr/share の各ファイル・ツリーを inurecv で個別に呼び出し、 インストール可能なプログラムのすべてのファイルを回復するのに使用します。 インストールのルート、 /usr、/usr/share 部分を保管するディレクトリーは、以下のようになります。

  • /lpp/パッケージ名/ファイルセット名/V.R.M.F.save,
  • '/usr/lpp/'パッケージ名'/'ファイルセット名'/V.R.M.F.saveおよび
  • /usr/share/lpp/パッケージ名/ファイルセット名/V.R.M.F.save

それぞれ、installp コマンドによって設定している場合です。 Level は、ソフトウェア・プロダクトのレベルを表し、vv.rr.mmmm.ffff.ppppppppp のフォーマットをとります。vv はバージョン、 rr はリリース、mmmm は変更、ffff は修正、ppppppppp は修正 ID です (バージョン 3.2 イメージの場合のみ)。

パラメーター

項目
説明
OptionList ProductName ソフトウェア・プロダクト用にリカバリーされる、別個にインストール可能なオプション ( bosnet.tcp.objなど) の名前が入っているスタンザ・ファイルの絶対パス名を指定します。 OptionList ファイル内のオプション名は、1 行に 1 つずつ指定しなければなりません。
ProductName 回復対象のファイルから構成される bosnet などのインストール可能なソフトウェア・プロダクトを指定します。

環境変数

項目
説明
INUEXPAND (拡張数) 回復を実行するために必要ならファイルシステムを拡張する場合 (つまり installp コマンドに -X フラグが渡された場合)、 このフラグは installp コマンドによって 1 に設定されます。 ファイルシステムを拡張しない場合は、0 に設定されます。 この環境変数が設定されていない場合、デフォルトではファイルシステムは拡張されません。
inusave このフラグは、ファイルが保存される場合 (つまり、 -N (N) フラグが渡されなかった場合) は インストール コマンドによって 1 に設定され、それ以外の場合は 0 に設定されます。 INUSAVE (I) が 1 に設定されている場合、 Inurecv コマンドはファイルのリカバリーを試みます。 INUSAVE (I) が 0 に設定されている場合、 Inurecv はリカバリーを実行せず、戻りコード INUGOOD (I)で終了します。 その環境変数が設定されていない場合、デフォルトとしてファイルのリカバリーが試行されます。
使用中のディレクトリー ファイルの保管先のディレクトリーへの絶対パス名。 この環境変数が設定されていない場合は、/usr/lpp/ProductName/inst_updt.save というディレクトリーが使用されます。
ODMDIR (DMDIR) ソフトウェア重要プロダクト・データの保管先であるオブジェクト・データ・マネージャーのオブジェクト・リポジトリー。 この環境変数が設定されていない場合は、/etc/objrepos というデフォルトのディレクトリーが使用されます。

エラー・コード

項目
説明
INUBADC1 あるディレクトリーから別のディレクトリーへのファイルのコピーに失敗しました。
INUGOOD (I) エラー条件は発生していません。
INUNORP1 プログラムのリカバリー中に、アーカイブ・ファイル内のファイルの置換に失敗しました。
INUNOSAV (国際連合) 保管ディレクトリーが存在していません。
INUNOSVF (S) 保管ディレクトリーに保管されたファイルが見つかりません。

セキュリティー

特権制御 : このコマンドを実行できるのは、root ユーザーだけです。

RBAC ユーザーの注意: このコマンドは特権操作を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

以前に保管された snaserv プログラムのファイルをすべて回復するには、次のように入力します。

inurecv snaserv

ファイル

/lpp/パッケージ名/ファイルセット名/V.R.M.F.save
ルート・ファイル・ツリーに保管されたファイル。
/usr/lpp/パッケージ名/ファイルセット名/V.R.M.F.save
/usr ファイル・ツリーに保管されたファイル。
/usr/share/lpp/パッケージ名/ファイルセット名/V.R.M.F.save
/usr/share ファイル・ツリーに保管されたファイル。
