目的

rndc コマンドの構成ファイルを生成します。

構文

rndc-confgen[ '-a] [ '-A アルゴリズム] [ '-b キーサイズ] [ '-c キーファイル] [ '-h] [ '-k キーネーム] [ '-p ポート] [ '-q] [ '-s アドレス] [ '-t chrootdir] [ '-u ユーザー]

説明

rndc-confgen コマンドは、 rndc コマンドの構成ファイルを生成します。 このコマンドは、'rndc.confファイル、対応するコントロール、および'named.confコマンドのキー・ステートメントを手動で記述する代わりに使うことができる。 rndc-confgenコマンドに'-aフラグを付けて'rndc.keyファイルをセットアップすれば、'rndc.confファイルとコントロール・ステートメントが不要になる。

フラグ

項目
説明
-a rndcコマンドの自動設定を行う。 これは、起動時に'rndcコマンドと'namedデーモンの両方が読み込む '/etcディレクトリ（またはBINDがビルドされたときに指定された 'sysconfdirディレクトリ）に'rndc.keyファイルを作成する。 rndc.keyファイルでは、「rndcコマンドがローカルホスト上の「namedデーモン と通信するための、デフォルトのコマンドチャネルと認証キーを定義する。
-A アルゴリズム トランザクション署名 (TSIG) 鍵に使用する必要があるアルゴリズムを指定します。 以下のいずれかの値を指定できる：
  • hmac-md5
  • hmac-sha1
  • hmac-sha224
  • hmac-sha256
  • hmac-sha384
  • hmac-sha512
デフォルト値はhmac-sha256です。
-b キーサイズ 認証キーのサイズをビット単位で指定します。 キーサイズの値の範囲は1～512である。
-c キーファイル -aフラグと併用し、'rndc.keyファイル名の代替場所を指定する。
-h rndc-confgen コマンドへのオプションと引数の簡易要約を印刷します。
-k キーネーム rndcコマンド認証キーのキー名を指定する。 名前は有効なドメイン名でなければならない。 デフォルトは「rndc-keyファイルである。
-p port namedデーモンが 'rndcコマンド認証キーからの接続をリッスンする コマンドチャネルポートを指定する。 デフォルトは953である。
-q 自動設定モードで、書き込まれたパスを印刷しないようにする。
-s address namedデーモンが 'rndcコマンド認証キーからのコマンドチャネル接続をリッスンする IP アドレスを指定する。 デフォルトはループバックアドレス127.0.0.1。
-t ルートディレクトリ -a フラグと一緒に使用して、named デーモンが chrooted を実行するディレクトリーを指定します。 chrootされた'namedデーモンによって発見された、このディレクトリに相対する'rndc.keyファイルの追加コピーが書き込まれる。
-u ユーザー -a フラグ指定で使用して、生成された rndc.key ファイルの所有者を設定します。 -t フラグも指定されている場合、chroot 領域にあるファイルだけにその変更済み所有者があります。

例

  1. 人手による構成を指定せずに rndc コマンドを使用するには、以下のコマンドを入力します。
    rndc-confgen -a
  2. サンプルの rndc.conf ファイルを印刷し、対応する 制御ステートメントとキー・ステートメントが named.conf ファイルに手作業で挿入されるようにするには、以下のコマンドを実行します。
    rndc-confgen
