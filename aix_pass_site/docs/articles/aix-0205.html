目的

iSCSI ターゲット・データを変更します。

構文

chiscsi '-l AdapterName'-g'static'-t TargetName[ '-n PortNumber'-i IPaddress] [-p password] [-u username] [-T NewTargetName] [-N NewPortNumber] [-I NewIPaddress]

chiscsi'-l AdapterName'-g'auto'-t TargetName[ '-p password] [-u username] [-T NewTargetName]

説明

chiscsi コマンドは、 ODM内の iSCSI ターゲット・データを変更します。 ODM には 2 つのカテゴリーのデータが保管されています。 1つ目は、静的に設定された「iSCSIターゲットに対するもので、「AIX」がターゲットを発見するためには、関連する「iSCSIターゲットの情報（ターゲット名、IPアドレス、ポート番号など）がすべて指定されている必要がある。 iSCSI ターゲット・データの第 2 のカテゴリーは、iSCSI ターゲット・デバイス用です。自動的に構成できますが、ホストからの認証 (パスワードなど) が必要です。 これら2つのカテゴリーの iSCSI ターゲット・データは、次のように関連付けられる。 static と auto フラグで指定された -g フラグによって指定される。

フラグ

項目
説明
-g グループ この iSCSI ターゲットが関連付けられるグループを指定します。 有効なグループは、 static と autoの 2 つです。 static グループは、このホストから自動的にディスカバーできない iSCSI ターゲット用です。それらに関連するすべての iSCSI ターゲット情報 (ターゲット名、IP アドレス、ポート番号など) を指定する必要があります。 auto グループは、自動的にディスカバーされるが、パスワードなどの認証情報を必要とする iSCSI ターゲット用です。
-I NewIPaddress iSCSI ターゲットの IP アドレスが変更されている場合、新規 IP アドレスを指定します。
-i IP アドレス iSCSI ターゲットの IP アドレスを指定します。
-l AdapterName この iSCSI ターゲットに接続される iSCSI TCP/IP Offload Engine (TOE) アダプターのアダプター名を指定します。 これはまた iSCSI ソフトウェア・ソリューション・デバイス用の iSCSI プロトコル・デバイスを指定することもできます。
-N NewPortNumber iSCSI ターゲットのポート番号が変更されている場合、新規ポート番号を指定します。
-n NewPortNumber iSCSI ターゲットがアクセスされる対象のポート番号を指定します。 デフォルトのポート番号は 3260 です。
-p パスワード この iSCSI ターゲットの新規パスワードを指定します。
-T NewTargetName iSCSI ターゲット名が変更されている場合、新規ターゲット名を指定します。
-t TargetName iSCSI ターゲット名 (例えば、iqn.sn9216.iscsi-hw1) を指定します。
-u ユーザー名 CHAP 認証に使用できる新しいチャレンジ・ハンドシェーク認証プロトコル (CHAP) ユーザー名を指定します。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

セキュリティー

chiscsi コマンドは、root によってのみ実行可能です。

例

  1. 静的に構成された iSCSI ターゲットのパスワードを my passwordに変更するには、次のように入力します。
    chiscsi -l ics0 -g static -t qn.mds9216.iscsi_hw -n 3260 -i 10.1.2.116 -p "my password"
  2. 静的に構成された iSCSI ターゲットの IP アドレスを 10.1.3.141に変更するには、次のように入力します。
    chiscsi -l ics0 -g static -t qn.mds9216.iscsi_hw -n 3260 -i 10.1.2.116 -I 10.1.3.141

場所

/usr/sbin/chiscsi
