目的

メッセージを送信します。

構文

送信 [ ファイル ... | { -ドラフト | -nodraftfolder | -draftfolder +フォルダー | -draftmessage メッセージ } ] [ -別名 ファイル ] [ -format (フォーマット) | -noformat (フォーマットなし) ] [ -nomsgid | -メッセージ ID ] [ -nofilter (フィルターなし) | -フィルター ファイル ] [ -ノプシュ | -プッシュ ] [ -進む | -転送しない ] [ -noverbose | -詳細 ] [ -ノワッチ | -監視 ]

説明

send コマンドは、メール送信システムを通してメッセージを送ります。 送信が失敗すると、send コマンドはエラー・メッセージを表示します。 デフォルトでは、From:およびDate:指定された各メッセージにフィールドが追加されます。 ただし、 $SIGNATURE 環境変数またはsignature:プロファイル項目が存在する場合、 send コマンドは送信側のアドレスをFrom:設定します。

send コマンドは、現在日付を以下の場所に入れます。Date:設定します。 dist コマンドが send コマンドを呼び出すと、 send コマンドは次のように追加します。Resent-:NONE.From:,Date:およびMessage-ID:フィールド

送信が正常に行われると、send コマンドはメッセージの名前を変更して、アクティブ状況からメッセージを除去します。 システムは現行メッセージ番号の前に , (コンマ) を付けて、メッセージの名前を変更します。 メッセージ・ハンドラー (MH) ・パッケージは非アクティブ・ファイルを使えません。 ただし、システム・コマンドは引き続き非アクティブ・ファイルを操作できます。 send コマンドを再び使用するまでは、アクティブでないファイルを取り出すことができます。

フラグ

項目
説明
-alias ファイル 検索するメール別名ファイルを指定します。 以下の MH 別名を使用するには、3 つの MH プロファイル・エントリーが必要です。
ali: -alias Aliases
send: -alias Aliases
whom: -alias Aliases

ここでAliases検索するファイルです。 デフォルトの別名ファイルは /etc/mh/MailAliases です。
-ドラフト ファイルが指定されない場合に、現行ドラフト・メッセージを使用します。 このフラグを使用せず、ファイルも指定しないと、send コマンドは現在のドラフト・メッセージを使用するかどうかをユーザーに尋ねます。
-draftfolder +フォルダー 送信されるドラフト・メッセージが入っているドラフト・フォルダーを指定します。 -draftfolder +Folder フラグのあとに Message パラメーターを付けると、-draftmessage フラグを指定するのと同じことになります。
-draftmessage メッセージ 送信するメッセージを指定します。 Message パラメーターの値として、以下のメッセージ参照のいずれか 1 つを使用できます。
Number
メッセージ番号。
cur または 。 (ピリオド)
現行メッセージ。 これはデフォルトです。
first
フォルダー内の最初のメッセージ
last
フォルダー内の最後のメッセージ
次へ
現行メッセージの次のメッセージ
prev
現行メッセージの直前のメッセージ。
-filter ファイル 指定されたファイル内のフォーマット命令を使用して、リストされている受信者に送信されるメッセージのコピーを再フォーマットします。Bcc:設定します。
- 形式 すべての宛先アドレスを、送信移送システム用に標準フォーマットにします。 このフラグはデフォルトです。
-前方 send コマンドがドラフトの送信に失敗したときに、障害メッセージをドラフト・メッセージに追加して、送信元にそのメッセージを戻します。 このフラグはデフォルトです。
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。

“注: MH の場合は、このフラグ名を省略することはできません。”
-msgid (メッセージ ID) メッセージ識別コンポーネントを追加します (例えば、次のようになります)。Message-ID:) をメッセージに追加します。
-ノドラフトフォルダー -draftfolder +Folder フラグの最後のオカレンスを取り消します。 このフラグはデフォルトです。
-フィルターなし 削除:Bcc:リストされている受信者のメッセージのヘッダー・フィールドTo:およびcc:フィールド このフラグは、次に、最小限のヘッダーを持つメッセージを、以下にリストされている受信者に送信します。Bcc:設定します。 このフラグはデフォルトです。
-ノフォーマット 宛先アドレスのフォーマットが変更されないようにします。
-ノーフォワード 送信が失敗した場合に、ドラフト・メッセージが送信者に戻されないようにします。
-ノムスギッド メッセージ識別コンポーネントが追加されないようにします。 このフラグはデフォルトです。
-ノープッシュ send コマンドをフォアグラウンドで実行します。 このフラグはデフォルトです。
-ノーヴァーボーズ sendmail コマンドへのメッセージ送信中に、情報が表示されないようにします。 このフラグはデフォルトです。
-ノウォッチ sendmail コマンドによる送信中に、情報が表示されないようにします。 このフラグはデフォルトです。
プッシュ send コマンドをバックグラウンドで実行します。 送信が失敗しても、send コマンドは端末にエラー・メッセージを表示しません。 送信に失敗したメッセージをユーザーに戻すには、-forward フラグを使用してください。
-verbose sendmail コマンドにメッセージを送信している間に情報を表示します。 この情報によって、ユーザーはメールの送信にかかわりのあるステップをモニターできます。
-監視 sendmail コマンドがメッセージを送信する間に情報を表示します。 この情報によって、ユーザーはメールの送信にかかわりのあるステップをモニターできます。

プロファイル・エントリー

以下のエントリーが UserMhDirectory/.mh_profile ファイルに入力されます。

項目
説明
Draft-Folder: ドラフトを入れるデフォルトのフォルダーを設定します。
mailproc: 障害の通知に使用するプログラムを指定します。
Path: ユーザーの MH ディレクトリーを指定します。
postproc: メッセージの通知に使用するプログラムを指定します。
Signature: メールの署名を設定します。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

$HOME/Mail/draft ファイルにあるドラフト・メッセージを送信するには、以下のように入力します。

send

システムは、次のようなメッセージで応答します。

Use "/home/david/Mail/draft"?

次のように入力したとします。yesドラフト・メッセージが送信され、シェル・プロンプトに戻ります。 この例では、$HOME ディレクトリーの名前は /home/david です。
