目的

IP Security トンネルエクスポートファイルを、IBMSecure Network Gateway でインポートできる形式に変換します。

構文

IP 変換 SNG22 | FW31 [「-f」 エクスポート・ディレクトリー]

説明

IP セキュリティーでは、 imptun コマンドを使用して IBM Secure Network Gateway 2.2 および IBM Firewall 3.1 トンネルをインポートできます。 しかし、これらのファイアウォール製品にはこの逆の機能はありません。 ipsec_convert コマンドは、エクスポートされた IP セキュリティー・トンネルを IBM ファイアウォール・トンネルに変換することにより、この機能を可能にします。 変換されたファイルは、現行ディレクトリーに置かれます。

フラグ

項目
説明
SNG22 | FW31 結果のファイルの形式が IBM Secure Network Gateway 2.2 または IBM Firewall 3.1 の形式になるかどうかを指定します。
-f エクスポートされた IPSec ファイルが置かれたディレクトリーを指定します。
