目的

HP-GL ファイルをプロッター・デバイスにプロットします。

構文

plotgbe [ -fr=X ] [ -noin ] File

説明

plotgbe コマンドは、HP-GL ファイルをプロッター・デバイスにプロットするバックエンド・プログラムです。 プロッター・デバイスは、5080 接続アダプターを介して 5085/5086 ワークステーションに接続する必要があります。 plotgbe コマンドを使用するには、plotgbe バックエンド・プログラムの印刷キューを定義しなければなりません。 enq コマンドを参照し、-o フラグを使用して、処理のためにオプションを plotgbe バックエンドに渡します。

plotgbe バックエンド・コマンドは、プロッターの初期化とプロットのスケーリングのために適切な HP-GL コマンドも生成します。 このデータがプロッターへ送信されてから、ユーザー指定の HP-GL ファイルが送信されます。 つまり、HP-GL ファイルに含まれるスケーリングや初期化のコマンドは、plotgbe バックエンド・コマンドによって作成されるコマンドを無効にします。

注: ユーザーには、印刷要求コマンドを使用して plotgbe コマンドに送信されるファイルに対する読み取り権限が必要です。

説明
-fr=X (英語) 複数フレームの図面のプロットを提供します。 このオプションにより、 X 個のフレームがプロットされます。ここで、 X は 1 から 9 までの範囲の数値です。 例えば、E サイズのロール・メディアに 20 ' の描画をプロットするには、5 つのフレームが必要になる場合があります。 つまり、オプション fr=5 が plotgbe バックエンドに渡されることになります。
-noin デフォルト値にリセットしなくても、プロッターの正面パネル設定が現在のプロットにそのまま有効であるようにします。 通常、プロッター上のプロット・ページを定義する P1 および P2 の位置は、 plotgbe コマンドによってデフォルトの位置に設定されます。 -noin 初期化なしオプションを使用して、デフォルトの位置を無効にします。

例

  1. ファイル longaxis.gl を plt プロッター・キューに送信し、ファイルの印刷に 5 つのフレームが必要であることをバックエンドに指定するには、次のように入力します。
    enq -Pplt -o -fr=5 longaxis.gl
  2. このファイルのプロット・ページ位置をデフォルトにリセットしないことを指定して、ファイル plotdata.gl を plt プロッター・キューに送信するには、次のように入力します。
    enq -Pplt -o -noin plotdata.gl
  3. ファイル twoplot.gl を plt プロッター・キューに送信し、プロット・ページの初期化を指定せず、プロッターが 2 つのフレームで図面を印刷するようにするには、次のように入力します。
    enq -Pplt -o -noin -o fr=2 twoplot.gl
