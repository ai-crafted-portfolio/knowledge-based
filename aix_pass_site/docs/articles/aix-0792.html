注：LDAP のユーザーがUID > 2 ^ 31で作成された場合、この lsldap コマンドではそれが負の数として表示されます。

目的

構成済み LDAP ディレクトリー・サーバーの命名サービス・オブジェクトを表示します。

構文

lsldap [-a] [ エンティティー [ entry_name | filter ]]

説明

この lsldap コマンドは、設定済みの LDAP ディレクトリサーバー上のネーミングサービスオブジェクトを表示します。 これは、デーモンを secldapclntd 介して LDAP サーバーにクエリを送信します。 特定のエンティティーの一部またはすべてのオブジェクトは、 lsldap コマンドによってリストすることができます。 デフォルトでは、 lsldap コマンドは、返されたオブジェクトの識別名 (DN) のみを表示します。 さらに、 -a フラグを使用して属性を表示できます。

automount エンティティーには 2 つのオブジェクト・クラスがあります。 lsldap コマンドは、 nisMap より優先順位の高い automountMap を処理します。 automountMap オブジェクトがない場合にのみ、常に automountMap オブジェクトを返し (検出された場合)、 nisMap オブジェクトを返します。

passwd および group エンティティについては、この lsldap コマンドは LDAP クライアントの設定に従って正しいオブジェクトを返します。 ただし、オブジェクト・ クラスに対応する正しい属性名を、lsldap passwd attribute=value 照会に 合うように指定する必要があります。

コマンド・ラインからエンティティー名を指定しない場合、 lsldap コマンドは、エンティティーのコンテナー項目と、これらのコンテナーの兄弟であるその他の項目を表示します。 コンテナー・エントリーをリストするには、ユーザーは root アクセス権を持っている必要があります。

entry_name パラメーターは、照会するオブジェクトの名前です。 例えば、エンティティーが passwd の場合は、entry_name はユーザー・アカウント名です。 entry_name パラメーターは、default attribute name = entry_name と同等です。 lsldap コマンドは、サブストリング検索のために entry_name 内の * ワイルドカードを受け入れます。 entry_name を指定しない場合は、すべてのエントリーが戻されます。

entry_name の代わりに、filter を指定して、特定の基準に合致するエントリーを検索することもできます。 簡易フィルターを attributename=attributevalue として指定することが できます。ここで、attributename は LDAP 属性名です。

lsldap コマンドは、結果を stdoutに出力します。 -a フラグが指定されていない場合、 lsldap は、DN の形式で検出された項目を、各 DN をブランク行で区切って印刷します。 -a フラグが指定されている場合、各エントリーは ldif 形式で出力され、エントリー間にはブランク行が入ります。

フラグ

項目
説明
-a 戻されたオブジェクトのすべての属性を表示します。 デフォルトでは、オブジェクトの DN のみが表示されます。

終了状況

正常に実行されると、 lsldap コマンドは 0を返します。 失敗すると、ゼロ以外の値が返され、以下のいずれかのエラー・メッセージが stderrに書き込まれます。

項目
説明
EIO 接続エラー。
EINVAL 無効なパラメーターです。
EPERM 操作を実行するためのアクセス権がありません。
ENOMEM メモリーが不足しています。
その他の errno その他のエラー。

セキュリティー

lsldap コマンドは、どのユーザーでも実行できます。 このコマンドは root ユーザーおよび セキュリティー・グループによって所有され、アクセス権 555 が付与されます。

特権のないユーザーが netgroup 対応 LDAP モジュールに対して lsldap –a passwd コマンドを実行した場合、lsldap コマンドは、ldap.cfg ファイル内で DisplayNetgroupUserInfo 属性が no に設定されていると、ユーザー情報を表示しません。 デフォルトでは、lsldap コマンドを実行すると、ユーザー特権に関係なく、netgroup 対応 LDAP モジュールにユーザー情報が表示されます。

root ユーザーが -a フラグを使用して passwd エンティティーをリストすると、 lsldap は検出されたユーザーのすべての属性を返します。 ただし、非特権ユーザーによって同じコマンドが実行された場合、 lsldap は、オブジェクト・クラス情報に加えて、 lsuser コマンドによって返されるのと同じ、一般的に読み取り可能な属性のみを返します。 他のすべてのエンティティーの場合、どのユーザーがこのコマンドを実行するかに関係なく、同じ出力が生成されます。

例

  1. ホスト・エンティティーのすべてのエントリーをリストするには、次のコマンドを入力します。
    lsldap hosts
    次のような情報が戻されます。
    dn: cn=myhost+ipHostNumber=192.3.193.46,ou=Hosts,cn=aixdata

 

dn: cn=starfish+ipHostNumber=192.3.193.47,ou=Hosts,cn=aixdata

 

dn: cn=loopback+ipHostNumber=127.0.0.1,ou=Hosts,cn=aixdata
  2. ホスト starfish およびそのすべての属性をリストするには、次のコマンドを入力します。
    lsldap -a hosts starfish
    次のような情報が戻されます。
    dn: cn=starfish+ipHostNumber=192.3.193.47,ou=Hosts,cn=aixdata

objectClass: top

objectClass: ipHost

objectClass: device

ipHostNumber: 192.3.193.47

cn: loopback

cn: localhost
  3. 文字 b が名前の先頭に付くユーザーをリストするには、次のコマンドを入力します。
    lsldap passwd "b*"
    次のような情報が戻されます。
    dn: uid=bin,ou=people,cn=aixdata

 

dn: uid=bob,ou=people,cn=aixdata
  4. ユーザー foo およびその属性をリストするには、次のコマンドを入力します。
    lsldap -a passwd foo
    次のような情報が戻されます。
    dn: uid=foo,ou=people,cn=aixdata

uid: foo

objectClass: account

objectClass: posixAccount

objectClass: shadowAccount

objectClass: top

cn: foo

uidNumber: 259

gidNumber: 1

homeDirectory: /home/foo

loginShell: /usr/bin/ksh

shadowlastchange: 12740

userpassword: {crypt}rNnLQ9TAD2u/k

shadowmin: 5
  5. /usr/bin/kshを実行するユーザーをリストするには、次のコマンドを入力します。
    lsldap passwd loginshell=/usr/bin/ksh
    次のような情報が戻されます。
    dn: uid=bin,ou=people,cn=aixdata

 

dn: uid=bob,ou=people,cn=aixdata

 

dn: uid=foo,ou=people,cn=aixdata

制約事項

lsldap コマンドは、 secldapclntd デーモンに依存して機能します。

ロケーション

/usr/sbin/lsldap
