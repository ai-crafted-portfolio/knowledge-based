目的

ファイルのアクセス時刻と変更時刻を更新します。

構文

touch [ -a ] [ -c ] [ -m ] [ -f ] [ -r RefFile ] [ Time | -t Time | -d date_time] { File ... | Directory ... }
注：前述の構文は、AIX®オペレーティング・システムでUNIX03モードが有効になっていない場合にのみ適用できる。

touch [-a c m f] [-r ref_file | -t time | -d date_time ] file... | Directory

注: 上記の構文は、 UNIX03 モードが有効になっている場合にのみ適用されます。 AIX オペレーティング・システムで UNIX03 モードを使用可能にするには、 XPG_SUS_ENV 環境変数の値を ONに設定する必要があります。

説明

touch コマンドは、Directory パラメーターで指定された各ディレクトリー内の、File パラメーターで指定された各ファイルのアクセス時刻と修正時刻を更新します。 Time 変数の値を指定しなければ、touch コマンドは現在の時刻を使用します。 存在しないファイルを指定すると、touch コマンドは、-c フラグを指定しない限り、ファイルを作成します。

touch コマンドからの戻りコードは、時刻を修正できなかった (存在しなかったファイル、および作成されなかったファイルを含む) ファイル数です。

-a フラグと -m フラグは、touch コマンドで指定されていないときでもアクティブです。

注:
  1. touch コマンドは、 utimenstat () サブルーチンを呼び出して、タッチされたファイルの変更時刻とアクセス時刻を変更します。 これにより、ファイルに対する書き込み許可があるにもかかわらず、実際にはファイルが存在しない場合は、フラグが使用された時点で touch コマンドが失敗することがあります。
  2. touch コマンドの使用時にエラー・メッセージを受け取った場合は、絶対パス名 /usr/bin/touch を指定しないでください。

例

  1. ファイルのアクセス時刻と変更時刻を更新するには、次のように入力します。
    touch program.c
    これにより、以下の最終アクセス時刻と最終変更時刻が設定されます。program.cファイルを現在の日時に変更します。 もしprogram.cファイルが存在しない場合、 touch コマンドはその名前の空のファイルを作成します。
  2. 新規ファイルを作成しないようにするには、次のように入力します。
    touch  -c program.c
  3. 変更時刻のみを更新するには、次のように入力します。
    touch  -m *.o
    これにより、以下で終わるファイルの最終変更時刻 (アクセス時刻ではなく) が更新されます。.o現行ディレクトリー内の拡張子。 make コマンドの結果を変更するときには、touch コマンドをこの方法でしばしば使用します。
  4. アクセス時刻と変更時刻を明示的に設定するには、次のように入力します。
    touch  -c  -t 02171425 program.c
    これにより、アクセスおよび変更の日付が 14:25 (午後 2 時 25 分 ) 現在の年の 2 月 17 日 に設定されます。
  5. 現在時刻の代わりに別のファイルのタイム・スタンプを使用するには、次のように入力します。
    touch  -r file1 program.c
    これにより、program.cタイム・スタンプと同じタイム・スタンプをファイルします。file1を適用します。
  6. 現在時刻以外の指定時刻を使用してファイルをタッチするには、次のように入力します。
    touch  -t 198503030303.55 program.c
    これにより、program.c3:03:55 a.mのタイム・スタンプをファイルします。 1985 年 3 月 3 日です
