    RACF USER/GROUP/DATASET > PERMIT WHEN¶

    WHEN(JESINPUT(name))¶

    分類: PERMIT WHEN ・ 難易度: 中級

    JES 入力元で絞る PERMIT 条件には、WHEN(JESINPUT(name)) を使います。ジョブがどの入力経路から投入されたかを条件にしたい場合に使います。ジョブ名や利用者 ID そのものの指定ではないため、JES 側の入力ソース名と RACF 側の条件を対応付けて確認します

    出典: SA23-2292 z / OS Security Server RACF Command Language Reference (zOS31_icha400.pdf) / SA23-2288 z / OS Security Server RACF Security Administrator's Guide

    ??? question "確認問題（1問）" 問題. 出力照合のセキュリティ管理に関する WHEN(JESINPUT(name))の引き継ぎです。後続担当者へ残すべき確認はどれですか。

    - A. LISTDSD DATASET('OSKBDATA') ALL の結果を残さず出力照合のセキュリティ管理の担当者名と日時のみを記録する。
- B. 別製品のメッセージを出力照合のセキュリティ管理の証跡として保存して根拠にする。
- C. WHEN(JESINPUT(name))の変更点を出力本文から切り離して出力照合のセキュリティ管理の承認欄のみ残す。
- D. 机上確認でも実出力の見出しに合わせ、出力照合の確認値として扱う。 ✅

正解: **D** ／ 難易度: 中級

**解説:** 出力照合のセキュリティ管理において選択記号 D を採用し、識別名は出力照合です。出力照合のセキュリティ管理において WHEN(JESINPUT(name)) は説明欄の「WHEN(JESINPUT(name))の状態と出力メッセージを結び付ける出力照合項目」と LISTDSD DATASET('OSKB.DATA') ALL または該当パネルの出力を照合する対象で、答え名は出力照合です。出力照合のセキュリティ管理に関する記録は、WHEN(JESINPUT(name))の出力行と ICH35001I を一緒に保存し、背景名は出力照合です。選択肢ごとの違いを示します。 A: 出力照合のセキュリティ管理は戻り値や記録番号に寄り、ICH35001I や属性表示を落とすため出力照合ではありません。 B: 出力照合のセキュリティ管理は別カテゴリの確認を流用しており、WHEN(JESINPUT(name))の根拠にならないため出力照合ではありません。 C: 出力照合のセキュリティ管理は名称や説明のみに寄り、状態を示す出力本文が不足するため出力照合ではありません。 D: 出力照合のセキュリティ管理は対象出力と項目説明を結び、根拠を残すので出力照合です。出力照合のセキュリティ管理で記録する WHEN(JESINPUT(name))は RACF の確認記録に残す対象名であり、用語名は出力照合です。

**出典:** SA23-2292 z / OS Security Server RACF Command Language Reference (zOS31_icha400.pdf) / SA23-2288 z / OS Security Server RACF Security Administrator's Guide

    WHEN(PARTNER(LU))¶

    分類: PERMIT WHEN ・ 難易度: 中級

    APPC の相手 LU で絞る PERMIT 条件には、WHEN(PARTNER(LU)) を使います。相手システムや通信先がアクセス可否に影響する設計で使います。ローカル利用者やデータセット名だけを見ても判断できないため、APPC の接続定義と LU 名を照合します

    出典: SA23-2292 z / OS Security Server RACF Command Language Reference (zOS31_icha400.pdf) / SA23-2288 z / OS Security Server RACF Security Administrator's Guide

**解説:** 範囲照合のセキュリティ管理において選択記号 C を採用し、識別名は範囲照合です。範囲照合のセキュリティ管理において WHEN(PARTNER(LU)) は説明欄の「RACF で WHEN(PARTNER(LU))の扱いを記録する範囲照合項目」と LISTDSD DATASET('OSKB.DATA') ALL または該当パネルの出力を照合する対象で、答え名は範囲照合です。範囲照合のセキュリティ管理を受け取る担当者は、WHEN(PARTNER(LU))の表示結果と ICH35001I を同じ確認単位として扱い、背景名は範囲照合です。不適切な選択肢を整理します。 A: 範囲照合のセキュリティ管理は別カテゴリの確認を流用しており、WHEN(PARTNER(LU))の根拠にならないため範囲照合ではありません。 B: 範囲照合のセキュリティ管理は戻り値や記録番号に寄り、ICH35001I や属性表示を落とすため範囲照合ではありません。 C: 範囲照合のセキュリティ管理は対象出力と項目説明を結び、根拠を残すので範囲照合です。 D: 範囲照合のセキュリティ管理は名称や説明のみに寄り、状態を示す出力本文が不足するため範囲照合ではありません。範囲照合のセキュリティ管理が示す WHEN(PARTNER(LU))は出典欄の資料で使い方を追跡できる項目であり、用語名は範囲照合です。

**解説:** 区切追跡の表示制御において選択記号 B を採用し、識別名は区切追跡です。区切追跡の表示制御において NORACF は説明欄の「区切追跡の表示制御に関係する定義値と表示行を照合する区切追跡項目」と LISTDSD DATASET('OSKB.DATA') ALL または該当パネルの出力を照合する対象で、答え名は区切追跡です。区切追跡の表示制御の証跡を読む担当者は、NORACF の属性行と ICH35001I を合わせて追跡し、背景名は区切追跡です。誤答側の問題点を分けます。 A: 区切追跡の表示制御は名称や説明のみに寄り、状態を示す出力本文が不足するため区切追跡ではありません。 B: 区切追跡の表示制御は対象出力と項目説明を結び、根拠を残すので区切追跡です。 C: 区切追跡の表示制御は戻り値や記録番号に寄り、ICH35001I や属性表示を落とすため区切追跡ではありません。 D: 区切追跡の表示制御は別カテゴリの確認を流用しており、NORACF の根拠にならないため区切追跡ではありません。区切追跡の表示制御に出る NORACF は RACF USER/GROUP/DATASET の運用手順で意味を確認する対象であり、用語名は区切追跡です。
