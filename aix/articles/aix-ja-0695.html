目的
ワークロードのダウンタイムなしに、指定されたプロセスのライブ・ライブラリ・アップデート（LLU）操作を実行します。

説明
llvupdate
コマンドは、AIX オペレーティング・システムの更新時にワークロードのダウンタイムをなくす LLU 操作を実行します。
ライブラリの更新を始める前に、プレビューモードで
llvupdate
コマンドを実行することができます。 プレビュー・モードでのコマンド出力は、プロセスで使用されているライブラリよりも新しいLLU対応ライブラリを少なくとも1つ持つLLU対応プロセスのリストを提供する。
llvupdate
コマンドは次のような場合に実行できる：
ライブアップデートの操作後。
llvupdate
コマンドを使って、ワークロードがサロゲート論理パーティション上で実行されている間に、実行中のプロセスのライブラリを更新することができます。
独立したオペレーションとして。 LLU 対応ライブラリの更新版がサービスアップデートや暫定的な修正という形で利用可能な場合、
llvupdate
コマンドを実行することで、ダウンタイムなしにライブラリを更新することができます。
注:
llvupdate
コマンドを実行できるのはrootユーザーだけです。
ライブアップデートの実行中は、
llvupdate
コマンドを個別に実行することはできません。 すべての制限についての詳細は、
LLU操作のための
llvupdate
コマンドの使用に関する制限
を参照してください。

構文
プレビュー・モード llvupdate -P -l <logfile> 実行モード llvupdate -p '<pid1> <pid2>...' [ -n <retries> ] [ -t <timeout> ] [ -l <logfile> ] llvupdate -a -l <logfile> -t <timeout> -n <retries> llvupdate -a -e '<pid1> <pid2>...' [ -n <retries> ] [ -t <timeout> ] [ -l <logfile> ]

オプション
フラグ
-h
コマンド、各種フラグ、使用可能なオプションに関するヘルプ情報を表示する。
-P
プレビューモードを指定する。
このコマンドは、システム上で実行中のすべてのプロセスをスキャンする。 システムによって現在ロードされているライブラリをチェックし、現在インストールされているライブラリと比較する。 このコマンドは、LLUに対応しているプロセスを表示し、LLU操作が進行中のプロセスも報告します。
-p
'<
pid1
> <
pid2
> ...'
指定したプロセスのライブ・ライブラリ・アップデートを開始します。
-p
フラグを使用すると、
llvupdate
コマンドは各プロセスの LLU 操作の進行状況を監視し、タイムアウト時間内に更新操作を完了しなかったプロセスについては操作を停止します。
-a
-p
フラグと同じ働きをしますが、このフラグはすべてのプロセスをスキャンし、タイムアウトポリシーに従ってすべての LLU 対応プロセスに対してライブライブラリアップデート操作を開始します。
-e
'<
pid1
> <
pid2
> ...'
-p
フラグと同じ働きをしますが、このフラグは指定されたプロセスをライブライブラリの更新操作から除外します。
-l
<
ログファイル
>
使用するログファイルを指定します。 デフォルトでは、ログファイルは
/var/adm/ras/liveupdate/logs/llvupdlog.<date.time>
です。
-n
<
リトライ
>
ライブ・ライブラリ更新操作を試行する回数を指定します。 デフォルト値は 3 です。
-t
<
タイムアウト
>
プロセス内のすべてのスレッドが、LLU操作を実行できる状態に到達するまでの時間を指定する。 このタイムアウト時間内にLLU操作が開始できなかった場合、そのプロセスの操作はキャンセルされ、10秒後に
-n
<
retries
>
フラグで指定された回数まで再試行されます。 デフォルトのタイムアウト時間は30秒である。 タイムアウトの最大値は300秒。

例
LLU 操作を開始する前に、LLU 対応プロセスと進行中の LLU 操作を識別し、特定のログ・ファイルを指定するには、次のコマンドを入力します：
llvupdate -a -t 25 -n 5 -l /tmp/foo
先の例では、
llvupdate
コマンドのログ情報は
/tmp/foo
ファイルに保存される。 デフォルトのログファイルは
/var/adm/ras/liveupdate/logs/llvupdlog
です。
特定のプロセスに対してLLU操作を実行し、タイムアウト時間を2分として再試行する回数として5を指定するには、以下のコマンドを入力する：
llvupdate -p 'p1 p2 p3' -t 120 -n 5
すべてのLLU対応プロセスに対してLLU操作を実行するには、以下のコマンドを入力する：
llvupdate -a
指定したプロセス以外のLLU対応プロセスに対してLLU操作を実行し、タイムアウト時間を2分として再試行する回数に5を指定するには、次のコマンドを入力します：
llvupdate -a -e 'p1 p2 p3' -t 120 -n 5
