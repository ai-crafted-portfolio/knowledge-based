目的
コマンドをハングアップせずに実行します。

説明
nohup
コマンドは、
Command
パラメーターおよび関連する
Arg
パラメーターで指定されたコマンドをハングアップ・シグナル (SIGHUP) をすべて無視して実行するか、
-p
オプションで指定されたプロセスを変更して SIGHUP シグナルをすべて無視するようにします。 SIGHUP は、プロセスの制御端末がクローズされたときにプロセスに送信されるシグナルです。
nohup
コマンドは、ログオフ後にバックグラウンドでプログラムを実行するために
使用することもできます。
nohup
コマンドをバックグラウンドで実行するには、コマンドの末尾に
&
(アンパーサンド) を追加します。
標準エラーが端末に表示され、標準出力が端末にも表示されず、ユーザーが指定した出力ファイル (デフォルト出力ファイルは
nohup.out
) にも送信されない場合、
./nohup.out
ファイルと
$HOME/nohup.out
ファイルの両方が作成されず、エラー・メッセージを追加するために開かれることもありません。
nohup
コマンドは、
nohup
コマンドで指定されたパラメーター・ユーティリティーを実行せず、終了状況 127 で終了します。
注:
-p
pid
オプションと
Command
オプションを一緒に指定することはできません。
-
p
pid
フラグを使用すると、指定されたプロセスの出力は
nohup.out
ファイルにリダイレクトされません。

構文
nohup { -p pid | コマンド [ Arg ...] [ & ]}

オプション
フラグ
項目 | 説明
-p PID | pid は、実行中のプロセスのプロセス ID です。 nohup コマンドは、すべてのハングアップ (SIGHUP) シグナルを無視するように、指定されたプロセスを変更します。

例
ログアウト後にコマンドをバックグラウンドで実行するには、次のように入力します。
$ nohup find / -print &
このコマンドを入力すると、次のように表示されます。
670
$ Sending output to nohup.out
プロセス ID 番号は、& (アンパーサンド) によって始動されるバックグラウンド・プロセスのプロセス ID 番号に変わります。 メッセージ
Sending output to nohup.out
find/-print
コマンドからの出力が
nohup.out
ファイルにあることを通知します。
find
コマンドがまだ実行中であっても、これらのメッセージが表示された後でログオフすることができます。
コマンドをバックグラウンドで実行し、標準出力を異なるファイルにリダイレクトするには、
次のように入力します。
$ nohup find / -print >filenames &
この例では、
find/-print
