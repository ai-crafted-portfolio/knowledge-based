目的

BNU のリモート・システムとの接続の状態を表示します。

構文

uusnap

説明

uusnap コマンドは、基本ネットワーク・ユーティリティー (BNU) の状態を示すテーブルを表示します。 テーブルには、各リモート・システムごとに以下の情報が表示されます。

項目
説明
SystemName リモート・システムの名前を示します。
Number Cmds コマンド・ファイルの数を指定します (C. * --> ファイル) がリモート・システム用にキューに入れられました。
Number Data データ転送の数を指定します (D. * (D) ファイル) がリモート・システム用にキューに入れられました。
Number Xqts リモート・コマンド実行数 (X * (*) ) を指定します。 ファイル) がリモート・システム用にキューに入れられました。
Message /var/spool/uucp/.Status/SystemName ファイルから、サイトの現在の状況メッセージを指定します。 このMessageフィールドには、BNU がリモート・システムを再試行するまでの残り時間、および BNU がシステムに到達しようとして失敗した回数 (ある場合) のカウントが含まれる場合があります。

例

BNU の状態のスナップショットを表示するには、以下のように入力します。

uusnap

このコマンドにより、以下のように出力されます。

nostromo  4 Cmds  2 Data  2 Xqts  SUCCESSFUL
zeus      2 Cmds  1 Data  2 Xqts  NO DEVICES AVAILABLE

これらの行は、4 つのコマンド・ファイル、2 つのデータ・ファイル、および 2 つの実行ファイルが現在システムのキューに入っていることを示しています。nostromo. 最後の接続先nostromoWAS SUCCESSFUL. システムへの最後の接続試行zeus一方、ローカル・システムで使用可能な装置がなかったため、成功しませんでした。

ファイル

項目
説明
/usr/bin/uusnap uusnap コマンドが入っています。
/var/spool/uucp/.Status/システム名 リモート・システムと接続する BNU の状態を記録します。
/var/spool/uucp/システム名 C. * -->を含む D. * (D), および X * (*) ウシコ デーモンによって転送されるファイル。
/var/spool/uucp/SystemName/C. * 転送されるファイルについて BNU に命令します。
/var/spool/uucp/SystemName/D. * BNU が転送するファイルが入っています。
/var/spool/uucp/ システム名 / X.* BNU が実行するリモート・コマンドが入っています。
