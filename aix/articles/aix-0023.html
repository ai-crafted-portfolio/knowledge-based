目的

システム内の各デバイスの属性の特性とその属性に指定できる値を表示します。

構文

lsattr { -D [ -O (O) ] | -E (E) [ -O (O) ] | -P [ -O (O) ] | -F (R) フォーマット [ -Z キャラクター ] } - 名前 [ -a 値 属性 ] ...[ 「-f」 ファイル ] [ -h ] [ -H ]

lsattr { -D [ -O (O) ] | -F (R) フォーマット [ -Z キャラクター ] } { [ 「-c」 クラス ] [ -s サブクラス ] [ T タイプ ] } [ -a 値 属性 ] ... [ 「-f」 ファイル ] [ -h ] [ -H ]

lsattr -R { - 名前 | [ 「-c」 クラス ] [ -s サブクラス ] [ T タイプ ] } -a 値 属性 [ 「-f」 ファイル ] [ -h ] [ -H ]

lsattr - 名前 { - 操作 [ ... ] } -F (R) フォーマット [ -Z キャラクター ] [ 「-f」 ファイル ] [ -h ] [ -H ]

lsattr { [ 「-c」 クラス ] [ -s サブクラス ] [ T タイプ ] } { - 操作 [ ... ] } -F (R) フォーマット [ -Z キャラクター ] [ 「-f」 ファイル ] [ -h ] [ -H ]

説明

lsattr コマンドは、指定されたデバイスまたはデバイス・タイプの属性についての情報を表示します。 デバイスの論理名を -l Name フラグを使用して指定しない場合は、-c Class、-s Subclass、および -t Type フラグの 1 つまたはすべての組み合わせを使用して、事前に定義されたデバイスを一意的に識別しなければなりません。

lsattr コマンドには次に示すフラグの中から 1 つを指定しなければなりません。

項目
説明
-D デフォルトの値を表示します。
-E 有効値を表示します (-l フラグで指定した、カスタマイズ・デバイスにのみ有効)。
-F フォーマット ユーザー定義のフォーマットを指定します。
-P デバイスが最後に構成されたときのデバイス値を表示します。
-R 正しい値の範囲を表示します。

カスタマイズされたデバイスの属性の有効値を表示すると、 情報はそのデバイスからではなく構成データベースから取り出されます。 -P または -T フラグを使って chdev コマンドでデータベース値を再構成していなければ、そのデータベース値は、デバイスがどのように構成されているかを反映します。 再構成が発生した場合、lsattr コマンドによって表示されている情報は、次のシステム・ブートの後になるまで、現在のデバイス構成を正確に示していない場合があります。

-D または -E フラグを使用すると、出力はデフォルトで属性の名前、 value、 descriptionの値になります。 およびユーザー設定可能ストリング ( -O フラグと一緒に使用される場合を除く)。

-P フラグは、デバイスが最後に構成されたときの、あるいは chdev コマンドを -P フラグまたは -T フラグと一緒に使用することによっていずれかの属性を変更する前の、属性値を表示します。

-O フラグは、指定されたすべての属性の名前をコロンで区切って表示します。 次の行に -O フラグは、 対応する属性値のすべてをコロンで区切って表示します。 -H フラグを -D、 -E、 -F フラグのどれかと共に使うと、 欄名の上にヘッダーを表示できます。 ユーザーは、-F Format フラグを使用して、ユーザー指定のフォーマットで出力のフォーマットを定義できます。ここで、Format パラメーターは、非英数字または空白文字で区切られ、引用符で囲まれた列名のリストです。 -F Format フラグが指定されている場合は、次のようになります。 -Z Character フラグを指定して、デフォルトのレコード分離文字を newline 文字から示されている Characterに変更することもできます。

lsattrコマンドは、Extended Predefined AttributePdAtXtd)オブジェクト・クラスの"operation "情報を表示することができる。 操作情報は -o operation フラグを経由してアクセスされます。 -o operation フラグおよび -a attribute フラグは、lsattr コマンドの同一の呼び出し内では指定できません。 -o operation フラグは、-R フラグとの併用も無効になります。 -o operation フラグを指定したときには、PdAtXtd オブジェクト・クラスからのフィールドのみが -F Format フラグで指定できます。

フラグは、コマンド・ラインで指定するか、指定した -f File フラグを使用して指定することができます。

フラグ

項目
説明
-a 属性 特定のデバイスまたはデバイス・タイプについて、 指定された属性に関する情報を表示します。 -a フラグは、 属性名ごとに 1 つ、または複数の属性名に対して 1 つ使えます。 複数の属性名に対して 1 つの -a フラグを使う場合、属性名のリストは引用符で囲み、名前の間をスペースで区切らなければなりません。 -R フラグを使用する場合は、属性名が 1 つだけの -a フラグを 1 つだけ指定する必要があります。 -a フラグも -R フラグも指定しないと、 lsattr コマンドは指定されたデバイスのすべての属性に関するすべての情報を表示します。 -a Attribute フラグは -o Operation フラグと共に使用することはできません。 フラグのこの組み合わせは、lsattr コマンドがエラー・メッセージを出して終了する原因となります。
-c クラス デバイスのクラス名を指定します。 このフラグを使うと、 出力を、指定したクラスのデバイスに制限できます。 このフラグは、 -E または -l フラグと一緒には使用できません。
-D 特定のデバイスが -O フラグと一緒に使用されない場合に、そのデバイスの属性名、デフォルト値、説明、およびユーザー設定可能フラグ値を表示します。 -D フラグを -O フラグと一緒に使用すると、属性名とデフォルト値だけがコロン・フォーマットで表示されます。 このフラグは、 -c、 -sの任意の組み合わせで使用できます。 および -t フラグは、事前定義デバイス・オブジェクト・クラスから、または -l フラグを使用して、デバイスを一意的に識別します。 このフラグは、 -E、 -Fと一緒には使用できません。 または -R フラグ。
-E 特定のデバイスが -O フラグと一緒に使用されない場合に、そのデバイスの属性名、現行値、説明、およびユーザー設定可能フラグ値を表示します。 -E フラグを -O フラグと一緒に使用すると、属性名と現行値のみがコロン形式で表示されます。 このフラグは、 -c、 -Dと一緒には使用できません。 -F、 -R、 -s、 または -t フラグ。
-f ファイル File パラメーターから必要なフラグを読み取ります。
-F フォーマット ユーザー指定のフォーマットで出力を表示します。 Format パラメーターは、 欄名を非英数字または空白文字で区切った引用符付きリストです。 セパレーターとして空白文字を使うと、 lsattr コマンドは位置合わせされた列に出力を表示します。 事前定義属性 (PdAt)、カスタマイズ属性 (CuAt)、 および拡張事前定義属性 (PdAtXtd) オブジェクト・クラスからのカラム名だけを指定できます。 カラム名のほかに、使用できる特別目的の名前が 2 つあります。名前 description を使うと属性の説明を表示でき、user_settable を使うと属性を変更できるかどうかを判別できます。 このフラグは、 -E、 -Dと一緒には使用できません。 -O、または -R フラグ。
-H 出力される列の上にヘッダーを表示します。 -O および -R フラグは、 -H フラグよりも優先されます。
-h コマンドの使用メッセージを表示します。
-l 名前 カスタマイズ・デバイス・オブジェクト・クラスにある、 属性名または属性値を表示したいデバイスの論理名を指定します。
-o 操作 特定のデバイスまたはデバイス・タイプについて、 指定された操作に関する情報を表示します。 それぞれの操作名または複数の操作名に対して 1 つの -o フラグが使用できます。

複数の操作名に対して 1 つの -o フラグを使用する場合、操作名のリストは引用符で囲み、名前の間をスペースで区切る必要があります。

ワイルドカード文字は、操作名にも使用できます。 ワイルドカード文字の有効なセットは、 odmget コマンドで使用されるセットと同じです。 特定のデバイスまたはデバイス・タイプに関連したすべての操作は、操作値 "?*" を使用して表示できます。 -o Operation フラグは、-a attribute フラグとも、-R フラグとも一緒に使用することはできません。 これらのフラグをどのように組み合わせても、lsattr コマンドがエラー・メッセージを出して終了する原因となります。
-O すべての属性名をコロンで区切って表示し、2 行目に対応するすべての属性値をコロンで区切って表示します。 属性値は、 -E フラグが指定されている場合は現行値、 -D フラグが指定されている場合はデフォルト値です。 このフラグは、 -F および -R フラグと一緒に使用することはできません。
-P 特定のデバイスが -O フラグと一緒に使用されない場合に、そのデバイスの属性名、値、説明、およびユーザー設定可能フラグ値を表示します。 表示される値は、chdev コマンドを -P フラグまたは -T フラグと共に使用することによってデバイス属性のいずれかが変更される前に、デバイス構成で使用された値です。 -P フラグを -O フラグと一緒に使用すると、 -P フラグは属性名と値だけをコロン区切り形式で表示します。 このフラグは、 -c、 -sの任意の組み合わせで使用できます。 および -t フラグは、事前定義デバイス・オブジェクト・クラスから、または -l フラグを使用して、デバイスを一意的に識別します。 このフラグは、 -D、 -Eと一緒には使用できません。 -O、または -R フラグ。
-R 属性名の正しい値を表示します。 -R フラグは、 -D, -Eと一緒には使用できません。 -F および -O フラグ ただし、 -c、 -sの任意の組み合わせで使用できます。 および -t フラグは、事前定義デバイス・オブジェクト・クラスから、または -l フラグを使用して、デバイスを一意的に識別します。 -R フラグは、 次のような属性値のリストを縦の欄で表示します。
Value1
Value2
.
.
ValueN

-R フラグは、範囲属性値を次のように表示します。x...n(+i)各項の説明は次のとおりです。x範囲の開始を指定します。n範囲の終わりであり、かつ、i増分です。
-s サブクラス デバイスのサブクラス名を指定します。 このフラグを使うと、 指定されたサブクラスのデバイスについての出力だけに限定できます。 このフラグは、 -E または -l フラグと一緒には使用できません。
-t タイプ デバイスのタイプ名を指定します。 このフラグを使うと、 指定されたクラスのデバイスについての出力だけに限定できます。 このフラグは、 -E または -l フラグと一緒には使用できません。
-Z 文字 -Z Character フラグは、 改行文字が組み込まれている場合がある ODM フィールドを処理するプログラムで使用されます。 -Z Character フラグは、 生成された出力のそれぞれのレコードまたは行のレコード分離文字を変更するために使用されます。 新規のレコード分離文字は、このフラグの Character 引数を使用して指定されます。 -Z Character フラグは、-F Format フラグが指定された場合のみ有効となります。 -Z Character フラグは、-D、-E、-O、または -R フラグと併用することはできません。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。
