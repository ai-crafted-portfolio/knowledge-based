構文
MMT [ -M (M) メディア ] [ -a 値 ] [ 「-c」 ] [ -e (E) ] [ - ] [ P- ] [ T ] [ -z ] [ -T (T) 名前 | -D 目的地 ] [ ファイル | - ]

オプション
フラグ
項目 | 説明
-M (M) メディア | 用紙上のイメージ可能領域の大きさを判別するために、用紙サイズを指定します。 Media 変数で有効な値は以下のとおりです。 A4 用紙サイズ 8.27 × 11.69 インチ (210 × 297 mm) を指定します。 A5 用紙サイズ 5.83 X 8.27 インチ (148 X 210 mm) を指定します。 B5 用紙サイズ 6.93 × 9.84 インチ (176 × 250 mm) を指定します。 EXEC 用紙サイズ 7.25 × 10.5 インチ (184.2 × 266.7 mm) を指定します。 LEGAL 用紙サイズ 8.5 X 14 インチ (215.9 X 355.6 mm) を指定します。 LETTER 用紙サイズ 8.5 X 11 インチ (215.9 X 279.4 mm) を指定します。 これはデフォルト値です。 “ 注: Media 変数では大文字と小文字は区別されません。 ”
-a | 読み取り可能な troff 出力を端末に表示します。
-c | cw コマンドで入力ファイルをプリプロセスします。
-e | eqn コマンドを呼び出します。また、 eqn コマンドに /usr/share/lib/pub/eqnchar ファイルを読み取らせます ( eqnchar ファイル・フォーマットを参照)。
-g | grap コマンドを呼び出し、次にこのコマンドが pic コマンドを呼び出します。
-p | pic コマンドを呼び出します。
-t | tbl コマンドを呼び出します。
-Z | troff コマンドの出力を処理またはリダイレクトするための出力フィルターを始動しません。
-D 目的地 | 出力を Destination 変数で指定したデバイスに送ります。 英語出力用にサポートされている宛先デバイスは 4014 で、これは tc コマンドによる Tektronix 4014 端末です。

-T 名前 | 名前 変数で指定された トロフ デバイスの出力を作成します。 出力は適切なポストプロセッサーを使用して送られます。 デフォルト値は ibm3816 です。 使用可能な Name 変数は次のとおりです。 ibm3812 3812 Pageprinter II ibm3816 3816 Pageprinter HPLJ Hewlett-Packard LaserJet II ibm5587G 5587-G01 漢字プリンター・マルチバイト言語サポート PSC PostScript。 X100 AIXwindows ディスプレイ。
- | 入力を標準入力から強制的に読み取ります。
