目的
監査レコードを読み取るためのチャネルを作成します。

説明
auditstream
コマンドは監査サブシステムの一部です。 このコマンドは、
/dev/audit
ファイル (監査デバイス) から監査レコードを読み取って、それらのレコードをバイナリー・フォーマットで標準出力にコピーします。
-c
フラグを使用して監査クラス (
/etc/security/audit/config
ファイルで定義) を指定することにより、監査レコードのサブセットを選択できます。そうしないと、現在使用可能なすべての監査クラスがコピーされます。
監査ストリーム・データは、生成された順に表示し処理できます。 例えば、コマンド出力は、監査バックエンド・コマンドへパイプを通して入力、そこでさらに処理したりファイルへリダイレクトすることができます。 バックエンド・コマンドの例としては、定義された基準に従ってデータ・レコードを選択する
auditselect
コマンドと、表示または出力用にレコードをフォーマットする
auditpr
コマンドがあります。
auditstream
コマンドは、コマンド・ラインから呼び出すか、または複数回実行できるように監査システム構成の一部として構成することができます。
auditstream
コマンドの設定については、『
セキュリティ
』の「監査の設定」および'
/etc/security/audit/config
ファイルを参照のこと。
注:
auditstream
コマンドはバックグラウンドで実行する必要があります。
AIX_AUDITBUFSZ
環境変数は、
auditstream
監査レコードのバッファー済み書き込み操作を可能にします。 バッファー済み書き込みオプションは、多数の監査レコードを生成するハイパフォーマンス・アプリケーションに役立ちます。
AIX_AUDITBUFSZ
環境変数は、8192 バイトから 67 MB の範囲の 10 進数値および 16 進数値を受け入れます。 許される値の範囲外にあるその他の正の値はいずれも、最も近い値に基づき、範囲の始めまたは範囲の終わりのどちらかに四捨五入されます。 この変数値が設定されていないか、あるいはこの変数に負の値または非数値が割り当てられている場合、
AIX_AUDITBUFSZ
変数は無視されます。

構文
auditstream [ -m ] [ -c Class ...]

オプション
フラグ
表 1. フラグ
項目 | 説明
-c class | コピーする監査クラスを指定します。 各クラスは、コンマ区切りの監査イベントのリストとして etc/security/audit/config ファイルで構成する必要があります。 デフォルト値は、現在使用可能になっているすべての監査イベントです。
-m | プロセッサー ID、ロール、および特権を各監査レコードに取り込みます。

例
監査システムの初期化時に監査データのストリーム収集を構成するには、
/etc/security/audit/config
ファイルのストリーム・スタンザに次のように追加します。
cmds = /etc/security/audit/streamcmds
次に、開始スタンザに次のように追加します。
streammode=on
次に、監査システムの初期化時に実行する必要があるすべてのストリーム・コマンドを
/etc/security/audit/streamcmds
ファイルに追加します。 次に例を示します。
/usr/sbin/auditstream -c authentication | \
/usr/sbin/auditpr -v > /dev/console
/usr/sbin/auditstream | /usr/sbin/auditselect -e \
"result == FAIL_ACCESS" | \
/usr/sbin/auditpr -t 2 -v > /dev/lpr2
最初のコマンドは、確認クラスのイベントに関するすべてのレコードをフォーマットし、それらのレコードをシステム・コンソールに書き込みます。 2 番目のコマンドは、アクセス否認になったすべてのレコードをフォーマットし、それらのレコードをプリンター
/dev/lp2
で印刷します。
監査ストリーム・イベントをライン・プリンターに記録するには、次のように入力します。
/usr/sbin/auditstream | /usr/sbin/auditselect -e "event == \
USER_Login || event == USER_SU" | \
/usr/sbin/auditpr -v > /dev/lp0 &
このコマンドは、すべてのユーザー・ログイン・イベントと
su
イベントをフォーマットしてライン・プリンターに書き込みます。
ストリーム・モードで開始されたサブシステムの監査用に 520000 バイトのバッファー・サイズで監査レコードに対してバッファー済み書き込みオプションを使用するには、次のコマンドを入力します。
export AIX_AUDITBUFSZ=520000
/usr/sbin/audit start
注:
ストリーム・モードでは、監査サブシステムを開始する前に、
AI_ 翻訳不要 _AIX_AUDITBUFSZ
環境変数を設定する必要があります。
