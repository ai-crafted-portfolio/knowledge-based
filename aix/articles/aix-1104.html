目的

描画するために troff コマンドの入力のプリプロセスをします。

構文

pic [ -T 名前 ] [ - | ファイル ...]

説明

pic コマンドは、組版システムで簡単な図を描くための troff コマンド・プリプロセッサーです。 基本的なオブジェクトは、ボックス、円、楕円、直線、スプライン、矢印、弧、および Text 変数で指定したテキストです。 最高レベルのオブジェクトが、ピクチャーです。

変数名は、小文字で始まり、ゼロか複数の文字または数字が続きます。 位置名は大文字で始まり、ゼロまたは複数の文字か数字が続きます。 位置名と変数名は、1 つのピクチャーから次のピクチャーへと、その値を保存します。

リスト内のエレメントは、改行文字または; (セミコロン) で区切る必要があります。長いエレメントは、行を ¥ (バックスラッシュ) で終了することによって継続できます。 コメントは、# 文字で始め、改行文字で終了します。

定義

以下の define ステートメントは、文法の一部ではありません。

define 名前 X 置換テキスト X

「置換テキスト」 変数内の $1 や $2 などの値の出現箇所は、 Name 変数が呼び出されると、以下のように対応するオプションで置き換えられます。

名前(Option1, Option2, ...)

存在しないオプションは、ヌル・ストリングに置き換えられます。 Replacement text 変数には、改行文字が使えます。

ステートメントのコピーおよびコピー

copy ステートメントには、以下のように直後に続くファイルまたは値からのデータが含まれています。

copy File
copy thru Macro
copy File thru Macro
copy File thru Macro until String

Macro パラメーター値は、定義されたマクロの名前、または本体の一部ではない文字で囲まれたマクロの本体のいずれかにすることができます。 ファイル名を指定しないと、copy ステートメントは、次の .PE マクロ行までの入力をコピーします。

ループおよび if 文の

for ステートメントと if ステートメントは、以下のようにループと意思決定を規定します。

Variable=Expression to Expression by Expression do X anything X
if Expression then X anything X else X anything X

by と else 節は、オプションです。 if ステートメントの Expression 変数では、通常の関係演算子または String1 == (または !=) String2 ストリング・テストを使用できます。

各種情報

sh コマンドは以下のようにコマンド・ラインを実行します。

sh X Commandline X

式の値を以下のようにプロットできます。

plot Expression OptionalFormat Attributes

Expression 変数値が評価され、ストリングに変換されます (指定されている場合は、フォーマット指定を使用します)。

画像に関しては、塗りつぶしモードまたは塗りつぶしなしモードの状態が保持されます。

入力番号は E (指数) 表記で表すことができます。
