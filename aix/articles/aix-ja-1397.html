目的
指定された
ワークロード・パーティション
に属するすべてのファイルを検索してバックアップします。

説明
サヴワル
コマンドは、指定された
ワークロード・パーティション
(
WPAR
) に属するすべてのファイルを検索してバックアップします。
savewpar
コマンドは、
mkwpardata
コマンドで作成されたデータ・ファイルを使用します。 このデータ・ファイルは、以下の形式を使用した以下のディレクトリーにあります。
/tmp/wpardata/WparName/image.data
WparName
変数は、
WPAR
の名前を反映します。
サヴワル
コマンドは、このファイルを使用して、
ワークロード・パーティション
を再作成するために
レスウパー
コマンドで使用できるバックアップ・イメージを作成します。 詳しくは、
restwpar
コマンドを参照してください。
カスタマイズされた (
rootvg
は含まない) ボリューム・グループをバックアップするには、
savevg
コマンドを参照してください。
制約事項:
savewpar
コマンドは、ブート可能テープの作成には使用できません。 パフォーマンスを最高にするために、
savewpar
コマンドを実行する前に、ファイルのオープンとクローズを頻繁に行うアプリケーションを正しく終了してください。
AIX ライブ・カーネル・アップデート操作中、
savewpar
コマンドを実行してはなりません。
savewpar
コマンドは、ブート可能テープの作成には使用できません。 パフォーマンスを最高にするために、
savewpar
コマンドを実行する前に、ファイルのオープンとクローズを頻繁に行うアプリケーションを正しく終了してください。

構文
サヴワル [ -a 値 ] [ -A ] [ -B ] [ -b (B) ブロック数 ] [ -e (E) ] [ 「-f」 装置 ] [ I | -m (M) ] [ -N (N) ] [ P- ] [ -T (T) ][ -v (V) ] [ V 値 ] [ -X (X) ] [ -Z ] [ -P ] WparName

オプション
フラグ
項目 | 説明
-a | 拡張属性または NFS バージョン 4 (NFS4) アクセス制御リスト (ACL) をバックアップしません。
-A | データ管理アプリケーション・プログラミング・インターフェース (DMAPI) のファイルシステムのファイルをバックアップします。
-B | 書き込み可能な namefs-mounted ファイルシステムに存在するファイルは、バックアップしません。 デフォルトでは、書き込み可能な namefs-mounted ファイルシステムからのファイルが、バックアップに含められます。
-b ブロック | 1 回の出力操作で書き込む 512 バイト単位のブロック数を指定します。 このパラメーターを指定しなければ、 backup コマンドは、 選択した物理デバイスにデフォルト値を使用します。 値が大きくなるほど、テープ・デバイスへの物理的な転送量は大きくなります。 指定する値は、使用するデバイスの物理ブロック・サイズの倍数でなければなりません。

-e | /etc/exclude. WparName ファイルで指定されたファイルをこのコマンドによるバックアップ対象から除外します。 ヒント: 特定のファイルをバックアップから除外したい場合は、ASCII エディターを使用して /etc/exclude. WparName ファイルを作成し、 WPAR バックアップ・イメージに含めないファイル名のパターンを入力します。 このファイル内のパターンは、 grep コマンドのパターン・マッチング規則へ入力され、 バックアップから除かれるファイルを判別します。 すべてのファイルは、基本ディレクトリーから相対的にバックアップされます (ドット文字「.」のマークが付きます)。 ( WPAR の場合)。 除外するファイルやディレクトリーについて、検索文字列を文字列先頭と 一致させることが重要である場合は、検索文字列の最初に脱字記号 (^)、続いてドット文字 (.)、そして 除外するファイル名またはディレクトリーを指定します。 例えば、以下の内容をすべて除外するとします。 /tmp ディレクトリーを含む他のディレクトリーを除外しないようにしてください。 /tmp パス名の中で、除外ファイルを次のように編集します。 ^./tmp/ 除外するファイル名またはディレクトリーが他のファイル名またはディレクトリーの文字列の一部である場合は、 脱字記号 (^) とそれに続けてドット文字 (.) を使用し、検索が行の開始から始まることを示すか、ドル記号 ($) を使用して、 検索が行の終わりで終了することを示します。
-f デバイス | イメージを保管するデバイス名またはファイル名を指定します。 デフォルト値は /dev/rmt0 デバイスです。
-i | mkwpardata コマンドを呼び出すことによって、データ・ファイルを作成します。
-m | -m フラグを指定して mkwpardata コマンドを呼び出すことによって、 マップ・ファイル付きのデータ・ファイルを作成します。

-N | ワークロード・パーティション のマウント・グループ内の書き込み可能 NFSマウント・ファイルシステムからファイルをバックアップします。 デフォルトでは、コマンドは、書き込み可能 NFS マウント・ファイルシステムからファイルをバックアップしません。 要件: NFS4-mounted ファイル・システムの場合、リモート・サーバー上のファイルの所有権を適切に確立するには、ローカル・システムとリモート・システムが同じセキュリティー・ドメインに属している必要があります。 これが当てはまらない場合は、 -N フラグを使用しないでください。
-p | ファイルがバックアップされるとき、ファイルのソフトウェア・パッキングを使用不可にします。 磁気テープ・ドライブのなかには、独自のパッキングおよび圧縮アルゴリズムを使用するものもあります。
-T | スナップショットを使用することにより、バックアップを作成します。 このフラグが適用されるのは JFS2 ファイルシステムの場合のみです。 ワークロード・パーティション のバックアップを作成するためにスナップショットを使用するように -T (T) フラグを指定すると、外部 JFS2 スナップショットが作成されます。 スナップショットによって JFS2 ファイルシステムのポイント・イン・タイム・イメージが作成できるため、システムを一時的に非アクティブ状態に設定する必要はありません。 スナップショットのサイズは、ファイルシステムのサイズの 2% から 15% です。 バックアップ操作が完了すると、スナップショットの論理ボリュームは除去されます。 ただし、ファイルシステムに既に他のスナップショットがある場合は、スナップショットは除去されません。 さらに、ファイルシステムに内部スナップショットがある場合、外部スナップショットを作成できないため、ファイルシステムのバックアップの作成にスナップショットが使用されません。 -T フラグの使用は、バックアップされているボリューム・グループ内に存在する JFS ファイルシステムには影響を及ぼしません。
-v | 冗長モードを指定します。 バックアップされるとき、ファイルをリストします。
-V | テープ・バックアップを検証します。 -V フラグを指定した savewpar コマンドは、バックアップ・テープ上の各ファイル・ヘッダーを検査し、読み取りエラーが発生するとすべて報告します。

-X | /tmp ファイルシステムは、必要に応じて自動的に解凍される必要があることを指定します。 要件: -X (X) フラグは、必要に応じて、 I フラグまたは -m (M) フラグと一緒にのみ適用できます。 注: このファイル・システム拡張は、デバイス・ファイル・システムの拡張には使用されません。デバイス・ファイル・システムが同じ /tmp ファイル・システムであっても、バックアップ・イメージが保存されます。
-Z | すべてのファイル、ディレクトリー、およびファイルシステムに関する暗号化ファイルシステム (EFS) 情報をバックアップしないように指定します。 このフラグは、 -Z フラグ付きの backup コマンドを実行します。
-P | /etc/exclude_packing ディレクトリーにリストされたパッキング・オプションからファイルを除外します。

例
バックアップするには
userwpar
ワークロード・パーティション
をデフォルトの磁気テープ・ドライブ (
dev/rmt0
) に追加し、新しいテープ・ドライブを作成します。
/tmp/wpardata/userwpar/image.data
ファイルの場合は、以下のコマンドを入力します。
savewpar -i userwpar
バックアップするには
wpar2
ワークロード・パーティション
および新規マップ・ファイルの作成
/tmp/wpardata/wpar2/image.data
rmt1
装置上のファイルの場合は、次のコマンドを入力します。
savewpar -mf/dev/rmt1 wpar2
バックアップするには
wpar2
ワークロード・パーティション
。以下にリストされているファイルを除外します。
/etc/exclude.wpar2
ファイルの場合は、以下のコマンドを入力します。
savewpar -ief/dev/rmt1 wpar2
バックアップするには
my_wpar
ワークロード・パーティション
テープ・ドライブ内のテープに対して
/dev/rmt0
、ファイル・ヘッダーの読みやすさを検証するには、次のコマンドを入力します。
savewpar -f /dev/rmt0 -V my_wpar
スクラッチ・ディレクトリーの内容のすべてを除外するには、除外ファイルを以下のように編集します。
/scratch/
/tmp
ディレクトリーの内容をすべて除外し、パス名に
/tmp
が存在する、その他のディレクトリーは除外させないようにするには、除外ファイルを以下のように編集します。
^./tmp/
wpar2
ワークロード区画をバックアップし、新規ワークロード区画を作成するには、以下のようにします。
/tmp/wpardata/userwpar/image.data
ファイルを UDFS 対応装置
/dev/usbms0
に追加するには、次のコマンドを入力します。
savewpar -f /dev/usbms0 wpar2
