目的
外部ホストがプログラムにアクセスするのを制御する 3 つの別々のシステム・データベース内のエントリーを直接操作します。

説明
ruser
低水準コマンドは、3 つの独立したシステム・データベースにエントリーを追加または削除します。 操作するデータベースは、
P-
、
-
、または
「-f」
フラグを使用して決定されます。 また、
ruser
コマンドは、データベースのうちの 1 つに含まれる 1 つまたはすべてのエントリーを表示できます。 各データベースは、名前のリストになっています。 3 つのデータベースは下記のとおりです。
/etc/
ftpusers
ファイル
/etc/
hosts.equiv
ファイル
/etc/
hosts.lpd
ファイル
注:
P-
オプションと
-
オプションを一緒に使用して、同時にデータベースに名前を追加することはできますが、
「-f」
オプションを一緒に使用することはできません。
このコマンドを実行するには、System Management Interface Tool (SMIT)
smit users
高速パスを使用するか、または次のように入力することもできます。
smit rprint

構文
データベース・ファイル名項目を追加または削除するには ruser { -a | -d } { -f "UserName ..." | -p "HostName ..." | -r "HostName ..." } データベース・ファイル内のすべての名前項目を削除または表示する ruser { -X | -s } { -F | -P | -R } [ -Z ]

オプション
フラグ
項目 | 説明
-a | 名前をデータベースに追加します。 -a 値 フラグは、 P- 、 - 、または 「-f」 のいずれかのフラグと一緒に使用する必要があります。
-d | 名前をデータベースから削除します。 P- 、 - 、または 「-f」 のいずれかのフラグと一緒に使用する必要があります。
-F | /etc/ftpusers ファイル内のすべてのエントリーを削除または表示します。 すべてのエントリーを削除するには、このフラグを -X (X) フラグと一緒に使用します。 すべてのエントリーを表示するには、このフラグを -s フラグと一緒に使用します。
-f " ユーザー名... " | リモート FTP クライアントが使用できないローカル・ユーザー名のリストが入っている /etc/ftpusers データベースに、 UserName 変数で指定されたユーザー名を追加または削除します。 「-f」 フラグは、 -a 値 フラグまたは -d 年 フラグと一緒に使用する必要があります。
-P | /etc/hosts.lpd ファイル内のすべてのエントリーを削除または表示します。 すべてのエントリーを削除するには、このフラグを -X (X) フラグと一緒に使用します。 すべてのエントリーを表示するには、このフラグを -s フラグと一緒に使用します。
-p " ホスト名... " | どの外部ホストがユーザーのコンピューター上で出力できるかどうかを指定するデータベース内で、 HostName 変数で指定されたホスト名の追加または削除を行います。 P- フラグは、 -a 値 フラグまたは -d 年 フラグと一緒に使用する必要があります。
-R | /etc/hosts.equiv ファイル内のすべてのエントリーを削除または表示します。 すべてのエントリーを削除するには、このフラグを -X (X) フラグと一緒に使用します。 すべてのエントリーを表示するには、このフラグを -s フラグと一緒に使用します。
-r " ホスト名... " | マシン上でリモート・コマンド ( rlogin 、 rcp 、 rsh 、または print ) を実行できる外部ホストを指定する /etc/hosts.equiv データベースに、 HostName 変数で指定されたホスト名を追加または削除します。 - フラグは、 -a 値 フラグまたは -d 年 フラグと一緒に使用する必要があります。

-s | データベース内のすべてのエントリーを表示します。 このフラグは、 -P 、 -R 、または -F (R) のいずれかのフラグと一緒に使用します。
-X | すべての名前をデータベースから削除します。 このフラグは、 -P 、 -R 、または -F (R) のいずれかのフラグと一緒に使用します。
-Z | -s フラグは、 -Z フラグを指定した場合に必要です。 -Z フラグを指定した場合、データベースの表示の前に簡潔なタイトルが表示されます。

例
どの外部ホストがローカル・コンピューター上で印刷できるかを指定する
/etc/hosts.lpd
データベースにエントリーを追加するには、コマンドを下記のフォーマットで入力します。
ruser
-a
-p
"host1"
この例では、外部ホストは以下のようになります。
host1
.

host1
