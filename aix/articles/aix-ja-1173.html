目的
プロンプト・エディターを始動させます。

説明
メッセージ・ハンドラー (MH) パッケージの一部である
prompter
コマンドは、メッセージの入力用にプロンプト・エディターを始動させます。
prompter
コマンドは、ユーザーによって始動されません。
prompter
コマンドはほかのプログラムによってのみコールされます。
prompter
コマンドは、
File
パラメーターで指定されたファイルを開き、
To:
コンポーネントなどの空のコンポーネントをスキャンして、ブランク・フィールドに入力するようプロンプトを出します。 必須フィールドを入力せずに入力キーを押すと、
prompter
コマンドはコンポーネントを削除します。
prompter
コマンドは、ファイルの最初のブランク行またはダッシュ行の後で、メッセージ本文にテキストを受け入れます。 本文に既にテキストが含まれていて、
-noprepend
フラグが指定されている場合は、
prompter
コマンドは以下のようにテキストに続いてメッセージを表示します。
--------Enter additional text
prompter
コマンドは、既存のメッセージの後に入力された新規テキストを追加します。
-prepend
フラグを指定した場合、
prompter
コマンドは以下のようなメッセージを表示します。
--------Enter initial text
新規のテキストはどれも、元のメッセージの本文より前に来ます。 Ctrl-D キー・シーケンス (ファイル終わり) を押すと、
prompter
コマンドはテキスト入力を終了させ、コール・プログラムへ制御を戻します。

構文
prompter [ -erase Character ] [ -kill Character ] [ -prepend | -noprepend ] [ -rapid | -norapid ] File

オプション
フラグ
表 1. フラグ
項目 | 説明
-erase 文字 | 消去文字として使用される文字を設定します。 Character 変数の値は、 \NNN の形式の文字の 8 進表記にすることができます。ここで、 \NNN は数値または文字自体です。 例えば、文字 \e は 8 進表記の \145 です。
-help | これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。 注: MH の場合、このフラグの名前は完全なスペルで指定する必要があります。 .
-kill 文字 | 抹消文字または停止文字として使用される文字を設定します。 Character 変数の値は、 \NNN の形式の文字の 8 進表記にすることができます。ここで、 \NNN は数値または文字自体です。 例えば、文字 \e は 8 進表記の \145 です。
-noprepend | 既にメッセージ本文内にあるテキストの後に余分なテキストを追加します。
-norapid | 既にメッセージ本文にあるテキストを表示します。 これはデフォルトです。
-prepend | 既にメッセージ本文にあるテキストの前に追加のテキストを追加します。 これはデフォルトです。
-rapid | 既にメッセージ本文にあるテキストを表示しません。
