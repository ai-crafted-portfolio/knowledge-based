目的

ストリーム構成を変更します。

構文

モジュールをストリームにプッシュする

Strchg -h Module1 [ , Module2 ... ]

モジュールをストリームからポップする

Strchg P- [ -a 値 | -ウー モジュール ]

モジュールをプッシュおよびポップして構成ファイルを適合させる

Strchg 「-f」 ファイル

説明

strchg コマンドは、ユーザーの標準入力に関連するストリームの構成を変更するために使用されます。 strchg コマンドは、ストリームにモジュールをプッシュしたり、 ストリームからモジュールをポップしたり、またはその両方を行います。 そのストリームの構成を変更できるのは、root ユーザーまたは STREAMS デバイスのオーナーだけです。 それ以外のユーザーがその構成を変更しようとしても、strchg コマンドは成功しません。

“注: モジュールが誤った順序でプッシュされると、ストリームが予期したとおりに機能しない場合があります。”

フラグ

項目
説明
-a 一番上のドライバーより上にあるすべてのモジュールをストリームからポップします。 -p フラグは、-a フラグの前に指定しなければなりません。
-f ファイル 指定したファイルで与えられた構成にストリームを準拠させるために、必要なモジュールをプッシュしたり、ポップしたりします。

-h、-p、-f フラグは、同時に使用できません。
-h Module1 ストリームにモジュールをプッシュします。 プッシュされる順序でコマンド・ラインにモジュールをリストします。
-p ストリームからモジュールをポップします。 このフラグだけを使用すると、-p フラグはストリームの一番上にあるモジュールをポップします。
-ウー モジュール 指定されたモジュールより上にあるすべてのモジュールをストリームからポップします。 -p フラグは、-u フラグの前に指定しなければなりません。

-a および -u フラグは同時には指定できません。

パラメーター

項目
説明
Module1 ストリームにプッシュするモジュールを指定します。 ( -h フラグによって使用されます。)
モジュール ストリーム上に残る一番上のモジュールを指定します。 このモジュールの上にあるすべてのモジュールは、ストリームからポップされます。 ( -ウー フラグによって使用されます。)
File ストリームの希望する構成を示すモジュールのリストが入っています。 各モジュール名は、別々の行に記述しなければなりません。 この場合、最初の名前が一番上のモジュールを表し、最後の名前がドライバーに一番近いモジュールを表します。

戻り値

正常終了すると、 Strchg コマンドは値 0 を戻します。 それ以外の場合は、ゼロ以外の値を返し、使用法エラー、不正なモジュール名、プッシュするモジュールが多すぎる、ストリームでの Ioctl 操作の失敗、または ファイル パラメーターで指定されたファイルのオープンの失敗を示すエラー・メッセージを出力します。

例

  1. プッシュするには、ldtermストリーム上のモジュールに対して、次のように入力します
    strchg -h ldterm
  2. 以下に関連付けられたストリームから最上位のモジュールをポップします。/dev/term/24以下のように入力します。
    strchg -p < /dev/term/24
    この場合、ユーザーはこのデバイスのオーナーか、root ユーザーでなければなりません。
  3. 以下の場合:fileconfファイルには以下が含まれます。
    compat
ldterm
ptem
    以下のコマンドは、以下のようにストリームを構成します。ptemモジュールがドライバーの上にプッシュされ, その後に,ldtermモジュール、およびcompatモジュールはストリーム・ヘッドに最も近い位置にプッシュされます。
    strchg -f fileconf
