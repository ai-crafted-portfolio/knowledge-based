目的
環境変数の値を表示します。

説明
printenv
コマンドは、環境変数の値を表示します。
Name
パラメーターを指定すると、システムは
Name
パラメーターに関連した値のみを表示します。
Name
パラメーターを指定しない場合には、
printenv
コマンドは現行環境を 1 行に 1 つずつ
Name
=
Value
の順序で表示します。
環境で定義していない
Name
パラメーターを指定した場合は、
printenv
コマンドは終了状況 1 を戻します。それ以外の場合には、0 (ゼロ) の状況を戻します。

構文
Printenv [ 名前 ]

例
メール・メッセージ
環境変数の現在の設定を調べるには、次のように入力します。
printenv MAILMSG
このコマンドは、
メール・メッセージ
環境変数の値を返します。 次に例を示します。
YOU HAVE NEW MAIL
