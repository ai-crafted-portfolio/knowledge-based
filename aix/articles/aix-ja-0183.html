目的
最小特権 (LP) Resource Shared ACL のアクセス制御を変更します。

説明
chlprsacl
コマンドは、Resource Shared ACL に関連付けられているアクセス制御リスト (ACL) を変更します。 このコマンドにより、ユーザーを Resource Shared ACL に追加するか、またはユーザーをこの ACL から削除することができます。 この ACL により、以下のことが可能です。
この ACL を使用して、Resource Shared ACL が制御を持つことを Resource ACL が指示するときに LP リソースへのアクセスを制御します。
1 つ以上の LP リソースへのアクセスを制御することができます。
LP リソースへのアクセス権を定義する ACL エントリーから構成することができます。
IBM.LPCommands
クラスの各ノードには、1 つの Resource Shared ACL が存在します。
chlpracl
コマンドは、LP リソースへのアクセスが Resource Shared ACL によって制御されることを示すために使用されます。
chlpriacl
コマンドは、Resource Initial ACL を変更することによって、新たに作成された LP リソースへのアクセスが Resource Shared ACL によって制御されることを示すために使用されます。
アクセス指定を Resource Shared ACL に追加するには、ID とその ID が持つアクセ
ス権を指定します。 ID とアクセス権のペアを、複数個指定できます。 複数の ID を追加する場合で、それらの ID がすべて同じ許可を持つ場合は、
-l
フラグを使用して、コマンドの形式が ID とそれに続く単一の許可 (すべての ID に適用される) のリストであることを示します。
-o
フラグを使用すると、コマンドで指定された ID とアクセス権によって既存のアクセス権が上書きされます。 この ACL の中の事前定義のアクセス指定は削除されます。
Resource Shared ACL からアクセス権を削除するには、
-d
フラグを使用して、削除する ID を指定します。
アクセス権がファイルに指定されていることを示すには、
-f
フラグを使用します。 このファイルの各行が、ID とその ID のアクセス権となります。
-d
フラグを
-f
フラグと一緒に使用すると、各行には ID のみが必要になります。 最初のスペースの後にあるものはすべて無視されます。

このコマンドはどのノードでも実行できます。 ドメイン内のすべてのノードでこのコマンドを実行する場合は、
-a
フラグを使用します。 ドメイン内のノードのサブセットでこのコマンドを実行する場合は、
-n
フラグを使用します。 それ以外の場合、このコマンドはローカル・ノードで実行されます。

構文
1 つ以上のアクセス指定を Resource Shared ACL に追加するか、または 1 つ以上 のアクセス指定を用いて Resource Shared ACL を上書きする場合: chlprsacl [ -a | -n host1 [ , host2 , ...] ] [ -o ] [ -h ] [ -TV ] ID_1 perm1 [ ID_2 perm2 ] … 1 つ以上のアクセス指定を Resource Shared ACL に追加するか、またはすべて同 じアクセス権を使用した 1 つ以上のアクセス指定を用いて Resource Shared ACL を上書きする場合: chlprsacl [ -a | -n host1 [ , host2 , ...] ] -l [ -o ] [ -h ] [ -TV ] ID_1 [ ID_2 ...] 永続 1 つ以上のアクセス指定を Resource Shared ACL から削除する場合: chlprsacl [ -a | -n host1 [ , host2 , ...] ] -d [ -h ] [ -TV ] ID_1 [ ID_2 ...] アクセス指定を Resource Shared ACL に追加する (またはアクセス指定をこの ACL から削除する)、あるいはファイルの中に指定されているアクセス指定を用いて Resource Shared ACL を上書きする場合: chlprsacl [ -a | -n host1 [ , host2 , ...] ] [ -o | -d ] -f file_name [ -h ] [ -TV ] アクセス権が許可されないように Resource Shared ACL を設定する場合: chlprsacl [ -a | -n host1 [ , host2 , ...] ] -x [ -h ] [ -TV ]
