目的

ワークロード・パーティションの特性をリストします。

構文

表形式:

Lswpar [-b | -ブレ | -Bf (B) | -D | -I (I) | -M (M) | -N (N) ] [ -X (X) ] [-a 値 フィールド名 [,...]] [-Q (Q)] [-s 状態] [T タイプ] [WPAR 名 ...]

パラグラフ形式:

Lswpar {-G | -L (L) | -R | -S (S) | -T (T)} [-s 状態] [T タイプ] [WPAR 名 ...]

区切り文字形式:

Lswpar {「-c」 | -d 年 デリム} [-a 値 フィールド名 [,...] | -G | {-b | -ブレ | -Bf (B) | -D | -X (X) -I (I) | -M (M) | -N (N)} [-a 値 フィールド名 [,...]] | -R | -S (S) | -T (T)] [-Q (Q)] [-s 状態] [T タイプ] [WPAR 名 ...]

説明

lswpar コマンドは、指定された 1 つ以上の ワークロード・パーティション (指定されていない場合はすべての ワークロード・パーティション ) に関する情報を標準出力に出力します。

-s フラグを使用して、以下の ワークロード・パーティション 状態に従ってすべてのリストをフィルターに掛けることができます。

項目
説明
定義済み ワークロード区画 は mkwpar コマンドによって定義され、使用する準備ができていますが、アクティブではありません。 startwpar コマンドを使用して、この状態で ワークロード・パーティション を開始します。
ロード済み ワークロード・パーティション がカーネルで構成されていますが、プロセスはまだ開始されていません。
注: この状態は、 lswpar コマンドを使用して ワークロード・パーティションを開始するプログラマチック・コンシューマーにのみ表示されます。
アクティブ ワークロード・パーティション は正常に実行されています。
凍結 チェックポイント操作が開始され、 ワークロード区画 のプロセスが静止し、保管フェーズを待機します。
注: Frozen 状態が表示されるのは、 lswpar コマンドを使用して ワークロード・パーティションのチェックポイントを指定した場合のみです。 チェックポイントまたは再始動機能には、基本 WPAR以外の追加ソフトウェア・パッケージが必要です。
一時停止 チェックポイントまたは再始動操作が実行され、 ワークロード区画 のプロセスを再開または強制終了する準備ができました。 チェックポイントまたは再始動機能には、追加のソフトウェアが必要です。
保守 ワークロード区画は、startwpar コマンドを指定して保守モードにすることができます。 保守モード中に、ワークロード区画がカーネル内に構成され、ファイルシステムがマウントされましたが、プロセスが開始されません。
移動中 非同期チェックポイント・リスタート操作が実行されました。 ワークロード区画 は到着サーバー上で 「アクティブ」 ですが、 ワークロード区画 は、すべてのリソースが正常に転送されるまで、出発サーバー上で 「移動中」 状態で表示されます。 チェックポイントまたは再始動機能には、追加のソフトウェアが必要です。
移行 管理操作が進行中です。 ワークロード区画 は、作成中、開始中、停止中、構成中などです。
中断 管理操作が失敗し、この ワークロード・パーティション は使用不可の状態のままです。
ERROR ワークロード区画名やフラグなどの無効なエレメントのために、エラーが発生しました。

-t フラグを使用すると、以下の ワークロード・パーティション ・タイプに従ってすべてのリストをフィルターに掛けることができます。

項目
説明
アプリケーション このタイプは、分離されたシステム・サービスなしで単一プロセス (またはその方法で呼び出されるプロセスのグループ) を実行するアプリケーション・ ワークロード・パーティションです。 プロセスまたはプロセスのグループは、その稼働環境 (ファイル・システム、セキュリティー、デバイス) を継承します。 アプリケーション・ ワークロード・パーティション が作成された環境から (以下同様)。
システム このタイプは、オペレーティング・システムの独立した完全に機能するインスタンスをエミュレートするシステム・ ワークロード・パーティションです。

追加のチェックポイントまたは再始動ソフトウェアがインストールされる場合は、以下のタイプも指定することができます。

項目

追加のバージョン管理された ワークロード・パーティション ・ソフトウェアがインストールされている場合は、以下のタイプを指定することもできます。
項目
説明

Versioned

表形式

オプションが使用されない場合は、出力は以下の例に示すように表形式です。

Name         State    Type    Hostname    Directory   RootVG WPAR
-------------------------------------------------------------------
wpar name    state    type  hostname    root directory   yes/no
...            ...    ...   ...           ...             ...

表形式では、 WPARごとに複数のレコードが存在する場合があります。 -D、 -I、 -M。 および -N フラグは表形式で表示されますが、 -c フラグおよび -d フラグと組み合わせて区切り形式を生成することができます。 -a フラグを使用すると、表形式で表示されるフィールドをカスタマイズすることができます。 -q フラグを使用して、表の見出しを抑止することができます。
ヒント: 自動化された目的で、表形式の出力の正確な形式と内容に依存しないでください。 区切り文字形式を使用すれば、解析が可能な出力を作成できます。
表形式の各フィールドの幅は、該当の列の最も長い値に応じて拡張されます。 したがって、要求されるフィールドに応じて、幅の狭い画面では出力の折り返しが起こることがあります。

パラグラフ形式

パラグラフ形式では、各フィールドには 1 つの WPARに対して 1 つの値があります。 -G、 -R、 -S、および -T フラグを使用して、 ワークロード・パーティション 構成の段落スタイルのサブセットを表示できます。 -L フラグは詳細なリストを表示します。このリストは、-D、-G、-I、-M、-N、-R、-S、および -T フラグによって示されるデータの組み合わせです。 それ以外の場合は、形式を組み合わせることはできません。

区切り文字形式

区切り文字形式は、機械可読形式の生成に使用されます。 任意の区切り文字を選択することができます。 -c または -d フラグを使用して区切り文字形式を生成することができます。 -a フラグを使用して、表示するフィールドをカスタマイズすることができます。 -q フラグを使用して、ヘッダー行を抑止することができます。 パラグラフ形式のフラグ (-G、-R、-S、および -T) と、表形式のフラグ (-D、-I、-M、および -N) を個別に使用することにより、対応する事前定義済みのフィールド・セットに表示を限定することができます。

WPAR-特定の経路

ワークロード・パーティション は、複数の経路を持つことができます。 したがって、-I フラグを使用する場合、次のフィールドに -a フラグを指定することができます。

  • RTInterface
  • RTTYPE
  • rtfamily (rtfamily)
この表示は、1 行につき 1 つの経路で構成されます。

ネットワーク

1 つの WPAR に複数のネットワークがある場合があります。 したがって、-N フラグを使用する場合、次のフィールドに -a フラグを指定することができます。
  • 名前 ( WPAR 名)
  • インターフェース
  • アドレス
  • netmask
  • Broadcast
この表示は、1 行につき 1 つのネットワークで構成されます。
 

マウント数

ワークロード・パーティション には、複数のマウントが存在する場合があります。 したがって、-M フラグを使用する場合、次のフィールドに -a フラグを指定することができます。

  • Mountpoint (マウント・ポイント名)
  • Device (マウントされたオブジェクト)
  • Vfs (仮想ファイルシステムのタイプ)

-M 要求された ワークロード区画ごとに詳細なマウント情報を生成します。 ワークロード・パーティション の外部からマウントされたファイル・システムがリストされ、 ワークロード・パーティション 内で定義されたファイル・システムは含まれません。 -M フラグは、-G、-I, -L、-N、-R、または -T フラグとは一緒に使用できません。 -c または -d フラグを指定しないと、次の例で示すように表出力が生成されます。
Name     MountPoint    Device    Vfs    Nodename  Options
----------------------------------------------------------
name   mountpoint   device   vfs   node     options
...   ...         ...     ...   ...     ...

-c または -d フラグを使用すると、次の例に示すような区切り文字形式の出力が生成されます。

name:mountpoint:device:vfs:nodename:options

出力を以下のフィールドのいずれかの組み合わせに限定するために、このフラグを -a フラグと一緒に使用することができます。
  • Name ( ワークロード・パーティション 名)
  • Mountpoint (マウント・ポイント名)
  • Device (マウントされたオブジェクト)
  • Vfs (仮想ファイルシステムのタイプ)
  • Nodename (マウントがリモートの場合、ノード名)
  • Options (任意のマウント・オプション)
-N 要求された ワークロード・パーティションごとに詳細なネットワーク情報を生成します。 このフラグは、-G 、-I、-L、-M、-R、-D、-S、または -T フラグと同時には使用できません。 -c または -d フラグを指定しないと、次の例で示すように表出力が生成されます。
Name    Interface    Address(6)         Mask/Prefix       Broadcast
------------------------------------------------------------
name    if           A.B.C.D            A.B.C.D           A.B.C.D
...
name    if           S:T:U:V:W:X:Y:Z    R
...

-c または -d フラグを使用すると、次の例に示すような区切り文字形式の出力が生成されます。

name:interface:address:mask_prefix:broadcast

-N フラグを -a フラグと一緒に使用することにより、出力を次のフィールドの任意の組み合わせに制限することができます。
  • 名前 ( WPAR 名)
  • インターフェース
  • Address(IPv4 または IPv6 アドレス)
  • Mask_Prefix (IPv4 netmask フィールドまたは IPv6 prefixlen フィールド)
  • Broadcast

WPAR に 1 つ以上の名前がマップされたインターフェースが含まれている場合、 lswpar コマンドは、 WPAR が 「定義済み」 状態のときに構成ファイルに指定された情報のみを表示します。 WPAR が アクティブ 状態の場合、実際のランタイム・ネットワーク属性が表示されます。

注: 区切り文字で区切られている出力に IPv6 アドレスが含まれることが予期される場合は、 IPv6 アドレスにはコロンが含まれるため、 -d フラグを使用して代替区切り文字を指定してください。
-q 表の見出しを抑止 (静止) します。 このフラグは、表形式と区切り文字形式の出力の場合にのみ有効です。
-R 要求された WPARごとに詳細なリソース制御情報を生成します。 このフラグは、-G、-I、-L、-M、-N、-D、-S、または -T フラグと同時には使用できません。 -c または -d フラグを指定しないと、各 ワークロード・パーティション 出力は以下の段落フォーマットになります。

Name - State

RSet:                                    rset
CPU Shares:                              n
CPU Limits:                              m%-S%,H%
Memory Shares:                           n
Memory Limits:                           m%-S%,H%
Per-Process Virtual Memory Limit:        nMB
Total Processes:                         n
Total Threads:                           n
Total PTYs:                              n
Total Large Pages:                       n
Max Message queue IDs:                   n%

Max Shared memory IDs:                   n%

-c または -d フラグを使用すると、区切り文字で区切られた出力は以下の例のようになります。

name:state:active:rset:shares_CPU:CPU:shares_memory:memory:
procVirtMem:totalProcesses:totalThreads:totalPTYs:
totalLargePages:pct_msgIDs:pct_semIDs:pct_shmIDs:pct_pinMem
-s {[D] [L] [A] [F] [P] [N] [M] [T] [B]} workload partition の状態に基づいて出力をフィルターに掛けます。 複数の状態コードを使用することができます。 状態コードについては、-c フラグを参照してください。
-S 要求された WPARごとに詳細なセキュリティー特権情報を生成します。 このフラグは、-D、-G、-I、-L、-M、-N、-R、または -T フラグとは一緒に使用できません。 -c または -d フラグを指定しないと、各 ワークロード・パーティション 出力は以下の段落フォーマットになります。
===============================

===============================
Privileges:  comma-separated list of privileges assigned to the workload partition
-t {[A][S][C][L]} ワークロード・パーティション ・タイプに基づいて出力をフィルタリングします。 複数のタイプ・コードを使用することができます。 タイプ・コードについては、-c フラグを参照してください。
-T 要求された ワークロード・パーティションごとに詳細なロック情報を生成します。 このフラグは、-D、-G、-I、-L、-M、-N、-R、-S、または -s フラグと同時には使用できません。 このフラグは、-c フラグも指定されていない限り、-q フラグと同時には使用できません。 -c フラグを指定しない場合、各 ワークロード・パーティション 出力の形式は次のようになります。
================
Name - State
================
Operation:  %c
Process ID: %p
Start time: %t

wparname (wparname) 1 つ以上の ワークロード・パーティションを指定します。 このパラメーターは、コマンド・ラインの最後のパラメーターでなければなりません。 複数の ワークロード・パーティション 名と一致するシェル・スタイルのワイルドカードを含めることができます。 (この場合、lswpar コマンドがメタキャラクターを受け取る前に、シェル拡張を防ぐための適切なシェル引用符を使用します。)

セキュリティー

アクセス制御: root ユーザーのみがこのコマンドを実行できます。

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。
