目的

キュースタンザの名前を表示します。

構文

lsque [ -c ] -q Name

説明

デフォルトでは、'lsqueコマンドは'printfサブルーチンを使用して、'/etc/qconfigファイ ルからキュースタンザの名前とそれに関連する属性を表示する。

プリンタ AIX サブシステムの拡張機能が無効になっている場合、この lsque コマンドはキュースタンザの名前と、それに関連する属性を /etc/qconfig.bin ファイルから表示します。 調整可能な printer_scalability パラメータの詳細については、 その他の調整可能なパラメータページの該当 printer_scalability セクションを参照してください。

フラグ

表 1. ファイル
項目
説明
-c システム管理インターフェイスツール（SMIT）で使用するために、コロン形式で出力を表示します。
-q 名前 標準出力に送られるキュー・スタンザの名前を指定する。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. キュー・スタンザ「lp0名前を表示するには、以下のコマンドを入力する：
    lsque -q lp0
    以下のようなリストが表示される：
    lp0:
   device = lpd0
   host = neptune
   rq = nlp0
  2. キュー・スタンザ「lp0名前をコロン形式で表示するには、以下のコマンドを入力する：
    lsque -c -q lp0
    以下のようなリストが表示される：
    device:discipline:up:acctfile:host:s_statfilter:l_statfilter:rq
lpd0:fcfs:true:false:neptune:::nlp0
