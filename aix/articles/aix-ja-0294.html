目的
グループ・サービス・サブシステムのチューナブル・パラメーターを実行時に変更します。
重要:
RSCT 2.5.5.0以降、グループ・サービスのトレース出力を制御するための
cthagstune
コマンドはサポートされません。 グループ・サービスのトレース出力を制御するには、トレース・スプールを使用できます。 詳しくは、
トレース・スプーリングの構成
を参照してください。

説明
cthagstune
コマンドは、実行時にグループ・サービス・サブシステムのチューナブル・パラメーターを変更します。

構文
cthagstune [ -l log_length] [ ログ長 -d log_dirsize］ cthagstune [ -h ]

オプション
フラグ
-l
ログ・ファイルの最大長を指定します。 値が
0
または負の数値の場合は、デフォルトのログ・ファイルの長さが使用されます。
-d
ログ・ディレクトリーの最大サイズをキロバイト単位で指定します。 値が
0
または負の数値の場合、デフォルトのログ・ディレクトリー・サイズが使用されます。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。

例
ログ・ファイルの長さを 6000 行に変更し、ログ・ディレクトリーのサイズを約 7 メガバイトに設定するには、次のように入力します。
cthagstune -l 6000 -d 7000
