表2. サブセクションの詳細
項目 | 説明
Processor utilization | このサブセクションは、すべてのプロセッサの使用状況の概要を1行で表示する。 このサブセクションをオフにするには、 c キーを 1 回押します。 複数のプロセッサーが存在する場合、 c キーを2回押すと、プロセッサーのリストが表示される。 c キーを3回押すと、プロセッサの累積使用量を示す棒グラフが表示される。 どちらのフォーマットでも、以下のフィールドが表示される： User% ユーザーモードで実行されるプログラムによって使用されるプロセッサーの割合。 デフォルトはUser%順。 Kern% カーネルモードで実行されるプログラムが使用するプロセッサの割合。 Wait% I/O待ち時間の割合。 Idle% プロセッサーがアイドル状態の時間のパーセンテージ。 Physc 使用する物理プロセッサの数。 パーティションが共有プロセッサで実行されている場合のみ表示されます。 %Entc 使用されている権利容量の割合。 パーティションが共有プロセッサで実行されている場合のみ表示されます。 このサブセクションがホット・プロセッサーのリストを表示する場合、 リストは User% フィールドによってソートされています。 しかし、他のフィールドでは、カーソルを必要な列に移動させることでリストをソートすることができる。

Network interfaces | このサブセクションは、すべてのネットワーク・インターフェースに関するアクティビティーの 1 行のレポート要約を示します。 このサブセクションをオフにするには、 n キーを 1 回押します。 n キーを2回押すと、アクティブなネットワーク・インターフェイスのリストが表示されます。 表示されるインタフェースの最大数は、 -n フラグを使用して指定された、監視されているアクティブなインタフェースの数である。 他のサブセクションも表示されている場合、それより少ない数のインターフェースが表示されます。 どちらのレポートでも、 以下のフィールドが表示されます。 BPS モニタリング・インターバルにおける1秒あたりのキロバイト（kbs）単位の総スループット。 このフィールドは、1秒あたりの受信と送信の合計（kbs）である。 Interf ネットワーク・インターフェースの名前。 I-Pack 監視期間中に1秒間に受信されたデータパケット数。 KB-In モニタリング・インターバルで1秒間に受信されたkbs数。 KB-Out モニタリング・インターバルで1秒間に送信されるkbs数。 O-Pack 監視期間中に1秒間に送信されたデータパケット数。 このサブセクションが ホット・ネットワーク・インターフェースを表示するときには、 リストは BPS フィールドによってソートされています。 しかし、他のフィールドでは、カーソルを必要な列に移動させることでリストをソートすることができる。 並べ替えは最大16個のネットワークアダプターまで有効です。

Physical disks | このサブセクションは、すべての物理ディスクのアクティビティに関する1行レポートのサマリーを表示します。 このサブセクションをオフにするには、 d キーを 1 回押します。 d キーをもう一度押すと、アクティブな物理ディスクのリストが表示されます。 表示される物理ディスクの最大数は、 -d フラグを使用して指定された、監視対象のアクティブな物理ディスクの数です。 他のサブセクションも表示されている場合、それより少ない数の物理ディスクが表示されます。 どちらのレポートでも、 以下のフィールドが表示されます。 Busy% 物理ディスクがアクティブな時間のパーセンテージ (ドライブの処理能力の使用)。 BPS モニター・インターバルに、1 秒間に転送された (読み取りおよび書き込み) データ量 (キロバイト単位)。 このフィールドは、 KB-Read と KB-Writ の値の合計です。 Disk 物理ディスクの名前。 KB-Read 物理ディスクから1秒間に読み出されるkbsの数。 KB-Writ 物理ディスクに1秒間に書き込まれるkbsの数。 TPS 1 秒間に物理ディスクに対して発行された転送の数。 転送とは、その物理ディスクに対する入出力要求のことです。 複数の論理要求をまとめて、ディスクに対する 1 つの入出力要求にすることができます。 転送のサイズは不確定です。 このサブセクションがホット物理ディスクのリストを表示するときには、 リストは BPS フィールドによってソートされています。 しかし、他のフィールドは、カーソルを必要な列に移動させることで、リストを並べ替えることができる。 ソートは、 最大で 128 個の物理ディスクに有効です。

File system | このサブセクションは、すべてのファイルシステムのアクティビティを1行でまとめたレポートを表示します。 セクションをオフにするには、 f キーを 1 回押します。 f キーを2回押して、アクティブなファイルシステムのリストを表示する。 表示されるファイルシステムの最大数は、 -f フラグを使用して指定されているときにモニターされるアクティブ・ファイルシステムの数です。 他のサブセクションも表示されている場合、それより少ない数のファイルシステムが表示されます。 どちらのレポートでも、 以下のフィールドが表示されます。 BPS モニター・インターバルに、1 秒間に転送された (読み取りおよび書き込み) データ量 (キロバイト単位)。 このフィールドは KB-Read および KB-Writ フィールドの値の合計です。 File System ファイルシステムの名前。 KB-Read ファイルシステムから1秒間に読み込まれるkbsの数。 KB-Writ ファイルシステムに1秒間に書き込まれるkbsの数。 TPS 1 秒間にファイルシステムに対して発行される転送の数。 転送とは、そのファイルシステムに対する入出力要求のことです。 複数の論理要求をまとめて、ファイルシステムに対する 1 つの入出力要求にすることができます。 転送のサイズは未確定です。 このサブセクションがファイルシステムのリストを表示する際、リストは BPS フィールドによってソートされています。 しかし、他のフィールドは、カーソルを目的の列に移動させることで、リストをソートすることができる。 ヒント: ファイル・システム名がディスプレイのフィールド幅を超える場合、ファイル・システム名は切り捨てられた形式で表示されます。 切り捨てはファイルシステムの最初と最後の数文字を含み、ピリオド（...）は名前の中間部分を置き換える。 例えば、ファイルシステム名が filesystem001234 である場合、名前は files..01234 で表示されます。

WLM classes | このサブセクションは、ホット ワークロード・マネージャー (WLM) クラスのリストを表示します。 表示される WLM クラスの最大数は、 -w フラグで指定されたホット WLM クラスの数です。 他のサブセクションも表示されている場合、それより少ない数のクラスが表示されます。 w キーを押すと、 このサブセクションがオフになります。 各クラスで以下のフィールドが表示されます。 % processor Utilization モニター・インターバルの、WLM クラスの平均プロセッサー使用量。 % Mem Utilization 監視期間中の WLM クラスの平均メモリ使用量。 % Blk I/O 監視期間中の WLM クラスのブロック I/O の平均 %。 このサブセクションが最初にホット WLM クラスのリストを表示するとき、リストは CPU% フィールドでソートされます。 しかし、その他のフィールドでは、カーソルを目的の列に移動させることでリストをソートすることができる。 ヒント: WLM クラス名が表示のフィールド幅を超えると、WLM クラス名は切り捨てられます。 切り捨てはWLMクラスの最初と最後の数文字を含み、ピリオド（...）は名前の中間部分を置き換える。 例えば、WLM クラス名が unclassified00123 である場合、WLM クラス名は uncla..00123 で表示されます。

Workload partitions | ワークロード・パーティション・サブセクションは 、 -@ フラグで開始された場合、WLM サブセクションを置き換える。 このサブセクションは、ホット・ ワークロード・パーティション のリストを表示します。 表示される ワークロード・パーティションの 最大数は、 -w および -@ フラグで指定されたときに監視されるホット WPAR の数である。 他のサブセクションも表示されている場合は、表示される WPAR の数が少なくなります。 ワークロード・パーティションの サブセクションをオフにするには、 @ キーを押す。 各 WPAR について、以下のフィールドが表示されます。 WPAR ワークロード・パーティション ( WPAR ) の名前。 % processor Utilization 監視期間中の WPAR の 平均プロセッサ使用量。 % Mem Utilization 監視期間中の WPAR の平均メモリ使用量。 % Blk I/O 監視期間中の WPARの ブロックI/Oの平均％。 このサブセクションがホット WPARの リストを表示する場合、リストは CPU% フィールドでソートされる。 しかし、他のフィールドでは、カーソルをリストの並べ替えに使いたい対象列の一番上に移動させることで、リストを並べ替えることができる。 ヒント: WPAR 名が表示内のフィールド幅を超えると、 WPAR 名は切り捨てられます。 切り捨ては WPARの 最初と最後の数文字を含み、ピリオド（...）は名前の中間部分を置き換える。 例えば、 WPAR 名が neptune00123 の場合、 WPARは neptu..00123 と表示される。

Processes | このサブセクションは、 ホット・プロセスのリストを表示します。 表示されるプロセスの最大数は、 -p フラグで指定された監視対象のホット・プロセスの数である。 他のサブセクションも表示されている場合、それより少ない数のプロセスが表示されます。 p キーを押すと、 このサブセクションがオフになります。 プロセスは、モニター・インターバルにおけるプロセッサーの使用量によってソートされます。 各プロセスで以下のフィールドが表示されます。 Name プロセス内で実行される実行プログラムの名前。 名前は、任意のパス名および引数情報から得られ、9 文字の長さに切り捨てられます。 Process ID プロセスのプロセス ID。 % CPU Utilization 監視期間中のプロセスの平均プロセッサ使用量。 プロセスが初めて表示される場合、この値はプロセスの存続期間での平均プロセッサー使用量です。 Paging Space Used このプロセスに割り当てられているページング領域のサイズ。 これは、プロセスのフットプリントの表現と考えることができるが、実行可能なプログラムとそれが依存する共有ライブラリを保持するために使用されるメモリは含まれない。 Process Owner (if the WLM section is off) プロセスを所有するユーザーのユーザー名。 ワークロード・マネージャー (WLM) Class (if the WLM section is on) プロセスが属する WLM クラス。 WPAR (if the WPAR section is on) プロセスが属している WPAR の名前。 ヒント: WLM クラス/ WPAR 名が表示内のフィールド幅を超えると、WLM クラス/ WPAR 名は切り捨てられます。 切り捨てには、WLM クラス/ WPAR の最初と最後の数文字が含まれ、名前の中央部分はピリオド (..) に置き換えられます。 例えば、WLM クラス/ WPAR 名が unclassified00123 の場合、WLM クラス/ WPAR 名は uncla..00123 と表示されます。

-V | ボリューム・グループ・パネルを表示します。 このパネルは、パネルの上部セクションではボリューム・グループに関する以下のメトリックを報告し、パネルの下部セクションでは論理ボリュームに関する同一メトリックを報告します。 LogicalVolume/VolumeGroup 論理ボリュームまたはボリューム・グループの名前。 TPS メトリックが表示される間隔に出された入出力要求の総数。 KB-R 指定の間隔に読み取られた合計キロバイト数。 KB-W 指定の間隔に書き込まれた合計キロバイト数。 KBPS 論理ボリュームまたはボリューム・グループの照会で 1 秒間に転送される (読み取りまたは書き込み) データの量 (キロバイト単位)。
-W | 分割表示である フルスクリーン WLM クラス表示 を表示します。 このディスプレイの上部では、 ホット WLM クラスのリストを示しています。 これはデフォルト・ディスプレイの WLM クラス・サブセクションと似ていますが、 完全クラス名を表示できるだけのスペースがあります。 このリストは任意の列でソートできます。 -@ フラグを指定するか、 @ サブコマンドを押すと、 WPAR セクションが表示され、WLM セクションは表示されません。 「WPAR」 セクションには、ホット WPAR のリストが表示されます。 このリストは任意の列でソートできます。 画面の下部には、フルスクリーン・プロセス表示と同様に最もビジーなプロセスのリストが表示されますが、 f キーを使用して選択された 1 つの WLM クラスまたは WPAR に属するプロセスのみが表示されます。 注： WLMクラスがアクティブでない場合、デフォルトのシステム・プロセスがディスプレイの下部に表示される。
-w [監視対象のホットWLMクラス数］ | hotwlmclass パラメーターで、監視する ホットワークロードマネージャー （WLM）クラスの数を指定します。 これは、画面に十分なスペースがある場合に表示されるWLMクラスの最大数でもある。 この数がインストールされているWLMクラスの数を超える場合、インストールされているWLMクラスのみが監視されます。 この引数を省略すると、 デフォルトである 2 が使用されます。 値として 0 (ゼロ) を指定すると、 WLM クラス情報はモニターされません。
