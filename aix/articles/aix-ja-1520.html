目的
文書の表面上の特性を分析します。

説明
style
コマンドは、英語で記述された文書の執筆形式の表面上の特性を分析します。 読みやすさ、文の長さと構造、ワード長と使用法、動詞のタイプ、文の始め方について報告します。
style
コマンドは、テキストを調べる前に
deroff
コマンドを実行するので、適切なフォーマット情報を含むヘッダー・ファイルを入力の一部として含めなければなりません。
“
注:
標準外フォーマット・マクロを使用すると、センテンスの切れ目が正しくなくなる可能性があります。
”

構文
スタイル [ -a 値 ] [ -e (E) ] [ - 数値 ] [ -ML ] [ -mm (M) ] [ P- ] [ -P ] [ - 数値 ] ファイル ...

オプション
フラグ
項目 | 説明
-a | すべての文に長さと読みやすさの指標を付けて表示します。
-e | 「」などの説明で始まるすべての文を印刷します。 There are ".
-l 番号 | Number パラメーターで指定されたワード数よりも長い文をすべて表示します。
-ml | deroff コマンドにリストをスキップさせます。 文書に文フラグメントのリストが多数含まれている場合は、 -ml を使用します。
-MM | デフォルトの ms マクロ・パッケージをオーバーライドします。
-p | 受動態動詞を含むすべての文を表示します。
-P | 文書内のワードの話法の一部を表示します。
-r 数値 | 読みやすさの指標が Number よりも大きい文をすべて表示します。
