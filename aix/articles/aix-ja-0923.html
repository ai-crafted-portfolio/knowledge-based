目的
スペシャル・ファイルを作成します。

説明
mknod
コマンドは、スペシャル・ファイル用のディレクトリー・エントリーとそれに対応する i ノードを作成します。 第 1 パラメーターはエントリー・デバイスの名前です。 デバイスを説明する名前を選択します。
mknod
コマンドには異なるフラグを持つ 2 つの形式があります。
最初の形式の「
mknod
コマンドは、rootまたはシステム・グループのメンバが実行できる。 第 1 形式では、
b
または
c
フラグを使用します。
b
フラグは、特殊ファイルがブロック指向デバイス（ディスク、ディスケット、テープ）であることを示す。
c
フラグは、特殊ファイルが文字指向デバイス（その他のデバイス）であることを示す。
最初のフォームの最後の2つのパラメータは、
メジャー・
デバイスと
マイナー・
デバイスを指定する数字である。
メジャー
デバイス番号は、オペレーティングシステムがデバイスドライバコードを見つけるのに役立ちます。
マイナー・
デバイス番号は、10進数または8進数の単位ドライブ番号またはライン番号である。 デバイスのメジャー番号とマイナー番号は、デバイスのconfigureメソッドによって割り当てられ、
ODM
の
CuDvDr
クラスに保持される。
メジャー番号およびマイナー番号をこのオブジェクト・クラスに定義することは、システムを通してデバイス定義の整合性を保証するのに重要です。
mknod
コマンドの第 2 形式では、
p
フラグを使用して FIFO パイプラインを作成します。

構文
rootまたはシステムグループメンバーによってのみ実行される mknod Name { b | c } Major Minor パイプまたはパイプラインとも呼ばれるFIFO（先入れ先出し）ファイルを作成します mknod Name { p }

オプション
フラグ
項目 | 説明
b | 特殊ファイルがブロック指向デバイス（ディスク、ディスケット、テープ）であることを示す。
c | 特殊ファイルが文字指向デバイス（その他のデバイス）であることを示す。
p | FIFO (名前付きパイプライン) を作成します。

例
新しいディスケット・ドライブのスペシャル・ファイルを作成するには、次のコマンドを入力します。
mknod /dev/fd2 b 1 2
このコマンドによって
/dev/fd2
スペシャル・ファイルが作成されます。
このスペシャル・ファイルは、メジャー・デバイス番号が 1、マイナー・デバイス番号が 2 の特殊ブロック・ファイルです。
新しいキャラクター・ドライブのスペシャル・ファイルを作成するには、次のコマンドを入力します。
mknod /dev/fc1 c 1 2
このコマンドによって
/dev/fc1
スペシャル・ファイルが作成されます。
このスペシャル・ファイルは、メジャー・デバイス番号が 1、マイナー・デバイス番号が 2 の特殊キャラクター・ファイルです。
FIFO パイプ・ファイルを作成するには、次のコマンドを入力します。
mknod fifo1 p
このコマンドは、名前が fifo1 の FIFO パイプ・ファイルを作成します。
