目的
構成済み LDAP ディレクトリー・サーバーの命名サービス・オブジェクトを表示します。

説明
この
lsldap
コマンドは、設定済みの LDAP ディレクトリサーバー上のネーミングサービスオブジェクトを表示します。 これは、デーモンを
secldapclntd
介して LDAP サーバーにクエリを送信します。 特定のエンティティーの一部またはすべてのオブジェクトは、
lsldap
コマンドによってリストすることができます。 デフォルトでは、
lsldap
コマンドは、返されたオブジェクトの識別名 (DN) のみを表示します。 さらに、
-a
フラグを使用して属性を表示できます。
lsldap
コマンドは、以下のエンティティーをサポートします。

automount エンティティーには 2 つのオブジェクト・クラスがあります。
lsldap
コマンドは、
nisMap
より優先順位の高い
automountMap
を処理します。
automountMap
オブジェクトがない場合にのみ、常に
automountMap
オブジェクトを返し (検出された場合)、 nisMap オブジェクトを返します。
passwd
および group エンティティについては、この
lsldap
コマンドは LDAP クライアントの設定に従って正しいオブジェクトを返します。 ただし、オブジェクト・
クラスに対応する正しい属性名を、
lsldap passwd attribute=value
照会に
合うように指定する必要があります。
コマンド・ラインからエンティティー名を指定しない場合、
lsldap
コマンドは、エンティティーのコンテナー項目と、これらのコンテナーの兄弟であるその他の項目を表示します。 コンテナー・エントリーをリストするには、ユーザーは root アクセス権を持っている必要があります。
entry_name
パラメーターは、照会するオブジェクトの名前です。 例えば、エンティティーが
passwd
の場合は、
entry_name
はユーザー・アカウント名です。
entry_name
パラメーターは、
default attribute name = entry_name
と同等です。
lsldap
コマンドは、サブストリング検索のために
entry_name
内の
*
ワイルドカードを受け入れます。
entry_name
を指定しない場合は、すべてのエントリーが戻されます。
entry_name
の代わりに、
filter
を指定して、特定の基準に合致するエントリーを検索することもできます。 簡易フィルターを
attributename

=
attributevalue
として指定することが
できます。ここで、
attributename
は LDAP 属性名です。
lsldap
コマンドは、結果を
stdout
に出力します。
-a
フラグが指定されていない場合、
lsldap
は、DN の形式で検出された項目を、各 DN をブランク行で区切って印刷します。
-a
フラグが指定されている場合、各エントリーは ldif 形式で出力され、エントリー間にはブランク行が入ります。

構文
lsldap [ -a ] [ エンティティー [ entry_name | filter ]]

オプション
フラグ
項目 | 説明
-a | 戻されたオブジェクトのすべての属性を表示します。 デフォルトでは、オブジェクトの DN のみが表示されます。

例
ホスト・エンティティーのすべてのエントリーをリストするには、次のコマンドを入力します。
lsldap hosts
次のような情報が戻されます。
dn: cn=myhost+ipHostNumber=192.3.193.46,ou=Hosts,cn=aixdata
dn: cn=starfish+ipHostNumber=192.3.193.47,ou=Hosts,cn=aixdata
dn: cn=loopback+ipHostNumber=127.0.0.1,ou=Hosts,cn=aixdata
ホスト
starfish
およびそのすべての属性をリストするには、次のコマンドを入力します。
lsldap -a hosts starfish
次のような情報が戻されます。
dn: cn=starfish+ipHostNumber=192.3.193.47,ou=Hosts,cn=aixdata
objectClass: top
objectClass: ipHost
objectClass: device
ipHostNumber: 192.3.193.47
cn: loopback
cn: localhost
文字
b
が名前の先頭に付くユーザーをリストするには、次のコマンドを入力します。
lsldap passwd "b*"
次のような情報が戻されます。
dn: uid=bin,ou=people,cn=aixdata
dn: uid=bob,ou=people,cn=aixdata
ユーザー
foo
およびその属性をリストするには、次のコマンドを入力します。
lsldap -a passwd foo
