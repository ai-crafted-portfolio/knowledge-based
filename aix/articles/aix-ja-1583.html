目的
トポロジー・サービス・サブシステムを始動します。

説明
topsvcsctrl
制御スクリプトは、トポロジー・サービス・サブシステムの操作を制御します。 サブシステムは、システム・リソース・コントローラー (SRC) の制御下にあり、
topsvcs
というサブシステム・グループに属します。 このスクリプトは、通常は HACMP/ES 始動プロセスが始動します。
クラスターのすべてのノードでは、トポロジー・サービス・サブシステムのインスタンスが実行されています。
操作の観点からは、トポロジー・サービス・サブシステム・グループは
次のように編成されています。
サブシステム
トポロジー・サービス
サブシステム・グループ
topsvcs
SRC サブシステム
topsvcs
サブシステムは、
hatsd
デーモンおよび
topsvcs
スクリプトに関連付けられています。
topsvcs

hatsd

topsvcs

topsvcsctrl
スクリプトは、トポロジー・サービス・サブシステムを操作するためのさまざまな制御を提供します。
サブシステムの追加、始動、停止、および削除
サブシステムのクリーンアップ (すべてのシステム区画からこれらを削除すること)。
トレースのオンおよびオフ
サブシステムをリフレッシュする。
これらの機能のいずれかを実行する前に、スクリプトは現在のクラスター名 (
cllsclstr
コマンドを使用) とノード番号 (
clhandle
コマンドを使用) を取得します。 ノード番号が
0
の場合、制御スクリプトは制御ワークステーションで実行されています。
クリーンおよび構成解除の機能を除き、その他のすべての機能は現行システム区画内で実行されます。
サブシステムの追加:
-a
フラグ
を指定すると、制御スクリプトは
mkssys
コマンドを使用してトポロジー・サービス・サブシステムを SRC に追加します。 制御スクリプトは次のように動作します。
topsvcs
サブシステムが停止していることを確認します。
topsvcs

サブシステムを SRC から除去します (まだ存在している場合)。
topsvcs
サブシステムを SRC に追加します。
サブシステムの開始:
-s
フラグ
を指定すると、制御スクリプトは
startsrc
コマンドを使用してトポロジー・サービス・サブシステム
topsvcs
を開始します。
サブシステムの停止:
-k
フラグ
を指定すると、制御スクリプトは
stopsrc
コマンドを使用してトポロジー・サービス・サブシステム
topsvcs
を停止します。
サブシステムの削除:
-d
フラグ
を指定すると、制御スクリプトは
rmssys
コマンドを使用して、SRC からトポロジー・サービス・サブシステムを除去します。 制御スクリプトは次のように動作します。
topsvcs
サブシステムが停止していることを確認します。
rmssys
コマンドを使用して、
topsvcs
サブシステムを SRC から除去します。
これにより、
/etc/services
ファイルからポート番号が削除されます。
サブシステムのクリーンアップ:
-c
フラグ
を指定すると、制御スクリプトは、すべてのクラスター区画のトポロジー・サービス・サブシステムを停止し、SRC から除去します。 制御スクリプトは次のように動作します。
stopsrc -g
topsvcs
コマンドを使用して、クラスター内のサブシステムのすべてのインスタンスを停止します。
topsvcs
サブシステムのすべての項目を
/etc/services
ファイルから除去します。
トレースをオンにする:
-t
フラグ
を指定すると、制御スクリプトは
traceson
コマンドを使用して、
hatsd
デーモンのトレースをオンにします。
トレースをオフにする:
-o
フラグ
を指定すると、制御スクリプトは
tracesoff
コマンドを使用して、
hatsd
デーモンのトレースをオフにします (デフォルト・レベルに戻します)。
サブシステムのリフレッシュ:
-r
フラグ
を指定すると、制御スクリプトは、
topsvcs refresh
コマンドおよび
refresh
コマンドを使用して、サブシステムをリフレッシュします。 グローバル・オブジェクト・データ・マネージャー (ODM) にノードおよびアダプター
構成の情報を再構築して、再構築した情報を読み取るようにデーモンに指示します。
ロギング:
トポロジー・サービス・デーモン (
hatsd
) は、実行中に、
/var/ha/log/topsvcs.

cluster_name
というログ・ファイルにエントリーを書き込むことによって、その操作とエラーに関する情報を提供します。

構文
topsvcsctrl { -a │ -s │ -k │ -d │ -c │ -u │ -t │ -o │ -r │ -h }

オプション
フラグ
項目 | 説明
-a | サブシステムを追加します。
-s | サブシステムを始動します。
-k | サブシステムを停止します。
-d | サブシステムを削除します。
-c | サブシステムをクリーニングします。
-u | すべての区画からトポロジー・サービス・サブシステムを除去します。
-t | サブシステムのトレース機能をオンにします。
-o | サブシステムのトレース機能をオフにします。
-r | サブシステムをリフレッシュします。
-h | スクリプトの使用方法の文を標準出力に書き込みます。

例
トポロジー・サービス・サブシステムを SRC に追加するには、次のように入力します。
topsvcsctrl -a
トポロジー・サービス・サブシステムを始動するには、次のように入力します。
topsvcsctrl -s
トポロジー・サービス・サブシステムを停止するには、次のように入力します。
topsvcsctrl -k
トポロジー・サービス・サブシステムを SRC から削除するには、次のように入力します。
topsvcsctrl -d
トポロジー・サービス・サブシステムをクリーンアップするには、次のように入力します。
topsvcsctrl -c
トポロジー・サービス・デーモンに対するトレースをオンにするには、次のように入力します。
topsvcsctrl -t
トポロジー・サービス・デーモンに対するトレースをオフにするには、次のように入力します。
topsvcsctrl -o
