目的
論理パーティション、論理ボリューム、ボリュームグループの入出力(I/O)統計情報を表示します。 また、pbuf およびブロック入出力の統計も報告します。

説明
lvmstat
コマンドは、物理ディスク間の入出力負荷のバランスを改善するために、
論理ボリューム構成を変更するのに使用できるレポートを作成します。
デフォルトによって、統計情報収集はシステムで使用可能になりません。 該当する論理ボリュームまたはボリューム・グループに対してこの機能を有効にするには、「
-e
フラグを使用する。 ボリュームグループの統計収集を有効にすると、そのボリュームグループ内のすべての論理ボリュームが有効になります。

lvmstat -m
は、アクティブなミラー書き込み一貫性キャッシュ（MWCC）の統計レポートを生成する。 レポートは以下のフォーマットで表示される：
表3. ミラー書き込み一貫性キャッシュ統計レポートフォーマット
列 | 説明
IO_CNT | リクエストの総数を指定します。
FULL_CNT | キャッシュが一杯になったためにリクエストが保留された回数を指定する。
INFLT_CNT | キャッシュ ' write 操作が進行中であったためにリクエストが保留された回数を指定する。

構文
lvmstat { -l | -v } Name [ -e | -d ] [ -F ] [ -C ] [ -c Count ] [ -s ] [ Interval [ Iterations ] ] lvmstat -v Name -r [ -L | -C ] lvmstat -v Name -m

オプション
フラグ
表4. フラグ
項目 | 説明
-c Count | 指定した行数だけ統計情報を表示します。 注記: MWCC統計ではフラグ -c はサポートされていません。
-C | 指定された論理ボリュームまたはボリュームグループについて、「 iocnt 、「 Kb_read 、「 Kb_wrtn 」を追跡するカウンターをクリアする。 このフラグは、スペースの再利用統計をリセットするためにも使用できる。
-d | 該当する論理ボリュームまたはボリュームグループの統計収集を無効にする必要があることを指定します。
-e | 該当する論理ボリュームまたはボリュームグループに対して統計収集を有効にする必要があることを指定します。
-F | 統計情報をコロンで区切って表示する。
-l | リストへのスタンザ名を指定する。
-L | スペース再利用統計情報を詳細リスト作成モードで表示します。
-m | Name 変数で指定されたボリュームグループのMWCC統計情報を表示します。
-r | ボリューム・グループ内のすべての物理ボリュームに関するスペース再利用統計情報を出力します。
-s | Interval を使用するときに、後続のレポートでヘッダーを抑制します。
-v | 指定する Name がボリューム・グループの名前であることを示します。

例
ボリューム・グループ「
datavg
」の統計収集を有効にするには（「
datavg
内のLVはすべて有効になっている）、次のコマンドを入力する：
lvmstat -v datavg -e
論理ボリューム「
hd2
」の全パーティションの履歴を表示するには、次のコマンドを入力する：
lvmstat -l hd2
ボリュームグループ「
uservg
」の最初の5つの論理ボリュームの履歴を表示するには、次のコマンドを入力する：
lvmstat -v uservg -c 5
論理ボリューム「
ramlv
」の連続レポートを2秒間隔で表示するには、次のコマンドを入力する：
lvmstat -l ramlv 2
ボリューム・グループ「
rootvg
」について、2秒間隔で6つのレポートを表示するには、次のコマンドを入力する：
lvmstat -v rootvg 2 6
ボリュームグループ「
uservg
内のすべての論理ボリュームの統計のカウンタをリセットするには、次のコマンドを入力します：
lvmstat -v uservg -C
datalv
統計収集を無効にするには、以下のコマンドを入力する：
lvmstat -l datalv -d
スペース再利用の統計を表示するには、次のコマンドを入力する：
lvmstat -v uservg -r
ロング・リスティング・モードでスペース再利用の統計を表示するには、以下のコマンドを入力する：
lvmstat -v uservg -r -L
スペース再利用の統計をクリアするには、以下のコマンドを入力する：
lvmstat -v uservg -r -C
ボリュームグループに対してMWCC統計
datavg
を有効にするには、次のコマンドを入力します:
lvmstat -v datavg -m -e
ボリュームグループに対するMWCC統計
datavg
を無効にするには、次のコマンドを入力します:
lvmstat -v datavg -m -d
ボリュームグループ MWCC の統計情報を
datavg
クリアするには、次のコマンドを入力します:
lvmstat -v datavg -m -C
ボリュームグループに対して、
datavg
10秒間隔で5つのMWCC統計レポートを一度に表示し、カンマ区切り値(csv)ファイル形式で出力するには、次のコマンドを入力します:
lvmstat -v datavg -F m -s 10 5
