目的
集中 RAS データを収集します。

説明
psrasc
コマンドは、
PowerHA pureScale
ログストリームに集中管理されている RAS (Reliability/Availability/Serviceability) データログレコードを抽出し、RAS データAIX®フォーマットのファイルを作成します。 PowerHA® pureScale®のサービス名は
CentralizedLogService
です。 このサービス名のバインディング情報は、
psrasc
コマンドを使用する前にセットアップする必要があります。

構文
psrasc type [ -d] [ -n number ] -o outputFile logSpace/logStream

オプション
フラグ
項目 | 説明
type | ログ・レコードに含まれる RAS データの型を指定します。 このパラメーターは、最初に指定する必要があります。 サポートされる RAS データ型は、 syslog と errlog です。 この型に応じて、出力ファイルのフォーマットが決まります。
-d | 収集されたログ・レコードが削除されることを指定します。
-n Number | 収集するログ・レコードの数を指定します。 最も古いログ・レコードが収集されます。 このパラメーターを指定しない場合は、すべてのログ・レコードが収集されます。
-o OutputFile | 出力ファイルの相対パス名または絶対パス名を指定します。 その名前のファイルが既に存在する場合は上書きされます。
ログ_スペース/ログ_ストリーム | システム・ログ・メッセージの収集元のログ・ストリームのフルネームを指定します。 フルネームは、 / (スラッシュ) で区切られた親ログ・スペース名とログ・ストリーム名で構成されます。

例
CentralizedRAS/Syslog
という名前のログストリームのログレコードを、'
syslog.out
ファイル上の
CentralizedLogService
サービス名で識別される
PowerHA pureScale
サーバーを入力します：
psrasc syslog -o syslog.out CentralizedRAS/Syslog
CentralizedRAS/Syslog
という名前のログストリームの最も古いログレコード 100 件を
PowerHA pureScale
サーバーの
/var/adm/ras/cluster_syslog
ファイルに収集するには、次の手順に従います
CentralizedLogService
サービス名で識別し、それらを削除するには、次のように入力します：
psrasc syslog -d -n 100 -o /var/adm/ras/cluster_syslog CentralizedRAS/Syslog
CentralizedRAS/Errlog
という名前のログストリームのログレコードを、CentralizedLogServiceサービス名で識別される
PowerHA pureScale
サーバー
上centralizedRAS_errlog
のファイルに収集するには、次のように入力します：
psrasc errlog -o centralizedRAS_errlog CentralizedRAS/Errlog
の
/var/adm/ras/cluster_errlog
エラーログファイルに、
CentralizedRAS/Errlog
というログストリームの最も古いログレコード100件を収集し、削除するには、以下の手順に従います
centralizedRAS_error
サービスによって識別される'
PowerHApureScale
サーバーを入力する：
psrasc errlog -d -n 100 -o /var/adm/ras/cluster_errlog CentralizedRAS/Errlog
