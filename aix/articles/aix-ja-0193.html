目的
NFS 外部 ID マッピングを変更します。

説明
chnfsim
コマンドは、LDAP サーバーの EIM (エンタープライズ識別マッピング) 層を使用して、 NFS 外部 ID マッピングを管理します。 このコマンドを使用するには、
bos.eim.rte
および
ldap.client
ファイルセットがインストールされている必要があります。 さらに、マシンを EIM LDAP サーバーにする場合は、
ldap.server
ファイルセットもインストールする必要があります。
システム上の ID マッピングを変更したら、その後で
nfsrgyd -f
コマンドを実行して、システムの ID キャッシュをフラッシュしてください。
他の機能を使用する前に、まず、
-c
フラグおよび
-a
フラグを使用して EIM を使用するようにシステムを構成する必要があります。 すべてのマッピング・データは、EIM LDAP サーバーに保管され、そこから
検索されることになります。
chnfsim
コマンドは、 NFSの EIM 構成を追加、リスト、および除去するために使用します。 次に、
chnfsim
コマンドを使用して、ユーザー ID とグループ ID に対する所有者と所有者グループのストリングを追加および削除します。 このコマンドによって、ユーザーまたはグループに
関連した ID マッピングをリストすることができ、名前またはドメインに関連したマッピング ID を検索
できます。
chnfsim
コマンドは、 Kerberos レルムを NFS ドメイン・マッピングに追加および除去するためにも使用され、現在のレルムからドメインへのマッピングをリストすることができます。

構文
ユーザーおよびグループ関連外部 ID マッピングの場合 chnfsim -a | -l | -s | -x -u | -g [ -i アイデンティティ］ [ -n 名前 -d ドメイン］ レルム・ドメイン間マッピングの場合 chnfsim -a | -l | -x [ -r レルム -d ドメイン］ EIM を使用するためにシステムを構成する場合 chnfsim -c -a | -l | -x [ -t タイプ -h ホスト名 [: ポート ] -e EIM ドメイン -f EIM 接尾部 -b 管理 DN -w 管理者パスワード -W アクセス・パスワード ] システムから EIM 構成を除去する場合 chnfsim -C

オプション
フラグ
項目 | 説明
-a | 追加操作
-b | LDAP 管理者の識別名を指定します。 デフォルト値は admin です。
-c | 構成操作
-C | EIM 構成を除去します。
-d | NFS V4 所有者ストリングの NFS ドメイン部分を指定します。
-e | NFS マッピングのために使用される EIM LDAP サーバーの EIM ドメインを 指定します。
-f | NFS マッピングのために使用される EIM LDAP サーバーの EIM ディレクトリー接尾部を 指定します。
-g | グループ・ベースの操作を指定します。
-h | NFS マッピングのために使用される EIM LDAP サーバーのホスト名とポートを 指定します。
-i | マッピング ID を指定します。 これは、特定の所有者または所有者グループを記述する固有のストリングです。
-l | リスト操作
-n | NFS V4 所有者ストリングの所有者または所有者グループの名前を 指定します。
-r | Kerberos レルムを指定します。
-s | 検索操作
-t | EIM LDAP サーバーのタイプを指定します。 p | P 1 次 LDAP サーバー。 S | S 2 次 (デフォルトの) LDAP サーバー。
-u | ユーザー・ベースの操作を指定します。
-w | EIM 管理者パスワードを指定します。
-W | EIM アクセス専用ユーザー・パスワードを指定します。
-x | 除去操作
アクション・マトリックス
項目 | 説明
Operation | フラグ (括弧内はオプションのフラグ)
-c | システムの現行 EIM 構成を 表示します。 -a -t -h -e -f -w (-b -W) EIM 使用のためのシステムを 構成します。 指定された hostname がローカル・システムの場合、 -w フラグは必須です。 hostname がローカル・システムでない場合は、少なくとも 1 つの -w または -W フラグを指定する必要があります。 複数の EIM LDAP レプリカ・サーバーに対して、NFS クライアントまたはサーバーを構成できます。 -l -h サーバー hostname [: port ] の構成に関する詳しいリストを、構成ファイルから作成します。 -x -h サーバー hostname [: port ] の構成の詳細を、構成ファイルから削除します。

-a | -u -i (-n -d) ユーザー・マッピング ID を追加します。 -n および -d フラグが指定されている場合、その ID マッピングはユーザー・マッピング ID に関連付けられます。 -g -i (-n -d) グループ・マッピング ID を追加します。 -n および -d フラグが指定されている場合、その ID マッピングはグループ・マッピング ID に関連付けられます。 -r -d レルム・ドメイン間マッピングを追加します。
-x | -u -i (-n -d) ユーザー・マッピング ID を除去します。 -n および -d フラグが指定されている場合、その ID マッピングのみがユーザー・マッピング ID から除去されます。 -g -i (-n -d) グループ・マッピング ID を除去します。 -n および -d フラグが指定されている場合、その ID マッピングのみがグループ・マッピング ID から除去されます。 -r -d レルム・ドメイン間マッピングを除去します。
-l | すべてのレルム・ドメイン間マッピングをリストします。 -u -i 指定されたユーザー・マッピング ID に関連したすべての ID マッピングを リストします。 -g -i 指定されたグループ・マッピング ID に関連したすべての ID マッピングを リストします。
-s | -u -n -d 指定された ID マッピングに関連したユーザー・マッピング ID を 検索します。 -g -n -d 指定された ID マッピングに関連したグループ・マッピング ID を 検索します。
-C | すべての EIM LDAP サーバー・エントリーを、構成ファイルから除去します。

例
NFS に対する現行 EIM 構成を表示するには、次のコマンドを使用します。
chnfsim -c
NFS 外部 ID マッピングに対して EIM を使用するようにシステムを構成するには、次のコマンドを使用します。
chnfsim -c -a -t P -h foos.com -e nfs -f nfseim -w mypasswd -W access_passwd
注:
指定された
hostname
がローカル・システムの場合、
chnfsim
コマンドは、EIM を実行するための LDAP サーバーもセットアップします。
NFS 外部 ID マッピングに対して EIM を使用するようにクライアント・システムを構成するには、
次のコマンドを使用します。
chnfsim -c -a -t P -h foos.com -e nfs -f nfseim -W access_passwd
注:
これにより、1 次 LDAP サーバーを使用してクライアントが構成されます (読み取り専用アクセス用)。 ここで指定したホスト名は、ローカル・システムではありません。
構成ファイルから、サーバー構成の詳しいリストを作成するには、次のコマンドを使用します。
chnfsim -c -l -h foos.com:1080
構成ファイルからサーバー構成の詳細を削除するには、次のコマンドを使用します。
chnfsim -c -x -h foos.com:1080
「John Doe」が「jdoe@com.com」であると指定するユーザー ID マッピングを追加するには、次のコマンドを使用します。
chnfsim -a -u -i "John Doe" -n jdoe -d com.com
注:
このコマンドは、「John Doe」の EIM ID を作成します (まだ存在していない場合)。
「John Doe」が「jdoe@com.com」であると指定するユーザー ID マッピングを除去するには、次のコマンドを使用します。
chnfsim -x -u -i "John Doe" -n jdoe -d com.com
ユーザー「John Doe」のすべての ID マッピングを除去する場合は、次のコマンドを使用します。
chnfsim -x -u -i "John Doe"
ユーザー「John Doe」のすべての ID マッピングをリストする場合は、次のコマンドを使用します。
chnfsim -l -u -i "John Doe"

「realm1」が「domain1」にマップすることを指定するレルム・ドメイン間マッピングを追加する
場合は、次のコマンドを使用します。
chnfsim -a -r realm1 -d domain1
「realm1」が「domain1」にマップすることを指定するレルム・ドメイン間マッピングを除去する
場合は、次のコマンドを使用します。
chnfsim -x -r realm1 -d domain1
すべてのレルム・ドメイン間マッピングをリストする場合は、次のコマンドを使用します。
chnfsim -l
「jdoe@com.com」に関連するユーザー・マッピング ID を検索するには、次のコマンドを使用します。
chnfsim -s -u -n jdoe -d com.com
システムからすべての EIM 構成を除去するには、次のコマンドを使用します。
chnfsim -C
注:
これによって、基礎となる LDAP データベースまたはエントリーが削除されることはありません。
