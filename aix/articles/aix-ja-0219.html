目的
ypinit
コマンドを再実行してコントローラー・サーバーからマップを取得し、
ypserv
デーモンを再始動してワーカー・サーバーを変更します。

説明
chslave
コマンドは、コマンド・ラインで指定されたコントローラー・サーバーからマップを取得するために
ypinit
コマンドを再度呼び出します。
ypserv
デーモンは、
ypinit
コマンドが正常に完了した後で再始動されます。
Master
パラメーターは、コントローラー・サーバーのホスト名を指定します。 指定されたコントローラー・サーバーは、現在使用中のコントローラー・サーバーであっても、構成済みで稼働中の新規コントローラー・サーバーであってもかまいません。
このコマンドは、System Management Interface Tool (SMIT)
smit chslave
高速パスを使用しても実行できます。

構文
/usr/etc/yp/chslave [ -C | 「-c」 ] [ -O (O) | - ] [ -I (I) | -B | -N (N) ] マスター

オプション
フラグ
項目 | 説明
-B | ypinit コマンドを呼び出し、 ypserv デーモンを始動します。 ypserv デーモンが既に動作中のときにこのフラグを指定すると、 ypinit コマンドはデーモンを抹消し、再始動します。 このフラグはデフォルトです。
-C | -n フラグを指定して ypinit コマンドを呼び出します。 chslave コマンドはエラーが発生しても処理を続行します。 このフラグはデフォルトです。
-c | エラーが発生すると、実行を停止します。
-I | ypinit コマンドをただちに実行しますが、 ypserv デーモンの始動または再始動は行いません。
-O | ドメインに存在するマップを上書きします。
-o | ドメインに存在するマップの上書きを禁止します。 このフラグはデフォルトです。
-N | ypinit コマンドを呼び出し、 ypserv デーモンを再始動します。

例
以下の名前のコントローラー・サーバーからマップを取得します。
host91
次のように入力します。
chslave -O -B host91
これにより、現行ドメインの既存のマップはすべて上書きされます。
