目的
C ソース・コードを読みやすいフォーマットにします。

説明
cb
コマンドは、標準入力または指定したファイルから C プログラムを読み取り、インデントとスペースを使用してコードの構造を示すフォーマットで標準出力にそのプログラムを書き込みます。 フラグを指定しないで呼び出すと、
cb
コマンドは、行の分割や結合を実行しません。 プリプロセッサー・ステートメントに句読点があるとインデント・エラーになることがあります。
最良の結果を得るために、構文的に正しいソース・コードでこのコマンドを使用してください。

構文
cb [ -s ] [ -l 長さ | -j ] [ File ...]

オプション
フラグ
項目 | 説明
-j | 分割された行を結合します。 -l フラグを指定すると無視されます。
-l 長さ | 文字数が Length より長い行を分割します。
-s | The C Programming Language にある Kernighan とリッチーのスタイルに従ってソース・コードをフォーマット設定します (Englewood Cli項式、ニュージャージー州: Prentice-Hall, Inc.)。 1978).

例
バージョンを作成するには
pgm.c
CALLED
pgm.pretty.c
これは読みやすいので、次のように入力します。
cb pgm.c > pgm.pretty.c
