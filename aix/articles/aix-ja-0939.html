目的
指定された CPU およびメモリー領域を含む rset を作成し、この rset をシステム・レジストリーに入れます。

説明
mkrset
コマンドは、CPU および/またはメモリー領域の指定のセットを持つ rset または排他的 rset (xrset) を作成して、システム・レジストリーに入れます。 rset 名はレジストリー内に存在しないものにしてください。 rset のオーナー ID およびグループ ID は、
コマンド発行者のオーナー ID およびグループ ID に設定されます。 rset に関して、オーナーは読み取り/書き込み許可、グループとその他のユーザーは読み取り許可が与えられます。
mkrset
コマンドを使用して xrset を作成すると、システム上の対応する CPU の状態が排他モードに変更されます。 xrset の作成には root 権限が必要です。

構文
mkrset -c CPUlist [ -m MEMlist ] rsetname

オプション
フラグ
項目 | 説明
-c | rset に含める CPU のリスト。 これは、1 つ以上の CPU または CPU 範囲にすることができます。
-m | rset に含めるメモリー領域のリスト。 これは、1 つ以上のメモリー領域または範囲にすることができます。

例
CPU 0 から 7 が含まれ、
名前が
test/cpus0to7
の
rset
を作成するには、次のように入力します。
mkrset -c 0-7 test/cpus0to7
CPU 1、3、5、6、7、10 が含まれ、
名前が
test/lotsofcpus
の
rset
を作成するには、
次のように入力します。
mkrset -c 1 3 5-7 10 test/lotsofcpus
