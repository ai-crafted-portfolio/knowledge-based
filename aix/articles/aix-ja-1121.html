目的
要求スクリプトへの応答を保管します。

説明
pkgask
を使用すると、管理者は、
対話式パッケージ (要求スクリプトを含むもの) またはパッケージのセットへの応答を保管することができます。 セットはセット・インストール・パッケージ (SIP) と呼ばれる特殊目的のパッケージと、
そのセットのメンバーである 1 つまたは複数のパッケージのコレクションからなります。 SIP はセットのインストールを制御します。
pkgask
を起動すると、
インストール時に入力として使用される
Response
ファイルが生成されます。 この
応答
ファイルを使用すると、パッケージに必要な情報が既に含まれているため、インストール中に対話が行われなくなります。
pkgask
を実行すると、応答ファイルと以下のディレクトリーが作成されます。
項目 | 説明
/ptfvars | このディレクトリーには、パッケージに関連する変数が含まれています。
/fileinfo | パッケージに関するチェックサム情報が含まれます。
/oldfiles | 以前のバージョンのパッケージのバックアップが含まれます。
非対話式で他のシステムにパッケージをインストールするためには、
これらのすべてのファイルおよびディレクトリーをターゲット・システムにコピーしなければなりません。
注:
これらのディレクトリーのいずれかを上書きする場合 (例えば、別のパッケージを非対話式にインストールする場合)、最初に元のディレクトリーの内容を復元しない限り、最初のパッケージを正常に削除することはできません。
-r
フラグを使用して、ディレクトリー名とファイル名を示すことができます。 ディレクトリー名は、多数の
応答
ファイルを作成するために使用されます。各ファイルは、関連付ける必要があるパッケージの名前を共有します。 この方法は、例えば、
pkgadd
を 1 回起動するだけで複数の対話式パッケージを追加できるようにしたい
場合などに使用できます。 それぞれのパッケージに
Response
ファイルが必要です。 パッケージ・インスタンスと同じ名前の複数の応答ファイルを作成するには、ファイルを作成するディレクトリーに名前を付け、
pkgask
コマンドで複数のインスタンス名を指定します。 パッケージをインストールするときには、
このディレクトリーを
pkgadd
コマンドで指定できます。

構文
pkgask [ -d Device] -r Response [ Pkginst [ Pkginst [. . .]]

オプション
フラグ
表 1. フラグ
項目 | 説明
-d Device | Device でパッケージの要求スクリプトを実行します。 Device は、ディレクトリー ( /var/tmp など) への絶対パス名、または標準入力から読み取られるデータ・ストリーム形式のパッケージを指定する - にすることができます。 デフォルト・デバイスはインストール先のスプール・ディレクトリー ( /var/spool/pkg ) です。
-r 応答 | ファイルまたはディレクトリー Response を識別します。これは、パッケージ要求スクリプトとの対話に対する応答を格納するために作成する必要があります。 このファイル、またはファイルのディレクトリーは、後で pkgadd コマンドへの 入力として使用できます ( pkgadd コマンドを参照してください)。 Pkginst がパッケージである場合、 Response には 絶対パス名またはディレクトリーを指定することができ、 Pkginst が SIP である場合、 Response にはディレクトリーを指定しなければなりません。

プッギンスト | 省略されたパッケージ名またはセット名を指定するために使用される短いストリングを定義します。 ( package instance という用語は大まかに使用されます。インスタンス ID が含まれていないものも含め、 Pkginst のすべてのインスタンス化を指します。) パッケージ名の省略形を作成するには、 PKG パラメーターを使用してそれを割り当てます。 例えば、省略形 cmds を拡張コマンド・パッケージに割り当てるには、 PKG=cmds と入力します。 Pkginst で SIP が指定されている場合、そのセットのメンバーであるパッケージのすべての要求スクリプトが実行され (存在する場合)、結果の応答ファイルは -r フラグに指定されたディレクトリーに配置されます。 パッケージのすべてのインスタンスを示すには、「 Pkginst .* 」を指定し、示されているようにコマンド行を単一引用符で囲み、シェルが * 文字を解釈しないようにします。 ソース・メディアで使用可能なすべてのパッケージを参照するには、トークン all を使用します。 注: コマンド・ラインで Pkginst を指定せずに呼び出すと、デバイス上に少なくとも 1 つの SIP が存在する場合、 pkgask はセットの名前を表示します。 したがって、セットのメンバーではないパッケージがある場合、それらのパッケージを参照できるのは、それらの Pkginst 名がコマンド行に指定されている場合に限られます。
