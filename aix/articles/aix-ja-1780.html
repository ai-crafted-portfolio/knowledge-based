目的
X-Window のフォント・リストを表示します。

説明
xlsfonts
コマンドは、指定した
Pattern
パラメーターと一致するフォントをリストします。 ワイルドカード文字「*」(アスタリスク) を使用すると、任意の文字シーケンス (「なし」を含む) および「?」に一致します。 (疑問符) は、任意の単一文字と一致します。 パターンを指定しなければ、"*" が想定されます。
“
注:
「*」および「?」 文字は、シェルによって拡張されないように、引用符で囲む必要があります。
”
フラグを使用すると、サーバー、出力する桁数と幅、フォント・リストのサイズ、
出力をソートするかどうか、および
ListFonts
の代わりに
OpenFont
を使用するかどうかを指定することができます。

構文
xlsfonts [ -表示 ホスト : 表示 ] [ -L [ L [ L ] ] ] [ -m (M) ] [ -C ] [ -1 ] [ -w (W) 幅 ] [ N カラム ] [ -ウー ] [ - ] [ -フーン パターン ]

オプション
フラグ
“
注:
xlsfonts
コマンドの
-
(小文字の L) フラグを使用すると、サーバーが長時間拘束される可能性があります。 これは、単一スレッドの非占有サーバーに典型的なものであり、プログラム・エラーではありません。
”
項目 | 説明
-1 | リストが単一の桁を使用することを示します。 このフラグは -n 1 フラグと同じです。
-C | リストに複数桁を使用することを示します。 このフラグは -n 0 フラグと同じです。
-表示 ホスト : 表示 | ホスト名とディスプレイ番号を指定して、接続する X サーバーを識別します。
-フーン パターン | xlsfonts がリストするフォント名 パターン を指定します。
- [ L [ L ] ] | (L の小文字) それぞれ、フォントごとに中程度の長さのリスト、長いリスト、および極端に長いリストが生成されることを示します。
-m | 長いリストに、フォントごとの最小および最大限界数も出力されることを示します。
N カラム | 出力表示に使用する桁数を指定します。 デフォルトでは、 xlsfonts コマンドは -w Width フラグで指定した文字数に納まる桁数でフォント名を表示しようとします。
-o | xlsfonts コマンドに対して、 ListFonts の代わりに OpenFont (および、適切であれば QueryFont ) を実行するように命令します。 -o フラグは、一部のスケール付きフォント・システムの場合と同様に、定義済みフォントを ListFonts または ListFontsWithInfo でリストできない場合に便利です。
-u | 出力をソートしないことを示します。
-w 幅 | 何桁表示するかを決めるのに使用する幅を文字数で指定します。 デフォルトは 79 です。

例
各フォントの中規模のリストを指定するには、小文字の L を使用して、次のように入力します。
xlsfonts -l
各フォントの 3 列のリストを指定するには、次のように入力します。
xlsfonts -n 3
名前の中にストリング iso8859 を含むすべてのフォントを表示するには、次のように入力します。
xlsfonts -ll "*"iso8859"*"
すべてのフォントをリストするには、 rom1 と、それに続く 1 文字を名前に付けて、次のように入力します。
xlsfonts rom1"?"
このコマンドにより、下記のようなリストが表示されます。
rom10 rom11 rom14 rom16 rom17
