目的
セキュリティー・モードと鍵タイプを変更し、指定されたモードへの移行を開始します。

説明
chsecmode
コマンドは、Reliable Scalable Cluster Technology (RSCT) セキュリティー・コンプライアンス・モードを
nist_sp800_131a
モードに設定します。 公開鍵と秘密鍵の新しい生成方式、メッセージ署名用の対称鍵、および検査も指定できます。 NIST コンプライアンス・モードも、このモードを none として渡すことによってオフに設定できます。
鍵生成方式が指定されていない場合、モードが、指定された新規コンプライアンス・モードに準拠している場合でも、現行方式は変更されません。 鍵生成方式が準拠状態でない場合、
nist_sp800_131a
モードでは
rsa2048_sha256
方式が使用され、none モードでは
rsa512
方式が使用されます。
対称鍵タイプがデフォルトである場合、実際の鍵タイプは、指定されたコンプライアンス・モードに合わせて RSCT によって内部で選択されます。
nist_sp800_131a
モードでは、デフォルトの対称鍵タイプとして
aes256_sha256
鍵が使用されます。 コンプライアンス・モードがオフになっている場合、状況に基づいて適切な対称鍵タイプが選択されます。

構文
ChsecMode 「-c」 モード [ -m (M) 方法 ] [ -s タイプ ] [ 「-f」 ] [ -x (X) ] [ -h ]

オプション
フラグ
項目 | 説明
-c モード | セキュリティー・コンプライアンス・モードを指定します。 有効なモードは nist_sp800_131a と none です。
-f | 鍵生成方式が変更されていない場合でも新しい鍵を生成します。
-h | chsecmode コマンドの使用状況の情報を表示します。
-m メソッド | 適切なタイプ (ノードの公開鍵または秘密鍵の生成に使用されているコンプライアンス・モードで有効なタイプ) を指定します。 nist_sp800_131a モードの場合、有効な鍵生成方式として以下がリストされます。 rsa2048_sha256 rsa2048_sha512 rsa3072_sha256 rsa3072_sha512 非 NIST コンプライアンス・モード none では、サポートされている鍵生成方式はすべて ( rsa512 方式と rsa1024 方式を含む) 有効です。
-s タイプ | クラスターのデフォルトの対称鍵タイプを指定します。 nist_sp800_131a モードでは、以下の対称鍵タイプが有効です。 aes128_sha256 aes128_sha512 aes256_sha256 aes256_sha512 非 NIST コンプライアンス・モード none では、以下を含め、サポートされている対称鍵タイプはすべて有効です。 aes128_md5 aes256_md5 3des_md5 des_md5
-x | 保留中の操作が強制的に上書きされるようにします。 保留中の変更が存在し、 -x オプションが指定されていない場合、 chsecmode コマンドは、セキュリティー構成の変更に使用されている場合は失敗します。

例
準拠状態の鍵生成方式および対称鍵タイプを使用して NIST コンプライアンス・モードを有効にするには、次のように入力します。
chsecmode -c nist_sp800_131a
現行方式および対称鍵タイプは、準拠状態である場合は変更されません。 現行方式とタイプが準拠状態でない場合、値として、鍵生成方式には
rsa2048_sha256
モードが、対称鍵タイプには
aes256_sha256
モードが使用されます。
rsa2048_sha512
鍵生成方式を使用して NIST コンプライアンス・モードを有効にするには、次のように入力します。
chsecmode -c nist_sp800_131a -m rsa2048_sha512
現在の対称鍵が既に準拠状態である場合、この対称鍵は変更されません。 現在の対称鍵が準拠状態ではない場合、この対称鍵は
aes256_sha256
鍵に置き換えられます。
rsa2048_sha512
鍵生成方式および
aes128_sha512
対称鍵を使用して NIST コンプライアンス・モードを有効にするには、次のように入力します。
chsecmode -c nist_sp800_131a -m rsa2048_sha512 -s aes128_sha512
NIST コンプライアンス・モードを無効にするには、次のように入力します。
chsecmode -c none
現在の鍵生成方式と対称鍵タイプは変更されません。
rsa512 鍵生成方式を使用して公開鍵と秘密鍵を生成するには、次のように入力します。
chsecmode -m rsa512
現在のコンプライアンス・モードが
nist_sp800_131a
の場合、この操作は拒否されます。 現在のコンプライアンス・モードが none であり、現在の鍵生成方式が
rsa512
ではない場合、現在の鍵生成方式は
rsa512
に置き換えられ、新しい秘密鍵と公開鍵のペアが生成されます。
鍵生成方式が変更されていない場合でも強制的に公開鍵と秘密鍵が生成されるようにするには、次のように入力します。
chsecmode -m rsa512 -f
現在のコンプライアンス・モードが
nist_sp800_131a
の場合、この操作は拒否されます。 現在のコンプライアンス・モードが none であり、現在の鍵生成方式が
rsa512
方式に置き換えられた場合、現在の公開鍵または秘密鍵が既に
rsa512
方式になっている場合でも、新しい秘密鍵と公開鍵のペアが生成されます。

保留中の操作を上書きまたは取り消すには、次のように入力します。
chsecmode -x -c nist_sp800_131a
保留中のコンプライアンス・モードが存在する場合、保留中の操作は無視され、
nist_sp800_131a
モードへの新たなコンプライアンス・モード変更が開始されます。
