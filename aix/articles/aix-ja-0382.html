目的
DOS
ファイルをコピーします。

説明
dosread
コマンドは、
File1
変数で指定された
DOS
ファイルを標準出力、または
File2
変数で指定されたファイルにコピーします。
File2
変数にパス名が指定されていない場合、
DOS
ファイルはルート・ディレクトリーにコピーされます。
特に指定がなければ、
dosread
コマンドは、
File1
のディレクトリー・エントリーに指定されたバイト数をコピーします。 つまり、規則ではディレクトリーのレコード・サイズが 0 になっているので、特にディレクトリーのコピーは機能しません。
DOS
のファイル命名規則を使用できますが、¥ (円記号) は例外です。
DOS
では ¥ 文字は特別な意味を持つ可能性があるため、
DOS
パス名でサブディレクトリー名を指定する場合は、/(スラッシュ) 文字を区切り文字として使用します。
dosdir
コマンドは、ディスクを検査する前に、ファイルまたはディレクトリー名の小文字を大文字に変換します。 ファイル名はすべて絶対パス名 (相対パス名ではない) と見なされるので、
最初の / (スラッシュ) は付ける必要はありません。
注:
dosread
コマンドは、* および ? (アスタリスクと疑問符) ワイルドカード文字を、特殊な意味を持つものと解釈しません。 ファイル名の拡張子を指定しないと、ブランクの拡張子を指定した場合と同様にファイル名の照合が行われます。
このコマンドの名前をカスタマイズすることはできません。 このコマンドは必ず
dosread
という名前でなければなりません。
dosread
コマンドは、
DOS
ディスケットが入っているデフォルト・ドライブからファイルを読み取ります。 次に、
dosread
コマンドは、そのファイルを現行ディレクトリーに、
このオペレーティング・システムが認識するファイルとしてコピーします。
DOS
ディスケットにサブディレクトリーが含まれている場合、
dosread
コマンドは、このオペレーティング・システムに対応する新しいサブディレクトリーを作成しません。 サブディレクトリーを作成し、新しいサブディレクトリーにコピーする各
DOS
ファイルを指定する必要があります。

構文
dosread [ -a ] [ -v ] [ -D デバイス ] File1 [ File2 ]

オプション
フラグ
項目 | 説明
-a | 各 CR-LF (復帰、改行) キー・シーケンスを改行文字に置き換え、Ctrl-Z (ASCII SUB) キー・シーケンスを 行の終わりの文字として解釈します。
-D デバイス | DOS デバイスの名前を /dev/fd0 または /dev/fd1 として指定します。 デバイス 変数のデフォルト値は /dev/fd0 です。 このデバイスは、 DOS ディスク・フォーマットでなければなりません。
-v | ディスクのフォーマットに関するファイル情報を、標準出力します。 デバイスが DOS ディスクであることを確認するには、このフラグを使用します。

例
DOS
からテキスト・ファイルをコピーするには、次のように入力します。
dosread
-a
chap1.doc chap1
このコマンド・シーケンスは、
DOS
テキスト・ファイルをコピーします。
\CHAP1.DOC
デフォルト装置
/dev/fd0
上の
chap1
現行ディレクトリーにあります。
DOS
ディスケットからバイナリー・ファイルをコピーするには、次のように入力します。
dosread -D/dev/fd1 /survey/test.dta /home/fran/testdata
このコマンド・シーケンスは、
DOS
データ・ファイルをコピーします。
\SURVEY\TEST.DTA
/dev/fd1
から
/home/fran/testdata
.
ディスケット上のすべての
DOS
ファイルをコピーするには、次のように入力します。
dosdir | awk '!/There are/ {print $1}'|xargs -t -i dosread {} {}
このコマンド・シーケンスは、
DOS
ディスクを含むデフォルト・ドライブからファイルを取得し、それらを現行ディレクトリーにコピーします。
