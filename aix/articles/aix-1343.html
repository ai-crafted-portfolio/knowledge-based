目的

これは、指定のサーバーとユーザーのエントリーについて /etc/smbcred ファイルに格納されている Server Message Block (SMB) クライアント・ファイルシステム資格情報を削除します。

構文

rmsmbcred -s server_name -u user_name

説明

rmsmbcred コマンドでサーバー名とユーザー名を指定する必要があります。 指定したサーバーとユーザーのエントリーが、/etc/smbcred ファイルにリストされている資格情報で見つかる場合は、対応する資格情報エントリーが削除されます。 資格情報エントリーが削除された後で、指定のユーザーについて指定のサーバーで SMB クライアント・ファイルシステムをマウントする場合は、指定のサーバーにおけるパスワードを手動で指定する必要があります。

フラグ

-s サーバー名
これは、リモート・ホスト (SMB サーバー) の名前を指定します。 ホスト名、IP アドレス、または完全修飾ドメイン・ネームとして server_name パラメーターを指定できます。
-u ユーザー名
これは、/etc/smbcred ファイルから削除しなければならない資格情報に対応するユーザー名を指定します。

終了状況

0
コマンドは正常に完了しました。
>0
エラーが発生しました。

例

user1 が xxx.in.ibm.com サーバーに SMB クライアント・ファイルシステムをマウントするために、 /etc/smbcred ファイルに保管されている資格情報を除去するには、次のコマンドを入力します。
rmsmbcred -s xxx.in.ibm.com -u user1

場所

/usr/sbin/rmsmbcred

ファイル

/etc/smbcred
ここに SMB クライアント・ファイルシステムの資格情報が格納されます。
