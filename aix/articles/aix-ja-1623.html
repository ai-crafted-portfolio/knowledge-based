目的
順序付きの対の順不同リストをソートします (トポロジカル・ソート)。

説明
tsort
コマンドは、
File
または標準入力から順序付けられた組の順不同リストを読み取り、完全な順序付けられたリストを構築して標準出力に書き出します。
入力
File
には、ブランクで区切られた空でない文字列の組が入っていなければなりません。 異なる項目の組は相対順序を示します。 同じ項目の組は、存在するものの相対順序ではないことを示します。
tsort
コマンドを使用すると、
lorder
コマンドの出力をソートできます。
File
に奇数のフィールドがあると、
該当するエラー・メッセージが表示されます。

構文
tsort [ - ] [ ファイル ]

オプション
フラグ
項目 | 説明
— | (二重ハイフン) — フラグに続くすべての引数をファイル名として解釈します。 ファイル名が —である場合、tsort — — を使用してください。
