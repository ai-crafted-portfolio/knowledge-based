目的
コマンドの実行時間を出力します。

説明
time
コマンドは、コマンドの実行中の経過時間、システム時間、
time
コマンドの実行時間を秒単位で標準エラーに表示します。
“
注:
スリープ時間は、システム時間にもユーザー時間にも課金されません。
”
time
コマンドは、異なるフォーマットで C シェル (
csh
) と Korn シェル (
ksh
) にも組み込まれています。
csh
シェルと
ksh
シェル内で
time
コマンドを実行するには、以下のように入力します。
/usr/bin/time

構文
time [ -p ] コマンド [ 引数 ...]

オプション
フラグ
項目 | 説明
-p | タイミング出力を標準エラーに書き出します。 秒数は、小数点以下の桁数が 1 桁以上の浮動小数点数として表されます。 このフラグの標準フォーマットは以下のとおりです。 "real %f\nuser %f\nsys %f\n", <real seconds>, <user seconds>, <system seconds>

例
プログラムの実行に必要な時間を測定するには、次のように入力します。
/usr/bin/time -p a.out
このコマンドはプログラム
a.out
を実行し、リアルタイム、ユーザー時間、システム時間の合計を、以下のように
-p
フラグで指定されたフォーマットで標準エラーに書き出します。
real 10.5
user 0.3
sys 3.6
time
コマンド情報のレコードをファイルに保管するには、次のように入力します。
/usr/bin/time a.out 2> a.time
