目的

システム上の現行シグニチャー・ファイルの照会または変更を許可します。

構文

システム上の現行エディションをリストするには、以下のように入力します。
chedition -l
standard エディションに変更するには、以下のようにします。
chedition -s  [-d Device  [ -p ]]
enterprise エディションに変更するには、以下のようにします。
chedition -e  [-d Device  [ -p ]]
private_cloud エディションに変更するには、以下のようにします。
chedition -c  [-d Device  [ -p ]]

説明

chedition コマンドは、システムの現行エディションを照会するために使用できます。 システムのエディション (標準、エンタープライズ、または private_cloud のいずれか) が表示されます。 お客様が変更したい新規エディションを指定することにより、エディションを変更することもできます。 /usr/sys/inst.data/sys_bundles に新規エディションのバンドル・ファイルがある場合は、インストールするイメージを含むデバイスまたはディレクトリーを指定するとそのファイルがインストールされます。 エディションを変更すると、/usr/lib/bos/swidtag ディレクトリーにあるシグニチャー・ファイルが変更されます。 インストールされている AIX® オペレーティング・システムのレベルに応じて、以前の場所は /usr/lpp/bos/iso-swid、 /usr/lpp/bos/properties/version、および /usr/lpp/bosでした。

最近のサービス・パックまたはテクノロジー・レベルからアップグレードを行うと、chedition コマンドは機能しない場合があります。 エディション・シグニチャー・ファイル名に変更がある場合は、システム上のエディションを変更することができます。 standard、 enterprise、または private_cloudのいずれかのエディションを選択できます。 新しいシグニチャー・ファイルは、bos.rte アップデートに付属しています。 最新のシグニチャー・ファイルは、すべてのソフトウェアが新しいサービス・パックまたはテクノロジー・レベルになった後で入手可能になります。

最近のサービス・パックまたはテクノロジー・レベルから bos.rte.install のアップグレードのみを行うと、chedition コマンドは、システム上のエディションを変更しようとしても機能しない場合があります。 これは、エディション・シグニチャー・ファイル名に変更がある場合に発生する可能性があります。 新しいシグニチャー・ファイルは、bos.rte アップデートに付属しています。 すべてのソフトウェアが新しいサービス・パックまたはテクノロジー・レベルになると、最新のシグニチャー・ファイルが入手可能になります。

フラグ

項目
説明
-d Device または Directory インストールするイメージを含むデバイスまたはディレクトリーを指定します。
-e enterprise エディションに変更する場合に使用します。
-l システムの現行エディションをリストします。 システムのエディション (Express、Standard、または Enterprise) が表示されます。
-p すべてのプリインストール検査を実行することにより、バンドル・ファイル・インストールのプレビューを実行します。 システムのエディションは更新されません。
-s standard エディションに変更する場合に使用します。
-c private_cloud エディションに変更する場合に使用します。

例

  1. システム上の現行エディションをリストするには、以下のように入力します。
    chedition –l

    次のいずれかの出力が戻されます。

    standard | enterprise | private_cloud
  2. Standard Edition に変更するには、次のように入力します。
     chedition –s
  3. enterprise エディションに変更し、Enterprise Edition バンドル・ファイルが存在する場合にその内容のプレビュー・インストールを実行するには、次のように入力します。
    chedition –e –d /usr/sys/inst.images -p

項目
説明
/usr/sbin/chedition chedition コマンドが入っています。
