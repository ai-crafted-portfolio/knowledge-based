目的

DOS ファイルを削除します。

構文

dosdel [ -v ] [ -D Device ] ファイル ...

説明

dosdel コマンドは、 File パラメーターで指定された DOS ファイルを削除します。 ディスクに関するフォーマット情報を取得するには、 -v フラグを使用します。

DOS のファイル命名規則は、1 つの例外を除いて使用されます。 ¥ (円記号) 文字はオペレーティング・システムにとって特別な意味を持つ可能性があるため、 DOS パス名でサブディレクトリー名を指定する場合は、/(スラッシュ) 文字を区切り文字として使用してください。 dosdel コマンドは、ディスクを検査する前に、ファイルまたはディレクトリー名の小文字を大文字に変換します。 ファイル名はすべて絶対パス名 (相対パス名ではない) と見なされるので、 最初の / (スラッシュ) は付ける必要はありません。

フラグ

項目
説明
-Dデバイス DOS デバイスの名前を /dev/fd0 または /dev/fd1として指定します。 デフォルト・デバイスは /dev/fd0 です。
-v ディスクのフォーマットに関する情報を、標準出力します。 デバイスが DOS ディスクであることを確認するには、このフラグを使用します。

例

デフォルト・デバイス上の DOS ファイルを削除するには、次のように入力します。

dosdel file.ext
