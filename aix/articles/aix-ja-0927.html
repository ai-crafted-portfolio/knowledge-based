目的
拡張アカウンティング・サブシステム
・データを処理するための LDAP クライアントおよびサーバー・マシンを構成します。

説明
mkprojldap
コマンドは、
拡張アカウンティング・サブシステム
・データを処理するための LDAP サーバーおよびクライアント・マシンを構成します。 LDAP サーバーとクライアントの関係が既に定義されている必要があり、
mkprojldap
は増分変更のみを行います。
mkprojldap
コマンドを使用して、基本 LDAP 接続を構成できます。
LDAP サーバーに
拡張アカウンティング
・サポートを追加するには、
拡張アカウンティング
の LDAP スキーマをサーバーにアップロードする必要があります。 スキーマは、サーバーに対する
拡張アカウンティング
・データの形式を記述します。これにより、サーバーはアカウンティング専用に使用可能にすることなく、アカウンティング・データを処理することができます。 これを行うには、
-u
オプションを使用します。 LDAP サーバーは
拡張アカウンティング
に依存しません。 このコマンドは、それぞれの LDAP サーバーごとに 1 回だけ実行することが必要です。 このコマンドを実行した後、
-s
オプションを使用して、
拡張アカウンティング
・データを保管する LDAP サーバー上の場所を定義します。 1 つ以上のアカウンティング・ドメインを設定するために、このコマンドを 1 回以上実行することができます。 LDAP クライアントでは、同時にただ 1 つのアカウンティング・ドメインにアクセスできるに過ぎません。
拡張アカウンティング
・データを受信するように LDAP クライアントを構成するには、
-c
・オプションを使用して、LDAP クライアントが使用する LDAP サーバー上の
拡張アカウンティング
・データ・セットの場所を指定します。
mkprojldap
コマンドを使用して、プロジェクトおよび管理ポリシーへの絶対パス (
識別名
(DN) と呼ばれる) を構成します。
拡張アカウンティング・サブシステム
は、プロジェクト定義と管理ポリシーを LDAP サーバーに保管するため、構成可能な
拡張アカウンティング
DN は 2 つあります。
mkprojldap -c
コマンドは、各クライアントで実行する必要があります。

構文
mkprojldap -s -h ホスト名 -D bindDN -w bindPWD -i -p projectInstallPoint -a adminInstallPoint mkprojldap -u -h ホスト名 -D bindDN -w bindPWD mkprojldap ' -c ' -D bindDN ' -w bindPWD [ ' -p accountingProjectDN ] [ ' -a accountingAdminDN ] [ ' -r cron ] mkprojldap { -l | -L [ -D バインド DN -w BindPWD ] | -V } [ -p ] [ -a ]

オプション
フラグ
項目 | 説明
-a accountingAdminDN | -s または -c オプションとともに使用する場合、LDAP サーバー上のアカウンティング管理 DN ロケーションを指定します。 -l または -L オプションと一緒に使用すると、このフラグはアカウンティング管理 DN を表示します。
-c | LDAP クライアントを構成します。
-D bindDN | サーバーの構成時に使用されるバインド DN を指定します。
-h ホスト名 | サーバーの構成時に LDAP サーバーのホスト名を指定します。
-i | サーバー構成時に管理者 ( -a ) およびプロジェクト ( -p ) のインストール・ポイントを提供します。
-L | このサーバーから認識できるアカウンティング DN となる可能性のある DN を表示 します。
-l | ldap.cfg ファイル内のアカウンティング DN を表示します。
-p accountingProjectDN | -s オプションまたは -c オプションを指定して使用する場合に、LDAP サーバー上のアカウンティング・プロジェクト DN ロケーションを指定します。 このフラグを -l または -L オプションと一緒に使用すると、アカウンティング・プロジェクト DN が表示されます。
-r コン | LDAP リポジトリーをリフレッシュする頻度 (毎時、毎日、またはオフ) を指定します。
-s | LDAP サーバーを構成します。
-u | 拡張アカウンティング ・スキーマを LDAP サーバーにアップロードします。
-V | コロンで区切られた形式で、現行の LDAP クライアント構成の詳細を表示します。
-w bindPWD | -D オプションで指定されたバインド DN のバインド・パスワードを指定するために使用されます。
注:
このコマンドで上記のフラグを使用する場合は、以下のガイドラインを使用してください。
サーバーとクライアントの構成時に、
-p
引数と
-a
引数の両方を同時に指定できますが、どちらも指定する必要はありません。 どちらも指定されていない場合、
mkprojldap
コマンドは、LDAP サーバー上のオブジェクトを検索することによって、欠落しているアカウンティング DN を計算しようとします。 これらのオブジェクトは、
ou=projects
および
ou=adminpolicy
です。 オブジェクトが見つかると、対応するアカウンティング DN が計算され、
ldap.cfg

ファイルに追加されます。
-l
または
-L
オプションを使用してアカウンティング DN をリストするときには、
-p
と
-a
の両方を使用できます。 どちらも指定しない場合は、
ldap.cfg
ファイル内のすべてのアカウンティング DN がリストされます。
-V
オプションによって表示されるコロン区切りデータの形式は、以下のとおりです。
ldap-server-hostname:bind DN:bind password:default-projectdn:default-admindn:cron

例
拡張アカウンティング
・スキーマをアップロードするには、次のように入力します。
mkprojldap -u -h mozilla -D cn=root -w mozillapasswd
LDAP サーバーを構成するには、次のように入力します。
mkprojldap -s -h ldap.svr.com -D cn=root -w passwd -i
-p cn=aixdata,o=ibm -a cn=aixdata,o=ibm
このコマンドにより、以下の形式で 2 つの DN が作成されます。
ou=projects,ou=aacct,cn=aixdata,o=ibm and ou=adminpolicy,ou=aacct,cn=aixdata,o=ibm
LDAP クライアントを構成するには、次のように入力します。
mkprojldap -c -D cn=testroot -w testpwd -p ou=projects,ou=aacct,ou=cluster1,cn=aixdata -a
ou=adminpolicy,ou=aacct,ou=cluster1,cn=aixdata -r hourly
現在構成されているアカウンティング DN を表示するには、次のように入力します。
mkprojldap -l
