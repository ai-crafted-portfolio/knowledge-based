目的
自動マウント・ポイントをマウントします。

説明
automount
コマンドは、
AutoFS
の管理ツールとして使用されます。 それは
AutoFS
マウント・ポイントをインストールし、
automount
マップを各マウント・ポイントに関連付けます。
AutoFS
ファイル・システムは、その中のディレクトリーへのアクセスをモニターし、
automountd
デーモンに通知します。 デーモンはマップを使用してファイル・システムを見つけ、それを
AutoFS
ファイル・システム内の参照点にマウントします。
以前の
automount
の動作では、
automount
コマンドを実行する前に、
COMPAT_AUTOMOUNT
環境変数が任意の値に設定されているかどうかを指定できます。 現在の動作は、
AIX
5.00でデフォルトの動作となった。
ファイル・システムが適切な間隔 (デフォルトでは 10 分) 内にアクセスされない場合、
automountd
デーモンはファイル・システムをアンマウントします。
SRC
デーモンが
automountd
起動していない場合、この
automount
コマンドは を使用してデーモンを起動しようとします。
マップ
自動マウント・マップは、アクセス時に自動的にマウントされるマウント・ポイントと、それらのマウント・ポイントの上に何をマウントする必要があるかを指定します。
/etc/auto_master
マップ・ファイルは、
キー
と呼ばれる初期マウント・ポイントと、それにマウントされるリモート・ファイル・システムを決定する対応するマップを指定します。
/etc/auto_master
ファイルのフォーマットは次のとおりです。
/key map
注:
/etc/auto_master
ファイルは、
automount
コマンドが最初に実行されるときにのみ読み取られます。 変更内容は、コマンドを
automount
再度実行するまで反映されません。
最も一般的なマップは、直接マップ、間接マップ、およびホスト・マップです。
直接マップでは
/etc/auto_master
ファイルに特殊キー (/-) が必要で、そのマップは次のフォーマットのファイルです。
/directkey [-options] server:/dir
ユーザーが
/directkey
ディレクトリーにアクセスすると、
automountd
デーモンは
/directkey
に
server:/dir
をマウントします。
間接マップのフォーマットは次のとおりです。

indirectkey [-options] server:/dir
ユーザーが
/key/indirectkey
ディレクトリーにアクセスすると、
automountd
デーモンは
/key/indirectkey
に
server:/dir
をマウントします。
ホスト・マップでは、
/etc/auto_master
ファイル内に特別なマップ (-hosts) が必要です。
automountd
デーモンは、
/etc/hosts
ファイルにリストされているすべてのサーバーの
/key
ディレクトリーの下にサブディレクトリーを作成します。 ユーザーが
/key/server
ディレクトリーにアクセスすると、
automountd
デーモンは、サーバーのエクスポートされたディレクトリーを
/key/server
ディレクトリーにマウントします。
代替マップ・ロケーション
自動マウント・マップは、NIS および LDAP サーバーでも探索されます。
automount
コマンドは、
/etc/irs.conf
ファイル内の自動マウント項目が変更されていない限り、デフォルトでローカル・システム上のファイルとしてマップを検索します。 次に例を示します。
automount nis_ldap
空白で区切ったリストを使用することで、使用順に複数のネームサービスを指定することができます。 たとえば、 LDAP のマップを最初に使用し、その後にローカルファイルを使用するように指定する場合、自動マウントのエントリは次のようになります：
automount nis_ldap files
自動マウント項目の有効な値は、
files
、
nis
、および
nis_ldap
です。

構文
automount [ -m ] [ -n ] [ -v ] [ -t duration ] [ -i interval ] [ -f file ] [ -s timeout ] [ -D name=value ] ... [ -d value ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-d Value | automount AutoFS 拡張機能およびデーモンのデバッグレベルを指定します。
-D 名前 = 値 | 環境変数とその値を指定します。 -D フラグを複数回使用することによって、複数の環境変数を指定できます。
-f file | 使用する新規マスター・マップ・ファイルを指定します。 デフォルトは /etc/auto_master です。
-i 間隔 | 非アクティブ autofs がマウントされたディレクトリーが存在する時間を秒単位で指定します。
-m | 自動マウントのマップのために NIS を検索しないように指定します。
-n | nobrowse オプションを指定します。
-s timeout | マウントに時間がかかりすぎる場合、新規プロセスが fork されるまでの時間を秒単位で指定します。 最小値は 30 です。
-t 期間 | auto アンマウント・プロセスが作業を再開するまでスリープする時間を秒単位で指定します。 最小値は 21 です。 デフォルト値は 120 です。 最大値は 600 です。
-v | これは、詳細状況と警告メッセージを標準出力に出力します。

例
LocalOpts
マウントポイントを自動的にマウントするために、,
LocalCaching
, および
Server
環境変数を指定するには、次のコマンドを入力してください：
automount -D LocalOpts=-rsize=16384,wsize=16384,timeo=15 \
-D LocalCaching=-rsize=16384,wsize=16384,timeo=15 -D Server=autoserver
デフォルトのファイル (
/etc/auto_master
) の代わりにマスターマップファイル (
/etc/myFile
) を使用するには、次のコマンドを入力してください：
automount -f /etc/myFile
以下のコマンドを入力して、デーモンの
automount
間隔時間を5分、タイムアウト値を30秒、実行時間を1分に設定します：
automount -i 300 -s 30 -t 60
