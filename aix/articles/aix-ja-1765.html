目的
フォント・パスからフォント・パスのエレメントを除去します。

説明
x_rm_fpe
コマンドは、選択されたネットワーク・タイプ名のフォント・パスから、フォント・パス・エレメントを除去します。
項目 | 説明
TypeName | エレメントを除去するネットワーク・タイプ名を指定します。
位置 | フォント・パス内のエレメントの位置を指定します。
メソッド (method) | フォント・パス・エレメントにアクセスする場合の方式を指定します。 有効なオプションは以下のとおりです。ネットワーク・フォント・サーバーの場合は tcp 、初期デフォルト・フォント・パス・エレメントの場合は default 、NFS の場合は nfs 、および TFTP の場合は tftp です。
Host | フォント・パス・エレメント内に指定されたシステム名を指定します。 デフォルトのアクセス方式を使用するエレメントの場合は、 None を指定します。
ポート | フォント・パス・エレメント内に指定されたサーバー・ポート番号を指定します。 以下を使用するエレメントの場合: nfs または tftp メソッド、 なし を指定します。
directory | フォントが入っているディレクトリーへの絶対パスを指定します。 ネットワーク・フォント・サーバー・エレメントの場合は、 None を指定します。

構文
x_rm_fpe TypeName Position Method ホスト・ポスト・ディレクトリー

例
フォント要素を削除するには
/usr/lib/X11/fonts/100dpi
ネットワーク・タイプのフォント・パスから
x_st_mgr.ether
次のように入力します。
x_rm_fpe x_st_mgr.ether 3 nfs waco None /usr/lib/X11/fonts/100dpi
この例では、フォント・パス・エレメント
/usr/lib/X11/fonts/100dpi
ホスト上でアクセスされる
waco
NFS の使用は、ネットワーク・タイプのフォント・パスの 3 番目の位置から削除されました。
x_st_mgr.ether
NFSにはポート番号が使用されないため、このパラメーターは以下のように設定されました。
None
