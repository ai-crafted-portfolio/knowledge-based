目的

仮想メモリーの統計情報を報告します。

構文

vmstat [ -f  ] [ -i ] [ -s  ] [ -I [ -W ]] [ -t ] [ -v ] [ -h ] [ -w ] [ -l ] [ -c ] [ -L level ] [ -@ wparname | ALL ] [{ -p | -P } physicalvolume | ALL ] ALL ] [ -S power ]  [ physicalvolume ] [ interval ] [ count ]
注： ワークロード・パーティションでは、 wparname オプションと -i フラグを併用してはならない。

説明

vmstat コマンドは、カーネル・スレッド、仮想メモリー、ディスク、ハイパーバイザー・ページ、トラップ、およびプロセッサー・アクティビティの統計情報を報告します。 vmstat コマンドによって生成されるレポートは、システム負荷活動のバランスをとるために使用される。 これらのシステム全体の統計は、値が全プロセッサのパーセンテージで表される場合は平均値として計算され、それ以外の場合は合計値として計算される。 vmstat コマンドは、統計がアトミックに読み込まれない場合、一貫性のない統計を返すことがある。

フラグを指定せずに vmstat コマンドを実行した場合、 vmstat コマンド・レポートには、システム起動時からの仮想メモリ・アクティビティの概要が含まれます。 -f フラグを指定すると、vmstat コマンドはシステム始動後の fork の数を報告します。 physicalvolume パラメーターは物理ボリュームの名前を指定する。

interval パラメーターは、各レポートの間隔を秒で指定します。 interval パラメータを指定しない場合、 vmstat コマンドはシステム起動時からの統計情報を含む単一のレポートを生成し、終了する。 count パラメーターは、interval パラメーターと一緒に指定する必要があります。 count パラメータを指定した場合、 count パラメータ値によって、生成されるレポートの数と秒間隔が決定される。 count パラメーターなしで interval パラメーターを指定すると、レポートは連続して生成されます。 count パラメーターに、ゼロの値を指定しないでください。

カーネルはカーネルスレッド、ページング、割り込みアクティビティの統計情報を保持しており、 vmstat コマンドは perfstat カーネル拡張を使用することでアクセスできます。 ディスクの入出力（I/O）統計は、デバイス・ドライバによって管理される。 ディスクの平均転送率は、活動時間と転送数の情報から求められます。 アクティブ時間%は、レポート中にドライブがビジー状態であった時間から計算される。

vmstat コマンドは、 マイクロ・パーティショニング環境において、消費された物理プロセッサ数（pc）と消費されたエンタイトルメントの割合（ec）をレポートします。

vmstat コマンドで生成されるレポートには、システム構成行と列見出しが含まれる。 フラグが指定された場合、 vmstat コマンド・レポートはシステム・コンフィギュレーションと WPAR コンフィギュレーションから構成される。

システム構成行

システム・コンフィギュレーションの行には以下の値がある：
lcpu
lcpu フィールドは、論理プロセッサの数を示す。
mem
mem フィールドはメモリ量を示す。
tmem
tmem フィールドは、論理パーティション（LPAR）の真のメモリサイズを示します。
注： このフラグは、 -c オプションが提供され、アクティブ・メモリー拡張が有効になっている場合にのみ使用可能。
ent
ent 。 この情報は、共有プロセッサー上でパーティションを実行する場合にのみ表示されます。
drives
drives フィールドはディスクの数を示す。 この情報は、物理ボリューム名が監視されている場合にのみ表示されます。
ワークロード・パーティション (WPARs)
WPARs フィールドは、アクティブなワークロードパーティションの数を示す。 この情報は、-@ フラグを指定した場合にのみ表示されます。
memlim
memlim フィールドは、 ワークロードパーティションのメモリリソースの上限（メガバイト単位）を示す。 この情報は、メモリリソースの制限がある WPARに対してのみ表示される。
cpulim
cpulim フィールドは、 ワークロードパーティションのプロセッサリソースの上限をプロセッサ単位で示す。 この情報は、プロセッサ・リソースの制限が適用された WPARに対してのみ表示される。
rset
rset フィールドは、 WPARに関連付けられている rset レジストリのタイプを示す。 rset レジストリ・タイプは、レギュラー・タイプとエクスクルーシブ・タイプがある。 この情報は、 rset レジストリに関連付けられている WPARs に対してのみ表示される。
mmode
mmode フィールドはメモリーモードを示す。 この指標は、システムでアクティブ・メモリー共有が有効になっている場合に自動的に表示される。 この指標は、 -c オプションを指定した場合にも表示される。
mpsz
mpsz フィールドは、メモリプールのサイズをギガバイト単位で示す。 この指標は共有メモリーモードでのみ表示される。

列見出し

vmstat コマンドで生成されるレポートの列見出しの値は以下の通り：

WPAR
WPARは ワークロードパーティション名で、 ワークロードパーティションに関する情報を提供する。 この情報は、-@ フラグを指定した場合にのみ表示されます。
注:
  1. システム WPAR 名はシステム全体の統計情報を示し、グローバル WPAR 名は統計情報がグローバルのみに属することを示す。
  2. vmstat コマンドを -@ ALL オプションで起動し、 WPAR 固有の情報がメトリックで利用できない場合、値の代わりにダッシュ記号 (-) が表示されます。
  3. -@ wparname または WPAR 内で vmstat コマンドを開始すると、 WPAR 情報がメトリックに利用できない場合、そのメトリックにはアットマーク（@）が付き、システム全体の値が表示されます。
  4. メトリックがサポートされない場合、値に代わりダッシュ (-) が表示されます。
kthr
カーネル・スレッドの状態に関する情報を提供する。
r
サンプリング間隔で実行可能なカーネル・スレッドの平均数を表す。 サンプリング間隔を超えて実行可能なカーネル・スレッドは、準備はできているがまだ実行を待っているスレッドと、すでに実行中のスレッドから構成される。
b
サンプリング間隔にわたって、VMM（Virtual Memory Manager）の待ち行列（リソース待ち、I/O待ち）に入れられたカーネル・スレッドの平均数を表す。
MEMORY
仮想メモリと実メモリの使用状況に関する情報を提供する。 仮想ページはアクセスされればアクティブとみなされる。 仮想ページは4096バイト。
avm
アクティブな仮想ページの数を示す。
fre
空きリストのサイズを示す。
注: 実メモリーの大部分は、ファイル・システム・データのキャッシュとして使用されます。 フリーリストのサイズは小さいままだ。
ページ
ページフォルトとページングアクティビティに関する情報を提供する。 この情報はインターバルで平均化され、1秒あたりの単位で表示される。
re
ページャーの I/O リストを示す。
pi
ページングスペースからページインされるページを示す。
po
ページングスペースにページアウトしたページを示す。
fr
解放されたページ（ページの入れ替え）を示す。
sr
ページ置換アルゴリズムによってスキャンされるページを示す。
cy
ページ置換アルゴリズムによるクロックサイクルを示す。
フォールト
サンプリング間隔における1秒あたりの平均トラップ・レートおよび割り込みレートに関する情報を提供する。
in
デバイスの割り込みを示す。
sy
システムコールを示す。
cs
カーネル・スレッドのコンテキスト・スイッチを示す。
CPU
プロセッサ時間の使用率の内訳に関する情報を提供する。
us
ユーザータイムを示す。

上限が設定されていないパーティションの現在の物理プロセッサ消費量が、権利を与えられた容量を超えた場合、パーセンテージは消費された物理プロセッサ数に対する相対的なものになる。

sy
システム時間を示す。

上限が設定されていないパーティションの現在の物理プロセッサ消費量が、権利を与えられた容量を超えた場合、パーセンテージは消費された物理プロセッサ数に対する相対的なものになる。

id
プロセッサのアイドル時間を示す。

上限が設定されていないパーティションの現在の物理プロセッサ消費量が、権利を与えられた容量を超えた場合、パーセンテージは消費された物理プロセッサ数に対する相対的なものになる。

wa
システムに未処理のディスクまたは NFS I/O 要求があったプロセッサのアイドル時間を示す。

上限が設定されていないパーティションの現在の物理プロセッサ消費量が、権利を与えられた容量を超えた場合、パーセンテージは消費された物理プロセッサ数に対する相対的なものになる。

pc
使用されている物理プロセッサの数を示す。 この情報は、共有プロセッサー上でパーティションを実行する場合にのみ表示されます。
ec
消費される権利付き容量の割合を示す。 この情報は、共有プロセッサー上でパーティションを実行する場合にのみ表示されます。 このデータが計算される時間ベースはさまざまであるため、権利のある容量パーセンテージは100％を超えることがあり、その超過はサンプリング間隔が小さい場合にのみ顕著となる。
rc
プロセッサリソースの使用率を示す。 この情報は、プロセッサー・リソースの制限を強制した WPAR の場合にのみ表示されます。
ディスク

サンプル間隔で発生した、指定した物理ボリュームへの1秒あたりの転送数に関する情報を提供します。 physicalvolume パラメーターには、1つから4つの名前を指定できる。 転送統計情報は、指定した各ドライブについて、指定した順番で報告されます。 この値は、物理デバイスに対する要求を表します。 読み書きのデータ量を意味するものではない。 複数の論理要求を 1 つの物理要求にまとめることができます。 physicalvolume 」パラメータを使用すると、コマンド実行の最初に物理ボリューム名が表示される。

ファントム割り込みごとに増加する。
revolutions of the clock hand
VMM クロック回転数 (つまり、メモリーのスキャン数) です。
start I/Os
VMM が開始した読み取りまたは書き込み入出力要求の回数です。
syscalls
システム・コールの回数です。
total reclaims
新しいI/O要求を開始せずにアドレス変換フォルトが満たされたときにインクリメントされる。 このイベントは次のような場合に発生する：
  • ページがVMMによって以前に要求されたが、I/Oがまだ完了していない場合。
  • ページがVMMのリード・アヘッド・アルゴリズムによってプリフェッチされたが、フォールト・セグメントからは隠されていた場合
  • そのページが無料リストに掲載され、まだ再利用されていない場合。
traps
イベントがオペレーティング・システムによって管理されていないことを示す。
zero-filled page faults
作業用ストレージで発生し、フレームの割り当てとゼロ埋め込みで回復できるページ・フォールトの数です。
-s フラグとともに -c フラグを指定すると、以下の追加メトリクスが表示されます：
compressed pool page ins
システム起動時からの圧縮プールからのページイン数を示す。
compressed pool page outs
システム起動時からの圧縮プールへのページアウト数を示す。
-s

-p pagesize フラグとともに使用されると、 -s フラグは、指定されたページ・サイズの合計構造をシステム全体の合計構造に追加する。 この追加スタンザの前には、ページサイズヘッダー（例えば4KBページ）が付く。 このページ・サイズ・ベースのスタンザでは、これらの統計はページ・サイズに関係しないため、以下の詳細は表示されない：

  • プロセッサー・コンテキスト切り換えの回数
  • デバイス割り込みの回数
  • ソフトウェア割り込みの回数
  • decrementer 割り込みの回数
  • MPC-sent 割り込みの回数
  • MPC-received 割り込みの回数
  • phantom 割り込みの回数
  • トラップの回数
  • システム・コールの回数
注:
  1. -@ ALL フラグで -s フラグを指定すると、システム全体の統計がワークロード・パーティション・セクションで繰り返される。
  2. -@ wparname フラグで -s フラグを指定すると、すべてのメトリクスが報告され、システム全体の統計情報にはアットマーク（@）が付きます。
  3. -l フラグとともに -s フラグを指定すると、 vmstat コマンドは以下のメトリックを表示する：
    large-page hi water count
    ラージページ使用中カウントの最大値を指定する。
-S power プロセッサーの統計値に 10 powerの値を掛ける。 電力のデフォルト値は 0 である。
以下の統計情報は、スケーリングされます。
  • us
  • sy
  • id
  • wa
  • pc
  • ec
注:
  1. -f、 -s、 -i、 -v、 -p のフラグで、 -S フラグを指定しないこと。
  2. -S フラグが指定されると、 us、 sy、 id、 wa 統計が変更される。 デフォルトでは、 us、 sy、 id、 wa の統計は、 WPARのプロセッサ消費量に対するものである。 -S フラグにゼロ以外の電力値が指定されている場合、これらの統計値はシステム全体のプロセッサ消費量に対する相対値である。
  3. -S フラグのパワー 値は、0～3の範囲である。
-t vmstat コマンドの出力の各行の横にタイムスタンプを表示する。 このタイム・スタンプは、HH:MM:SS フォーマットで表示されます。
注： -f、 -s、 -i のフラグが指定されている場合、タイムスタンプは表示されない。
-v Virtual Memory Managerが保持する様々な統計情報を標準出力に書き出す。 -v フラグは、 -s、 -L、 -h フラグと一緒にのみ使用できる。

-v フラグを指定すると、以下の統計情報が表示されます。

compressed percentage
圧縮ページが使用するメモリの割合を示す。
client filesystem I/Os blocked with no fsbuf
fsbuf が利用できなかったためにブロックされたクライアントファイルシステムI/Oリクエストの数を示す。 Network File System ( NFS ) と Veritas ( VxFS ) はクライアント・ファイル・システムである。 Fsbuf は、ファイルシステム層でI/O要求を保持するために使われるピン留めされたメモリバッファである。
client pages
クライアントのページ数を示す。
compressed pages
圧縮メモリのページ数を示す。
external pager filesystem I/Os blocked with no fsbuf
fsbuf が利用できなかったためにブロックされた外部ページャークライアントのファイルシステム I/O 要求の数を示す。 JFS2 は外部ページャークライアントファイルシステムである。 Fsbuf は、ファイルシステム層でI/O要求を保持するために使われるピン留めされたメモリバッファである。
file pages
ファイルキャッシュが使用する4KBBページの数を示す。
free pages
4KBBの無料ページ数を示す。
filesystem I/Os blocked with no fsbuf
fsbuf が利用できなかったためにブロックされたファイルシステム I/O 要求の数を示す。 Fsbuf は、ファイルシステム層でI/O要求を保持するために使われるピン留めされたメモリバッファである。
lruable pages
4KBBページのうち、差し替えを検討しているページ数を示す。 この数には、VMM 内部ページに使用されるページや、カーネル・テキストのピンされた部分に使用されるページは含まれません。
maxclient percentage
クライアント・ページに使用できるメモリの最大パーセンテージを指定するチューニング・パラメータ（ vmo を使用して管理）を示します。
maxperm percentage
vmo を使用して管理される実メモリの割合のチューニングパラメータを示す。
maxpin percentage
ピン留めできる実メモリの割合を指定するチューニングパラメータ（ vmo で管理）を示す。
memory pages
実メモリのサイズを4KBBページ数で示す。
memory pools
vmo を使用して管理するメモリプールの数を指定するチューニングパラメータを示す。
minperm percentage
vmo を使用して管理される実メモリの割合のチューニングパラメータを示す。
numclient percentage
クライアント・ページが占めるメモリの割合を示す。
-v （続き）
numperm percentage
ファイルキャッシュが使用する lruable メモリの割合を示す。
paging space I/Os blocked with no psbuf
psbuf スペースが利用できないためにブロックされたページングスペース I/O 要求の数を示す。 psbufs 空間は、仮想メモリー・マネージャー層でI/O要求を保持するために使用されるピン留めメモリー・バッファである。
pending disk I/Os blocked with no pbuf
pbuf が利用できなかったためにブロックされた、保留中のディスクI/O要求の数を示す。 pbuf は、論理ボリュームマネージャレイヤーでI/O要求を保持するために使用されるピン留めメモリバッファである。
pinned pages
ピン留めされた4KBBページの数を示す。
注記： カーネル・ロック機能（vmm_klock_mode パラメーター）が有効な場合、ピン留めされたページにはカーネル・ロック（klocked ）ページが含まれる。 カーネル・ロック機能の詳細については、以下のコマンドを入力してください：
vmo -h vmm_klock_mode
remote page-outs scheduled
クライアント・ファイルシステムに対してスケジュールされているページアウトの数を示す。

-v フラグとともに -h フラグを指定すると、以下の追加メトリクスが表示されます：

Time resolving virtualized partition memory page faults
仮想パーティションがメモリ・ページ・フォールトの解決待ちのためにブロックされている合計時間を示します。 時間はミリ秒の細分度で、計測の単位は秒です。
Virtualized partition memory page faults
仮想化パーティションに対して記録された仮想パーティション・メモリ・ページ・フォールトの総数を示します。
Number of 4 KB page frames loaned
パーティションのメモリのうち、ハイパーバイザーに貸与される4KBページの数を示す。
Percentage of partition memory loaned
ハイパーバイザーに貸与されるパーティションのメモリの割合を示します。
注:
  1. -v フラグが -@ ALL フラグとともに使用されている場合、システム全体の統計はワークロード・パーティション・セクションで繰り返されない。
  2. -s フラグを -@ wparname フラグとともに使用すると、すべてのメトリクスが報告され、システム全体の統計情報にはアットマーク（@）が付けられる。
-v フラグとともに -c フラグを指定すると、以下の追加メトリクスが表示されます：
Compressed Pool Size
圧縮プールのサイズを4KBページ単位で示す。
percentage of true memory that is used for compressed pool
圧縮プールに使用される未展開メモリの割合を示す。
free pages in compressed pool (4 KB pages)
圧縮プール内の空きページ数を4KBページ単位で示す。
target memory expansion factor
LPAR に設定されているターゲットメモリ拡張率を示します。
achieved memory expansion factor
現在のメモリ拡張倍率を示す。
-h ハイパーバイザーのページ情報を含む hypv-page セクションを表示します。 hypv-page セクションには、以下のメトリックが含まれます。
hpi
1秒あたりのハイパーバイザーのページイン数を示す。
hpit
ハイパーバイザーのページインごとに費やされる平均時間をミリ秒単位で示す。
pmem
パーティションの論理メモリをバックアップする物理メモリの量を示す。 値の計測の単位はギガバイト (GB) です。

-v フラグとともに -h フラグを指定すると、 -v フラグを使用して表示されるメトリッ クに加えて、以下のメトリクスが表示されます：

Time resolving virtualized partition memory page faults
仮想パーティションがメモリ・ページ・フォールトの解決待ちのためにブロックされている合計時間を示します。 時間はミリ秒の細分度で、計測の単位は秒です。
Virtualized partition memory page faults
仮想化パーティションに対して記録された仮想パーティション・メモリ・ページ・フォールトの総数を示します。
Number of 4 KBB page frames loaned
パーティション内のハイパーバイザーに貸与されるメモリの4KBBページ数を示す。
Percentage of partition memory loaned
パーティション内のハイパーバイザーに貸与されているメモリのパーセンテージを示します。
-w レポートを幅広モードで表示します。
-W kthr セクションに追加フィールド w を表示する。 このオプションは、-I フラグと共に指定した場合にのみ許可されます。
注:
  1. Active Memory Expansion が有効な場合、 vmstat コマンドは拡張ビューでメモリ統計を報告する。 ただし、環境変数 AME_MEMVIEW が TRUE に設定されている場合は、 メモリーの統計情報は True ビューに表示されます。
  2. AME_MEMVIEW 環境変数は、 -c フラグを使用して報告されるメモリ統計には影響しません。

例

  1. ブート以後の統計情報の要約を表示するには、次のコマンドを入力します。
    vmstat
  2. 秒間隔で5つのサマリーを表示するには、以下のコマンドを入力する：
    vmstat 2 5
  3. 論理ディスク scdisk13 と scdisk14 の統計を含む、ブート以降の統計のサマリーを表示するには、以下のコマンドを入力します：
    vmstat scdisk13 scdisk14
  4. fork 統計情報を表示するには、次のコマンドを入力します。
    vmstat -f
  5. さまざまなイベントの回数を表示するには、次のコマンドを入力します。
    vmstat -s
  6. vmstat コマンドの出力の各列の横にタイムスタンプを表示するには、以下のコマンドを入力する：
    vmstat -t
  7. I/O 指向のビューに列の代替セットを表示するには、次のコマンドを入力します。
    vmstat -I
  8. 使用可能なすべての VMM 統計情報を表示するには、次のコマンドを入力します。
    vmstat -vs
  9. alp 、 flp のカラムを8秒間隔でラージページ・セクションに表示するには、以下のコマンドを入力する：
    vmstat -l 8
  10. 特定のページ・サイズ (例えば、4 KB) に固有の VMM 統計情報を表示するには、次のコマンドを入力します。
    vmstat -p 4K
  11. システムでサポートされているすべてのページ・サイズについての VMM 統計情報を表示するには、次のコマンドを入力します。
    vmstat -p ALL
    または、 次のコマンドを入力します。
    vmstat -p all
  12. 特定のページ・サイズ (この例では、4 KB) についての VMM 統計情報のみを表示するには、次のコマンドを入力します。
    vmstat -P 4K
  13. サポートされているすべてのページ・サイズについて、ページごとの VMM 統計情報の内訳のみを表示するには、次のコマンドを入力します。
    vmstat -P ALL
    または、 次のコマンドを入力します。
    vmstat -P all
  14. ブート後にすべてのワークロードパーティションの統計のサマリーを表示するには、以下のコマンドを入力します：
    vmstat -@ ALL
  15. すべてのワークロード・パーティションで利用可能なすべてのVMM統計を表示するには、次のコマンドを入力します：
    vmstat -vs -@ ALL
  16. ワークロード・パーティションから WPAR とシステム全体の VMM 統計情報の両方を表示するには、次のコマンドを入力します。
    vmstat -@
  17. プロセッサー値を 10 倍してその結果を表示するには、次のコマンドを入力します。
    vmstat -S 1
  18. ハイパーバイザーのページに関する統計情報を表示するには、次のコマンドを入力します。
    vmstat -h
  19. ハイパーバイザーに貸し出されているページについての情報を表示するには、次のコマンドを入力します。
    vmstat -vh
  20. メモリー圧縮統計情報 (Active Memory Expansion が有効になっている LPAR 内) を表示するには、次のコマンドを入力します。
    vmstat -c
  21. (Active Memory Expansion が有効になっている LPAR 内の) 各ページ・サイズに固有のメモリー圧縮統計を表示するには、次のコマンドを入力します。
    vmstat -c -P ALL
  22. (Active Memory Expansion が有効になっている LPAR で) -s フラグで表示される統計情報にメモリ圧縮情報を追加するには、次のコマンドを入力します：
    vmstat -s -c
  23. (Active Memory Expansion が有効になっている LPAR で) -v フラグで表示される統計情報にメモリ圧縮情報を追加するには、次のコマンドを入力します：
    vmstat -v -c
  24. ソフトページのプロモーション統計を表示するには、以下のコマンドを入力する：
    vmstat -L 1
