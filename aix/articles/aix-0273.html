目的

AIXコマンドを受け取り、それをクラスタのメンバーであるノードのセットに配布する。

構文

clcmd [ -n clustername] [ -m nodename [, ...]] [ ファイル ]

説明

AIX オペレーティング・システムは、単一ノード構成またはマルチノード構成で稼働できます。 AIX オペレーティング・システムのマルチノード構成は、クラスター構成です。

システム管理者は、 AIX システム管理コマンド ( mkuser コマンド、 mkvg コマンド、および lslv コマンドなど) を使用して、デバイス、ファイル・システム、およびユーザー管理属性などの特性および機能定義に対する操作を実行できます。 これらのシステム管理コマンドは、ローカル範囲またはクラスター範囲で実行できます。

クラスター構成で AIX コマンドを実行すると、クラスターに参加しているすべてのノードに AIX コマンドが配布されます。 したがって、 AIX システム管理者は、ノードのグループを単一オブジェクトとして管理することができます。

クラスター認識のための AIX コマンドの使用可能化には、以下の特性があります。

  • AIX コマンドのターゲット・ノードを決定します。
  • AIX コマンドをターゲット・ノードに配布します。

フラグ

項目
説明
-n クラスター名 コマンドの送信先のクラスターの名前を指定します。 クラスター内のすべてのノードがこのコマンドを受信します。
-m ノード名 コマンドの送信先のノード名を指定します。 これらのノードは、クラスターのメンバーでなければなりません。 これにより、コマンドをクラスター内のノードのサブセットに配布することができます。

例

  1. ps コマンドを clusterabc クラスター内の oscar-test-dev1 および oscar-test-dev2 ノードに送信するには、次のコマンドを入力します。
    clcmd -n clusterabc -m oscar-test-dev1,oscar-test-dev2 -- /usr/bin/ps

ファイル

項目
説明
/path/to/localcmd < localcmd_options> 実行するコマンドを指定するために使用される修飾ファイル指定。 < localcmd_options> リストには、実行中のコマンドに関連するオプションが含まれています。
