目的
新規ドメインを作成します。

説明
mkdom
コマンドは、ドメイン・データベースに新規ドメインを作成します。 ドメイン属性は、
Attribute
=
Value
パラメーターを使用してドメイン作成フェーズ時に設定できます。
システムが拡張
ロール・ベース・アクセス制御
(
RBAC
) モードで稼働している場合、
setkst
コマンドを使用してデータベースがカーネル・セキュリティー・テーブルに送信されるまで、ドメイン・データベースに対して行われた変更はセキュリティー上の考慮事項に使用されません。
注:
ドメイン ID 値は 1024 以下にすることができます。
mkdom
コマンドを使用すると、システム上に 1024 のドメインを作成できます。
役割ベースのアクセス制御 (RBAC) ドメイン・データベースに対して複数の認証ロード・モジュールを使用するようにシステムが構成されている場合、新しい RBAC ドメインは、
/etc/nscontrol.conf
ファイルの
domains
スタンザ内の
secorder
属性によって指定された最初のロード・モジュールに作成されます。 特定の認証ロード・モジュール内に RBAC ドメインを作成する場合は、
-R
フラグを使用します。

構文
mkdom [ -R load_module ] [ 属性 = 値 ...] Name

オプション
フラグ
項目 | 説明
-R load_module | RBAC ドメインを作成するときに使用するロード可能モジュールを指定します。

例
ドメイン
hrdom
を作成し、
mkdom
コマンドで適切な ID 値を割り当てるには、次のコマンドを入力します。
mkdom hrdom
Lightweight Directory Access Protocol (LDAP) にカスタム・ドメインを作成するには、次のコマンドを入力します。
mkdom -R LDAP custom
