目的

システムの固定ライセンス数と浮動ライセンスの状況を変更します。

構文

chlicense [[ -D | -I ] -u FixedUsers]] [[ -v ] -f FloatingStatus ]

注: chlicense コマンドには、少なくとも 1 つのフラグを指定する必要があります。

説明

ユーザー・ライセンスには、固定と浮動の 2 つのタイプがあります。 固定ライセンスは常に使用可能であり、chlicense コマンドの -u フラグを使用してライセンス数を変更できます。 浮動ライセンスは、-f フラグを使用して使用可能または使用不可にします。

フラグ

注: chlicense コマンドには、少なくとも 1 つのフラグを指定する必要があります。
項目
説明
-D -D フラグを指定すると、新規固定ライセンスの値は、 login.cfg ファイルでのみ更新されます。 -I フラグが出されていない場合、これはオプションです。 新しい数が有効になる前に、システムを再始動する必要があります。
-f FloatingStatus システムの浮動ライセンスの状況を変更します。 状況は on または off のいずれかでなければなりません。 状況を on にすると浮動ライセンスが使用可能になり、 off にすると使用不可になります。 -f フラグはオプションです。
-I -I フラグを指定すると、chlicense コマンドは、login.cfg ファイル内の値の変更に加えて、 固定ライセンスのカウント・セマフォーの現行値も変更します。
-u FixedUser システムの固定ライセンス数を変更します。 FixedUser の値は 0 より大きい数値でなければなりません。 -u フラグはオプションです。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

例

  1. システムのフローティング・ライセンスを使用可能にするには、次のように入力します。
    chlicense -f on
  2. システムのフローティング・ライセンスを使用不可にするには、次のように入力します。
    chlicense -f off
  3. 固定ライセンス数を 125 に変更し、システムでフローティング・ライセンスを使用可能にするには、以下のように入力します。
    chlicense -u 125 -f on
  4. 固定ライセンス数を直ちに 5 に増やすには、次のように入力します。
    chlicense -I -u 5
