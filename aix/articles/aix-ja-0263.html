目的
confsrc
コマンドはサブシステム、サブシステムのグループ、またはサブサーバーを構成します。

説明
confsrc
コマンドは、システム・リソース・コントローラー (SRC) にサブシステムを構成するための要求を送信します。 サブサーバーを構成する要求が SRC に渡され、そのサブサーバーが所属するサブシステムがアクティブでない場合、SRC はサブシステムを始動してサブシステムに要求を伝送します。
注:
サブサーバーの構成要求は、サブシステムがその要求をサポートしている場合にのみ処理されます。

構文
confsrc [[ -R ] -h ホスト] [ -p SubsystemPID ] [ -q ] [ -Q ] [ -u UserID ] [ -U パスワード ] -s サブシステム -a ConfigString

オプション
フラグ
項目 | 説明
-a ConfigString | 構成情報を含むストリングを指定します。 このストリングはコマンド・ラインから渡され、サブシステム・オブジェクト・クラスからコマンド・ライン引数に追加されます。 指定されたストリングが 1200 文字を超えると、このコマンドは失敗します。 コマンド引数は、シェルで使用される規則に従って SRC によってサブシステムに渡されます。 引用符付き文字列は、単一の引数として渡され、引用符付き文字列の外にあるブランクは、引数を区切ります。 ストリングには、単一引用符と二重引用符を使用できます。
-h ホスト | 構成アクションが要求される外部ホストを指定します。 ローカル・ユーザーは、 root として実行している必要があります。 リモート・システムは、 -r フラグを指定して srcmstr デーモン ( /etc/inittab ) を開始し、リモート要求を許可するように /etc/hosts.equiv または rhosts ファイルを構成することにより、リモート SRC 要求を受け入れるように構成されている必要があります。
-p SubsystemPID | 構成要求が渡されるサブシステムのインスタンスを指定します。
-q | 最小ローカル出力の抑止モードの操作を指定します。
-Q | 出力抑止での抑止モードの操作を指定します。
-R | リモート接続に TCP を使用します。 注: このフラグは、 -h フラグが使用されている場合にのみアクティブになります。
-s サブシステム | 始動するサブシステムを指定します。 指定する Subsystem は、実際のサブシステム名か、サブシステムの同義語名にすることができます。 指定された Subsystem がサブシステム・オブジェクト・クラスに含まれていないと、このコマンドは失敗します。
-u UserID | リモート・ホストで使用されるユーザー ID を指定します。 注: このフラグは、 -h フラグが使用されている場合にのみアクティブになります。
-U パスワード | ユーザー ID のパスワードを指定します。 注: このフラグは、 -u フラグが使用されている場合にのみアクティブになります。
