目的
snap
出力ファイルを、任意のサイズまたは指定したサイズの複数の小さいファイルに分割します。

説明
snapsplit
コマンドは、
snap
出力ファイルをより小さいファイルに分割するために使用します。 このコマンドは、非常に大きな
snap
ファイルを処理する場合に役立ちます。 ファイルは、1 MB の倍数である特定サイズの複数のファイルに分割されます。 さらに、
-u
オプションを指定して呼び出すと、これらのファイルが元のファイルに結合されます。
出力ファイルの名前は、
snap.
machinename
.
timestamp
.pax.gzxxx
のようになります。
Machinename
はホスト名で、
timestamp
は MMDDYYHHMMSS 形式です。 さらに、
xxx
は、分割ファイルの拡張子を表します。これは、これらのファイルをまとめる際に非常に重要です。 ファイルの先頭からの拡張子は、
aaa, aab, aac, aad, aae ..., aaz, aba, abb, abc,
abd, ..., abz, aca, acb, acc, ...
の順序になります。
これらのファイルに対して
ls
を実行すると、リストされた最初のファイルが元のファイルの先頭を表し、最後のファイルが元のファイルの末尾を表します。
このコマンドは、
paxed
および圧縮された
snap
ファイルに対してのみ使用する必要があることに注意してください。
snap
出力が収集されたローカル・システムで実行する場合は、
-H
オプションを使用する必要はありません。 このフラグは、ユーザーが完全な
snap
ファイルをリモート・システムに移動し、それを分割したい場合に使用します。 任意のマシン名を使用できますが、データが収集されたマシンの名前を使用することをお勧めします。

構文
snapsplit [ -s サイズ］ [ -H マシン名］ [ -f ファイル名］ snapsplit -u -T タイムスタンプ [ -H マシン名 ]

オプション
フラグ
項目 | 説明
-f ファイル名 | snapsplit ファイルを入力します。 これは、圧縮された pax ファイルでなければなりません。 デフォルトは snap.pax.gz です。
-H マシン名 | ホスト・マシンの名前。 指定しない場合は、現行ホストがデフォルトとなります。 該当するシステムの snap ファイルに名前を付ける際には注意が必要です。
-s サイズ | snap 出力のサイズを 1 MB の倍数で指定します。 最後のファイルは、このサイズに等しいか小さくなります。 size は MB 単位で入力してください。 デフォルト・サイズは 1 MB です。
-T タイム・スタンプ | 元の snap 出力のリストアに使用する snapsplit ファイルのタイム・スタンプ。 MMDDYYHHMMSS 形式で指定します。MM は月、DD は日、YY は年、HH は時間、MM は分、SS は秒です。
-u | snapsplit ファイルの再結合に使用されるフラグ。 -T フラグと共に使用されます。

例
デフォルトのスナップ・ファイル (
snap.pax.gz
は現行ディレクトリーになければなりません) を分割するには、次のコマンドを入力します。
snapsplit
このコマンドの出力は現行ディレクトリーに書き込まれます。
ファイル
snap.somefile.pax.gz
をシステム
doe
から分割するには、次のコマンドを入力します。
snapsplit -H doe -f snap.somefile.pax.Z
注:
結果のファイルは、
snap.doe.MMDDYYHHMMSS.pax.gz
という名前になります。
snap
ファイル (
snap.sue.102303141211.xxx
) がシステムスー用で、タイム・スタンプが 102303141211 のファイルをリストアするには、次のように入力します。
snapsplit -u -T 102303141211 -H sue
重要:
いずれかの
snap
ファイルが欠落しているか、名前変更されている場合、作成された
snap
ファイルは破損します。
タイム・スタンプ 102603084512 を持つ現行システム用のファイルから
snap
ファイルをリストアするには、次のように入力します。
snapsplit -u -T 102603084512
lslpp -hBc
コマンドの出力を含む、一般的なシステム構成情報を収集するには、次のように入力します。
snap -g -o /dev/rfd0
出力は、
/tmp/ibmsupt/general/lslpp.hBc
および
/tmp/ibmsupt/general/general.snap
ファイルに書き込まれます。 また、このコマンドは、システム情報を取り外し可能ディスケットにも書き込みます。
