目的
ボリューム・グループから論理ボリュームを除去します。

説明
注意:
このコマンドは、指定された論理ボリューム内のすべてのデータを破棄します。
rmlv
コマンドは論理ボリュームを除去します。 LogicalVolume パラメーターは、論理ボリューム名または論理ボリューム ID のいずれかです。 論理ボリュームは、まず最初にクローズしなければなりません。
ボリューム・グループ
がコンカレント・モードでオンに変更されている場合、
ボリューム・グループ
が変更されているすべてのコンカレント・ノード上で論理ボリュームをクローズする必要があります。 例えば、論理ボリュームにファイルシステムが入っている場合は、
マウントを解除しなければなりません。 ただし、論理ボリュームを除去しても、そのボリューム上に存在していたファイルシステムが破壊されたことはオペレーティング・システムに通知されません。
rmfs
コマンドは
/etc/filesystems
ファイルを更新します。
注:
このコマンドを使用するには、root ユーザー権限を持っているか、あるいは
system
グループのメンバーでなければなりません。
rmlv
コマンドは、スナップショット・ボリューム・グループまたは、
スナップショット・ボリューム・グループを持つボリューム・グループには使用できません。
補助ダンプ論理ボリュームであるアクティブ・ファームウェアに対して
rmlv
コマンドを使用することはできません。
AIX® 7.2 テクノロジー・レベル 1 以降では、
rmlv
コマンドを実行して区画を解放した後、解放された区画に対してスペース再利用プロセスが実行されます。
rmlv
コマンドを実行する前に、物理ボリューム上に構成されているすべての暗号化論理ボリュームの鍵サーバーおよび鍵ファイルの認証方式を削除します。
rmlv
コマンドは、暗号化論理ボリュームが削除される前に、プラットフォーム鍵ストア (PKS) 認証方式のみ削除します。
また、System Management Interface Tool (SMIT) の
smit rmlv
ファスト・パスを使用して、このコマンドを実行することもできます。

構文
rmlv [ -B ] [ -f ] [ -w ] [ -p Physical Volume ] LogicalVolume ...

オプション
フラグ
表 1. フラグ
項目 | 説明
-B | 論理ボリュームが -l フラグを使用して作成された場合、親論理ボリュームに対して chlvcopy -B -s を発行します。 通常の論理ボリュームの場合、 -B フラグは無視されます。
-f | 確認を要求せずに論理ボリュームを除去します。
-p PhysicalVolume | PhysicalVolume 上の論理区画のみ削除します。 他に未割り当ての物理区画がない限り、論理ボリュームは削除されません。 重要: 論理ボリュームが複数の物理ボリュームにまたがっている場合、 PhysicalVolume 上の論理区画のみを除去すると、論理ボリューム全体の整合性が損なわれる可能性があります。
-w | スペース・レクラメーション処理の完了を待機します。 注: スペース再利用の完了の待機時間は、物理区画の数によって異なります。

例
重要:
この例で使用されているコマンドは、論理ボリューム内のすべてのデータを破棄します。
ユーザーの確認を要求させずに論理ボリューム
lv05
を除去するには、以下のコマンドを入力します。
rmlv
-f
lv05
論理ボリュームがボリューム・グループから除去されます。
