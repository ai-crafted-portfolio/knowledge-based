目的
運勢のデータベースから無作為に運勢を表示します。

説明
fortune
コマンドは、
fortunes.dat
ファイルまたは
File
パラメーターで指定されたファイルから運勢を表示します。 運勢を表示した後、
fortune
コマンドは終了します。

構文
財産 [ - ] [ -S | - | -a 値 [ -w (W) ] ] [ ファイル ]

オプション
フラグ
項目 | 説明
- | 使用方法の概要を表示します。
-a | 両方のタイプの運勢を表示します。
-l | 長期的な運勢だけを表示します。
-s | 短期的な運勢だけを表示します。
-w | 運勢を表示した後、ユーザーがそれを読む間待機します。
