目的
ネットワークファイルシステム( NFS )のチューニングパラメータを管理する。

説明
nfso
コマンドは NFS チューニング・パラメーターを設定する。
nfso
コマンドは、 NFS チューニング・パラメーターの現在または次のブート値を設定または表示する。 このコマンドは、恒久的な変更を加えることも、次の再起動まで変更を延期することもできる。 付随するフラグは、コマンドがパラメーターを設定するか表示するかを決定する。
-o
フラグは、パラメーターの値を表示したり、パラメーターに新しい値を設定したりできます。
調整可能なパラメーターを変更した場合の効果
nfso
コマンドを誤用すると、システムが操作不能になることがあります。
チューナブル・パラメーターの変更とその目的についての詳細は、チューナ
ブル・
パラメーターのセクションのチューナブル・パラメーターの特性を参照のこと。
調整可能なパラメータの「診断」と「調整」のセクションが、あなたの状況に当てはまることを確認してください。 チューナブル・パラメーターの値を変更することで、システムのパフォーマンスが向上する可能性があります。
Diagnosis（診断）セクションとTuning（チューニング）セクションの両方が「N/A」のみの場合、開発部からの指示がない限り、チューニング可能なパラメータを変更しないでください。
AIX
の指示がない限り、調整可能なパラメータを変更しないでください。

構文
nfso [ -p | -r ] [ -c ] { -o Tunable [ = newvalue ] } nfso [ -p | -r ] { -d Tunable } nfso [ -p | -r ] -D nfso [ -p | -r ] -a [ -F ] [ -c ] nfso -h [ Tunable ] nfso -l [ hostname ] nfso [ -F ] -L [ Tunable ] nfso [ -F ] -x [ Tunable ] nfso [ -@ WparName ] [ -p | -r ] -a [ -c ] nfso [ -@ WparName ] [ -p | -r ] [ -c ] { -o Tunable [ = newvalue ] } nfso -H {ha operation} 注： -o 、 -d 、 -x 、 -L のような複数のフラグを使用することができる。
