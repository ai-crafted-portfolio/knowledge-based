目的
オブジェクト・ファイルのプロファイル・データを表示します。

説明
prof
コマンドは、オブジェクト・ファイル
Program
(デフォルトでは
a.out
) の
monitor
サブルーチンによって収集されたプロファイル・データを解釈します。 これは、オブジェクト・ファイル
Program
内の記号テーブルを読み取って、プロファイル・ファイル (デフォルトでは
mon.out
) と関連付けます。
prof
コマンドは、外部テキストの記号ごとに、その記号のアドレスから次の記号のアドレスまでに費やされた実行時間のパーセンテージ、関数のコール回数、およびコール 1 回当たりの平均ミリ秒数を表示します。
注:
C++ オブジェクト・ファイルからのシンボルの名前は、使用される前にデマングルされます。
関数の呼び出し回数を集計するには、
-p
フラグを指定した
cc
コマンドを使用してファイルをコンパイルしておく必要があります。
-p
フラグによって、コンパイラーは
mcount
サブルーチンのコールを、プログラムの再コンパイル後の各関数に対して生成されたオブジェクト・コードに挿入させます。 プログラムの実行中、親関数が子関数をコールするたびに、子関数は
mcount
サブルーチンをコールして、その親子の対に対して専用のカウンターを増やします。
-p
フラグで再コンパイルされないプログラムには、挿入される
mcount
サブルーチンがないため、どの関数がそれらを呼び出したかを記録しません。
また
-p
フラグは、プログラム開始時と終了時に
monitor
サブルーチンをコールする特別プロファイル始動関数がオブジェクト・ファイルに含まれるようにします。 プログラムが終了し、
mon.out
ファイルを書き込むときの
monitor
サブルーチンの呼び出し。 したがって、明示的にメインプログラムを終了させるかまたはメインプログラムから戻るプログラムのみが、
mon.out
ファイルを作成します。
注:
生成された出力ファイルの名前を変更するには、PROF 環境変数を使用して、次のように設定します。
PROF=filename:<filename>
例えば、
PROF=myprof
を設定した場合、生成されるファイルの名前は
myprof.out
になります。
ロードされたオブジェクトの位置および名前は
mon.out
ファイルに保管されます。 フラグを選択しない場合、
prof
はこれらの名前を使用します。 プログラムを指定するか、
-L
オプションを使用して他のオブジェクトにアクセスしてください。
注:

インポートされた外部ルーチン呼び出し (共有ライブラリー・ルーチンへの呼び出しなど) には、実際のルーチンへの呼び出しをセットアップするローカル
glink
コードへの中間呼び出しがあります。 このコードの実行中にタイマー・クロックがオフになると、時間は
routine
.gl
と呼ばれるルーチンにカウントされます。ここで、
routine
はコール先のルーチンです。 例えば、
glink
コードが
printf
サブルーチンをコールしている間にタイマーがオフになると、時間は
printf.gl
ルーチンにカウントされます。

構文
prof [ -t | -c | -a| -n ] [ -o | -x ] [ -g ] [ -z ] [ -h ] [ -s ] [ -S ] [ -v ] [ -L PathName ] [ Program ] [ -m MonitorData ... ]

オプション
フラグ
互いに排他的なフラグ
a
、
c
、
n
、および
t
によって、
prof
コマンドが出力行をソートする方法が決まります。
表 1. フラグ
項目 | 説明
-a | シンボル・アドレスを大きくしてソートします。
-c | 呼び出し回数を減らしてソートします。
-n | シンボル名の字句別にソートします。
-t | 合計時間のパーセンテージの降順でソートします (デフォルト)。
注:
同じコマンドで複数のフラグ
a
、
c
、
n
、および
t
を使用した場合でも、
prof
コマンドは正常に実行できます。
prof
コマンドは、コマンド行で検出したこれらのフラグの最初のフラグを受け入れ、その他のフラグは無視します。
相互に排他的なフラグ
o
および
x
は、モニターされる各記号のアドレスの表示方法を指定します。
項目 | 説明
-o | 各アドレスをシンボル名とともに 8 進数で表示します。
-x | 各アドレスをシンボル名とともに 16 進数で表示します。
注:
同じコマンドで
-o
フラグと
-x
フラグの両方を使用した場合でも、
prof
コマンドは正常に実行できます。
prof
コマンドは、コマンド行で検出したこれら 2 つのフラグのうちの最初のフラグを受け入れ、もう一方のフラグを無視します。
注。
以下のフラグは任意に組み合わせて使用できます。
項目 | 説明
-g | 非グローバル記号 (静的関数) を含めます。
-h | レポートに通常表示される見出しを抑止します。 これは、レポートをさらに処理する場合に有効です。
-L PathName | 共有オブジェクトの位置を決定するときに使用する代替パス名を使用します。
-m MonitorData | mon.out ではなく、 MonitorData からプロファイル・データを取得します。
-s | mon.sum に要約ファイルを生成します。 これは、複数のプロファイル・ファイルを指定するときに有効です。
-S | 標準エラーにモニター・パラメーターおよび統計情報の要約を表示します。
-v | すべての表示を抑制し、プロット・フィルターで表示できるように標準出力に図形バージョンのプロファイルを送信します。 そのため、プロット時に、低い数値と高い数値 (デフォルトでは 0 と 100) を指定することで、プロファイルの選択されたパーセンテージをより高い解像度でプロットすることができます。

-z | 0 (ゼロ) コールおよび 0 (ゼロ) 時間に関連している場合でも、すべての記号をプロファイルの範囲内に含めます。

例
時間でソートされた各シンボル・アドレスで費やされた時間を、ヘッダーなしで表示するには、次のように入力します。
prof -t -h
以下の例では、
/home/score/lib
ディレクトリーに
runfile
ファイルを作成するために使用される共有ライブラリーのローカル・バージョンを取得します。 使用されるデータ・ファイルは、
mon.out
ではなく
runfile.mon
になります。
prof -x -L/home/score/lib runfile -m runfile.mon
