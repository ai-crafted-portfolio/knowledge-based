目的
メッセージ・ハンドラー (MH) のアドレスを操作します。

説明
whom
コマンドは以下のことを行います。
メッセージのヘッダーをアドレスのセットに展開します。
メッセージの提案された受信者のアドレスをリストします。
は、アドレスがトランスポート・サービスに配信可能であることを確認します。
“
注:
whom
コマンドは、送信可能なアドレスとしてリストされた宛先に実際に送信されるかどうかについては保証しません。
”
メッセージはドラフト・フォルダーまたはファイルに入れることができます。 メッセージの保管場所を指定するには、
-draft
、
-draftfolder
、
-draftmessage
のフラグを使用してください。
-draftfolder
フラグが指定されていない場合、または
Draft-Folder:
$HOME/.mh_profile
ファイル内のエントリーが定義されていません。
workstation
コマンドは MH ディレクトリーで
draft
ファイルを検索します。
-draftfolder +
Folder
フラグの後にメッセージを指定すると、
-draftmessage
フラグを指定した場合と同じになります。

構文
対象者 [ -別名 ファイル ... ] [ -nocheck (検査なし) | -チェック ] [ { -draftfolder + フォルダー | -nodrafth旧 | ファイル }{ -draftmessage メッセージ | -ドラフト ファイル } ]

オプション
フラグ
項目 | 説明
-alias ファイル | メール別名を検索するファイルを指定します。 デフォルトの場合は、システムは /etc/mh/Mailaliases ファイルを検索します。
-ドラフト | UserMhDirectory /draft ファイルのヘッダー情報 (存在する場合) を使用します。
-draftfolder + フォルダー | 指定したフォルダー内のドラフト・メッセージからのヘッダー情報を使用します。 存在しないドラフト・フォルダーを指定した場合には、システムが新規に作成します。
-draftmessage メッセージ | 指定したドラフト・メッセージからのヘッダー情報を使用します。
-help | これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。 “ 注: MH の場合は、このフラグ名を省略することはできません。 ”
Message | メッセージ・ドラフトを指定します。 下記のものを使ってメッセージを指定します。 Number メッセージ番号。 cur または 。 (ピリオド) 現行メッセージ。 これはデフォルトです。 first フォルダー内の最初のメッセージ last フォルダー内の最後のメッセージ 次へ 現行メッセージの次のメッセージ prev 現行メッセージの直前のメッセージ。
-ノドラフトフォルダー | -draftfolder + Folder フラグの最後のオカレンスを取り消します。
“
注:
他の 2 つのフラグ
-check
および
-nocheck
も使用できます。 これらのフラグを指定しても、
whom
コマンドの検査方法は変わりません。
-check
フラグおよび
-nocheck
フラグは互換性だけを検査するものです。
”
