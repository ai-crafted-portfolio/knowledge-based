目的
メッセージに応答します。

説明
repl
コマンドは、ユーザーがメッセージに対する応答を作成できるように、インターフェースを始動させます。 デフォルトでは、このコマンドは現行フォルダー内の現行メッセージの応答のドラフトを作成します。
-draftfolder
フラグが指定されていない場合、または
Draft-Folder:
$HOME/.mh_profile
ファイル内のエントリーが未定義の場合、
repl
コマンドは MH ディレクトリーで
draft
ファイルを検索します。 フォルダーを指定すると、そのフォルダーが現行フォルダーになります。
複製
コマンドを入力すると、システムは、
To:
,
cc:
および
In-Reply-To:
応答のテキストの入力を求めるプロンプトが出されます。 エディターを終了するには、Ctrl-D を押します。 エディターが終了すると、
repl
コマンドは MH の
whatnow
コマンドを始動します。 以下の場所で Enter キーを押すと、使用可能な
Whatnow
サブコマンドのリストを表示できます。
What now?
できます。 これらのサブコマンドを使用すると、応答の再編集、リスト、送信、または
repl
コマンド処理の終了を実行できます。
注:
メッセージの送信時にメッセージが識別されるようにするには、メッセージのヘッダーと本文の間にダッシュ 1 行またはブランク行を残しておく必要があります。
repl
コマンドは、
/etc/mh/replcomps
ファイル内の定義を使用して、応答メッセージをフォーマットします。 MH ディレクトリー内で
replcomps
ファイルを作成したり、または
-form
フラグを使用して、代替応答フォーマットを定義することができます。 オリジナル・メッセージのコピーをそのまま応答メッセージ内に残すには、
-filter
フラグを使用します。
元のメッセージに再配布情報に関する注釈を付けるには、
-annotate
フラグを使用します。 このフラグは、元のメッセージに以下の注釈を付けます。
Resent:
および現在の日付と時刻を示します。
repl
コマンド処理を終了する前に応答を送信した場合のみ、メッセージに注釈が付けられます。

構文
複製 [ + フォルダー ] [ -draftfolder + フォルダー | -nodraftfolder ] [ メッセージ ] [ -draftmessage メッセージ ] [ -注釈を付ける [ -ノインプレース | -inplace (インプレース) ] | -注釈なし ] [ -CC 名前 ... ] [ -nocc 名称 ... ] [ -照会 | -noquery (照会なし) ] [ -fcc + フォルダー ] [ -形式 FormFile ] [ -エディター 編集者 | -noedit (編集不可) ] [ -format (フォーマット) | -noformat (フォーマットなし) ] [ -フィルター ファイル ] [ -幅 数値 ] [ -whatnowproc (whatnowproc) プログラム | -nowhatnowproc (処理なし) ]

オプション
フラグ
項目 | 説明
-注釈を付ける | 応答中のメッセージに注釈として応答日時を付けます。 -inplace フラグを使用すると、注釈付きメッセージへのリンクを保存することができます。
-CC 名称 | リストされるユーザーを指定します。 cc: 応答のフィールド。 Names には、 all 、 to 、 cc 、および me を指定できます。 デフォルトは -cc all です。
-draftfolder + フォルダー | 指定したフォルダーにドラフト・メッセージを入れます。 + フォルダー が指定されていない場合は、以下のようになります。 Current-Folder と見なされます。
-draftmessage メッセージ | ドラフト・メッセージを指定します。 -draftmessage フラグを付けずに -draftfolder を指定すると、デフォルト・メッセージは新規となります。 -draftfolder フラグを付けずにこのフラグを指定すると、システムはデフォルト・ファイル UserMHdirectory / draft 内でドラフト・メッセージを作成します。
-editor エディター | 応答を構成する最初のエディターを識別します。 -エディター フラグを指定しない場合、 競合 コマンドは、以下によって指定されたデフォルト・エディターを選択します。 Editor: $HOME/.mh_profile ファイル内のエントリー。
-fcc + フォルダー | 指定されたフォルダー内に応答のファイル・コピーを入れます。 このフラグを指定しなければ、 repl コマンドはファイル・コピーを生成しません。
-フィルター ファイル | 応答されるメッセージを再フォーマットして、再フォーマットされたメッセージを応答文中に入れます。 File 変数を指定するときはこのフラグも指定しなければなりません。 -filter フラグは、 mhl コマンドで使えるフォーマット・ファイルを使用します。
+ フォルダー | 応答対象となるメッセージが入っているフォルダーを識別します。 フォルダーが指定されていない場合は、次のようになります。 Current-Folder 使用されます。
-フォーム FormFile | 応答フォーマットを指定します。 repl コマンドは、指定されたフォーマット・ファイル内の各行をフォーマット文字列として処理します。

- 形式 | 重複するアドレスを削除します。 To: , cc: および Bcc: -幅 フラグで指定された列を使用して、これらのフィールドを標準化します。 -format フラグは、デフォルトとしてインターネット・フォーマットを使用するかどうかを示します。
-help | これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。 注: MH の場合は、このフラグ名を省略することはできません。
-inplace | 注釈付きメッセージとのリンクを保存するために、注釈付けが所定の箇所で強制的に行われるようにします。
Message | メッセージを指定します。 応答対象のメッセージとメッセージ・ドラフトの両方を指定する場合は、 -draftmessge フラグを使用しなければなりません。 以下を使用してメッセージを定義します。 Number メッセージ番号。 cur または 。 (ピリオド) 現行メッセージ。 デフォルトの応答メッセージ。 first フォルダー内の最初のメッセージ last フォルダー内の最後のメッセージ NEW 新たに作成するメッセージ。 デフォルトのドラフト・メッセージは new です。 次へ 現行メッセージの次のメッセージ prev 現行メッセージの直前のメッセージ。
-注釈なし | 注釈を付けません。 このフラグはデフォルトです。
-nocc 名称 | リストされないユーザーを指定することができます。 cc: 応答のフィールド。 Names には all 、 to 、 cc 、および me を指定できます。
-ノドラフトフォルダー | UserMhDirectory /draft 内にドラフトを配置します。
-noedit (編集不可) | 初期編集を抑制します。
-noformat (フォーマットなし) | 重複するアドレスの削除を両方とも抑止します。 To: , cc: および Bcc: これらのフィールドの標準化を行います。
-ノインプレース | 適切な注釈付けを強制しません。 このフラグはデフォルトです。
-noquery (照会なし) | 自動的にビルド To: および cc: フィールド このフラグはデフォルトです。
-nowhatnowproc (処理なし) | repl コマンドが対話式で処理されないようにします。 このフラグを付けると編集できなくなります。
-query | 次の場所に各アドレスを含める許可をユーザーに照会します: To: および cc: フィールド

-whatnowproc プログラム | ユーザーに応答タスクについて指示を与えるプログラムとして、指定のコマンド・ストリングを始動させます。 デフォルトは、 whatnow プログラムです。
-幅 数値 | アドレス・フィールドの幅を設定します。 デフォルトは 72 桁です。

例
現行フォルダー内の現行メッセージに応答するには、次のように入力します。
repl
システムは以下のようなテキストで応答します。
To: patrick@venus
cc: tom@thomas
Subject: Re: Meeting on Monday
In-reply-to: (Your message of Thu, 21 Jul 88 13:39:34 CST.)
<8807211839.AA01868>
--------------
これで応答を入力できます。 応答の本文を入力し終えたら、Ctrl-D キー・シーケンスを押してエディターを終了させます。 システムは以下のように応答します。
What now?
実行
send
応答を送信します。 サブコマンドのリストを表示したければ、Enter キーを押します。 この例では、現行フォルダー内の現行メッセージに応答を送信することになります。
メッセージに応答を送信するには
4
合計の
inbox
次のように入力します。
repl
+
inbox 4

cc: jay@venus

In-reply-to: (Your message of Thu, 21 Jul 88 13:39:34 CST.)
<8807211839.AA01868>

これで応答を入力できます。 応答の本文を入力し終えたら、Ctrl-D キー・シーケンスを押してエディターを終了させます。 システムは以下のように応答します。
What now?
