目的

Server Message Block (SMB) クライアント・ファイルシステム・エントリーを /etc/filesystems ファイルから削除し、その SMB クライアント・ファイルシステムがマウントされている場合はアンマウントします。

構文

rmsmbcmnt -f MountPoint [-B | -N | -I]

説明

rmsmbcmnt コマンドは、SMB クライアント・ファイルシステム・エントリーを /etc/filesystems ファイルから削除します。 SMB クライアント・ファイルシステムがマウントされている場合、rmsmbcmnt コマンドがそのファイルシステムをアンマウントします。

フラグ

-B
対応する SMB クライアント・ファイルシステム・エントリーを /etc/filesystems ファイルから削除し、その SMB クライアント・ファイルシステムをアンマウントします。 これがデフォルト設定です。
-f MountPoint
SMB クライアント・マウント・ポイントのパス名を指定します。
-I
ファイル・システムをアンマウントしませんが、ファイル・システムが既にアンマウントされている場合にのみ、 /etc/filesystems ファイルからエントリーを除去します。
-N
SMB クライアント・ファイルシステムをアンマウントしますが、その SMB エントリーは /etc/filesystems ファイルから削除しません。

終了状況

0
コマンドは正常に完了しました。
>0
エラーが発生しました。

例

/mnt マウント・ポイントを使用してマウントされている SMB エントリーを削除し、その SMB クライアント・ファイルシステムをアンマウントするには、次のコマンドを入力します。
rmsmbcmnt -f /mnt

場所

/usr/sbin/rmsmbcmnt

ファイル

/etc/filesystems
SMB クライアント・マウント・ポイントが入っている SMB クライアント・ファイルシステム・エントリーを保管します。
