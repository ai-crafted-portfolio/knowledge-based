目的
hosts ファイルから、LDAP データ交換形式 (LDIF) ファイルを作成します。

説明
/usr/sbin/hosts2ldif
コマンドは、
/etc/hosts
ファイル、
あるいは
/etc/hosts
に似た別のファイルから、
LDAP データ交換形式を作成します。 フラグを指定しない場合、
/etc/hosts
ファイルは、以下のコマンドを使用して
/tmp/hosts.ldif
のLDIFファイルを作成するために使用されます
cn=hosts
baseDNとして指定します。
このコマンドによって作成される LDIF ファイルは、 SecureWay ディレクトリー・スキーマに準拠し、
ldap
メカニズムのセットアップに使用されます。
ldap
メカニズムはサポートされていますが、
ldap
メカニズムではなく、
nis_ldap
メカニズムの使用をお勧めします。

構文
hosts2ldif [ -i InputFile ][ -o OutputFile ][ -s SearchBase ]

オプション
フラグ
項目 | 説明
-i InputFile | 入力に使用する hosts ファイルを指定します。
-o OutputFile | 出力に使用する LDIF ファイルを指定します。
-s SearchBase | LDAP サーバー上で、ホスト・テーブルの baseDN を指定します。

例
/etc/hosts
ファイルから
/home/ldifhosts
を作成するには、
次のように入力します。
hosts2ldif -o /home/ldifhosts
/home/hosts.bak
ファイルから、
/tmp/hosts.ldif
を作成するには、次のように入力します。
hosts2ldif -i /home/hosts.bak
/home/ldifhosts
を
/etc/hosts
ファイルから作成するには、次のようにします。
cn=hosttab
を baseDN, ：
hosts2ldif -o /home/ldifhosts -s cn=hosttab
