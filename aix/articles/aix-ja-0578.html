目的
システム構成データベース内のアドレス・マッピング・エントリーを直接操作します。

説明
hostent
低レベル・コマンドは、システム構成データベース内でアドレス・マッピング・エントリーを追加、削除、または変更します。 データベース内のエントリーは、インターネット・プロトコル (IP) アドレス (ローカルまたはリモート) を等価のホスト名にマッピングするときに使います。
hostent
コマンドは、
/etc/hosts
ファイル内のアドレスからホスト名へのマッピング・エントリーを 1 つまたはすべて表示できます。 所定のローカルまたはリモート・ホストのインターネット・プロトコル (IP) アドレスは、1 つ以上のホスト名に対応付けることができます。 IP アドレスを表すには、小数点付き 10 進の構文を使います。 ホスト名は最大長が 255 文字の文字列として表され、ブランク文字は使いません。 各エントリーは 1 行に設定しなければなりません。 複数の
HostNames
(または別名) を指定できます。
注:
有効なホスト名または別名のホスト名には、少なくとも 1 文字が含まれている必要があります。
x
で始まり、その後に 16 進数字 (
0-f
) が続くホスト名または別名を指定する場合、そのホスト名または別名には、16 進数字として表すことができない別の文字が少なくとも 1 つ含まれていなければなりません。 システムは、ホスト名または別名に 16 進数字以外の文字が少なくとも 1 文字ある場合を除き、16 進数字が後に続く先行
x
をアドレスの
base 16
表記として解釈します。 したがって、
xdeer
は有効なホスト名でなければなりませんが、
xdee
はそうではありません。
System Management Interface Tool (SMIT) の
smit hostent
高速パスを使用して、このコマンドを実行できます。

構文
Address-to-Host 名前マッピングを追加する hostent -a IPAddress -h "HostName..." Address-to-Host 名前マッピングを削除する hostent -d IPAddress すべてのアドレスからホスト名へのマッピングを削除するには hostent -X アドレスからホスト名へのマッピングを変更するには hostent -c IPAddress -h "HostName..." [ -i NewIPAddress ] アドレスまたはホスト名をコロン・フォーマットで表示するには hostent -s { IPAddress | "HostName" } [ -Z ] アドレスからホスト名へのすべてのマッピングをコロン・フォーマットで表示するには hostent -s [ -Z ]

オプション
フラグ
注:
-a
、
-d
、
-c
、および
-s
フラグを一緒に使用することはできません。
項目 | 説明
-a IP アドレス | データベース内の IP アドレスの IP アドレスからホスト名へのマッピング・エントリーを追加します。 -h フラグを使用してホスト名を指定します。
-c IP アドレス | IPAddress 変数により指定されたアドレスに対応するデータベース内で、アドレスからホスト名へのマッピング・エントリーを変更します。 -h フラグを使用して、変更されたホスト名を指定します。 現在の IP アドレスを新しいアドレス ( IPAddress ) に変更する場合は、 -i フラグを使用します。
-d IP アドレス | IPAddress 変数により指定されたアドレスに対応するデータベース内で、IP アドレスからホスト名へのマッピング・エントリーを削除します。
-h " HostName ..." | ホスト名のリストを指定します。 リスト内のエントリーはブランクで区切ります。 -h " HostName ..." フラグは、 -a フラグと一緒に使用する必要があります。 -c フラグでは、 -h " HostNameも必要になる場合があります。 .." フラグ。
-i NewIPAddress | 新しい IP アドレスを指定します。 このフラグは、既存の IP アドレスを NewIPAddress 変数で置き換える場合に、 -c フラグによって必要とされます。
-s | データベース内のすべての項目を表示します。
-s " HostName " | " HostName " 変数で指定されたホスト名と一致する IP アドレスからホスト名へのマッピング項目を表示します。
-s IP アドレス | IPAddress 変数で指定された項目と一致する IP アドレスからホスト名へのマッピング項目を表示します。
-X | データベース内で IP アドレスからホスト名へのマッピング・エントリーをすべて削除します。
-Z | コロン・フォーマットで照会のレポートを生成します。 このフラグは、 hostent コマンドを SMIT ユーザビリティー・インターフェースから開始する場合に使用します。
注:
hostent
コマンドは、アドレス
0.08
、
.008
、
.09
、および
.009
を認識します。 先行ゼロが付いたアドレスは 8 進として解釈され、8 進数には 8 または 9 が使えません。

例
アドレスを一連のホスト名に関連付ける項目をデータベースに追加するには、次の形式でコマンドを入力します。
:
hostent
-a
192.100.201.7
-h
"alpha bravo charlie"
例 1 では、1 次ホスト名が
alpha
で、シノニムが
bravo
および
charlie
のホストのアドレスとして IP アドレス
192.100.201.7
が指定されています。
ホスト名に一致するデータベース内の項目を表示するには、次の形式でコマンドを入力します。
hostent
-s
alpha
例 2 では、表示されるエントリーはホスト名
alpha
と一致します。
エントリーの IP アドレスを新しい IP アドレスに変更するには、次の形式でコマンドを入力します。
hostent
-c
192.100.201.7
-i
192.100.201.8
例 3 では、古い IP アドレスが
192.100.201.7
で、
新アドレスは
192.100.201.8
です。
