目的
論理ボリュームの内容を新しい論理ボリュームにコピーします。

説明
注意:
データが入っている大きい論理ボリュームから小さい論理ボリュームにコピーしないでください。 これを実行すると、一部のデータ (スーパーブロックなど) がコピーされないので、その
結果ファイルシステムが破壊されます。
cplv
が新しい論理ボリュームを作成し、
ボリューム・グループがコンカレント・モードで vary on されている場合は、
このコマンドは失敗します。
cplv
コマンドは、
SourceLogicalVolume
の内容を新規または既存の
DestinationLogicalVolume
に
コピー
します。
SourceLogicalVolume
パラメーターは、論理ボリューム名または論理ボリューム ID となります。
cplv
コマンドは、デフォルトの構文を使うと、システムが生成する名前で新しい論理ボリュームを作成します。 システムが生成する名前は表示されます。
注:
ストライピングされた論理ボリュームをコピーする場合、
コピー先の論理ボリュームが存在しなければ、
ソース論理ボリュームのストライピングされたブロック・サイズとストライプ幅を含む、
同一のコピーが作成されてからデータがコピーされます。
ストライピングされた論理ボリュームをコピーする場合、
異なるストライプ・ブロック・サイズとストライプ幅を指定して
mklv
コマンドを使ってコピー先論理ボリュームを作成してある場合、
またはコピー先がストライピングされた論理ボリュームでない場合は、
新しい特性が保守され、データはソース論理ボリュームからコピーされます。
このコマンドを使用するには、root ユーザー権限を持っているか、あるいは
system
グループのメンバーでなければなりません。
cplv
コマンドは、スナップショット・ボリューム・グループでは使用できません。
SourceLogicalVolume
が jfs またはjfs2タイプの場合、'
cplv
コマンドを実行する前に、 ファイル・システムが正常にアンマウントされ、新しく作成されたファイル・システムで
fsck が
正常に実行されなければならない。 新規ファイルシステムをマウントする前に
fsck
コマンドを実行すると、
スーパーブロック内に含まれるロギング用装置が依然として元のファイルシステムを参照するため、エラーが戻されます。
fsck
の実行前に新規ファイルシステムをマウントし、新規ロギング用装置が作成されるようにしてください。
新しい論理ボリュームは、元の論理ボリュームと同じ暗号化ポリシーに従います。

cplv
コマンドは、パスフレーズ認証方式を、暗号化された元の論理ボリュームから新しい論理ボリュームにコピーします。 新しいパスフレーズ認証方式を追加するには、
-I
フラグを使用します。
元の論理ボリュームにプラットフォーム鍵ストア (PKS) 認証方式があり、PKS 鍵スロットが使用可能である場合、
cplv
コマンドは PKS 方式を新しい論理ボリュームに追加します。
このコマンドは、System Management Interface Tool (SMIT)
smit cplv
高速パスによって実行することができます。

構文
新しい論理ボリュームにコピーする cplv [-v VolumeGroup] [-y NewLogicalVolume| -Y Prefix ] [-I ] SourceLogicalVolume 既存の論理ボリュームにコピーする cplv -e DestinationLogicalVolume [-f ] SourceLogicalVolume

オプション
フラグ
項目 | 説明
-e | DestinationLogicalVolume に既存の論理ボリュームを指定し、存在しなくても作成されないことを指定します。 DestinationLogicalVolume が SourceLogicalVolume より小さい場合、余分な論理区画はコピーされません。 このフラグを使うと、 DestinationLogicalVolume 内に既に存在していたデータが破壊されます。 このため、 -f フラグが追加されない限り、ユーザー確認が必要です。 データを不注意に上書きしないように、 DestinationLogicalVolume の Type 特性は copy でなければなりません。 Type 特性 を変更するには、 chlv コマンドを使用します。
-f | ユーザーに確認せずに既存の論理ボリュームをコピーします。
-I | これは、新しいパスフレーズ認証方式を新しい論理ボリュームに追加します。 これは、標準入力から新しいパスフレーズを読み取ります。 このフラグを使用する場合は、新しい論理ボリュームについてのみパスフレーズ認証方式を追加できます。
-v VolumeGroup | 新しい論理ボリュームが入るボリューム・グループを指定します。 このフラグを指定しないと、新しい論理ボリュームは、 SourceLogicalVolume と同じボリューム・グループの中に入ります。
-y NewLogicalVolume | 新しい論理ボリュームに関して、システム生成名の代わりに使う名前を指定します。 論理ボリューム名はシステム全体で固有となる名前でなければならず、1 文字から 15 文字までの範囲で指定できます。
-Y 接頭部 | 新しい論理ボリュームに関してシステム生成名を構築するときに使う接頭部を指定します。 接頭部は 13 文字以下でなければなりません。 この名前は、他のデバイスに関してデバイス構成データベース内の PdDv クラス内で定義済みの接頭部で始めることはできません。また、別のデバイスが既に使っている名前は使えません。

例
論理ボリュームの内容をコピーする
fslv03
新規論理ボリュームに対して、次のように入力します。
cplv fslv03
新規論理ボリュームが作成され、以下と同じボリューム・グループに配置されます。
fslv03
名前はシステムによって指定されます。
論理ボリュームの内容をコピーする
fslv03
ボリューム・グループ内の新規論理ボリュームへの
vg02
、タイプ:
cplv -v vg02 fslv03
fslv03
はコピー元の論理ボリューム名です。 これは必須フィールドです。 新規論理ボリュームが作成され、名前が付けられ、ボリューム・グループに追加されます。
vg02
.
論理ボリュームの内容をコピーする
lv02
より小さい既存の論理ボリュームに
lvtes
ユーザー確認を必要とせずに、次のように入力します。
cplv -e lvtest -f lv02
