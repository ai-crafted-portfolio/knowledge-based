目的

これは、/etc/filesystems ファイルに定義されている Server Message Block (SMB) クライアント・マウント・ポイントをリストします。

構文

lssmbcmnt [-c | -l | -p] [FileSystem]

説明

lssmbcmnt コマンドは、/etc/filesystems ファイルに定義されている指定の SMB マウント・ポイントをリストします。

フラグ

-c
これは、コロン区切りのフォーマットで SMB クライアント・マウント・ポイントを表示します。
-l
これは、各フィールドが空白文字で区切られた標準フォーマットで SMB クライアント・マウント・ポイントを表示します。 これがデフォルト設定です。
-p
これは、パイプ区切りのフォーマットで SMB クライアント・マウント・ポイントを表示します。

パラメーター

FileSystem
これは、指定の SMB クライアント・ファイルシステムの特性を表示します。 このパラメーターが指定されない場合は、すべての SMB クライアント・ファイルシステムが表示されます。

終了状況

0
コマンドは正常に完了しました。
>0
エラーが発生しました。

例

  • /etc/filesystems ファイルに定義されている SMB クライアント・マウント・ポイントをすべてリストするには、次のコマンドを入力します。
    lssmbcmnt
  • コロン区切りのフォーマットで SMB クライアント・マウント・ポイントをすべてリストするには、次のコマンドを入力します。
    lssmbmnt -c
  • SMB クライアント・マウント・ポイント /mnt の SMB クライアント・ファイルシステム・エントリーをリストするには、次のコマンドを入力します。
    lssmbmnt /mnt

ロケーション

/usr/sbin/lssmbcmnt
