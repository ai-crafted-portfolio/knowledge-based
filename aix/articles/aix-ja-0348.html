sanitize
オペレーションをサポートするNVMe対応デバイスで、NVMe（Non-Volatile Memory Express）の「
sanitize
コマンドを実行する。 NVMeの「
sanitize
操作は、キャッシュや不揮発性メディアから以前のユーザーデータを復元できないように、不揮発性メモリ（NVM）サブシステムを変更します。 SED対応ドライブの「
sanitize
操作は、SED対応ドライブを工場出荷時の設定に戻します。
このコマンドは、System Management Interface Tool (SMIT)
smit
diag
高速パスを使用して実行できます。

構文
diag [ [ -a ] | [ -s [ -c ] ] [ -E days] [ -e] | [ -d Device [ -c ] [ -v ] [ -e ] [ -A ] ] | [ -B [ -c ] ] | [ -T taskname] | [ -S testsuite] | [ -c -d Device -L pending | complete ]

オプション
フラグ
注：
「
diag
コマンドはメニュー主導のプログラムであるため、ほとんどのユーザーはフラグを使用する必要はない。
表 1. フラグ
項目 | 説明
-A | 拡張モードを指定します。 また、「 -d フラグを使用してデバイスを指定する。
-a | 脱落リソースが除去されたかどうか、オフになったかどうかなどを質問することによって、ハードウェア構成の変更を処理します。 欠落しているリソース（Mで表示）および欠落しているリソースパス（Pで表示）は、診断リソース選択リストに統合される。
-B | 診断テストで、基本システムのテストを実行するように指示します。 エラー・ログ分析をサポートする基本システムの領域では、エラー・ログ分析も行われます。
-c | マシンが無人で動作することを示します。 (マシンからの質問は行われません。) 結果は標準出力に書き出されます。 また、テストするデバイスを指定するオプションのフラグ（ d 、' B 、' s ）を使用する。
-d Device | 診断テストを行うデバイスを指定します。
-E 日 | エラー・ログ分析の実行の際、エラー・ログを検索するために使用する日数を指定します。 このフラグは、他のフラグとともに動作します。
-e | エラー・ログ解析を実行します (選択されたデバイスでサポートされている場合)。 テストは行われません。 このフラグは「 -d フラグと一緒に使用しなければならない。 そうでない場合は、リソース選択メニューが表示される。 -v フラグとともに使用された場合は、 -v フラグが優先され、 -e フラグは無視されます。
-S テストスイート | 以下のような、テスト対象のデバイスからなる特定のテスト・セットを示します。 基本システム 入出力デバイス 非同期デバイス グラフィック・デバイス SCSI デバイス 記憶デバイス 共通デバイス マルチメディア・デバイス
-L ペンディング｜完了 | -d および ' -c オプションで指定したリソースの修復動作を記録する。 部品が交換されたが、その部品がシステムに残っているかどうかがまだわからない場合、 pending パラメータを使用する。 部品が交換され、その部品がシステムに残っていることが分かっている場合は、 完全な パラメータを使用する。
-s | すべてのリソースに対して診断テストを実行します。

-T タスク名 | 実行する特定の高速パス・タスクを指定します。 以下のリストには、現在のfastpathタスクが表示されます： format メディア・フォーマット・タスク certify メディア認証タスク download マイクロコード・ダウンロード・タスク disp_mcode マイクロコード・レベル表示タスク chkspares スペア・セクター可用性タスク identifyRemove ホット・プラグ・タスク nvme_sanitize sanitize オペレーションをサポートするNVMe対応デバイスをサニタイズする。 nvme_sanitize タスクを指定する場合、 -f フラグを使用して force オプションも指定する必要がある。 -f フラグは、' diag コマンドで' -c フラグが指定されたときのみ必要であり、そうでなければ' diag コマンドはエラーで失敗する。 nvme_sanitize タスクは、SED対応ドライブのノーコンソール（コマンドライン）モードではサポートされません。 update システムファームウェアを検証し、更新します（HMC非対応システムの場合 Hardware Management Console ）。 このオプションのフラグ -T は、root ユーザーと ragent ユーザーのみが実行できます。 このオプションはコンソールモードでのみサポートされています。 注: タスクはプラットフォームとデバイスに依存します。 タスクによっては、システムで使用できないものもあります。
-v | システム検証モードで診断テストを実行し、エラーログ解析は実行されない。 デフォルトは、デバイスをテストし、エラー・ログ分析を行う問題判別モードです。 -e フラグとともに使用された場合は、 -v フラグが優先され、 -e フラグは無視されます。 診断テストを実行する デバイスを指定するには、 -d フラグとともに使用する必要があります。

例
問答無用で「
scdisk0
デバイスの診断テストを実行するには、以下のコマンドを入力する：
diag -d scdisk0 -c
NVMeデバイス（
nvmeX
）でNVMeサニタイズ処理を実行するには、以下のコマンドを入力する：
diag -c -d nvmeX -T "nvme_sanitize -f"
