目的
メッセージ・カタログの全部または一部を表示します。

説明
dspcat
コマンドは、特定のメッセージ、セット内のすべてのメッセージ、またはカタログ内のすべてのメッセージを表示します。
dspcat
コマンドは、メッセージを標準出力に出力します。
注:
dspcat
コマンドは、
LC__FASTMSG
属性が C または POSIX ロケール環境で
False
に設定されている場合に、
NLSPATH
環境変数の下でカタログ・ファイルを探します。
LC__FASTMSG
属性は、C および POSIX ロケールにデフォルト・メッセージが使用されること、および
LC__FASTMSG
属性が
True
に設定されている場合に
NLSPATH
環境変数が無視されることを指定します。
LC__FASTMSG
属性のデフォルト値は、
/etc/environment
パスの
True
です。
CatalogName
パラメーターはメッセージ・カタログを指定します。
SetNumber
パラメーターは、
CatalogName
パラメーターで指定したカタログ内のセットを指定します。
MessageNumber
パラメーターは、
SetNumber
パラメーターで指定したセット内の特定のメッセージを指定します。 3 つのパラメーターをすべて指定すると、
dspcat
コマンドは特定のメッセージを表示します。
MessageNumber
パラメーターを指定しないと、
dspcat
コマンドはセット内のすべてのメッセージを表示します。 存在しない
SetNumber
または
MessageNumber
パラメーター値を指定すると、
dspcat
コマンドはエラー・メッセージを表示し、0 以外の戻り値を戻します。
CatalogName
パラメーターだけを指定すると、
dspcat
コマンドはカタログ内のすべてのメッセージを表示します。
MessageNumber
パラメーターを設定する場合は、必ず
SetNumber
パラメーターを指定する必要があります。
CatalogName
パラメーターの値に/(スラッシュ) 文字を使用しない場合は、
dspcat
コマンドは、
NLSPATH
環境変数および
LC_MESSAGES
カテゴリーを使用して、指定されたメッセージ・カタログを検索します。

構文
カタログ内のメッセージを表示する dspcat CatalogName [ SetNumber [ MessageNumber ]] gencat コマンド用に出力をフォーマットする dspcat -g CatalogName [ SetNumber ]

オプション
フラグ
項目 | 説明
-g | gencat コマンドへの入力として使われる出力をフォーマットします。 MessageNumber パラメーターは、 -g フラグを使用する場合は無効です。

例
メッセージ番号を表示する
2
セット番号
1
世界とは
test.cat
ファイル、入力:
dspcat test.cat 1 2
