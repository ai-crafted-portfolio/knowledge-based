目的
ダンプ圧縮ファイルを復元します。

説明
dmpuncompress
コマンドは、ダンプ時に圧縮された元のダンプ・ファイルを復元します。
File
パラメーターで指定された各圧縮ファイルは、解凍コピーによって除去および置換されます。 解凍されたファイルの名前は、圧縮バージョンと同じですが、拡張子
.BZ
は付きません。 ユーザーが root 権限を持っている場合、この解凍ファイルは、元のファイルと同じ所有者、グループ、モード、および変更時刻を保持します。 ユーザーが root 権限を持っていない場合、このファイルは同じモードおよび変更時刻を保持しますが、新規所有者およびグループを獲得します。

構文
/usr/bin/dmpuncompress [ -f ] [ -p ] [ ファイル ]

オプション
フラグ
項目 | 説明
-f ファイル | 拡張を強制します。 ファイルが既に存在している場合は、ファイルを上書きします。 ユーザーに対して、システムは既存のファイルが上書きされることを示すプロンプトを出しません。 ファイルのサイズは、実際には縮小しないことがあります。
-p ファイル | 元の .BZ ファイルと非圧縮ダンプ・ファイルを保存します。 これにより、オリジナルのダンプ・ファイルの回復が成功している場合は圧縮ファイルの除去が無効になります。 オリジナルのダンプ・ファイルの回復がエラーにより完全でなかった場合、このオプションは部分的なダンプの除去を使用不可にします。

例
dump.BZ
ファイルを圧縮解除するには、次のように入力します。
/usr/bin/dmpuncompress dump.BZ
dump.BZ
ファイルは圧縮解除され、
dump
に名前変更されます。
完了後も
dump.BZ
ファイルと新しく作成されたダンプ・ファイルをファイル・システムに保持するには、次のように入力します。
/usr/bin/dmpuncompress -p dump.BZ
