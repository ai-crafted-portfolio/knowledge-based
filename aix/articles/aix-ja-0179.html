目的
最小特権 (LP) リソース・クラス (
IBM.LPCommands
) のアクセス制御を変更します。

説明
chlpclacl
コマンドは、最小特権 (LP) リソース・クラス (
IBM.LPCommands
) に関連付けられているアクセス制御リスト (ACL) を変更します。 このコマンドにより、
IBM.LPCommands
クラス ACL に対するアクセス権限の追加または削除が可能になります。 この ACL は、LP リソースの作成や削除などの
クラス操作へのアクセスを制御します。
IBM.LPCommands
クラスの各ノードには、1 つのクラス ACL が存在します。
IBM.LPCommands
クラス ACL にアクセス権を追加するには、ID とその ID が持つ許可を指定します。 ID とアクセス権のペアを、複数個指定できます。 複数の ID を追加する場合で、それらの ID がすべて同じ許可を持つ場合は、
-l
フラグを使用して、コマンドの形式が ID とそれに続く単一の許可 (すべての ID に適用される) のリストであることを示します。
-o
フラグを使用すると、コマンドで指定された ID とアクセス権によって既存のアクセス権が上書きされます。 Class ACL の中に事前に定義されたアクセス指定は削除されます。
IBM.LPCommands
クラス ACL からアクセス権を削除するには、
-d
フラグを使用して、削除する ID を指定します。
アクセス権がファイルに指定されていることを示すには、
-f
フラグを使用します。 このファイルの各行が、ID とその ID のアクセス権となります。
-d
フラグを
-f
フラグと一緒に使用すると、各行には ID のみが必要になります。 最初のスペースの後にあるものはすべて無視されます。
このコマンドはどのノードでも実行できます。 ドメイン内のすべてのノードでこのコマンドを実行する場合は、
-a
フラグを使用します。 ドメイン内のノードのサブセットでこのコマンドを実行する場合は、
-n
フラグを使用します。 それ以外の場合、このコマンドはローカル・ノードで実行されます。

構文
1 つ以上のアクセス権を IBM.LPCommands クラス ACL に追加するか、1 つ以上のアクセス権で IBM.LPCommands クラス ACL を上書きするには、以下のようにします。 chlpclacl [ -a | -n host1 [ , host2 , ...] ] [ -o ] [ -h ] [ -TV ] ID_1 perm1 [ ID_2 perm2 ] … 1 つ以上のアクセス権を IBM.LPCommands クラス ACL に追加するか、または同じアクセス権を使用する 1 つ以上のアクセス権で IBM.LPCommands クラス ACL を上書きするには、以下のようにします。 chlpclacl [ -a | -n host1 [ , host2 , ...] ] -l [ -o ] [ -h ] [ -TV ] ID_1 [ ID_2 ...] 永続 IBM.LPCommands クラス ACL から 1 つ以上のアクセス権を削除するには、次のようにします。 chlpclacl [ -a | -n host1 [ , host2 , ...] ] -d [ -h ] [ -TV ] ID_1 [ ID_2 ...] IBM.LPCommands クラス ACL へのアクセス権を追加 (またはそこからアクセス権を除去) するか、またはファイルに指定されているアクセス権で IBM.LPCommands クラス ACL を上書きするには、次のようにします。 chlpclacl [ -a | -n host1 [ , host2 , ...] ] [ -o | -d ] -f file_name [ -h ] [ -TV ] すべてのアクセスを拒否するように IBM.LPCommands クラス ACL を設定するには、次のようにします。 chlpclacl [ -a | -n host1 [ , host2 , ...] ] -x [ -h ] [ -TV ]
