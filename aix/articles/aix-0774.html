目的

クラスター構成情報をリストします。

構文

クラスター { I | - [ -k (K) ] | -d 年 | 「-c」 [ N クラスター名 ] } | { -m (M) [ ノード名 ] | -s | I インターフェース名 | - インターフェース名 | -d 年 ディスク名 }

説明

lscluster コマンドは、クラスターおよびクラスター構成に関連した属性を表示します。

フラグ

項目
説明
-c クラスター構成をリストします。
-d クラスター・ストレージ・インターフェースをリストします。
-g ノードごとに報告された、現在アクティブになっているネットワーク・ゲートウェイ・インターフェースをリストします。
-i 各 Cluster Aware AIX® (CAA) ノードで現在構成されているネットワーク・デバイス・ドライバー (NDD) および疑似 NDD インターフェースをリストします。 CAA が、ハートビート・パケットを交換するためにインターフェースをすべては使用しない可能性があります。
注: ストレージ・フレームワーク通信 (sfwcom) インターフェースは、このインターフェースが構成済みで使用可能な場合にのみ、 UP として表示されます。 そうでない場合は、表示されません。
-k ノードごとに割り当てられているネットワーク・ゲートウェイ・インターフェースをリストします。 これらのインターフェースはダウンしている場合も、構成されていない場合もあります。 このフラグは、-g フラグと一緒にのみ指定できます。
-m クラスター・ノード構成情報をリストします。 この情報には、連絡先のリストが含まれます。 連絡先 は、クラスターがハートビート・パケットを交換するために使用するクラスター構成インターフェースです。 連絡先に長時間にわたって CAA トラフィックがない場合、その連絡先は連絡先のリストから削除されます。
-n すべてのインターフェース、ストレージ、またはクラスター構成についてクラスター名を照会できるようにします (-i、-d、または -c フラグを指定した場合のみ適用可能)。
-s ローカル・ノード上のクラスター・ネットワーク統計情報をリストします。
