目的

ドメインネームシステム・セキュリティ拡張(DNSSEC)キーのキータイミングのメタデータを設定する。

構文

dnssec-settime [-f] [-K ディレクトリー] [-L ttl] [-P date/offset] [-P ds date/offset] [-P sync date/offset] [-A date/offset] [-R date/offset] [-I date/offset] [-D date/offset] [-D ds date/offset] [-D sync date/offset] [-S key] [-i interval] [-h] [-V] [-v level] [-E エンジン] {keyfile} [-s] [-g state] [-d state date/offset] [-k state date/offset] [-r state date/offset] [-z state date/offset]

説明

dnssec-settimeコマンドはDNSSEC秘密鍵ファイルを読み込み、「-P、「-A、 「-R、「-I、「-Dオプションで指定された鍵タイミングの メタデータを設定する。 dnssec-signzoneコマンドや他の署名ソフトウェアが使用するメタデータは、鍵がいつ 公開されなければならないか、ゾーンの署名に使用されなければならないか、 その他の詳細を決定する。

これらのオプションが設定されていない場合、'dnssec-settimeコマンドは、すでにキーに格納されているキー・ タイミングのメタデータを表示する。 鍵メタデータ・フィールドが変更されると、鍵ペアの両方のファイル (Knnnn.+aaa+iiiii.key と Knnnn.+aaa+iiiii.private) が再生成されます。

メタデータ・フィールドは、プライベート・ファイルに保管されます。 キー・ファイルには、人間が理解できるメタデータの記述もコメントとして配置されます。 プライベート・ファイルのパーミッションは、常に所有者以外がアクセスできないように設定されている（モード0600）。

ステート・ファイルを扱う場合、'-sフラグを使用することで、それらのファイルのタイミング・メタデータを更新することができる。 このオプションを使用すると、 -d (DS)、 -k (DNSKEY)、 -r (KSK の RRSIG)、または -z (ZSK の RRSIG) フラグを使用して、鍵の状態を更新することもできます。 許可される状態は、 HIDDEN、 RUMOURED、 OMNIPRESENT、および UNRETENTIVEです。

鍵の目標状態は、 -g フラグを使用して設定することもできます。 この値は'HIDDENまたは'OMNIPRESENTどちらかでなければならず、 そのキーがゾーンから削除されなければならないのか、それとも公開されなければ ならないのかを表す。

注：テスト目的以外では、ステートファイルを手動で操作することはできません。

項目
説明
-f メタデータ・フィールドのない古い形式のキーを強制的に更新します。 このオプションがないと、'dnssec-settimeコマンドはレガシー・キーを更新しようとして失敗する。 このオプションでは、鍵は新しい形式で再作成されるが、元の鍵データは保持される。 キーの作成日は現在に設定される。 他の値が指定されていない場合、鍵の発行日と有効化日も現在時刻に設定される。
-K ディレクトリー 鍵ファイルが存在する必要があるディレクトリーを設定します。
-L トル この鍵がDNSKEY RRに変換される際に使用されるデフォルトのTTL(time-to-live)を設定する。 この TTL は、DNSKEY RRset が存在しない限り、鍵がゾーンにインポートされるときに使用されます。DNSKEY RRset が存在する場合は、既存の TTL が優先されます。 この値が設定されておらず、DNSKEY RRset が使用可能でない場合、TTL はデフォルトで SOA TTL になります。 デフォルトの TTL を 0 または noneに設定すると、TTL は鍵から削除されます。
-h 使用法メッセージを表示して終了します。
-V バージョン情報を印刷します。
-v レベル デバッグのレベルを設定します。
-E エンジン

使用する必要がある暗号ハードウェアを指定します (該当する場合)。

BIND 9 がOpenSSL,とともにビルドされる場合、このフラグには暗号アクセラレータまたはハードウェア・サービス・モジュールを駆動するOpenSSLエンジン識別子を設定しなければなりません（通常はpkcs11）。

タイミング・フラグ

日付は以下のいずれかの形式で表すことができる：
  • YYYYMMDDまたは'YYYYMMDDHHMMSS、これはキーファイル内で使われるフォーマットである。
  • dnssec-settime -pコマンドで表示されるDay Mon DD HH:MM:SS YYYY。
  • dnssec-settime -upコマンドが表示するUNIXエポック時間。
  • リテラル 'now.

引数がプラス記号（+）またはマイナス記号（-）で始まる場合は、現在時刻からのオフセットとして解釈される。 リテラル「now」は、オフセットの前では省略できる。 このようなオフセットの後に、接尾辞「y、「mo、「w、「d、「h、「miいずれかが続く場合、オフセットは、年（うるう年を無視し、365 日 24 時間として定義される）、月（30 日 24 時間として定義される）、週、日、時、分の単位で計算される。 接尾部がない場合、オフセットは秒単位で計算されます。 明示的に日付が設定されないようにするには、'none、'never、または'unsetを使用する。

表2. タイミングフラグ
項目
説明
-P 日付/オフセット 鍵をゾーンに公開する必要がある日付を設定します。 その日付以降、キーはゾーンに組み込まれますが、ゾーンの署名には使用されません。
-P ds 日付/オフセット このキーに一致する DS レコードが親ゾーンで使用可能であった日付を設定します。
-P sync 日付/オフセット このキーにマッチするCDSおよびCDNSKEYレコードをゾーンに公開しなければ ならない日付を設定する。
-A 日付/オフセット 鍵をアクティブ化する必要がある日付を設定します。 その日付を過ぎると、キーはゾーンに組み込まれ、ゾーンに署名するために使用されます。
-R 日付/オフセット 鍵を取り消す必要がある日付を設定します。 その日付を過ぎると、鍵には取り消されたことを示すフラグが立てられます。 それでもゾーンに含まれ、ゾーンの署名に使用される。
-I 日付/オフセット 鍵を廃棄する必要がある日付を設定します。 その日付以降も、鍵はゾーンに含まれますが、ゾーンの署名には使用されません。
-D 日付/オフセット 鍵が削除される日付を設定します。 その日付を過ぎると、キーはゾーンに含まれなくなります。 しかし、キーリポジトリには残るかもしれない。
-D ds 日付/オフセット このキーに一致する DS レコードが親ゾーンから除去された日付を設定します。
-D sync 日付/オフセット このキーと一致する CDS および CDNSKEY レコードを削除する必要がある日付を設定します。
-S キー 変更されたキーが明示的な後継キーであるキーを選択する。 先行キーの名前、アルゴリズム、サイズ、タイプは、変更されるキーの値と正確に一致しなければならない。 後続キーの活動化日付は、先行操作の非活動化日付に設定されます。 公開日は、アクティベーション日から公開前の間隔 (デフォルトは 30 日) を引いた日付に設定されます。
-i 間隔

鍵の公開前の間隔を設定します。 設定されている場合、発行日と起動日は少なくとも指定された時間ごとに区切られていなければならない。 有効化日が指定され、発行日が指定されていない場合、発行日のデフォルトは有効化日以前の指定時刻となる。 発行日が指定され、有効化日が指定されていない場合、有効化は発行後の指定された時間に設定される。

鍵が他の鍵の明示的な後継として作成された場合、デフォルトの公開前間隔は30日である。

日付オフセットと同様に、引数の後に接尾辞「y、「mo、「w、「d、「h、「miいずれかが続く場合、間隔は年、月、週、日、時、分の単位で計測される。 接尾部がない場合、間隔は秒単位で測定されます。

鍵の状態フラグ

dnssec-policyをテストするには、人工的なステート情報でキーを構築しなければならない。 これらのオプションは、テストフレームワークによってテスト目的で使用されますが、本番環境では決して使用してはいけません。

キーとなる状態は「HIDDEN、「RUMOURED」、「OMNIPRESENT、「UNRETENTIVEである。

表3. キー・ステート・フラグ
項目
説明
-s キーのタイミングデータを設定する際に、ステートファイルも更新する必要があることを示す。
-g 状態 このキーの目標状態を設定します。 HIDDEN または OMNIPRESENTでなければなりません。
-d 状態日付/オフセット 指定された日付の現在日付からのオフセット時点でのこのキーの DS 状態を設定します。
-k 状態日付/オフセット 指定された日付 (現在日付からのオフセット) に従って、このキーの DNSKEY 状態を設定します。
-r 状態日付/オフセット 指定された日付 (現在日付からのオフセット) ごとに、この鍵の RRSIG (KSK) 状態を設定します。
-z 状態日付/オフセット 指定された日付 (現在日付からのオフセット) ごとに、このキーの RRSIG (ZSK) 状態を設定します。
