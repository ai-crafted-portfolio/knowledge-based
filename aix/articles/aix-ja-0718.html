例
デフォルトの
LPAR
統計を取得するには、以下のコマンドを入力します：
lparstat 1 1
以下のコマンドを入力し、ハイパーバイザーのサマリー統計を含むデフォルトの
LPAR
統計を取得します：
lparstat -h 1 1
以下のコマンドを入力し、パーティションに関する情報を取得する：
lparstat -i
ハイパーバイザーの詳細な統計情報を取得するには、次のコマンドを入力します：
lparstat -H 1 1
以下のコマンドを入力し、共有メモリープールとパーティションのI/Oメモリーエンタイトルメントに関する統計を取得する：
lparstat -m
LPAR
内の I/O メモリプールに関する統計を取得するには、以下のコマンドを入力します：
lparstat -me
LPAR が 4 SMT スレッドで共有モードで動作している場合、
Type
は以下の形式になります：
Type - Shared-SMT-4
LPAR が 2 SMT スレッドで専用モードで動作している場合、
Type
は以下の形式になります：
Type - Dedicated-SMT
Active Memory Expansion が有効な
LPAR
でメモリ圧縮統計を計算するには、次のコマンドを入力します：
lparstat -c 1 1
LPAR 内のページ合体に関する統計を取るには、以下のコマンドを入力してください：
lparstat -mp
