目的
最小特権 (LP) リソース・クラス (
IBM.LPCommands
) のアクセス制御を表示します。

説明
lslpclacl
コマンドは、最小特権 (LP) リソース・クラス (
IBM.LPCommands
) に関連したアクセス制御リスト (ACL) を表示します。 ACL エントリーに含まれるアクセス権が表示されます。
IBM.LPCommands
クラス ACL は、
IBM.LPCommands
クラス操作へのアクセスを制御します。 デフォルトでは、このコマンドは情報をテーブル形式 (
-t
) で表示します。
このコマンドは、以下の ACL 情報を表示します。
フィールド | 説明
ID | ユーザーのネットワーク ID。 ネットワーク ID の説明については、 lpacl コマンドを参照してください。
Permissions | Identity に許可されている許可。 有効な値は以下のとおりです。 a 管理者アクセス権 r 読み取り許可 ( e 、 l 、 q 、および v 許可で構成) w 書き込み許可 ( c 、 d 、 o 、および s 許可で構成) x 実行アクセス権 c リフレッシュ・アクセス権 d 定義および定義解除アクセス権 e イベント・アクセス権 l 列挙アクセス権 o オンライン、オフライン、およびリセット・アクセス権 q 照会アクセス権 s 設定アクセス権 v 検証アクセス権 0 アクセス権なし
NodeName | IBM.LPCommands リソース・クラスのロケーション (管理ドメイン有効範囲またはピア・ドメイン有効範囲の場合)。
PeerDomain | IBM.LPCommands リソース・クラスが定義されている RSCT ピア・ドメインの名前。 このフィールドは、 -p フラグが指定されている場合に表示されます。
このコマンドはどのノードでも実行できます。 ドメイン内のすべてのノードでこのコマンドを実行する場合は、
-a
フラグを使用します。 ドメイン内のノードのサブセットでこのコマンドを実行する場合は、
-n
フラグを使用します。 それ以外の場合、このコマンドはローカル・ノードで実行されます。

構文
IBM.LPCommands リソース・クラスのアクセス制御を表示するには、以下のようにします。 ローカル・ノードの場合: lslpclacl [ -l | -i | -t | -d | -D 区切り文字 ] [ -p ] [ -E ] [ -x ] [ -h ] [ -TV ] ドメイン内のすべてのノードで以下のように入力します。 lslpclacl -a [ -l | -i | -t | -d | -D 区切り文字 ] [ -p ] [ -E ] [ -x ] [ -h ] [ -TV ] ドメイン内の一部のノードで以下のように入力します。 lslpclacl { -n host1 [ , host2 , ...] } [ -l | -i | -t | -d | -D 区切り文字 ] [ -p ] [ -E ] [ -x ] [ -h ] [ -TV ]
