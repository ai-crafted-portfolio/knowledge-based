目的
rndc
コマンドの構成ファイルを生成します。

説明
rndc-confgen
コマンドは、
rndc
コマンドの構成ファイルを生成します。 このコマンドは、'
rndc.conf
ファイル、対応するコントロール、および'
named.conf
コマンドのキー・ステートメントを手動で記述する代わりに使うことができる。
rndc-confgen
コマンドに'
-a
フラグを付けて'
rndc.key
ファイルをセットアップすれば、'
rndc.conf
ファイルとコントロール・ステートメントが不要になる。

構文
rndc-confgen [ ' -a ] [ ' -A アルゴリズム ] [ ' -b キーサイズ ] [ ' -c キーファイル ] [ ' -h ] [ ' -k キーネーム ] [ ' -p ポート ] [ ' -q ] [ ' -s アドレス ] [ ' -t chrootdir ] [ ' -u ユーザー ]

オプション
フラグ
項目 | 説明
-a | rndc コマンドの自動設定を行う。 これは、起動時に' rndc コマンドと' named デーモンの両方が読み込む ' /etc ディレクトリ（またはBINDがビルドされたときに指定された ' sysconfdir ディレクトリ）に' rndc.key ファイルを作成する。 rndc.key ファイルでは、「 rndc コマンドがローカルホスト上の「 named デーモン と通信するための、デフォルトのコマンドチャネルと認証キーを定義する。
-A アルゴリズム | トランザクション署名 (TSIG) 鍵に使用する必要があるアルゴリズムを指定します。 以下のいずれかの値を指定できる： hmac-md5 hmac-sha1 hmac-sha224 hmac-sha256 hmac-sha384 hmac-sha512 デフォルト値は hmac-sha256 です。
-b キーサイズ | 認証キーのサイズをビット単位で指定します。 キーサイズ の値の範囲は1～512である。
-c キーファイル | -a フラグと併用し、' rndc.key ファイル名の代替場所を指定する。
-h | rndc-confgen コマンドへのオプションと引数の簡易要約を印刷します。
-k キーネーム | rndc コマンド認証キーのキー名を指定する。 名前は有効なドメイン名でなければならない。 デフォルトは「 rndc-key ファイルである。
-p port | named デーモンが ' rndc コマンド認証キーからの接続をリッスンする コマンドチャネルポートを指定する。 デフォルトは 953 である。
-q | 自動設定モードで、書き込まれたパスを印刷しないようにする。
-s address | named デーモンが ' rndc コマンド認証キーからのコマンドチャネル接続をリッスンする IP アドレスを指定する。 デフォルトはループバックアドレス 127.0.0.1 。
-t ルートディレクトリ | -a フラグと一緒に使用して、 named デーモンが chrooted を実行するディレクトリーを指定します。 chrootされた' named デーモンによって発見された、このディレクトリに相対する' rndc.key ファイルの追加コピーが書き込まれる。

-u ユーザー | -a フラグ指定で使用して、生成された rndc.key ファイルの所有者を設定します。 -t フラグも指定されている場合、chroot 領域にあるファイルだけにその変更済み所有者があります。

例
人手による構成を指定せずに
rndc
コマンドを使用するには、以下のコマンドを入力します。
rndc-confgen -a
サンプルの
rndc.conf
ファイルを印刷し、対応する
制御ステートメントとキー・ステートメントが
named.conf
ファイルに手作業で挿入されるようにするには、以下のコマンドを実行します。
rndc-confgen
