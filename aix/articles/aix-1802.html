目的

ネットワーク情報サービス (国家情報院) マップを出力します。

構文

Network Information Services データベースを表示する
ypcat [ -k ] [ -t ] [ -d DomainName ] MapName
ニックネーム変換テーブルを表示するには
ypcat -x

説明

ypcat コマンドは、 MapName パラメーターで指定した Network Information Services (NIS) マップを印刷します。 マップ名またはマップのニックネームを指定できます。 ヤマネコ コマンドは 国家情報院 サービスを使用するため、サーバーを指定する必要はありません。

フラグ

表 1. フラグ
項目
説明
-k 値が NULL であるマップ、またはキーが値の一部ではないマップのキーを表示します。 ( /etc ディレクトリーに ASCII バージョンがあるファイルから派生したマップは、このクラスには入りません。)
-t MapName パラメーターを使って指定された名前が、ニックネームではない ことを示します。 このフラグによって、ypcat コマンドはニックネーム変換テーブルをバイパスし、MapName パラメーターを使って指定されたマップだけを検索します。
-d DomainName 指定されたマップを指定されたドメイン内で検索します。
-x ニックネーム変換テーブルを表示します。 このテーブルはコマンドが認識しているマップ・ニックネームをリストし、各ニックネームに関連する (MapName パラメーターで指定されたとおりの) マップ名を示します。

例

  1. ネットワーク全体のパスワード・マップ passwd.bynameを表示するには、次のように入力します。
    ypcat passwd
    この例では以下のようにします。passwdpasswd.byname マップのニックネームです。
  2. マップを見つけるには、次のように入力します。
    ypcat -t passwd
    この例では、 ヤマネコ コマンドは、次のニックネームを持つマップをすべてバイパスします。passwd次に、以下のフルネームを持つマップを検索します。passwd.
  3. 別のドメインのマップを表示するには、次のように入力します。
    ypcat -d polaris passwd
    この例では、 ヤマネコ コマンドは、以下の名前のマップを見つけます。passwd指定されたドメイン内polaris.
  4. マップ・ニックネーム変換テーブルを表示するには、次のように入力します。
    ypcat -x
    この例では、ypcat コマンドはマップ・ニックネームのリストと、それらに関連するマップ名を表示します。
