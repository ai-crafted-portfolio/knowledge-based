目的

集中 RAS データを収集します。

構文

psrasc type[ -d] [ -n number]-o outputFile logSpace/logStream

説明

psrascコマンドは、PowerHA pureScaleログストリームに集中管理されている RAS (Reliability/Availability/Serviceability) データログレコードを抽出し、RAS データAIX®フォーマットのファイルを作成します。 PowerHA® pureScale®のサービス名はCentralizedLogService です。 このサービス名のバインディング情報は、psrasc コマンドを使用する前にセットアップする必要があります。

RAS データ型

指定された型が syslog の場合は、ログ・レコードには、メッセージ・イニシエーター・ホスト名を含むシステム・ログ・メッセージが含まれます。 生成されたファイルのフォーマットは、システム・ログ宛先ファイルに類似しています。 指定された型が errlog の場合は、ログ・レコードにはエラー・ログ・エントリーが含まれます。 生成されたファイルは、あとで errpt コマンドによって活用できるエラー・ログ・ファイルです。

フラグ

項目
説明
type ログ・レコードに含まれる RAS データの型を指定します。 このパラメーターは、最初に指定する必要があります。 サポートされる RAS データ型は、syslog と errlog です。 この型に応じて、出力ファイルのフォーマットが決まります。
-d 収集されたログ・レコードが削除されることを指定します。
-n Number 収集するログ・レコードの数を指定します。 最も古いログ・レコードが収集されます。 このパラメーターを指定しない場合は、すべてのログ・レコードが収集されます。
-o OutputFile 出力ファイルの相対パス名または絶対パス名を指定します。 その名前のファイルが既に存在する場合は上書きされます。
ログ_スペース/ログ_ストリーム システム・ログ・メッセージの収集元のログ・ストリームのフルネームを指定します。 フルネームは、/ (スラッシュ) で区切られた親ログ・スペース名とログ・ストリーム名で構成されます。

終了状況

このコマンドは、以下の終了値を戻します。
項目
説明
0 正常終了。
> 0 エラーが発生しました。

例

  1. CentralizedRAS/Syslogという名前のログストリームのログレコードを、'syslog.outファイル上の

    CentralizedLogServiceサービス名で識別されるPowerHA pureScaleサーバーを入力します：
    psrasc syslog -o syslog.out CentralizedRAS/Syslog
  2. CentralizedRAS/Syslogという名前のログストリームの最も古いログレコード 100 件をPowerHA pureScaleサーバーの/var/adm/ras/cluster_syslogファイルに収集するには、次の手順に従います

    CentralizedLogServiceサービス名で識別し、それらを削除するには、次のように入力します：

    psrasc syslog -d -n 100 -o /var/adm/ras/cluster_syslog CentralizedRAS/Syslog
  3. CentralizedRAS/Errlogという名前のログストリームのログレコードを、CentralizedLogServiceサービス名で識別されるPowerHA pureScaleサーバー上centralizedRAS_errlog のファイルに収集するには、次のように入力します：
    psrasc errlog -o centralizedRAS_errlog CentralizedRAS/Errlog
  4. の/var/adm/ras/cluster_errlogエラーログファイルに、CentralizedRAS/Errlogというログストリームの最も古いログレコード100件を収集し、削除するには、以下の手順に従います

    centralizedRAS_errorサービスによって識別される'PowerHApureScaleサーバーを入力する：

    psrasc errlog -d -n 100 -o /var/adm/ras/cluster_errlog CentralizedRAS/Errlog
