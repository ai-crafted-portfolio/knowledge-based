目的
メールの送信者を判別します。

説明
from
コマンドはメールボックス・ファイル内のメッセージ見出しを表示し、メールの送信者を表示します。
user
を指定すると、自分のメールボックスではなく、
user
のメールボックスが検査されます (user のメールボックスの読み取り許可がある場合)。

構文
from [ -d Directory ] [ -s 送信者 ] [ user ]

オプション
フラグ
項目 | 説明
-d ディレクトリー | システム・メールボックス・ディレクトリーを指定します。
-s 送信者 | Sender が送信したメールのメッセージ・ヘッダーだけを出力します。

例
メールボックス内のメッセージ見出しを表示するには、以下のように入力します。
from
送信者名とメッセージ日付が表示されます。
特定のユーザーによって送信されたメールのメッセージ見出しを表示するには、次のように入力します。
from
-s
dale
この例では、ユーザーから送信されたメッセージのメッセージ見出しのみが表示されます。
dale
が表示されます。
特定のユーザーのメールボックス内のメッセージ見出しを表示するには、次のように入力します。
from dawn
この例では、ユーザーからのメッセージ見出し
dawn's
メールボックスが表示されます (読み取り権限がある場合)。
dawn's
メールボックス)。
bob
が
jane
から受信したすべてのメッセージを表示するには、次のように入力します。
from -d /var/spool/mail -s jane bob
これにより、アクセス権がある場合は (例えば、root)、
bob
が
jane
から受信したすべてのメッセージを見ることができます。
