目的
ワークロード・パーティション
の特性を変更します。

説明
chwpar
コマンドは、
wparname
パラメーターで指定された
ワークロード・パーティション
の構成オプションを変更します。
ワークロード・パーティション
が実行されているかどうかに関係なく、ほとんどのオプションを変更できます。 実行中の
ワークロード・パーティション
に対するいくつかの変更が検出され、許可されません (
-d
および
-n
オプションを参照)。 使用中のデバイスのアンエクスポートやマウントされたファイル・システムの除去などのその他の変更は、実行中の
ワークロード・パーティション
でエラーを生成する可能性がありますが、これらの変更を行うことができます。
ワークロード・パーティション
の構成から特性を除去するには、
-K
フラグを使用します。 デフォルト・オプション付きの属性の場合は、属性値を除去するとオプションのデフォルト設定に戻ります。
WPAR
は、すべてのタイプの CD ROM デバイスをサポートしているわけではありません。 サポートされるのは FCP (サブクラス・タイプ) を使用する CSI CD ROM デバイスのみです。 ただし、Integrated Drive Electronics (IDE)、Serial ATA (SATA)、および (バーチャル入出力サーバーからエクスポートされた) 仮想デバイスはいずれもサポートされていません。

例
ワークロード・パーティション
のホスト名を変更するには、以下のようにします。
roy
次のコマンドを入力します。
chwpar -h roy.com roy
ワークロード・パーティション
からネットワーク・アドレスを除去するには、以下のようにします。
dale
次のコマンドを入力します。
chwpar -K -N address=219.81.45.65 dale
ワークロード区画
内のリソース制御を使用不可にするには、以下のようにします。
wayne
将来の使用に備えて設定を保持しながら、以下のコマンドを入力します。
chwpar -R active=no wayne
ワークロード区画の
bootlist
属性を bootset 1、bootset 2、および bootset 3 の番号付きリストに変更するには、次のコマンドを入力します。
chwpar -b bootlist=1,2,3 <wpar name>
hdisk3 および hdisk4 から構成される
bootset
を RootVG ワークロード区画に対して作成するには、次のコマンドを入力します。
chwpar -B devname=hdisk3 -B devname=hdisk4 <wpar name>
bootset ID 3 を使用して hdisk3 および hdisk4 から構成される
bootset
を RootVG ワークロード区画に対して作成するには、次のコマンドを入力します。
chwpar -B devname=hdisk3 bootset=3 -B devname=hdisk4 bootset=3 <wpar name>
bootset
を非 RootVG ワークロード区画に対して作成するには、次のコマンドを入力します。
chwpar -B <wpar name>
特定のボリューム・グループの
bootset
を非 RootVG ワークロード区画に対して作成するには、次のコマンドを入力します。
chwpar -B vg=<volume group> <wpar name>
bootset ID 5 を使用して特定のボリューム・グループの
bootset
を非 RootVG ワークロード区画に対して作成するには、次のコマンドを入力します。
chwpar -B bootset=5 vg=<volume group> <wpar name>
bootset ID 3 を持つ
bootset
をワークロード区画から除去するには、次のコマンドを入力します。

chwpar -K -B bootset=3 <wpar name>
ワークロード区画
からデバイスをアンエクスポートするには、次のコマンドを入力します。
chwpar -K -D devname=hdisk1 <wpar name>
デバイスをエクスポートするには、次のコマンドを入力します。
chwpar -D devname=hdisk1 devtype=disk <wpar name>
ワークロード・パーティション
の名前を以下のように変更します。
moore
へ
hart
次のコマンドを入力します。
chwpar -n hart moore
アダプター fcs2 を「roy」という名前のワークロード区画に追加するには、次のコマンドを入力します。
chwpar -D devname=fcs2 roy
アダプター fcs2 を「roy」という名前のワークロード区画から除去するには、次のコマンドを入力します。
chwpar -K -D devname=fcs2 roy
