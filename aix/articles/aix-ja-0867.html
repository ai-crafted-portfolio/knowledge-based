目的
メッセージの書き込みを許可または拒否します。

説明
mesg
コマンドは、システム上の他のユーザーが
write
コマンドまたは
talk
コマンドを使用して、
メッセージを送信できるかどうかを制御します。 引数なしで呼び出されると、
mesg
コマンドは、ワークステーションの現在のメッセージ許可設定を表示します。
シェルの始動プロセスは、デフォルトでメッセージを送信できるようにします。 このデフォルト・アクションは、以下の行を含めることによってオーバーライドできます。
mesg n
$HOME/.profile
ファイル内。 root 権限を持つユーザーは、メッセージ許可設定に関係なく、どのワークステーションにでもメッセージを送信できます。 メッセージ許可は、電子メール・システムを介して送達されたメッセージには影響しません。
追加する場合
mesg y
$HOME/.profile
にアクセスすると、
write
コマンドまたは
talk
コマンドを介して他のユーザーからメッセージを受け取ることができます。
追加する場合
mesg
n
$HOME/.profile
に対しては、
write
コマンドまたは
talk
コマンドを使用して他のユーザーからメッセージを受信することはできません。

構文
mesg [ n | y ]

オプション
フラグ
項目 | 説明
n | root ユーザーのみがワークステーションにメッセージを送信できるようにします。 他のユーザーからの着信メッセージでディスプレイが乱雑にならないように、この形式のコマンドを使用します。
y | ローカル・ネットワーク上のすべてのワークステーションが使用しているワークステーションにメッセージを送信できるようにします。

例
root ユーザーのみがワークステーションにメッセージを送信できるようにするには、次のように入力します。
mesg
n
すべてのユーザーがワークステーションにメッセージを送信できるようにするには、次のように入力します。
mesg
y
現在のメッセージ許可設定を表示するには、以下のように入力します。
mesg
次のような情報が表示されます。
is
y

です。

に変更した場合
n
