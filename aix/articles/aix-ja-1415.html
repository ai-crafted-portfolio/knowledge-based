目的
ローカル送達またはネットワーク送達のためにメールの経路指定を行います。

構文
sendmail [ -ba | -bd | -bD | -bh | -bH | -bi | -bm | -bp | -bs | -bv | -bt [ -Ac File ] [ -C File ] [ -D Log File ] [ -d Value ] ] [ -B Type ] [ -F FullName ] [ -f Name ] [ -G ] [ -h Number ] [ -i ] [ -M x Value ] [ -n ] [ -N Dsn ] [ -OOption=Value ] [ -o Option [ Value ] ] [ -p Protocol ] [ -q [ Time ] ] [ -qG name ] [ -qI Substr ] [ -qR Substr ] [ -qS Substr ] [ -R Return ] [ -r addr ] [ -t ] [ -V Envid ] ] [ -v ] [ -X LogFile ] Address 注： Address パラメータは、' -bd 、' -bi 、' -bp 、' -bt 、' -q [ Time ] フラグではオプションである。

フラグ
表 1. フラグ
項目 | 説明
-Ac ファイル | 動作モードに基づいて代替構成ファイルを選択するには、 sendmail コマンドを指定します。 -bm 、 -bs 、 -t のいずれかのフラグを指定した場合、 sendmail コマンドは submit.cf 構成ファイルを使用します。 他のフラグを指定した場合、旧バージョンとの互換性のために、 sendmail コマンドは sendmail.cf 構成ファイルを使用します。 file 変数を指定しない場合、 sendmail コマンドはデフォルトで submit.cf 構成ファイルを使用します。
-B タイプ | 本文のタイプを type に設定します。 現在有効な値は 7BI または 8BITMIMEです。 注: -b フラグは同時には指定できません。
-ba | ARPANET モードで sendmail コマンドを開始する。 コマンドへのすべての入力行は、復帰とライン・フィード (CR-LF) で終っていなければなりません。 sendmail コマンドは最後に CR-LF の付いたメッセージを生成し、 From: フィールドと Sender: フィールドを調べて、 送信元の名前を見付けます。 sendmail コマンドのバージョン 8.18.1 以降、非標準のシーケンス ( <LF>.<CR><LF> ) や ß( <LF>.<LF> ) ではなく、標準のデータ終了シーケンス ( <CR><LF>.<CR><LF> ) を期待するように動作が更新される。
-bd | sendmail コマンドを、Simple Mail Transfer Protocol (SMTP) メールルーターとしてバックグラウンドで動作するデーモンとして起動する。
-bD | SMTPメールルーターとしてフォアグラウンドで動作するデーモンとして、 sendmail コマンドを起動する。
-bh | 永続ホスト状況データベースを出力します。
-bH | 永続ホスト状況データベースを削除します。
-bi | /etc/mail/aliases ファイルに定義された情報からエイリアスデータベースを構築する。 このフラグを付けて' sendmail コマンドを実行することは、' newaliases コマンドを実行することと同じである。
-bm | デフォルトでは通常の方法でメールを配信する。

-bp | メール・キューのリストを出力します。 このフラグを付けて' sendmail コマンドを実行することは、' mailq コマンドを実行することと同じである。
-bs | RFC821に記述されているSMTPを使い、標準入力からメールを収集する。 このフラグには、SMTPと互換性のある' -ba フラグの操作が含まれる。
-bt | sendmail コマンドをアドレス検査モードで始動します。 このモードを使うと、対話式アドレスを入力し、 sendmail コマンドがアドレスを解析するステップを表示するのを見ることができる。 検査モード・プロンプトが表示されたら、単一の規則セットまたはコンマで区切った複数の規則セットと、 1 つのアドレスを入力してください。 このモードは、新しい構成ファイルのアドレス解析規則をデバッグするのに使用してください。
-bv | sendmail コマンドを、コマンドの Address パラメータフィールドに指定されたユーザーIDを検証するリクエストで開始する。 sendmail コマンドは、どのIDがメーラーコマンドに解決できるかを知らせるメッセージで応答する。 メッセージの収集および送信は行いません。 このモードは、ユーザー ID、別名、またはメーリング・リストのフォーマットの妥当性を検査するのに使用します。
-C ファイル | File 変数が指定する代替構成ファイルを使用して、 sendmail コマンドを開始する。 新しいコンフィギュレーション・ファイルを、実行するコンフィギュレーション・ファイルとしてインストールする前にテストするには、 -C フラグと -bt フラグを併用する。
-D ログファイル | 指定されたログ・ファイルにデバッグ出力を送信します。 -D オプション は -d オプションの前に指定する必要があります。
-d Value | デバッグ値を Value 変数で指定された値に設定します。 有効な値は' 21. n のみで、 n は0以外の整数である。 これはアドレス解析に関する情報を生成し、 -bt フラグとともに使用される。 n の値が大きくなるほど、作成される情報は詳しくなります。 このフラグを使用するには、root 権限が必要です。
-F FullName | 送信者のフルネームを FullName 変数で指定する文字列に設定します。

-f name | from 人（メールの封筒差出人）の名前を設定する。 このアドレスは、 From: ヘッダーが最初の送信時に欠落していた場合にも使用される。 エンベロープの差出人アドレスは、配送状況通知の受取人として使用され、 Return-path: ヘッダーにも表示されることがある。 -f フラグは、信頼されたユーザー（通常、root、daemon、 uucp ）、または、あなたがなろうとしている人物とあなたが同じ人物である場合にのみ使用しなければならない。 そうでない場合は、 X-Authentication-Warning ヘッダーがメッセージに追加される。
-G | メッセージのリレー (ゲートウェイ) 実行依頼。 例えば、 rmail コマンドが sendmail コマンドを呼び出す場合です。
-h 番号 | ホップ数を Number 変数が指定する値に設定する。 ホップ数は、SMTPルーター（ sendmail コマンドのローカルコピーだけではない）がメッセージを処理する回数である。 メールルーターはメッセージが処理されるたびにホップカウントを増やす。 限界に達すると、メールシステムの無限ループを防ぐために、エラーメッセージとともにメッセージが返される。
-i | 着信メッセージの行にドットのみがある場合はそれを無視します。 このオプションは、ファイルからデータを読み込む場合に設定する必要がある。
-L | syslog メッセージで使われる識別子を指定されたタグに設定する。
-M x 値 | マクロ x を、指定された value に設定します。
-N Dsn | データソース名（DSN）に配信状況の通知条件を設定します。 配送状況の通知条件は以下の通りです： never 通知なし、またはコンマで区切られた値のリストの場合。 failure 配送に失敗した場合の通知用。 delay 配達が遅れた場合の通知用。 success メッセージが正常に配信されたときの通知用。
-n | sendmail コマンドが別名を解釈しないようにします。
-O オプション=値 | Option を指定された Value に設定する。 これは、オプション名が長い場合に使用します。

-o オプション [ 価値 ] | Option 変数を設定します。 オプションが値付きオプションの場合は、 Value 変数に値を指定する必要があります。 注： 有効な値については、『 Performance Tools Guide and Reference 』の「 sendmail.cf ファイルの「sendmailコマンドのオプション」を参照してください。
-p Protocol | 送信プロトコルを設定します。 このオプションを設定する必要がある。 Protocol を' Protocol:Host 形式で設定すると、送信プロトコルと送信ホストの両方を設定できる。 例えば、' -pUUCP:uunet は送信プロトコルをUUCPに、送信ホストを' uunet に設定する。 既存のプログラムの中には、' -oM フラグを使って' r と' s マクロを設定するものがあるが、これは' -p フラグと同等である。
-qI サブストリング | プロセス・ジョブを、キュー ID のサブストリングとしての Substr を含むプロセス・ジョブに制限します。
-qG name | キュー・グループ内のプロセス・ジョブは、名前だけで呼び出される。
-qR サブストリング | プロセス・ジョブを、いずれかの受信者のサブストリングとしての Substr を含むプロセス・ジョブに制限します。
-qS サブストリング | プロセス・ジョブを、送信者のサブストリングとしての Substr を含むプロセス・ジョブに制限します。
-q [ 時間 ] | Time 変数が指定する間隔で、キューに保存されたメッセージを処理する。 Time 変数を指定しない場合、 -q フラグはキューを一度に処理する。
-R Return | メッセージがバウンスする場合に戻されるメッセージの量を設定します。 Return パラメーターは、 全メッセージを戻す full にすることも、ヘッダーのみを戻す hdrs にすることもできます。
-r アドレス | -f の古い形式。
-t | メッセージヘッダの To: 、 Cc: 、 Bcc: フィールドで指定された受信者と、コマンドラインで指定されたユーザーにメッセージを送る。
-V Envid | オリジナルのエンベロープ ID を設定します。 これは、SMTP によって、DSN をサポートするサーバーに伝搬され、DSN 準拠のエラー・メッセージで戻されます。

-v | sendmail コマンドを冗長モードで開始する。 sendmail コマンドは、送信状況とエイリアスの展開に関するメッセージを表示する。
-X LogFile | メーラーの問題をデバッグするために、' sendmail コマンドから出入りするすべてのトラフィックを LogFile に記録する。 このフラグは大量のデータを高速に生成するため、控えめに使用すること。
