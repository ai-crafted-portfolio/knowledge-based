目的
ワークロード・マネージメント・クラスとその制限をリストします。

説明
lsclass
コマンドに引数を指定しない場合、
1 行に 1 つずつのスーパークラスのリストを戻します。 クラス名を引数として指定すると、
このコマンドはクラスを表示します。
-r
(recursive) フラグか、
または
-S
Superclass
フラグを使用すると、
サブクラスが表示できます。
WLM が開始されると、
空ストリングが
-d
フラグと共に構成の名前として渡される場合に、
lsclass
はメモリー内の WLM データ構造で定義されたクラスをリストします。
lsclass
コマンドは、
特別なレベルの特権を必要とせず、
すべてのユーザーがアクセスできます。
注:
このコマンドに時間ベースの構成のセットが指定されている場合 (
-d
フラグで指定されているか、現在の構成がセットであるため)、
lsclass
コマンドは、コマンドの発行時に適用される (または適用される) 通常構成のクラスを戻します。

構文
lsclass [ -C | -D | -f ] [ -r ] [ -d Config_Dir ] [ -S SuperClass ] [クラス］
