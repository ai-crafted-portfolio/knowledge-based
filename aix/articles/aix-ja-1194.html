目的
順列索引を生成します。

説明
ptx
コマンドは、指定された英語テキスト (
Infile
パラメーター) を読み取り、そこから配列し直した索引を作成し、指定されたファイル (
Outfile
) へ書き込みます。 標準入力と標準出力がデフォルトです。
ptx
コマンドは、指定されたファイル (
Infile
) でキーワードを探索し、行をソートし、ファイル
Outfile
を作成します。 その後、
Outfile
ファイルを
nroff
または
troff
コマンドで処理して、再配列された索引を作成することができます。
ptx
コマンドは以下の 3 つのステップで処理します。
順列を実行し、入力行のキーワードごとに 1 行を生成し、キーワードを行の前に回転させます。
順列ファイルをソートします。
ソートされた行を回転させて、キーワードが各行の中央にくるようにします。
結果として生成される行のフォーマットは、
Outfile
ファイル内で次のようになります。
.xx "" "before keyword" "keyword" "after keyword"
ここで、
.xx
は、ユーザーまたは
ptx
コマンドによって提供される
nroff
または
troff
マクロです。
mptx
マクロ・パッケージは、
.xx
マクロ定義を提供します。
before keyword
フィールド、
keyword
フィールド、および
after keyword
フィールドには、印刷時にキーワードの周囲に収まるだけの行が取り込まれます。 先頭フィールドと最終フィールドは、少なくとも一方は常に空文字列で、行の反対端の未使用のスペースに入るように折り返されます。
注:
行の長さのカウントは、重ね打ちやプロポーショナル・スペーシングを考慮しません。
~ (ティルド) を含む行は、
ptx
コマンドがその文字を内部で使用するため、機能しません。
ptx
コマンドは、非英数字を破棄しません。

構文
ptx [ -f ] [ -r ] [ -t ] [ -b Breakfile ] [ -g Number ] [ -w Number ] [ -i Ignore | -o Only ] [ — ] [ Infile [ Outfile ] ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-b BreakFile | 指定された切断ファイル内の文字を使用してワードを区切ります。 タブ文字、改行文字、スペースは、常に切断文字として使用されます。
-f | ソートのときに大文字と小文字を区別しません。
-g 番号 | 出力されるときに ptx コマンドが行の 4 つの部分間でそれぞれのギャップに予約する文字として、指定数を使用します。 デフォルトの Number 変数値は 3 です。
-i 無視 | Ignore ファイルで指定された単語をキーワードとして使用しないでください。 -i と -o フラグを使用しない場合には、 /usr/lib/eign ファイルがデフォルトの Ignore ファイルです。
-o のみ | Only ファイルでキーワードとして指定されている単語のみを使用します。
-r | 各入力行のブランク以外の先頭文字を、行のテキストと切り離された参照 ID と見なします。 ID を、各出力行の 5 番目のフィールドとして接続します。
-t | フォトタイプセッター用の出力を準備します。
-w 番号 | 出力行の長さとして、指定された数を使用します。 デフォルトの行長は、 nroff コマンドの場合には 72 文字で、 troff コマンドの場合には 100 文字です。
— | (二重ダッシュ) フラグの終わりを示します。
