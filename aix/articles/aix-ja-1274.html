目的
ワークロード・パーティション
をリストアします。

説明
restwpar
コマンドは、
savewpar
、
mkcd
、または
mkdvd
コマンドによって作成された
ワークロード・パーティション
・バックアップ・イメージから
ワークロード・パーティション
を作成します。
警告:
AIX® Live Update 操作の進行中は、
restwpar
コマンドを実行しないでください。
ワークロード・パーティション
のバックアップ・イメージには、
image.data
ファイルと、
ワークロード・パーティション
WparName
の特性を確立するために使用される
ワークロード・パーティション
仕様ファイルが含まれています。 これらのデフォルト・ファイルは、
-i
フラグおよび
-w
フラグを使用してオーバーライドできます。
-f
フラグを指定しない場合、入力デバイスとして
/dev/rmt0
デバイスが使用されます。
/tmp/wpardata/
WparName
/image.data
ファイルの
logical_volume_policy
スタンザの
EXACT_FIT
フィールドに値 Yes を指定すると、
restwpar
コマンドはマップ・ファイルを使用して、各論理ボリュームの物理区画の配置を保持します。
ユーザー・ボリューム・グループが rootvg WPAR と一緒に構成されている場合、それらのグループは、rootvg WPAR がリストアされた後で自動的にインポートされることはありません。
注:
バックアップ・イメージ内のファイルを表示したり、バックアップ・イメージから個々のファイルをリストアしたりするには、
-T
または
-x
フラグを指定した
lssavewpar
、
restwparfiles
、または
restore
コマンドを使用します。
共有ワークロード区画 (WPAR) では、ソース・システムのインストール履歴がターゲット・システムのインストール履歴と異なっている場合、
restwpar
コマンドおよび
syncroot
コマンドがいくつかのファイルセットにおいて失敗する可能性があります。
restwpar
操作の終了時に、
syncroot
コマンドの以下の例のような失敗メッセージが表示される場合があります。
syncroot: Error synchronizing installp software
syncroot: Returns Status = FAILURE

共有 WPAR を、ソース論理区画 (LPAR) のインストール履歴と同様のインストール履歴を持つ LPAR に復元またはマイグレーションする必要があります。

構文
restwpar [ -a ][ -A ][ -b ブロック ] [ -B devexportsFile ][ -C ][ -d ディレクトリ］ [ -f デバイス ] [ -F ][ -h hostName ][ -i imagedataFileName ][ -k ][ -K ][ -M mkwparFlags ][ -n WparName [ -r ][ -s ][ -S { a | A | f | F | n }][ -U ][ -w wparSpecificationFile ]

オプション
フラグ
項目 | 説明
-a | 必要なら、静的設定の競合を自動的に解決します。 解決可能な設定は、名前、ホスト名、ベース・ディレクトリー、およびネットワーク構成です。
-A | /etc/rc.wpars コマンドが実行されるたびに ワークロード区画 を開始します。これは、システム始動のたびに実行するためにグローバル /etc/inittab に追加されます。 デフォルトでは、 ワークロード・パーティション は自動的に開始されません。
-b blocks | 1 回の入力操作で読み取る 512 バイト・ブロックの数を指定します。 Blocks パラメーターを指定しない場合、 restore コマンドはデフォルト値 100 を使用します。 値が大きくなるほど、テープ・デバイスへの物理的な転送量は大きくなります。
-B devexportsFile | マスター・デバイス・エクスポート・ファイルとして使用できる代替ファイルを指定します。 このファイルは、デバイス・エクスポート・ファイルのフォーマットに一致しなければなりません。 ファイル名を指定しない場合は、 /etc/wpars/devexports ファイルが使用されます。

-C | バックアップ・イメージからのシステムとバックアップがリストアされるシステムとの間で互換性検査が失敗した場合でも、指定された ワークロード・パーティション の作成を強制します。 ワークロード・パーティション がターゲット・システムと互換性がない場合。 操作できない可能性があります。 グローバル・システムのオペレーティング・システムが、VRMF 内の異なるモディフィケーション・レベルまたはフィックス・レベル (バージョン、リリース、モディフィケーション、およびフィックス・レベル) を持つ WPAR よりも新しいテクノロジー・レベルまたはサービス・パック・レベルである場合、 ワークロード・パーティション (WPAR) を新しいグローバル・システムと同期させることができます。 同期の正常実行には、さまざまな要因が影響します。 同期操作が完了した後、ログを確認してください。 新しいグローバル・システムに適用されたすべての更新をコミットする必要があり、WPAR をバックアップする前に WPAR に対する更新をコミットする必要があります。 AIX 6100-08 または 7100-02 以前のテクノロジー・レベルを実行しているシステムに新しいグローバル・システムがインストールされている場合は、同期化を機能させるために ワークロード区画 を復元する前に、 cp_bos_updates コマンドを実行する必要があります。
-d ディレクトリー | ワークロード・パーティション の基本ディレクトリーを指定します。 ディレクトリー名を指定しない場合は、 WPAR 仕様ファイルのディレクトリー名が使用されます。
-f 装置 | バックアップ・メディアのデバイス名を指定します。 デフォルト値は /dev/rmt0 です。
-F | 指定された ワークロード・パーティション の作成を強制します。 指定された ワークロード・パーティション が存在する場合、新しい ワークロード・パーティション が作成される前に、アクティブの場合は停止され、その後削除されます。
-h ホスト名 | ワークロード・パーティション のホスト名を指定します。 指定しない場合、 mkwpar コマンドはホスト名に ワークロード・パーティション 名を使用します。
-i imagedataFileName | ファイル名を指定するオプションのフラグ。 このファイルは、復元されるバックアップ・イメージ内にある image.data ファイルの代わりとして使用されます。

-k | 最小サイズの論理ボリュームをバックアップから作成します。
-K | インストール後のカスタマイズ・スクリプトを作成します。
-M mkwparFlags | ワークロード区画 を作成するために mkwpar コマンドに直接渡すフラグを指定します。 -M フラグは、他のフラグを mkwpar コマンドに渡すために使用されます。 フラグがそれ自身のオプションおよび -M フラグを通して渡される場合、両方のフラグが mkwpar コマンドに渡されます。 注: -i フラグと -f フラグは restwpar コマンドで使用するために予約されているため、 mkwparFlags 値にこれらのフラグを含めることはできません。 -i フラグまたは -f フラグを mkwparFlags 値として指定すると、エラーになります。
-n WparName | 作成する ワークロード・パーティション の名前を指定します。 -n フラグを指定しない場合、 WparName は WPAR 仕様ファイルから取られます。
-r | グローバル・システムからネットワーク・ネーム・レゾリューション構成を複写します。 以下のファイルが存在する場合は、 ワークロード・パーティション にコピーされます。 /etc/resolv.conf /etc/hosts /etc/netsvc.conf /etc/irs.conf /etc/networks NSORDER 環境変数が呼び出し側環境で定義されている場合は、 ワークロード・パーティション の /etc/environment ファイルに追加されます。
-s | ワークロード・パーティション を作成後に開始します。

-S { a | A | f | F | n } | ワークロード・パーティション 内のソフトウェアのレベルをグローバル環境内のソフトウェアのレベルと同期するために、バックアップからファイルがリストアされた後に使用する同期のタイプを指定します。 a ソフトウェアを除去せずに追加のインストールを行います。 このオプションはデフォルトです。 A ソフトウェアを除去せずに追加のインストールを行い、同期エラーはすべて無視します。 重要: -S A を指定すると、 ワークロード・パーティション が使用不可状態になる可能性があります。 f 追加のインストール、ソフトウェアの除去、およびアンインストールを行います。 F 追加のインストール、ソフトウェアの除去、およびアンインストールを行います。 このオプションは、同期のエラーをすべて無視します。 重要: -S F を指定すると、 ワークロード・パーティション が使用不可状態になる可能性があります。 n ファイルが復元された後の同期化処理を防ぎます。 重要: -S n を指定すると、 ワークロード・パーティション が使用不可状態になる可能性があります。
-U | 既存の MAP ファイルが無視されることを指定します。 -U フラグは、 WparName .data ファイルの logical_volume_policy スタンザの EXACT_FIT フィールドの値をオーバーライドします。
-w wparSpecificationFile | ファイル名を指定するオプションのフラグ。 このファイルは、 mkwpar コマンドによって WPAR バックアップ・イメージ内のバージョンではなく、 WPAR 仕様ファイルとして使用されます。

例
ワークロード・パーティション
・イメージを
/dev/rmt1
デバイスからリストアするには、次のコマンドを入力します。
restwpar -f/dev/rmt1
/mydata/wpar.img
ファイルに保存されている
ワークロード・パーティション
・イメージを
mywpar
という名前でベース・ディレクトリー
/wpars/mywpar
にリストアするには、次のコマンドを入力します。
restwpar -f/mydata/wpar.img -n mywpar -d /wpars/mywpar
ワークロード・パーティション
・イメージを
/dev/usbms0
デバイスからリストアするには、次のコマンドを入力します。
restwpar -f/dev/usbms0
