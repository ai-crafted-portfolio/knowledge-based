目的
プログラム・ファイルの位置 (別名とパスを含めて) を見つけます。

説明
which
コマンドはプログラム名のリストを入力として受け取り、その名前をコマンドとして入力すると実行されるファイルを検索します。
which
コマンドは、引数が別名の場合は拡張し、ユーザーのパスに従って検索します。 別名とパスは、ユーザーのホーム・ディレクトリーにある
.cshrc
ファイルから取り出されます。
.cshrc
ファイルが存在しない場合、またはパスが
.cshrc
ファイルに定義されていない場合、
which
コマンドはユーザーの環境に定義されたパスを使用します。
名前が複数の単語の別名であったり、引数名に関連する実行可能ファイルがパスに見つからなかった場合、診断が戻ります。
Korn シェルの場合、
whence
コマンドを使えばより詳細な報告が得られます。

構文
which [ 名前 ...]

例
コマンド名に関連付けられた実行可能ファイルを検索するには、次のようにします。
lookup
:
which lookup
