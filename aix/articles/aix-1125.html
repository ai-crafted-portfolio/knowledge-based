目的

インストールの正確度を検査します。

構文

インストール済みオブジェクトの内容を確認するには
pkgchk [ -l | -a -c -f -q -v ] [ -n -x ] [ -P path ] [ -p Path1[,Path2 . . . ] [ -i File] [ Pkginst  . . . ]
指定された装置でスプールされたパッケージの内容を検査するには、以下のようにします。
pkgchk -d Device [ -l | -v ] [ -p Path1[,Path2 . . . ] [ -i File] [ Pkginst  . . . ]
指定された pkgmap に記述されているパッケージの内容を確認するには
pkgchk -m Pkgmap [ -e Envfile] [ -l | -a -c -f -q -v ] [ -n -x ] [ -i File] [ -p Path1[,Path2 . . . ]]

説明

pkgchk インストール済みファイルの正確性を確認するか、 -l フラグを使用して、パッケージ・ファイルに関する情報を表示します。 このコマンドはディレクトリー構造およびファイルの整合性を検査します。 矛盾がある場合には、問題の詳しい説明とともに stderr に報告されます。

上記で定義された最初の概要は、システムにインストールされているオブジェクトの内容 and/or 属性をリストまたは確認するために使用されます。 パッケージ名をコマンド・ラインにリストすることも、デフォルトでマシン全体の内容を 検査させることもできます。 -P オプションを指定した pkgadd コマンドを使用して、パッケージが代替ルート・ディレクトリー・パスにインストールされている場合、 -P オプションで指定されているのと同じ代替ルート・ディレクトリー・パスを使用して、コンテンツおよび属性を検査またはリストすることができます。

2 番目の構文は、指定された装置にスプールされているがインストールされていないパッケージの内容をリストまたは検査するために使用されます。 スプール・パッケージの属性は検査できません。

3 番目の構文は、オブジェクトの内容 and/or 属性をリストまたは検査するために使用されます。これらの属性については、示されている Pkgmapで説明されています。

フラグ

表 1. フラグ
項目
説明
-l パッケージを構成する、選択されたファイルに関する情報をリストします。 これは、a、c、f、g、 または v フラグと一緒には使用できません。
-a ファイル属性の監査だけを行い、ファイル内容は検査しません。 デフォルトでは、両方を検査します。
-c ファイル内容の監査だけを行い、ファイル属性は検査しません。 デフォルトでは、両方を検査します。
-f 可能な場合、ファイル属性を訂正します。 -x フラグと一緒に使用すると、隠しファイルは除去されます。 このフラグを指定して pkgchk を呼び出すと、ディレクトリー、名前付きパイプ、リンク、および特殊デバイス (存在しない場合) が作成されます。
-q 抑止モードを使用可能にします。 存在しないファイルに関するメッセージは生成されません。
-v 詳細モードを使用可能にします。 処理されたファイルがリストされます。
-n 揮発性のファイルまたは編集可能なファイルは無視されます。 このフラグは、ほとんどのインストール後の検査に使用する必要があります。
-x 排他的ディレクトリーだけを検索し、インストール・ソフトウェア・データベース または指定された Pkgmap ファイルにないファイルが存在しているかどうかを調べます。 (排他的ディレクトリーとは、パッケージによって作成され、パッケージ用に作成されるディレクトリーのことです。排他的ディレクトリーには、パッケージとともに配布されるファイルのみが含まれている必要があります。 排他的ディレクトリーで非パッケージ・ファイルが検出された場合、 pkgchk はエラーを報告します。) -x を -f フラグと一緒に使用すると、 隠しファイルが除去されるだけで、それ以外の検査は行われません。
注: 隠しファイルの除去だけを行うためには、-f フラグ と -x フラグを一緒に使用してください。 隠しファイルを削除し、ファイルの属性と内容を確認するには、 -f、 -x、 -c、および -a フラグを一緒に使用します。
-p リストされたパス名またはパス名の正確性を検査します。 パス名は、コンマ (または、リストが引用符で囲まれている場合は空白) で区切られた 1 つ以上のパス名にすることができます。
-i File からパス名のリストを読み取り、このリストを、 インストール・ソフトウェア・データベースまたは指定された Pkgmap ファイル と対比します。 inputfile に含まれていないパス名は検査されません。
-d スプール・パッケージが常駐する装置を指定します。 Device には、ディレクトリー・パス名、または標準入力から読み取られるデータ・ストリーム形式のパッケージを指定する - を指定できます。
-m このフラグは、パッケージを pkgmap ファイル Pkgmapと照合します。
-e 指定された pkgmap ファイルに示されているパラメーターを解決するために、 Envfile という名前の pkginfo ファイルを使用することを要求します。
プッギンスト パッケージ名の省略形を指定するために使用される短いストリングを定義します。 ( package instance という用語は大まかに使用されます。これは、インスタンス ID が含まれていない場合でも、 Pkginstのすべてのインスタンス化を指します。)

パッケージのすべてのインスタンスを示すには、「Pkginst.*'」を指定し、示されているようにコマンド行を単一引用符で囲み、シェルが * 文字を解釈しないようにします。 ソース・メディアで使用可能なすべてのパッケージを参照するには、"all" というトークン を使用してください。
-P パス このフラグは、代替ルート・ディレクトリー・パス内のパッケージを検査します。
