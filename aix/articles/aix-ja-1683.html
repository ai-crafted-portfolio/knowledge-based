目的
BNU スプール・ディレクトリー内のファイルを除去します。

説明
uuclean
コマンドは、基本ネットワーク・ユーティリティー (BNU) のスプール・ディレクトリー (
/var/spool/uucp
) を検査して指定された接頭部の付いたファイルを見つけ、与えられた時間より古いものを削除します。
-n
Hours
フラグを指定しない場合には、
uuclean
コマンドは 72 時間以上古いファイルを削除します。
-p
フラグが含まれていない場合には、
uuclean
コマンドは経過日数要求に適合するスプール・ディレクトリーの指定されたサブディレクトリー内のすべてのファイルを削除します。
-d
フラグが含まれていない場合には、
コマンドはスプール・ディレクトリーの指定されたすべてのサブディレクトリー内のすべてのファイル (経過日数および接頭部要求に合うもの) を削除します。 したがって、
-d
フラグも
-p
フラグも組み込まれていない場合、
uuclean
コマンドは、存続期間要件を満たす、
/var/spool/uucp
ディレクトリーの
すべての
サブディレクトリー内の
すべての
ファイルを削除します。
-m (M)
フラグが指定されていない場合、
ユクレアン
コマンドは、すべてのコマンドの所有者 (
C. * -->
) にメールを送信します。 ファイルを削除します。
-m (M)
フラグが指定されている場合、コマンドは、データ (
D. * (D)
) を含めて、削除する各ファイルの所有者にメールを送信します。 および実行 (
X * (*)
) ファイルのみ。 メール・メッセージには、削除されたファイル名が含まれます。
uuclean
コマンドは通常、
cron
デーモンによって実行されます。
“
注:
ユクレアン
コマンドを発行できるのは、root ユーザー権限を持つユーザー、または
UUCP
としてログインしているユーザーのみです。
”

構文
/usr/sbin/uucp/uuclean [ -m ] [ -n Hours ] [ -p Prefix ] [ -d サブディレクトリー ]

オプション
フラグ
項目 | 説明
-d 年 サブディレクトリー | -n フラグと -p フラグの指定が一致すれば、 /var/spool/uucp ディレクトリーの指定のサブディレクトリーからファイルを削除します。 -d フラグを指定しなかった場合、 uuclean コマンドは /var/spool/uucp ディレクトリーのすべてのサブディレクトリーを検査します。 最高 10 個までのサブディレクトリーを -d フラグに指定することができます。
-m | uuclean コマンドに、 ファイルの削除時に各ファイルのオーナーに対してメールを送信させます。
N 時間 | Hours 変数で指定された時間を超える経過日数のファイルが、 -d フラグと -p フラグで与えられた指定と一致する場合には、これを削除します。 デフォルトは 72 時間です。
P- 接頭部 | Prefix 変数で指定されたファイルが、 -n フラグと -d フラグで与えられた指定と一致する場合には、これを削除します。 最高 10 個までの接頭部を -p フラグに指定することができます。

例
古いコマンド・ファイルをすべて削除するには、次のように入力します。
/usr/sbin/uucp/uuclean -pC
このコマンドは、名前が以下で始まる
/var/spool/uucp
ディレクトリーのすべてのサブディレクトリー内のすべてのファイルを削除します。
C
72 時間 (デフォルト) を超えています。 システムは、各ファイルの元のオーナーに、ファイルが削除されたことを知らせるメールを送信します。
システムのスプール・ディレクトリーからすべての古いファイルを削除します。
venus
および
nostromo
次のように入力します。
/usr/sbin/uucp/uuclean -n84 -dvenus -dnostromo
このコマンドは、
/var/spool/uucp/venus
ディレクトリー、
および
/var/spool/uucp/nostromo
ディレクトリー内のファイルの中で、
84 時間より古いものをすべて削除します。 デフォルトでは、システムは
C. * -->
の所有者に通知します。 ファイルが削除されたことを示します。ただし、削除した他のファイルの所有者には通知しません。
すべてのスプール・ディレクトリーから古いファイルをすべて削除し、それらのファイルが削除されたことをユーザーに通知するには、次のように入力します。
/usr/sbin/uucp/uuclean -m
このコマンドは、スプール・ディレクトリーのすべてのサブディレクトリー内にあるファイルの中で、
72 時間 (デフォルト) より古いものをすべて削除します。 削除した各ファイルのオーナーにメールを送信します。
uuclean
コマンドが
cron
デーモンによって定期的に開始されるようにスケジュールするには、次のようなエントリーを
/var/spool/cron/crontabs/uucp
ファイルに追加します。
15 22 * * * /usr/sbin/uucp/uuclean -n96 -pC -pD -pX
このエントリーにより、
cron
デーモンは
uuclean
コマンドを 2: 15 (10:15 p.m) に開始します。 毎日。
ユクレアン
コマンドは、すべてのコマンド (
C. * -->
) を削除します。 データ (
D. * (D)
) および実行 (
X * (*)
) スプール・ディレクトリーのすべてのサブディレクトリーから 96 時間より古いファイル。
