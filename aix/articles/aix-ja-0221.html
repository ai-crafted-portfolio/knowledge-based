目的
保管された資格情報を使用して Server Message Block (SMB) クライアント共有の以後のマウント操作を可能にするために、
/etc/smbcred
ファイルに保管されている特定のサーバー・ユーザー・エントリーのパスワードを変更します。

説明
chsmbcred
コマンドを実行する場合は、サーバー名とユーザー名を指定する必要があり、オプションでパスワードを指定できます。 指定したサーバーとユーザーのセットの資格情報が
/etc/smbcred
ファイルに見つかった場合、パスワードが
-p
フラグで指定されていないと、コマンド・ラインでパスワードを要求するプロンプトが出されます。
/etc/smbcred
ファイルで定義されているサーバー・ユーザー・エントリーの既存パスワードを置き換えるには、隠し入力として読み取られ、暗号化形式で
/etc/smbcred
ファイルに保管されているパスワードを指定します。

構文
chsmbcred -s server_name -u user_name [-p password]

オプション
フラグ
-
サーバー名
これは、リモート・ホスト (SMB サーバー) の名前を指定します。 ホスト名、IP アドレス、または完全修飾ドメイン・ネームとして
server_name
パラメーターを指定できます。
-
ユーザー名
指定したリモート・ホストにアクセスできるように、指定したパスワードでパスワードを変更するユーザー名を指定します。
-
パスワード
指定したリモート・ホストの特定ユーザー名の既存パスワードを変更するために使用される新規パスワードを指定します。

例
user1
が
xxx.in.ibm.com
サーバーに SMB クライアント・ファイルシステムをマウントするために、
/etc/smbcred
ファイルに保管されているパスワードを変更するには、次のコマンドを入力します。
chsmbcred -s xxx.in.ibm.com -u user1
