目的
最小特権 (LP) リソースのアクセス制御を変更します。

説明
chlpracl
コマンドは、最小特権 (LP) リソースに関連付けられているアクセス制御リスト (ACL) を変更します。 このコマンドにより、アクセス指定を Resource ACL に追加するか、またはアクセ
ス指定をこの ACL から削除することができます。 この ACL は、属性値のリスト作成や LP コマンドの
実行などのリソース操作へのアクセスを制御します。 LP リソースごとに Resource ACL が 1 つ存在します。
LP リソースへのアクセスを制御するために、以下の 3 つの異なるタイプの Resource ACL が存在します。
Resource ACL
Resource Initial ACL
Resource Shared ACL
chlpracl
コマンドにより、Resource ACL は、アクセスを制御する代わりに Resource Shared ACL を使用する必要があることを示すことができます。 これらの ACL の説明については、
lpacl
情報ファイルを参照してください。
アクセス指定を Resource ACL に追加するには、LP リソースの名前、その ID、およ
びその ID が持つアクセス権を指定します。 ID とアクセス権のペアを、複数個指定できます。 複数の ID を追加する場合で、それらの ID がすべて同じ許可を持つ場合は、
-l
フラグを使用して、コマンドの形式が ID とそれに続く単一の許可 (すべての ID に適用される) のリストであることを示します。
-o
フラグを使用すると、コマンドで指定された ID とアクセス権によって既存のアクセス権が上書きされます。 この ACL の中の事前定義のアクセス指定は削除されます。
アクセス権を Resource ACL から削除するには、
-d
フラグを使用して、LP リソースの名前と削除する ID を指定します。
アクセス権がファイルに指定されていることを示すには、
-f
フラグを使用します。 このファイルの各行が、ID とその ID のアクセス権となります。
-d
フラグを
-f
フラグと一緒に使用すると、各行には ID のみが必要になります。 最初のスペースの後にあるものはすべて無視されます。
このコマンドはどのノードでも実行できます。 ドメイン内のすべてのノードでこのコマンドを実行する場合は、
-a
フラグを使用します。 ドメイン内のノードのサブセットでこのコマンドを実行する場合は、
-n

フラグを使用します。 それ以外の場合、このコマンドはローカル・ノードで実行されます。

構文
1 つ以上のアクセス指定を Resource ACL に追加するか、または 1 つ以上のアク セス指定を用いて Resource ACL を上書きする場合: chlpracl [ -a | -n host1 [ , host2 , ...] ] [ -o ] [ -r ] [ -h ] [ -TV ] リソース ID_1 perm1 [ ID_2 perm2 ] ... 1 つ以上のアクセス指定を Resource ACL に追加するか、またはすべて同じアクセ ス権を使用した 1 つ以上のアクセス指定を用いて Resource ACL を上書きする場合: chlpracl [ -a | -n host1 [ , host2 , ...] ] -l [ -o ] [ -r ] [ -h ] [ -TV ] resource ID_1 [ ID_2 ...] 永続 1 つ以上のアクセス指定を Resource ACL から削除する場合: chlpracl [ -a | -n host1 [ , host2 , ...] ] -d [ -r ] [ -h ] [ -TV ] リソース ID_1 [ ID_2 ...] アクセス指定を Resource ACL に追加する (またはアクセスをこの ACL から削除す る)、あるいはファイルの中に指定されているアクセス指定を用いて Resource ACL を上書きする場合: chlpracl [ -a | -n host1 [ , host2 , ...] ] [ -o | -d ] -f file_name [ -r ] [ -h ] [ -TV ] リソース アクセス権が許可されないように 1 つの Resource ACL を設定するか、または Resource Shared ACL を使用する場合: chlpracl [ -a | -n host1 [ , host2 , ...] ] { -b | -x } [ -r ] [ -h ] [ -TV ] リソース アクセス権が許可されないようにすべての Resource ACL を設定するか、または Resource Shared ACL を使用する場合: chlpracl [ -a | -n host1 [ , host2 , ...] ] { -B │ -X } [ -h ] [ -TV ]
