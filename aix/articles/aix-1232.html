目的

ローカルで定義された特定の役割ベースのアクセス制御 (RBAC) およびドメインの役割ベースのアクセス制御テーブルを LDIF フォーマットで標準出力 (stdout) に出力します。

構文

rbactoldif -dbaseDN [ -s テーブル ]

説明

rbactoldif コマンドは、ローカルに定義された RBAC テーブルからデータを読み取り、結果を LDIF フォーマットで stdout に出力します。 ファイルにリダイレクトすると、ldapadd コマンドまたは ldif2db コマンドを使用して、LDAP サーバーに結果を追加できます。

rbactoldif コマンドは /etc/security/ldap/sectoldif.cfg ファイルを読み取って、権限、ロール、特権コマンド、特権デバイス、およびデータのエクスポート先の特権ファイル・サブツリーにどのような名前を付けるかを決定します。 rbactoldif コマンドは、ファイルで定義されている AUTHORIZATION、ROLE、PRIVCMD、PRIVDEV、および PRIVFILE の各タイプにのみデータをエクスポートします。 このファイルで指定される名前は、-d フラグで指定される基本識別名 (DN) の下にサブツリーを作成するために使用されます。 詳しくは、「 Files Reference 」の /etc/security/ldap/sectoldif.cfg ファイルを参照してください。

フラグ

項目
説明
-d baseDN RBAC データが下に置かれる指定 DN を指定します。
-s 表 読み取りの対象となるテーブルのセットを指定します。 -s フラグを指定しない場合は、すべての RBAC およびドメインの RBAC テーブルが読み取られます。 以下の文字の 1 つ以上を指定します。これらの文字はそれぞれテーブル名を表します。
a
権限テーブルを指定します。
c
特権コマンド・テーブルを指定します。
d
特権デバイス・テーブルを指定します。
e
ドメイン・テーブルを指定します。
f
特権ファイル・テーブルを指定します。
o
ドメイン・オブジェクト・テーブルを指定します。
r
ロール・テーブルを指定します。
t
trvi テーブルを指定します。

セキュリティー

rbactoldif コマンドは、モード・ビット 500 を持ち、root グループおよびセキュリティー・グループにより所有されます。

アクセスされるファイル

ファイル
モード
/etc/security/authorizations r
/etc/security/roles r
/etc/security/privcmds r
/etc/security/privdevs r
/etc/security/privfiles r
/etc/security/.rbac_ids r
/etc/security/domains r
/etc/security/domobjs r

例

  1. すべての RBAC テーブルおよびドメイン RBAC テーブルを、以下の基本 DN を持つ LDIF フォーマットにエクスポートします。cn=aixdata次のコマンドを使用します。
    rbactoldif -d cn=aixdata
  2. 基本 DN を持つ許可テーブルおよびロール・テーブルのみをエクスポートするには、以下のようにします。cn=aixdata次のコマンドを使用します。
    rbactoldif -d cn=aixdata -s ar
  3. 基本 DN を持つ domobjs 表のみをエクスポートするには、以下のようにします。cn=aixdata次のコマンドを使用します。
    rbactoldif -d cn=aixdata -s o
