目的
プリンターまたはプロッターのアカウンティング・レコードを準備します。

説明
pac
コマンドは、選択されたプリンターのユーザーごと、または
Name
パラメーターで指定されたユーザーごとに、プリンターまたはプロッターのアカウンティング・レコードを準備します。 プリンターの選択については、
-P
フラグのセクションを参照してください。
計測単位は、ラスター・デバイスを除き、用紙のフィートが計測されるページの数です。 出力は、使用される単位の数と料金 (単位はドル) の両方で表されます。 1 単位当たりの料金 (価格) については
-p
フラグのセクションを参照してください。
/etc/qconfig
ファイルで指定されたアカウンティング・ファイル、および要約情報を格納するために作成されたファイルは、root ユーザーまたは
printq
グループに読み取りおよび書き込み権限を付与する必要があります。
pac
コマンドは、
/etc/qconfig
ファイル内の
acctfile =
節で指定されたパス名に
_sum
を付加することによって、要約ファイル名を生成します。 例えば、
qconfig
ファイルが以下のようになるとします。
acctfile = /var/adm/1p0acct
pac
コマンドは要約ファイルに
/var/adm/1p0acct_sum
という名前を付けます。

構文
pac [ -c ] [ -m ] [ -p Price ] [ -P Printer ] [ -q File ] [ -r ] [ -s ] [ Name ... ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-c | ユーザーのアルファベット順の代わりに、価格別に出力をソートします。
-m | ホスト・コンピューターに関係なくユーザーのすべての印刷料金をグループ化します。
-p 価格 | 出力の 1 単位当たりで請求される価格をドルで指定します。 デフォルトでは、システムは単位当たり $0.02 を課金します。
-P Printer | アカウンティング・レコードが作成されるプリンターを指定します。 デフォルトでは、システムは、 PRINTER 環境変数またはデフォルト値 lp0 で指定されたプリンターを選択します。 注: LPDEST 環境変数を設定すると、同じに機能する PRINTER 環境変数より優先されます。 コマンド行から発行された宛先オプションは、 LPDEST 環境変数と PRINTER 環境変数の両方をオーバーライドします。
-q ファイル | キュー構成ファイルを指定します。 デフォルト値は /etc/qconfig ファイルです。
-r | ソート順序を反転させます。これを指定すると、レコードが z から a までの逆アルファベット順にソートされたり、価格が降順にソートされます。
-s | 要約ファイル内でアカウント情報を要約します。 このフラグは処理量の大きいシステムに必要です。

例
lp0
プリンターのすべてのユーザーに関するプリンターまたはプロッターのアカウンティング情報を作成するには、次のように入力します。
/usr/sbin/pac
このコマンドは、印刷されたページ数と料金をユーザー別にソートして表示します。 この例では
PRINTER
環境変数を指定しないと想定しています。
プリンターまたはプロッターのアカウンティング・レコードを要約ファイルに収集するには、次のように入力します。
/usr/sbin/pac
-s
smith
、
jones,
および
greene
のプリンターまたはプロッターのアカウンティング情報を
lp12
プリンターから作成するには、次のように入力します。
/usr/sbin/pac
-P
lp12 smith jones greene
注:
フラグと変数の間にはスペースを入れないでください。例えば
-p
Price、
-P
Printer
、
-q
File
のように指定します。
