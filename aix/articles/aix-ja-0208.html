目的
リソース・モニターおよび制御 (RMC) ACL ファイルを更新します。

説明
このコマンドは、RMC ACL ファイル (
/var/ct/cfg/ctrmc.acls
) を更新するために使用します。 このファイルが存在しない場合、
chrmcacl
はデフォルト ACL ファイルを
/opt/rsct/cfg/ctrmc.acls
から
/var/ct/cfg/ctrmc.acls
にコピーします。 このコマンドは、標準入力から更新情報を読み取ります。 この入力は ACL ファイル・フォーマットでなければなりません。そのため、1 つ以上のスタンザで構成されている必要があります。この場合、各スタンザは、スタンザ名で始まり、その後にゼロあるいはそれ以上のスタンザ行が続きます。 スタンザは、ブランク行、コメント行、別のスタンザ、またはファイルの終わりで終了します。 詳細については、「
Administering RSCT
」の RMC ACL ファイルの説明を参照してください。
フラグを指定しないと、
chrmcacl
はスタンザ全体の追加、置換、または削除を行います。 入力スタンザが ACL ファイル内に存在していなければ、追加されます。 ACL ファイル内に入力スタンザと一致するものがある場合は、入力スタンザは、既存の ACL ファイル・スタンザと置き換わります。 入力スタンザにスタンザ行が含まれておらず、ACL ファイル内に入力スタンザと一致するものがある場合は、既存の ACL ファイル・スタンザは除去されます。
-a
、
-r
、または
-d
フラグが指定されている場合、
chrmcacl
は個々のスタンザ行の追加、置換、または削除を行います。 スタンザ行は、マッチング・スタンザ内のスタンザ行のユーザー ID およびオブジェクト・タイプ・トークンに基づいてマッチングされます。 マッチングは正確でなければなりません。すなわち、ワイルドカード・マッチングはありません。
-a
フラグを使用すると、入力スタンザ行に指定された許可が、ACL ファイル内の一致するスタンザ行の許可に追加されます。 この結果、アクセス権に有効な変更が生じた場合は、ACL ファイル内の新規アクセス権が更新されます。 ACL ファイル内にマッチング・スタンザ行がない場合は、入力スタンザ行は ACL ファイル内のマッチング・スタンザに追加されます。
-r

フラグを使用すると、入力スタンザ行は ACL ファイル内の一致するスタンザ行を無条件に置き換えます。 ACL ファイル内にマッチング・スタンザ行がない場合は、入力スタンザ行は ACL ファイル内のマッチング・スタンザに追加されます。
-a
フラグおよび
-r
フラグの場合、入力スタンザが ACL ファイルに一致しなければ、完全な入力スタンザが ACL ファイルに追加されます。
-d
フラグを使用すると、ACL ファイル内のすべての一致するスタンザ行が削除されます。 その結果、ACL ファイル内のマッチング・スタンザにスタンザ行がない場合は、そのスタンザは ACL ファイルから除去されます。
このコマンドの副生成物として、各スタンザ内のスタンザ行は、最も具体的なユーザー ID およびオブジェクト・タイプから具体的でないユーザー ID およびオブジェクト・タイプに至るまで順序付けられます。
chrmcacl
コマンドは、他の RSCT コンポーネントによって使用されるファイル・ロックを使用して、更新をシリアライズし、ファイル破損を防止します。 したがって、ファイルを直接変更するのではなく、このコマンドを使用して ACL ファイルを更新することをお勧めします。
ACL ファイルが更新されると、前のバージョンが最初に
/var/ct/cfg/ctrmc.acls.orig
として保存されます。 有効な変更がない場合または何らかのエラーがある場合は、ACL ファイルは更新されません。
ACL ファイルへの変更は、次に RMC サブシステムが始動するときに有効になります。 ACL ファイルの変更を即時に有効にさせるには、次のコマンドを実行します。
refresh -s ctrmc

構文
chrmcacl [ -a │ -d │ -r │ -h ]

オプション
フラグ
-a
入力スタンザ行のアクセス権をマッチング ACL ファイル・スタンザ内のマッチング・スタンザ行に追加します。
-d
マッチング ACL ファイル・スタンザ内のマッチング・スタンザ行を削除します。
-r
マッチング ACL ファイル・スタンザ内のマッチング・スタンザ行を入力スタンザ行と置き換えます。
-h
コマンドの使用状況ステートメントを標準エラーに書き込みます。

例
/var/ct/cfg/ctrmc.acls
ファイルに既に
IBM.Sensor
スタンザが含まれているが、
OTHER
スタンザが含まれていない場合は、
chrmcacl
に以下の入力を行います (フラグは指定しません)。
IBM.Sensor
joe@Host1.CoX.com * rw
Host1.CoX.com * r
OTHER
Host1.CoX.com C r
コマンドが正常に完了すると、
IBM.Sensor
スタンザが入力スタンザに置き換えられ、
OTHER
スタンザがファイルに追加されます。
例 1 の結果であり、
chrmcacl
への以下の入力 (フラグを指定しない) が与えられた
/var/ct/cfg/ctrmc.acls
ファイルを使用します。
IBM.Sensor
OTHER
Host1.CoX.com * r
コマンドが正常に完了すると、
IBM.Sensor
スタンザが削除され、
OTHER
スタンザが入力スタンザに置き換えられます。
例 2 の結果であり、
chrmcacl
への以下の入力 (
-a
フラグを指定) が与えられた
/var/ct/cfg/ctrmc.acls
ファイルを使用します。
OTHER
Host1.CoX.com * w
ファイル内の
OTHER
スタンザは、次のようになります。
OTHER
Host1.CoX.com * rw
:NONE.
例 3 の結果であり、例 3 と同じ
chrmcacl
への入力 (
-r
フラグを指定) が与えられた
/var/ct/cfg/ctrmc.acls
ファイルの場合、ファイル内の
OTHER
スタンザは次のようになります。
OTHER
Host1.CoX.com * w
:NONE.
/var/ct/cfg/ctrmc.acls
ファイルに以下のスタンザがあるとします。
IBM.Sensor
joe@Host1.CoX.com C rw
joe@Host1.CoX.com R r
Host1.CoX.com * r
および
chrmcacl
への以下の入力 (
-d
フラグを指定):
IBM.Sensor
joe@Host1.CoX.com R r
ファイル内の
IBM.Sensor
スタンザは、次のようになります。
IBM.Sensor
joe@Host1.CoX.com C rw
Host1.CoX.com * r
:NONE.
