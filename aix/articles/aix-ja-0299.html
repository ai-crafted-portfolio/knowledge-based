目的
メッセージ・セキュリティー・サービス (MSS) キー・ファイルの内容を表示および管理します。

説明
ctmsskf
コマンドは、メッセージ・セキュリティー・サービス (MSS) タイプのキー・ファイルの内容を表示および管理します。 このコマンドは、キー・ファイルに対するキーの追加と削除、またはキー・ファイルの内容のリストに使用します。
鍵の追加:
このコマンドを使用してキー・ファイルにキー・エントリーを追加する場合は、以下の項目を指定する必要があります。
キーを追加するキー・ファイルの名前
追加するキーのタイプ
キー・ファイルに追加するキーのバージョン (オプション)
16 桁のキーの値
このコマンドは、指定したキー・ファイルが存在しない場合にはそのファイルを作成します。 指定された鍵ファイルが
存在する
場合、
ctmsskf
コマンドは、新しい鍵に指定された鍵タイプが、ファイル内に既に記録されている鍵で使用されているタイプと一致しているかどうかを検査します。 既存のキー・ファイルに追加できるのは、同一タイプのキーのみです。 キーがファイルに正常に追加されると、そのキーのバージョンは
アクティブ・キー・バージョン
となります。
-v
key_version
フラグを使用して鍵バージョンを指定すると、
key_version
が新しいバージョン番号として使用され、アクティブ・バージョンになります。
key_version
を指定しなければ、前のアクティブ・キー・バージョン番号より 1 つ大きいキー・バージョン値を使用してキーが追加されます。
存在しているキーのバージョンは交換できません。 鍵の既存のバージョンを置き換えたり、鍵の既存のバージョンの値を変更したりするには、まず
-d
フラグを使用してその鍵バージョンを削除してから、
-a
フラグを使用して再度追加する必要があります。 既存のキー・ファイル内のキーで使用中のバージョン番号を使用したキーを追加しようとすると、コマンドはエラーを戻します。 一般に、キーの交換は現在アクティブなキーの値でのみ実行する必要があります。
なぜなら、古いキー・バージョンの値を変更すると古いキー・バージョンがアクティブになってしまいます。
キー・バージョンは任意の順序でキー・ファイルに追加できるので、最も大きいキー・バージョン番号が現在アクティブなキー・バージョンかどうかはわかりません。 ファイルに対して現在アクティブな鍵バージョンを判別するには、
-l
フラグを使用します。
鍵の削除:
このコマンドを使用してキー・エントリーをキー・ファイルから削除する場合は、以下の項目を指定する必要があります。

キーを削除するキー・ファイルの名前
削除するキーのタイプ (オプション)
削除するキーのバージョン (オプション)
このコマンドは、指定されたキーが空か、存在しないか、または適切なヘッダーを持っていない場合は、エラーを戻します。 キー・タイプが指定されていて、それがヘッダー内のキー・タイプと一致しない場合は、エラーを戻します。 キー・バージョンが指定されている場合は、その指定されたバージョンに対応するレコードを見つけて、それをファイルからパージします。 そのようなレコードが存在しない場合は、エラーを戻します。 キー・バージョンが指定されていない場合は、非アクティブとしてマークされたレコードだけをパージします。
鍵ファイルの内容のリスト:
このコマンドを使用してキー・ファイルの内容をリストする際には、次の情報が表示されます。
キー・ファイルのヘッダー。
キー・ファイル内のキーのリスト。
各キーに対し次の情報が表示されます。
レコードが非アクティブかどうかの表示
キーのバージョン
キーのタイプ
16 桁のキーの値

構文
ctmsskf { -a | -d | -l | -h } [ -f key_file ] [ -t key_type ] [ -v key_version ] [ -k key_value ]

オプション
フラグ
-a
キーをキー・ファイルに追加します。
-f
、
-k
、および
-t
フラグも指定する必要があります。
-d
キー・ファイルからキーを削除します。
-f
および
-v
フラグも指定する必要があります。
-t
フラグが指定されている場合、コマンドは、鍵ファイルのタイプが指定された鍵タイプと同じであるかどうかを検査します。
-l
キー・ファイルの内容をリストします。
-f
フラグも指定する必要があります。
-v
フラグが指定されている場合、コマンドは指定されたバージョン番号と一致するキーのみをリストします。
--f
key_file
キー・ファイルの名前を指定します。 このキー・ファイルは、MSS API またはこのコマンドによって作成された有効なキー・ファイルでなければなりません。
--t
キータイプ
追加するキーのタイプを指定します。 その指定したキー・ファイルが空でない場合、指定したキー・タイプがそのキー・ファイルのヘッダー内のキー・タイプと一致するかどうかが検査されます。 有効なキー・タイプ値は、
3des_md5
、
aes256_md5
、
des_cbc
、
des_md5
、
rsa512_sha
、および
rsa1024_sha
です。
--v
key_version
キーのバージョンを指定します。
--k
key_value
16 桁のキーの値を指定します。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。

例
鍵ファイル
/my_key_file
に含まれている鍵を表示するには、次のように入力します。
ctmsskf -l -f /my_key_file
バージョン 9 の鍵を鍵ファイル
/my_key_file
から表示するには、次のように入力します。
ctmsskf -l -v 9 -f /my_key_file
鍵ファイル
/my_key_file
に鍵を追加するには、次のように入力します。
ctmsskf -a -t des_cbc -f /my_key_file -k 16_digit_value
鍵ファイル
/my_key_file
から鍵を削除するには、次のように入力します。
ctmsskf -d -f /my_key_file -v 10
鍵ファイル
/my_key_file
内のすべての非アクティブ鍵を削除するには、次のように入力します。
ctmsskf -d -f /my_key_file
