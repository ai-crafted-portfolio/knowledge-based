目的
指定されたメディア上のボリューム・グループ・バックアップの内容をリストまたは復元します。

説明
lsmksysb
コマンドは、テープ、ファイル、CD-ROM、またはその他のソースからのボリューム・グループ・バックアップの内容をリストし、有効なバックアップ・ソースからのファイルの復元のために使用できます。
lsmksysb
コマンドは、複数の CD、DVD、USB ディスク、またはテープなどのマルチボリューム・バックアップにも機能します。
lsmksysb -r
コマンドおよび
restorevgfiles
コマンドは同等な操作を実行し、交換可能であると見なされます。

構文
LSMKSYSB [ -b ブロック ] [ 「-f」 装置 ] [ -a 値 ] [ 「-c」 ] [ - ] [ N ] [ - ] [ -s ] [ -d 年 パス ] [ -B ] [ -D ] [ -L (L) ] [ V 値 ] [ ファイル・リスト ]

オプション
フラグ
項目 | 説明
-a | -b block フラグで定義されたように、テープ・バックアップの物理ブロック・サイズを検査します。 バックアップの読み取りの必要に応じて、ブロック・サイズを変更できます。 -a フラグが有効なのは、テープ・バックアップが使用された場合のみです。
-b ブロック | blocks パラメーターによって定義されたように、1 回の入力操作で読み取る 512 バイト単位のブロック数を指定します。 blocks パラメーターが指定されない場合、読み取るブロックのデフォルト値は 100 です。
-B | ボリューム・グループ・バックアップ・ログを stdout に表示します。 このフラグは、過去 256 のバックアップを表示します (概要を表示)。 ログは alog フォーマットで、 /var/adm/ras/vgbackuplog に保管されます。 ログの各行には、セミコロンで区切られたファイルまたはデバイス名、バックアップを作成する際に使用されたコマンド、バックアップの日付、圧縮サイズ、フルサイズ、および推奨保守レベルまたはテクノロジー・レベル (ある場合) がリストされます。 注: 縮小サイズは、すべてのファイル・システム上のデータのサイズです。 フルサイズは、各ファイルシステムの合計サイズです (未使用 + データ)。
-c | コロンで区切られた出力を生成します。 このフラグは、 -l フラグおよび -L フラグと共に指定した場合のみ機能します。
-d パス | ファイルが復元されるディレクトリー・パスを path パラメーターで定義されたように指定します。 -d パラメーターを使用しない場合には、現在の作業ディレクトリーが使用されます。 これは、現在の作業ディレクトリーが root の場合に問題となります。 root の代わりに、一時フォルダーに書き込むことをお勧めします。
-D | デバッグ出力を生成します。
-f デバイス | バックアップ (ファイル、テープ、CD-ROM、またはその他のソース) を含むデバイスのタイプを device パラメーターで定義されたように指定します。 -f が指定されない場合、 device のデフォルトは /dev/rmt0 です。

-l | ボリューム・グループ・バックアップに関する有効な情報を表示します。 このフラグには、 -f device フラグが必要です。 このフラグを指定すると、 lsmksysb は、ボリューム・グループ、バックアップ 作成日時、バックアップ・システムの uname 出力、OS レベル、推奨保守レベルまたはテクノロジー・レベル、 バックアップ・サイズ (メガバイト)、バックアップ圧縮サイズ (メガバイト) などの情報を表示します。 圧縮サイズは、すべてのファイルシステム上のデータのサイズです。 フルサイズは、各ファイルシステムの合計サイズです (未使用 + データ)。 また、 -l フラグは、" lsvg -l vgname " の実行時と同じように、バックアップ・ボリューム・グループの論理ボリュームおよびファイルシステム情報も表示します。
-L | mksysb バックアップのみに関する lpp ファイルセット情報を表示します。 このフラグには、 -f device フラグが必要です。 このフラグは、稼働中のバックアップ・システムで " lslpp -l " を実行 した際に生成される情報と同じ情報を表示します。 このフラグは、 mksysb 以外で作成されたボリューム・グループ・バックアップ に関する出力は生成しません。
-n | ACL、PCL、または拡張属性を復元しません。
-r | file-list パラメーターで定義されたようにバックアップ・ファイルを復元するために指定します。 file-list パラメーターが指定されない場合、バックアップ中のすべてのファイルが復元されます。 -r フラグが使用されない場合、 lsmksysb コマンドを実行すると、指定したバックアップ内のファイルのみがリストされます。
-s | バックアップ・ソースがユーザー・ボリューム・グループであって rootvg ではないことを指定します。
-V | テープ・バックアップを検証します。 このフラグには、 -f device フラグが必要です。 このフラグは、磁気テープ装置のみに使用します。 -V フラグを指定すると、 lsmksysb は、 ボリューム・グループ・バックアップ上の各ファイルのヘッダーの読み易さを検証し、 発生したエラーを stderr に表示します。

例
デフォルト・デバイス
/dev/rmt0
上のシステム・バックアップの内容をリストするには、次のコマンドを入力します。
lsmksysb
デバイス
/dev/cd1
上のシステム・バックアップの内容をリストするには、次のコマンドを入力します。
lsmksysb -f /dev/cd1
rootvg ではないユーザー・ボリューム・グループである、デバイス
/dev/cd1
上のシステム・バックアップの内容をリストするには、次のコマンドを入力します。
lsmksysb -f /dev/cd1 -s
デバイス
/dev/cd1
上のシステム・バックアップから
/etc/filesystems
を復元するには、次のコマンドを入力します。
lsmksysb -f /dev/cd1 -r ./etc/filesystems
デバイス
/dev/cd1
上の rootvg ではないバックアップの
/myfs/test
ディレクトリー中のすべてのファイルを復元し、復元されたファイルを
/data/myfiles
に書き込むには、次のコマンドを入力します。
lsmksysb -f /dev/cd1 -r -s -d /data/myfiles ./myfs/test
/dev/rmt0
にある
mksysb
バックアップ・テープに関する lpp 情報をコロンで区切って表示するには、次のコマンドを入力します。
lsmksysb -Lc -f /dev/rmt0
ボリューム・グループのバックアップ・ログを
stdout
に表示するには、次のコマンドを入力します。
lsmksysb -B
/tmp/mybackup
にあるバックアップに関するボリューム・グループおよび汎用バックアップ・データをリストするには、次のコマンドを入力します。
lsmksysb -l -f /tmp/mybackup
/dev/rmt0
にあるボリューム・グループ・バックアップ・テープ上の各ヘッダーの読み易さを検証するには、次のコマンドを入力します。
lsmksysb -V -f /dev/rmt0
デバイス
/dev/usbms0
上のシステム・バックアップの内容をリストするには、次のコマンドを入力します。
lsmksysb –f /dev/usbms0
