目的
プロセッサーのクロック速度を測ります。

説明
pmcycles
コマンドは、システムの
公称
プロセッサー速度と測定プロセッサー速度を MHz 単位で表示します。 公称プロセッサー速度とは、すべての環境およびワークロードの条件において、システムが動作できる最大周波数です。 システム条件によっては、公称プロセッサー周波数は、達成可能な最小または最大のプロセッサー速度を表さない可能性があります。 測定周波数とはプロセッサーの現行動作周波数です。
現時点でのプロセッサー速度を判別するには、
lparstat -E 1 1
コマンドと
mpstat -E 1 1
コマンドも使用できます。

構文
pmcycles [ -d ] [ -m ] [ -M ]

オプション
フラグ
項目 | 説明
-d | 速度の減分を MHz 単位およびティックあたりのナノ秒数で示します。
-m | それぞれのプロセッサーの速度を表示します。
-M | これは、プロセッサーの測定周波数を表示します。

例
プロセッサー速度を表示するには、次のコマンドを入力します。
pmcycles
出力は次の例のようになると考えられます。
This machine runs at 133 MHz
各プロセッサー速度を表示するには、次のコマンドを入力します。
pmcycles -m
出力は次の例のようになると考えられます。
Cpu 0 runs at 200 MHz
CPU 1 runs at 200 MHz
測定プロセッサー速度を表示するには、次のコマンドを入力します。
pmcycles -M
出力は次の例のようになると考えられます。
The measured frequency is 2294 MHz
