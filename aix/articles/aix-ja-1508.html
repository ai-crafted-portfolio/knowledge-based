目的
ストリーム構成を照会します。

説明
strconf
コマンドは、ストリームの構成を照会するために使用します。 フラグを指定しないで使用すると、一番上のドライバーだけでなく、ストリーム内の全モジュールのリストを表示します。 リストには、1 行に 1 つの名前が表示されます。
この場合、最初に表示される名前がストリームの一番上のモジュールで、最後に表示される項目がドライバーの名前です。
“
注:
strconf
コマンドは、標準入力からのみ読み取ります。
”

構文
strconf [ -t | -m モジュール ]

オプション
フラグ
項目 | 説明
-m モジュール | 指定したモジュールがストリーム上に存在するかどうか判別します。 モジュールが存在する場合、 strconf コマンドは次のメッセージを出力します。 yes 値 0 を戻します。 存在しない場合、 strconf コマンドは次のメッセージを表示します。 no ゼロ以外の値を戻します。 -t と -m のフラグは、同時には指定できません。
-t | ストリームの一番上のモジュール (存在する場合) だけを表示します。

例
以下のもののみを持つストリームの場合:
ldterm
上にプッシュされたモジュール
ports
ドライバーの場合、
strconf
コマンド (フラグなし) は、以下の出力を生成します。
ldterm
ports
以下のコマンドを入力すると、
ldterm
モジュールはストリーム上にあります:
strconf -m ldterm
この場合、コマンドは、以下の出力を生成し、終了状況 0 を戻します。
yes
