目的
ログに記録されたエラーのレポートを生成します。

説明
errpt
コマンドは、エラー・ログ内のエントリーからエラー・レポートを作成します。 errpt コマンドには、特定の基準に一致するエラーを選択するためのフラグが含まれています。 デフォルト条件を使用すると、エラー・ログ・エントリーを、発生時に記録したのとは逆の順序で表示することができます。
-c
(concurrent) フラグを使用すると、エラーを発生した時点の状態で表示することができます。
errpt
コマンドで
-i
フラグを使用しなければ、
errpt
によって処理されるエラー・ログ・ファイルは、エラー・ログ構成データベースで指定したファイルになります。 (エラー・ログ構成データベースの情報を表示するには、
エルデモン
コマンドを使用します。)
デフォルトの要約レポートには、エラーごとに 1 行ずつデータが入っています。 フラグを使用すると、別のフォーマットでレポートを生成できます。
“
注:
エラー
コマンドはエラー・ログ分析を実行しません。分析するには、
ディアグ
コマンドを使用します。 ただし、エラー・ログ分析を実行すると、診断によっては、
診断情報が再びエラー・ログに追加される場合があります。 このような情報は、それに対応するエラー・ログ・エントリーの明細データに続けて表示されます。
”
System Management Interface Tool (SMIT) の
smit errpt
高速パスを使用して、このコマンドを実行できます。

例
完全な要約レポートを表示するには、次のように入力します。
errpt
完全な詳細レポートを表示するには、次のように入力します。
errpt -a
エラー ID についてログに記録されたすべてのエラーの詳細報告書を表示します。
E19E094F
次のように入力します。
errpt -a -j E19E094F
過去 24 時間以内にログに記録されたすべてのエラーの詳細なレポートを表示するには、次のように入力します。
errpt -a -s mmddhhmmyy
ここで、
mmddhhmmyy
ストリングは、現在の月、日、時、分、および年から 24 時間を引いた値に等しくなります。
エラー・ログ・エントリーに対してログ記録がオフにされているエラー・レコード・テンプレートを表示するには、次のように入力します。
errpt -t -F log=0
代替エラー・ログ・ファイルのすべての項目を表示する
/var/adm/ras/errlog.alternate
次のように入力します。
errpt -i /var/adm/ras/errlog.alternate
代替エラー・ログ・ファイルからすべてのハードウェア項目を表示する
/var/adm/ras/errlog.alternate
次のように入力します。
errpt -i /var/adm/ras/errlog.alternate -d H
エラー・ラベルについてログに記録されたすべてのエラーの詳細レポートを表示します。
ERRLOG_ON
次のように入力します。
errpt -a -J ERRLOG_ON
すべてのエラーおよびグループ重複エラーの詳細レポートを表示するには、次のように入力します。
errpt -aD
8 月中のエラー・ラベル
DISK_ERR1
および
DISK_ERR2
に関してログに記録されたすべてのエラーの詳細レポートを表示するには、次のように入力します。
errpt -a -J DISK_ERR1,DISK_ERR2 -s 0801000004 -e 0831235904"
