目的

ボリューム・グループ内の物理ボリュームの特性を変更します。

構文

CHPV [ -h ホット・スペア ] [  -a 値 割り振り ] [ -v (V) 可用性 [「-f」]][ 「-c」 ] [ P- ミラー・プール ] [ -P ] [ -m (M) ミラー・プール ] 物理ボリューム ... [ -C hdiskname ]

説明

chpv コマンドは、 割り当て許可を「割り当て可能」または「割り当て禁止」のどちらかに設定し、 アベイラビリティー状態を「使用可能」か「使用不可」のどちらかに設定することにより、 ボリューム・グループの物理ボリュームの状態を変更します。 またこのコマンドは、指定の物理ボリュームのブート・レコードを消去するのに使用することもできます。 物理ボリュームの特性は、該当のフラグを使って明示的に変更しない限り、有効な状態のままになっています。
注: このコマンドを使用するには、root ユーザー権限を持っているか、 またはシステム・グループのメンバーである必要があります。

このコマンドは、System Management Interface Tool (SMIT) smit chpv 高速パスを使用しても実行できます。

フラグ

項目
説明
-a 割り振り physicalvolume パラメーターによって指定された物理ボリューム上の追加物理区画の割り当て許可を設定します。 これは、物理ボリュームに、追加物理区画の割り当てを許可 (yes) するか、禁止 (no) するかのいずれかを設定します。 allocation 変数は、以下のいずれかです。
y
物理ボリュームに対する追加物理区画の割り当てを許可します。
n
物理ボリュームに対する追加物理区画の割り当てを禁止します。 物理ボリューム上の論理ボリュームにはアクセスできます。
-c 指定の物理ボリュームのブート・レコードを消去します。
-C ディスク名 所有するボリューム・マネージャーをディスクから消去します。 このフラグは root ユーザーとして実行中の場合にのみ有効です。 ディスクがインポートされた LVM ボリューム・グループの一部である場合、このコマンドは、所有するボリューム・マネージャーとしての LVM の消去に失敗します。
-f オープン論理ボリュームのある物理ボリュームにアクティブなページングまたはダンプ・デバイスがなければ、その物理ボリュームを強制的に使用不可に (除去) します。 また、 -f フラグを使用すると、物理ボリュームに論理ボリュームの最後の正常なコピーが含まれている場合でも、その物理ボリュームに欠落のマークを強制的に付けることができます。
-h ホット・スペア 物理ボリュームのスペアリング特性を設定して、 物理ボリュームをホット・スペアとして使用できるようにします。 さらに、physicalvolume パラメーターで指定された物理ボリュームに物理区画の割り当て許可を設定します。 このフラグは、ミラーリングされていない論理ボリュームには何ら影響しません。 hotspare 変数は、以下のいずれかです。
y
ディスクを、所属するボリューム・グループ内のホット・スペア・ディスクとしてマーク付けして、 物理ボリュームへの物理区画の割り当てを禁止します。 ディスクは、ホット・スペア・ディスクとして正常にマークされる、 論理グループに割り当てられている区画を持つことを禁止されます。
n
ディスクが常駐しているボリューム・グループのホット・スペア・プールからディスクを除去し、 物理ボリュームに対して物理区画が割り当てられるようにします。
-m ミラー・プール 指定されたディスクに割り当てられたミラー・プールの名前を、mirrorpool パラメーターの値に変更します。
-p ミラー・プール 物理ボリュームをミラー・プールに割り当てます。 15 文字までの長さのミラー・プール名を指定できます。 ボリュームグループでミラープールを有効にすると、ミラープールをサポートしていないAIXのバージョン（AIXバージョン6.1以前）にボリュームグループをインポートできなくなります。
-P 現在割り当てられているミラー・プールから物理ボリュームを除去します。 ミラー・プールから物理ボリュームを除去できるのは、ミラー・プールが有効になっている論理ボリュームに 割り当てられた区画が、物理ボリュームに存在する場合のみです。
-v 可用性 物理ボリュームのアベイラビリティーを設定します。 アベイラビリティーをクローズに設定すると、物理ボリュームに対する論理入出力が停止されます。 ファイルシステムや仮想メモリー・マネージャーによる物理ボリューム・データへのアクセスは停止されますが、システム管理コマンドは引き続き使用できます。 availability 変数は、以下のいずれかです。
a
物理ボリュームを論理入出力に使用できるようにします。
r
物理ボリュームを論理入出力に使用できないように (除去) します。 ボリューム・グループ・クォーラムを維持するために物理ボリュームが必要な場合は、エラーが発生し、物理ボリュームは論理入出力に使用可能なままになります。
注: chpv -vr コマンドが正常に実行されると、物理ボリュームはボリューム・グループ・クォーラムの一部ではなくなります。 chpv -vr コマンドは、指定された物理ボリュームの論理ボリューム・マネージャー (LVM) メタデータ領域を更新する必要があります。 物理ボリュームが低速である場合は、 chpv -vr コマンドを使用して論理入出力用の物理ボリュームを除去する代わりに、 chpv -vm コマンドを使用して欠落のマークを付けることができます。
m
物理ボリュームに欠落のマークを付けます。

ボリューム・グループ・クォーラムを維持するために物理ボリュームが必要な場合、 chpv コマンドは失敗します。 物理ボリュームに論理ボリュームの最後の正常なコピーが含まれている場合、強制フラグ (-f) を使用しない限り、 chpv コマンドは失敗します。

注: chpv -vm コマンドが正常に実行されると、物理ボリュームは欠落としてマークされますが、ボリューム・グループ・クォーラムの一部として残ります。 物理ボリュームが欠落状態の場合、指定された物理ボリュームの LVM メタデータ領域を更新する必要はありません。

例

  1. 物理ボリュームをクローズするにはhdisk3次のコマンドを入力します。
    chpv  -vr hdisk3
    物理ボリュームは、 -va フラグが使用されるまで、論理入出力に対してクローズされます。
  2. 物理ボリュームを開くには hdisk3次のコマンドを入力します。
    chpv  -va hdisk3
    これで、論理入出力に対して物理ボリュームがオープンされます。
  3. 物理ボリュームへの物理区画の割り当てを停止するhdisk3次のコマンドを入力します。
    chpv  -an hdisk3
    -ay フラグが使用されるまで、物理区画を割り当てることはできません。
  4. 物理ボリュームのブート・レコードをクリアするhdisk3次のコマンドを入力します。
    chpv -c hdisk3
  5. 物理ボリュームに欠落のマークを付けるには、次のコマンドを入力します。
    chpv -vm hdisk3
