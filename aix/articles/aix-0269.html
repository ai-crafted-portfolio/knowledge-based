目的

フィルター・ルールの構文を検査します。

構文

ckfilt [ -O ] [ -v 4 | 6 ]

説明

ckfilt コマンドは、フィルター・ルールの構文を検査します。 IPsec ステートフル・フィルター・ルールでは、IF、ELSE、および ENDIF などのアクションが可能です。 そのため、ルール・セットの中で構文エラー (ENDIF を伴わない IF、または IF が先行していない ELSE や ENDIF など) が発生する可能性があります。 ckfilt コマンドは、そのようなエラーがないか検査します。 IF ルールのネストは許可されます。 ckfilt コマンドは、フィルター規則を表示し、有効範囲を指定する方法で IF ステートメント内の規則を字下げします。 -O フラグを使用すると、フィルター・ルールとそのすべての属性がスコープ設定された方法で表示されます。 このコマンドの IPsec フィルター規則は、 genfilt コマンド、「仮想プライベート・ネットワーク」サブメニューの IPsec smit (IP バージョン 4 または IP バージョン 6) を使用して構成することができます。

フラグ

項目
説明
-O フィルター・ルールの属性を表示します。
-v 4 | 6 IPv4 または IPv6 を指定します。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 コマンドは正常に完了しました。
non-zero エラーが発生しました。

セキュリティー

このコマンドを実行できるのは root だけです。

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

例

  1. ネストされた if-else-endif フィルター・ルールのセットを作成するには、以下のように genfilt コマンドを使用します。
    genfilt -v4 -a I -s 192.168.100.101 
-d 192.168.100.102 -c tcp -O eq -P 21 -D "IF ftp-cmd being used"

genfilt -v4 -a I -s 192.168.100.101
-d 192.168.100.102 -c tcp -O eq -P 1525 -D "IF 1525 port starts being used"

genfilt -v4 -a D -s 192.168.100.101
-d 192.168.100.102 -c tcp -O eq -P 37 -D "if scope: deny time"

genfilt -v4 -a L -s 192.168.100.101
-d 192.168.100.102 -c tcp -D "ELSE"

genfilt -v4 -a D -s 192.168.100.101 
-d 192.168.100.102 -c tcp -O eq -P 13 -D "else scope: deny date"

genfilt -v4 -a E -s 192.168.100.101 
-d 192.168.100.102 -c tcp -D "ENDIF"

genfilt -v4 -a L -s 192.168.100.101 
-d 192.168.100.102 -c tcp -D "ELSE"

genfilt -v4 -a D -s 192.168.100.101 
-d 192.168.100.102 -c tcp -O eq -P 20 -D "else scope: deny ftp-data"

genfilt -v4 -a E -s 192.168.100.101 
-d 192.168.100.102 -c tcp -D "ENDIF"

場所

/usr/sbin/ckfilt

ファイル

項目
説明
/etc/security/ipsec_filter このコマンドは、 /etc/security/ipsec_filter ODM データベースを読み取ります。 このデータベースでは、 genfilt および chfilt コマンドを使用して、規則の挿入と変更を行います。
