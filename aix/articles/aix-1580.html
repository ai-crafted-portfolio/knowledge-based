目的

選択したローカル・システムおよびリモート・システムの統計情報を報告します。

構文

topas [ -d hotdisk ] [ -f  hotfs ] [ -h ] [ -i interval ] [ -n hotni ] [ -p hotprocess ] [ -w hotwlmclass ] [ -c hotprocessor ] [ -I remotepollinterval ] [ -@ [ wparname  ] ] [ -U username ] | [ -C -D | -G | -F |  -L | -P | -V | -T | -M | -t | -E | -W ] [ -m ]
制限事項： ワークロード・パーティションからコマンドを発行する場合は、 -C、 -L、 -E、 -V、 -T、 -t、 -w、 -W、 -I、 -@ フラグを使用しないでください。

説明

topas コマンドは、ローカル・システム上の活動に関する選択された統計情報を報告する。 このコマンドは、curses ライブラリーを使用して、 80x25 文字ベースのディスプレイ上または、 少なくとも同サイズのウィンドウでグラフィカル・ディスプレイ上で表示するのに適したフォーマットで、 その出力を表示します。 topas コマンドを実行するには、 bos.perf.tools と perfagent.tools ファイル・セットがシステムにインストールされている必要がある。

topas 。 AIX パーティションのパフォーマンス・メトリクスを報告します。 このサポートの詳細については、 Cross-Partition View および Cluster Utilization Viewのセクションを参照してください。
注： システムに対する動的なコンフィギュレーションの変更については、変更内容を表示するためにツールを再起動してください。
topas コマンド -D フラグはディスクの詳細を報告する。 レポートの詳細については、 ディスク・パネルの項を参照のこと。 ディスクパネルからサブコマンドを実行すると、以下のビューが表示される：
アダプター・パネル
d キーを押すことによって指定されます。 アダプタパネルには、選択したアダプタのアダプタとディスクの詳細が表示されます。
仮想アダプター・パネル
d キーと v キーを押して指定。 このパネルには、 ディスクに関連した仮想アダプターの詳細が表示されます。
MPIO パネル
m キーを押すことによって指定されます。 このパネルには、 ディスクとパスの詳細が表示されます。
パネルのフリーズ
キーボードの space bar キーで指定。 space bar キーは、 topas パネルをフリーズさせるトグルとして機能する。
スクロール
Page Up 、 Page Down キーでデータをスクロールする。
制限アダプタパネル、仮想アダプタパネル、MPIOパネルは WPAR 内で制限されています。

topas コマンドの変数部分は、1つ、2つ、3つ、4つ、または5つのサブセクションを表示する。 複数のサブセクションが表示される場合は、以下の順序で表示される：

  • プロセッサー使用率
  • ネットワーク・インターフェース
  • 物理ディスク
  • ファイルシステム
  • ワークロード・マネージャー クラス
  • ワークロード・パーティション

topas コマンドを起動すると、ホットエンティティを監視するサブセクションが表示される。 Workload Manager （WLM）クラスのサブセクションは、WLMがアクティブな場合にのみ表示されます。

WLMと WPARの統計情報を表示するには、WLMを起動する必要があります。

ヒント: WPAR 固有の情報がメトリックに利用できない場合、そのメトリックのシステム全体の値が背景を反転して表示されます。

このサブセクションは、ホット ワークロード・マネージャー (WLM) クラスのリストを表示します。 表示される WLM クラスの最大数は、 -w フラグで指定されたホット WLM クラスの数です。 他のサブセクションも表示されている場合、それより少ない数のクラスが表示されます。 w キーを押すと、 このサブセクションがオフになります。 各クラスで以下のフィールドが表示されます。

実行の特性

topas またはその他の SPMI コンシューマを起動した後に追加されたディスクとネットワーク・アダプタは、 topas に反映されません。 topas 、SPMIを使用するすべてのクライアントを停止し、ディスクとネットワーク・アダプターの変更後に再起動する。
