目的

X サーバーの現行出力デバイスとビューポート・サイズを変更します。

“注: このコマンドは、X サーバーの実行中にのみ使用できます。”

構文

CHVMODE [{ + | - } L ] [{ + | - } C ] [ -vsize (V サイズ) 幅X高さ [@ VSync]

説明

chvmode コマンドは、X サーバーの現行の出力デバイスとビューポート・サイズを変更します。

ビューポート・サイズの仕様は、CRT ディスプレイとその解像度にパンのオプションがある場合にのみ使用できます。

また、System Management Interface Tool (SMIT) を使用して、このコマンドを実行することもできます。

フラグ

項目
説明
+ / -c CRT 出力を使用可能または使用不可にします。
+ / -l LCD 出力を使用可能または使用不可にします。
-vsize 幅x高さ[ @VSync ] CRT ディスプレイのビューポート・サイズと、垂直同期 (Hz 単位のリフレッシュ・レート) を指定します。 @VSync が指定されない場合は、現行の垂直同期周波数が使用されます。

セキュリティー

アクセス制御: 任意のユーザー

監査イベント: なし

終了状況

次のような終了値が戻されます。

項目
説明
0 正常終了。
>0 エラーが発生しました。

例

  1. LCD パネルを使用不可にして CRT 表示を使用可能にするには、次のように入力します。
    chvmode -l +c
  2. 現在の CRT ビューポートを 1024x768に変更するには、次のように入力します。
    chvmode -vsize 1024x768
  3. 75Hzの高いリフレッシュ・レートで VGA モードを指定するには、以下のように入力します。
    chvmode -vsize 640x480@75

ファイル

項目
説明
/usr/bin/X11/chvmode chvmode コマンドが入っています。
