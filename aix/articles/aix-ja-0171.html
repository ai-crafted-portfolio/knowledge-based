目的
グループの管理者またはメンバーを変更します。

説明
chgrpmem
コマンドは、
Group
パラメーターで指定したグループの管理者またはメンバーを変更します。 このコマンドを使用して、グループのメンバーまたは管理者のリストの追加、削除、設定を行います。 ユーザーをその 1 次グループから除去することはできません。 ユーザーの 1 次グループは、
/etc/passwd
ファイル内で保守されます。
chgrpmem
コマンドでグループのみを指定すると、このコマンドは、グループのメンバーと管理者をリストにして表示します。
代替の ID および認証 (I & A) メカニズムを使用して作成されたグループの管理者またはメンバーを変更するには、
-R
フラグを使用して I & A ロード可能モジュールを指定できます。 ロード・モジュールは、
/usr/lib/security/methods.cfg
ファイルで定義されます。
グループ管理者としてユーザーを追加、削除、または設定するときは、
-a
フラグを指定します。 そうではなくて、グループ・メンバーとしてユーザーを追加、削除、または設定するときは、
-m
フラグを指定します。 これらのフラグのうちの 1 つ、およびユーザーのグループ・メンバーシップを変更するための演算子を指定する必要があります。 演算子には、次の働きがあります。
項目 | 説明
+ | 指定したユーザーを追加します。
- | 指定したユーザーを削除します。
= | 指定したユーザーに対して管理者またはメンバーのリストを設定します。
一度に複数の
User
パラメーターを指定できます。 その場合、ユーザー名をコンマで区切ったリストを指定します。
グループ情報の変更に適用される制限のリストについては、
chgroup
コマンドのセクションを参照してください。

構文
chgrpmem [ -R load_module ] [{ -a | -m } { + | - | = } ユーザー ...] グループ

オプション
フラグ
項目 | 説明
-a | グループの管理者リストを変更します。
-m | グループのメンバー・リストを変更します。
-R | グループの管理者またはメンバーの変更に使用するロード可能 I&A モジュールを指定します。

例
削除対象
jones
管理者として
f612
次のように入力します。
chgrpmem
-a
- jones f612
メンバーを追加するには
davis
および
edwards
グループへ
f612
次のように入力します。
chgrpmem
-m
+ davis,edwards f612
グループのメンバーと管理者をリストする
staff
次のように入力します。
chgrpmem staff
LDAP I & A ロード可能モジュール・グループ
monsters
のメンバーをリストするには、次のように入力します。
chgrpmem -R LDAP monsters
