目的
ネットワーク・インストール管理 (NIM) 環境に関する情報を表示します。

説明

事前定義情報は、NIM によって事前設定された値からなり、ユーザーが変更することはできません。 事前定義情報の例は次のとおりです。

構文
サポートされる NIM クラス、サブクラス、またはタイプのリストを表示する Lsnim { P- | -P } [ 「-c」 クラス | -S (S) ] 事前定義された NIM 情報を表示する Lsnim { P- | -P } [ 「-c」 クラス | -s サブクラス | T タイプ ] [ - | [ - ] | -O (O) ] [ -Z ] または lsnim { -p| -P } [ -a 属性 ].. [ -Z ] 操作に必要な属性を表示する Lsnim T タイプ -Q (Q) 操作 カスタマイズされたすべての NIM オブジェクトの情報を表示する Lsnim [ 「-c」 クラス | -s サブクラス | T タイプ ] [ - | [ - ] | -O (O) ] [ -Z ] または lsnim [ -a 属性 ].. [ -Z ] 特定の NIM オブジェクトの情報を表示する lsnim [ -l | -O | -a 属性 ..] [ -Z] ObjectName または lsnim [ -q 操作 ] ObjectName 特定の NIM マシンに使用可能なリソースの情報を表示する lsnim -L [ -s サブクラス | -t タイプ ] オブジェクト名 NIM グループの情報を表示する lsnim -g | -m [ -a 属性 | -c クラス | -L | -l | -s サブクラス | -t タイプ ] GroupObjectName

オプション
フラグ
項目 | 説明
-a 属性 | 指定した属性名に基づいて、表示される情報にフィルターをかけます。 使用可能な属性を以下に示します。 操作 サブクラス (subclass) タイプ クラス
-c クラス | NIM オブジェクト・クラスを指定します。 Objectname パラメーターを指定しないでこのフラグを使用すると、 そのクラスのオブジェクトの情報だけが表示されるように、情報にフィルターがかけられます。
-g | 個別のメンバーの状態情報を持つグループ・オブジェクトの詳細リストを表示します。
-l | 詳細情報を表示します。
-L | クライアント・マシンによりアクセスされるリソースの情報を表示します。
-m | 指定されたフラグ以外のフラグは、グループ・メンバーに適用されます。
-o | NIM 環境の SMIT インターフェースによって使用されます。
-O | NIM でサポートされる操作をリストします。
-p | デフォルトの値を使用して事前定義情報を表示します。
-P | 事前定義されているデータのヘルプ情報を表示します。
-q 操作 | 指定された操作に必要な属性をリストします。
-S | NIM サブクラスのリストを表示します。
-s サブクラス | NIM サブクラスを指定します。 ObjectName パラメーターを指定しないでこのフラグを使用すると、そのサブクラスのオブジェクトの情報だけが表示されるように、 情報にフィルターがかけられます。
-t タイプ | NIM オブジェクト型を指定します。 Objectname パラメーターを指定しないでこのフラグを使用すると、 そのタイプのオブジェクトの情報だけが表示されるように、 情報にフィルターがかけられます。
-Z | 情報をコロンで区切ったフォーマットで表示します。

例
NIM オブジェクト・クラスのリストを表示するには、次のように入力します。
lsnim -p
NIM サブクラスのリストを表示するには、次のように入力します。
lsnim -p -S
システムの NIM オブジェクト・タイプのリストを表示するには、
machines
オブジェクト・クラス、入力:
lsnim -p -c machines
NIM オブジェクト・タイプに関するヘルプ情報を表示するには、
machines
オブジェクト・クラス、入力:
lsnim -P -c machines
名前付き NIM 属性に関する詳細情報を表示するには、次のように入力します。
lpp_source
および
Rstate
次のように入力します。
lsnim -p -a lpp_source -a Rstate
以下に対して実行できる操作を表示します。
paging
オブジェクト・タイプ、入力:
lsnim -p -t paging -O
実行に必要な情報を表示するには、以下のようにします。
bos_inst
オブジェクトに対する操作
standalone
オブジェクト・タイプ、入力:
lsnim -t standalone -q bos_inst
カスタマイズされたすべてのオブジェクトに関する情報を表示するには、以下のようにします。
diskless
オブジェクト・タイプ、入力:
lsnim -t diskless
カスタマイズされたオブジェクトをすべて表示するには、以下のようにします。
networks
オブジェクト・クラス、入力:
lsnim -c networks
次の名前の NIM オブジェクトに関する詳細情報を表示するには、次のようにします。
altoid
次のように入力します。
lsnim -l altoid
名前付きオブジェクト間の関係を表示するには、以下のようにします。
altoid
およびすべての NIM リソースを入力します。
lsnim -c resources altoid
適用できる操作のリストを表示するには、以下のようにします。
altoid
次のように入力します。
lsnim -O altoid
使用可能なリソースのリストを表示するには、以下のようにします。
altoid
次のように入力します。
lsnim -L altoid
マシン・グループのメンバーを表示するには
MacGrp1
状態およびグループ除外状況の場合は、次のように入力します。
lsnim -g MacGrp1
リソース・グループのメンバーに関する基本情報を表示する

ResGrp1
次のように入力します。
lsnim -m ResGrp1
マシン・グループのメンバーの詳細リストを表示する
MacGrp1
非表示の NIM 内部情報があれば、次のように入力します。
lsnim -m -Fl MacGrp1
マシン・グループのすべてのメンバーを表示する
MacGrp1
スポットが割り振られている場合は、次のように入力します。
lsnim -ma spot MacGrp1
