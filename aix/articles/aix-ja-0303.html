目的
Reliable Scalable Cluster Technology (RSCT) コンポーネントについての構成、ログ、およびトレース情報を収集します。

説明
ctsnap
コマンドは、 AIX® または PowerHA®とともにインストールされた RSCT コンポーネントに関する構成情報、ログ情報、およびトレース情報を収集します。 このコマンドは、コマンドが実行されているローカル・ノードのデータのみを収集します。 インストールされるプログラムに応じて、以下のコンポーネントについての情報が含まれます。

構文
CT スナップ [ -a 値 ] [ 「-c」 クラスター名のパターン ] [ -C クラスター ID パターン (cluster_ID_pattern) ] [ -d 年 出力ディレクトリー ] [ -D daemon_name_pattern ] [ -k (K) stackdump_default ] [ N ノード名パターン ] [ -N (N) ノード ID パターン ] [ P- 日 | { 「-f」 開始日 T 終了日 } ] [ -s スプール・ディレクトリー ] [ -S (S) サイズ ] [ -x (X) runrpttr ] [ -h ] [ -z ]

オプション
フラグ
-a
Linux® オペレーティング・システム上の High Availability Cluster Multi-Processing (HACMP) クラスターにのみ関連する情報を収集します。
--c
クラスタ名パターン
トレース収集を特定のクラスター名に限定する選択パターンを指定します。 パターンは、Perl 言語の正規表現として解釈されます。
--C
cluster_ID_pattern
トレース収集を特定のクラスター ID に限定する選択パターンを指定します。 パターンは、Perl 言語の正規表現として解釈されます。
--d
output_dir
出力ディレクトリーを指定します。 デフォルトのディレクトリーは
/tmp/ctsupt
です。
--D
デーモン名パターン
トレース収集を特定のデーモンに限定する選択パターンを指定します。 パターンは、Perl 言語の正規表現として解釈されます。
--f
from_date
情報を収集するいつからの日付を指定します。
from_date
パラメーターのフォーマットは次のとおりです。
yyyy-mm-dd[.hh[:mm[:ss]]]
注:
-f
は
-t
フラグと一緒に使用してください。
-k stackdump_default
これらの RSCT サブシステムのスタック・ダンプを生成します：
cthags
、
cthats
、
ctrmc
、
IBM.AuditRM
、
IBM.CIMRM
、
IBM.ConfigRM
、
IBM.ERRM
、
IBM.FSRM
、
IBM.GblResRM
、
IBM.LPRM
、
IBM.MicroSensorRM
、
IBM.RecoveryRM
、
IBM.SensorRM
、および
IBM.StorageRM
。
--n
ノード名パターン
トレース収集を特定のノード名に限定する選択パターンを指定します。 パターンは、Perl 言語の正規表現として解釈されます。
--N
node_ID_pattern
トレース収集を特定のノード ID に限定する選択パターンを指定します。 パターンは、Perl 言語の正規表現として解釈されます。
-
日
収集するスプール済みトレース情報の価値が、何日前まであるかを指定します。
--s
spool_dir
トレース・ファイルを指定したスプール・ディレクトリーに取り込みます。
--S
サイズ
収集するすべてのトレース・ファイルの最大累積サイズ (メガバイト) を指定します。
--t
to_date

情報を収集するいつまでの日付を指定します。
to_date
パラメーターのフォーマットは次のとおりです。
yyyy-mm-dd[.hh[:mm[:ss]]]
注:
-t
は
-f
フラグと一緒に使用してください。
-x runrpttr
すべての RSCT リソース・マネージャーのトレース・ファイルの内容をフォーマットします。
このフラグを使用すると、
ctsnap
出力ファイルのサイズが増加し、出力ディレクトリーを含むファイルシステムのサイズを増加しなければならない場合があります。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。
-z
Cluster Aware AIX (CAA) 環境であっても、
snap caa
情報を収集しないようにします。

例
RSCT サポート情報を集めるには、次のように入力します。
ctsnap
RSCT サポート情報を収集し、それを
/tmp/mydir
ディレクトリーに入れるには、次のように入力します。
ctsnap -d /tmp/mydir
/opt/traces
ディレクトリーのすべてのトレース・ファイルを取り込むには、次のように入力します。
ctsnap -s /opt/traces
/opt/traces
ディレクトリーのすべてのトレース・ファイルを構成リソース・マネージャー・デーモンに関して取り込むには、次のように入力します。
ctsnap -s /opt/traces -D '.*ConfigRM.*'
/opt/traces
ディレクトリーのすべてのトレース・ファイルを日付範囲 (
08-28-2008
から
08-29-2008
まで) について取り込むには、次のように入力します。
ctsnap -s /opt/traces -f 08-28-2008 -t 08-29-2008
/opt/traces
ディレクトリーのすべてのトレース・ファイルを前 4 日間について取り込むには、次のように入力します。
ctsnap -s /opt/traces -p 4
/opt/traces
ディレクトリーのすべてのトレース・ファイルをトレース情報の最新
50
MB について取り込むには、次のように入力します。
ctsnap -s /opt/traces -S 50
