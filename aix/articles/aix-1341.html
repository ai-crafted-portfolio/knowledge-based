目的

Subserver Type オブジェクト・クラスからサブサーバー定義を除去します。

構文

rmserver -t タイプ

説明

rmserver コマンドは、Subserver Type オブジェクト・クラスから既存のサブサーバー定義を除去します。

フラグ

項目
説明
-t タイプ 除去する既存のサブサーバーを特定に識別するサブサーバー名を指定します。 サブサーバー・タイプ・オブジェクト・クラスで Type 名が認識されない場合、 rmserver コマンドは失敗します。

セキュリティー

監査イベント: サブシステムの監査が正しく構成されていて使用可能にされると、 rmserver コマンドを実行するたびに次のような監査レコード (イベント) が生成されます。

イベント
情報
SRC_Delserver 削除されたサブサーバー定義の名前を監査ログにリストします。
