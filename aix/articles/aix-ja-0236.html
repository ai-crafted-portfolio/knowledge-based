目的
ある権限に対する現行ユーザー・セッションを検査します。

説明
ckauth
コマンドは、
ckauth
コマンドを呼び出すプロセスが、
AuthName
パラメーターに指定された権限を持っているかどうか判別します。 このコマンドは、権限の検査を必要とするシェル・スクリプトで使用されます。
ckauth
では、コンマで区切ったリストを使用して、単一の権限または複数の権限を指定することができます。 呼び出しプロセスがリストにある権限のいずれかを持っていれば、
ckauth
コマンドは 0 を戻します。
-A
オプションを指定した場合、
呼び出しプロセスがリストにある権限をすべて持っているときに、
ckauth
コマンドは 0 を戻します。 失敗すると、ゼロ以外の値が戻されます。

構文
ckauth [ -A ] { AuthName [, AuthName ] ...}

オプション
フラグ
項目 | 説明
-A | 呼び出しプロセスがリストにある権限をすべて持っているか検査します。

例
既存のユーザー・セッションに以下のものがあるかどうかを判別します。
aix.fs.manage
許可については、以下のコマンドを使用します。
$ ckauth aix.fs.manage
$ echo $?
0
既存のユーザー・セッションに以下の両方があるかどうかを判別します。
aix.security.user
および
aix.security.group
許可については、以下のコマンドを使用します。
$ ckauth -A aix.security.user,aix.security.group
$ echo $?
0
