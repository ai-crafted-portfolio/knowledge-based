目的
ディレクトリーを NFS クライアントにエクスポートします。

説明
mknfsexp
コマンドは、指定されたフラグとパラメーターを使用し、
/etc/exports
ファイルに正しい構文の行を構成します。 このコマンドが
-B
フラグ付きで呼び出された場合、
/etc/exports
ファイルにエントリーが追加され、指定したディレクトリーをエクスポートするために
exportfs
コマンドが呼び出されます。 一方、
-I
フラグを指定すると、
exports
ファイルにエントリーが追加されますが、ディレクトリーがエクスポートされません。
-N
フラグを指定すると、
exports
ファイルにエントリーが追加されませんが、ディレクトリーがエクスポートされます。

構文
/usr/sbin/mknfsexp -d ディレクトリ [ -e パス名 ] [ -f エクスポート_ファイル ] [ -t [ { rw | ロー | 取り除く } { rm -h ホスト名 [ , ホスト名 ... ] } ] ] [ -a UID ] [ -r HostName [ , HostName ... ] ] [ -c HostName [ , HostName ... ] ] [ -s | -n ] [ -I | -B | -N ] [ -P | -p ] [ -D {yes | no} ] [ -v ] [ -x | -X ] [ -S 味 [ 風味 ] ] [ -G rootpath@host [ + ホスト ][ : rootpath@host [ + ホスト ]] ] [ -g rootpath@host [ + ホスト ][ : rootpath@host [ + ホスト ]] ] [ -o ご注文 ]

例
読み取り専用許可を持つディレクトリーをエクスポートするには、次のように入力します。
mknfsexp -d /usr -t ro
この例では、
mknfsexp
コマンドは、
/usr
読み取り専用権限を持つディレクトリー。
読み取り指定アクセス権とセキュア・プロトコルを持つディレクトリーを特定のホストにエクスポートするには、次のように入力します。
mknfsexp -d /home/guest -t rm -h bighost,littlehost -s
この例では、
mknfsexp
コマンドは、
/home/guest
よりセキュアなプロトコルを使用する、読み取り専用許可を持つディレクトリー。
読み取り/書き込み許可を持つディレクトリーを特定のネットグループおよび特定のホストにエクスポートし、次回のシステム再始動時にエクスポートを有効にするには、次のように入力します。
mknfsexp -d /usr -t rw -c host1,host3,grp3 -I
上記の例では、
mknfsexp
コマンドは、
/usr
ディレクトリーに対する読み取りおよび書き込み権限を付与します
host1
,
host2
および
grp3
.
-I
フラグを指定すると、次回のシステム再始動時にこの変更が有効になります。
読み取り専用許可を持つディレクトリーを
/etc/exports
以外のエクスポート・ファイルにエクスポートするには、次のように入力します。
mknfsexp -d /usr -t ro -f /etc/exports.other
上記の例では、
mknfsexp
コマンドは、
/usr
読み取り専用権限を持つディレクトリー
/etc/exports.other
を適用します。

のプロトコルを使用するクライアントにのみアクセスを許可するために
/common/documents
ディレクトリーをエクスポートするには、次のように入力します。
mknfsexp -d /common/documents -v 4
/common/documents
ディレクトリーをエクスポートして、krb5
アクセスを使用するクライアントの
client1
および
client2
にアクセスを許可するには、
次のように入力します。
mknfsexp -d /common/documents -S krb5 -r client1,client2
/common/documents

ディレクトリーをエクスポートするには、次のように指定されたホストの完全な分散を使用します。
s1
および
s2
参照として指定されている場合は、以下のコマンドを入力します。
mknfsexp -d /common/documents -v 4 -G /common/documents@s1:/common/
documents@s2 -o full
/common/documents
ディレクトリーを、指定されたホストで部分的に分散してエクスポートするには、以下のようにします。
s1
,
s2
および
s3
レプリカとして指定されている場合は、以下のコマンドを入力します。
mknfsexp -d /common/documents -v 4 -g /common/documents@s1:/common/
documents@s2:/common/documents@s3 -o partial

/common/documents

/exports1/cool/mike

mknfsexp -d /common/documents -e /exports1/cool/mike -S sys -v 4
