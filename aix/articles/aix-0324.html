目的

クラスター内のサブシステムを制御します。

構文

cthactrl -i <init_opt> -s | -k | -b | -r | -d | -z | -h

説明

cthactrl コマンドは、クラスター・サブシステム情報を設定および制御し、トポロジー・サービスおよびグループ・サービスを管理します。

フラグ

--i <init_opt
グループ・サービスおよびトポロジー・サービス・サブシステムを初期化します。ここで、<init_opt> は以下のように指定できます。
--c <クラスタ名
クラスター名を指定します。
--n <ノデナム
ノード番号を指定します。
--e <環境
クラスター・アクセス・モジュールが入っているサブディレクトリーを指定します。
[[-p <ポート仕様］
グループ・サービスおよびトポロジー・サービスの UDP ポート番号を指定します。
次に例を示します。
cthactrl -i -c filesys -n 1 -e filesys -p "cthats=12347,cthags=12348"
-s
グループ・サービス・サブシステムおよびトポロジー・サービス・サブシステムを始動します。
-k
グループ・サービス・サブシステムおよびトポロジー・サービス・サブシステムを停止します。
-b
グループ・サービスおよびトポロジー・サービス・サブシステムの構成を再作成します (例えば、machines.lst)。
-r
グループ・サービス・サブシステムおよびトポロジー・サービス・サブシステムをリフレッシュします。
-d
グループ・サービス・サブシステムおよびトポロジー・サービス・サブシステムを削除します。
-z
グループ・サービスおよびトポロジー・サービス・サブシステムをアンインストールします。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。

セキュリティー

このコマンドを実行するには、 root 権限が必要です。

終了状況

0
正常終了。
ゼロ以外
障害が発生しました。

制約事項

このコマンドは、 cthags および cthats サブシステムにのみ適用されます。

標準出力

-h フラグを指定すると、このコマンドの使用状況ステートメントが標準出力に書き込まれます。

例

  1. ローカル・ノードを filesys1 のクラスターの一部として初期化し、 12347 を cthags の UDP ポート番号として指定し、 12348 を cthagsの UDP ポート番号として指定するには、次のように入力します。
    cthactrl -i -c filesys1 -n 1 -p "cthats=12347,cthags=12348" -e filesys1
  2. グループ・サービスおよびトポロジー・サービス・サブシステム (cthags および cthats) を開始するには、次のように入力します。
    cthactrl -s
  3. グループ・サービスおよびトポロジー・サービス・サブシステム (cthags および cthats) を停止するには、次のように入力します。
    cthactrl -k

場所

/opt/rsct/bin/cthactrl
