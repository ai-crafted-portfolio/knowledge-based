目的

起動時に IPv6 のネットワークインターフェースを自動的に設定します。

構文

autoconf6 [ -a ] [ -A ] [ -i ] [ -s ] [ -6 ] [ -M ] [ -O ] [ -R ] [ -c ] [ -v ] [ -S ] [ -m main_interface ] [ interface_name ... ]

説明

起動時にこの autoconf6 コマンドを使用することで、ND対応のネットワークインターフェースにリンクローカルアドレスを割り当てることができます。 この autoconf6 コマンドは、ループバックインターフェースを初期化し、必要に応じて自動トンネルを設定し、必要なルートを追加します。 このコマンドを使用 autoconf6 すれば、いつでもリンクローカルアドレスを設定し、新しく設定されたイーサネット風のインターフェースで自動トンネリングを有効にすることができます。

フラグ

表 1. フラグ
項目
説明
-a Internet Protocol バージョン 4 ( IPv4 ) の設定で構成された、使用可能なインターフェースを設定および有効化します。
-A 使用可能なインターフェースを設定し、有効にします。
-i 引数として指定されたインターフェースを設定し、有効にします。 および -i フラグを -a 指定しない場合、すでにアップ状態にあるインターフェースのみが設定されます。
-s Simple Internet Transition (SIT) インターフェースと、 IPv4-compatible プログラムをインストールします。 このフラグを -s 指定しない場合、SITインターフェースは、すでにSITインターフェースがアップ状態にある場合にのみ設定されます。
-6  SIT インターフェースおよび IPv4 互換の相互運用機能 (interoperability) は、インストールも変更もされません。
-M デバッグモードでは、既存の IPv6 マルチキャストルートに変更を加えないでください。
-O デバッグモードでは、ループバックインターフェースを設定しないでください。
-R デバッグモードでは、デフォルトの IPv6 ルートをインストールしないでください。
-c 以前の互換性フラグは、不正なリンクローカルアドレスを持つユーザーを対象としていました。
-v 詳細な出力を生成し、プログラムが実行する各操作や発生したエラーに関する詳細情報を表示するようにします。
-S

RFC 7217 に基づく安定したプライバシーアドレスをリンクローカルインターフェースに設定し、各インターフェースが安定かつランダム化された IPv6 リンクローカルアドレスを確実に取得できるようにします。 このアドレスは、ハードウェア由来の識別子が漏洩するのを防ぎ、システムの再起動後もアドレスの安定性を維持するRFC 7217アルゴリズムを用いて生成されます。
-m main_interface 主インターフェースを指定します。 main_if6また、この no コマンドに引数「」を指定して使用することもできます。
interface_name 設定が必要なインターフェースの名前を指定します。 flag を interface_name とともに指定 -i することができます。 interface_name を指定せずにこのフラグを -i 指定した場合、インターフェースは設定されません。 flag を -i 指定せずに interface_name を指定すると、プログラムは使用方法のメッセージを表示します。 interface_name として を ibX 指定すると、 InfiniBand ポートの EUI-64 に基づいて、その ibX インターフェースに IPv6 アドレスが設定されます。 コマンド autoconf6 でインターフェース ibX を使用するには、その ibX インターフェースに IPv4 アドレスが事前に設定されている必要があります。
