目的
Network Installation Management (NIM)クライアントが、NIMサーバーのNIM HTTP サービスに HTTP リソース要求を送信できるようにする。

説明
NIM クライアントは、
nimhttp
コマンドを使用して、ディレクトリー内の NIM サーバーからリソースをダウンロードすることができます。 このディレクトリは、NIM HTTP サービスが有効な場合、
httpd.conf
ファイルの
document_root
オプションで指定される。
NIM HTTP サービスを NIM サーバーに設定する手順の詳細については、
HTTP プロトコルを介して AIX アップデートと新しいパッケージをインストールするための NIM の使用に関する
トピックを参照してください。

構文
nimhttp [ -i <ip_address> ] [ -p <port> ] [ -f <filename> ] [ -s ] [ -o options ] [ -v ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-f filename または -f foldername | NIM サーバーから取り出すファイル名またはフォルダー名を指定します。 以下の 2 つの基準が満たされている場合、サーバーは指定されたフォルダーのディレクトリー・リストを提供します。 NIM サーバーから取り出すファイル名の代わりに、フォルダー名が指定されています。 NIM サーバーの httpd.conf ファイルの enable_directory_listing オプションが yes に設定されています。
-i IP アドレス | HTTP リソース要求の送信に使用しなければならない宛先NIMサーバーのIPアドレスを指定します。
-o オプション | リソースの取り出しに使用するオプションを指定します。 以下の値は、 -o フラグの有効なオプションです。 dest = 宛先値 NIM サーバーからリソースをダウンロードする宛先ディレクトリーのパスを指定します。 cert =cert_value 証明書と秘密鍵を含む、プライバシー強化メール（ PEM ）形式のファイルのパスを指定します。 ca_cert =ca_cert_value デジタル証明書の署名に使用される認証局のファイル・パスを指定します。
-p port | 宛先 NIM サーバーのポートを指定します。
-s | この nimhttp コマンドでは、認証のためにSecure Sockets Layer（ SSL ）によるハンドシェイクを使用する必要があることを指定します。
-v | 詳細出力を有効にします。

例
NIM サーバーからクライアントにファイルを取得するには、次のコマンドを入力します。
# nimhttp -f /export/nim/scripts/sample.txt -o dest=/tmp
# cat /tmp/export/nim/scripts/sample.txt
This is a sample file
#
NIM サーバーからディレクトリー・リストを入手するには、次のコマンドを入力します。
# nimhttp -f /export/nim/scripts/ -o dest=/tmp
# cat /tmp/export/nim/scripts/.content
FILE: sample.txt 0:0 00100644 22
#
NIM サーバーの指定された宛先 IP アドレスおよびポートからファイルを取得するには、次のコマンドを入力します。
# nimhttp -i octopus -p 4901 -f /export/nim/scripts/sample.txt -o dest=/tmp
# cat /tmp/export/nim/scripts/sample.txt
This is a sample file
#
SSL ハンドシェイクを使用してNIMサーバーからファイルを取得するには、次のコマンドを入力します：
# nimhttp -f /export/nim/scripts/sample.txt -o dest=/tmp -s
# cat /tmp/export/nim/scripts/sample.txt
This is a sample file
#
SSL ハンドシェイクを使用してNIMサーバーからファイルを取得し、特定の証明書ファイルを使用してそのファイルを認証するには、次のコマンドを入力します
# nimhttp -f /export/nim/scripts/sample.txt -o dest=/tmp -o ca_cert=/ssl_nimsh/certs/octopus.pem -s
# cat /tmp/export/nim/scripts/sample.txt
This is a sample file
#
