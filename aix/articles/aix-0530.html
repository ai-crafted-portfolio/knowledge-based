目的

ディスケットまたは読み取り/書き込み光メディア・ディスクをフォーマットします。

構文

format [ -d Device ] [ -f ] [ -l ]

説明

重要: ディスケットまたは読み取り/書き込み光ディスクをフォーマットすると、そのディスク上の既存のデータはすべて破棄されます。

format コマンドは、Device パラメーターで指定されたディスケット・ドライブ内のディスケットをフォーマットします。 format コマンドは、以下のいずれかの装置タイプを判別します。

  • 5.25 インチの低密度ディスケット (360 KB)。それぞれに 9 つのセクターがある 40x2 トラックが入っています。
  • 5.25 インチ大容量ディスケット (1.2 MB)。それぞれに 15 セクターずつの 80x2 トラックが入っています。
  • 3.5 それぞれが 9 セクターの 80x2 トラックを含む低密度インチ・ディスケット (720 KB)
  • 3.5 インチ大容量ディスケット (1.44 MB)。それぞれに 18 セクターの 80x2 トラックが入っています。
  • 3.5 インチ大容量ディスケット (2.88 MB)。それぞれに 36 セクターの 80x2 トラックが入っています。

セクターのサイズはどのディスケット・タイプの場合も 512 バイトです。

format コマンドは、 Device パラメーターで異なる密度が指定されていない限り、ディスケット・ドライブでサポートされる最大容量のディスケットをフォーマットします。

format コマンドは、ドライブが障害リスト・ヘッダーのフォーマット・オプション有効 (FOV) ビットを 0 に設定することをサポートしている場合に、読み取り/書き込み光ディスクをフォーマットします。 読み取り/書き込み光ディスクをフォーマットするには、読み取り/書き込み光ディスク・ドライブの名前 ( /dev/romd0など) を -d フラグの後に使用します。

format コマンドは、ディスケットまたは読み取り/書き込み光ディスクをフォーマットする前に、確認を求めるプロンプトを表示します。 これにより、ユーザーは操作を正常に終了することができます。

フラグ

表 1. フラグ
項目
説明
-d Device ディスケットの形式設定に使用する装置を指定します。 デバイス名の末尾に文字 h が付いていると、ドライブはディスケットを高密度用にフォーマットします。 デバイス名の末尾に文字 l が付いていると、ドライブはディスケットを低密度用にフォーマットします。 有効な装置タイプについては、 fd スペシャル・ファイルを参照してください。 このフラグは format コマンドと一緒に使用しなければなりません。
重要: ディスケット・ドライブが、ディスケットが製造された最大容量よりも高い容量をサポートする場合は、 format コマンドの Device パラメーター (-d Device フラグ) でディスケットの容量を明示的に指定する必要があります。 例えば、4 MB のディスケット・ドライブ上の 1 MB のディスケットをフォーマットするには、 -d フラグに次のようにディスケット容量を指定します。
-d /dev/fd0.9 for a 1MB diskette

これを行わないと、読み取りおよび書き込みエラーが発生する可能性があります。
-f 不良トラックの検査をしないでディスケットをフォーマットします。この方法をとると、短時間でフォーマットできます。 このフラグはディスケットにのみ適用されます。読み取り/書き込み光ディスクには適用されません。 format コマンドと一緒に使用する必要があります。
-l (小文字の L) 360 KB ディスケットを 5.25 インチ、 1.2 MB のディスケット・ドライブにフォーマットします。 3.5-inch 1.4 MB ディスケット・ドライブの 720 KB ディスケットをフォーマットします。 このフラグはディスケットにのみ適用されます。読み取り/書き込み光ディスクには適用されません。 format コマンドと一緒に使用する必要があります。
重要: 360 KB ディスケット・ドライブは、 1.2 MB ドライブでフォーマットされた 360 KB ディスケットを読み取ることができません。

パラメーター

表 2. パラメーター
項目
説明
device フォーマットしたいディスケットが入っているデバイスを指定します。 デフォルトは、デバイス /dev/rfd0 (ドライブ 0) です。

例

  1. /dev/rfd0 デバイスでディスケットをフォーマットするには、次のように入力します。
    format   -d   /dev/rfd0
  2. 不良トラックを検査せずにディスケットをフォーマットするには、次のように入力します。
    format   -f
  3. /dev/rfd1 装置の 5.25 インチ、 1.2 MB のディスケット・ドライブで 360 KB ディスケットをフォーマットするには、次のように入力します。
    format   -l   -d   /dev/rfd1
  4. 3.5 インチの低密度 (720 KB) ディスケットをフォーマットするには、次のように入力します。
    format -d /dev/fd0.9
  5. 3.5 インチの大容量 (1.44 MB) ディスケットをフォーマットするには、次のように入力します。
    format -d /dev/fd0.18
  6. /dev/romd0 装置で読み取り/書き込み光ディスクをフォーマットするには、次のように入力します。
    format -d /dev/romd0
