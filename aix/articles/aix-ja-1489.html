目的
定義済みのリソースを開始します (すなわち、定義済みのリソースをオンラインにします)。

説明
startrsrc
コマンドは、Resource Monitoring and Control (RMC) サブシステムが 1 つ以上のリソースをオンラインにすることを要求します。 要求は該当するリソース・マネージャーによって実行されます。
1 つ以上のリソースを開始するには、
-s
フラグを使用して、指定した選択文字列に一致するすべてのリソースをオンラインにします。
selection_string
に複数のノード名を指定する代わりに、
-N
node_file
フラグを使用して、ノード名がファイル内にあることを示すことができます。 標準入力からノード名を読み取るには、
-N
"-"
を使用します。
特定のリソースを開始するには、
-r
フラグを使用して、その特定のリソースを表すリソース・ハンドルを指定します。
指定されたリソース・クラスが追加のコマンド引数を受け入れるかどうかを判別するには、
-l
フラグを使用します。
システムにクラスター・システム・マネージメント (CSM) がインストールされている場合は、CSM 定義のノード・グループをノード名の値として使用して、複数のノードを参照できます。 CSM ノード・グループの処理および CSM
nodegrp
コマンドの使用については、「
CSM: Administration Guide
」および「
CSM: Command and Technical Reference
」を参照してください。
このコマンドが正常に終了しても、リソースがオンラインであることは保証されません。リソース・マネージャーがこのリソースをオンラインにするための要求の受信に成功しただけです。 リソースの動的属性
OpState
をモニターして、リソースがいつオンラインになるかを判別します。 リソースが実際にいつオンラインになるかを知るために、
OpState
属性を指定して、リソースのイベントを登録します。 あるいは、リソースがオンラインである (
OpState
の値が
1
である) ことがわかるまで、
lsrsrc
コマンドを断続的に実行してください。 次に例を示します。
lsrsrc -s 'Name == "/filesys1"' -t IBM.FileSystem Name OpState
