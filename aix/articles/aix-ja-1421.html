目的
システムの実行モードを設定します。

説明
setrunmode
コマンドは、システムの実行モードを設定します。 実行モードは、CONFIGURATION モードか OPERATIONAL モードのいずれかです。

構文
setrunmode { -c | -o }

オプション
フラグ
項目 | 説明
-c | CONFIGURATION モードを指定します。
-o | OPERATIONAL モードを指定します。

例
システムを CONFIGURATION モードに設定するには、以下のコマンドを入力します。
setrunmode –c
システムを OPERATIONAL モードに設定するには、以下のコマンドを入力します。
setrunmode –o
