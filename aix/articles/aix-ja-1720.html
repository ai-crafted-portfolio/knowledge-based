目的
仮想メモリーの統計情報を報告します。

説明
vmstat
コマンドは、カーネル・スレッド、仮想メモリー、ディスク、ハイパーバイザー・ページ、トラップ、およびプロセッサー・アクティビティの統計情報を報告します。
vmstat
コマンドによって生成されるレポートは、システム負荷活動のバランスをとるために使用される。 これらのシステム全体の統計は、値が全プロセッサのパーセンテージで表される場合は平均値として計算され、それ以外の場合は合計値として計算される。
vmstat

サポートされているすべてのページ・サイズについて、ページごとの VMM 統計情報の内訳のみを表示するには、次のコマンドを入力します。
vmstat -P ALL
または、
次のコマンドを入力します。
vmstat -P all
ブート後にすべての
ワークロードパーティションの
統計のサマリーを表示するには、以下のコマンドを入力します：
vmstat -@ ALL
すべての
ワークロード・パーティションで
利用可能なすべてのVMM統計を表示するには、次のコマンドを入力します：
vmstat -vs -@ ALL
ワークロード・パーティション
から
WPAR
とシステム全体の VMM 統計情報の両方を表示するには、次のコマンドを入力します。
vmstat -@

プロセッサー値を 10 倍してその結果を表示するには、次のコマンドを入力します。
vmstat -S 1
ハイパーバイザーのページに関する統計情報を表示するには、次のコマンドを入力します。
vmstat -h
ハイパーバイザーに貸し出されているページについての情報を表示するには、次のコマンドを入力します。
vmstat -vh
メモリー圧縮統計情報 (Active Memory Expansion が有効になっている LPAR 内) を表示するには、次のコマンドを入力します。
vmstat -c
(Active Memory Expansion が有効になっている LPAR 内の) 各ページ・サイズに固有のメモリー圧縮統計を表示するには、次のコマンドを入力します。
vmstat -c -P ALL
(Active Memory Expansion が有効になっている LPAR で)
-s
フラグで表示される統計情報にメモリ圧縮情報を追加するには、次のコマンドを入力します：
vmstat -s -c
(Active Memory Expansion が有効になっている LPAR で)
-v
フラグで表示される統計情報にメモリ圧縮情報を追加するには、次のコマンドを入力します：
vmstat -v -c
ソフトページのプロモーション統計を表示するには、以下のコマンドを入力する：
vmstat -L 1
