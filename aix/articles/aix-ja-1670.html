目的
updatevsdtab
- 仮想共有ディスク・サブシステム属性を変更します。

説明
このコマンドを使用して、仮想共有ディスク・サイズを更新します。
updatevsdtab
コマンドを使用して仮想共用ディスク・サイズを変更した場合、その変更は、仮想共用ディスクが構成解除されて再構成されるまで有効になりません。
-f
フラグが指定された場合、
関連した仮想共有ディスクは、作動しており、
当初この仮想共有ディスクが構成されていたすべてのノード上に再構成されます。
このコマンドは、System Management Interface Tool (SMIT) を使用して実行できます。 SMIT を使用するには、以下のように入力します。
smit vsd_mgmt
そして、「Set/Show virtual shared disk Device Driver Operational Parameters (仮想共有ディスク・デバイス・ドライバー稼働パラメーターの設定/表示)」
オプションまたは「Update virtual shared disk Options (仮想共有ディスク・オプションの更新)」オプションを選択します。

構文
updatevsdtab {-v vsd_names ｜-a}。 {[ -s ]}[- f ]

オプション
フラグ
-
vsd_names
更新される仮想共有ディスク名のリストを指定します。
-a
システムまたはシステム区画のすべてのノード上で、
オプションが変更されることを指定します。
-s
関連した論理ボリューム・サイズの変更後に、
仮想共有ディスク・サイズを更新します。
-f
仮想共有ディスクが構成されている現行システム区画内のすべてのノード上で、
仮想共有ディスクを再構成することにより変更を強制実行します。

例
USER1n3 という名前の仮想共有ディスクのサイズをリセットするには、次のように入力します。
updatevsdtab -v USER1n3 -s
