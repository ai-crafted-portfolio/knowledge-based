目的
X サーバーの現行出力デバイスとビューポート・サイズを変更します。
“
注:
このコマンドは、X サーバーの実行中にのみ使用できます。
”

説明
chvmode
コマンドは、X サーバーの現行の出力デバイスとビューポート・サイズを変更します。
ビューポート・サイズの仕様は、CRT ディスプレイとその解像度にパンのオプションがある場合にのみ使用できます。
また、System Management Interface Tool (SMIT) を使用して、このコマンドを実行することもできます。

構文
CHVMODE [{ + | - } L ] [{ + | - } C ] [ -vsize (V サイズ) 幅 X 高さ [@ VSync]

オプション
フラグ
項目 | 説明
+ / -c | CRT 出力を使用可能または使用不可にします。
+ / -l | LCD 出力を使用可能または使用不可にします。
-vsize 幅 x 高さ [ @VSync ] | CRT ディスプレイのビューポート・サイズと、垂直同期 (Hz 単位のリフレッシュ・レート) を指定します。 @ VSync が指定されない場合は、現行の垂直同期周波数が使用されます。

例
LCD パネルを使用不可にして CRT 表示を使用可能にするには、次のように入力します。
chvmode -l +c
現在の CRT ビューポートを 1024x768に変更するには、次のように入力します。
chvmode -vsize 1024x768
75Hzの高いリフレッシュ・レートで VGA モードを指定するには、以下のように入力します。
chvmode -vsize 640x480@75
