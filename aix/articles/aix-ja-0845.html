目的
lvupdateRegKE
コマンドは、
AIXLive Update
操作中にサロゲート論理パーティション（LPAR）にカーネル拡張をロードするために使用するコマンドを登録するために使用します。

説明
ライブ・アップデート
操作には、更新されたサロゲート LPAR でワークロードの実行を再開する前に、特定のカーネル・エクステンションをロードする機会が含まれています。 このコマンドは、サロゲート区画に始動時にロードされるカーネル・エクステンションのリストを管理します。 このコマンドを使用して、リストにカーネル・エクステンションを追加するほか、カーネル・エクステンションをロードおよび構成することができます。 リストからカーネル・エクステンションを削除したり、カーネル・エクステンションのリストをリストまたは表示したりするためのオプションも用意されています。 このリストは、
/etc/liveupdate/lvup_preload_KE
ファイルに入れられます。 サロゲート LPAR の開始時にロードされるようにするには、カーネル・エクステンションがそのファイルに含まれている必要があり、
ライブ・アップデート
操作の開始時に元の LPAR にロードされている必要があります。
注:
lvupdateRegKE
コマンドで登録するコマンドは、
/
、
/var
、
/usr
、
/opt
、
/tmp
のいずれかのファイル・システムに存在している必要があります。 また、このコマンドによってロードされるカーネル・エクステンションは、これらのファイル・システムのいずれかに存在している必要があります。

構文
lvupdateRegKE [ -a kext_path -c command | -r kext_path | -l ]

オプション
フラグ
項目 | 説明
-a kext_path | ライブ・アップデート 操作中にロードされるカーネル・エクステンションのリストにカーネル・エクステンションを追加します。 注: -a フラグが指定されている場合、 -c フラグは必須です。
-c コマンド | カーネル・エクステンションをロードします。 ストリングを二重引用符で囲むことにより、コマンド引数を組み込むことができます。
-l | ライブ・アップデート 操作中にロードされるカーネル・エクステンションのセットと、それらをロードするために指定されたコマンドをリストします。
-r kext_path | リストからカーネル・エクステンションを削除します。

例
ライブ・アップデート
操作中にカーネル・エクステンションをロードするために登録されているすべてのコマンドをリストするには、次のコマンドを入力します。
# lvupdateRegKE -l
ライブ・アップデート
操作中にカーネル・エクステンションをサロゲート LPAR にロードするコマンドを登録するには、次のコマンドを入力します。
# lvupdateRegKE -a /usr/lib/drivers/mykext -c "/opt/myapp/bin/load_kext -x -y"
ライブ・アップデート
操作中にカーネル・エクステンションをロードするために以前に登録されたコマンドを除去するには、次のコマンドを入力します。
# lvupdateRegKE -r /usr/lib/drivers/mykext
