構文
サービス更新管理アシスタント（SUMA）タスクを作成、編集、またはスケジュールするには suma { { [ -x ] [ -w ] } | -s CronSched } [ -a Field=Value ]... [ TaskID ] SUMAのタスクをリストアップする suma -l [ TaskID ]... デフォルトのSUMAタスクを一覧表示または編集するには suma -D [ -a Field=Value ]... SUMAのグローバルコンフィギュレーション設定を一覧表示または編集するには suma -c [ -a Field=Value ]... SUMAタスクのスケジュールを解除するには suma -u TaskID SUMAタスクを削除するには suma -d TaskID

-a (続き) | FilterDir 重複するフィックスがダウンロードされないようにフィルタリングするフィックス・リポジトリー・ディレクトリーの名前を指定します。 このオプションを使用すると、 DLTarget 以外のディレクトリーをフィルターに掛けることができます。 たとえば、このディレクトリにダウンロードすることなく、NIM lpp_source に対してフィルターをかけることができる。 ブランクのままにすると、 DLTarget が使用されます。 FilterDir フィールドの値が /installp/ppc フィックス・リポジトリー・ディレクトリーで終わる場合、 suma コマンドは指定されたディレクトリー内のフィックスをフィルタリングします。 FilterDir フィールドの値の末尾が /installp/ppc フィックス・リポジトリー・ディレクトリーでない場合、 suma コマンドは、 /installp/ppc ディレクトリー内のフィックスを検索してフィルタリングしようとします。 FilterDir 」フィールドで指定された修正リポジトリー・ディレクトリーに「 /installp/ppc 」ディレクトリーがあれば、フィルター処理は成功です。 FilterDir 」フィールドで指定された修正リポジトリ・ディレクトリが「 /installp/ppc 」ディレクトリを持たない場合、フィルター処理は失敗します。 FilterML フィルタリングするTLを指定する。 例えば、6100-03。 指定がない場合は、ローカル・システムの oslevel -r コマンドが返す値が使用される。 MaxDLSize 単一のポリシー実行によってダウンロードされるデータの最大許容量を MB 単位で指定します。 ダウンロードがこのサイズを超えると判断された場合は、ダウンロードは行われません。 値 unlimited または -1 は、ダウンロードするデータ量に上限がないことを示す。 Extend yを 指定すると、 DLTarget が存在するファイルシステムが自動的に拡張される。 nが 指定され、ダウンロードにそれ以上のスペースが必要な場合、ダウンロードは行われない。

-a (続き) | MaxFSSize DLTarget ファイルシステムを拡張できる最大許容サイズを MB 単位で指定する。 ダウンロードがこの限度を超えると判断された場合は、ダウンロードは行われません。 値 unlimited または -1 は、ファイルシステムのサイズにそれ以上の制限がないことを示す。 ファイルシステムのサイズに高い制限が設定されていなければ、物理的なディスク容量がなくなるまでファイルシステムを拡張することができる。 拡張後の DLTarget ファイルシステムの実際のサイズは、要求されたサイズよりわずかに大きいかもしれない。 DLTarget ファイルシステムの拡張処理は、ボリュームグループ（VG）の物理パーティション（PP）サイズを使用します。 必要なファイルシステムのサイズは、ファイルシステムが拡張されるときに、PPの次の倍数に切り上げられる。 suma コマンドは、TL と SP のダウンロードに必要なファイル・システム・メモリを計算するために、TL と SP の合計ダウンロード・サイズに 1.15 のファッジ・ファクターを乗算する。 MaxFSize オプションの値は、以下の数式を使用して計算できます。 Y = X * 1.15 / (1024 * 1024) ここで、 Y は必要なファイルシステムサイズ（MB）、 X はダウンロードされたアップデートの合計バイト数である。 ファイルシステムで利用可能な空きメモリ（MB単位）が Z で示され、 Y の値が Z より大きい場合、TLとSPをダウンロードするためにファイルシステムでより多くのメモリが必要となる。 ファイルシステムに必要な余分なメモリは、 Y と Z の値の差（MB）として計算できる。 ファイルシステムの総サイズが T （単位：MB）で示される場合、ファイルシステムは F の値まで拡張される。 F は以下の式で計算される： F = T + ( Y - Z ) MaxFSize オプションを F の値より大きい値に設定することで、修正プログラムのダウンロードを正常に完了できるサイズまでファイルシステムが拡張されます。
