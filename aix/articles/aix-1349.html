目的

Object Data Manager ( ODM ) から Non-Volatile Memory Express (NVMe) over TCP/IP ターゲットデータを削除します。

構文

rmtcpnvme -l ProtocolDevice [ -g group ] [ -t DiscoveryControllerNQN ] [ -n PortNumber ] [ -i IPaddress ]

説明

注： AIX® 7.3 テクノロジー・レベル4（ TL4 ）から、NVMe over TCP/IPプロトコルはテクノロジー・プレビューとしてのみ利用できるようになりました。

rmtcpnvme コマンドは、NVMe over TCP/IP ターゲットデータを Object Data Manager ( ODM ) から削除します。 統計的に設定されたNVMe over TCP/IPデータは、 ODM に保存されます。 AIX が NVMe over TCP/IP ターゲット・データを検出するには、ディスカバリ・コントローラの NVMe 適 格名（NQN）、IP アドレス、ポート番号など、関連する NVMe over TCP/IP ターゲット情報を指定する必要があります。

フラグ

表 1. フラグ
項目
説明

-gGroup

NVMe over TCP/IPターゲットが属するグループを指定します。 これは、このホストから自動検出されないNVMe over TCP/IPターゲット・データ用です。 NVMe over TCP/IPターゲット・データを検出するには、ディスカバリー・コントローラNQN、IPアドレス、ポート番号など、関連するNVMe over TCP/IPターゲット情報を指定する必要があります。

-i IPAddress

NVMe over TCP/IPターゲットのIPアドレスを指定します。

-l ProtocolDevice

NVMe over TCP/IPプロトコルのデバイス名を指定します。 例えば、 tcpnvmeX。

-n PortNumber

NVMe over TCP/IPターゲットにアクセスするポート番号を指定します。 デフォルトのポート番号は4420である。

-t DiscoveryControllerNQN

NVMe over Fabrics ( NVMe-oF ) Discovery Controller の NQN を指定します。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 rmtcpnvme コマンドは正常に完了した。
>0 rmtcpnvme コマンドがエラーを検出した。

セキュリティー

rmtcpnvme 、rootユーザーのみが実行できる。

例

以下のコマンドを入力して、静的に構成された NVMe over TCP/IP ターゲットを 1 つ削除します：
rmtcpnvme -l tcpnvme0 -g static -t nqn.2014-08.org.nvmexpress.discovery -n 4420 -i 10.32.154.107
以下のコマンドを入力して、デバイスのすべての NVMe over TCP/IP ターゲットを削除します。 tcpnvme0:
rmtcpnvme -l tcpnvme0

場所

ファイルは usr/sbin/rmtcpnvme ディレクトリにある。
