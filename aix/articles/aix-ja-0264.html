目的
コピー元ファイルの内容をコピー先ファイルにコピーする。

説明
cp
。

パラメータが指定するコピー元ファイルをコピー先ファイルにコピーする。 この
TargetFile
パラメータは保存先ファイルを指定する。 ターゲット・ファイルが存在する場合、
cp
コマンドは内容を上書きするが、そのファイルに関連付けられているモード、所有者、グループは変更されない。 パラメータの最終アクセス時刻と
SourceFile
パラメータの最終アクセス時刻と

パラメータと同じ名前の新しいファイルを作成する。 この

構文
ファイルを別のファイルにコピーするには、以下の構文を使用します。 cp [ -d ] [ -e ] [ -E { force|ignore|warn } ] [ -f ] [ -h ] [ -i ] [ -p ] [ -I ] [ -S ] [ -U ] [ -- ] SourceFile TargetFile ファイルをディレクトリーにコピーするには、以下の構文を使用します。 cp [ -d ] [ -e ] [ -E { force|ignore|warn } ] [ -f ] [ -h ] [ -i ] [ -p ] [ [ -r | -R ] [ -H | -L | -P ] ] [ -I ] [ -U ] [ -- ] SourceFile ... TargetDirectory ディレクトリーをディレクトリーにコピーするには、以下の構文を使用します。 cp [ -d ] [ -e ] [ -E { force|ignore|warn } ] [ -f ] [ -h ] [ -i ] [ -p ] { -r | -R } [ -H | -L | -P ] [ -I ] [ -U ] [ -- ] SourceDirectory ... TargetDirectory

例
カレント・ディレクトリにファイルのコピーを作成するには、以下のコマンドを入力する：
cp prog.c prog.bak
このコマンドは、
prog.c
ファイルを
prog.bak
ファイルにコピーする。
prog.bak
ファイルが存在しない場合、
cp
コマンドがファイルを作成する。
prog.bak
ファイルが存在する場合、
cp
コマンドはそれを
prog.c
ファイルのコピーに置き換える。
カレント・ディレクトリにあるファイルを別のディレクトリにコピーするには、以下のコマンドを入力する：
cp jones /home/nick/clients
このコマンドは、
jones
ファイルを
/home/nick/clients/jones
ファイルにコピーする。
ファイルを新しいファイルにコピーし、ソース・ファイルに関連付けられた変更日時、ACLを保持するには、次のコマンドを入力する：
cp -p smith smith.jr
このコマンドは、
smith
ファイルを
smith.jr
ファイルにコピーする。 システムは現在の日付とタイム・スタンプでファイルを作成する代わりに、
smith.jr
ファイルに
smith
ファイルと同じ日付と時刻を与えます。
smith.jr
ファイルは
smith
ファイルのアクセス制御保護を継承する。
あるディレクトリ内のすべてのファイルを新しいディレクトリにコピーするには、以下のコマンドを入力する：
cp /home/janet/clients/* /home/nick/customers
このコマンドは、
clients
ディレクトリのファイルのみを
customers
ディレクトリにコピーする。
すべてのファイルとサブ・ディレクトリーを含むディレクトリーを別のディレクトリーにコピーするには、次のコマンドを入力する：
cp /home/janet/clients/* /home/nick/customers
注:
ディレクトリーをそれ自体にコピーすることはできません。
このコマンドは、
clients
ディレクトリ（そのすべてのファイル、サブディレクトリ、およびそれらのサブディレクトリ内のファイルを含む）を、
customers/clients
ディレクトリにコピーする。
特定のファイル群を別のディレクトリにコピーするには、以下のコマンドを入力する：
cp jones lewis smith /home/nick/clients
このコマンドは、作業ディレクトリの
jones
ファイル、
lewis
ファイル、

smith
ファイルを、
/home/nick/clients
ディレクトリにコピーする。
パターン・マッチ文字を使用してファイルをコピーするには、以下のコマンドを入力する：
cp programs/*.c .
このコマンドは、
.c
ファイルで終わる
programs
ディレクトリのファイルを、シングル・ドット (
.
) で示されるカレント・ディレクトリにコピーする。
c
と最後のドットの間にはスペースを入れる。
ファイルを新しいファイルにコピーし、ソース・ファイルに関連付けられたACLとEAを保持するには、以下のコマンドを入力する：
cp -U smith smith.jr
コピー中にソース・ファイルのスパース性を維持するには、以下のコマンドを入力する：
cp -S file.c sparse_file.c
