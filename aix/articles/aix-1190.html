目的

ファイルを troff 形式から PostScript 形式に変換します。

構文

psroff [ -t] [ -dQueue ] [ -nNumber ] [ -tTitle ] [ -DFontDirectory ] [ -FFontFamily ] [ -PFlag ] [ troffFlags ] [ File ... ]

説明

psroff コマンドは、環境で troff コマンドを実行して PostScript プリンターで出力を生成するシェル・スクリプトです。 psdit コマンドを使用して、 troff 中間出力を PostScript 形式に変換し、この出力を印刷用にスプールします。 ファイルを指定しないと、標準入力が使用されます。

任意の PostScript 言語コマンドまたはファイルを troff 文書に組み込むには、 psdit コマンドを参照してください。

フラグ

表 1. フラグ
項目
説明
-DFontDirectory 標準フォント・ディレクトリーではなく、インストール手順で構成された指定フォント・ディレクトリーでフォント・ファミリー・ディレクトリーを検索します。 troff コマンドで -F フラグを模倣するには、このフラグと -F フラグの両方を使用する必要がある場合があります。
-dキュー Queue パラメーターで指定したキューに出力を入れます。 -d フラグを使用しない場合には、psroff コマンドが出力をデフォルトのキューに入れ、最初のキューが qdaemon に対して認識されます。 このフラグは、スプーラー印刷によって認識されます。
-FFontFamily Times デフォルト・ファミリーではなく、 R フォント、 I フォント、 B フォント、または BI フォントに指定されたフォント・ファミリーを使用します。 Times、Courier、Helvetica フォント・ファミリーはユーザーの現場で定義され、他のフォントも同様に使用できます。 ユーザーが使用するプリンターが、ユーザーの選ぶフォント・ファミリーを持っていることを確認してください。 このフラグは、troff コマンドの -F フラグを変更します。 troff command -F フラグを使用する場合は、 troff コマンドを直接実行するか、代わりに -D フラグを使用する必要があります。
-n Number Number パラメーターで指定された数の出力コピーが作成されます。 デフォルトは 1 部です。 このフラグは、スプーラー印刷によって認識されます。
-Pフラグ Flag パラメーターをスプーラーへ渡します。 これは、スプーラーのフラグと psroff コマンドを使用したフラグの間で矛盾がある場合に便利です。
-t PostScript 出力をプリンターにスプーリングするのではなく、標準出力に送信します。 このフラグは、troff コマンドの -t フラグを変更します。 troff command -t フラグが必要な場合は、 troff コマンドを直接実行する必要があります。
-tタイトル 最初のバナー・ページで使用するジョブ名を設定します。 デフォルトでは、最初の入力ファイルの名前が使用されます。 このフラグは、スプーラー印刷によって認識されます。
