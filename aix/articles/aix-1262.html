目的

仮想共有ディスクのセットを除去します。

構文

removevsd
{-v vsd_names | -a} [-f[- f]

説明

仮想共有ディスクに関連付けられた論理ボリュームを除去するには、このコマンドを 使用します。 ボリューム・グループはこのコマンドでは除去されません。

仮想共有ディスクがシステム区画の任意のノードに構成されている場合、-f フラグが指定されていない限り、このコマンドは失敗します。

このコマンドは、System Management Interface Tool (SMIT) を使用して実行できます。 SMIT を使用するには、以下のように入力します。

smit delete_vsd

さらに、Remove a Virtual Shared Disk オプションを選択します。

フラグ

-v
仮想共有ディスクの名前またはこのコマンドにより除去される名前を指定します。
-a
コマンドが、RSCT ピア・ドメイン内の仮想共有ディスクをすべて除去するように指定します。
-f
仮想共有ディスクを構成解除し、除去するようシステムを強制実行します。 -f が指定されず、除去される仮想共有ディスクのいくつかが構成されている場合は、 このコマンドは失敗します。

パラメーター

VSAM 名
仮想共有ディスクを指定します。 仮想共有ディスクが停止状態にない場合は、 エラー・メッセージが出されます。

セキュリティー

このコマンドを実行するには、 root 権限が必要です。

制約事項

このコマンドは、ピア・ドメインでオンラインのノードから実行する必要があります。 オンラインのピア・ドメインに移動するには startrpdomain コマンドを使用します。 既存のピア・ドメイン内で、オンラインの特定ノードに移動するには startrpnode コマンドを使用します。 RSCT ピア・ドメインの作成と管理の詳細については、「RSCT Administration Guide」を参照してください。

例

システムまたはシステム区画内の定義済みの仮想共有ディスクを、すべて構成解除し除去するには、 次のように入力します。

removevsd -a -f

場所

/opt/rsct/vsd/bin/removevsd
