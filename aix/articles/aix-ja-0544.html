目的
トレース・ファイルの収集を管理します。

説明
gettrc
コマンドは、
snap
コマンドと一緒に使用されるスクリプトです。 このコマンドは、システム・トレース・ファイル、軽量メモリー・トレース (LMT) ファイル、およびコンポーネント・トレース (CT) ファイルの収集を管理します。

構文
gettrc [ 「-c」 ] [ -C ディルネーム ] [ -m (M) ] [ -M (M) ディルネーム ] [ -s ] [ -S (S) ファイル名 ]

オプション
フラグ
フラグ | 説明
-c | コンポーネント・トレース・ファイルを収集します。
-C ディレクトリー名 | dirname で指定されたディレクトリーからコンポーネント・トレース・ファイルを収集します。
-m | メモリー・トレース・ファイルを収集します。
-M ディレクトリー名 | dirname で指定されたディレクトリーから軽量メモリー・トレース・ファイルを収集します。
-s | システム・トレース・ファイルを収集します。
-S ファイル名 | filename で指定されたディレクトリーからシステム・トレース・ファイルを収集します。

例
gettrc
を
snap
コマンドと一緒に使用して、さまざまな種類のトレース・ファイルを検索するには、次のように入力します。
snap "gettrc -c -C dirname -m -M dirname -s -S filename"
このコマンドでは、
dirname
で指定されたディレクトリーにリストされるファイルを含めて、システム・トレース・ファイル、LMT ファイル、および CT ファイルが戻されます。
