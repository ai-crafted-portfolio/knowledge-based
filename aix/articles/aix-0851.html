目的

論理パーティション、論理ボリューム、ボリュームグループの入出力(I/O)統計情報を表示します。 また、pbuf およびブロック入出力の統計も報告します。

構文

lvmstat { -l | -v } Name [ -e | -d ] [ -F ] [ -C ] [ -c Count ] [ -s ] [ Interval [ Iterations ] ]
lvmstat -v Name -r [ -L | -C ]
lvmstat -v Name -m

説明

lvmstat コマンドは、物理ディスク間の入出力負荷のバランスを改善するために、 論理ボリューム構成を変更するのに使用できるレポートを作成します。

デフォルトによって、統計情報収集はシステムで使用可能になりません。 該当する論理ボリュームまたはボリューム・グループに対してこの機能を有効にするには、「-eフラグを使用する。 ボリュームグループの統計収集を有効にすると、そのボリュームグループ内のすべての論理ボリュームが有効になります。

注：'-eフラグと'-dフラグは、'-rフラグで指定されるスペース再 生統計には適用されない。

lvmstat生成される最初のレポートは、システムが起動してからの時間に関する統計情報を提供する。 後続のレポートでは、それぞれ直前のレポートからの時間が扱われます。 lvmstat実行されるたびに、すべての統計が報告される。 レポートは、ヘッダ行の後に、指定されたフラグに依存する各論理パーティションまたは論理ボリュームの統計情報の行が続きます。

-l フラグを指定した場合、 Name は論理ボリューム名で、 統計情報はこの論理ボリュームの物理区画に関するものになります。 論理区画のミラー・コピーは、統計情報の報告に関して、個別であると見なされます。 i/os（iocnt）の数が多い順に、パーティションに表示される。

Interval パラメーターは、それぞれの報告の間の時間 (秒単位) を指定します。 最初のレポートには、'varyonvgコマンドを使用してボリューム・グループがアクティブ化されてからの統計が含まれる。 それ以降の各レポートには、前回のレポートから一定期間内に収集された統計情報が含まれる。 Countパラメータが指定された場合、レポートの最高Count行のみが生成される。 論理ボリュームで、Count が 10 の場合、 使用頻度が最も高い 10 個の区画のみが識別されます。 IterationsパラメータがIntervalパラメータと一緒に指定された場合、その回数だけ繰り返しが実行される。 Iterationsパラメータが指定されていない場合、'lvmstatは連続的にレポートを生成する。 Intervalを使用して'lvmstatを複数回実行した場合、前回の実行から統計値に変化がなければ、レポートは印刷されない。 代わりに、1 つのピリオド . (period) が表示されます。

lvmstat コマンドは、 論理ボリュームにおいて使用頻度が最も高い物理区画を識別するため、 ある物理ボリュームがパフォーマンスの障害になっていないかどうかを判別する上で役立ちます。

注: lvmstat コマンドでは、 ローカル・ノードの入出力統計情報のみが報告されます。

セキュリティー

lvmstat を使用するには、root ユーザー権限がなければなりません。

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. ボリューム・グループ「datavg」の統計収集を有効にするには（「datavg内のLVはすべて有効になっている）、次のコマンドを入力する：
    lvmstat -v datavg -e
  2. 論理ボリューム「hd2」の全パーティションの履歴を表示するには、次のコマンドを入力する：
    lvmstat -l hd2
  3. ボリュームグループ「uservg」の最初の5つの論理ボリュームの履歴を表示するには、次のコマンドを入力する：
    lvmstat -v uservg -c 5
  4. 論理ボリューム「ramlv」の連続レポートを2秒間隔で表示するには、次のコマンドを入力する：
    lvmstat -l ramlv 2
  5. ボリューム・グループ「rootvg」について、2秒間隔で6つのレポートを表示するには、次のコマンドを入力する：
    lvmstat -v rootvg 2 6
  6. ボリュームグループ「uservg内のすべての論理ボリュームの統計のカウンタをリセットするには、次のコマンドを入力します：
    lvmstat -v uservg -C
  7. datalv統計収集を無効にするには、以下のコマンドを入力する：
    lvmstat -l datalv -d
  8. スペース再利用の統計を表示するには、次のコマンドを入力する：
    lvmstat -v uservg -r
  9. ロング・リスティング・モードでスペース再利用の統計を表示するには、以下のコマンドを入力する：
    lvmstat -v uservg -r -L
  10. スペース再利用の統計をクリアするには、以下のコマンドを入力する：
    lvmstat -v uservg -r -C
  11. ボリュームグループに対してMWCC統計 datavgを有効にするには、次のコマンドを入力します:
    lvmstat -v datavg -m -e
  12. ボリュームグループに対するMWCC統計 datavgを無効にするには、次のコマンドを入力します:
    lvmstat -v datavg -m -d
  13. ボリュームグループ MWCC の統計情報を datavgクリアするには、次のコマンドを入力します:
    lvmstat -v datavg -m -C
  14. ボリュームグループに対して、 datavg 10秒間隔で5つのMWCC統計レポートを一度に表示し、カンマ区切り値(csv)ファイル形式で出力するには、次のコマンドを入力します:
    lvmstat -v datavg -F m -s 10 5
