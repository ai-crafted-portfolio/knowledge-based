目的
応答のアクションを追加または削除、あるいは応答を名前変更します。

説明
chresponse
コマンドは、応答にアクションを追加したり、応答からアクションを削除したりします。 アクションは、応答を条件付きで使用し、条件が発生するとコマンドが実行するように定義します。
chresponse
コマンドを使用して、応答の名前を変更することもできます。
システム・ソフトウェアを適切に機能させるために特定の応答が必要な場合、その応答は
ロックされることがあります。 ロックされた応答はアンロックされない限り変更したり、取り除くことはできません。
chresponse
コマンドで指定した応答がロックされている場合、その応答は変更されません。代わりに、応答がロックされていることを通知するエラーが生成されます。 応答をアンロックするには、
-U
フラグを使用できます。 ただし、応答はシステム・ソフトウェアが
適切に機能するために必須であり、通常ロックされているので、これをアンロックする際は
注意が必要です。 応答をロックして変更できないようにするには、
-L
フラグを使用します。
システムにクラスター・システム・マネージメント (CSM) がインストールされている場合は、CSM 定義のノード・グループをノード名の値として使用して、複数のノードを参照できます。

構文
応答にアクションを追加するには、次のように入力します。 chresponse -a -n アクション [ -d days_of_week [ , days_of_week ... ]] [ -t time_of_day [ , time_of_day ... ]] [ -s action_script ] [ -r return_code ] [ -b | [ -e a | A | b | e | r ] [ -o ] [ -E env_var = value [ , env_var = value ... ] ] [ -u ] [ -h ] [ -TV ] 応答 [ : node_name ] 応答からアクションを削除するには、次のように入力します。 chresponse -p -n action [ -h ] [ -TV ] 応答 [ : node_name ] 応答の名前を変更するには、次のように入力します。 chresponse -c new_response [ -h ] [ -TV ] 応答 [ : node_name ] 応答をアンロックまたはロックするには、次のように入力します。 chresponse { -U | -L } [ -h ] [ -TV ] 応答 [ : node_name ]

例
以下の例は、スタンドアロン・システムに適用されます。
この例では、「E-mail root」という名前のアクションは唯一のアクションにはなり得ません。 「E-mail root」を「E-mail root anytime」という名前の応答から削除するには、
次のコマンドを実行します。
chresponse -p -n "E-mail root" "E-mail root anytime"
この例では、「E-mail root」という名前のアクションが月曜日から金曜日の午前 8 時から午後 6 時まで使用され、コマンド
/opt/rsct/bin/notifyevent root
が使用され、標準出力が監査ログに保管され、アクションからの戻りコード 5 が予期されます。 「E-mail root」を「E-mail root anytime」という名前の応答に追加するには、
次のコマンドを実行します。
chresponse -a -n "E-mail root" -d 2-6 -t 0800-1800 \
-s "/opt/rsct/bin/notifyevent root" -o -r 5 \
"E-mail root anytime"
「E-mail root anytime」という応答を「E-mail root and admin anytime」に名前変更するには、
次のコマンドを実行します。
chresponse -c "E-mail root and admin anytime" "E-mail root anytime"
以下の例は管理ドメインに適用されます。
「E-mail root」という名前のアクションを、管理サーバーに定義されている「E-mail root
anytime」という名前の応答から削除するには、管理サーバーで次のコマンドを実行します。
chresponse -p -n "E-mail root" "E-mail root anytime"
この例では、「E-mail root」という名前のアクションが月曜日から金曜日の午前 8 時から午後 6 時まで使用され、コマンド
/opt/rsct/bin/notifyevent root
が使用され、標準出力が監査ログに保管され、アクションからの戻りコード 5 が予期されます。 「E-mail root」を、管理サーバーに定義されている「E-mail root
anytime」という応答に追加するには、管理サーバーで次のコマンドを実行します。

chresponse -a -n "E-mail root" -d 2-6 -t 0800-1800 \
-s "/opt/rsct/bin/notifyevent root" -o -r 5 \
"E-mail root anytime"
「E-mail root」という名前のアクションを、管理対象ノード
nodeB
で定義されている「E-mail root anytime」という名前の応答から削除するには、管理サーバーで次のコマンドを実行します。
chresponse -p -n "E-mail root" "E-mail root anytime":nodeB
以下の例はピア・ドメインに適用されます。
この例では、「E-mail root」という名前のアクションが月曜日から金曜日の午前 8 時から午後 6 時まで使用され、コマンド
/opt/rsct/bin/notifyevent root
が使用され、標準出力が監査ログに保管され、アクションからの戻りコード 5 が予期されます。 ドメイン内のノード
nodeA
で定義されている応答「E-mail root anytime」に「E-mail root」を追加するには、ドメイン内の任意のノードで次のコマンドを実行します。
chresponse -a -n "E-mail root" -d 2-6 -t 0800-1800 \
-s "/opt/rsct/bin/notifyevent root" -o -r 5 \
"E-mail root anytime":nodeA
ドメイン内のノード
nodeA
に定義されている「E-mail root anytime」という名前の応答から「E-mail root」という名前のアクションを削除するには、ドメイン内の任意のノードで次のコマンドを実行します。
chresponse -p -n "E-mail root" "E-mail root anytime":nodeA
