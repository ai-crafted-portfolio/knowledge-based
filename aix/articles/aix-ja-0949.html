目的
Server Message Block (SMB) クライアント・ファイルシステムの資格情報を
/etc/smbcred
ファイルに追加します。 この資格情報は、SMB クライアント
shares
の以降のマウント操作に使用できます。

説明
mksmbcred
コマンドを実行する場合は、サーバー名とユーザー名を指定する必要があります。
-p
フラグで引数としてパスワードを指定しないと、
mksmbcred
コマンドは隠し文字入力としてパスワードを求めるプロンプトを出します。 パスワードは暗号化され、資格情報は
/etc/smbcred
ファイルに
server_name
|
username
|
password
のセットとして保管されます。 同じサーバーの資格情報セットを異なるユーザー名で複数作成できます。 また、異なるサーバーの資格情報セットを同じユーザー名で複数作成することもできます。

構文
mksmbcred -s server_name -u user_name [-p password]

オプション
フラグ
-
サーバー名
これは、リモート・ホスト (SMB サーバー) の名前を指定します。 ホスト名、IP アドレス、または完全修飾ドメイン・ネームとして
server_name
パラメーターを指定できます。
-
ユーザー名
特定のリモート・ホストにアクセスするために資格情報の定義を必要とするユーザー名を指定します。
-
パスワード
特定のリモート・ホストの特定ユーザーのパスワードを指定します。

例
user1
が
xxx.in.ibm.com
サーバー上で SMB クライアント・ファイルシステムをマウントするための資格情報を追加するには、次のコマンドを入力します。
mksmbcred -s xxx.in.ibm.com -u user1
