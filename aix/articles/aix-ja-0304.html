目的
クラスター・セキュリティー・サービス・トラステッド・ホスト・リスト・ファイルの内容を表示および変更します。

説明
このコマンドは、クラスター・セキュリティー・サービス・トラステッド・ホスト・リスト・ファイルの内容を表示および変更します。
-f
フラグが指定されていない場合、コマンドはトラステッド・ホスト・リスト・ファイル
ctcasd.cfg
ファイルで構成されている
に対してその操作を実行します。
ctsthl
を使用すると、コマンド・ユーザーは、特定のホストのトラステッド・ホスト・リスト内の項目を追加、変更、または除去することができます。 ホストを追加または変更する場合、このコマンドのユーザーは以下の情報を提供しなければなりません。
ホストの ID (例えば、
zathras.ibm.com
または
129.34.128.54
など)
このホストに使用される、ID の 16 進値を表す文字ストリング・フォーマットのホスト ID 値 (例えば、
b87c55e0
)
ホスト ID の生成に使用された方式 (
ctskeygen -i
コマンドの説明を参照してください)
このコマンドは、生成方式名を妥当性検査し、文字列表記をバイナリー形式に変換して、このホスト用のトラステッド・ホスト・リスト・ファイル内にエントリーを新規作成します。 通常、ホスト ID の値は非常に大きいです。 例えば、RSA 1024 ビットで生成された ID の文字表現では、そのサイズが 256 文字を超えます。 これは、
AIX
のようなコマンドラインの長さを小さく制限しているシステムで問題を引き起こす可能性がある。 この問題を回避するには、シェル・スクリプトから、または
xargs
コマンドと一緒に
ctsthl -a
コマンドを使用します。
トラステッド・ホスト・リスト・ファイルの内容が表示されると、
ctsthl
は各項目について以下の情報を提供します。
ホストのネットワーク ID
文字列として表現されたそのホストのホスト ID 値
そのホスト ID の生成に使用された方式

構文
ctsthl { -a | -d | -h | -l | -s } [ -f trusted_host_list_file ] [ -n host_name ] [ -m method ] [ -p IDER_値 ]

オプション
フラグ
-a
トラステッド・ホスト・リストにホスト・エントリーを追加するか、またはこのリストのエントリーを交換します。
-n
、
-m
、および
-p
フラグも指定する必要があります。 指定されたホストがトラステッド・ホスト・リスト・ファイル内に既に存在している場合、そのホストのエントリーは、このコマンドに提供された情報と一致するように変更されます。
-d
あるホストのエントリーをトラステッド・ホスト・リスト・ファイルから除去します。 除去するホストを示すために、
-n
フラグも指定する必要があります。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。
-l
トラステッド・ホスト・リスト・ファイルの内容をリストするようコマンドに指示します。 このフラグを
-a
または
-d
フラグと組み合わせると、これらのフラグが処理された後に内容が表示されます。 このフラグを
-s
フラグと組み合わせて使用すると、コマンドによって作成されたすべての新規エントリーと、ローカル・システムによってサポートされるホスト名および IP アドレスについて検出された公開鍵の不一致が表示されます。
-
信頼できるホスト・リスト・ファイル
トラステッド・ホスト・リスト・ファイルの完全修飾パス名を指定します。 このフラグを指定しない場合は、
ctcasd.cfg
ファイルで構成されたトラステッド・ホスト・リスト・ファイルが使用されます。
--n
ホスト名
この操作で使用するホストの ID を指定します。 この ID は、ホスト名または IP アドレスで指定したものでなければなりません。
これにより、クラスターのネットワークはホストを認識します。
-
メソッド
ホスト ID キーを作成する際には指定されたキー生成方式を使用するようコマンドに指示します。
ctskeygen -i
コマンドを使用して、
method
の有効な値を表示することができます。
--p
identifier_value
そのホスト用として保管されるホスト ID の値を指定します。 これは、この ID として保管されるホスト ID の 16 進値を表す文字列です。 例えば、ホスト ID の値が
0xB87C55E0
の場合、このフラグは
-p b87c55e0
と指定されます。 一般にAIX®では、ホスト識別子キーはこの例よりもずっと長くなり、
AIX
のような一部のシステムでは、コマンドラインの制限には大きすぎる。 結果のコマンド行が大きすぎる場合は、
xargs

を使用して拡張するか、シェル・スクリプトからコマンドを発行してください。
-s
デーモンが検出できる AF_INET 構成されたアクティブなアダプターに関連付けられた、
すべての既知の IP アドレスとホスト名をローカル・システムの中で探索します。 ローカル・システムのホスト名または IP
アドレスが、ローカル・システムのトラステッド・ホスト・リスト・ファイルで検出されなければ、
1 つのエントリーがその値をローカル・システムの公開鍵値に関連付けるために追加されます。

例
ファイル
/mythl
に含まれているトラステッド・ホストの内容を表示するには、次のように入力します。
ctsthl -l -f /mythl
システム
zathras.ibm.com
のデフォルトのトラステッド・ホスト・リスト・ファイルにエントリーを追加するには、次のように入力します。
ctsthl -a -n zathras.ibm.com -m rsa1024 -p 120400a9...
この例では完全な ID 値の途中までしか書かれていないことに注意してください。
システム
129.23.128.76
のデフォルトのトラステッド・ホスト・リスト・ファイルにエントリーを追加するには、次のように入力します。
ctsthl -a -n 129.23.128.76 -m rsa1024 -p 120400a9...
この例では完全な ID 値の途中までしか書かれていないことに注意してください。
デフォルトのトラステッド・ホスト・リストから zathras.ibm.com 用のエントリーを除去するには、次のように入力します。
ctsthl -d -n zathras.ibm.com
