目的
コマンド・パス名を記憶または報告します。

説明
hash
コマンドは、パス名をリストに追加するか、リストの内容をパージすることによって、現行シェルがコマンドのパス名を記憶する方法に影響を与えます。
パラメーターまたはフラグを指定しないと、
hash
コマンドは
パス名リストの内容を標準出力に報告します。 このレポートには、以前に
hash
コマンドを起動した際に見つかった現行シェル環境内のコマンドのパス名が含まれます。 この表示には、通常のコマンド検索プロセスによって呼び出され、検出されたコマンドを含めることもできます。
注:
シェル組み込みコマンドは、
hash
コマンドでは報告されません。
-r
フラグを使用すると、コマンド・パス名リストの内容をクリアすることができます。 また、
PATH
環境変数の値をリセットしても、リストからパス名をクリアすることができます。 最も単純なフォーマットでクリアする場合は、次のように入力します。
PATH="$PATH"
Command
パラメーターを使用すると、
hash
コマンドは指定したコマンドのパス名を検索し、このパスをリストに追加します。 コマンドの指定には、/ (スラッシュ) を使用しないでください。
hash
コマンドは現行シェル環境に影響を与えるので、Korn シェル (POSIX シェル) の正規組み込みコマンドとして用意されています。 以下の例のように、
hash
コマンドを別のコマンドの実行環境内で呼び出すと、
呼び出し元の環境のコマンド検索プロセスには影響しません。
nohup hash -r
find . -type f | xargs hash
hash
コマンドを使用することは、
alias
-t
コマンドを使用することと同等です。

構文
コマンドのパスをパス名リストに追加するには、以下のようにします。 hash [ Command ... ] パス名リストをクリアするには hash -r

オプション
フラグ
表 1. フラグ
項目 | 説明
-r | パス名リストの内容をクリアします。

例
wc
コマンドのパス名を見つけて、それをパス名リストに追加するには、次のように入力します。
hash wc
パス名リストの内容をクリアするには、次のように入力します。
hash -r
