# このサイトについて

本サイトは z/OS と関連製品の技術知識を、**技術項目・確認問題（QA）・検証手順**の3層でカテゴリ別に整理した実務用ナレッジベースです。

## 収録の考え方

- **技術項目**: 各分野の機能・用語・設定を、出典マニュアルとともに整理した骨格です。
- **確認問題（QA）**: 技術項目の理解確認用の4択問題（問題文・選択肢・正解・解説・難易度・出典）です。
- **検証手順**: 机上で確認できる操作手順（検証目的・前提条件・操作・画面出力・合格条件・検証状態・出典）です。

## 対応率の意味

各カテゴリの「QA対応 / 手順対応」は、技術項目に**明示的に対応付けられた件数**を分子にした割合です。2026-07-16 時点で全体は QA 85.47%・手順 56.08% で、**全項目が完備しているわけではありません**。不足分は継続して増補しています。
