# 初回セットアップ手順

初めて利用する際の基本的なセットアップ手順を説明します。

## 前提条件

- Windows 10 以降
- Excel 2016 以降
- 管理者権限

## 手順

### 1. インストーラを起動

配布された ZIP を任意のフォルダに展開し、`install.bat` を実行します。

### 2. 初期設定を行う

起動後、初期設定ダイアログでユーザー名と保存先フォルダを指定してください。

!!! info "ヒント"
    保存先フォルダはネットワーク共有でも構いません。

### 3. 動作確認

サンプルナレッジを 1 件登録し、検索画面で表示されることを確認します。
