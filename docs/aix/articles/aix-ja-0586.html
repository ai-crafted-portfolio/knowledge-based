目的
システム全体のハードウェア・パフォーマンス・カウンター情報を提供します。

説明
hpmstat
コマンドは、実行壁時計時刻、ハードウェア・パフォーマンス・カウンター情報、および派生したハードウェア・メトリックを提供します。
hpmstat
コマンドを使用できるのは、root 特権を持つユーザーのみです。
コマンド行オプションを指定しない場合、
hpmstat
コマンドは、イベントのデフォルト・セット
1
に対して、ユーザー、カーネル、およびハイパーバイザー (ハイパーバイザー・モードをサポートするプロセッサーの場合) のアクティビティーのデフォルトの
1
反復を 1 秒間カウントします。 続いて、このコマンドは、ロウ・カウンター値および導出メトリックを標準出力
に書き出します。 デフォルトでは、
runlatch
は無効になっているため、アイドル・サイクルでの実行中にカウントを実行できます。
-U
オプションが指定されている場合、
interval
はマイクロ秒単位で、反復
count
は無限大であり、派生メトリックは計算されず、標準出力に書き込まれません。 カウンター多重方式が指定されている場合は、このオプションは無視されます。
-T
オプションを指定すると、出力情報の前にタイム・スタンプ (秒とマイクロ秒) が付き、時間情報が秒単位ではなくタイム・スタンプとして書き込まれます。
モニター対象のイベント・タイプおよび関連するハードウェア・パフォーマンス・カウンターは、set
-s
オプションを使用するか、
HPM_EVENT_SET
環境変数にイベント・グループ名またはセット番号を指定することによって指定します。 あるいは、カウンターとイベントのペア (
POWER3
および
PowerPC 604 RISC マイクロプロセッサー
) またはイベント・グループ名 (
POWER4
以降) を
libHPM_events
入力ファイルに指定します (
HPM_EVENT_SET
よりも優先されます)。 カウント・モードは、各セットを修飾することができます。 イベントのグループ番号または名前を指定するには、
-g
オプションを設定するか、または
HPM_EVENT_GROUP
環境変数でイベント・グループのコンマ区切りリストを指定します。 同様に、カウント・モードは各イベント・グループを限定することができます。
セット番号の代わりに、コンマで区切られたイベント・セットのリストを指定することができます。その場合は、カウンター多重方式が選択されます。 イベント・セットをすべて選択するには、セット番号の値を
0
に設定します。

有効なイベント・セット番号は、
pmlist
コマンドを使用してリストできるプロセッサー・タイプに応じて、
1
から上限まで実行されます。
派生メトリックのコンマ区切りリストを指定するには、
-D
オプションを設定します。 カウント・モードでは、各派生メトリックを限定することができます。
派生メトリック・グループのリストを指定するには、
-m
オプションを設定するか、または
HPM_PMD_GROUP
環境変数で派生メトリック・グループのコンマ区切りリストを指定します。 この操作により、ユーザーは、指定されたグループに関連するすべての派生メトリックを選択できます。 カウント・ノードは、各メトリック・グループを修飾します。
多重化モードでカウントする場合は、使用する前に結果を正規化する必要があります。 データ正規化に使用されるデフォルトのベースは、時間ベースです。
-b
オプションを使用すると、データの正規化に PURR 時間または SPURR 時間 (プロセッサーでサポートされている場合) を使用できます。 データ正規化のベースは、
HPM_NORMALIZE
環境変数を使用して定義することもできます。
グローバル・ワークロード区画 (WPAR) から
hpmstat
コマンドを実行する場合、
-@
WparName
オプションを使用して特定の WPAR をモニターすることができます。
-@
ALL
オプションを使用して、システム内のすべてのアクティブな WPAR をモニターし、WPAR ごとのデータを取得することができます。
結果は、
-x
オプションを使用して XML 形式で出力できます。

構文
hpmstat [ -b time_base ] [ -d ] [ -D metrics ] [ -O options ] [ -g event_groups ] [ -H ] [ -k ] [ -m metrics_groups ] [ -o file ] [ -r ] [ -s set ] [ -T ] [ -U ] [-u ] [ -x ] [ -@ ALL | WparName ] interval count hpmstat [-h]

フラグ
項目 | 説明

-b time_base | データの正規化のための基準を選択します。 使用可能なベースは以下のとおりです。 time 時間基準 purr PURR 時間 (使用可能な場合) spurr SPURR 時間 (使用可能な場合) デフォルト値は time です。

-D メトリック | 評価する派生メトリックのリストを選択します。 カウント・モードでは、以下のオプションを使用して、各派生メトリックを修飾できます。 metric:counting_modes (使用可能なカウント・モードについては、 -m オプションを参照してください。)

-O オプション | -O オプションには、以下の値を指定できます。 threshold_cmp_val = 値 しきい値比較浮動小数点値を設定します。 Power ® プロセッサーには、しきい値カウンター機能があります。 しきい値カウンターは、1 次パフォーマンス・モニター・カウンター (PMC) とは異なります。これは、コア・サブシステム、キャッシュ・サブシステム、およびメモリー・サブシステムの指定された開始イベントと終了イベントの別個のセットの間で発生するイベントの数をカウントできるためです。 このオプションは、指定された開始イベントと終了イベントの間のイベント数を比較するために使用できるしきい値を指定します。 threshold_event_sel = 名前 しきい値カウントで考慮する必要があるイベントを指定します。 threshold_event_sel オプションの有効な値は以下のとおりです。 THRESHOLD_COUNT_CYCLES 制御レジスター実行ラッチが設定されている、発生したイベントまたはサイクルの数をカウントします。 AIX® オペレーティング・システムは、制御レジスター・ビットを使用して、アイドル状態または実行状態を示します。 パフォーマンス・モニター・ユニット (PMU) もこのビットを使用して、アイドル期間中のイベントのカウントを回避します。 このビットは通常、 実行ラッチ と呼ばれます。 このオプションは、凍結条件に依存しません。 このオプションは、PMU がイベント・カウンターの内容を凍結した場合でもイベントがカウントされることを意味します。 THRESHOLD_COUNT_NUM_COMP_INSTR 制御レジスター run latch が設定されたときに完了した命令の数をカウントします。 このオプションは、凍結条件に依存しません。 このオプションは、PMU がイベント・カウンターの内容を凍結した場合でもイベントがカウントされることを意味します。 THRESHOLD_COUNT_PMC1_EVENTS PMC1 イベントをカウントします。 PMC1 - PMC4 は 32 ビット・レジスターであり、プログラムによってカウント可能なイベントが指定されるため、プログラマブル・カウンターと呼ばれます。 このオプションは、凍結条件によって異なります。 このオプションは、PMU がイベント・カウンターの内容を凍結したときにイベントがカウントされないことを意味します。

-O options (続き) | THRESHOLD_COUNT_PMC2_EVENTS PMC2 イベントをカウントします。 このオプションは、凍結条件によって異なります。 このオプションは、PMU がイベント・カウンターの内容を凍結したときにイベントがカウントされないことを意味します。 THRESHOLD_COUNT_PMC3_EVENTS PMC3 イベントをカウントします。 このオプションは、凍結条件によって異なります。 このオプションは、PMU がイベント・カウンターの内容を凍結したときにイベントがカウントされないことを意味します。 THRESHOLD_COUNT_PMC4_EVENTS PMC4 イベントをカウントします。 このオプションは、凍結条件によって異なります。 このオプションは、PMU がイベント・カウンターの内容を凍結したときにイベントがカウントされないことを意味します。 threshold_eve_start_sel = 名前 しきい値カウントを開始するイベントを指定します。 このオプションの有効な値については、 threshold_eve_stop_sel を参照してください。

-O options (続き) | threshold_eve_stop_sel = 名前 しきい値カウントを停止するイベントを指定します。 threshold_eve_start_sel オプションおよび threshold_eve_stop_sel オプションには、以下の値を設定できます。 PM_MRK_INST_DECODED サンプリングされた命令はデコードされます。 PM_MRK_INST_DISP サンプリングされた命令がディスパッチされます。 PM_MRK_INST_ISSUED サンプル命令が発行されます。 PM_MRK_INST_FIN サンプル命令が終了しました。 PM_MRK_INST_CMPL サンプル命令が完了しました。 PM_MRK_LD_MISS_L1 サンプル命令レベル 1 (L1) ロード・キャッシュが欠落しています。 PM_MRK_L1_RELOAD_VALID サンプリングされた命令レベル 1 (L1) の再ロードは有効です。 EVE_SEL_PMC1 PMC1 のモニター・モード制御レジスター (MMCR) 1 で選択されたイベントが発生しました。 EVE_SEL_PMC2 PMC2 の MMCR1 で選択されたイベントが発生しました。 EVE_SEL_PMC3 PMC3 に対して MMCR1 で選択されたイベントが発生しました。 EVE_SEL_PMC4 PMC4 の MMCR1 で選択されたイベントが発生しました。 PM_MRK_NTF_FIN サンプリングされた命令は次の終了状態になっています。 PM_MRK_L2_RC_DISP サンプリングされた命令に対してディスパッチされる RC マシン。 PM_MRK_ST_DONE_L2 サンプリングされた命令に対して実行される RC マシン。

-O options (続き) | random_samp_ele_crit = 名前 サンプリングする命令を選択するためのランダム基準を指定します。 このオプションの有効な値は以下のとおりです。 ALL_INSTR すべての命令が適格です。 この値がデフォルト設定です。 LOAD_STORE 操作はロード・ストア・ユニット (LSU) にルーティングされます。例えば、ロード・ストアにルーティングされます。 PROB_NOP 特殊な操作なし命令 (プローブ NOP イベントと呼ばれる) をサンプリングします。 LARX_STCX サンプルは、索引付き (LARX) 命令をロードして予約し、条件付き索引付き (STCX) 命令を保管します。 LOAD_SAMPLING サンプルは命令をロードします。 LONG_LATENCY_OP 長い待ち時間命令 ( div/sqrt/mul ) をサンプリングします。 STORE_SAMPLING サンプル・ストアの指示。 LOAD_MISSES ロード・ミス命令をサンプリングします。 LOAD_HIT_STORE load-hit-store 命令のサンプル。 この値は、ロード操作でストア・キューから終了状態にデータを転送できる場合にのみ適用されます。 この値は、ロード・ヒット・ストア命令がストア・キューにあるが、ロード操作が部分的にストアとオーバーラップしている場合には適用されません。 BRANCH_MISPREDICTS ブランチ予測の誤りの命令をサンプリングします。 BRANCH_MISPREDICTS_DIR_CR_CTR 分枝予測イベント (方向、CR、または CTR) をサンプリングします。 BRANCH_MISPREDICTS_TA ブランチの誤予測イベント (TA) をサンプリングします。 BRANCHES_RESOLVED_TAKEN 解像度を持つサンプル・ブランチ。 NON_REPEATING_BRANCHES 非反復ブランチをサンプリングします。 ALL_BRANCHES_REQ_PRED 予測が必要なすべてのブランチをサンプリングします。

-g event_groups | イベントの事前定義グループまたはイベントのグループ名または番号のコンマ区切りリストをリストします。 コンマで区切られたグループのリストを使用する場合は、カウンター多重方式が選択されます。 カウント・モードでは、以下のオプションを使用して各イベント・グループを修飾できます。 event_group:counting_modes (使用可能なカウント・モードについては、 -m オプションを参照してください。)
-H | ハイパーバイザー活動状況のみをカウントします。
-h | ヘルプ・メッセージを表示します。
-k | システム稼働状況のみをカウントします。
-m metrics_groups | 評価する派生メトリック・グループのリストを選択します。 デフォルトの派生メトリック・グループは、特定の派生メトリック・グループに属さないすべての派生メトリックを参照します。 カウント・モードでは、以下のオプションを使用して各メトリック・グループを修飾できます。 metric_group_name:counting_modes 使用可能なカウント・モードは以下のとおりです。 u user モード k kernel モード h hypervisor モード r runlatch モード n nointerrupt モード
-o ファイル | 出力ファイル名。
-r | runlatch を使用可能にし、アイドル・サイクルで実行中のカウントを使用不可にします。
-s セット | イベントの事前定義セット、またはセットのコンマ区切りリスト ( 1 を N に設定、または 0 を指定してすべてを選択) をリストします。 pmlist コマンドを参照してください。) コンマで区切られたセットのリストを使用する場合は、カウンター多重方式が選択されます。 カウント・モードでは、以下のオプションを使用して各セットを修飾できます。 event_set:counting_modes (使用可能なカウント・モードについては、 -m オプションを参照してください。)
-T | 秒単位の時間ではなく、タイム・スタンプを書き込みます。
-U | カウント時間間隔をマイクロ秒単位で書き込みます。 カウンター多重方式が指定されている場合は、このオプションは無視されます。
-u | ユーザー活動状況のみをカウントします。
-x | 結果を VPA XML フォーマットで表示します。

例
ハードウェア・カウンターからセット 2 のイベントに関する 1 秒間のシステム、ユーザー、およびハイパーバイザーのアクティビティーに関する情報を書き込むには、次のコマンドを入力します。
hpmstat -s 2
グループ 0 のイベントに関するユーザー・アクティビティー、および
wpar1
WPAR のグループ 1 のイベントに関するシステム・アクティビティーに関する情報を 5 秒間隔で書き込むには、次のコマンドを入力します。
hpmstat -@ wpar1 -g 0:u,1:k 5
しきい値開始イベントと終了イベントの別個のペアの間で経過したしきい値カウント・イベントの数をカウントし、比較するしきい値を指定するには、次のコマンドを入力します。
hpmstat -g 607 -O threshold_cmp_val=10000 -O
threshold_event_sel=THRESHOLD_COUNT_CYCLES -O
threshold_eve_start_sel=PM_MRK_L1_RELOAD_VALID -O
threshold_eve_stop_sel=PM_MRK_ST_DONE_L2 -O
random_samp_ele_crit=ALL_INSTR
