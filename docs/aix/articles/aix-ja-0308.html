目的
ctsyschk
コマンドは、Reliable Scalable Cluster Technology (RSCT) クラスターをノード上に作成しているときに発生した問題を識別します。

説明
ctsyschk
コマンドは、さまざまな RSCT ベースのクラスタリング・ソリューションにおいて問題を発生させる可能性がある、システム設定およびネットワーキング動作を検証します。 オプションを付けずに
ctsyschk
コマンドを実行すると、コマンドの使用法が出力として表示されます。 ホスト名の指定なしで
ctsyschk
コマンドを実行すると、このコマンドは、ローカル・システム設定を検査します。 1 つ以上のホスト名または IP アドレスを指定すると、
ctsyschk
コマンドは
ssh
または
rsh
などのリモート・シェル・コマンドを実行して、リモート・ターゲットから収集します。
ctsyschk
コマンドは、ローカル・ノード、使用可能なインターフェースとノード ID、およびリモート・ノード上のポート番号可用性に関する情報を使用して、RSCT クラスターでの作成における座標を決定します。
リモート・コマンドを実行するためには、
ctsyschk
コマンドは、ユーザーが以下のいずれかをセットアップすることを必要とします。
パスワードなしの
ssh/rsh
tcl/tk
は、コマンドが実行されるノード上で予期します。 この場合、ユーザー名には
-U
オプション (デフォルトでは
root
) を使用し、すべてのノードへのリモート・ログインのパスワードを指定するには
-P
オプションを使用する必要があります。
制限:
リモート・ログインが機能するためには、すべてのノードが同じユーザー名とパスワードを持っている必要があります。

構文
ctsyschk [ V 値 ] [ -U (U) username ] [ -P password ] [ -C cluster_type ] [ I ip-addr-type ] [ P- checking_subsys_port ] [ -m (M) ] [ N ] [ -s session_auth_type ] node_name1 [ node_name2... ]

オプション
フラグ
-V
ctsyschk
コマンドの詳細メッセージを標準出力に書き込みます。
-U username
リモート・ログインのためのユーザー名を指定します。 デフォルト・ユーザーは
root
です。 複数のノードが入力となっている場合、すべてのノードにおいてユーザー名は 1 つでなければなりません。
-P password
リモート・ユーザーのパスワードを指定します。 パスワードなしのリモート・ログイン (
rsh
または
ssh
) が設定されていない場合は、
-U
オプションで指定されたユーザー名のパスワードを指定する必要があります。 ユーザー名が指定されていない場合は、
root
ユーザーのパスワードを指定する必要があります。 複数のノードが入力となっている場合、すべてのノードにおいて、リモート・ログイン用のパスワードは 1 つでなければなりません。
-C cluster_type
クラスター・タイプを指定します。 有効な値は次のとおりです。
p (ピア・ドメイン)
ctsyschk
コマンドが
cluster_type
オプション
p
で実行されると、以下の項目が検査されます。
指定された入力ノード間に IPv4 接続または IPv6 接続が存在するかどうか。
入力ノードにおける Resource Monitoring and Control (RMC) ポート、High Availability Group Services (HAGS) ポート、または Host Access
Transformation Service (HATS) ポートの可用性。
指定された入力ノード間において、ファイアウォールが RMC ポートに構成されているかどうか。
ノード間の最大伝送単位 (MTU) サイズの互換性。
入力ノードにおけるノード ID の固有性。
m (管理ドメイン)
ctsyschk
コマンドが
cluster_type
オプション
m
で実行されると、以下の項目が検査されます。
RMC ポートの可用性 (論理区画 (LPAR) とハードウェア管理コンソール (HMC) との間で、RMC ポートにファイアウォールが構成されているかどうかを判別)。
LPAR と HMC との間の MTU サイズ互換性。
a (ピア・ドメインおよび管理ドメイン)
ctsyschck
コマンドが
cluster_type
オプション
a
で実行されると、以下の項目が検査されます。
指定された入力ノード間に IPv4/IPv6 接続が存在するかどうか。

指定された入力ノードでの RMC/HAGS/HATS ポートの可用性。
指定された入力ノード間において、ファイアウォールが RMC ポートに構成されているかどうか。LPAR 上の RMC ポートの可用性も検査されます。
LPAR と HMC との間で、ファイアウォールが RMC ポートに構成されているかどうか。
