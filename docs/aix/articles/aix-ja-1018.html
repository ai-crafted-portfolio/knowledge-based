目的
現行の NFSv4 統計情報およびプロパティーを表示または変更します。

説明
nfs4cl
コマンドを使用して、クライアントに関するすべての fsid 情報を
表示するか、fsid のファイルシステム・オプションを変更します。
注:
nfs4cl
更新は、ファイル・システム内の新しくアクセスされるファイルに影響します。 以前にアクセスされたすべてのファイルに影響を及ぼすには、アンマウントおよび
再マウントが必要です。

構文
/usr/sbin/nfs4cl [ サブコマンド ] [ path ] [ 引数 ]

例
クライアント上のすべての fsid 構造を表示するには、次のように入力します。
nfs4cl showfs
/mnt/usr/sbin
のファイルシステム・オプションを、「
retrans=3
」のみを
含むように設定するには、次のように入力します。
nfs4cl setfsoptions /mnt/usr/sbin retrns=3
/mnt/use/sbin
のファイルシステム・オプションをリセットするには、
次のように入力します。
nfs4cl resetfsoptions /mnt/user/sbin
/mnt/usr/sbin
の
df
コマンド出力を
表示するには、次のように入力します。
nfs4cl showstat /mnt/usr/sbin
/mnt/usr/sbin
で複製が行われたときに、クライアントがサーバー
boo
にフェイルオーバーするようにするには、次のように入力します。
nfs4cl setfsoptions /mnt/usr/sbin prefer=boo
