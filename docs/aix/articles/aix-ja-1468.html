目的
nroff
コマンド・ファイル内の
.so
要求を処理します。

説明
ソエリム
コマンドは、指定されたファイルまたは標準入力を読み取り、
NROFF
コマンドおよび次の形式の
トロフ
コマンド要求によって指定された組み込みを実行します。
.so filename
要求が入力行の先頭に表示される場合。
.so
要求の後でファイル名の前に、ASCII スペースと ASCII タブ文字のあらゆる組み合わせを続けることができます。 ファイル名の後には文字を入れないでください。
tbl
コマンドなどのコマンドは通常は処理中にファイルへの組み込みを実行しないため、
soelim
コマンドは便利です。
-
(負符号 (-)) フラグが指定されると、標準入力に対応するファイル名が組み込まれます。

構文
ソエリム [ ファイル ... | - ]

オプション
フラグ
項目 | 説明
- | 標準入力に対応するファイル名を示します。
“
注:
組み込みは、以下の代わりに
(単一引用符) を使用することによって抑止できます。
.
(ピリオド)。以下のとおりです。
”

例
以下は
soelim
コマンドの使用例です。
soelim exum?.n | tbl | nroff -ms -Tlp | col -Tlp | pg
上記の例では、
soelim
コマンドを使用して、ファイル組み込み (
.so
) 要求を前処理できます。 次に、出力は
tbl
コマンドへ渡されます。 これによって、大規模な文書を作成する場合に組み込まれるテーブルを、別々のファイル内に簡単に入れることができます。
