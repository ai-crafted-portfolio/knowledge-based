目的
Server Message Block (SMB) クライアント・ファイルシステムのマウント操作の統計情報を表示します。

説明
smbcstat
コマンドは、SMB クライアント・ファイルシステムのマウント操作の統計情報を表示します。 マウントされた特定のリモート・ディレクトリー、特定のマウント・ポイント、または論理区画内のすべてのマウント・ポイントの統計情報を表示できます。 オプションを指定しない場合、
smbcstat
コマンドは、論理区画内のすべての SMB マウント・ポイントの統計情報をリストします。

構文
/usr/sbin/smbcstat [-l] [-s <remote share> | -d <mount point>]

オプション
フラグ
-
マウントポイント
この操作に引数として指定された SMB マウント・ポイントの統計情報をリストします。
-l
すべての SMB マウント・ポイントの統計情報をリストします。
-
リモートシェア
この操作に引数として指定されたリモート・マウント・ポイントのマウント統計情報をリストします。

例
SMB クライアント・ファイルシステム内のすべてのマウント・ポイントの統計情報をリストするには、次のコマンドを入力します。
smbcstat -l
SMB プロトコル・バージョン 2.1 の場合、このコマンドは以下の例のような出力を表示します。

User Name : braz2lpa2usr1
Domain Name : SMB_30_2.DEV

User Id : 0
Mode : 0
SPN : cifs/llm141.in.ibm.com
----------------------------
Total Number of SMB Client Filesystem Mounts : 1
