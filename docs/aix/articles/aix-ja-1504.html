目的
アクティブな
ワークロード・パーティション
を非アクティブにします。

説明
stopwpar
コマンドは、実行中の
ワークロード区画
を非活動化します。 これには、以下のタスクの停止が含まれます。
ワークロード・パーティション
内で実行中のプロセスの停止。
ワークロード・パーティション
の WLM クラスのアンロード (ある場合)。
ワークロード・パーティション
の IP アドレスの非アクティブ化 (ある場合)。
ワークロード・パーティション
のファイル・システムをアンマウントします (存在する場合)。
システム
ワークロード・パーティション
を再始動しています。
アプリケーション
ワークロード・パーティション
を削除しています。
stopwpar
コマンドは、以下の状況では失敗します。
指定された
ワークロード・パーティション
は存在しません。
kill
コマンドで 1 つ以上のプロセスを停止できません (強制的に実行するには、
-F
フラグを使用します)。
1 つ以上のファイルシステムをアンマウントできません (強制するには、
-F
フラグを使用します)。

構文
/usr/sbin/stopwpar [ -h | -F ] [ -r ] [ -t 秒 | -N ] [ -v ] WparName

オプション
フラグ
項目 | 説明
-F | ワークロード・パーティション を強制的に停止し、実行中のプロセスをより積極的にシグナル通知して、リモート・ファイル・システムをアンマウントします。 プロセスを停止できない場合、 ワークロード区画 は Broken 状態のままになり、再始動できません。
-h | ハード・ストップを使用して、 ワークロード・パーティション サブシステムに終了をシグナル通知します。 ハード・ストップ使用時の、デフォルトのタイムアウト値は 60 秒です。
-N | タイムアウトなしにシャットダウン/停止が完了することを指定します。
-r | すべての停止操作が完了した後、 ワークロード・パーティション を再始動します。 これは、 stopwpar コマンドの後に startwpar コマンドを呼び出すのと同等です。 このフラグは、アプリケーション ワークロード・パーティション には無効です。
-t 秒 | コマンドが失敗し、プログラムが終了するまでに、シャットダウン/停止が完了するのを待つタイムアウトの長さ (秒数) を指定します。 デフォルトは、シャットダウン/停止が完了しなかった場合に、600 秒後の失敗です。
-v | 詳細出力を表示することを指定します。

例
ロイ
という名前の
ワークロード・パーティション
を停止するには、次のように入力します。
stopwpar roy
85 秒後に
ピント
と呼ばれる
ワークロード・パーティション
のシャットダウン処理を中止するには、次のように入力します。
stopwpar -t 85 pinto
