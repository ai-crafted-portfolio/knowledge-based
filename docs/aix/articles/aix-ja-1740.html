目的
ドラフトの後処理のためのプロンプト・インターフェースを開始します。

説明
whatnow
コマンドは、メッセージの後処理用のインターフェースを提供します。 デフォルトでは、インターフェースは現行ドラフト・メッセージ上で操作されます。
whatnow
コマンドを入力すると、ユーザーはこのインターフェースに入ることができ、システムは下記のプロンプトを戻します。
What now?
インターフェース内では、
whatnow
サブコマンドを使用してメッセージ・ドラフトを操作することができます。 サブコマンドのリストを表示するには、次の画面で Enter キーを押します。
What now?
できます。 インターフェースを終了するには、
q
.

構文
Whatnow [ { -draftfolder + フォルダー | -nodraftfolder | ファイル } { -draftmessage メッセージ | ファイル } ] [ -エディター 編集者 | -noedit (編集不可) ] [ -prompt ストリング ]

オプション
フラグ
項目 | 説明
-draftfolder + フォルダー | メッセージの入っているフォルダーを指定します。 デフォルトでは、システムは UserMhDirectory /draft ファイルを使用します。 -draftfolder + folder フラグの後にメッセージを指定すると、 -draftmessage フラグを使用した場合と同じになります。
-draftmessage メッセージ | ドラフト・メッセージを指定します。
-editor エディター | editor 変数の値がメッセージの構成または改訂用の初期エディターであることを指定します。
-help | これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。 “ 注: MH の場合は、このフラグ名を省略することはできません。 ”
ファイル | ユーザーが選択したドラフト・ファイル。
message | メッセージを指定します。 以下の参照を使ってメッセージを指定します。 Number メッセージ番号。 cur または 。 (ピリオド) 現行メッセージ。 これはデフォルトです。 first フォルダー内の最初のメッセージ last フォルダー内の最後のメッセージ 次へ 現行メッセージの次のメッセージ prev 現行メッセージの直前のメッセージ。 -ノドラフトフォルダー ドラフトを UserMhDirectory /draft ファイルに入れます。 -noedit (編集しない) 初期編集を抑制します。 -prompt 文字列 指定した文字列をプロンプトとして使用します。 デフォルトのストリングは次のとおりです。 What now? .
