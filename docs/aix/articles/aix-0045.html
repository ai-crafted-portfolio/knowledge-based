目的

これは Advanced Crypto Facility (ACF) のチューナブル・パラメーターを管理します。

構文

acfo [-d] | [-d -t tunable_name]
acfo -R
acfo -r tunable_name
acfo -p [-R | -r -t tunable_name] | [-t tunable_name=value]
acfo -t tunable_name=value
acfo [-h] | [-h -t tunable_name]

説明

acfo コマンドは、ACF の現行チューナブル・パラメーターと永続チューナブル・パラメーターを表示または変更できます。 ACF チューナブル・パラメーターは、Public Key Cryptography Standard (PKCS) #11 によって指定されるカーネル暗号 API でネスト (NX) アクセラレーションまたはメモリー内暗号アクセラレーションを使用する必要があるかどうかを決定します。

現在、 NX アクセラレーションおよびメモリー内暗号アクセラレーションでは、PKCS #11 サブシステムに対して Advanced Encryption Standard (AES) のみがサポートされています。

NX暗号アクセラレーションは、POWER7+プロセッサーベースのサーバーでサポートされています。 インコア暗号アクセラレーションは、POWER8プロセッサー搭載サーバー以降でサポートされる。 サーバーがメモリー内暗号アクセラレーションをサポートしていない場合は、メモリー内暗号アクセラレーションはオンにできません。

カーネル暗号 API は、暗号化ファイル・システム (EFS)、IP セキュリティー (IPSec)、論理ボリューム暗号化、カーネル・エクステンション、および AIX® PKCS #11 API オブジェクト /usr/lib/pkcs11/ibm_pks11.soを使用するユーザー・スペース・アプリケーションで使用されます。

acfo コマンドの実行時には、PKCS #11 デバイス・ドライバーがアクティブになっていなければなりません。

永続チューナブル・パラメーター値は、リブート操作中にチューナブル・パラメーターが保持する値です。 永続チューナブル・パラメーター値は、ODM データベースに保管されます。 CFG_INIT コマンドがチューナブル・パラメーターを初期化するために実行される場合、これらの値は PKCS #11 デバイス・ドライバーによって使用されます。

acfo コマンドは、システム全体のチューナブル・パラメーターにのみ影響します。 そのため、acfo コマンドはワークロード区画 (WPAR) 環境ではサポートされません。
注: 複数のカーネル暗号操作が進行中の場合、管理者は NX またはメモリー内の暗号アクセラレーション設定を変更してはなりません。 acfo コマンドの -p パラメーターを使用して加速設定を永続的に変更してから、論理区画を再始動して変更を適用します。

フラグ

-a
これは、すべての ACF チューナブル・パラメーターの値を 1 行に 1 つずつ表示します。
-d
これは、ACF チューナブル・パラメーターの名前と現行値をすべて表示します。 -d フラグを -t フラグと一緒に使用した場合、acfo コマンドは指定のチューナブル・パラメーターの現行値を表示します。
-h
これは、コマンドとその引数に関するヘルプ情報を表示します。 -t フラグを -h フラグと一緒に使用した場合、このコマンドは特定チューナブル・パラメーターに関するヘルプ情報を表示します。
-p
これは、チューナブル・パラメーターの現行値とリブート値を永続的に変更します。 -p フラグを指定しない場合は、チューナブル・パラメーターの現行値のみが変更されます。 変更はリブート操作には適用されません。
-R
これは、すべてのチューナブル・パラメーターをデフォルト値にリセットします。
--r チューナブル
これは、指定のチューナブル・パラメーターをデフォルト値にリセットします。
-t チューナブル [=新しい値]
これは、指定のチューナブル・パラメーターの現行値を表示するか、またはそのチューナブル・パラメーターを指定の値に設定します。

チューナブル・パラメーター

AFC チューナブル・パラメーターのデフォルト値および値範囲については、acfo -h -t tunable_name コマンドを実行してください。 有効なチューナブル・パラメーター名を以下に示します。

nx_enabled
これは NX 暗号アクセラレーションを指定します。 値が 1 の場合は、NX 暗号アクセラレーションが有効になります。 値が 0 の場合は、NX 暗号アクセラレーションが無効になります。
min_sz
これは、NX 暗号アクセラレーションに適した最小データ・サイズ (バイト) を指定します。 アクセラレーション要求において、必要となるデータが指定の最小値より小さい場合は、汎用 CPU によって実行される暗号ソフトウェア・メソッドなどのソフトウェア実装が使用されます。 このチューナブル・パラメーターは、NX 暗号アクセラレーションに関してのみ適用できます。
in_core_enabled
これはメモリー内暗号アクセラレーションを指定します。 値が 1 の場合は、メモリー内暗号アクセラレーションが有効になります。 値が 0 の場合は、メモリー内暗号アクセラレーションが無効になります。 このチューナブル・パラメーターは nx_enabled チューナブル・パラメーターに優先します。

セキュリティー

注: acfo コマンドを実行できるのは root ユーザーのみです。

例

  1. AFC チューナブル・パラメーター名と、対応する現行値をすべて表示するには、以下のコマンドを実行します。
    acfo -d
nx_enabled              : 1.
min_sz                  : 1024.
in_core_enabled         : 0.
  2. AFC NX 暗号アクセラレーションの最小データ・サイズを 1024 バイトの非永続値に設定するには、以下のコマンドを実行します。
    acfo -t min_size=1024
  3. NX 暗号アクセラレーションを永続的にオフにするには、以下のコマンドを実行します。
    acfo -p -t nx_enabled=0
