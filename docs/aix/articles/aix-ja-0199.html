目的
ユーザーのパスワードを変更します。

説明
chpasswd
コマンドは、ユーザーのパスワードを管理します。 root ユーザーは、標準入力によって
指定されたユーザーのパスワードを提供または変更できます。 入力の各行は、それぞれ次のフォーマットである
必要があります。
username:password
このコマンドを使用してパスワードを設定できるのは、root ユーザーのみです。
デフォルトでは、
chpasswd
コマンドはユーザーの ADMCHG フラグを設定します。
-f
オプションを他の有効なフラグと一緒に使用して、デフォルトをオーバーライドすることができます。
-c
オプションは、すべてのパスワード・フラグをクリアします。
パスワード・フィールドは、平文でもかまわないし、暗号アルゴリズムを使用して暗号化された値でも
かまいません。
-e
オプションは、パスワードが暗号化形式であることを示します。 なお、バッチ内のパスワードは、すべてが同じフォーマットに準拠する必要があることに
注意してください。
LDAP ユーザー・パスワードを ldap_auth 環境で設定するには、
chpasswd
コマンドを使用し、
-R
LDAP
を指定します。 ただし、暗号化フォーマットに
-e
オプションを指定する場合は、
chpasswd
コマンドの暗号化フォーマットと LDAP サーバーの暗号化フォーマットが一致している必要があります。

構文
chpasswd [ -R load_module ] [[ -e ][ -f フラグ -c ]

オプション
フラグ
項目 | 説明
-c | すべてのパスワード・フラグをクリアします。
-e | パスワードが暗号化されたフォーマットであることを指定します。
-f フラグ | 設定するパスワード・フラグをコンマで区切ったリストを指定 します。 有効なフラグ値は、ADMIN、ADMCHG、または NOCHECK、およびそのすべてです。 これらの値について詳しくは、 pwdadm コマンドの資料を参照してください。
-R ロード・モジュール | ユーザーのパスワードを変更する場合に使用するロード可能 I&A モジュールを 指定します。

例
コマンド・ラインからユーザーのパスワードを設定する場合は、次のように入力します。
chpasswd
その後に、各行ごとに一対ずつ
username:password
対の入力を
続けます。 終了したら、CTRL+D を入力します。
user1:passwd1
user2:passwd2
CTRL+D
mypwdfile
という名前のファイルに含まれるユーザーのパスワードを設定するには、次のように入力します。
cat mypwdfile | chpasswd
mypwdfile
には
username:password
ペア (1 行に 1 つのペア) が含まれている必要があることに注意してください。 次に例を示します。
user1:passwd1
user2:passwd2
...
