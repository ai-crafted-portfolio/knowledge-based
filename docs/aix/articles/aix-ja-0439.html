コマンドのエラーとなる。

構文
epkg [ -w WorkDirectory ] [ -a APARrefFile ] [ -p PrerequisiteFile ] [ -d DescriptionFile ] [ -e interimfixControlFile ] [ -g PrerequisiteFile ] [ -l LockFile ] [ -S SupersedeFile ] [ -u {y|n} ] ] [ -r {y|n|o} ] [ -s ] [ -T {y|n} ] [ -X ] [ -v ] interimfixLabel

オプション
フラグ
表3. フラグ
項目 | 説明
-a APARrefFile | 1つ以上のAPAR参照番号を含むファイルを指定する。
-d DescriptionFile | 中間修正 の説明を含むファイルを指定します。
-e interimfixControlFile | 暫定修正 の構成方法を制御する 暫定修正 制御ファイルを指定します。
-g PrerequisiteFile | 暫定修正 ラベル名を含む 暫定修正 前提条件ファイルの場所を指定します。 これらのラベルは、 暫定修正 パッケージをインストールする前に必要です。
-l LockFile | パッケージ名が入っているロックされたファイルの位置を指定します。 これらのパッケージは、' emgr コマンドでロックされるか、ファイルの所有権に基づいて自動的にロックされる。
-p PrerequisiteFile | インストール前提条件を含むファイルを指定します。
-r {y|n|o} | epkg ' REBOOT 属性を設定する。 これにより、「 emgr コマンドはブートイメージに必要な変更を加え、インストール後に再起動を指示するメッセージを発行する。 y 引数は、リブートとボスブートが必要であることを指定する。 引数 n は、再起動が不要であることを指定する。 o 引数は再起動が必要であることを示すが、' emgr bosbootを呼び出してはならない。
-S SupersedeFile | 暫定修正 ラベル名が入っている 暫定修正 置き換えファイルの場所を指定します。 これらのラベルは、' epkg がインストールされたときに置き換えられる。
-s | epkg コマンドは、スクリプトと前提条件ファイルに関する質問をスキップする。
-T | この 暫定修正 がテストされたかどうかを示します。 有効な値は yes または no である。 デフォルトは no です。
-u { はい | いいえ } | 既存の 中間修正 コントロールファイルを使用するかどうかを指定します。
-v | epkg コマンドが拡張オプションに関してさらに質問を加えます。 このオプションには、すべての 中間修正 ファイルのパーミッションを指定する質問が含まれています。
-w WorkDirectory | epkg コマンドが使用する代替作業ディレクトリを指定する。 デフォルトの作業ディレクトリーは $HOME/epkgwork です。

-X | emgr コマンドは、 暫定修正 がインストールされたときに、スペースが必要で拡張が可能であれば、ファイルシステムを自動的に拡張するようにする。
