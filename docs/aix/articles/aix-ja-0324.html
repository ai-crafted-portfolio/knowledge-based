目的
動的 DNS (DDNS) 更新を保護するためのトランザクション署名 (TSIG) 用の鍵を生成します。

説明
tsig-keygen
」と「
ddns-confgen
コマンドは、TSIG署名に使える鍵を生成するユーティリティの呼び出しメソッドである。 生成された鍵は、ゾーンの動的なドメイン名システム(DNS)更新や「
rndc
コマンドチャネルの安全性を確保するために使用できる。
tsig-keygen
コマンドを実行するときに、生成される鍵の名前として使用する必要があるドメイン・ネームを指定できます。 名前を指定しない場合、生成されるキーのデフォルト名は「
tsig-key
である。
ddns-confgen
コマンドを実行すると、生成されたキーに、ダイナミックDNSをセットアップする際に「
nsupdate
」と「
named
コマンドで使用できる設定テキストと指示が添付される。 生成されたキーには、「
update-policy
ステートメントの例も添えられている。 この使用法は、コマンド・チャネル・セキュリティーをセットアップするための
rndc-confgen
コマンドと似ています。
named
コマンドを実行し、「
nsupdate -l
コマンドを使ってローカルDDNSキーを設定することができる。 ただし、このコマンドは、ゾーンが'
update-policy local
コマンドで設定されている場合に使用できる。
ddns-confgen
コマンドは、より詳細な構成が必要な場合にのみ実行してください。 例えば、
nsupdate
コマンドをリモート・システムから使用する必要がある場合などです。

構文
tsig-keygen [ -a アルゴリズム ] [ -h ] [名前］ ddns-confgen [ -a algorithm ] [ -h ] [ -k keyname ] [ -q ] [ -s name ] [ -z zone ] ]

オプション
フラグ
-a
アルゴリズム
TSIGキーに使用しなければならないアルゴリズムを指定する。 以下のアルゴリズムが利用可能なオプションである：
hmac-md5
hmac-sha1
hmac-sha224
hmac-sha256
hmac-sha384
hmac-sha512
デフォルトのオプションは「
hmac-sha256
である。 オプションは大文字小文字を区別せず、接頭辞「
hmac-
」は省略できる。
-h
オプションと引数の簡単な要約を出力します。
-k
キー名
DDNS認証鍵の鍵名を指定します。
-s
または '
-z
フラグを指定しない場合、デフォルト値は '
ddns-key
となる。 そうでない場合、デフォルト値は'
ddns-key
後にオプションの引数が続く。 例えば、'
ddns-key.example.com
. キー名は、文字、数字、ハイフン、およびピリオドで構成される有効なドメイン・ネームの形式でなければなりません。
-q
(
ddns_confgen
のみ)
説明文や使用例を表示せず、キーのみを表示するクワイエットモードを有効にする。
-s
name
(
ddns_confgen
のみ)
単一ホスト名の動的更新を示す構成例を生成します。 例 '

name
name タイプを使用して、指定された名前に更新ポリシーを設定する方法を示しています。 デフォルトのキー名は「

self

zone
(
ddns_confgen
のみ)
ゾーンの動的更新を示す構成例を生成します。 例の

テキストは、
zonesub
名前タイプを使用して、指定されたゾーンの更新ポリシーを設定する方法を示しています。 そのゾーン内のサブドメイン名を更新することもできます。 このフラグを
-z
フラグと一緒に使用することはできません。
