目的
unfencevsd
-1 つのノードまたはノード・グループで実行されているアプリケーションが、それらのノードで実行されているアプリケーションから以前に隔離された仮想共用ディスクまたは仮想共用ディスク・グループにアクセスできるようにします。

説明
特定の環境化で、システムはノードが作動不能になったと判断し、
ノードが実際には作動可能であるが、同一のアプリケーションを実行している
他のノードとの通信からはカットオフされている時に、リカバリー手順を開始することがあります。 この場合、
リカバリーが完了して、そのアプリケーションを実行している他のノードが問題ノードを作動可能と認識するまでは、
問題ノードに、それが通常管理している仮想共有ディスクへの要求の処理を許可してはなりません。
fencevsd
コマンドは、問題のノードがその仮想共用ディスクの要求を満たすことができないようにします。
unfencevsd
コマンドを使用すると、fenced ノードが仮想共用ディスクへのアクセスを取り戻すことができます。
このコマンドは、
ピア・ドメイン内でオンラインとなっている任意のノードから実行することができます。

構文
unfencevsd { -a | -v vsd_name_list } { -n node_list [ -f ]}

オプション
フラグ
-a
すべての仮想共有ディスクを指定します。
-f
分離されたノードがそれ自身を分離解除することを許可します。
-
ノードリスト
コンマで区切られた 1 つ以上のノード番号を指定します。
-
vsd_name_list
コンマで区切られた 1 つ以上の仮想共有ディスク名を指定します。

例
ノード 5 を、仮想共有ディスク vsd1 および vsd2 から分離解除するには、次のように入力します。
unfencevsd -v vsd1,vsd2 -n 5
unfencevsd
コマンドをノード 7 から入力する必要があるときに、仮想共用ディスク vsd1 および vsd2 からノード 7 を分離解除するには、次のように入力します。
unfencevsd -v vsd1,vsd2 -n 7 -f
