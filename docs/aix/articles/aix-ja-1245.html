目的
システム
ワークロード・パーティション
を停止して再始動します。
制約事項:
rebootwpar
コマンドは、アプリケーション・
ワークロード・パーティション
では実行できません。

説明
rebootwpar
コマンドは、
ワークロード・パーティション
を停止して再始動します。

構文
リブート・パラメーター [ -F | -h ] [ -N | -t seconds ] [ -v ] WparName

オプション
フラグ
項目 | 説明
-F | 強制停止を指定します。
-h | ハード・ストップを指定します。
-N | 停止のタイムアウトがないことを指定します。
-T seconds | 停止のタイムアウト (秒) を指定します。
-v | 詳細モード。
WparName | ワークロード区画名を指定します。

例
"MyWpar", という
ワークロードパーティションを
再起動するには、次のように入力する：
rebootwpar MyWpar
