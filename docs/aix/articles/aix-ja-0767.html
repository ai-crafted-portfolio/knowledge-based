目的
フィルター・テーブルまたは IP セキュリティー・サブシステムのいずれかのフィルター・ルールをリストします。

説明
lsfilt
コマンドは、
フィルター・ルールとその状況をリストします。
注:
フィルターの説明フィールドはカーネルにリストされません。 アクティブまたは動的なフィルター・ルールがリストされる場合には、フィルターの記述テキストは
表示されません。

構文
lsfilt -v 4 | 6 [ -n fid_list ] [ -a ] [ -d ]

オプション
フラグ
項目 | 説明
-a | アクティブなフィルター・ルールだけをリストします。 アクティブなフィルター・ルールとは、 現行フィルター・カーネルにより使用されている規則のことです。 このフラグを省略すると、 フィルター・ルール・テーブル内のすべてのフィルター・ルールがリストされます。
-d | Internet Key Exchange (IKE) トンネルに使用する動的フィルター・ルールをリストします。 このテーブルは、 IKE ネゴシエーションにより IP セキュリティー・トンネルの作成が開始される時に動的に作成され、 対応するフィルター・ルールが動的 IKE フィルター・テーブルに追加されます。
-n | 表示するフィルター・ルールの ID を指定します。 fid_list は、スペースまたは「 , 」または「 - 」で区切られたフィルター ID のリストです。 -n は、アクティブなフィルター規則用ではありません。 このフラグは、 -a フラグと一緒には使用できません。
-v | リストしたいフィルター・ルールの IP バージョンです。 このフラグの有効な値は 4 および 6 です。 このフラグを使用しない場合は、IP バージョン 4 と IP バージョン 6 の両方がリストされます。
