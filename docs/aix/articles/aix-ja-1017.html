目的
NFS および NIS 操作を停止します。

説明
/etc/nfs.clean
コマンドは、 NFS、NIS、またはその両方の操作をシャットダウンするために使用します。 このスクリプトは
shutdown
コマンドによって使用されますが、 NFS または NIS のみの操作を停止するために使用できます。 デフォルトでは、すべての NFS および NIS デーモンが停止されます。
nfs.clean
コマンドは正しい順序でデーモンをシャットダウンするため、
stopsrc -g nfs
を使用する代わりにこのコマンドを使用することをお勧めします。
stopsrc
コマンドには、グループのデーモンを適切な順序で停止するという概念はありません。 これにより、
statd
および
lockd
デーモンが実行中で、
statd
デーモンが
lockd
デーモンの前に停止した場合に、問題が発生する可能性があります。

構文
/etc/nfs.clean [ -d ][ -y ][ -t nfs|nis]

オプション
フラグ
項目 | 説明
-d | サーバー固有のデーモンのみを停止します。 クライアントで実行されている可能性のあるデーモンは停止されません。
-y | サーバー固有の NIS デーモンのみを停止します。 このフラグは、 -d フラグが使用されている場合に想定されます。
-t | 指定したシステムのみを停止します。 -t nfs を指定した場合は、 NFS デーモンのみが停止されます。 -t nis を指定すると、NIS デーモンのみが停止されます。

例
すべての NFS および NIS デーモンを停止するには、次のように入力します。
/etc/nfs.clean
NFS のみを停止するには、次のように入力します。
/etc/nfs.clean -t nfs
NFS サービス・デーモンのみを停止するには、次のように入力します。
/etc/nfs.clean -d -t nfs
