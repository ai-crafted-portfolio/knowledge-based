目的

Light Directory Access Protocol（ LDAP ）サーバー上の集中管理場所へ、 AIX Security ExpertのXML設定ファイルをアップロードしたり、そこからダウンロードしたりします。

構文

AIXPERTLDAP -ウー -D Binddn -w (W) BindPWD [ -b ベース DN ] [ 「-f」 ファイル名 ] [ - ラベル ]

AIXPERTLDAP -d 年 -D Binddn -w (W) BindPWD [ -b ベース DN ]

aixpertldap [ -? ]

説明

` aixpertldap ` コマンドを使用すると、システム管理者は、 LDAP サーバー上の集中管理された場所に、 AIX Security ExpertのXML設定ファイルを保存することができます。 これらの構成ファイルを共有することにより、 似た環境で作動する似たシステムが、簡単にこれらのセキュリティー・ポリシー (XML 構成ファイル) をダウンロードし、 aixpert コマンドを使って適用することができます。 このようにして、似たセキュリティー要件を持つシステムが、同じように構成されます。

このコマンドを実行して、 LDAP サーバーから AIX Security Expertのセキュリティポリシー設定ファイルをダウンロードすると、これらのファイルはローカルの /etc/security/aixpert/ldap ディレクトリに保存されます。 システム管理者はこれらのファイルをスキャンし、 関連ファイルを選択し、aixpert コマンドの -f オプションを使用して、 ファイルに指定されているセキュリティー設定を適用します。

ヒント: LDAP サーバーに XML 構成ファイルを保管するか、またはそこから取得するために、このコマンドは、既存の LDAP セットアップと共に、実行中の LDAP クライアントのバインディング識別名とバインディング・パスワードを使用します。

フラグ

項目
説明
-D binddn LDAP サーバーに接続するための バインディング識別名を指定します。
-w (W) BindPWD LDAP サーバーから XML 構成ファイルを読み取ったり、または書き込んだりするための バインディング・パスワードを指定します。
-b ベースn XML 構成ファイルが集中して保管されている場所を指定します。

  • XML ファイルのアップロード中に basedn パラメーターを指定した場合、XML ファイルは basedn パラメーターで指定された場所に保管されます。それ以外の場合、ファイルはデフォルトの basedn 値 cn=aixdataで指定された場所に保管されます。

    例えば、basedn パラメーターを "ou=Austin,o=ibm,c=US" と指定すると、 aixpertldap コマンドは、 XML 構成ファイルを "ou=aixpert,ou=Austin,o=ibm,c=US" 識別名 (DN) の下に保管します。

  • XML ファイルのダウンロード中に basedn パラメーターを指定すると、 aixpertldap コマンドは特定の DN の下で XML ファイルを検索します。 このパラメーターを指定しない場合、その XML ファイルを検索するために、デフォルトの basedn 値 (cn=aixdata) が使用されます。

    例えば、basedn パラメーターを指定しない場合、 aixpertldap コマンドは、デフォルトの basedn 値: ou=aixpert, ou=aixdata の下で XML ファイルを検索します。
-d XML 構成ファイルを LDAP サーバーからローカルの /etc/security/aixpert/ldap ディレクトリーにダウンロードします。
-f ファイル名 LDAP サーバーにアップロードする XML 構成ファイルの絶対パスを指定します。

このオプションを指定しない場合、 デフォルトでは /etc/security/aixpert/core/appliedaixpert.xml ファイルが LDAP サーバーにアップロードされます。

制約事項: f オプションと d オプションを同時には使用できません。
-l ラベル アップロード中の XML 構成ファイルの内容についての簡略な説明を記述します。 このオプションを使用しない場合、XML ファイルのホスト名がラベルとして指定されます。

例えば、XML ファイルに会計部門 (Accounts department) のセキュリティー設定が含まれている場合、 ラベルには AccountsDept と指定されます。

制約事項: l オプションと d オプションを同時には使用できません。
-u XML 構成ファイルを LDAP サーバーにアップロードします。
-? コマンドの使用方法の説明文を表示します。

終了状況

項目
説明
0 成功。
1 失敗、または一部失敗。

セキュリティー

root ユーザーだけが aixpertldap コマンドを実行できます。

例

  1. NetworkSecurity ラベルを持つ ou=aixpert, ou=Bangalore,o=ibm,c=IN DN の下に /home/hussain/netwsec.xml ファイルをアップロードするには、次のコマンドを使用します。
    aixpertldap –u –D binddn -w secret –b ou=Bangalore,o=ibm,c=IN 
–f /home/hussain/netwsec.xml –l NetworkSecurity
  2. すべての XML ファイルを ou=aixpert, ou=Bangalore,o=ibm,c=IN DN から /etc/security/aixpert/ldap ディレクトリーにダウンロードするには、次のコマンドを使用します。
    aixpertldap –d –D binddn -w secret –b ou=Bangalore,o=ibm,c=IN
  3. ou=aixpert, cn=aixdata DN から XML ファイルをダウンロードするには、次のコマンドを使用します。
    aixpertldap -d –D binddn -w secret

ファイル

項目
説明
/etc/security/aixpert/ldap ダウンロード済みの XML 構成ファイルを保管します。
