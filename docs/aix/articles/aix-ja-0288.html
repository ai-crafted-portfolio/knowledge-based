目的
クラスター管理グループを定義します。

説明
ctadmingroup
コマンドは、クラスター管理グループを定義するために使用します。 このコマンドはトレース・ファイルのグループ所有権を設定します。従って、クラスター管理グループに属するユーザーには、Reliable Scalable Cluster Technology (RSCT) サブシステムが作成したトレース・ファイルを調べるアクセス権があります。
ctadmingroup
は、既存のトレース・ファイルを新しい許可およびグループ所有権に変更します。
ctadmingroup
コマンドの実行後に作成されるトレース・ファイルには、新しい許可が含まれています。 このコマンドは、指定されたグループを作成することもしなければ、ユーザーをグループに追加することもしません。単に、このグループのユーザーにトレース・ファイルへのアクセスを与えるのみです。
以下を指定して
ctadmingroup
コマンドを実行するとします。
別のグループ名、指定された新しいグループがクラスター管理グループとなり、前のグループに置き換わります。
フラグ
・
オプション
なし、またはパラメーターなし、クラスター管理グループのグループ名と ID を表示します。 クラスター管理グループが定義されていない場合は、このコマンドは何の出力も出しません。
-u
flag
オプション
。クラスター管理グループを除去します。 グループが除去された後は、そのグループに属するユーザーはトレース・ファイルを調べることができなくなる可能性があります。 クラスター管理グループが定義されていない場合は、このコマンドは何の出力も出しません。
セキュリティー・サブシステムのトレース・ファイルのロケーションが構成可能である。 トレース・ファイルの場所を判別するために、
ctadmingroup
コマンドは、
/var/ct/cfg/ctcasd.cfg
ファイル (存在する場合) および
/opt/rsct/cfg/ctcasd.cfg
ファイルに情報を要求します。

構文
グループを定義するには、次のようにします。 ctadmingroup [ -h ] [ -TV ] グループ名 グループを除去するには、次のようにします。 ctadmingroup -u [ -h ] [ -TV ] [グループ名］

オプション
フラグ
-u
クラスター管理グループを除去します。 グループが除去された後は、そのグループに属するユーザーはトレース・ファイルを調べることができなくなる可能性があります。 クラスター管理グループが定義されていない場合は、このコマンドは何の出力も出しません。
-h
コマンドの使用方法の文を標準出力に書き込みます。
-T
標準エラーにコマンドのトレース・メッセージを書き込みます。 これはソフトウェア・サービス組織専用です。
-V
コマンドの詳細メッセージを標準出力に書き出します。

例
