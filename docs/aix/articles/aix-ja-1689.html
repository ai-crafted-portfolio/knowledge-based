目的
BNU ファイル転送の状況に関する定期的な情報を提供します。

説明
/usr/sbin/uucp/uudemon.admin
コマンドは、
基本ネットワーク・ユーティリティー (BNU) のアクティビティーに関する状況情報を、
/var/spool/cron/crontabs/uucp
ファイルに指定した間隔で、
uucp
ログイン ID にメールするシェル・プロシージャーです。 このコマンドは、
uustat -p
コマンドおよび
uustat -q
コマンドの両方を、以下のように実行します。
P-
フラグは、ロック・ファイル内のすべてのプロセス ID (PID) 番号に対して
ps-flp
コマンド (指定されたプロセス ID の完全な長いリストを生成するプロセス状況) を実行するように
ウスタット
コマンドに指示します。
-Q (Q)
フラグは、各システムで実行するために現在キューに入れられているジョブをリストします。 これらのジョブは、実行待ちか、プロセスの実行中のいずれかです。 システム用の状況ファイルがあるときは、その日時、状況情報が通知されます。
uudemon.admin
コマンドは、少なくとも 1 日に 1 回は実行してください。
uudemon.admin
コマンドは、BNU プログラムのインストール時は使用可能ではありません。 このコマンドを自動的に実行させるには、
/var/spool/cron/crontabs/uucp
ファイルを編集して、
uudemon.admin
コマンドの実行を管理する行の先頭のコメント文字 (#) を除去します。

構文
uudemon.admin

例
uudemon.admin
コマンドを自動的に実行させるには、
/var/spool/cron/crontabs/uucp
ファイルを編集し、
uudemon.admin
コマンド・ラインの先頭からコメント文字 (#) を除去します。 変更:
#48 8,12,16 * * * /usr/bin/sh -c
"/usr/sbin/uucp/uudemon.admin > /dev/null"
to:-->
48 8, 12, 16 * * * /usr/bin/sh -c "/usr/sbin/uucp/uudemon.admin > /dev/null"
この
48
表記は分を表します。
8,12,16
表記は 24 時間クロックに基づいて時間を表し、3 つのアスタリスク (
* * *
) それぞれ、月の日、年の月、および曜日を表すプレースホルダーです。 したがって、この行は、
cron
デーモンに対して、
uudemon.admin
コマンドを毎日 0800、1200、および 1600 の 48 分後、つまり 8:48 a.mに実行するように指示します。 12:48 p.m.、 および 4:48 p.m., です。
注:
これらの実行間隔はデフォルトです。 これらを変更すれば、
cron
デーモンが
uudemon.admin
コマンドを実行する時刻を、
サイトの必要に応じて変更することができます。
