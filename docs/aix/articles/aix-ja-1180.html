目的
Tektronix 4014 ファイルを PostScript 形式に変換します。

説明
ps4014
コマンドは、Tektronix 4014 フォーマットのファイルを読み取り、 PostScript プリンターで印刷するために PostScript フォーマットに変換します。 ファイルを指定しないと、標準入力が使用されます。 結果の PostScript ファイルは、標準出力または名前付きファイルに送ることができます。
注:
デフォルトでは、4014 イメージは横長方向でほぼページ全体を占めるように拡大縮小されます。

構文
ps4014 [ -m ] [ -C ] [ -N ] [ -R ] [ -sWidth,Height ] [ -lLeft,Bottom ] [ -SWidth ] [ -pOutFile ] [ File ]

オプション
フラグ
注:
-m
、
-C
、および
-N
フラグは、4014 コマンドの解釈に影響を与える 4014 ハードウェア・オプションの値を指定します。
表 1. フラグ
項目 | 説明
-C | 左マージンのペン位置に復帰を移動させますが、次行の下には移動させません。 デフォルトでは、復帰コマンドは、次行の下と左マージンの上にペンを移動します。
-l Left 、 Bottom | 変換されたラスター・イメージの左下隅の印刷ページ上の位置を指定します。 Left パラメーターおよび Bottom パラメーターで指定される値は、印刷されたページの左下隅からイメージの左下隅までの距離 (インチ単位) です。
-m | 4014 の "Margin 2" モードを使用可能にします。
-N | 次行の下のペン位置に行送りを移動させますが、左マージンには移動させません。 デフォルトでは、行送りは、次行の下と左マージンの上にペンを移動します。
-p OutFile | PostScript ファイルが、標準出力ではなく OutFile パラメーターで指定されたファイルに書き込まれるようにします。
-R | 縦方向のページ上でイメージを 90 度回転します。 デフォルトは、横方向です。
-s 「幅」 、 「高さ」 | 印刷ページの変換済みラスター・イメージのサイズを指定します。 Width および Height パラメーターは、印刷ページの結果イメージの寸法 (インチ単位) を指定します。
-S 幅 | このオプションを使用すると、ユーザーはイメージの形状をゆがめることなくイメージを拡大することができます。 Width パラメーターは、印刷ページの結果イメージの幅 (インチ単位) を指定します。 イメージの縦の長さは、出力イメージの縦と横の比率が入力ラスター・フォーマット・ファイルの場合と同じになるように計算されます。
