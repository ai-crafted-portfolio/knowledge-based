目的

AutoFS マウントおよびアンマウント・デーモンです。

構文

automountd [ -n ] [ -T ] [ -v ] [ -D  name=value ]

説明

この automountd デーモンは、ローカルの AutoFS ファイルシステムカーネル拡張機能からのリクエストを処理し、応答する RPC サーバーです。 それは、ローカル・ファイルまたはネーム・サービス・マップを使用して、マウントするファイルシステムを探します。

マップ

マップ・ファイルの説明については、 automount デーモンの Maps に関する情報を参照してください。

フラグ

表 1. フラグ
項目
説明
-Dname=値 指定された automountd デーモン環境変数に値を割り当てます。
-n デフォルトにより、すべてのマップ上で nobrowse オプションを設定します。
-T RPC サーバー呼び出しをトレースして、それを標準出力に表示します。
-v これは、詳細状況と警告メッセージを標準出力に出力します。
