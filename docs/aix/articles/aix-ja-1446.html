目的
Processes General Security Services API (GSSAPI) 認証は、Server Message Block (SMB) クライアント・ファイルシステムを要求します。

説明
AIX
オペレーティング・システムにおける SMB クライアント・ファイルシステムは、SMB プロトコル・バージョン
2.1 を使用してユーザー認証セッションを開始するために、Kerberos ベース GSSAPI を必要とします。
AIX
オペレーティング・システムでは、GSSAPI は IBM® Network Authentication Service (NAS) バージョン 1.16.1.0以降のファイルセットのユーザー・スペース・ライブラリーによって提供されます。 このファイルセットは、
AIX
Expansion Pack にあります。
smbcd
デーモンは、要求された Kerberos ベース GSSAPI に対して SMB クライアント・ファイルシステムを認証し、要求のタイプに基づいて、後で SMB クライアント・ファイルシステムの設定済み認証コンテキストを削除します。 SMB クライアント・ファイルシステムは、マウントまたはアンマウントの操作中にリモート共有 (ファイルとディレクトリー) にアクセスする要求、および一定間隔で、またはセッションの期限切れ後に、既存のセッションを再認証する要求を SMB サーバーに送信します。
smbc.rte
ファイルセットがインストールされると、
smbcd
デーモンは、システム・リソース・コントローラー (SRC) マスター・プログラムで動作するように構成されます。 SRC コマンドにより、
smbcd
デーモンを停止および開始できます。
smbcd
デーモンは、論理区画が開始されると自動的に開始されます。
smbcd
デーモンが強制終了されると、SRC マスター・プログラムは
smbcd
デーモンを自動的に再始動します。
smbcd
デーモンが実行されていないと、SMB サーバーでのセッションの認証も再認証も行うことができません。 それ以後、非認証セッションで SMB クライアント・ファイルシステム内のファイルにアクセスしようとしても、すべて失敗します。
smbcd
デーモンは、
startsrc
コマンドを実行することによって直接開始できます。
smbcd
デーモンが始動すると、
smbcd
デーモンは
/etc/smbc/smbctune.conf
ファイルを解析し、ファイルからのチューナブル・パラメーターの最新値でカーネルを更新します。 このように、チューナブル・パラメーター値はシステム再始動操作間で保持されます。
smbctune
コマンドの

smbc_max_concurrent_mount
チューナブル・パラメーターを使用して、実行できる同時認証の数を判別できます。
smbcd
デーモン状況を照会して、プロセス ID、状態、サブシステムなどの基本情報を判別できます。

構文
/usr/sbin/smbcd
