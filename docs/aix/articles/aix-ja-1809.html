目的
サーバー上で現在使用中の
ネットワーク情報サービス
(
国家情報院
) マップのオーダー番号 (ID 番号) を表示します。

説明
yppoll
コマンドは、
ypserv
デーモンを使って、
MapName
パラメーター内で指定したマップのオーダー番号を表示します。 オーダー番号はマップの ID 番号で、システムによって割り当てられます。 この番号はマップが更新されるたびに変わります。 特定のマップの最新バージョンをサーバーが使用していることを確認したいときはいつでも、
yppoll
コマンドを使ってください。
ポーリング
コマンドは、
ネットワーク情報サービス
(
国家情報院
) プロトコルのバージョン 1 またはバージョン 2 のいずれかがインストールされているシステムで実行できます。 ただし、プロトコルの各バージョンにはそれぞれ独自の診断メッセージ・セットがあることに注意してください。
注：
'
MapName
を指定する場合は、必ずマップのフルネームを入力してください。
yppoll
コマンドはマップのニックネームを認識しません。

構文
/usr/sbin/yppoll [ -h Host ] [ -d Domain ] MapName

オプション
フラグ
表 1. フラグ
項目 | 説明
-h ホスト | デフォルト・サーバー以外のサーバーを指定できるようにします。 コマンドのデフォルト・サーバーを知りたいときは、 ypwhich コマンドを使ってください。
-d ドメイン | デフォルト・ドメイン以外のドメインを指定できるようにします。 コマンドのデフォルト・ドメインを知りたいときは、 domainname コマンドを使ってください。

例
特定のホストにあるマップを表示するには、次のように入力します。
/usr/sbin/yppoll -h thor netgroups.byuser
この例では、
ポーリング
コマンドは、以下のオーダー番号を表示します。
netgroups.byuser
指定されたホスト上にあるマップ
thor
.
ドメイン上のマップを表示するには、次のように入力します。
/usr/sbin/yppoll -d atlantis hosts.byname
この例では、
ポーリング
コマンドは、以下のオーダー番号を表示します。
hosts.byname
ドメインに配置されているマップ
atlantis
.
