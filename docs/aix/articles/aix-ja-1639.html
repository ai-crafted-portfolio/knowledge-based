目的
ucfgvsd
- 仮想共有ディスクを構成解除します。

説明
ucfgvsd
コマンドは、
指定された仮想共有ディスクを構成解除します。 構成解除するには、
指定された仮想共有ディスクが停止状態にあることが必要です。 このコマンドは、仮想共有ディスクの定義を何も変更しません。 このコマンドは、仮想共有ディスクを停止状態から定義状態に移行します。
このコマンドは、System Management Interface Tool (SMIT) を使用して実行できます。 SMIT を使用するには、以下のように入力します。
smit vsd_mgmt
そして、「
Unconfigure a Virtual Shared Disk (仮想共有ディスクを構成解除)
」オプションを選択します。
通常の環境では、このコマンドを発行すべきではありません。 リカバリー可能仮想共有ディスク・サブシステムがこのコマンドを使用して、
共有ディスクを
制御された方法で管理します。 このコマンドを
発行する場合、結果は予測不能です。

構文
ucfgvsd { -a | vsd_name ...}

オプション
フラグ
-a
停止状態の仮想共有ディスクがすべて
構成解除されることを指定します。

例
停止状態の仮想共有ディスク
vsd1vg1n1
を構成解除するには、
次のように入力します。
ucfgvsd vsd1vg1n1
