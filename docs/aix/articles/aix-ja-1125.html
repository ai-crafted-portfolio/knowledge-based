目的
パッケージのパラメーター値を表示します。

説明
pkgparam
コマンド行で要求された 1 つ以上のパラメーターに関連付けられている値を表示します。 値は、以下のいずれかの場所にあります。
Pkginst
の
pkginfo
ファイル、
-d
フラグで指定された
Device
、または
-f
フラグで指定された特定のファイル。 (2 番目の形式のように)
Device
を指定して、
Pkginst
を
指定しなかった場合、
Device
にあるすべてのパッケージ
に関するパラメーター情報が表示されます。
-P
オプションを指定した
pkgadd
コマンドを使用して代替ルート・ディレクトリー・パスにパッケージをインストールする場合は、
-P
オプションで指定したのと同じ代替ルート・ディレクトリー・パスを使用して、パッケージ・パラメーターを要求できます。
1 つのパラメーター値が 1 行ずつ表示されます。
-v
フラグが指定されていない場合には、1 つのパラメーターの値だけが表示されます。 このフラグを使用すると、コマンドの出力は次の形式で示されます。
Parameter1='Value1'
Parameter2='Value2'
Parameter3='Value3'
コマンド行にパラメーターが指定されていない場合は、パッケージに関連付けられているすべてのパラメーターの値が表示されます。

構文
pkginfo に含まれるパラメーターの値を表示するには pkgparam [ -v] [ -d Device] [ -P path ] Pkginst [ Param ...] デバイスに含まれるパラメーターの値を表示するには pkgparam -d Device [ -v] [ Param ...] ファイルに含まれるパラメーターの値を表示するには pkgparam -f File [ -v] [ Param ...]

オプション
フラグ
表 1. フラグ
項目 | 説明
-v | 冗長モードを指定します。 パラメーターの名前とその値を表示します。
-d Device | Pkginst が保管されている Device を指定します。 Device には、ディレクトリーへの絶対パス名 ( /var/tmp など)、または標準入力から読み取られるデータ・ストリーム形式のパッケージを指定する "-" を指定できます。
-f | コマンドに、 File からパラメーター値を読み取ることを要求します。 このファイルは、 pkginfo ファイルと同じ形式でなければなりません。 例えば、このようなファイルをパッケージ開発時に作成し、 このステージでソフトウェアをテストするときに使用できます。
プッギンスト | パラメーター値を表示する必要がある特定のパッケージを定義します。 Pkginst .* という形式を使用して、パッケージのすべてのインスタンスを示すことができます。 このフォーマットを使用する場合は、シェルが * 文字を解釈しないように、コマンド行を単一引用符で囲みます。
パラメーター | 値を表示する必要がある特定のパラメーターを定義します。
-P パス | 代替ルート・ディレクトリー・パスで pkginfo ファイルを検索します。
