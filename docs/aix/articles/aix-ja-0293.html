目的
グループ・サービス・サブシステムを制御します。

説明
cthagsctrl
制御コマンドは、システム・リソース・コントローラー (SRC) の制御下にあるグループ・サービス・サブシステム (
cthags
) の操作を制御します。
クラスターのすべてのノードでは、グループ・サービス・サブシステムのインスタンスが実行されています。
操作上の視点から、グループ・サービス・サブシステム・グループは次のように編成されています。
サブシステム
グループ・サービス
サブシステム・グループ

SRC サブシステム
cthags
サブシステムは、
hagsd
デーモンに関連付けられています。
ノード上のサブシステム名は
cthags
です。 1 つのノードにつき 1 つのサブシステムが存在し、それらのサブシステムのそれぞれはそのノードが属すクラスターに関連付けられています。
デーモン
hagsd
グループ・サービス機能を提供します。
一般に、
cthagsctrl
コマンドはコマンド行からは発行されません。 これは通常、クラスターの作成中に
cthactrl
コマンドによって呼び出されます。
cthagsctrl
コマンドは、グループ・サービス・サブシステムを操作するためのさまざまな制御を提供します。

Adding the subsystem
-a
フラグを指定すると、制御コマンドはグループ・サービス・サブシステムを SRC に追加します。 この制御コマンドは、次のことを行います。
cthags
サブシステムが停止していることを確認します。
クラスター・データから
cthags
サブシステムのポート番号を取得します。
cthags
サブシステムを SRC から除去します (まだ存在する場合)。
cthags
サブシステムを SRC に追加します。
現在、
cthags
グループのエントリーを
/etc/inittab
ファイルに追加しません。 結果として、
cthags
は、必要に応じて別のサブシステムによって開始される必要があります。
Starting the subsystem
-s
フラグが指定されている場合、制御コマンドは
startsrc
コマンドを使用して、グループ・サービス・サブシステム
cthags
を開始します。
Stopping
the subsystem
-k
フラグが指定されている場合、制御コマンドは
stopsrc

コマンドを使用して、グループ・サービス・サブシステム
cthags
を停止します。
Deleting
or cleaning the subsystem
-d
フラグが指定されている場合、制御コマンドは
rmssys
コマンドを使用して、グループ・サービス・サブシステムを SRC から除去します。 この制御コマンドは、次のことを行います。
cthags
サブシステムが停止していることを確認します。
rmssys
コマンドを使用して、
cthags
サブシステムを SRC から除去します。
/etc/services
ファイルからポート番号を削除します。
Turning tracing on
-t
フラグを指定すると、制御コマンドは
traceson
コマンドを使用して
hagsd
デーモンのトレースをオンにします。
Turning
tracing off
-o
フラグを指定すると、制御コマンドは
tracesoff
コマンドを使用して、
hagsd
デーモンのトレースをオフにします (デフォルト・レベルに戻します)。
Refreshing
the subsystem
-r
フラグは、
cthags
サブシステムをリフレッシュします。

構文
cthagsctrl { -a [ -p port-number ] -s | -k | -d | -r | -z | -h | -t | -o }

オプション
フラグ
--a [-p
ポート番号］
サブシステムを追加します。
-s
サブシステムを始動します。
-k
サブシステムを停止します。
-d
サブシステムを削除します。
-t
サブシステムのトレース機能をオンにします。
-o
サブシステムのトレース機能をオフにします。
-r
サブシステムをリフレッシュします。
-z
cthags
サブシステムをアンインストールします。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。

例
グループ・サービス・サブシステムを現行クラスターの SRC に追加するには、次のように入力します。
cthagsctrl -a
ポート番号 12347 を使用してグループ・サービス・サブシステムを追加するには、次のように入力します。
cthagsctrl -a -p 12347
現行クラスターでグループ・サービス・サブシステムを始動するには、次のように入力します。
cthagsctrl -s
現行クラスターでグループ・サービス・サブシステムを停止するには、次のように入力します。
cthagsctrl -k
グループ・サービス・サブシステムを現行クラスターの SRC から削除するには、次のように入力します。
cthagsctrl -d
現行クラスターでグループ・サービス・デーモンに対するトレースをオンにするには、次のように入力します。
cthagsctrl -t
現行クラスターでグループ・サービス・デーモンに対するトレースをオフにするには、次のように入力します。
cthagsctrl -o
