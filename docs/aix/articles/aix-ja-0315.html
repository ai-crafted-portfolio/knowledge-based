目的
C および C++ プログラムの相互参照リストを作成します。

説明
cxref
コマンドは、C および C++ プログラム・
ファイル
を分析して相互参照テーブルを作成し、
cpp
コマンドを使用して記号テーブルに
#define
ディレクティブを記述します。 これは、処理された各ファイル内のすべてのシンボルのリストを、個別にまたは組み合わせて標準出力に書き出します (
-c
フラグを参照)。 関数定義の仮パラメーターは常に書き込まれます。ただし、プロトタイプの関数でまだ定義されていない場合は、パラメーターは書き込まれません。 記号への参照がその記号の宣言の場合、参照の前に * (アスタリスク) が付きます。

構文
CXREF [ 「-c」 ] [ -F アイル ] [ -Q (Q) オプション ] [ -s ] [ T ] [ -w (W) 数値 ] [[ -D 名前 [ = 定義 ]] [ -I (I) ディレクトリー ] [ -U (U) 名前 ]] ... [ -Nd (N) 数値 ] [ -Nl (N) 数値 ] [ -Nn (N) 数値 ] [ -Nt (N) 数値 ] ファイル ...

オプション
フラグ
項目 | 説明
-c | すべての入力ファイルの相互参照をまとめて記述したリストを表示します。
-o ファイル | File に指定したファイルへ出力を書き込みます。
-s | 入力ファイル名を非表示にします。
-t | リストの幅を 80 桁に設定します。
-w 数値 | リストの幅を Number に指定された数の桁に設定します。 Number には、51 以上の 10 進数の整数値を指定できます。 Number に 51 未満の数値が指定されると、リストの幅は 80 桁になります。
- Nd 数値 | 寸法テーブルのサイズを Number に変更します。 デフォルトは 2000 です。
- Nl 数値 | タイプ・ノードの数を Number に変更します。 デフォルトは 8000 です。
- Nn 数値 | 記号テーブルのサイズを Number に指定した値に変更します。 デフォルトは 1500 です。
- Nt 数値 | ツリー・ノードの数を Number に変更します。 デフォルトは 1000 です。
cxref
コマンドは、以下の
cpp
コマンド (マクロ・プリプロセッサー) のフラグも認識します。
項目 | 説明
-D 名前 [= 定義 ] | Name を #define ディレクティブとして定義します。 デフォルトの Definition は 1 です。
-I ディレクトリー | 名前の先頭にスラッシュ (/) が付いていない #include ファイルを、指定したディレクトリー、標準リストのディレクトリーの順に検索します ( cpp コマンドを参照)。
-U 名前 | Name の初期定義を除去します。 Name は、プリプロセッサーにより事前に定義された予約済み記号です。
-q オプション | -q Option をプリプロセッサーに渡します。 例: -qmbcs 現行ロケールで指定されたマルチバイト・モードを設定します。 -qidirfirst #include file_name ディレクティブに含まれているファイルの検索順序を変更します。

例
以下の結合相互参照リストを提供します。
stdin1.c
および
stdin2.c
出力の幅を 80 桁にするには、次のように入力します。
cxref
-c
-t
stdin1.c stdin2.c > output
