目的

/etc/cifs_fs/cifscred ファイルに保管されている特定のサーバー/ユーザー項目のパスワードを変更します。

構文

chcifscred -h RemoteHost -u ユーザー [-p パスワード]

説明

chcifscred コマンドは、サーバー名とユーザー名を入力として使用します。 この入力に /etc/cifs_fs/cifscredにリストされている資格情報がある場合、コマンド行は、既存のパスワードを置き換えるためのパスワードの入力を求めるプロンプトを出します。 このパスワードは、暗号化されたフォーマットで保管されます。

フラグ

項目
説明
-h RemoteHost リモート・ホスト (CIFS サーバー) の名前を指定します。 これは、ホスト名、IP アドレス、または完全修飾ドメイン名として指定することができます。
-p パスワード 指定されたリモート・ホスト上の指定されたユーザーに対して新規パスワードを指定します。
-u ユーザー 指定されたホストにアクセスするために、パスワードを変更中のユーザー名を指定します。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

例

  1. user1 用に保管されているパスワードを、 server1にマウントするように変更するには、 server1 および user1 資格情報が既に /etc/cifs_fs/cifscredに存在するようにします。次のように入力します。
    chcifscred -h server1 -u user1

場所

/usr/sbin/chcifscred

ファイル

項目
説明
/etc/cifs_fs/cifscred CIFS 証明書を保管します。
