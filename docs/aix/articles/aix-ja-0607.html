目的
新規メールをフォルダーに取り込みます。

説明
inc
コマンドは、着信メールを指定したフォルダーにファイルし、ファイルされたメッセージのリストを出力します。 フォルダーはシステム・ディレクトリーです。 デフォルトでは、
inc
コマンドはメール・ドロップから新しいメッセージを除去し、指定したフォルダーに収めます。 メール・ドロップを削除せずに新規メールをファイルするには、
-notruncate
フラグを使用します。
指定されたフォルダーがない場合、
inc
コマンドはフォルダーを作成するかどうかをユーザーに尋ねるプロンプトを表示します。 システムはユーザーのメッセージ・ハンドラー (MH) ディレクトリーのサブディレクトリーとしてフォルダーを作成します。 デフォルトのフォルダーは
inbox
です。
“
注:
以下のものがない場合:
Path:
.mh_profile
ファイルに指定されているエントリーの場合、
増分
コマンドは、現行ディレクトリーのサブディレクトリーとしてフォルダーを作成します。
”
ファイルされたメッセージには、フォルダー内の 2 番目に大きい番号で始まる連続メッセージ番号が割り当てられます。 各新規メッセージは、以下で指定された保護コードを受け取ります。
Msg-Protect:
.mh_profile
ファイル内の項目。 もし
Msg-Protect:
項目が存在しない場合は、保護コード 644 が割り当てられます。 もし
Unseen-Sequence:
項目が存在している場合には, その項目によって指定された各順序に新しいメッセージが追加されます。

構文
増分 [ + フォルダー ] [ -監査なし | -監査 ファイル ] [ -チェンジャー | -ノチェンカー ] [ -形式 FormFile | -format (フォーマット) ストリング ] [ -ヘルプ ] [ -ファイル ファイル ] [ -切り捨て | -notruncate (切り捨てなし) ] [ -nosilent (サイレント) | -サイレント ] [ -幅 数値 ]

オプション
フラグ
項目 | 説明
-監査 ファイル | 現在の日付を指定したファイルにコピーし、 inc コマンドの出力をそのファイルに追加します。
-チェンジャー | 最初の新規メッセージを、指定したフォルダーの現行メッセージとして設定します。 このフラグはデフォルトです。
-ファイル ファイル | ユーザーのメール・ドロップからではなく、指定したファイルからのメッセージをファイルします。
+ フォルダー | 新しいメッセージを収めるためのフォルダーを指定します。 デフォルトでは、システムは inbox と呼ばれるサブディレクトリーを、ユーザーの MH ディレクトリー内に作成します。
-フォーム FormFile | inc コマンドの代替出力フォーマットが含まれているファイルを識別します。
-format (フォーマット) ストリング | inc コマンドの代替出力フォーマットを定義する文字列を指定します。
-help | これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。 “ 注: MH の場合は、このフラグ名を省略することはできません。 ”
-監査なし | ファイルされる新しいメッセージに関する情報の記録を抑制します。 これはデフォルトです。
-ノチェンカー | 指定したフォルダーに対する現行メッセージを変更できないようにします。
-nosilent (サイレント) | 必要な情報をユーザーに確認するプロンプトを表示します。 このフラグはデフォルトです。
-notruncate (切り捨てなし) | inc コマンドが新しいメッセージを取り込むときに、そのメッセージが入っているメールボックスまたはファイルをクリアしないようにします。 -file フラグを指定した場合は、 -notruncate フラグがデフォルトになります。
-サイレント | inc コマンドによる情報を確認するプロンプトが表示されないようにします。 このフラグは、 inc コマンドをバックグラウンドで実行する場合に便利です。
-切り捨て | inc コマンドが新しいメッセージを取り込むときに、そのメッセージが入っているメールボックスまたはファイルをクリアします。 -file フラグを指定しない場合は、 -truncate フラグがデフォルトになります。
-幅 数値 | コマンド出力の桁数を設定します。 デフォルトはディスプレイの幅です。
