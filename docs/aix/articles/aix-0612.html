目的

システム全体のハードウェア・パフォーマンス・カウンター情報を提供します。

構文

hpmstat [ -b time_base ] [ -d ] [ -D metrics ] [ -O options ] [ -g event_groups ] [ -H ] [ -k ] [ -m metrics_groups ] [ -o file ] [ -r ] [ -s set ] [ -T ] [ -U ] [-u ] [ -x ] [ -@ ALL | WparName ] interval count
hpmstat [-h]

説明

hpmstat コマンドは、実行壁時計時刻、ハードウェア・パフォーマンス・カウンター情報、および派生したハードウェア・メトリックを提供します。 hpmstat コマンドを使用できるのは、root 特権を持つユーザーのみです。

コマンド行オプションを指定しない場合、 hpmstat コマンドは、イベントのデフォルト・セット 1 に対して、ユーザー、カーネル、およびハイパーバイザー (ハイパーバイザー・モードをサポートするプロセッサーの場合) のアクティビティーのデフォルトの 1 反復を 1 秒間カウントします。 続いて、このコマンドは、ロウ・カウンター値および導出メトリックを標準出力 に書き出します。 デフォルトでは、 runlatch は無効になっているため、アイドル・サイクルでの実行中にカウントを実行できます。

-U オプションが指定されている場合、 interval はマイクロ秒単位で、反復 count は無限大であり、派生メトリックは計算されず、標準出力に書き込まれません。 カウンター多重方式が指定されている場合は、このオプションは無視されます。

-T オプションを指定すると、出力情報の前にタイム・スタンプ (秒とマイクロ秒) が付き、時間情報が秒単位ではなくタイム・スタンプとして書き込まれます。

モニター対象のイベント・タイプおよび関連するハードウェア・パフォーマンス・カウンターは、set -s オプションを使用するか、 HPM_EVENT_SET 環境変数にイベント・グループ名またはセット番号を指定することによって指定します。 あるいは、カウンターとイベントのペア (POWER3 および PowerPC 604 RISC マイクロプロセッサー) またはイベント・グループ名 (POWER4 以降) を libHPM_events 入力ファイルに指定します ( HPM_EVENT_SETよりも優先されます)。 カウント・モードは、各セットを修飾することができます。 イベントのグループ番号または名前を指定するには、-g オプションを設定するか、または HPM_EVENT_GROUP 環境変数でイベント・グループのコンマ区切りリストを指定します。 同様に、カウント・モードは各イベント・グループを限定することができます。

セット番号の代わりに、コンマで区切られたイベント・セットのリストを指定することができます。その場合は、カウンター多重方式が選択されます。 イベント・セットをすべて選択するには、セット番号の値を 0 に設定します。

有効なイベント・セット番号は、 pmlist コマンドを使用してリストできるプロセッサー・タイプに応じて、 1 から上限まで実行されます。

派生メトリックのコンマ区切りリストを指定するには、-D オプションを設定します。 カウント・モードでは、各派生メトリックを限定することができます。

派生メトリック・グループのリストを指定するには、-m オプションを設定するか、または HPM_PMD_GROUP 環境変数で派生メトリック・グループのコンマ区切りリストを指定します。 この操作により、ユーザーは、指定されたグループに関連するすべての派生メトリックを選択できます。 カウント・ノードは、各メトリック・グループを修飾します。

多重化モードでカウントする場合は、使用する前に結果を正規化する必要があります。 データ正規化に使用されるデフォルトのベースは、時間ベースです。 -b オプションを使用すると、データの正規化に PURR 時間または SPURR 時間 (プロセッサーでサポートされている場合) を使用できます。 データ正規化のベースは、 HPM_NORMALIZE 環境変数を使用して定義することもできます。

グローバル・ワークロード区画 (WPAR) から hpmstat コマンドを実行する場合、 -@ WparName オプションを使用して特定の WPAR をモニターすることができます。 -@ ALL オプションを使用して、システム内のすべてのアクティブな WPAR をモニターし、WPAR ごとのデータを取得することができます。

結果は、 -x オプションを使用して XML 形式で出力できます。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. ハードウェア・カウンターからセット 2 のイベントに関する 1 秒間のシステム、ユーザー、およびハイパーバイザーのアクティビティーに関する情報を書き込むには、次のコマンドを入力します。
    hpmstat -s 2
  2. グループ 0 のイベントに関するユーザー・アクティビティー、および wpar1 WPAR のグループ 1 のイベントに関するシステム・アクティビティーに関する情報を 5 秒間隔で書き込むには、次のコマンドを入力します。
    hpmstat -@ wpar1 -g 0:u,1:k 5
  3. しきい値開始イベントと終了イベントの別個のペアの間で経過したしきい値カウント・イベントの数をカウントし、比較するしきい値を指定するには、次のコマンドを入力します。
    hpmstat -g 607 -O threshold_cmp_val=10000 -O
threshold_event_sel=THRESHOLD_COUNT_CYCLES -O
threshold_eve_start_sel=PM_MRK_L1_RELOAD_VALID -O
threshold_eve_stop_sel=PM_MRK_ST_DONE_L2 -O
random_samp_ele_crit=ALL_INSTR
