目的
インターネット・ドメイン・ネーム・システム（DNS）に対話的に問い合わせる。

説明
nslookup
コマンドは、次の2つのモードでインターネット・ドメイン・ネーム・サーバーに問い合わせる：
対話モード
様々なホストやドメインに関する情報をネームサーバーに問い合わせたり、ドメイン内のホストのリストを印刷したりすることができる。
非インタラクティブ・モード
指定されたホストまたはドメインの名前と要求された情報を表示します
nslookup
コマンドは、引数を与えない場合、または最初の引数が「
-
（ハイフン）で、2番目の引数がネームサーバーのホスト名またはIPアドレスの場合、対話モードになる。 引数を指定しないと、コマンドはデフォルトのネーム・サーバーを照会します。
nslookup
コマンドは、検索するホストの名前またはIPアドレスを第1引数に指定すると、非インタラクティブ・モードになる。 オプションの第2引数には、ネームサーバーのホスト名またはアドレスを指定する。 コマンド・ラインに各オプションを指定可能なのは、オプションが各引数の前にあり、かつ、ハイフンが接頭部として付けられている場合です。 例えば、デフォルトの照会タイプをホスト情報に変更し、初期タイムアウトを 10 秒に変更するには、下記のコマンドを入力します。
nslookup -query=hinfo -timeout=10
-version
オプションは、「
nslookup
コマンドにバージョン番号を表示させ、終了させる。

構文
nslookup [ - option ] [ name | - ] [ server ]
