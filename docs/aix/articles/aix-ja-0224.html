目的
ファイルの
トラステッド・コンピューティング・ベース
属性を変更または照会します。

説明
chtcb
コマンドは、
File
パラメーターで指定されたファイルの
トラステッド・コンピューティング・ベース
(TCB) 属性を変更または照会します。 有効な代替値は、次のとおりです。
項目 | 説明
オン | trusted computing base 属性を使用可能にします。
off | trusted computing base 属性を使用不可にします。
照会 | trusted computing base 属性の値を表示します。
このコマンドは、トラステッド・パスで実行してください。

構文
ChTCP { オン | オフ | 照会 } ファイル ...

例
以下を識別します。
plans
トラステッド・コンピューティング・ベース (TCB) の一部としてファイルを作成するには、
トラステッド・コンピューティング・ベース
属性を
on
値を指定するには、次のように入力
chtcb on plans
この
plans
トラステッド・パスからファイルを実行できるようになりました。
照会するには、以下のようにします。
plans
ファイルがトラステッド・コンピューティング・ベース (TCB) の一部である場合は、次のように入力します。
chtcb query plans
状況が表示されると、次のことがわかります。
plans
TCB 属性が
on
値に設定されている場合、ファイルはトラステッド・コンピューティング・ベースの一部です。
削除するには、
plans
トラステッド・コンピューティング・ベース (TCB) からのファイルの場合は、次のように入力します。
chtcb off plans
