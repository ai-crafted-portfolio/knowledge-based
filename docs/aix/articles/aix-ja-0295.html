目的
トポロジー・サービス・サブシステムを制御します。

説明
cthatsctrl
制御コマンドは、トポロジー・サービス・サブシステムの操作を制御します。 サブシステムは、システム・リソース・コントローラー (SRC) の制御下にあり、
cthats
というサブシステム・グループに属します。 各サブシステムと関連付けられているのは、デーモンおよびこのデーモンを構成して始動するコマンドです。
クラスターのすべてのノードでは、トポロジー・サービス・サブシステムのインスタンスが実行されています。
サブシステムの追加
-a
フラグが指定されている場合、制御コマンドは
mkssys
コマンドを使用してトポロジー・サービス・サブシステムを SRC に追加します。 この制御コマンドは、次のことを行います。
cthats
サブシステムが停止していることを確認します。
クラスター・データからポート番号を取得し、そのポート番号が
/etc/services
ファイルに設定されていることを確認します。
/etc/services
ファイルに入力されたサービス名は
cthats
です。
cthats
サブシステムを SRC から除去します (まだ存在する場合)。
cthats
サブシステムを SRC に追加します。
サブシステムの始動
-s
フラグが指定されている場合、制御コマンドは
startsrc
コマンドを使用して、トポロジー・サービス・サブシステム
cthats
を開始します。
サブシステムの停止
-k
フラグを指定すると、制御コマンドは
stoptsrc
コマンドを使用してトポロジー・サービス・サブシステム
cthats
を停止します。
サブシステムの削除
-d
フラグが指定されている場合、制御コマンドは
rmssys
コマンドを使用して、SRC からトポロジー・サービス・サブシステムを除去します。 この制御コマンドは、次のことを行います。
cthats
サブシステムが停止していることを確認します。
rmssys
コマンドを使用して、
cthats
サブシステムを SRC から除去します。
/etc/services
ファイルから
cthats
ポート番号を削除します。
構成の再ビルド
-b
フラグが指定されている場合、制御コマンドはクラスター・データから構成情報を読み取り、トポロジー・サービス・デーモン用の構成ファイル
machines.lst
を作成します。
トレースをオンにする
-t
フラグが指定されている場合、制御コマンドは、
traceson
コマンドを使用してトポロジー・サービス・デーモンのトレースをオンにします。

トレースをオフにする
-o
フラグを指定すると、制御コマンドは
tracesoff
コマンドを使用してトポロジー・サービス・デーモンのトレースをオフにします (デフォルト・レベルに戻します)。
サブシステムをリフレッシュする。
-r
フラグが指定されている場合、制御コマンドは
refresh
コマンドを使用してサブシステムをリフレッシュします。
-r
フラグは、再作成された情報を読み取るようにデーモンにシグナル通知します。

構文
cthatsctrl { -a [ -p port-number ] | -s | -k | -d | -b | -t | -o | -r | -h }

オプション
フラグ
--a [-p
ポート番号］
サブシステムを追加します。
-s
サブシステムを始動します。
-k
サブシステムを停止します。
-d
サブシステムを削除します。
-t
サブシステムのトレース機能をオンにします。
-o
サブシステムのトレース機能をオフにします。
-b
クラスター・データ内の構成情報から、トポロジー・サービス構成ファイルを再構築します。
-r
サブシステムをリフレッシュします。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。

例
トポロジー・サービス・サブシステムを SRC に追加するには、次のように入力します。
cthatsctrl -a
トポロジー・サービス・サブシステムを始動するには、次のように入力します。
cthatsctrl -s
トポロジー・サービス・サブシステムを停止するには、次のように入力します。
cthatsctrl -k
トポロジー・サービス・サブシステムを SRC から削除するには、次のように入力します。
cthatsctrl -d
トポロジー・サービス・デーモンに対するトレースをオンにするには、次のように入力します。
cthatsctrl -t
トポロジー・サービス・デーモンに対するトレースをオフにするには、次のように入力します。
cthatsctrl -o
クラスター・データ内の構成情報からトポロジー・サービス構成ファイルを再構築するには、次のように入力します。
cthatsctrl -b
クラスター内のすべてのトポロジー・サービス・デーモンに対してこの新規構成ファイルを読み取るよう指示するシグナルを送るには、次のように入力します。
cthatsctrl -r
使用方法情報を標準出力に書き込みには、次のように入力します。
cthatsctrl -h
