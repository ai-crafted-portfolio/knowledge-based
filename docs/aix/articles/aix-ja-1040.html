目的
ネットワーク・インストール管理 (NIM) クライアント・パッケージを構成します。

説明
この
niminit
コマンドは、コマンド
nimclient
を使用する前に、NIMクライアントパッケージの設定を行います。
niminit
コマンドが必要な属性を受け取ると、
niminit
コマンドを実行するマシンを表す新しいマシン・オブジェクトが作成される。
niminit
コマンドが正常に完了すると、
niminit
コマンドを実行したマシンは NIM 環境に参加できるようになる。
NIMクライアント・パッケージが設定されたら、
niminit
コマンドを実行して、クライアント上の
/etc/niminfo
ファイルを再構築することができます。
/etc/niminfo
ファイルは
niminit
コマンドで使用される。 ユーザーが意図せずファイルを削除した場合、
/etc/niminfo
ファイルを再構築しなければならない。
niminit
alternate_master
。
is_alternate

yesに
設定されている場合。
alternate_master
オブジェクトを設定する前に、
bos.sysmgt.nim.master

alternate_master
オブジェクトが設定された後、
alternate_master

alternate_master

構文
NIMクライアントパッケージを設定するには、次のコマンドを入力してください： niminit { -a name=Name -a pif_name=Pif -a master=Hostname } [ -a master_port=PortNumber ] [ -a registration_port=PortNumber ] [ -a cable_type=CableType | -a ring_speed=Speed ] [ -a iplrom_emu=Device ] [ -a platform=PlatformType ] [ -a netboot_kernel=NetbootKernelType ] [ -a adpt_add=AdapterAddress ] [ -a is_alternate= yes | no ] [ -a connect=value ] [ -a vlan_tag=value ] [ -a vlan_pri=value ] [ -c ] ファイルを /etc/niminfo 再構築するには、次のコマンドを入力してください： niminit { -a name=Name -a master=Hostname -a master_port=PortNumber }
