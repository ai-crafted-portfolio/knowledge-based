目的
ディスク使用状況のアカウンティングを実行します。

説明
acctdisk
コマンドおよび
acctdusg
コマンドは、
dodisk
コマンドによって呼び出され、ディスク使用状況のアカウンティングを実行します。 通常、このプロシージャーは、
cron
デーモンが
dodisk
コマンドを実行するときに開始されます。
通常は、
diskusg
コマンドの出力が
acctdisk
コマンドの入力になります。 より完全ではあるが低速なバージョンのディスク・アカウンティングが必要な場合は、
dodisk -o
コマンドを使用して、
diskusg
コマンドではなく
acctdusg
コマンドを呼び出してください。
集計は、ローカル・ユーザー用のローカル・ファイルシステムにあるファイルに関してだけ行われます。 リモート・ユーザー (YP クライアントやディスクレス・クライアントなど) をカウントするシステム管理者は、
acctdusg -p
コマンドを使用できます。
acctdisk
コマンドは、
diskusg
または
acctdusg
コマンドの出力行を標準入力から読み取り、個々のレコードを合計アカウンティング・レコードに変換し、そのレコードを標準出力に書き出します。 これらのレコードは、
acctmerg
コマンドにより他のアカウント・レコードとマージされ、日次集計レポートが生成されます。
acctdusg
コマンドは、低速で詳細なディスク集計が必要な場合に、
dodisk -o
コマンドにより呼び出されます。 それ以外の場合、
dodisk
コマンドは
diskusg
コマンドを呼び出します。
acctdusg
コマンドは、標準入力 (
find / -print
コマンドからパイプ接続) からファイルのリストを読み取り、各ファイル所有者に割り振られたディスク・ブロック (間接ブロックを含む) の数を計算し、各ユーザーの個々のレコードを標準出力に書き出します。 デフォルトでは、コマンドは、ログイン名と番号を
/etc/passwd
ファイル内で検索します。
-p
File
フラグと変数を指定すれば、その他のファイルを検索できます。 各出力レコードは次のフォーマットになります。
acctdusg
コマンドは、標準入力 (
find / -print
コマンドからパイプ接続) からファイルのリストを読み取り、各ファイル所有者に割り振られたディスク・ブロック (間接ブロックを含む) の数を計算し、各ユーザーの個々のレコードを標準出力に書き出します。 デフォルトでは、コマンドは、ログイン名と番号を

/etc/passwd
ファイル内で検索します。
-p
File
フラグと変数を指定すれば、その他のファイルを検索できます。 各出力レコードは次のフォーマットになります。
uid login #blocks
#blocks
値は、ユーザーが使用している 1 KB ブロックの数です。

構文
acctdisk acctdusg [ -u File ] [ -p File ] [ -X ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-p ファイル | /etc/passwd ファイルを検索しないで、指定のファイルからログイン名と番号を検索します。
-u ファイル | 課金免除にするファイル名のレコードを、指定のファイルに入れます。
-X | 長いユーザー名のサポートをオンにします。

例
通常のディスク・アカウンティング手順を開始するには、次のような行を
crontab
ファイルに追加して、
cron
デーモンがディスク・アカウンティング・コマンドを自動的に実行するようにします。
0 2 * * 4 /usr/sbin/acct/dodisk
この例では、
dodisk
プロシージャーは
(0 2)
毎週木曜日の
(4)

dodisk
プロシージャーは
diskusg
および
acctdisk
コマンドを呼び出して、ディスク使用量レコードを
/usr/adm/acct/nite/dacct
ファイルに書き込みます。
