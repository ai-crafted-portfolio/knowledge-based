目的
参考文献データベースをソートします。

説明
sortbib
コマンドは、ユーザー指定キーによる
refer
コマンド・キー文字を含むレコードのファイルをソートします。 レコードはブランク行で区切るか、. [(ピリオド、左大括弧) と.] で囲むことができます。 (ピリオド、右大括弧) 区切り文字ですが、2 つのスタイルを混在させることはできません。
sortbib
コマンドは
Database
パラメーターで指定された各データベースを通して読み取り、別にソートされたキー・フィールドを取り出します。 ソートされたキー・フィールドにはファイル・ポインター、バイト・オフセット、対応するレコードの長さが含まれます。 これらのレコードはディスク・シークおよび読み取りを使って配布されるため、
sortbib
コマンドは標準入力を読むためのパイプライン内では使用できません。
デフォルトでは、
ソルトビブ
コマンドは最初のコマンドのアルファベット順になります。
%A
および
%D
フィールドには、上級作成者と日付が含まれます。
ソルトビブ
コマンドは、以下の中の最後のワードでソートします。
%A
作成者の姓であると想定されるフィールド。 最後の位置にある単語。例えば、以下のようになります。
jr.
または
ed
前の名前がコンマで終わっている場合には,. は無視されます。 2 つの語からなる姓を持つ、または一般的ではない構造の名前の作成者は、スペース文字の代わりに
&#xa5;0
を使う
nroff
のコマンド規則を使うことによって、正しくソートできます。 指定する
%Q
フィールドは次と類似しています:
%A
ただし、ソートは最後の単語ではなく最初の単語から開始します。
“
注:
作成者フィールドが欠落しているレコードは、タイトルでソートする必要があります。
”
ソルトビブ
コマンドは、以下の最後のワードでソートします。
%D
行 (通常は年)。 タイトルでソートする場合、先頭の記事は無視されます。
%T
または
%J
フィールド 無視された冠詞は、そのロケールに特定のもので、
ロケール特定の
refer
メッセージ・カタログ
内で指定されます。 このカタログ内では、冠詞は単一メッセージ内に含まれます。 各冠詞は任意の数の ASCII スペースまたはタブ文字で区切られます。 レコードにソート・キーとなるフィールドがない場合、
sortbib
コマンドはそのレコードを、そのフィールドを含む他のレコードの前に置きます。

1 回にソートできるデータベースは 16 までです。 4096 文字を超えるレコードは切り捨てられます。
Database
パラメーターには、
sortbib
コマンドがソート時に使用する、ユーザー指定キーによる
refer
コマンド・キー文字が記述されます。

構文
ソルトビブ [ -s キー ] [ データベース ... ]

オプション
フラグ
項目 | 説明
-s キー | ソートするフィールド・キーを指定します。

例
作成者、タイトル、および日付でソートするには、以下のようにします。
sortbib -sATD Database
作成者と日付でソートするには、以下のようにします。
sortbib -sA+D Database
