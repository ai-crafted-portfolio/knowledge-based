目的
ドメインネームシステム（DNS）検索ユーティリティ。

説明
Domain Information Groper (
dig
) コマンドは、ドメインネームシステム (DNS) のネームサーバーを調べるための柔軟なツールである。 DNS ルックアップを実行し、照会されたネーム・サーバーから返された応答を表示します。 ほとんどのDNS管理者は、DNSの問題のトラブルシューティングに「
dig
コマンドを使用する。
dig
コマンドは通常、コマンドライン引数とともに使用されるが、ファイルからルックアップ要求を読み込むバッチモードもある。
-h
フラグを使うと、コマンドライン引数とオプションの簡単な要約が表示される。
dig
コマンドのBIND9実装では、コマンドラインから複数の検索を発行することができる。 特定のネームサーバーに問い合わせるように指示されない限り、「
dig
コマンドは「
/etc/resolv.conf
ファイルにリストされている各サーバーを試行する。 使用可能なサーバーアドレスが見つからない場合、「
dig
コマンドはローカルホストに問い合わせを送る。 コマンドライン引数やオプションを指定しない場合、「
dig
コマンドはルートに対して「
NS
クエリーを実行する。
${HOME}/.digrc

dig
コマンドのユーザーごとのデフォルトを設定することができる。
dig

-r
オプションは、予測可能な動作が必要なスクリプトではこの機能を無効にする。

構文
dig [ @server ] [ -b address ] [ -c class ] [ -f file ] [ -k keyfile ] [ -m ] [ -p port# ] [ -q name ] [ -t type ] [ -v ] [ -x addr ] [ -y [ hmac:] Keyname:secret ] [ -4 ] [ -6 ] [name ] [type ] [class ] [queryopt... ] dig [ -h ] dig [ global-queryopt... ] [query... ]

フラグ
表 1. フラグ
項目 | 説明
-4 | dig コマンドがIPv4クエリートランスポートのみを使用することを許可する。
-6 | dig コマンドがIPv6クエリートランスポートのみを使用することを許可する。
-b アドレス [#ポート］ | クエリーの送信元IPアドレスを設定する。 指定されたアドレスは、ホストのネットワークインターフェースの1つ、または ' 0.0.0.0 か ' :: 有効なアドレスでなければならない。 port パラメータ値を付加することで、オプションのポートを指定することができる。
-c class | クエリ・クラスを設定します。 class パラメータ値には、' HESIOD レコードには ' HS 、' CHAOSNET レコードには ' CH など、有効なクラスを指定する。
-f file | 処理する検索要求のリストを指定のファイル名から読み取ることにより、 dig コマンドをバッチ・モードで操作します。 ファイル内の各エントリーは、コマンドライン・インターフェイスを使用して、' dig コマンドへのクエリーとして表示されるのと同じ方法で整理されなければならない。
-h | コマンド・ライン引数とオプションの要約を出力します。
-k keyfile | -k オプションを使用して、トランザクション署名 (TSIG) または SIG(0) 鍵ファイルを指定し、 ' dig コマンドで送られた DNS クエリに署名する。 tsig-keygen コマンドを使用して、鍵ファイルを生成できます。 dig コマンドでTSIG認証を使用する場合、問い合わせを受ける「 name サー バーは、使用されている鍵とアルゴリズムを特定しなければならない。 BINDでは、TSIGのために' named.conf ファイル中の適切な' key と' server を指定し、 ゾーンデータ中のKEYレコードのSIG(0)をチェックすることで、この操作を行う。
-m | メモリ使用量とデバッグを有効にする。
-p ポート番号 | サーバーの非標準ポート番号を問い合わせる。 port# パラメーター値は、 dig コマンドがその照会を標準の DNS ポート番号 53 の代わりに送信するポート番号です。 このオプションを使用すると、非標準のポート番号でクエリーをリッスンするように設定されているネームサーバーをテストすることができる。
-q name | 名前と他の引数を区別します。 クエリ名を指定した name パラメータ値に設定します。

-t type | クエリ・タイプを type パラメータ値に設定します。 これは、BIND 9でサポートされている有効なクエリー型で、' NS や' AAAA ような型ニーモニックで指定されます。 デフォルトのクエリータイプは ' A であるが、' -x オプションで逆引きを指定することができる。 ゾーン転送は、ゾーン転送の タイプ として' AXFR 指定して要求される。 インクリメンタルゾーン転送(IXFR)が必要な場合、 type パラメータ値は 「 ixfr=N 」に設定される。 増分ゾーン転送は、ゾーンレコードのSOAにおける通し番号が' N であるように、 ゾーンに加えられた変更を含む。 すべてのリソースレコードの型は nn 型で表すことができ、 nn は 型 の数である。 リソースレコードのタイプがBIND 9でサポートされていない場合、結果は' RFC3597 のように表示される。
-u | 印刷クエリー時間をミリ秒ではなくマイクロ秒で指定しなければならないことを示す。
-v | バージョン番号を表示して終了します。
-x アドレス | 逆引き（アドレスと名前の対応付け）を簡素化。 addr パラメータ値は、ドット付き10進数表記のIPv4アドレス、またはコロン区切りのIPv6アドレスである。 このオプションを使用する場合、 name class と type の引数を指定する必要はない。 dig コマンドは自動的に' 11.12.13.10.in-addr.arpa ような名前のルックアップを実行し、クエリータイプとクラスを' PTR と' IN に設定する。 IPv6アドレスは、「 IP6.ARPA ドメインの下でニブルフォーマットを使用して検索される。
-y [hmac:] キーネーム：secret | dig コマンドで送信される DNS クエリーに署名するトランザクション署名 (TSIG) 鍵ファイルを指定する。 keyname は鍵の名前、 secret は base64-encoded共有秘密、 hmac は鍵アルゴリズムの名前である。 以下のオプションが hmac の有効な選択肢である： hmac-md5 hmac-sha1 hmac-sha224 hmac-sha256 hmac-sha384 hmac-sha512 hmac が指定されない場合、デフォルト値は' hmac-md5 である。 MD5が無効の場合、デフォルト値は「 hmac-sha256 である。
