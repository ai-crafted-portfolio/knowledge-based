目的
単一サイトのクラスターを作成すること。

説明
mkcluster
コマンドはクラスターを作成します。 クラスターは、ノードおよびディスクの集合です。 クラスタに追加される各ノードには、ゾーン化された共通のストレージ・エリア・ネットワーク（SAN）ストレージ・デバイスが必要です。 SAN ストレージ・デバイスは、クラスター・リポジトリー・ディスクおよびクラスター化されたすべての共有ディスクに使用されます。
クラスター内のノード間でのクラスター通信には、マルチキャスト・アドレスが使用されます。 クラスタを作成する前にネットワークに関する注意事項を確認する必要がある場合は、クラスタのシステム管理者に相談してください。

構文
mkcluster -r reposdev [ -S sitename { [ cle_uuid=UUID, cle_globid=id, cle_prio=prio ] } ] [ -m node { [ cle_ip=addr, cle_uuid=UUID, cle_globid=id ] }] [,...] [ -d shareddisk [,...] ] [ -n clustername ] [ -s multi_cast_addr ] [ -c capability [,...] ] [ -v ] [ -b backupdisk [,...] ] [ -p comdisk ]

-m ノード | クラスタのメンバーであるノードのホスト名またはIPアドレスをコンマで区切って一覧表示します。 ローカル・ホストはこのリストに含まれなければなりません。 -m フラグを使用しない場合、ローカル・ホストは暗黙で指定され、単一ノードのローカル・クラスターが作成されます。 以下のノード情報を指定できます。 cle_uuid ノードのUUIDで、クラスタ全体で一意であると認識される。 指定されない場合、ノード UUID が自動的に生成されます。 cle_globid ノードの短いIDで、0より大きいユニークな符号なし数字でなければならない。 指定されない場合、ノードの簡略 ID が自動的に生成されます。 以下のノード属性を指定できます。 cle_ip ノードのゲートウェイアドレス（クラスタが複数のサイトにまたがっている場合）。 通常、この属性は、外部ノードからこのノードに到達するために使用できるアドレスです。 このアドレスは、IP バージョン 4 またはバージョン 6 の形式で指定できます。
-d 共有ディスク | hdisk12 、 hdisk34 など、クラスタ構成に組み込む共有ストレージ・エリア・ネットワーク（SAN）デバイスのコンマ区切りリストを指定します。 指定されたデバイスは、 mkcluster コマンドの実行時にオープンしていてはなりません。
-n クラス名 | 作成されるクラスターの名前を設定します。 mkcluster コマンドを実行する際にnameが指定されない場合、デフォルトの CL_hostname 。 hostnameは ローカルホストの名前である。 ローカル・ホストの名前は gethostname() 関数を実行して取得できます。
-s マルチキャスト | 作成されるクラスターのマルチキャスト・アドレスを設定します。 このアドレスは、クラスター内の内部通信に使用されます。 IPv4 形式のマルチキャストアドレスのみ受け付ける。 IPv6 マルチキャスト・アドレスが必要な場合は、IPv4 アドレスから生成する必要があります。 mkcluster コマンドを最初に実行するときに -s フラグが指定されていない場合、必要なマルチキャストアドレスが自動的に生成される。
-v | 冗長モードを指定します。
