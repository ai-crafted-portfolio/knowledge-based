目的
グループを除去します。

説明
rmgroup
コマンドは、
Name
パラメーターで指定したグループを除去します。 このコマンドは、
すべてのグループ属性も削除します。 グループを除去するには、そのグループ名が既に存在していなければなりません。 グループ・メンバーであるユーザーは、システムから除去されません。
グループがあるユーザーの 1 次グループである場合、
chuser
コマンドを使用してそのユーザーの 1 次グループを再定義しない限り、
そのグループは除去できません。
chuser
コマンドは、
/etc/passwd
ファイルを変更します。 root ユーザー、または、GroupAdmin 権限が与えられているユーザーだけが、
管理グループや管理ユーザーとして入っているグループを除去することができます。
代替の ID および認証 (I & A) メカニズムを使用して作成されたグループの場合、
-R
フラグを使用して、使用される I & A ロード・モジュールを指定できます。 ロード・モジュールは、
/usr/lib/security/methods.cfg
ファイルで定義されます。
また、System Management Interface Tool (SMIT)
smit rmgroup
高速パスを使用して実行することもできます。

構文
RM グループ [ P- ] [ -R ロード・モジュール ] 名前

オプション
フラグ
項目 | 説明
-p | グループ鍵ストアを除去します。
-R ロード・モジュール | グループの除去に使用するロード可能 I&A モジュールを指定します。

例
finance グループを除去するには、以下のように入力します。
rmgroup finance
LDAP I&A ロード可能なモジュール・グループを除去するには、以下のように入力します。
rmgroup -R LDAP monsters
