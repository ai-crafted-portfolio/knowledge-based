目的
suspendvsd
- 使用可能な仮想共有ディスクを非アクティブにします。

説明
suspendvsd
コマンドは、
指定された仮想共有ディスクをアクティブ状態から延期状態に移行します。 ディスクは引き続き使用可能です。 仮想共有ディスクが活動状態の時にアクティブであった読み取りおよび書き込み要求は、
中断され保持されます。 後続の読み取りおよび書き込み操作も保持されます。 仮想共有ディスクが延期状態の場合、このコマンドは、
仮想共有ディスクを延期状態のままにします。
このコマンドは、System Management Interface Tool (SMIT) を使用して実行できます。 SMIT を使用するには、以下のように入力します。
smit vsd_mgmt
そして、「
Suspend a Virtual Shared Disk (仮想共有ディスクを中断)
」オプションを選択します。
通常の環境では、このコマンドを発行すべきではありません。 リカバリー可能仮想共有ディスク・サブシステムがこのコマンドを使用して、
共有ディスクを
制御された方法で管理します。 このコマンドを
発行する場合、結果は予測不能です。

構文
suspendvsd { -a | vsd_name ...}

オプション
フラグ
-a
アクティブ状態の仮想共有ディスクがすべて
中断されることを指定します。

例
仮想共有ディスク
vsd1vg1n1
をアクティブ状態から延期状態に移行するには、
次のように入力します。
suspendvsd vsd1vg1n1
