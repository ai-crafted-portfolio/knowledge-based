目的
ypinit
コマンドを呼び出して
NIS
コントローラー・サーバーからマップを検索し、
ypserv
デーモンを始動してワーカー・サーバーを構成します。

説明
mkslave
コマンドは
ypinit
コマンドを呼び出して、コマンド・ラインで指定されるコントローラー・サーバーからマップを取得します。
ypserv
デーモンは、
ypinit
コマンドが正常終了したら始動します。
Master
パラメーターを使用してコントローラー・サーバーのホスト名を指定します。 指定したコントローラー・サーバーは既に構成されていて稼働しています。
このコマンドは、System Management Interface Tool (SMIT)
smit mkslave
高速パスを使用して実行することができます。

構文
/usr/sbin/mkslave [ -C | 「-c」 ] [ -O (O) | - ] [ -I (I) | -B | -N (N) ] マスター

オプション
フラグ
項目 | 説明
-C | -n フラグを指定して ypinit コマンドを呼び出します。 mkslave コマンドはエラーが発生しても継続します。 このフラグはデフォルトです。
-c | エラーが発生すると、実行を停止します。
-O | ドメインに存在するマップを上書きします。
-o | ドメインに存在するマップを上書きしません。 このフラグはデフォルトです。
-I | 即座に ypinit コマンドを呼び出しますが、次にシステムがリブートされるまで、 ypserv デーモンは始動しません。
-N | ypinit コマンドを呼び出し、 ypserv デーモンを始動します。
-B | ypinit コマンドを呼び出し、 ypserv デーモンを始動し、 ypserv 構成して、システムをリブートします。 このフラグはデフォルトです。

例
ypinit
コマンドを呼び出して、コントローラー・サーバーが
host2
マップの場合は、次のように入力します。
mkslave -O host42
このコマンドは現行マップを上書きします。
