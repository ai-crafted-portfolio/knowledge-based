目的

コマンド、デバイス、特権ファイル、またはドメイン割り当て済みオブジェクトについて、データベース内にあるセキュリティー属性定義を除去します。

構文

rmsecattr [-R load_module] { -c | -d | -f | -o } Name

説明

rmsecattr コマンドは、コマンド、デバイス、ファイル・エントリー、または Name パラメーターで識別されるドメイン割り当て済みオブジェクトのセキュリティー属性を、該当するデータベースから除去します。 このコマンドは、 「-c」 (コマンド)、 -d 年 (デバイス)、 「-f」 (特権ファイル)、または - (ドメイン割り当てオブジェクト) のいずれのフラグが指定されているかに基づいて、 名前 パラメーターをコマンド、デバイス、ファイル項目、またはドメイン割り当てオブジェクトとして解釈します。 -c フラグを指定する場合、Name パラメーターにはコマンドへの絶対パスを含める必要があり、またそのコマンドはその時点で /etc/security/privcmds 特権コマンド・データベース内にエントリーを持っている必要があります。

-d フラグを指定する場合、Name パラメーターにはデバイスへの絶対パスを含める必要があり、またそのデバイスはその時点で /etc/security/privdevs 特権デバイス・データベース内にエントリーを持っている必要があります。

-f フラグを指定する場合、Name パラメーターにはファイルへの絶対パスを含める必要があり、またそのファイルは /etc/security/privfiles 特権ファイル・データベース内にエントリーを持っている必要があります。

-o フラグを指定する場合、オブジェクト・タイプがファイルまたはデバイスであれば Name パラメーターには絶対パスを含める必要があり、またそのオブジェクト・タイプは /etc/security/domobjs ドメイン割り当て済みオブジェクト・データベース内にエントリーを持っている必要があります。

重要: rmsecattr コマンドは、そのセキュリティー属性の定義のみを除去します。実際のコマンド、デバイス、またはファイルは除去しません。

複数のドメインからデータベースを使用するようにシステムが構成されている場合、rmsecattr コマンドは、 /etc/nscontrol.conf ファイル内の対応するデータベース・スタンザの secorder 属性で指定された順序で、データベース・ドメインから最初の一致を検索します。 それと同時に、rmsecattr コマンドは、検索されたコマンドまたはデバイスのエントリーをドメインから除去します。 残りのドメインに一致するエントリーがあっても、それらのエントリーは影響されません。 特定のドメインからエントリーを除去するには、-R フラグを使用します。

このコマンドで行われた変更は、setkst コマンドを使用してデータベースがカーネル・セキュリティー・テーブルに送られるまで、セキュリティー上の考慮事項としては使用されません。

フラグ

項目
説明
-c Name パラメーターと一緒に使用した場合、特権コマンド・データベースにエントリーを持つシステム上の 1 つ以上のコマンドへの絶対パスを指定します。
-d Name パラメーターと一緒に使用した場合、特権デバイス・データベースにエントリーを持つシステム上の 1 つ以上のデバイスへの絶対パスを指定します。
-f Name パラメーターと一緒に使用した場合、システム上の特権ファイルへの絶対パスを指定します。
-o Name パラメーターと一緒に使用した場合、ドメイン割り当て済みオブジェクト・データベースで指定されたオブジェクトを指定します。
-R ロード・モジュール Name エントリーの削除に使用するロード可能モジュールを指定します。

パラメーター

項目
説明
Name 変更するオブジェクトを指定します。 Name パラメーターは、指定された -c、-d、-f、または -o フラグに従って解釈されます。

セキュリティー

rmsecattr コマンドは特権コマンドです。 これは、モードを 755 に設定した root ユーザーおよびセキュリティー・グループによって所有されます。 このコマンドを実行するには、次の権限の 1 つ以上が必要です。

項目
説明
aix.security.cmd.remove -c フラグを指定してコマンドのセキュリティー属性を除去するために必要です。
aix.security.device.remove -d フラグを指定してデバイスのセキュリティー属性を除去するために必要です。
aix.security.dobject.remove -o フラグを指定してドメイン割り当て済みオブジェクトのセキュリティー属性を除去するために必要です。
aix.security.file.remove -f フラグを指定してファイルのセキュリティー属性を除去するために必要です。

アテンション RBAC ユーザー: このコマンドは特権操作を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

アクセスされるファイル

ファイル
モード
/etc/security/domobjs rw

例

  1. グループから/usr/sbin/mytest特権コマンド・データベースからのコマンド、次のように入力します。
    rmsecattr -c /usr/sbin/mytest
  2. グループから/dev/mydev特権装置データベースからの装置の場合は、次のように入力します。
    rmsecattr -d /dev/mydev
  3. グループから/dev/mydevLDAP の特権デバイス・データベースからの装置の場合は、次のように入力します。
    rmsecattr -R LDAP -d /dev/mydev
  4. 特権ファイル・データベースから /etc/testconf ファイルを除去するには、次のように入力します。
    rmsecattr -f /etc/testconf
  5. ネットワーク・インターフェースを削除するにはen0ドメイン・オブジェクト・データベースから、次のように入力します。
    rmsecattr -o objectype=netint en0
