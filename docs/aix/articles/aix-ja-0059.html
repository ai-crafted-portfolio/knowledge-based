目的
監査レコードのビンを書き込みます。

説明
auditcat
コマンドは、監査サブシステムの一部であり、監査データ・レコードを処理する幾つかのバックエンド・コマンドの 1 つです。
auditcat
コマンドは、標準入力から、または
InFile
パラメーターで指定されたファイルから、監査レコードのビン・ファイルを読み取ります。 次に、このコマンドは、レコードを処理し、標準出力かまたは
0utFile
パラメーターに指定されているファイルに、出力を書き込みます。 出力は、選択したフラグに応じて、圧縮することもしないこともできます。
このコマンドの主な用途の 1 つは、圧縮されたビン・ファイルをシステム監査証跡ファイルの終わりに追加することです。
/etc/security/audit/bincmds
ファイルに入力ファイルとして
$bin
が含まれている場合は、入力は現行ビン・ファイル
bin1
または
bin2
からとられます。
/etc/security/audit/bincmds
に
$trail
が出力ファイルとして含まれている場合、レコードはシステム監査証跡ファイルの末尾に書き込まれます。
ビン・ファイルが有効なヘッダーとテールを使って適切に作成されていないと、エラーが戻されます。 監査ヘッダーとテールについては
auditpr
コマンドを、エラー・リカバリーについては
auditbin
コマンドを参照してください。
-s
オプションに有効な値が指定されている場合は、trail ファイルのバックアップを取り、そのサイズをゼロに縮小します。 パス名を指定すると、バックアップ・ファイルがそのパスにコピーされます。 バックアップ・ファイル名の形式は以下のとおりです。 YYYYMMDDThhmmss. < 乱数>
/audit
ファイル・システムのサイズがフリー・スペース (
/etc/security/audit/config
が設定されている) より小さく、
-d
有効なパス・パラメーターで指定されている場合、そのパスへのトレール・ファイルのバックアップが取られます。 異なるトレール・ファイルの出力を表示するには、
auditmerge
コマンドを使用します。

構文
auditcat [ -p | -u ] [-s size] [-d pathname] [ -oOutFile ] [ -r ] [ InFile ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-o OutFile | auditcat コマンドがレコードを書き込む監査証跡ファイルを指定します。 $trail を OutFile パラメーターのファイルとして指定した場合、 auditbin デーモンがシステム監査証跡ファイルの名前を置換します。
-p | 出力時にビン・ファイルを圧縮 (パック) することを指定します。 デフォルト値は、ビンを圧縮しないことを指定します。
-r | リカバリー手順を要求します。 リカバリーが行われるようにするには、 InFile および OutFile パラメーターの両方にファイル名を指定する必要があります。したがって、コマンドの構文は auditcat -o OutFile -r InFile とならなければなりません。 このコマンドは、 InFile パラメーターに指定された bin ファイルが付加されているかどうかを検査し、付加されていない場合は、 OutFile パラメーターで指定されたファイルに bin ファイルを付加します。 ビン・ファイルが不完全である場合は、 auditcat コマンドは、有効な証跡を追加し、 OutFile パラメーターに指定されているファイルにビン・ファイルを追加します。
-u | 圧縮された証跡ファイルを出力時に圧縮解除することを指定します。
-s Size | 証跡のバックアップを取る必要があった後の、証跡ファイルのサイズの制限を指定します。 サイズは、512 バイトのブロック単位で指定する必要があります。 size パラメーターが -ve またはゼロ、あるいは無効な値の場合、 auditcat はフラグと値を無視します。 最大値は 4194303 (約 2 GB の空きディスク・スペース) です。
-d パス名 | パス名は、有効な絶対ディレクトリー・パスでなければなりません。このパスでは、証跡ファイルのバックアップを取る必要があります。 パス名の値が無効な場合、 auditcat はフラグと値を無視します。

例
監査ビン・データをシステム監査証跡ファイルに追加するようにシステムを構成するには、
/etc/security/audit/bincmds
ファイルに下記の行を追加します。
/usr/sbin/auditcat
-o
$trail $bin
auditbin
デーモンは、
auditcat
コマンドを呼び出すときに、
$bin
文字列を現行ビン・ファイルのパス名に置き換え、
$trail
文字列をデフォルトの監査証跡ファイルの名前に置き換えます。
