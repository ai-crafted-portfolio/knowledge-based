目的

Cisco Discovery Protocol (CDP) を使用して着信データ・パケットまたはメッセージを受信する cdpd デーモンを制御し、物理的に接続された Cisco デバイスを発見します。

構文

cdpctl subcommand device_name

説明

CDP は、メディアやネットワークから独立した層 2 (データ・リンク層) プロトコルです。 CDP は、デバイスに直接接続されている他の Cisco デバイスを発見するために Cisco デバイスで実行されるネットワーキング・アプリケーションで使用されます。 7200-05 AIX7の 以降、CDP 機能は、CDP を使用して受信データ・パケットまたはメッセージを受信する 「cdpdデーモンを使用して、AIX®論理パーティションに実装されます。 次のコマンドを実行すると、System Resource Controller (SRC) サブシステムは cdpd デーモンを開始します。
startsrc -s cdpd
cdpctl コマンドは、物理的に接続された Cisco デバイスに関する情報を含む CDP を使用して着信データ・パケットまたはメッセージを受信するように AIX 論理区画上のネットワーク・インターフェースを構成することにより、 cdpd デーモンを制御します。 cdpctl コマンドはまた、接続された Cisco デバイスからブロードキャストされたデータ・パケットまたはメッセージを検出することによって、物理的に接続された Cisco デバイスと、関連する構成設定を発見します。
注: CDP 機能は、CDP メッセージを受信し、物理的に接続されたデバイスのみをディスカバーするために、 AIX オペレーティング・システムに実装されています。 CDP データ・パケットは、Cisco デバイスに接続された物理インターフェースでのみ受信でき、仮想インターフェースでは受信できません。

サブコマンド

リスト
AIX 論理区画上の CDP 対応ネットワーク・インターフェースのリストを表示します。 CDP 対応のネットワーク・インターフェースとは、CDP を使用して着信データ・パケットまたはメッセージを受信するようにネットワーク・インターフェースを構成可能であることを意味します。
構文: cdpctl list
追加
CDP 対応の Cisco デバイスまたはネットワーク・インターフェースを AIX 論理区画に追加します。
構文: cdpctl add device_name
show portlist
CDP を使用して着信データ・パケットまたはメッセージを受信するように構成されたネットワーク・インターフェースのリストを表示します。
構文: cdpctl show portlist
show port
構成済み CDP 対応ネットワーク・インターフェースで受信された CDP 情報 (スイッチ機能やルーター機能など) を表示します。
構文: cdpctl show port device_name
remove
構成済みネットワーク・インターフェースが、接続された Cisco デバイスから CDP を使用して着信データ・パケットもメッセージも受信できなくなるよう、そのネットワーク・インターフェースを削除します。
構文: cdpctl remove device_name

例

  • cdpctl コマンドの使用方法を表示するには、次のコマンドを入力します。
    cdpctl
  • AIX 論理区画内のすべての CDP 対応デバイスおよびネットワーク・インターフェースをリストするには、次のコマンドを入力します。
    cdpctl list
    次の例に示すような出力が表示されます。
    CDP capturable devices on the system:
en0
en2
  • CDP を使用して物理的に接続された Cisco デバイスから着信データ・パケットまたはメッセージを受信できるネットワーク・インターフェースを AIX 論理区画に追加するには、次のコマンドを入力します。
    cdpctl add en0
    次の例に示すような出力が表示されます。
