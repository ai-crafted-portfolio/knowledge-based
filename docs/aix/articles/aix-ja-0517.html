目的
標準入力から
wtmp
フォーマットのバイナリー・レコードを読み取り、フォーマットされた ASCII レコードに変換することによって、接続時アカウンティング・レコードを処理します。 不良なレコードを編集するには ASCII バージョンを使用することができます。

説明
fwtmp
コマンドは、標準入力から
wtmp
形式のバイナリー・レコードを読み取り、それらをフォーマット済み ASCII レコードに変換することによって、アカウンティング・レコードを操作します。

構文
/usr/sbin/acct/fwtmp [ -i ] [ -c ] [ ]。 -X ][ -L ]

オプション
フラグ
項目 | 説明
-i | utmp フォーマットの ASCII レコードを入力として受け入れます。
-c | 出力を utmp フォーマットのバイナリー・レコードに変換します。
-ic | ASCII utmp フォーマットの入力レコードをバイナリー出力レコードに変換します。
-X | 最初の 8 文字に切り捨てることをせずに、各ユーザー名の使用可能なすべての文字を印刷します。
-L | 各ホスト名は、最初の 32 文字に切り捨てられずに、使用可能なすべての文字が印刷されます。

例
wtmp
フォーマットのバイナリー・レコードを ASCII レコードに変換するには、次のようにします。
dummy.file
次のように入力します。
/usr/sbin/acct/fwtmp < /var/adm/wtmp > dummy.file
バイナリー・ファイル
wtmp
の内容は、ダミーの ASCII ファイルにリダイレクトされます。
ASCII を変換するには
dummy.file
wtmp
フォーマットのバイナリー・ファイルに
/var/adm/wtmp
、以下を入力します。
fwtmp
を指定したコマンド
-ic
スイッチ:
/usr/sbin/acct/fwtmp
-ic <
dummy.file > /var/adm/wtmp
ダミーの ASCII ファイルはバイナリー・ファイル
wtmp
にリダイレクトされます。
