目的
送信前にメール・メッセージをフォーマットします。

説明
fmt
コマンドは、連結された入力
Files
(
Files
の指定がない場合は標準入力) を読み取るテキスト・フォーマッターを始動し、入力の行の長さを
-
Width
の値に設定したものを標準出力に生成します。
-
Width
フラグによる値の指定がない場合は、72 文字のデフォルト値を使用します。 入力行の先頭のスペーシングは、ブランク行や語間のスペーシングと同じように、出力内に保存されます。
fmt
コマンドは通常、送信前のメール・メッセージをフォーマットしてメッセージの外観を整えるために使用します。 しかし、
fmt
コマンドは単純なフォーマット作業にも有効です。 例えば、vi エディターなどのテキスト編集プログラムのビジュアル・モードで
!}fmt
コマンドを実行すると、すべての行が
-
Width
フラグで指定した値に設定されるようにパラグラフがフォーマットされます。
-Width
フラグによる値の指定がない場合は、72 文字のデフォルト値を使用します。 複雑なフォーマット操作の場合は、
fmt
より標準テキスト編集プログラムの方が適しています。
注:
メッセージに他のファイルからの組み込みメッセージまたは事前にフォーマットされた情報が含まれている場合は、
fmt
コマンドを使用しないでください。 このコマンドは、組み込みメッセージの見出し情報をフォーマットします。
フォーマット済みの情報のフォーマットが変更されてしまう場合があります。

構文
/usr/bin/fmt [ - 幅 ] [ ファイル ... ]

オプション
フラグ
項目 | 説明
File | フォーマットするファイルの名前を指定します。
- 幅 | 行の長さを指定します。 Width のデフォルト値は 72 文字です。

例
メール・エディターで作成したメッセージをフォーマットするには、次のように入力します。
~| fmt
この
~|
は、メッセージの左マージンに入力されます。 次のコマンドを発行した後、
~| fmt
メッセージがフォーマット設定されます。 単語
(continue)
より多くの情報を入力したり、メッセージを送信したりできることを示すために表示されます。
ファイルをフォーマットして、出力を画面に表示するには、次のように入力します。
fmt file1
この例では、以下のファイルを使用します。
file1
がフォーマット設定され、画面に表示されます。
