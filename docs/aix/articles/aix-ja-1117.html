目的
プリンター・バックエンド・メッセージをユーザーに送信します。

説明
piomsg
コマンドは、メッセージ・カタログからプリンター・バックエンド・メッセージを取り出すか、指定したメッセージ・テキストを 1 人または複数のユーザーに送信するかのいずれかを行います。
piomsg
コマンドは、印刷ジョブを実行すると動作します。 通常
piomsg
コマンドは、プリンターのコロン・ファイルで使用して、
piobe
コマンドを指定して印刷ジョブを処理している間に、印刷ジョブを実行依頼しているユーザーにメッセージを送信します。
-c
、
-s
、または
-n
フラグを指定すると、
piomsg
コマンドはメッセージ・カタログからメッセージを取り出します。 このコマンドは、
NLSPATH
環境変数で指定されたディレクトリーでメッセージを検索します。
NLSPATH
環境変数にディレクトリー・パスが入っていない場合、
piomsg
コマンドは、デフォルトのディレクトリー
/usr/lib/lpd/pio/etc
を検索します。
/usr/lib/lpd/pio/etc
ディレクトリーにメッセージが見つからない場合、コマンドは
MessageText
変数で指定されたテキストを提供します。
-c
、
-s
、または
-n
フラグを指定しなければ、
piomsg
コマンドは、
MessageText
変数の値 (ある場合) を戻します。
各メッセージは、
%s
または
%n$s
printf
サブルーチン変換の仕様について解析されます。 メッセージ文字列を指定すると、メッセージがユーザーに送信される前に
printf
変換の仕様が提供されたメッセージ文字列に置き換えられます。
piomsg
コマンドは、メッセージに組み込まれている改行
/n
または水平タブ
/t
などのエスケープ・シーケンスを処理します。

構文
piomsg [ -u UserList ] [ -c MsgCatalog [ -sMsgSet ] -n MsgNumber ] [ -a MsgArg ] ... [ MsgText ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-a MsgArg | メッセージ引数文字列を指定します。 MsgArg 変数の値は、 %s または %n$s printf サブルーチンの変換の仕様が入っていると、メッセージに置換します。 -a フラグを最高 10 個まで指定して、複数の引数を指定できます。 変換指定の構文解析中にエラーが発生した場合は、元のメッセージが送信されます。
-c MsgCatalog | 取り出すメッセージが入っているメッセージ・カタログを指定します。 -c フラグは、 -n フラグとともに指定しなければなりません。
-n MsgNumber | メッセージ番号を指定します。 -n フラグは、 -c フラグとともに指定しなければなりません。
-s MsgSet | オプションのメッセージ・セットを指定します。 MsgSet 変数のデフォルト値は 1 です。 -s フラグは、 -c フラグと -n フラグの両方と一緒に指定する必要があります。
-u UserList | メッセージを受け取るユーザーのリストを指定します。 UserList 変数のユーザー名とノード名は、コンマで区切ります。 ユーザー・リストにノード名を入れるには、@ 文字に続けてノード名またはアドレスを指定します。 -u フラグを省略した場合、メッセージは印刷ジョブを開始したユーザーに戻ります。

例
メッセージ・セット番号 1 のメッセージ番号
100
を
piobe.cat
メッセージ・カタログから取り出し、そのメッセージを印刷サーバーと同じノード上のユーザー
joe
とノード
foobar
上の
tom
に送信するには、次のように入力します。
piomsg -u joe,tom@foobar -c piobe.cat -n 100
メッセージ引数ストリングを含むメッセージを、印刷ジョブを実行依頼したユーザーに送信するには、次のように入力します。
piomsg -a "/usr/bin/troff" "The specified filter %s is not found\n"
セット number2 内のメッセージ番号 5 を
xyz.cat
から取り出し、障害が発生した場合にダミー・メッセージを使用し、そのメッセージをプリンターに送信するには、次のように入力します。
piomsg -cxyz.cat -s2 -n5 "xyz.cat is not installed.\n"
注:
piomsg
コマンドが
NLSPATH
環境変数またはデフォルト・ディレクトリーで指定されたカタログからメッセージを取得できない場合、提供されたメッセージ・テキストがユーザーに送信されます。
