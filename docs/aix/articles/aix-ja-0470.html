目的
コマンドのヒストリー・リストを処理します。

説明
fc
コマンドは、コマンド・ヒストリー・ファイルの内容を表示するか、以前にシェルに入力されたコマンドを変更および再実行するためにエディターを起動します。
コマンド・ヒストリー・ファイルでは、コマンドが番号別に表示されます。 リスト内の最初の番号は任意に選択されます。 番号とそのコマンドとの関係は変化しませんが、ユーザーがログインするときに他のプロセスがそのリストにアクセスしていない場合は除きます。 その場合、システムは番号付けをリセットして、コマンドを古い順に 1 から番号付けを始めます。
コマンド・ヒストリー・ファイル内の数値が、
HISTSIZE
環境変数の値または 32767 より大きい値のいずれか大きい値に達すると、シェルは 1 に折り返されます。 このオプションの数値ラッピングにもかかわらず、
fc
コマンドはコマンドの時刻順を維持します。 例えば、3 つのコマンドの番号が順々に 32766、32767 および 1 (折り返し後の番号) となっている場合、
コマンド 32767 は引き続きコマンド 1 の前にあるものと見なされます。
ヒストリー・ファイル内のコマンドは、
-l
(小文字の L) フラグを使用して表示できます。
-l
フラグが指定されず、
-e
Editor
フラグを使用してコマンドが編集される場合、結果の行はヒストリー・ファイルの最後に入力されてから、シェルによって再実行されます (
fc -e
Editor
コマンドはコマンド・ヒストリー・リストに入力されません)。 エディターが 0 以外の終了状況を戻すと、ヒストリー・ファイル内の入力とコマンドの再実行が抑止されます。
fc
コマンドで使用されるコマンド・ラインの変数代入またはリダイレクト演算子は、前のコマンドをもう一度起動し、
fc
コマンドと前のコマンドの両方の標準エラーを抑止します。 次に例を示します。
fc -s -- -1 2>/dev/null

構文
以前に入力したコマンドを変更および再実行するためにエディターを開くには fc [ -r ] [ -e Editor ] [ First [ Last ] ] 以前に入力したコマンドのリストを生成するには fc -l [ -n ] [ -r ] [ First [ Last ] ] 以前に入力したコマンドと実行時刻のリストを生成するには fc -t [ -n ] [ -r ] [ First [ Last ] ] 以前に入力したコマンドを再実行するには fc -s [ Old= New ] [ First ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-e エディター | 指定されたエディターを使用してコマンドを編集します。 Editor パラメーターはコマンド名です。 このコマンドは、 PATH 環境変数を使用して見つけます。 FCEDIT 環境変数の値は、 -e フラグが指定されていない場合にデフォルトとして使用されます。 FCEDIT 環境変数が null、または設定されていない場合は、ed エディターが使用されます。
-l | (小文字の L) ヒストリー・ファイル内のコマンドを表示します。 コマンドを変更するためのエディターは起動されません。 コマンドは、 -r フラグの影響を受けて、 First および Last パラメーターで示された順序で書き込まれ、各コマンドの前にコマンド番号が付けられます。
-n | -l フラグと一緒に使用すると、コマンド番号の表示を抑止します。
-r | コマンドのリスト順序 ( -l フラグと一緒に使用した場合) を反転、またはコマンドの編集順序 ( -l フラグを指定しない場合) を反転させます。
-s | エディターを起動せずにコマンドを再度実行します。 First パラメーターも指定していない場合は、 -s フラグは直前のコマンドを再度実行します。
-t | コマンドを、それが実行された時刻とともにヒストリー・ファイルにリストします。 この機能は -l フラグと似ていますが、コマンドの実行時刻が表示されます。 注: EXTENDED_HISTORY=ON を設定して時刻フィールドを以前に記録した場合は、フォーマット設定された時刻フィールドが表示され、それ以外の場合は「?」が表示されます。

例
最新のコマンド (デフォルト・エディターは
/usr/bin/ed
) で
FCEDIT
環境変数によって定義されたエディターを呼び出すには、次のように入力します。
fc
このコマンドは、編集が終わると実行されます。
直前に実行された 2 つのコマンドをリストするには、次のように入力します。
fc -l -2
cc
で始まるコマンドを見つけ、
foo
を
bar
に変更し、そのコマンドを表示して実行するには、次のように入力します。
fc -s foo=bar cc
以前実行されたコマンドを、その実行時刻と
ともにリストするには、次のように入力します。
fc –t
