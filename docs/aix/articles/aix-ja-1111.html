目的
プリンター・フォーマッターを始動します。

説明
pioformat
コマンドは、プリンター・フォーマッター・ドライバーを開始します。 フォーマッター・ドライバーは、データベース値へのアクセスを確立し、プリンター・フォーマッターをロードしてリンクし、その
setup
関数、
initialize
関数、
lineout
関数、
passthru
関数、および
restore
関数を呼び出すことによってフォーマッターを駆動します。 フォーマッター・ドライバーは、フォーマッターが使用する
piogetopt
サブルーチン、
piogetstr
サブルーチン、
pioexit
サブルーチンも提供します。
この後にリストされるフラグは、フォーマッター・ドライバーによって処理され、フォーマッターには渡されません。 ただし、これより後にリストされていないすべてのフラグは、フォーマット・フラグであると想定され、フォーマッターに渡されます。

構文
/usr/lpd/pio/etc/pioformat -@ DataBaseFile [ -! FormatterName ] [ -# + PassThroughOption ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-@ DataBaseFile | 以下のいずれかを指定します。 アクセスする (要約された) データベース・ファイルの絶対パス名。 コロンで区切られた、印刷キューとキュー・デバイスの名前 引数文字列が / (スラッシュ) 文字で始まる場合、絶対パス名であると想定されます。 キューの名前とキュー・デバイス名を組み合わせると、データベース・ファイル名の一部である固有文字列になり、 /var/spool/lpd/pio/@local/ddi ディレクトリー内でデータベース・ファイル名の検索に使用されます。 この短形式の代替は、フォーマッター・ドライバーおよびフォーマッターがスプーラーではなくスタンドアロン・デバイスとして実行される場合に、便宜上提供されます。
-! FormatterName | ロード、リンク、および始動の対象となるフォーマッターの絶対パス名を指定します。 -! フラグが指定されていない場合は、データベース内の mf 属性名で定義されているデフォルトのフォーマッター名が使用されます。 デフォルトのフォーマッター名は、フォーマッター・ドライバーおよびフォーマッターがスプーラーではなくスタンドアロン・デバイスとして実行される場合に、便宜上提供されます。
-# + PassThroughOption | 印刷ファイルを変更せずにパススルーする必要があることを指定します。 -# + フラグが指定されていない場合は、印刷ファイルがフォーマット設定されます。 フォーマッターの setup ルーチンに渡されるパラメーターには、0 ではなく 1 の値が含まれています。これは、ファイルをフォーマットする代わりにパススルーする必要があることを示しています。

例
pro
という名前の印刷キューに関連付けられている
std
という名前のキュー・デバイスのデータベース・ファイル (仮想プリンター記述) に従って
myfile
ファイルをフォーマットし、ページ幅を 132 文字にオーバーライドし、
pioformat
コマンドとフォーマッターをスタンドアロン・フィルターとして使用するには、次のように入力します。
cat myfile | pioformat
-@
pro:std -w 132 >/dev/lp0
スプーラーの下で実行されているパイプラインで
pioformat
コマンドおよびフォーマッターを使用するには、次のように入力します。
%Ide/pioformat
-@
%Idd/%Imm
-!
%Idf/piof420x %Fbb %Fee ...
この例では、以下のことが想定されています。
印刷装置は 4207-2 型プロプリンターです。
印刷キュー名は
pro.
です。
印刷キューに定義されているキュー・デバイス (仮想プリンター) は 1 つだけであり、その名前は
std
で、その出力データ・ストリーム・タイプは
asc
(拡張 ASCII) です。
プリンター名は
/dev/lp0.
です。
印刷ジョブ実行依頼者が、フラグと引数
-i 5
を指定しました。
印刷ジョブ・マネージャー (
piobe
コマンド) は、ファイルをフォーマットするためにパイプラインをシェルに渡す前に、属性値に対するパイプラインの組み込み参照を解決します。 この例で前述した前提事項に基づいて、属性参照を次のように解決できます。
項目 | 説明
%Ide -> /usr/lpd/pio/etc | pioformat コマンドが存在するディレクトリー
%Idd -> /var/spool/lpd/pio/@local/ddi | データベース・ファイルのディレクトリー。
%Imm -> 4207-2.asc.lp0.pro:std | データベース・ファイル名。
%Idf -> /usr/lpd/pio/fmtrs | フォーマッターのディレクトリー
%Fbb -> | ヌル・ストリング (実行依頼者が -b フラグを指定しなかったため)
%Fee -> -i 5 | 実行依頼者は、このフラグと引数を指定しました。
この後に表示される結果のパイプラインは、ファイルをフォーマット設定するためにシェルに渡すことができます (読みやすくするために複数行で表示されます)。

/usr/lpd/pio/etc/pioformat # initiate the formatter driver
-@/usr/lpd/pio/ddi/4207-2.asc.lp0.pro:std
# (digested) database file
-!/usr/lpd/pio/fmtrs/piof420x # loadable formatter
-i5 # formatting option
# (indent 5 characters)
