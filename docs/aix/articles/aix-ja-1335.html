目的
定義済みリソースを除去します。

説明
rmrsrc
コマンドは、指定された 1 つ以上のリソース・インスタンスを削除するか、「未定義」にします。
rmrsrc
コマンドは、Resource Monitoring and Control (RMC) サブシステムに対して、特定のリソース・インスタンスを定義解除する要求を出します。 リソースのリソース・マネージャーはそのリソースを除去します。
このコマンドの最初のフォーマットでは、リソース・クラス名パラメーターと、
-s
フラグを使用して指定された選択ストリングが必要です。 指定された選択文字列に一致する指定されたリソース・クラス内の全リソース除去されます。 選択文字列が除去するリソースを複数識別した場合は、
選択文字列に一致するリソースごとに一度ずつこのコマンドを実行するのと同じことです。
このコマンドの 2 番目の形式を使用することで、
特定のリソースにリンクした実際のリソース・ハンドルをパラメーターとして指定できます。 コマンドのこの形式は、スクリプト内で使用する必要があります。
selection_string
に複数のノード名を指定する代わりに、
-N
node_file
フラグを使用して、ノード名がファイル内にあることを示すことができます。 標準入力からノード名を読み取るには、
-N
"-"
を使用します。
システムにクラスター・システム・マネージメント (CSM) がインストールされている場合は、CSM 定義のノード・グループをノード名の値として使用して、複数のノードを参照できます。 CSM ノード・グループの処理および CSM
nodegrp
コマンドの使用については、「
CSM: 管理ガイド
」および「
CSM: コマンドおよびテクニカル・リファレンス
」を参照してください。

構文
1 つ以上のリソースを除去するには、以下のように実行します。 コマンド・ラインで入力する場合: rmrsrc -s " selection_string " [ -a | -N { node_file | "-" }] [ -h ] [ -TV ] resource_class rmrsrc -r 「リソース・ハンドル -h ][ -TV ] 入力ファイルでは次のように事前定義されています。 rmrsrc -f resource_data_input_file -s " selection_string " [ -a | -N { node_file | "-" }] [ -h ] [ -TV ] resource_class rmrsrc -f リソースデータ入力ファイル -r 「リソース・ハンドル -h ][ -TV ] コマンド引数の名前とデータ・タイプを表示するには、次のように入力します。 rmrsrc -l [ -h リソースクラス

例
リソース・クラス
IBM
.Host から名前c175n05を持つリソースを削除するには、次のように入力します：
rmrsrc -s 'Name == "c175n05"' IBM.Host
リソース・ハンドル 0x4017 0x0001 0x00000000 0x0069684c 0x0d52332b3 0xf3f54b45にリンクされているリソースを除去するには、次のように入力します。
rmrsrc -r "0x4017 0x0001 0x00000000 0x0069684c 0x0d52332b3 0xf3f54b45"
/tmp/common/node_file

Test1
という名前のリソースを
IBM.Foo
から削除するには、以下のようにします。
# common node file
#
node1.ibm.com main node
node2.ibm.com main node
node4.ibm.com backup node
node6.ibm.com backup node
#
次のように入力します。
rmrsrc -s 'Name == "Test1"' -N /tmp/common/node_file IBM.Foo
