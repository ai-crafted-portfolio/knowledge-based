目的

印刷ジョブを取り消します。

構文

qcan [ -X ] [ -x JobNumber ] [ -P プリンター ]

説明

qcan コマンドは特定のジョブ番号または印刷キュー内のすべてのジョブを取り消します。

System Management Interface Tool (SMIT) の smit qcan 高速パスを使用してこのコマンドを実行することもできます。

qstatus は、重複した 3 桁のジョブ番号を示して、ローカル・キューの管理を向上させるように拡張されています。 -W フラグを enq、qchk、lpstat、および lpq 状況コマンドと共に使用して、ジョブ番号の桁数をさらに多くして表示することができます。

キュー表示が重複した 3 桁のジョブ番号を示す場合は、qchk -W を使用してさらに高い精度でジョブ番号をリストしてください。 そうすると、特定のジョブを取り消すことができます。

例:qchkジョブ番号を表示する123その間に二度qchk -Wジョブ番号を表示します。1123および2123. ジョブ番号 2123 を取り消したい場合は、次のように指定します。qcan -x 123を使用すると、 qdaemon は、その内部リストで最初に見つかった一致するジョブ番号を取り消します。これは、以下のようになります。1123-W (W) フラグが提供する追加情報を使用して、特定のジョブ番号を取り消すことができます。

フラグ

項目
説明
-P プリンター すべてのジョブまたは選択したジョブ番号を取り消す Printer を指定します。
-x JobNumber JobNumber 変数で指定されたジョブ番号のみを取り消すことを指定します。
-X すべてのジョブまたは指定されたプリンターに関するすべてのジョブを取り消します。 root ユーザー権限がある場合は、そのキュー上のすべてのジョブが削除されます。 root ユーザー権限がない場合は、ユーザーが実行要求したジョブのみが取り消されます。 このフラグは、ローカル印刷ジョブに対してのみ有効です。

セキュリティー

アテンション RBAC ユーザー: このコマンドは特権操作を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

例

  1. プリンターでキューに入れられているすべてのジョブを取り消すlp0次のように入力します。
    qcan  -X  -P lp0
  2. ジョブ番号を取り消す123ジョブがどのプリンターにあっても、次のように入力します。
    qcan  -x 123
