目的

Server Message Block (SMB) クライアント・ファイルシステムのマウント操作の統計情報を表示します。

構文

/usr/sbin/smbcstat [-l] [-s <remote share> | -d <mount point>]

説明

smbcstat コマンドは、SMB クライアント・ファイルシステムのマウント操作の統計情報を表示します。 マウントされた特定のリモート・ディレクトリー、特定のマウント・ポイント、または論理区画内のすべてのマウント・ポイントの統計情報を表示できます。 オプションを指定しない場合、smbcstat コマンドは、論理区画内のすべての SMB マウント・ポイントの統計情報をリストします。

フラグ

-マウントポイント
この操作に引数として指定された SMB マウント・ポイントの統計情報をリストします。
-l
すべての SMB マウント・ポイントの統計情報をリストします。
-リモートシェア
この操作に引数として指定されたリモート・マウント・ポイントのマウント統計情報をリストします。

終了状況

0
成功を示します。
>0
エラーを示します。

例

  • SMB クライアント・ファイルシステム内のすべてのマウント・ポイントの統計情報をリストするには、次のコマンドを入力します。

    smbcstat -l
