目的
/etc/cifs_fs/cifscred
ファイルに保管されているサーバー項目またはユーザー項目をリストします。

説明
lscifscred
コマンドは、
/etc/cifs_fs/cifscred
ファイルにパスワードが保管されているすべてのサーバー項目またはユーザー項目をリストします。

構文
lscifscred [ -h RemoteHost ] [ -u ユーザー ]

オプション
フラグ
項目 | 説明
-h RemoteHost | 指定されたリモート・ホスト (CIFS サーバー) のみにマッチングする証明書をリストします。
-u ユーザー | 指定されたユーザー名のみにマッチングする証明書をリストします。

例
server1
と名付けられているサーバー上のすべてのサーバー項目またはユーザー項目をリストするには、次のように入力します。
lscifscred -h server1
