目的
インストールされたバージョンの AIX のコマンドに不足しているファイルセットを特定し、自動的にインストールします。

説明
自動ファイルセット・インストールの有効化、無効化、またはステータスの確認は、
autofsinstall
コマンドで行うことができます。 この機能を有効にすると、
autofsinstall
コマンドは
which_fileset
コマンドを使用して、見つからないコマンドに必要な適切なファイルセットを自動的に特定する。
LPP（Licensed Program Product）リソースが割り当てられているNIM（Network Installation Management）サーバーがシステムを管理する場合、システムは以下のアクションを実行します：
見つからないファイルセットの名前を表示する
不足しているファイルセットのインストールを確認するプロンプトが表示されます
NIMサーバーから必要なファイルセットを取得し、インストールを確認すると自動的にインストールする

構文
autofsinstall [ -a ] [ -d ] [ -l ]

オプション
フラグ
項目 | 説明
-a | 不足しているコマンドのファイルセットの自動インストールを有効にし、永続化のために .profile ファイルを更新します。
-d | 自動インストール機能を無効にし、自動インストールに関連するエントリを .profile ファイルから削除します。
-l | 不足しているコマンドのファイルセットの自動インストール状態が有効か無効かを表示します。

例
不足しているコマンドのファイルセットの自動インストールを有効にするには、以下のコマンドを入力する：
autofsinstall -a
変更を適用するには、新しいターミナルを開く。
不足しているコマンドのファイルセットの自動インストールを無効にするには、以下のコマンドを入力する：
autofsinstall -d
変更を適用するには、新しいターミナルを開く。
不足しているコマンドのファイルセットの自動インストールのステータスを確認するには、以下のコマンドを入力する：
autofsinstall -l
