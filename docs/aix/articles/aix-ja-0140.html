目的
cfgvsd
-仮想共用ディスクを構成します。

説明
既に定義された仮想共有ディスクを構成し、停止状態にするにはこのコマンドを使用します。 この
コマンドは仮想共有ディスクを使用可能にしません。
通常の環境では、このコマンドを発行すべきではありません。 リカバリー可能仮想共有ディスク・サブシステムがこのコマンドを使用して、
共有ディスクを
制御された方法で管理します。 このコマンドを
発行する場合、結果は予測不能です。
System Management Interface Tool (SMIT) を使用して、
cfgvsd
コマンドを実行することができます。 SMIT を使用するには、以下のように入力します。
smit vsd_mgmt
そして「
仮想共有ディスクの構成 (Configure a virtual shared disk)
」オプションを選択します。

構文
cfgvsd { -a | vsd_name ...}

オプション
フラグ
-a
定義されているすべての仮想共有ディスクを指定します。

例
仮想共用ディスク
vsd1vg1n1
を定義済み状態から停止状態にするには、次のように入力します。
cfgvsd vsd1vg1n1
