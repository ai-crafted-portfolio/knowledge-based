目的
構成されているすべてのキューの名前をリストします。

説明
デフォルトでは、'
lsallq
コマンドは、'
/etc/qconfig
ファイルに含まれる、すべての設定済み キューの名前をリストアップする。
プリンタ AIX サブシステムの拡張機能が無効になっている場合、この
lsallq
コマンドは設定済みキューをすべて表示します。
/etc/qconfig.bin
調整可能な
printer_scalability
パラメータの詳細については、
その他の調整可能なパラメータ
ページの該当
printer_scalability
セクションを参照してください。
-c
フラグを指定すると、このリストはコロン形式で表示される。 このフラグは、主にシステム管理インターフェイスツール（SMIT）で使用される。
また、System Management Interface Tool (SMIT)
smit lsallq
高速パスを使用しても、このコマンドを実行できます。

構文
lsallq [ -c ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-c | コロン・フォーマットの出力を SMIT で使えるようにします。

例
/etc/qconfig
ファイル内のキュー名をリストアップするには、以下のコマンドを入力する：
lsallq
以下のようなリストが表示される：
lp0
lp1
lp2
設定されているすべてのキューをコロン形式で一覧表示するには、以下のコマンドを入力します：
lsallq -c
以下のようなリストが表示される：
lp0
lp0:queue1
lp0:queue2
lp1
