目的

ホストシステムに現在インストールされているマイクロコードまたはバイタル・プロダクト・データ（VPD）を調査する。

構文

invscout [ -v ] [ -m  machine_type_and_model ] [ -s  serial_number ] [ -q ]

invscout [ -u [ mask] ] [ -e ] [ -r ] [ -m  machine_type_and_model ] [ -s  serial_number ] [ -catl microcode_catalog_path ] [ -q ]

invscout [ -U | -UF [ mask] ] [ -e ] [ -m  achine_type_and_model ] [ -s  serial_number ] [ -catl microcode_catalog_path] [ -fl microcode_file_path] [ -q ]

invscout [ -h | -g ]

説明

invscout コマンドは、インベントリー・スカウト (Inventory Scout) プロセスのスタンドアロン・バージョンの 1 つのインスタンスを実行します。 invscoutdコマンドは、クライアントまたはサーバー・バージョンのサーバー・デーモン側を起動する。

Inventory Scoutプロセスは、以下の2つの調査タイプをサポートしています：

  • マイクロコード調査
  • VPD調査 ( '-v)
マイクロコード調査

マイクロコード調査は、インベントリスカウトプロセス、デバイス、およびアダプタのサポートされているシステムに対して現在インストールされているマイクロコードに関するホストシステムのデータを収集します。 次の表は、マイクロコード・サーベイが収集するデータタイプと、データが保存されるファイルについて説明しています：

VPDサーベイ(-v)
VPDサーベイは、システムのVPDを VPDサーベイアップロードファイルに保存し、インターネットを通じてウェブサーバーにアップロードすることができる。 CGIはファイルをリポジトリに転送し、操作のステータスを示すウェブページを作成する。
VPD 調査の場合、定様式テキスト・レポートはありません。

フラグ

項目
説明
-v 調査または連結タイプを VPD に設定します (デフォルトはマイクロコード)。 このオプションは、ユーザーグループ'systemまたは'invscoutに属するユーザーのみサポートされています。
-r マイクロコードサーベイの場合、フォーマットされたテキストレポートファイルのコピーを、コマンドが開始されたスクリーンに送信する。 -v フラグまたは -c フラグが使用されている場合、このフラグは無視されます。
注意: このフラグは推奨されません。 代わりに「–uオプションを使用する。
-m machine_type_and_model VPD調査の場合、この情報を使用または必要とするホストに対して、ホストプラットフォームのマシンタイプとモデルの入力を許可する。
-s serial_number VPD 調査の場合は、ホストのホスト・シリアル番号を入力し、この情報を使用する、または必要とするホストに渡します。
-catl マイクロコード・カタログ・パス マイクロコードカタログファイルのデフォルトの場所を上書きする。
-g このコマンドおよび現在使用中の論理データベースのバージョンを表示します。
-q ほとんどのランタイムメッセージを抑制する。
-h ヘルプ (使用方法) ステートメントを生成します。 このフラグを使用した場合、その他のすべてのフラグは無視されます。
-U マスク 利用可能なマイクロコードアップデートでデバイスを更新します。 このフラグでは、システムに次の項目が存在していることが要求されます。
  • 有効なマイクロコード・カタログ・ファイル
  • 有効なマイクロコード・イメージ

マスクの有効なオプションには、以下の値の組み合わせがある：

  • L、l：最新
  • C,c：電流
  • P、P前
  • A,a: 利用可能
  • オー、オー：結果
  • D,d：説明
  • E,e：効果
  • S,s：提案されたアクション
-UF マスク 利用可能なマイクロコードアップデートでデバイスとシステムファームウェアを更新します。 このフラグでは、システムに次の項目が存在していることが要求されます。
  • 有効なマイクロコード・カタログ・ファイル
  • 有効なマイクロコード・イメージ
このフラグはシステムを再起動させるかもしれない。

マスクの有効なオプションには、以下の値の組み合わせがある：

  • L、l：最新
  • C,c：電流
  • P、P前
  • A,a: 利用可能
  • オー、オー：結果
  • D,d：説明
  • E,e：効果
  • S,s：提案されたアクション
-u マスク マイクロコード更新が使用可能なハードウェアを識別する定様式テキスト・レポートを生成します。 このフラグでは、有効なカタログ・ファイルがシステムに存在していることが要求されます。

マスクの有効なオプションには、以下の値の組み合わせがある：

  • L、l：最新
  • C,c：電流
  • P、P前
  • A,a: 利用可能
  • オー、オー：結果
  • D,d：説明
  • E,e：効果
  • S,s：提案されたアクション
-fl マイクロコード・ファイル・パス マイクロコード・ファイルのデフォルト・パス名を変更します。 これらのファイルは「.rpm形式で保存される。 このオプションはrootユーザー専用です。
-e –U または -u フラグとともに使用する必要がある。 -e フラグは、コール・ホーム・クラウド・コネクト（CHCC）から最新のマイクロコード・カタログ・ファイルをダウンロードし、フィックス・セントラル・データベースからマイクロコードの更新を取得します。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 正常終了したことを示します。
ゼロ以外 エラーが発生したことを示します。

エラーが発生した場合、コマンドはエラーログを書き込む。

セキュリティー

このコマンドはrootが所有し、どのユーザーでも実行できるように「setuidビットをONにしてインストールされる。

例

  1. マイクロコード・サーベイを 1 回実行し、結果をフォーマットされたテキスト・レポート・ファイルとアップロード・ファイルに送信するには、次のコマンドを入力します：
    invscout
  2. VPDサーベイを1回実行し、結果をアップロードファイルに送信するには、以下のコマンドを入力する：
    invscout -v
