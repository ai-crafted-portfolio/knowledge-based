目的
Network Information Services
(
NIS
) が使用する
netid.byname
マップのデータを生成します。

説明
mknetid
コマンドを使用して、
netid.byname
NIS マップ用のデータを生成します。 このコマンドはコマンド・ラインで指定されたファイルを構文解析し、対応する NETID キーと値を構築します。 ユーザーは次のエントリーを受け取ります。
unix.<uid>@<domainname> <uid>:<gid1>,<gid2>,...
ホストは次のエントリーを受け取ります。
unix.<hostname>@<domainname> 0:<hostname>
使用されるドメイン名は、
mknetid
の実行時にシステムで構成されるものと同じです。 生成されたデータは
stdout
に送信されます。 それぞれの行にはエントリーが 1 つ含まれ、キーとデータがスペースで区切られて入っています。

構文
NIS マップを作成するには、以下のようにします。 /usr/sbin/mknetid [ -q (Q) ] [ P- PasswordFile ] [ - GroupFile ] [ -h HostsFile ] [ -m (M) NetidFile ]

オプション
フラグ
項目 | 説明
-q | quiet モード - データについての警告を報告しません。
-p PasswordFile | ユーザーのリストを読み取るために使用される passwd ファイルを指定します。
-g GroupFile | グループ・メンバーシップのリストを読み取るために使用される groups ファイルを指定します。
-h HostsFile | ホスト名のリストを読み取るために使用される hosts ファイルを指定します。
-m NetidFile | 組み込まれる NETID の追加エントリーを読み取るファイルを指定します。
