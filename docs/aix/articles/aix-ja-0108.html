目的
システム全体または各アクセラレーターおよびプロセスの、コヒーレント・アクセラレーターに関連する統計のレポートを作成します。

説明
caccelstat
コマンドは、システム内のコヒーレント・アクセラレーターのアクティビティーをモニターするために使用します。 このコマンドは、すべての Coherent Accelerator Processor Interface (CAPI) 対応プロセスに関する集約統計のレポートを作成できます。または、各 CAPI 対応プロセスに関する統計も表示できます。 また、このコマンドは各 Accelerator Function Unit (AFU) の統計も表示できます。この場合、AFU は
/dev/caccel0
などのコヒーレント・アクセラレーター・デバイスです。
システム全体の集約統計
システム全体の集約統計レポートには、以下の情報が含まれます。
CAPI 対応プロセスの数
システム内のアクセラレーターの数
ユーザー・コンテキストの数
カーネル・コンテキストの数
マスター・コンテキストの数
ページ・フォールトの数
セグメント・テーブル (STAB) フォールトの数
AFU エラーの数
AFU 例外の数
AFU シグナルの数
AFU 停止の数
コンテキスト統計
このレポートには、コンテキスト統計 (コンテキストごとに 1 行ずつ) が含まれます。 プロセス ID (pid) もデバイスも指定されていない場合、システム内の登録済みのすべてのユーザー・コンテキストがレポート対象になります。 カーネル・コンテキストは除外されます。 pid またはデバイスのいずれかが指定されている場合、その pid またはデバイスのコンテキストがレポート対象になります。 pid とデバイスの両方が指定されている場合、選択された pid とデバイスに関連するコンテキストのみがレポート対象になります。
以下の情報を含むレポート。
State
コンテキストの状態。
このフィールドには、以下の値が含まれる可能性があります。
S
コンテキストは中断状態です。
R
コンテキストは実行状態です。
D
コンテキストは切り離し状態です。
A
コンテキストは接続状態です。
E
コンテキストはエラー状態です。
マスター・プロセスの場合、各状態と
M
が組み合わせて表示されます。 例えば、マスター・プロセスのコンテキストが実行状態の場合、状態フィールドには
MR
と表示されます。
注:
実行状態 (
R
) は、AFU がこのコンテキストを実行していることを意味するものではありません。 この意味は、他のどの状態でもないということです。
pid

プロセス ID オプションに pid が指定されている場合、この列はスキップされます。
pf
ページ・フォールト数。
spf
STAB フォールトの数。
pi
ページインの数。
err
プロセス・エラーの数。
exc
プロセス例外の数。
sig
プロセス・シグナルの数。
stalls
例外が原因で起こった AFU 停止の数。
aur
このプロセスの Accelerator Utilization Register (AUR) の値。 AUR がサポートされていない場合、このフィールドには 0 が表示されます。
装置
装置名。 オプションにデバイスが指定されている場合、この列はスキップされます。
集約デバイス (AFU) 統計
このレポートには、すべてのプロセス・コンテキストに関する AFU の集約統計が含まれます。 デバイスが指定されない場合、システム内のすべての AFU の統計がレポート対象になります。 このレポートには、以下の列 (デバイスごとに 1 行ずつ) が含まれます。
nctx
登録済みプロセス・コンテキストの数。
pf
ページ・フォールト数。
spf
STAB フォールトの数。
pi
ページインの数。
err
AFU エラーの数。
exc
AFU 例外の数。
sig
AFU シグナルの数。
stalls
例外キューが満杯になったことが原因で起こった AFU 停止の数。
装置
装置名。 オプションにデバイスが指定されている場合、この列はスキップされます。
プロセス・コンテキスト統計の集約
このレポートには、CAPI 対応プロセスに関する集約統計とプロセス・コンテキストごとの統計が含まれます。 pid は AIX プロセス ID です。 pid が指定されない場合、システム内のすべての CAPI 対応プロセスの統計がレポート対象になります。
このレポートには、以下の列 (コンテキストごとに 1 つずつ) が含まれます。
pid
AIX プロセス ID。 オプションにデバイスが指定されている場合、この列はスキップされます。
nctx
登録済みプロセス・コンテキストの数。
pf
ページ・フォールト数。
spf
STAB フォールトの数。
pi
ページインの数。
err
AFU エラーの数。
exc
AFU 例外の数。
sig
AFU シグナルの数。
stalls
例外キューが満杯になったことが原因で起こった AFU 停止の数。
aur

このプロセスの Accelerator Utilization Register (AUR) の値。 AUR がサポートされていない場合、このフィールドには 0 が表示されます。
デバイス・カーネル・コンテキスト統計の集約
このレポートには、デバイス・カーネル・コンテキストの集約統計、またはデバイスごとのカーネル・コンテキスト統計が含まれます。 デバイスが指定されない場合、すべての AFU に関する統計がレポート対象になります。 このレポートには以下の列 (デバイスごとに 1 つずつ) が含まれます。
pf
ページ・フォールト数。
spf
STAB フォールトの数。
pi
ページインの数。
err
AFU エラーの数。
exc
AFU 例外の数。
装置
装置名。 オプションにデバイスが指定されている場合、この列はスキップされます。
システム内の各アクティブ・ワークロード・パーティション (WPAR) の集約統計
このレポートには、システム内に存在する各アクティブ WPAR の集約統計が含まれます。 このレポートには、以下の列 (WPAR ごとに 1 行ずつ) が含まれます。
wpar
WPAR 名。
nctx
コンテキストの数。
pf
ページ・フォールト数。
spf
STAB フォールトの数。
pi
ページインの数。
err
AFU エラーの数。
exc
AFU 例外の数。
sig
AFU シグナルの数。
stalls
AFU 停止の数。

構文
システム全体の集約統計 caccelstat -a [-t count] [-i interval] コンテキスト統計 caccelstat -c [-p pid -d device] [-t count] [-i interval] [-@ wparname] 装置またはアクセラレーター機能単位 (AFU) 統計の集約 caccelstat -d [device] [-t count] [-i interval] [-@ wparname] プロセス・コンテキスト統計の集約 caccelstat -p [pid] [-t count] [-i interval] [-@ wparname] デバイス・カーネル・コンテキスト統計の集約 caccelstat -k [device] [-t count] [-i interval] [-@ wparname]

オプション
フラグ
フラグ | 説明
-a | システム全体の集約統計のレポートを作成します。
-c | コンテキストごとの統計のレポートを作成します。
-d | AFU の集約統計のレポートを作成します。
-p | プロセスの集約統計のレポートを作成します。
-k | デバイス・カーネルに関する集約統計のレポートを作成します。
-t カウント | 統計報告の必須回数を指定します。
-i 間隔 | 統計報告間の必須時間間隔 (秒数) を指定します。
-@ ALL | システム内に存在する各アクティブ WPAR に関する集約統計のレポートを作成します。
-@ ワーパルネーム | 指定された WPAR に関する集約統計のレポートを作成します。
