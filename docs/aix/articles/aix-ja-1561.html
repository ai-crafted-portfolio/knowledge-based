目的
プログラムの出力を表示して、その出力をファイルにコピーします。

説明
tee
コマンドは標準入力を読み取り、プログラムの出力を標準
出力に書き出すと同時に、指定されたファイルもしくは、複数のファイルにコピーします。

構文
tee [ -a ] [ -i ] [ File ... ]

オプション
フラグ
項目 | 説明
-a | 上書きする代わりに File の終わりに出力を追加します。
-i | 割り込みを無視します。

例
コマンドからの出力を同時に表示して保存するには、以下のようにします。
lint program.c | tee program.lint
これにより、ワークステーションでコマンド
lint
program.c
の標準出力が表示され、同時にそのコピーがファイルに保存されます。
program.lint.
次の名前のファイルが
program.lint
既に存在しています。削除されて置き換えられます。
コマンドからの出力を表示して既存のファイルに保存するには、以下のようにします。
lint program.c | tee
-a
program.lint
これにより、
lint
program.c
コマンドの標準出力がワークステーションで表示され、同時にそのコピーがワークステーションの末尾に追加されます。
program.lint
ファイル
.
もし
program.lint
ファイルが存在しません。作成されます。
