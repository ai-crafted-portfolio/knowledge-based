目的

メールの別名とそのアドレスをリストします。

構文

ali [ -alias File ] [ -list | -nolist ] [ -normalize | -nonormalize] [ -user User | -nouser ] [ Alias ... ]

説明

ali コマンドは、メールの別名とそれぞれのアドレスを出力します。 デフォルトでは、このコマンドは /etc/mh/MailAliases ファイルを検索し、そのファイルに定義されている各別名とそのアドレスを標準出力に書き出します。 代替メール別名ファイルを指定するには、 -alias File フラグを使用します。

-user フラグを指定すると、 ali コマンドは別名ファイルでユーザー名を検索し、このユーザー名を含む別名を標準出力に書き出します。

フラグ

表 1. フラグ
項目
説明
-alias ファイル 検索するメール別名ファイルを指定します。 デフォルトは /etc/mh/MailAliases ファイルです。
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。
注: MH の場合は、このフラグ名を省略することはできません。
-list アドレスを 1 行に 1 つずつ表示します。
-nolist アドレスをできるだけ少数の行に表示します。 このフラグはデフォルトです。
-nonormalize ローカル・ホスト・ニックネームが公式ホスト名に変換されないようにします。 このフラグはデフォルトです。
-normalize ローカル・ホスト・ニックネームを公式ホスト名に変換します。
-nouser 別名のアドレスを出力します。 このフラグはデフォルトです。
-user ユーザー 指定したユーザーを含む別名を出力します。 -user フラグと -nonormalize フラグを共に使うと、指定したユーザーを含む別名の部分リストを表示することができます。

例

  1. /etc/mh/MailAliases ファイル内のすべての別名とそのアドレスのリストを表示するには、次のように入力します。
    ali
  2. mygroup 別名の名前とアドレスをリストするには、次のように入力します。
    ali   mygroup
    次のようなリストが、ローカル・システムに表示されます。
    mike@mercury   george@helium   vicky@venus
