目的
ソリッド・ステート・ドライブ (SSD) デバイスでキャッシングを提供するインフラストラクチャーを管理します。

説明
cache_mgt
コマンドは、SSD デバイス上のキャッシングを管理するために使用されます。 このコマンドにより、以下の機能が提供されます。
システム上のキャッシュ・プールの作成または拡張に使用できる SSD デバイスをリストします。
システム上のキャッシュ・プールの作成、削除、拡張、およびリスト表示を行います。 キャッシュ・プールとは、SSD デバイスのグループのことです。 キャッシュ区画は、キャッシュ・プールから作成されます。
システム上のキャッシュ区画の作成、削除、拡張、割り当て、割り当て解除、およびリスト表示を行います。 キャッシュ区画は、キャッシュ・プールの一部です。 キャッシュ区画は、キャッシュに入れる必要があるターゲット・デバイスに割り当てられる必要があります。
ターゲット・デバイスのキャッシングを開始および停止します。 また、キャッシュ区画を、割り当て先のターゲット・デバイスおよびそのキャッシング状況とともにリストします。 キャッシュ・エンジンは、キャッシングの開始前に登録される必要があります。
キャッシュ統計をモニターします。
キャッシュ・エンジンの登録と登録抹消を行います。 また、登録済みのキャッシュ・エンジンの情報をリストします。
キャッシング・モード
キャッシングは、以下のいずれかの方法で実行できます。
物理モード
キャッシュ・デバイス (SSD デバイス) は、論理区画 (LPAR) に直接割り当てられます。
cache_mgt
コマンドを使用して、キャッシュ・プール、キャッシュ区画、およびターゲット・デバイスのキャッシングを管理できます。
仮想モード
キャッシュ・デバイス (SSD デバイス) は、仮想入出力サーバーに割り当てられます。 キャッシュ・プールおよびキャッシュ区画は、仮想入出力サーバーで管理されます。 仮想入出力サーバー上のキャッシュ区画は、仮想 SCSI を使用してクライアント LPAR に対して仮想化できます (仮想キャッシュ・デバイス)。 キャッシュ区画の割り当てとキャッシングは、LPAR で管理される必要があります。
キャッシュ・エンジン情報
キャッシュ・エンジン・モジュールは、ターゲット・デバイスをキャッシュ区画のキャッシュに入れます。 キャッシュ・エンジンは、デフォルトで組み込まれていて、クライアント LPAR で自動的に登録されます。
物理モードでは単一のキャッシュ・プールのみがサポートされており、単一のキャッシュ区画でのみキャッシングを開始できます。

構文
cache_mgt object action [-I [level]] [-T [timeout]] キャッシュ・デバイス管理コマンド cache_mgt device list [-l] キャッシュ・プール管理コマンド cache_mgt pool list [-l] cache_mgt pool create -d devName[,devName,...][-p poolName] [-f] cache_mgt pool remove [-p poolName] [-f] cache_mgt pool extend [-p poolName] -d devName[,devName,...] [-f] キャッシュ区画管理コマンド cache_mgt partition list [-l] cache_mgt partition create [-p poolName] -s partitionSize [-P partitionName] cache_mgt partition remove [-P partitionName] [-f] cache_mgt partition extend [-P partitionName] -s partitionSize cache_mgt partition assign [-P partitionName] -t targetDevName cache_mgt partition unassign {-t targetDevName | [-P partitionName]} [-f] ターゲット・デバイス上のキャッシングを管理するためのコマンド cache_mgt cache list cache_mgt cache start {-t targetDevName -P partitionName | -t {targetDevName | all} | -f} cache_mgt cache stop {-t {targetDevName | all} | -p {poolName | all}} 統計モニター・コマンド cache_mgt monitor start cache_mgt monitor stop cache_mgt monitor get {-h -s | -h | -s} キャッシュ・エンジンを管理するためのコマンド cache_mgt engine list [-l] cache_mgt engine register -n cePath cache_mgt engine unregister [-n cePath]

オプション
フラグ
キャッシュ・デバイス管理コマンド
オブジェクト | アクション | フラグおよびパラメーター | 説明
device | リスト | [ -l ] | SSD デバイスをリストします。 -l フラグを使用すると、コマンドは、関連するキャッシュ・プール名を出力します。
キャッシュ・プール管理コマンド
オブジェクト | アクション | フラグおよびパラメーター | 説明
プール | リスト | [ -l ] | キャッシュ・プールをリストします。 -l フラグを使用すると、コマンドは、関連する SSD デバイスも出力します。
プール | 作成 | -d デバイス名 [, デバイス名 ,...] [ -p poolName ] [ -f ] | -d フラグで指定された SSD デバイスのリストを使用して、キャッシュ・プールを作成します。 プール名は、 -p フラグでも指定できます。 強制 -f ) フラグを指定すると、デバイスが以前にどのように使用されていたかに関係なく、キャッシュ・プールが作成されます。
プール | remove | [ -p poolName ] [ -f ] | キャッシュ・プールを削除します。 区画がまだプール内に存在している場合、このアクションは失敗します。 強制 ( -f ) フラグを指定すると、プール内に存在しているすべての区画が削除されます。
プール | extend | [ -p poolName ] ' -d devName [ ,devName ,...] [ -f ] | -d フラグで指定された SSD デバイスのリストを使用して、既存のプールを拡張します。 強制 -f ) フラグを指定すると、デバイスが以前にどのように使用されていたかに関係なく、キャッシュ・プールが拡張されます。
キャッシュ区画管理コマンド
オブジェクト | アクション | フラグおよびパラメーター | 説明
区画 | リスト | [ -l ] | キャッシュ区画 (仮想キャッシュ・デバイス) をリストします。 -l フラグを使用すると、コマンドは、区画が論理ボリュームである場合は関連するプール名、構成されている場合には関連するターゲット・デバイス名をコンマ区切り形式で出力します。

区画 | 作成 | [ -p poolName ] -s partitionSize [ -P partitionName ] | プール内にキャッシュ区画を作成します。 プール名は、 -p フラグで指定できます。 区画名は、 -P フラグで指定できます。 区画サイズは、 -s フラグで指定できます。 区画のサイズは、以下のいずれかの単位でなければなりません。 B/b 512 byte blocks K/k KB M/m MB G/g GB
区画 | remove | [ -P partitionName ] [ -f ] | キャッシュ・プールから区画を削除します。 区画名は、 -P フラグで指定できます。 注: パーティションを削除する前に、割り当てを解除する必要があります。 あるいは、強制 ( -f ) フラグを使用して削除します。
区画 | extend | [ -P partitionName ] -s partitionSize | -s フラグで指定された partitionSize 値によって既存のパーティションを拡張します。 partitionName 値は、 -P フラグでも指定できます。
区画 | 割り当て | [ -P partitionName ] -t targetDevName | -P フラグで指定されたキャッシュ区画名と、構成の -t フラグで指定されたターゲット・デバイス名との間の関係を作成します。 キャッシング状態は 0 (停止済み) のままになり、キャッシング操作は開始されません。 キャッシング操作を開始して、構成のキャッシング状態を変更するには、 cache start -t アクションを実行する必要があります。
区画 | 割り当て解除 | -t targetDevName [ -f ] | キャッシュ区画と、構成の -t フラグで指定されたターゲット・デバイス名との間の関係を削除します。 削除する前に区画のキャッシングを停止する必要があります。あるいは、削除する前に強制 ( -f ) フラグを使用します。
区画 | 割り当て解除 | [ -P partitionName ] [ -f ] | キャッシュ区画と、構成の中のすべてのターゲット・デバイスとの間の関係を削除します。 削除する前に区画のキャッシングを停止する必要があります。あるいは、削除する前に強制 ( -f ) フラグを使用します。
ターゲット・デバイス上のキャッシングを管理するためのコマンド

オブジェクト | アクション | フラグおよびパラメーター | 説明
キャッシュ | リスト | | キャッシング操作が開始された対象の区画をリストします。
キャッシュ | start | -t targetDevName -P partitionName | -t フラグで指定されたターゲット・デバイス名のキャッシング操作を、 -P フラグで指定されたキャッシュ区画名で開始します。
キャッシュ | start | -t { targetDevName | すべて} | 以前に割り当てられたキャッシュ区画に対して、 -t フラグで指定されたターゲット・デバイス名のキャッシング操作を開始します。 all オプションに -t フラグを指定した場合、コマンドは、関連付けられているすべてのターゲット・デバイスのキャッシング操作を開始します。
キャッシュ | start | -f | キャッシュ・デバイスがない場合でも、キャッシュ・エンジンをロードします。
キャッシュ | 停止 | -t { targetDevName | すべて} | -t フラグで指定されたターゲット・デバイス名のキャッシング操作を停止します。 all オプションに -t フラグを指定した場合、コマンドは、関連付けられているすべてのターゲット・デバイスのキャッシング操作を停止します。 キャッシュ区画割り当ての定義は、構成から削除されません。
キャッシュ | 停止 | -p { poolName | すべて} | -p フラグで指定されたキャッシュ・プール名のすべてのターゲット・デバイスのキャッシング操作を停止します。 all オプションに -p フラグを指定した場合、コマンドは、関連付けられているすべてのターゲット・デバイスのキャッシングを停止します。 キャッシュ区画割り当ての定義は、構成から削除されません。
