目的
ユーザーを認証し、PAG 関連付けを作成します。

説明
paginit
コマンドは、
username
(デフォルトでは、コマンドを実行するユーザー) を認証し、
username
とカーネル・トークン (プロセス認証グループ・エントリー (PAG) と呼ばれる) の関連付けを作成します。 このコマンドにより、新しいログイン・シェルが作成されます。
-R
フラグを指定しないと、
paglist
はユーザーのレジストリー属性を照会し、
その値を
module_name
に使用します。
ユーザー名
を代替の ID および認証 (I & A) メカニズムに関連付けるために、
-R
フラグを使用して、ユーザーの作成に使用する I & A ロード・モジュールを指定できます。 ロード・モジュールは、
/usr/lib/security/methods.cfg
ファイルで定義されます。

構文
ページ初期化 [ -R モジュール名 ] [ ユーザー名 ]

オプション
フラグ
項目 | 説明
-R モジュール名 | ユーザーの認証に使用するロード可能な I&A モジュールを指定します。

例
paginit -R FPKI
ユーザーはレジストリー FPKI を使用して認証され、
これは
/usr/lib/security/methods.cfg
ファイルに定義されています。 PAG は現行のプロセス・クレデンシャルと関連付けられます。
