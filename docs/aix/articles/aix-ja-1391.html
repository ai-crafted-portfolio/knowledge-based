目的
SCCS ファイルの現在の編集状況を表示します。

説明
sact
コマンドは、ソース・コード制御システム (SCCS) ファイルを読み取って、
指定した
File
変数の値に関連した p ファイルの内容があれば、
それを標準出力に書き出します。 p ファイルは、
get -e
コマンドで生成されます。
ファイル
value
,
に
-
(負符号) を指定すると、
SACT
コマンドは標準入力を読み取り、各行を SCCS ファイルの名前として解釈します。
File
値がディレクトリーになっている場合、
sact
コマンドは、すべての SCCS ファイルに対してアクションを実行します。

構文
sact ファイル ...

例
p ファイルの内容を表示するには、以下のように入力します。
sact File
