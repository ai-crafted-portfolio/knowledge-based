目的
PostScript ファイルのページ順序を反転し、印刷するページ範囲を選択します。

説明
psrev
コマンドは、
File
変数で指定したファイルのページ順序を逆にし、
Pagespec
パラメーターで指定したページを印刷します。 ファイルは、 PostScript ファイル構造化規則に準拠している必要があります。
File
に値を指定しないと、
psrev
コマンドは標準入力から読み取ります。
psrev
コマンドは、結果として生成されたファイルを標準出力へ書き出します。

構文
PSCREV [ -R ] [ -s パゴスペック ,... ] [ ファイル ]

オプション
フラグ
項目 | 説明
-R | ページ順序を逆にしません (指定すれば、ページをサブセットします)。
-s パゴスペック | 印刷すべきページの範囲 (または複数の範囲) を指定します。 Pagespec パラメーターはスペースなしの文字列です。 パゴスペック パラメーターは、単一ページ番号、または N-M という形式の範囲にすることができます。これは、 N から 分 までのページを印刷します。 -N (N) は、文書の先頭から N ページまでを印刷します。 M- は、 分 ページから文書の終わりまでを印刷します。

例
次は、ページ範囲と逆順しない個別ページを示した
psrev
コマンドの使用例です。
psrev -R -s2-4,6
psrev -R -s2-4,6-8
