目的
印刷ジョブをキューに入れます。

説明
lpr
コマンドはスプーリング・デーモンを使って、
機能が使用可能になったときに指定された
File
パラメーターを印刷します。 ファイルが指定されないと、
lpr
コマンドは標準入力から読み取ります。

構文
LPR [ 「-f」 ] [ - ] [ -h ] [ -j (J) ] [ - ] [ -m (M) ] [ N ] [ P- ] [ - ] [ -s ] [ -P プリンター ] [ -# NumberCopies ] [ -C クラス ] [ -J ジョブ ] [ -T (T) タイトル ] [ I [ NumberColumns ] ] [ -w (W) 幅 ] [ ファイル ... ]

オプション
フラグ
項目 | 説明
-# 数値 | 指定された各ファイルの印刷部数として Number 変数を使用して、複数の出力を作成します。
-C クラス | 印刷 Class をバースト・ページ上のジョブ分類として指定します。
-f | フィルターを使用して、各行の先頭文字を標準の FORTRAN 紙送り制御文字として解釈します。
-g | 指定したファイルは標準の作図データが設定されているものと想定されます。
-h | バースト・ページの印刷を抑制します。 注: デフォルトでは、トレーラー・ページではなくヘッダー・ページが印刷されます。
-i [ 数値 ] | 出力を Number 変数スペース分、字下げします。 Number 変数を指定していない場合は、 デフォルトとして 8 個のスペースが字下げされます。
-j | 以下のメッセージを指定します。 Job number is: nnn , 各項の説明は次のとおりです。 nnn 割り当てられたジョブ番号です。標準出力に表示されます。 このメッセージは、ジョブがローカル印刷キューに実行依頼されると表示されます。
-J ジョブ | Job 変数をジョブ名としてバースト・ペーストに印刷します。 通常、 lpr コマンドは最初のファイルの名前を使用します。
-l | (小文字の L) フィルターを使用して、制御文字を印刷可能にします。
-m | スプーリングが完了するとメールを送ります。
-n | ditroff (デバイスに依存しない troff ) データを含むファイルをフォーマットするフィルターを使用します。
-P プリンター | 強制的に Printer 変数に出力します。 このフラグが指定されない場合、次の条件が発生します。 デフォルトの値が設定されている場合、 lpr コマンドはデフォルト・プリンターを使用します。 LPDEST 環境変数が設定されている場合は、 lpr は LPDEST 変数により指定された値を使用します。 この環境変数を設定すれば、 PRINTER 変数も設定した場合でも、この値が必ず使用されます。 PRINTER 変数が設定されており、 LPDEST 変数が設定されていない場合は、 lpr は PRINTER 環境変数により指定された値を使用します。 注: コマンド・ラインの宛先オプションはいずれも、 LPDEST と PRINTER の両方の環境変数をオーバーライドします。

-p | pr コマンドを使用して、ファイルをフォーマットします ( lpr -p とても似ています pr | lpr ).
-r | スプーリングが完了するとファイルを除去します。
-s | データ・ファイルをコピーしようとするのではなく、コマンド・ラインで指定したファイルから印刷します (非常に大きいファイルを印刷することができます)。 これは、データ・ファイルの印刷が終わるまでデータ・ファイルを変更したり除去したりできないことを意味します。 このフラグは有効なのは、 ローカル・ホスト上で (リモート・プリンター・ホストに送られるファイルは必ずコピーされます)、 指定データ・ファイルを使って作業する場合のみです。 lpr コマンドをパイプラインの最後に指定すると、このフラグは動作しません。
-T タイトル | pr コマンドが使用するタイトルに、ファイル名の代わりに Title 変数を使用します。
-w 数値 | Number 変数を pr コマンドのページ幅として使います。

例
ファイルのコピーを 3 部印刷するには、以下のようにします。
new.index.c,
print.index.c,
および
more.c,
次のように入力します。
lpr
-#
3 new.index.c print.index.c more.c
以下のコピーを 3 部印刷します。
new.index.c
ファイル、3 つのコピー
print.index.c
file,
3 部のコピーを
more.c file
.
3 つのファイルの連結のコピーを 3 部印刷するには、次のようにします。
new.index.c,
print.index.c,
および
more.c
次のように入力します。
cat new.index.c print.index.c more.c | lpr
-#
3
印刷するには
Operations
バースト・ページで、その後にファイルが続きます。
new.index.c
次のように入力します。
lpr
-C
Operations new.index.c
これにより、システム名 (ホスト名によって戻される名前) が以下のように置き換えられます。
Operations
バースト・ページに表示します。
MyFile ファイルをキューに入れ、ジョブ番号を戻すには、次のように入力します。
lpr -j MyFile
