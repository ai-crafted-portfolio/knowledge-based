目的
ログイン・ポート (通常、共有、および遅延) を使用可能にするか、使用可能性を報告します。

説明
pstart
コマンドは、
/etc/inittab
ファイルにリストされているすべてのポート (通常、共有、および遅延) を使用可能にします。 システムでは、
/etc/inittab
ファイル内のエントリーを更新し、次に
init
プロセスにシグナルを送信することによって、ポートを使用可能にします。
init
プロセスは、シグナルを受信し、更新された状況項目を読み取ると、適切なアクションを実行します。
Device
パラメーターを使用して、使用可能にするポートを指定します。 以下の値が使えます。
デバイスのフルネーム (
/dev/tty1
デバイスなど)
簡単なデバイス名 (
tty1
デバイスなど)
数値 (例えば、
/dev/tty1
装置を示す場合は 1)
Device
パラメーターを指定しない場合、
pstart
コマンドは、すべての使用可能なポートの名前と、それらのポートが通常、共用、または遅延のいずれとして使用可能になっているかを報告します。
注:
このコマンドを実行するには root ユーザー権限を持っていなければなりません。

構文
pstart [ -a ] [ Device ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-a | すべてのポート (通常、共有、および遅延ポート) を使用可能にします。

例
現在使用可能になっているすべてのポート (通常、共用、および遅延) の名前と、それらが使用可能になっている方法を表示するには、次のように入力します。
pstart
/etc/inittab
ファイルにリストされているすべての通常ポート、共用ポート、および遅延ポートを使用可能にするには、次のように入力します。
pstart -a
