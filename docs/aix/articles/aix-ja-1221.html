目的
ファイルシステム・クォータの整合性を検査します。

説明
quotacheck
コマンドは、
FileSystem
パラメーターで指定されたファイルシステムを調べ、現在のディスク使用量のテーブルを作成し、テーブル内の情報をファイル・システムのディスク割り当て量ファイルに記録された情報と比較します。 情報の不一致が検出された場合には、クォータ・ファイルが更新されます。 デフォルトでは、ユーザー・クォータとグループ・クォータが両方とも検査されます。
オプションの
-g
フラグは、グループ割り当て量のみを検査することを指定します。 オプションの
-u
フラグは、ユーザー割り当て量のみを検査することを指定します。
-g
フラグと
-u
フラグの両方を指定することは、ユーザー割り当て量とグループ割り当て量の両方を検査するデフォルトの動作と同等です。
-a
フラグは、ディスク・クォータが有効になっている
/etc/filesystem
ファイル内のすべてのファイルシステムが検査されることを指定します。
JFS と JFS2 の両方のファイルシステムの場合、オプションの
-d
フラグは、
/etc/passwd
または
/etc/group
に存在せず、ファイルシステムに割り当てられていないすべてのユーザーまたはグループ ID の使用状況統計を削除します。 影響を受けるユーザーまたはグループは、
repquota
コマンドによって表示される統計を持たなくなります。
quotacheck
コマンドは通常、サイレントに動作します。
-v
フラグが指定されている場合、
quotacheck
コマンドは、計算されたディスク・クォータと記録されたディスク・クォータの間の矛盾を報告します。
JFS の場合、
quotacheck
コマンドは、
/etc/filesystems
ファイル (デフォルトでは、ファイルの名前は
quota.user
および
quota.group
で、ファイルシステムのルートにあります) から割り当て量ファイル名を判別します。 JFS2の場合、これらのファイルの名前と場所は事前に決定されており、変更することはできません。 これらのファイルが存在しない場合は、
quotacheck
コマンドによって作成されます。
注:
アクティブ・ファイル・システムに対して
quotacheck
コマンドを実行しないでください。 ファイル・システムに現行アクティビティーがある場合、
quotacheck
を実行すると、誤ったディスク使用情報が生成される可能性があります。

構文
quotacheck [ -d ] [ -g ] [ -u ] [ -v ] { -a | ファイル・システム ... }

オプション
フラグ
項目 | 説明
-a | /etc/filesystems にある、ディスク・クォータが使用可能なすべてのファイルシステムを 検査します。
-d | 未定義で、割り振りを持たない ID の使用率統計を削除します (JFS と JFS2 の両方)。
-g | グループ・クォータのみを検査します。
-u | ユーザー・クォータのみを検査します。
-v | 計算上のディスク・クォータと記録されたディスク・クォータとの間の相違を報告します。

例
ユーザー・クォータおよびグループ・クォータを確認するには、
/usr
ファイル・システム、タイプ:
quotacheck /usr
グループ・クォータのみを検査するには、
/usr
ファイル・システム、タイプ:
quotacheck -g /usr
