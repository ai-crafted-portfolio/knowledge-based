目的
DNS ルックアップ操作を実行します。

説明
host9
コマンドは、ドメインネームシステム（DNS）のルックアップ操作を実行する簡単なユーティリティである。 このコマンドを使用して、名前とIPアドレスの両方を変換することができます。 引数もオプションも指定しない場合、'
host9
コマンドはコマンドライン引数とオプションの短い要約を表示する。

構文
host9 [ ' -a ' A ' C ' d ' l ' n ' r ' s ' T ' U ' w ' v ]。[ ' -c class ] [ ' -N ndots ] [ ' -p port ] [ ' -R number ] [ ' -t type ] [ ' -W wait ] [ ' -m flag ] [ -4 ] [ -6 ] [ -v ] [ -V ] name [ server ] [ サーバー

オプション
フラグ
表 1. フラグ
項目 | 説明
-4 | host9 コマンドがIPv4クエリートランスポートのみを使用することを許可する。
-6 | host9 コマンドがIPv6クエリートランスポートのみを使用することを許可する。
-a | -v -t * のフラグを使用する場合と同じです。 このフラグは、「 -l リストゾーンオプションの動作にも影響する。
-A | -a と同じであるが、' RRSIG 、' NSEC 、' NSEC3 レコードは出力から除外される。
-c class | 指定されたクラスの DNS クエリの実行方法を指示する。 このフラグを使うと、' Hesiod または ' Chaosnet クラスのリソースレコードを検索することができます。 デフォルトのクラスはインターネット（IN）。
-C | そのゾーンの権威ネームサーバーから、ゾーン名に対応するSOA(Start of Authority)レコードの表示を試みる。 ゾーンで見つかった' NS レコードは、ネームサーバのリストを定義する。
-d | デバッグトレースを表示し、' -v フラグと同等である。
-l | リスト・モードを指定します。 このオプションは、' host9 コマンドにゾーン 名 のゾーン転送を実行させる。 NS 、' PTR 、およびアドレスレコード( A or AAAA )を出力してゾーンを転送する。 -l フラグと ' -a フラグを併用した場合、 ' host9 コマンドはすべてのレコードを出力する。
-m フラグ | メモリ使用量のデバッグを設定する。 フラグには「 record 、「 usage 、「 trace 」がある。 -m オプションを複数回設定して、複数のフラグを設定することができる。
-N ドット | 絶対名前とみなすために必要なドットの数を設定する。 デフォルト値は、' /etc/resolv.conf ファイルの' ndots ステートメントを使用して定義され、' ndots ステートメントが存在しない場合は1である。 ドットが少ない名前は相対名と解釈され、「 /etc/resolv.conf ファイルの「 search または「 domain ディレクティブに記載されているドメインで検索される。
-p port | サーバー上のクエリーへのポートを指定する。 デフォルト値は 53 です。

-r | 非再帰クエリを指定します。 クエリのRD（Recursion Desired）ビットをクリアするには、このオプションを設定する。 これは、クエリーを受信したネームサーバーが' name を解決しようとしないことを意味する。 host9 コマンドは、非再帰的なクエリーを行い、通常は他のネームサーバーへのリファーラルであるクエリーに対する答えを受け取ることを期待することで、ネームサーバーの動作を模倣することを可能にする。
-R 番号 | ルックアップに対する User Datagram Protocol （ UDP ）の再試行回数を変更します。 number 値は、 host9 コマンドが応答のない照会を繰り返す回数を示します。 デフォルトの再試行回数は1回、または「 /etc/resolv.conf ファイルの「 attempts オプションの値である。 数値が負またはゼロの場合、再試行回数はデフォルトの 1 になります。
-s | host9 コマンドは、' SERVFAIL 応答を返すサーバがあれば、次の ' name サーバに問い合わせを送らないようにする。
-t type | 照会タイプを選択します。 type 引数には、認識されているクエリー型を指定します。 例えば、「 CNAME 、「 NS 、「 SOA 、「 TXT 、「 DNSKEY 、「 AXFR 」など。 照会タイプが指定されていない場合は、 host9 コマンドにより適切な照会タイプが自動的に選択されます。 デフォルトでは、' A 、' AAA 、' MX レコードを探す。 -C フラグを指定すると、SOAレコードの問い合わせが行われ、 名前 がドット付き10進数のIPv4アドレスまたはコロン区切りのIPv6アドレスの場合、' host9 コマンドは' PTR レコードの問い合わせを行う。 クエリータイプに「 IXFR 選択した場合、イコール記号の後に開始シリアル番号を続けることで、開始シリアルを指定することができます（例えば、「 -t IXFR=12345678 ）

-T , -U | ネームサーバーへのクエリには、トランスミッション制御プロトコル（ TCP ）または UDP 接続を使用します。 デフォルトでは、この host9 コマンドは UDP 接続を使用します。 このオプションを -T 指定すると、この host9 コマンドは TCP 接続を使用します。 ゾーン転送（AXFR）リクエストなどのクエリに対しては、 TCP 接続が自動的に選択されます。 オプション -U を使用することで、クエリが最初に UDP 接続を使用するように強制することができます。
-v | 詳細出力を生成します。 このフラグは -d フラグと同じように機能します。 冗長出力は、「 /etc/resolv.conf ファイルに「 debug オプションを設定することでも有効にできる。
-V | バージョン番号を印刷して終了します。
-w | 応答を永続的に待機します。 応答を待つ時間は、整数量に対するハードウェアの最大値で与えられた秒数に設定される。
-W 待機 | wait 秒間待機します。 wait 値が 1 より小さい場合は、待機間隔が 1 秒に設定されます。 デフォルトでは、この host9 コマンドは UDP への応答を5秒間、 TCP への接続を10秒間待機します。 これらのデフォルト値は、「 /etc/resolv.conf ファイルの「 timeout オプションによって上書きされる。
name | 検索するドメイン名を指定します。 この場合、「 host9 コマンドはそのアドレスの逆引きを実行する。
サーバー | オプションの引数を指定する。 このオプションは、 /etc/resolv.conf ファイルにリストされているサーバーの代わりに、 host9 コマンドが問い合わせるネーム・サーバーの名前または IP アドレスのいずれかである。
IDN サポート
host9
コマンドが国際化ドメイン名（IDN）をサポートして構築されている場合、非ASCIIドメイン名を受け入れ、表示することができる。
host9
コマンドは、DNSサーバーにリクエストを送信したり、サーバーからの応答を表示したりする前に、ドメイン名の文字エンコードを変換する。 何らかの理由でIDNサポートをオフにするには、環境変数'
IDN
DISABLE
を定義する。
host9
コマンド実行時に変数がセットされている場合、IDNサポートは無効になる。

例
mephisto
という名前のホスト・マシンのアドレスを表示するには、次のコマンドを入力します。
host9 mephisto
このコマンドは、以下の出力と同様の情報を表示する：
mephisto is 192.100.13.5, Aliases: engr, sarah
アドレスが 192.100.13.1 のホスト・マシンを表示するには、次のコマンドを入力します。
host9 192.100.13.1
このコマンドは、以下の出力と同様の情報を表示する：
mercutio is 192.100.13.1
ドメイン名が
test.ibm.com
の MX レコードを表示するには、次のコマンドを入力します。
host9 -n -t mx test.ibm.com
このコマンドは、以下の出力と同様の情報を表示する：
test.ibm.com mail is handled (pri=10) by test1.tt.ibm.com
test.ibm.com mail is handled (pri=10) by test2.aix.ibm.com
