目的
ネットワーク情報サービス
(
国家情報院
) でネットワーク・パスワードを変更します。

説明
yppasswd
コマンドは、ネットワークパスワードを変更（またはインストール）し、
Name
変数で指定したユーザー名と関連付ける。 パスワードを作成または変更するには、変更したいパスワードのオーナーである必要があります。
NIS
のパスワードは、自分のマシンのものとは異なることがある。
NIS
サーバーのルート・ユーザーは、そのユーザーの元のパスワードを知らなくても、他のユーザーのパスワードを変更できる。 他のユーザーのパスワードを変更するには、ルートユーザーが、そのユーザーの元のパスワードの代わりにそのパスワードを入力する。
NIS
クライアントのルート・ユーザーはこの権限を持たない。
コマンド・ラインに
yppasswd
コマンドを入力すると、システムは古いパスワードを入力するようプロンプトを表示します。 その後、新しいパスワードの入力を求めるプロンプトが表示されます。 パスワードは、大文字と小文字を含む最低4文字でなければなりません。 それ以外の場合、パスワードは6文字以上でなければならない。 これらの規則は、順守すれば厳しいものではありません。
古いパスワードを間違って入力した場合、システムがエラーメッセージを表示する前に新しいパスワードを入力する必要があります。
update
コマンドは両方のパスワードを同時にサーバーに送信するため、システムは両方のパスワードを必要とする。 サーバーはエラーを検出し、入力された古いパスワードが間違っていることを通知します。
新しいパスワードを検査するために、システムはパスワードをもう一度入力するようプロンプトを表示します。 新しいパスワードを有効にするには、「
yppasswdd
デーモンが
NIS
サーバー上で実行されていなければならない。
注：
「
yppasswd
コマンドは、「
passwd
コマンドのようにパスワードのルールを設定することはできない。

構文
yppasswd [ -f[Name ]| -s [ Name [ ShellProg ]] ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-f [ 名前 ] | NIS マップのユーザー 名 のgecos情報を変更する。 ゲコスの情報は、' /etc/passwd ファイルに保存されている一般的な情報である。
-s [ 名称 [ ShellProg ]] | NIS マップのユーザー 名 のログインシェルを変更します。
