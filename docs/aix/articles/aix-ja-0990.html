目的
英語ビュー・グラフとスライドをタイプセットします。

説明
mvt
コマンドは、
mmt
コマンドと同様の方法でビュー・グラフやスライドの入力を
mv
マクロ・パッケージでタイプセットします。
mvt
コマンドは、
tbl
、
eqn
、
pic
、
cw
、および
grap
コマンドによるプリプロセスを指定するフラグを持ちます。
troff
コマンドとマクロ・パッケージのために生成されるパイプライン、フラグ、およびパラメーターは、選択したフラグによって決まります。
mvt
コマンドは、
troff
コマンドとは異なり、特に禁止されない限りポストプロセッサーに自動的に出力を送ります。 ユーザーは、
mvt
コマンドを使用するときにポストプロセッサーを指定しないでください。
mvt
コマンドのパスは次のとおりです。
-z
フラグ (ポストプロセッサーは使用されません)。
-T
Name
フラグ。
TYPESETTER
環境変数が読み取られます。
デフォルトは
ibm3816
に設定されています。
File
は、
mvt
コマンドがフォーマットするファイルを指定します。

構文
MvT [ -a 値 ] [ 「-c」 ] [ -e (E) ] [ - ] [ P- ] [ T ] [ -z ] [ -T (T) 名前 | -D 目的地 ] [ ファイル ... | - ]

オプション
フラグ
フラグの指定順序は任意ですが、必ず
File
パラメーターの前に指定します。 ファイルを指定しないと、
mvt
コマンドはフラグのリストを出力します。
項目 | 説明
-a | 読み取り可能な troff 出力を端末に表示します。
-c | cw コマンドを呼び出します。
-e | eqn コマンドを呼び出します。また、 eqn コマンドに /usr/share/lib/pub/eqnchar ファイルを読み取らせます。
-g | grap コマンドを呼び出し、次にこのコマンドが pic コマンドを呼び出します。
-p | pic コマンドを呼び出します。
-t | tbl コマンドを呼び出します。
-Z | troff コマンドの出力を処理またはリダイレクトするための出力フィルター (またはポストプロセッサー) を呼び出しません。
-D 宛先 | 出力を指定したデバイス宛てに送ります。 Destination 変数のサポートされている値は 4014 で、これは tc コマンドによる Tektronix 4014 端末を示します。
-T 名前 | Name 変数で指定された troff デバイスの出力を作成します。 出力は適切なポストプロセッサーを使用して送られます。 デフォルトは ibm3816 です。
- | 入力を標準入力から強制的に読み取ります。
mvt
コマンドに指定する他のパラメーターまたはフラグ (
-a
フラグなど) は
troff
コマンドに渡されます。
File
パラメーターの代わりに
-
(マイナス) フラグを指定すると、
mvt
コマンドは標準入力を読み取ります。
出力するページの範囲を指定するには、
troff
コマンドの
-o
List
フラグを使用します。
“
注:
1 つ以上の
-e
、
-c
、
-t
を指定して
mvt
コマンドを呼び出すと、
-p
、
-g
、または
-
フラグ。
troff
コマンドの
-o
List
フラグと一緒に使用すると、次のようになります。
broken pipe
開くのに失敗しました。 このような状況は、文書の最後のページが
List
変数に指定されていない場合に起こります。 この broken pipe メッセージは問題があることを示すものではないので、無視してかまいません。
