目的

他のフォント・ファイルを BDF フォント・ファイルに変換します。

構文

twconvfont [ -v CodePage ] [ -f Source ] [ -t ターゲット ]

説明

twconvfont コマンドは、1 つのフォント・ファイル・タイプを BDF フォント・ファイルに変換します。 サポートされているコード・ページは SOPS、PS55、および ET です。

フラグ

項目
説明
-f ソース 変換するフォント・ファイルの名前を指定します。
-t ターゲット 変換されたフォント・ファイルの名前を指定します。
-v CodePage 変換するコード・ページのタイプを指定します。 CodePage は以下のものにすることができます。

SOPS

PS55

ET。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 正常終了。
>0 エラーが発生しました。

セキュリティー

アクセス制御: このコマンドを実行するには、root 権限を持っていなければなりません。

イベントの監査 : 該当しません。

例

フォント・ファイルを変換するにはUSRFONT.C12名前を持つ SOPS タイプのコード・ページの BDF フォント・ファイルにuser.bdf次のように入力します。

twconvfont -v SOPS -f USRFONT.C12 -t user.bdf

ファイル

項目
説明
/usr/lpp/tls/bin/twconvfont twconvfont コマンドが入っています。
