目的
スプールされた印刷ジョブを保持し、解放します。

説明
qhld
コマンドは、印刷ジョブをスプール状態で保持します。 保持するジョブは、ジョブ番号、キュー名、またはユーザー名で指定します。
-r
フラグを指定すると、印刷ジョブの保持が解除されます。
qstatus
は、重複した 3 桁のジョブ番号を示して、ローカル・キューの管理を向上させるように拡張されています。
-W
フラグを
enq
、
qchk
、
lpstat
、および
lpq
状況コマンドと共に使用して、ジョブ番号の桁数をさらに多くして表示することができます。
キュー表示が重複した 3 桁のジョブ番号を示す場合は、
qchk -W
を使用してさらに高い精度でジョブ番号をリストしてください。 その後で特定ジョブを保持することができます。
例:
qchk
ジョブ番号を表示する
123
その間に二度
qchk -W
ジョブ番号を表示します。
1123
および
2123
. ジョブ番号 2123 を保留したい場合は、次のように指定します。
qhld -# 123
により、
qdaemon
は、内部リストで最初に見つかった一致するジョブ番号を保持します。
1123
.
qstatus -W
が提供する追加情報を持つことで、特定のジョブ番号を保持することができる。

構文
qhld [ -r ] { -# JobNumber [ -P Queue ] | -P Queue | -u User [ -P Queue ]}

オプション
フラグ
項目 | 説明
-# ジョブ番号 | 保持する印刷ジョブの番号を指定します。
-P 待ち行列 | 保持する印刷キューを指定します。
-r | 番号、キュー、またはユーザー名で印刷ジョブを解放します。
-ウー ユーザー | 保持する印刷ジョブが属するユーザーの名前を指定します。

例
印刷ジョブ番号を保留する
300
次のように入力します。
qhld -#300
キューにあるすべての印刷ジョブを保留する
lp0
次のように入力します。
qhld -P lp0
ユーザーに属するすべてのジョブを保留する
fred
次のように入力します。
qhld -u fred
ジョブ番号を解放する
300
次のように入力します。
qhld -#300 -r
キュー上のすべてのジョブを解放します。
lp0
次のように入力します。
qhld -Plp0 -r
ユーザーに属するすべてのジョブを解放します。
fred
次のように入力します。
qhld -u fred -r
