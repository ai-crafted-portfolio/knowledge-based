目的
CIFS マウントを
/etc/filesystems
ファイルに追加し、マウントを実行します。

説明
mkcifsmnt
コマンドは、
/etc/filesystems
ファイルに付加される CIFS エントリーを構成します。 それから CIFS ファイルシステムへのマウントを試みます。 そのオプションは解析され、
crfs
コマンドに渡されるように準備されます。このコマンドは、実際に CIFS 項目を
/etc/filesystems
に追加します。

構文
mkcifsmnt -f MountPoint -d RemoteShare -h RemoteHost -c ユーザー [ -p パスワード ] [ -m MountTypeName ] [ -A | -a ] [ -I | -B | -N ] [ -t { rw|ro }] [ -u ユイド ] [ -g ギド ] [ -x エフモード ] [ -w ワークグループ ]

オプション
フラグ
項目 | 説明
-a | このファイル・システムの /etc/filesystems 項目を、システム再始動時に自動的にマウントしないことを指定します。 これはデフォルトです。
-A | このファイル・システムの /etc/filesystems 項目が、システム再始動時に自動的にマウントされることを指定します。
-B | 項目を /etc/filesystems に追加し、システム再始動時にマウントする必要があることを指定します。
-c ユーザー | ユーザー名は CIFS の共有へのアクセス取得に使用されることを指定します。
-d RemoteShare | マウントする CIFS サーバー上の共有名を指定します。
-f MountPoint | CIFS 共有がマウントされるパス名を指定します。
-g GID | マウントされているファイルに割り当てられている GID を指定します。 デフォルトは 0 です。
-h RemoteHost | リモート・ホスト (CIFS サーバー) の名前を指定します。 これは、ホスト名、IP アドレス、または完全修飾ドメイン名として指定することができます。
-I | 項目を /etc/filesystems ファイルに追加するが、マウントしないことを指定します。
-m MountTypeName | /etc/filesystems ファイルに追加されるマウント・タイプを定義します。これにより、 mount コマンドの -t オプションを使用して、特定のタイプのすべてのファイルシステムをマウントすることができます。 デフォルトでは、タイプ値は /etc/filesystems に追加されません。
-N | 指定されたオプションを使用して CIFS 共有をマウントしますが、 /etc/filesystems ファイルは変更しません。

-p パスワード | 特定サーバーへの特定ユーザーのアクセス許可に使用するパスワードを指定します。 特定の資格情報 (server/user/password) が cifscred ファイルに追加されます (パスワードは暗号化されます)。 -p オプションが指定されておらず、資格情報が cifscred ファイルにまだ存在しない場合、コマンド・ラインからユーザーにパスワードの入力を求めるプロンプトが出され、資格情報が cifscred ファイルに追加されます。 サーバー/ユーザー資格情報が既に cifscred ファイルに存在する場合、このオプションは無視され、既存の資格情報がマウントに使用されます。
-t {rw|ro} | ファイルシステムを読み取り専用としてマウントすべきかどうか指定します。 デフォルトは読み取り/書き込み (rw) です。
-u ユイド | マウントされているファイルに割り当てられている UID を指定します。 デフォルトは 0 です。
-x エフモード | 所有者、グループ、およびマウントされるファイルに割り当てられる許可ビットを指定します。 デフォルトは 755 です。
-w ワークグループ | マウント中にユーザーの認証に使用するドメインを指定します。 このオプションを使用しない場合、CIFS サーバーはローカルの認証として取り扱います。

例
/mnt
上のマウントを
server1
上の
share1
に追加し、
user1
として認証するには、次のように入力します。
mkcifsmnt -f /mnt -d share1 -h server1 -c user1
