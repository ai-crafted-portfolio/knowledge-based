目的

プロセス・アカウンティング・プロシージャーを実行します。

構文

acctprc1 [ InFile ]
acctprc2 [ -X] 
accton [ [-@] OutFile ]

説明

acctprc1、 acctprc2、および accton, の 3 つの acctprc コマンドは、プロセス・アカウンティング・シェル・プロシージャーを実行するために runacct コマンドによって呼び出されます。

acctprc1 コマンドは、acct フォーマットの標準入力からレコードを読み取り、ユーザー ID に対応するログイン名を追加して、ASCII レコードを標準出力に書き出します。 このレコードには、ユーザー ID、ログイン名、基本 CPU 時間、非基本 CPU 時間、転送された文字の合計数 (1024 バイト単位)、読み書きされたブロックの合計数、および各プロセスの平均メモリー・サイズ (64 バイト単位) が含まれます。

InFile パラメーターを指定すると、 utmp 形式のログイン・セッションのリストが含まれます。このリストは、ユーザー ID とログイン名でソートされます。 File パラメーターが指定されていない場合、 acctprc1 は /etc/passwd パスワード・ファイルからログイン名を取得します。 InFile パラメーターの情報は、ユーザー ID を共有するさまざまなログイン名を区別するのに役立ちます。

acctprc2 コマンドは、 acctprc1 コマンドによって書き込まれたレコードを (標準入力から) 読み取り、ユーザー ID と名前で要約し、ソートされた要約を合計アカウンティング・レコードとして標準出力に書き込みます。

accton コマンドをパラメーターなしで使用した場合は、プロセスのアカウンティングはオフになります。 OutFile パラメーター (既存ファイル) を指定すると、プロセスのアカウンティングがオンになり、カーネルはレコードをそのファイルに追加します。 プロセス・アカウンティングを開始するには、 OutFile パラメーターを指定します。 OutFile パラメーターは、accton コマンドでは作成されません。 OutFile パラメーターで指定するファイルは、適切なグループ、所有者、および許可を持つファイルでなければなりません。 多くのシェル・スクリプトでは、/var/adm/pacct ファイルが想定されています。

フラグ

表 1. フラグ
項目
説明
-X 最初の 8 文字に切り捨てずに、ユーザー名ごとに使用可能なすべての文字を処理します。 またこのフラグを使用すると、acctprc2 コマンドが、tacct バイナリー・レコードではなく tacctx フォーマットのバイナリー・レコードを作成します。
注: このフラグは、 acctprc2 コマンドでのみ使用できます。
-@ ワークロード・パーティション プロセス・アカウンティング・レコードをグローバル WPAR アカウンティング出力ファイルに組み込みます。 このオプションは、 ワークロード・パーティション内では無効です。

セキュリティー

アクセス制御: これらのコマンドは adm グループのメンバーにのみ実行 (x) アクセスを認可します。

例

  1. バイナリー・ファイル内の各プロセス・アカウンティング・レコードにユーザー名を追加し、そのレコードを ASCII ファイル名 out.fileに変換するには、以下のコマンドを入力するか、シェル・スクリプトで行を使用します。
    /usr/sbin/acct/acctprc1 < /var/adm/pacct >out.file
  2. 例 1 の ASCII 出力ファイルの合計アカウンティング・レコードを作成する場合は、コマンドを次のように 入力するか、またはこれと同じ行をシェル・スクリプトで使用します。
    /usr/sbin/acct/acctprc2 < out.file > \
/var/adm/acct/nite/daytacct 
    この結果生成されるファイルは、tacct フォーマットのバイナリー合計アカウンティング・ファイルで、ユーザー ID 別にソートされた個々のレコードが入っています。 ファイル /var/adm/acct/nite/daytacct は、acctmerg コマンドにより他の合計アカウント・レコードとマージされ、/var/adm/acct/sum/tacct ファイル内に日計要約レコードを生成します。
  3. アカウンティング・プロセスをオフにするには、次のコマンドを入力します。
    /usr/sbin/acct/accton
