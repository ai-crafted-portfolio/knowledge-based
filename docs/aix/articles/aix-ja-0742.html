オプション
フラグ
項目 | 説明
-a 属性 | 特定のデバイスまたはデバイス・タイプについて、 指定された属性に関する情報を表示します。 -a フラグは、 属性名ごとに 1 つ、または複数の属性名に対して 1 つ使えます。 複数の属性名に対して 1 つの -a フラグを使う場合、属性名のリストは引用符で囲み、名前の間をスペースで区切らなければなりません。 -R フラグを使用する場合は、属性名が 1 つだけの -a フラグを 1 つだけ指定する必要があります。 -a フラグも -R フラグも指定しないと、 lsattr コマンドは指定されたデバイスのすべての属性に関するすべての情報を表示します。 -a Attribute フラグは -o Operation フラグと共に使用することはできません。 フラグのこの組み合わせは、 lsattr コマンドがエラー・メッセージを出して終了する原因となります。
-c クラス | デバイスのクラス名を指定します。 このフラグを使うと、 出力を、指定したクラスのデバイスに制限できます。 このフラグは、 -E または -l フラグと一緒には使用できません。
-D | 特定のデバイスが -O フラグと一緒に使用されない場合に、そのデバイスの属性名、デフォルト値、説明、およびユーザー設定可能フラグ値を表示します。 -D フラグを -O フラグと一緒に使用すると、属性名とデフォルト値だけがコロン・フォーマットで表示されます。 このフラグは、 -c 、 -s の任意の組み合わせで使用できます。 および -t フラグは、事前定義デバイス・オブジェクト・クラスから、または -l フラグを使用して、デバイスを一意的に識別します。 このフラグは、 -E 、 -F と一緒には使用できません。 または -R フラグ。
-E | 特定のデバイスが -O フラグと一緒に使用されない場合に、そのデバイスの属性名、現行値、説明、およびユーザー設定可能フラグ値を表示します。 -E フラグを -O フラグと一緒に使用すると、属性名と現行値のみがコロン形式で表示されます。 このフラグは、 -c 、 -D と一緒には使用できません。 -F 、 -R 、 -s 、 または -t フラグ。
-f ファイル | File パラメーターから必要なフラグを読み取ります。

-F フォーマット | ユーザー指定のフォーマットで出力を表示します。 Format パラメーターは、 欄名を非英数字または空白文字で区切った引用符付きリストです。 セパレーターとして空白文字を使うと、 lsattr コマンドは位置合わせされた列に出力を表示します。 事前定義属性 ( PdAt )、カスタマイズ属性 ( CuAt )、 および拡張事前定義属性 ( PdAtXtd ) オブジェクト・クラスからのカラム名だけを指定できます。 カラム名のほかに、使用できる特別目的の名前が 2 つあります。名前 description を使うと属性の説明を表示でき、 user_settable を使うと属性を変更できるかどうかを判別できます。 このフラグは、 -E 、 -D と一緒には使用できません。 -O 、または -R フラグ。
-H | 出力される列の上にヘッダーを表示します。 -O および -R フラグは、 -H フラグよりも優先されます。
-h | コマンドの使用メッセージを表示します。
-l 名前 | カスタマイズ・デバイス・オブジェクト・クラスにある、 属性名または属性値を表示したいデバイスの論理名を指定します。
-o 操作 | 特定のデバイスまたはデバイス・タイプについて、 指定された操作に関する情報を表示します。 それぞれの操作名または複数の操作名に対して 1 つの -o フラグが使用できます。 複数の操作名に対して 1 つの -o フラグを使用する場合、操作名のリストは引用符で囲み、名前の間をスペースで区切る必要があります。 ワイルドカード文字は、操作名にも使用できます。 ワイルドカード文字の有効なセットは、 odmget コマンドで使用されるセットと同じです。 特定のデバイスまたはデバイス・タイプに関連したすべての操作は、操作値 "?*" を使用して表示できます。 -o Operation フラグは、 -a attribute フラグとも、 -R フラグとも一緒に使用することはできません。 これらのフラグをどのように組み合わせても、 lsattr コマンドがエラー・メッセージを出して終了する原因となります。
-O | すべての属性名をコロンで区切って表示し、2 行目に対応するすべての属性値をコロンで区切って表示します。 属性値は、 -E フラグが指定されている場合は現行値、 -D フラグが指定されている場合はデフォルト値です。 このフラグは、 -F および -R フラグと一緒に使用することはできません。

-P | 特定のデバイスが -O フラグと一緒に使用されない場合に、そのデバイスの属性名、値、説明、およびユーザー設定可能フラグ値を表示します。 表示される値は、 chdev コマンドを -P フラグまたは -T フラグと共に使用することによってデバイス属性のいずれかが変更される前に、デバイス構成で使用された値です。 -P フラグを -O フラグと一緒に使用すると、 -P フラグは属性名と値だけをコロン区切り形式で表示します。 このフラグは、 -c 、 -s の任意の組み合わせで使用できます。 および -t フラグは、事前定義デバイス・オブジェクト・クラスから、または -l フラグを使用して、デバイスを一意的に識別します。 このフラグは、 -D 、 -E と一緒には使用できません。 -O 、または -R フラグ。
-R | 属性名の正しい値を表示します。 -R フラグは、 -D , -E と一緒には使用できません。 -F および -O フラグ ただし、 -c 、 -s の任意の組み合わせで使用できます。 および -t フラグは、事前定義デバイス・オブジェクト・クラスから、または -l フラグを使用して、デバイスを一意的に識別します。 -R フラグは、 次のような属性値のリストを縦の欄で表示します。 Value1 Value2 . . ValueN -R フラグは、範囲属性値を次のように表示します。 x...n(+i) 各項の説明は次のとおりです。 x 範囲の開始を指定します。 n 範囲の終わりであり、かつ、 i 増分です。
-s サブクラス | デバイスのサブクラス名を指定します。 このフラグを使うと、 指定されたサブクラスのデバイスについての出力だけに限定できます。 このフラグは、 -E または -l フラグと一緒には使用できません。
-t タイプ | デバイスのタイプ名を指定します。 このフラグを使うと、 指定されたクラスのデバイスについての出力だけに限定できます。 このフラグは、 -E または -l フラグと一緒には使用できません。

-Z 文字 | -Z Character フラグは、 改行文字が組み込まれている場合がある ODM フィールドを処理するプログラムで使用されます。 -Z Character フラグは、 生成された出力のそれぞれのレコードまたは行のレコード分離文字を変更するために使用されます。 新規のレコード分離文字は、このフラグの Character 引数を使用して指定されます。 -Z Character フラグは、 -F Format フラグが指定された場合のみ有効となります。 -Z Character フラグは、 -D 、 -E 、 -O 、または -R フラグと併用することはできません。
