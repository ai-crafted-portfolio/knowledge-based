目的
システム・リソース・コントローラーを始動します。

説明
srcmstr
デーモンは、システム・リソース・コントローラー (SRC) です。
srcmstr
デーモンは、サブシステムの作成および制御を行い、サブシステムの簡略的な状況要求を処理し、要求をサブシステムに渡して、エラー通知を処理します。
srcmstr
デーモンは通常、
inittab
ファイル・エントリーによって始動されます。

構文
srcmstr /usr/sbin/srcmstr [ -r ] [ -B ]

オプション
フラグ
項目 | 説明
-r | このデーモンが -r フラグを指定して始動される場合、リモート要求を受け入れます。 -r フラグを指定しないで srcmstr デーモンを始動すると、リモート要求は無視されます。
-B | 以前のリリース AIX 4.3.1 およびそれ以前）と同様に srcmstr デーモンを実行させる -B フラグを指定します。 注: srcmstr デーモンは通常、 inittab から始動されます。 -r または -B フラグを追加するには、 /etc/inittab を編集して init q を実行するか、リブートします。 ユーザーは、リモート・システム上で root として実行中でなければなりません。 リモート要求が行えるように、ローカル /etc/hosts.equiv ファイルまたは /.rhosts ファイルが構成されている必要があります。
