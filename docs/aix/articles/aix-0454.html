目的

暫定修正 マネージャーを開始します。このマネージャーは、システム暫定修正をインストール、除去、リスト、および検査します。

構文

emgr -l [ -L Label | -n interimfixNumber | -u VUID ] [-v{1|2|3|4} ] [ -X ] [-a path] 
emgr -e interimfixPackage | -f ListFile [-w Directory ] [ -b | -k | -I ] [ -p ] [ -q ] [ -m ] [ -o ] [ -X ] [-a path]
emgr -i interimfixPackage | -f ListFile [ -w Directory ] [ -C ] [ -p ] [ -q ] [ -X ] [ -a path ]
emgr -C -i interimfixPackage | -f ListFile [ -w Directory ] [ -p ] [ -q ] [ -X ] [ -a path ]
emgr -C -L Label [ -p ] [ -q ] [ -X ]
emgr -r -L Label | -n interimfixNumber | -u VUID | -f ListFile [-w Directory ] [-a path] [ -b | -k | -I ] [ -p ] [ -q ] [ -X ]
emgr -c [ -L Label | -n interimfixNumber | -u VUID | -f ListFile ] [ -w Directory ] [-a path] [-v{1|2|3} ] [ -X ]
emgr -M | -U [ -L Label | -n interimfixNumber | -u VUID | -f ListFile ] [ -w Directory ] [-a path] [ -X ]
emgr -R interimfixLabel [ -w Directory ] [-a path] [ -X ]
emgr -P [ Package ] [-a path] [ -X ]
emgr -d -e interimfixPackage | -f ListFile [-w Directory ] [-v{1|2|3} ]

説明

emgr（暫定修正マネージャ）コマンドは、システムの暫定修正をインストールし、管理するために使用することができます。 暫定修正マネージャは、「epkgコマンドで作成されたパッケージをインストールし、暫定修正情報を含むデータベースを管理します。 emgr コマンドは以下の操作を実行します。

  • 暫定修正 パッケージのインストール
  • 暫定修正 の削除
  • 暫定修正 リスト
  • 暫定修正 検査
  • 暫定修正 のマウント
  • 暫定修正 のアンマウント
  • パッケージのロックの表示
  • インストール済み 暫定修正 強制除去
注:
  • 暫定修正マネージャーによってロックされているファイルセットを (「installp、「install_all_updates、または smit 「update_allコマンドを使用して) 更新しようとすると、どのファイルセットがロックされているかを示すメッセージが表示される。 ファイルセットのインストールが阻害された理由を示す通知がないことがある。 lslpp コマンドは、EFIXLOCKED 状態にある、ロックされているすべてのファイルセットを表示します。
  • 暫定的な修正またはサービスの更新によって更新されたライブラリまたは実行可能プログラムであって、アクティブなプロセスで使用中のものは、そのプロセスが再起動されない限り、そのプロセスに反映されません。 たとえば、kshを変更するアップデートは、すでに実行されているkshプロセスに変更を反映させない。 同様に、「libc.aライブラリの更新は、すでに実行中のプロセスには反映されない。 さらに、ライブラリを使用しているプロセスで、ライブラリの更新後に同じライブラリの「dlopen操作を行った場合、再起動しないと不整合が発生する可能性がある。
Ifix の参照

暫定修正 を参照する方法は、以下のとおりです。

ラベルによる参照
特定のシステムにインストールされる各暫定修正プログラムには、固有の暫定修正プログラムラベルがあります。 この中間修正ラベルは、すべての異なるデータベース・オブジェクトを結びつける一意のキーである。 中間修正をラベルで参照するには、「-Lフラグのパラメータとしてラベルを渡す。 たとえば、ラベル「ABC123」の中間フィックスに対してチェック・オペレーションを実行するには、次のように入力する：
emgr -cL ABC123
Ifix ID による参照
特定のシステムにインストールされている各 暫定修正 には、 暫定修正 ID があります。 暫定修正 ID は、単に 暫定修正 が 暫定修正 データベースにリストされている順序番号です。 このオプションは、中間フィックスのリストに基づいて中間フィックスの操作を行う場合に便利です。 emgrコマンドは、中間フィックスIDを中間フィックスラベルに変換してから、指定された操作を実行する。 IDで中間修正を参照するには、「-nフラグのパラメータとしてIDを渡す。
注: Ifix ID は、暫定修正が削除されて追加されるにつれて変更される可能性があります。 -lフラグを使用して、特定の暫定修正プログラムまたはすべての暫定修正プログラムをリストアップし、現在の暫定修正プログラムID番号を常に確認してください。
例えば、ID が 1 の最初の 暫定修正 に対して検査操作を実行するには、次のように入力します。
emgr -cn1
VUID による参照
暫定修正 パッケージはどのエンティティーによっても正式に追跡されないため、同じ 暫定修正 ラベルが複数の 暫定修正 パッケージに使用される可能性があります。 しかし、'emgrコマンドは、同じ暫定修正ラベルを持つ複数の暫定修正を同時にインストールすることを受け付けません。 VUID (仮想的に固有の ID) を使用して、同じ 暫定修正 ラベルを持つパッケージを区別することができます。 emgrコマンドは、指定された操作を実行する前に、VUIDを暫定的なフィックス・ラベルに変換する。 例えば、VUIDが'000775364C00020316020703に等しいインストール済みの暫定修正を一覧表示するには、次のように入力します：
emgr -l -u 000775364C00020316020703
注: VUID は、 暫定修正 のインストールおよび削除のプレビュー・フェーズで表示されます。 VUID は、-v フラグを使用して 詳細レベル 3 でリストする場合も表示されます。

installp による暫定修正の自動削除の有効化

暫定修正は、APAR参照番号を含むAPAR参照ファイルを「epkgコマンドでパッケージ化することができる。 APAR参照番号により、'installpは中間修正を、その修正が出荷されたすべての技術レベルのAPARにマッピングすることができる。 installp、適用される技術レベル、サービスパック、またはPTFに暫定修正が含まれていると判断した場合、「installpアップデートを適用する前に暫定修正を自動的に削除する。

中間修正の自動削除が有効になっている場合、「emgrコマンドは中間修正のインストール中に次のようなメッセージを表示します：

ATTENTION: Interim fix is enabled for automatic removal by installp.
並行更新

emgrコマンドは、コンカレント・アップデートと呼ばれる新しい種類の暫定的な修正プログラムのインストールをサポートします。 この形式の暫定修正は、AIXカーネルまたはそのカーネル拡張の1つに修正を加えるもので、システム・メモリに直接適用できるため、システムを再起動する必要はない。 このようにシステム・メモリに直接パッチを当てることで、ディスク上にあるシステムの現在のカーネルを含むファイルを変更することなく、カーネルの変更を安全に評価・テストすることができる。 -Cフラグを使用して、同時更新によってもたらされた変更をディスクにコミットすることを選択しない限り、システムメモリに適用された同時更新は、システム再起動後も持続しません。 並行更新は、同じモジュールの別のパッチに直接適用することができます。 既存のパッチを除去する必要はありません。 ただし、ロードするモジュールのバージョンは 1 つのみでなければなりません。 また、REBOOT_REQUIRED 状態では暫定修正の並行更新操作 (メモリー内またはディスク上) は、システムがリブートするまで実行できません。

emgrコマンドは、NIMシン・サーバー（ディスクレスまたはデータレス・クライアント）のインメモリー同時更新をサポートする。 シンサーバーはオペレーティングシステムファイルを他のクライアントと共有しているため(/usrディレクトリは読み取り専用)、同時更新をディスクにコミットする(-Cフラグ)オプション'emgrはシンサーバーでは無効である。

注：シンサーバーの共有オペレーティングシステムファイルをディスクにパッチする必要がある場合、シンサーバーにサービスを提供するNIMマスター上のSPOTリソースに暫定的な修正が適用される可能性がある。 SPOTへの中間修正のインストールについては、『インストール・ガイド』の「SPOTリソースへの中間修正のインストール」セクション、またはNIMマスターの「/usr/lpp/bos.sysmgt/nim/READMEファイル（NIM IFIX/EMGRセクション）を参照してください。

/usrファイルシステムはシンサーバーでは読み取り専用なので、'emgrデータベースはシンサーバーの'/var/emgrdataディレクトリに配置される。

bosbootやファイルシステム拡張など、特定の「emgr操作はシンサーバー環境ではサポートできない。 その結果、次の「emgrフラグは、シンサーバー環境ではサポートされない： 「-C、「-e、「-I、「-k、「–X。 また、「–bフラグは、再起動を必要とする暫定的な修正のためにbosbootプロセスをスキップするもので、シンサーバーではbosboot操作がサポートされていないため、該当する場合は常に使用される。

説明

-M emgrコマンドに、'-mフラグを使ってマウントインストールされた暫定フィックスまたは暫定フィックスをマウントするように指示する。 -Mフラグは、「-mフラグを使用してインストールされ、 「-Uフラグによってアンマウントされるか、システムをリブート するなどの他の手段によってアンマウントされた暫定修正をマウントする ために使用できる。

-q エラーおよび重大な警告以外のすべての出力を抑止します。
-r emgrコマンドに、指定された暫定フィックスまたは暫定フィックスの削除を指示する。

アクティブなパッチを除去すると、モジュールに既存のパッチがある場合はそのパッチが復元されます。 事前にパッチが存在しない場合、モジュールは元のパッチ未適用の状態に戻される。

-U emgrコマンドに、'-mフラグを使ってマウントインストールされている暫定フィックスまたは暫定フィックスをアンマウントするように指示する。
--v{1|2|3} -v{1|2|3} フラグは、リスト操作の詳細レベル、または検査操作の検査レベルを指定します。 -v4 フラグは、リスト操作のコロン区切りの出力を表示します。 -vフラグの有効レベルは1、2、3、4であり、「-v4フラグは「-lフラグでのみサポートされる。

セキュリティー

aix.system.install 権限を持つシステム管理者またはユーザーは、マルチレベル・セキュア (MLS) システムで emgr コマンドを実行できます。 Ifix データ、保存ファイル、および一時ファイルは、root ユーザーのみがアクセス可能です。

権限 aix.system.install.list を持つ非rootユーザーは、現在 efixesインストールされているパッケージを一覧表示するコマンド emgr を実行できます。 非rootユーザーが認証 aix.system.install を持っている場合、インストールや削除を行うことができます efixes。

emgr コマンドは、システムから、サポートされる MD5 生成コマンドを探します。 見つかると、emgr コマンドは MD5 チェックサムをユーザーに表示します。 ユーザーはこのMD5合計を安全なソースとクロスチェックする。 MD5 生成コマンドが見つからない場合は、emgr コマンドはその後の 処置をとりません。

ユーザーは、EMGR_MD5_CMD シェル変数をエクスポートすることによって MD5 コマンドへのパスを強制的に設定できます。 この変数には、MD5を生成するコマンドの絶対パスを格納しなければならない。

注:
  • この機能は、 暫定修正 管理の元のリリースではサポートされていません。 ユーザーは、「bos.rte.install最新レベルに更新することにより、暫定的な修正管理の最新レベルに更新することを推奨する。

  • Trusted Execution (TE) ポリシーが TSD_LOCK ポリシーまたは TSD_FILE_LOCK ポリシーと一緒にオンになっていると、emgr コマンドは失敗します。 インストールを続行するには、TSD_LOCK ポリシーまたは TSD_FILE_LOCK ポリシーをオフにしてください。 emgr コマンドは、 TSD_LOCK ポリシーまたは TSD_FILE_LOCK ポリシー以外の TE ポリシーを使用して正常に実行されます。

    また、TE ポリシーがオンになっていると、サポートされる emgr コマンドのインスタンスは 1 つだけです。

例

  1. games.020303.epkg.Z」という中間修正パッケージのインストールをプレビューするには、以下のコマンドを入力する：
    emgr -p -e games.020303.epkg.Z
  2. games.020303.epkg.Z」と呼ばれる暫定修正パッケージをインストールし、追加のスペースが必要な場合にファイルシステムを自動的に拡張するには、以下のコマンドを入力する：
    emgr -X -e games.020303.epkg.Z
  3. システム上のすべての暫定修正をリストするには、次のコマンドを入力します。
    emgr -l
  4. システム上のすべての暫定修正をコロンで区切ってリストするには、次のコマンドを入力します。
    emgr -l -v4
  5. ラベル「games」を持つ中間修正のレベル3リストを作成するには、以下のコマンドを 入力します：
    emgr -lv3 -L games
  6. ラベル「games」の暫定修正を削除するには、以下のコマンドを入力する：
    emgr -r -L games
  7. ファイル「/tmp/myfixes」の暫定修正ラベルの削除をプレビューするには、以下のコマンドを入力する：
    emgr -rp -f /tmp/myfixes
  8. すべての暫定修正を検査レベル 2 で検査するには、次のコマンドを入力します。
    emgr -cv2
  9. 暫定修正 ID 番号 3 を検査レベル 1 (デフォルトの検査レベル) で検査するには、次のコマンドを入力します。
    emgr -c -n3
