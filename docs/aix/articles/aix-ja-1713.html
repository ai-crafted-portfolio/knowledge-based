目的
仮想ファイバー・チャネル (VFC) クライアント・アダプターに関する情報 (統計、状況、アクティビティーなど) を表示します。

説明
vfcstat
コマンドは、仮想 FC アダプターの状態、状況、NPort ID、入出力キュー情報、読み取り/書き込み統計、ホスト (VIOS) とのバインディング情報、リンク・エラー、パス・タイムアウトなどの情報を報告します。 必要な情報はリアルタイムで取り出され、出力に表示されます。 統計やエラー件数などの詳細の一部をリセットできます。
-F
オプションを使用して、スクリプトの目的でフォーマット済み出力の読み取り/書き込み統計情報を取得することもできます。
vfcstat
コマンドは、指定された時間間隔における特定の回数の統計を表示します。
vfcstat
コマンドは、仮想 FC クライアント・アダプターでのみ機能します。

構文
vfcstat [ -h ] | [-l ] vfcstat -d vfc_client_adapter [ -f 関数名 ] vfcstat -d vfc_client_adapter -e [ -z ] vfcstat -d vfc_client_adapter [ -s [ -z ]] [ -c no_of_times_to_run [ -i intervel_sec ]] [ -F ]

オプション
フラグ
--c
no_of_times_to_run
stats 関数を指定するときに
vfcstat
コマンドを実行する必要がある回数を指定します。 有効な値の範囲は 1 から 86400 です。
--d
vfc_client_adapter
仮想 FC クライアント・アダプターの名前を指定します。
-e
リンクおよびパス・タイムアウト・イベントのエラー件数を表示します。
--f
関数名
出力を表示する機能を指定します。 仮想 FC クライアント・アダプターで使用可能な機能のリストについては、
例 2
を参照してください。
-F
定様式統計出力を表示します。
-h
使用法とヘルプ情報を表示します。
-
インターレベル秒
vfcstat
コマンドを複数回実行する間隔を指定します。 有効な値は、1 から 86400 秒の範囲です。 デフォルト値は 1 秒です。
-l
すべての仮想 FC クライアント・アダプターをリストします。
-s
読み取り/書き込み統計を表示します。
-z
統計またはエラー件数のメトリックをリセットします。

例
すべての仮想 FC クライアント・アダプターをリストするには、次のコマンドを入力します。
# vfcstat -l
出力は次の例のようになると考えられます。
fcs0
fcs1
特定の仮想 FC アダプターで使用可能なすべての機能をリストするには、次のコマンドを入力します。
# vfcstat -d fcs0
出力は次の例のようになると考えられます。
activity
capabilities
hostinfo
link
nport_id
status
tunables
wwpn
特定の仮想 FC アダプターの状況を表示するには、次のコマンドを入力します。
# vfcstat -d fcs0 -f status
