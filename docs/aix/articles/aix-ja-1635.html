目的
他のユーザー辞書をオペレーティング・システムのユーザー辞書に変換します。

説明
twconvdict
コマンドは、ディクショナリーをオペレーティング・システムのユーザー辞書に変換します。 サポートされているコード・ページは SOPS、PS55、および ET です。 ディクショナリーのタイプには、Tseng_Jye と Phonetic ユーザー辞書の両方があります。

構文
twconvdict [ -i Type ] [ -v CodePage ] [ -f Source ] [ -t ターゲット ]

オプション
フラグ
項目 | 説明
-f ソース | 変換するフォント・ファイルの名前を指定します。
-i タイプ | 変換するディクショナリーのタイプを指定します。 Type は、以下のいずれかです。 TJ Tseng_Jye PH Phonetic
-t ターゲット | 変換されたフォント・ファイルの名前を指定します。
-v CodePage | 変換するコード・ページのタイプを指定します。 CodePage は以下のものにすることができます。 SOPS PS55 ET 。

例
辞書を変換するには
USRFONT.C12
タイプ SOPS のコード・ページおよび名前 Tseng_Jye のディクショナリー・タイプ Tseng_Jye のオペレーティング・システム辞書に
aix
次のように入力します。
twconvdict -i TJ -v SOPS -f USRFONT.C12 -t aix
