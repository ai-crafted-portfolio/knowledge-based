目的
i ノード番号からパス名を生成します。

説明
ncheck
コマンドは、ファイルシステム・ファイルの i ノード番号とパス名を表示します。 パスに表示される疑問符 (??) を使用して、見つからなかったコンポーネントを示します。 表示されるパス名 ... (省略符号) は, ループまたは 10 個を超える項目のパス名のいずれかを示します。
ncheck
コマンドは単純なハッシュ・アルゴリズム
を使用して、表示するパス名を作成し直します。 このため、ncheck コマンドを実行できるファイルシステムはディレクトリーのエントリーが 50,000 未満のファイルシステムに制限されます。

構文
ncheck [[[ -a ] [ -i InNumber ... ]] | [ -s ]] [ -o Options ] [ FileSystem ]

オプション
フラグ
項目 | 説明
-a | リストします。 (ドット) ファイルおよび .. (ドット・ドット) ファイルだけでなく、 (ドット・ドット) ファイル名。
-i InNumber | InNumber パラメーターで指定されたファイルのみをリストします。
-o オプション | 仮想ファイルシステム用のインプリメント固有のオプションのコンマ区切りリストを指定します。 以下のオプションは、拡張ジャーナル・ファイルシステム (JFS2) に固有です。 - o snapshot= snapName )： ncheck コマンドの対象となる内部スナップショットの名前を指定します。 スナップショットを所有するファイルシステムがマウントされていなければなりません。
-s | スペシャル・ファイルとセット・ユーザー ID モードを持つファイルのみをリストします。

例
デフォルト・ファイルシステム内の各ファイルの i ノード番号とパス名をリストするには、次のように入力します。
ncheck
指定されたファイル・システム内のすべてのファイルをリストするには、次のように入力します。
ncheck
-a
/
これは、
/
(ルート) ファイルシステム内の各ファイル (. (ドット) および .. を含む) の i ノード番号とパス名をリストします。 各ディレクトリー内の (ドット・ドット) 項目。
i ノード番号が分かっているファイルの名前をリストするには、次のように入力します。
ncheck
-i
690 357 280 /tmp
これは、
/tmp
ファイルシステム内のすべてのファイルの i ノード番号とパス名を i ノード番号とともにリストします。
690
,
357
、または
280
ファイルに複数のリンクがある場合には, そのすべてのパス名がリストされます。
特殊ファイルおよびセット・ユーザー ID ファイルをリストするには、次のように入力します。
ncheck
-s
/
これは、
/
(ルート) ファイルシステム内でスペシャル・ファイル (装置ファイルとも呼ばれる) か、もしくはセット・ユーザー ID モードが使用可能になっているすべてのファイルの i ノードおよびパス名をリストします。
