目的
次のメッセージを表示します。

説明
next
コマンドは、メッセージ・ハンドラー (MH) フォルダーにファイルされている次のメッセージにシステムが割り当てる番号を表示します。
next
コマンドは、
next
値をメッセージとして指定した
show
コマンドと同じです。
next
コマンドは
show
プログラムにリンクし、スイッチを
showproc
プログラムに渡します。
next
値にリンクし、そのリンクに
next
以外の名前を付ける場合、リンクは
next
コマンドではなく、
show
コマンドと同様に機能します。
show
コマンドは認識されないフラグを、リストを行うプログラムに渡します。
next
コマンドは、いくつかのフラグをリストするプログラムに渡します。

構文
next [ + フォルダー ] [ -header | -noheader ] [ -showproc CommandString | -noshowproc ]

オプション
フラグ
項目 | 説明
+ フォルダー | 表示したいメッセージが入っているフォルダーを指定します。
-header | 表示対象のメッセージについて 1 行の記述を表示します。 記述には、フォルダー名とメッセージ番号が含まれます。 これはデフォルトです。
-help | これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。 “ 注: MH の場合は、このフラグ名を省略することはできません。 ”
-ヘッダーなし | 表示する各メッセージを 1 行での記述で表示するのを抑制します。
-ノショウプロック | リスト作成を行うため /usr/bin/cat ファイルを使用します。 これはデフォルトです。
-ショープロック CommandString | 指定されたコマンド・ストリングを使用してリスト作成を行います。

例
現行フォルダー内の次のメッセージを表示するには、次のように入力します。
next
システムは、次のようなメッセージで応答します。
(Message schedule: 10)
メッセージのテキストも表示されます。 この例では、次のメッセージがあります。
10
現行フォルダー内
schedule
次のメッセージです。
次のメッセージを表示するには、次のようにします。
project
次のように入力します。
next
+
project
システムはメッセージのテキストと以下のようなヘッダーを表示して応答します。
(Message project: 5)
