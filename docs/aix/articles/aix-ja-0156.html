目的
コア・ファイルの設定を変更します。

説明
chcore
コマンドは、コア設定を変更するためのユーザー・インターフェースです。 これは次のようにして使用します。
chcore [-R registry] options [username|-d]
ここで、
options
は、次のうちの少なくとも 1 つ (複数の可能性がある) です。
-c {on|off|default}
コア圧縮に関する設定
-p {on|off|default}
コア・ロケーションに関する設定
-l path
使用するディレクトリーの
指定
-n {on|off|default}
コアの命名に関する設定
-d
が指定されている場合、
chcore
はシステムのデフォルト設定を変更します。
-d
オプションは、指定された
username
および
registry
の指定と同時に使用することはできません。
-d
も
username
も指定しない場合、
chcore
は現行ユーザーの設定を変更します。
-d
オプションと、別のユーザー (現行ユーザー以外) の設定を変更する機能は両方とも特権操作であり、root またはシステム権限を持つ別のユーザーのみが実行できます。 次のログイン・セッションまでは、加えられた変更は有効になりません。
代替識別および認証 (I & A) メカニズムの属性を変更するには、
-R
フラグを使用して I & A ロード・モジュールを指定できます。
-R
フラグが指定されていない場合、
chcore
コマンドはデフォルトの属性を使用します。 ロード・モジュールは、
/usr/lib/security/methods.cfg
ファイルで定義されます。
注:
chcore
コマンドによって変更されたコア設定は、システムのリブート後も持続します。

構文
chcore [ -R 登録簿 ] [ -c { on | off | default }] [ -p { on | off | default }] [ -l { パス | default] [ -n { on | off | default }] [ ユーザー名 | -d ]

オプション
フラグ
項目 | 説明
-c { on | off | default } | コア圧縮に関する設定
-d | システムのデフォルトの設定値を表示します。
-l パス | 保管コア・ファイルのディレクトリー・パス
-n { on | off | default } | コアの命名に関する設定
-p { on | off | default } | コア・ロケーションに関する設定
-R レジストリー | ロード可能な I&A モジュールを指定します。

例
ルート・ダンプ圧縮コア・ファイルによっていずれかのプロセスを実行させ、コア・ファイルのロケーションを
システム・デフォルトにリストアする場合は、次のように入力します。
chcore -c on -p default root
注:
デフォルトが指定されていない場合、コアは現行ディレクトリーにダンプされます。
システムのデフォルトのコア・パスを使用可能にする場合は、次のように入力します。
chcore -p on -l /corefiles -d
注:
chcore -p off
を使用してコア・パスを明示的に無効にしないか、
chcore -l
を使用してコア・パスをオーバーライドしないすべてのユーザーは、コア・ファイルをディレクトリー
/corefiles
にダンプします。 ユーザーにそのディレクトリーへの
書き込み許可がなかったり、そのディレクトリーが存在しない場合は、コア・ファイルが生成されません。
