目的

ファイルを DOS ファイルにコピーします。

構文

doswrite [ -a ] [ -v ] [ -DDevice ] File1 File2

説明

doswrite コマンドは、 File1 パラメーターで指定されたファイルを File2 パラメーターで指定された DOS ファイルにコピーします。 doswrite コマンドは、ファイルを単一の DOS ディスケットにコピーします。 doswrite コマンドは、複数の DOS ディスケット間でファイルをコピーすることはできません。

doswrite コマンドは、標準の DOS 命名規則を使用して、 File2 パラメーターで指定されたファイルを DOS デバイスに書き込みます。 DOS ¥ (バックスラッシュ) 文字は、 DOS オペレーティング・システムでは特別な意味を持つ可能性があるため、 File2 パラメーターでサブディレクトリー名を指定するときに ¥ (バックスラッシュ) を使用しないでください。 代わりに / (スラッシュ) 文字を使用してください。

doswrite コマンドは、 File1 パラメーターに指定された小文字を大文字に変換してから、 DOS デバイスを検査します。 すべてのファイル名が絶対パス名 (相対パス名ではない) と見なされるので、 最初の / (スラッシュ) は付ける必要はありません。

File2 パラメーターで指定したファイルに / (スラッシュ) が含まれている場合、 その間にある各コンポーネントはディレクトリーとして存在しなければならず、最後のコンポーネント (指定されたファイル) は存在していてはなりません。 同じ名前のファイルが存在する場合は、すべて上書きされます。

注:
  1. このコマンドでは、ワイルドカード文字 * と ? (アスタリスクと疑問符) は 特別な方法で処理されません (ただし、シェルによって処理されます)。 ファイル名の拡張子を指定しないと、ブランクの拡張子を指定した場合と同様にファイル名の照合が行われます。
  2. このコマンドは、 doswrite と指定されなければなりません。
  3. DOS ディレクトリーは、最大 244 個のファイルを保持します。

フラグ

項目
説明
-a NL (改行文字) を CR-LF (復帰、改行) シーケンスに置き換えます。 ファイルの末尾に Ctrl-Z が追加されます。
-D デバイス DOS デバイスの名前を /dev/fd0 または /dev/fd1として指定します。 デフォルト・デバイスは /dev/fd0 です。 このデバイスは、 DOS ディスク・フォーマットでなければなりません。
-v ディスクのフォーマットに関する情報を、標準出力します。 デバイスが DOS ディスクであることを確認するには、このフラグを使用します。

例

  1. テキスト・ファイルを DOS ディスケットにコピーするには、次のように入力します。
    doswrite  -a chap1 chap1.doc
    これによりファイルがコピーされますchap1現行ディレクトリーから DOS テキスト・ファイルへ\CHAP1.DOCデフォルト・デバイス /dev/fd0上。
  2. バイナリー・ファイルを DOS ディスケットにコピーするには、次のように入力します。
    doswrite -D/dev/fd1 /home/fran/testdata /survey/test.dta
    これによりデータ・ファイルがコピーされます/home/fran/testdataDOS ファイルへの\SURVEY\TEST.DTA/dev/fd1の場合。
  3. 現行ディレクトリー内のすべてのファイルをデフォルト・ドライブの DOS ディスケットにコピーするには、次のように入力します。
    for i in *
do
doswrite $i $i
done
