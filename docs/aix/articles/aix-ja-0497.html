目的
ディスケットへのコピーと、ディスケットからのコピーを行います。

説明
flcopy
コマンドは、ディスケット (
/dev/rfd0
としてオープン) を現行ディレクトリーに作成された
floppy
という名前のファイルにコピーしてから、次のメッセージを印刷します。
Change floppy,
hit return when done
次に、
flcopy
コマンドは
floppy
ファイルをディスケットにコピーします。 フラグ
-f
、
-h
、
-r
、
-t
Number
を使用して、
flcopy
コマンドの動作を変更できます。
注:
flcopy
コマンドを使用して、あるディスケットから別のサイズのディスケットにデータをコピーすることはできません。

構文
flcopy [ -f デバイス ] [ -h | -r ] [ -t Number ]

オプション
フラグ
項目 | 説明
-f デバイス | /dev/rfd0 以外のドライブが指定できます。
-h | flcopy コマンドに現行ディレクトリー内の floppy ファイルをオープンさせ、 /dev/rfd0 にコピーさせます。
-r | ディスケットを現行ディレクトリー内の flcopy ファイルにコピーした後で終了するよう floppy コマンドに命令します。
-t 数値 | Number で指定した数のトラックをコピーします。 常にディスケットの最初のトラックからコピーされます。

例
/dev/rfd1
を現行ディレクトリーの
floppy
ファイルにコピーするには、次のように入力します。
flcopy
-f
/dev/rfd1
-r
ディスケットの最初の 100 トラックをコピーするには、次のように入力します。
flcopy
-f
/dev/rfd1
-t
100
