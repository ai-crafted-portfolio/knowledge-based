目的

インターネット・ドメイン・ネーム・システム（DNS）に対話的に問い合わせる。

構文

nslookup [ - option ] [ name | - ] [ server ]

説明

nslookupコマンドは、次の2つのモードでインターネット・ドメイン・ネーム・サーバーに問い合わせる：
対話モード
様々なホストやドメインに関する情報をネームサーバーに問い合わせたり、ドメイン内のホストのリストを印刷したりすることができる。
非インタラクティブ・モード
指定されたホストまたはドメインの名前と要求された情報を表示します
nslookupコマンドは、引数を与えない場合、または最初の引数が「-（ハイフン）で、2番目の引数がネームサーバーのホスト名またはIPアドレスの場合、対話モードになる。 引数を指定しないと、コマンドはデフォルトのネーム・サーバーを照会します。 nslookupコマンドは、検索するホストの名前またはIPアドレスを第1引数に指定すると、非インタラクティブ・モードになる。 オプションの第2引数には、ネームサーバーのホスト名またはアドレスを指定する。 コマンド・ラインに各オプションを指定可能なのは、オプションが各引数の前にあり、かつ、ハイフンが接頭部として付けられている場合です。 例えば、デフォルトの照会タイプをホスト情報に変更し、初期タイムアウトを 10 秒に変更するには、下記のコマンドを入力します。
nslookup -query=hinfo  -timeout=10
-versionオプションは、「nslookupコマンドにバージョン番号を表示させ、終了させる。

戻り値

nslookupコマンドは、クエリーに失敗すれば終了ステータスを1、そうでなければ0を返す。

IDN サポート

nslookupコマンドが国際化ドメイン名（IDN）をサポートして構築されている場合、非ASCIIドメイン名を受け入れ、表示することができる。 nslookupコマンドは、DNSサーバーにリクエストを送信したり、サーバーからの応答を表示したりする際に、ドメイン名の文字エンコードを変換する。 IDN サポートをオフにするには、 IDN_DISABLE 環境変数を定義します。 nslookupコマンドの実行時に環境変数'IDN_DISABLEが設定されている場合、 または標準出力がttyでない場合、IDNのサポートは無効になる。
