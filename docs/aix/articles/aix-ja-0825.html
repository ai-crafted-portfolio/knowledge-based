目的
TCP/IP 経由のNon-Volatile Memory Express（NVMe）ターゲットデータに関する情報を表示します。

説明
注：
AIX® 7.3 テクノロジーレベル 4 ( TL4 ) 以降、NVMe over TCP/IP プロトコルはテクノロジープレビューとしてのみ利用可能です。
この
lstcpnvme
コマンドは、Object Data Manager（ ODM ）からのNVMe over TCP/IP ターゲットデータに関する情報を表示します。 統計的に構成されたNVMe over TCP/IP のターゲットデータは、 ODM に保存されます。 AIX がNVMe over TCP/IP ターゲットのデータを検出するには、ディスカバリーコントローラのNVMe認定名（NQN）、IPアドレス、ポート番号など、関連するNVMe over TCP/IP ターゲット情報を指定する必要があります。

構文
lstcpnvme [ -l ProtocolDevice ] [ -g group ] [ -F format ]

オプション
フラグ
項目 | 説明
-F Format | ユーザーが指定したフォーマットで出力を表示する。 カラム名の引用符付きリストで 書式を 指定する。 カラム名は英数字以外の文字または空白で区切られる。 区切り文字として空白を使用した場合、 lstcpnvme コマンドは、整列された列で出力を表示する。
-g Group | TCP/IP 上のNVMeターゲットが関連付けられているグループを指定します。 「静的グループ」オプションがサポートされています。これは、このホストから自動的に検出されない、 TCP/IP 経由のNVMeターゲットデータ用です。 NVMe over TCP/IP ターゲットのデータを検出するには、検出対象のコントローラのNQN、IPアドレス、ポート番号など、関連するNVMe over TCP/IP ターゲット情報を指定する必要があります。
-l ProtocolDevice | NVMe over TCP/IP プロトコル対応デバイスの名前を表示します。 例えば、 tcpnvme X はNVMeデバイスの名前である。

例
tcpnvme0 デバイスのNVMe over TCP/IP ターゲットのデータ一覧を表示するには、次のコマンドを入力します：
lstcpnvme -l tcpnvme0
システムは以下の画面のような出力を表示する：
tcpnvme0 172.20.20.12 4420 nqn.2014-08.org.nvmexpress.discovery 0xffff
このホストのNVMe over TCP/IP ターゲットのデータを一覧表示するには、次のコマンドを入力してください：
lstcpnvme
システムは以下の画面のような出力を表示する：
tcpnvme0 172.20.20.12 4420 nqn.2014-08.org.nvmexpress.discovery 0xffff
tcpnvme1 172.20.20.14 4420 nqn.2014-08.org.nvmexpress.discovery 0xffff
