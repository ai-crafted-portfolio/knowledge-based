構文
トロフ [ -a 値 ] [ I ] [ -Q (Q) ] [ -z ] [ -F (R) ディレクトリー ] [ N 数値 ] [ - リスト ] [ - ANumber (A) ] [ -s 数値 ] [ -T (T) 名前 ] [ -mm (M) | -私 | -MPTX | -ミリ秒 | -マン | -mv (M) ] [ -M (M) メディア ] [ ファイル ... | - ]

オプション
フラグ
項目 | 説明
-a | 印刷可能で、ASCII に相当する形でフォーマットされた結果を標準出力に送ります。
-F ディレクトリー | デフォルトの /usr/lib/font/dev Name ディレクトリーではなく、 Directory/ dev Name ディレクトリーのフォント情報にアクセスします ( Name は -T フラグで指定します)。
-i | ファイルがなくなると標準入力を読みます。
-M メディア | 用紙上のイメージ可能領域の大きさを判別するために、用紙サイズを指定します。 Media 変数で有効な値は以下のとおりです。 A4 用紙サイズ 8.3 X 11.7 インチ (210 X 297 mm) を指定します。 A5 用紙サイズ 5.83 X 8.27 インチ (148 X 210 mm) を指定します。 B5 用紙サイズ 6.9 X 9.8 インチ (176 X 250 mm) を指定します。 EXEC 用紙サイズ 7.25 × 10.5 インチ (184.2 × 266.7 mm) を指定します。 LEGAL 用紙サイズ 8.5 X 14 インチ (215.9 X 355.6 mm) を指定します。 LETTER 用紙サイズ 8.5 X 11 インチ (215.9 X 279.4 mm) を指定します。 これはデフォルト値です。 注: Media 変数では大文字小文字の区別はありません。
-n 数値 | Number 変数で指定された値を使って最初の印刷ページに番号を付けます。

-o リスト | List 変数で指定されたページだけを印刷します。 List は以下のように、ページ番号と範囲をコンマで区切ったリストです。 Start-Stop の範囲は、 Start から Stop までのページの印刷を意味します。 次に例を示します。 9-15 ページ 9 から 15 までを印刷します。 最初の -Stop は、先頭ページからページ Stop までの印刷を意味します。 最後の Start- は、ページ Start から最終ページまでの印刷を意味します。 ページ番号と範囲を組み合わせると、指定したページが印刷されます。 次に例を示します。 -3,6-8,10,12- 先頭から 3 ページ目、6 から 8 ページ目、10 ページ目、12 ページ目から末尾までを印刷します。 注: このフラグをパイプラインで使用すると (例えば、 pic 、 eqn、 または tbl コマンドを 1 つ以上使用すると)、以下のようになります。 broken pipe 文書の最後のページが List 変数に指定されていない場合は、メッセージが表示されます。 この broken pipe メッセージは問題があることを示すものではないので、無視してかまいません。
-q | .rd 要求の同時入出力モードを呼び出します。
-r アンナンバー | A 変数で指定されたレジスターを指定の数値に設定します。 A 変数の値は、1 文字の ASCII 名でなくてはなりません。
-s 数値 | 指定されたページ数ごとにタイプセッターを停止させる出力を生成します。

-T 名前 | 指定のプリンターへの出力を準備します。 フォトタイプセッターまたはそれに相当する印刷装置は、オペレーティング・システム国際拡張文字に以下の Name 変数を使用しています。 デフォルトは ibm3816 です。 注: 次のようなメッセージが表示されます。 bad point size 装置が指定されたポイント・サイズをサポートしていない場合。 troff コマンドは最も近い有効ポイント・サイズを使ってフォーマットを継続します。 正規 (canonls) Canon Lasershot LBP-B406S/D/E,A404/E,A304E ibm3812 3812 Pageprinter II ibm3816 3816 Pageprinter hplj (hplj) Hewlett-Packard LaserJet II ibm5585H-T 5585-H01 中国語 (繁体字) サポート ibm5587G 5587-G01、5584-H02、5585-H01、5587-H01、5589-H01 Kanji Printer マルチバイト言語サポート PSC PostScript プリンター。 X100 AIXwindows が表示されます。 注: troff コマンドの -T Name フラグを使用する代わりに、 TYPESETTER 環境変数を上記のいずれかの値に設定することもできます。
-男性 | man マクロ処理パッケージを選択します。
-私 | me マクロ処理パッケージを選択します。
-MM | mm マクロ処理パッケージを選択します。
-エムピーティーエックス | mptx マクロ処理パッケージを選択します。
-ms | ms マクロ処理パッケージを選択します。
-mv | mv マクロ処理パッケージを選択します。
マクロについて詳しくは、「
フォーマット・ツールのマクロ・パッケージ
」を参照してください。
