目的
NIS
コントローラー・サーバーの構成の特性を表示します。

説明
lsmaster
コマンドは、
NIS
コントローラー・サーバーの特性を表示します。 ワーカー・サーバーのホスト名が、現在提供されているドメインとともにリストされます。
このコマンドは、System Management Interface Tool (SMIT)
smit lsmaster
高速パスを使用して実行することができます。

構文
/usr/sbin/lsmaster [ -c | -l ]

オプション
フラグ
項目 | 説明
-c | コロン・フォーマットで出力するように指定します。 このフラグはデフォルトです。
-l | リスト・フォーマットで出力するように指定します。

例
NIS
コントローラー・サーバーの特性をコロン・フォーマットでリストするには、次のように入力します。
lsmaster -c
