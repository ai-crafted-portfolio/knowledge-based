目的
cdromd
デーモンに、デバイスの管理を中断または再開するように伝えます。

説明
cdutil
コマンドは、
DeviceName
によって指定されたデバイスの管理を中断 (
-s
フラグ) または再開 (
-r
フラグ) する
cdromd
デーモンに、適切なコマンドを送信します。
cdromd
によって管理されるデバイスは、未構成とする必要がある場合
(例えば、親アダプターのホット・スワップのために)、一時停止状態に設定しなければなりません。
再開フラグ (
-r
) は、
cdromd
にデバイスのポーリングを再始動するように要求します。

構文
cdutil { -l | -r | -s [ -k ]} [ -q ] [ -h | -? ] DeviceName

オプション
フラグ
項目 | 説明
-h または -? | コマンドの使用メッセージを表示します。
-k | デバイスを中断している時はメディアをイジェクトしないでください。
-l | ドライブにメディアがある場合はロードします。
-q | サイレント・モード (情報またはエラー・メッセージを書き出さない) を指定します。
-r | cdromd によるデバイス管理を再開します。
-s | cdromd によるデバイス管理を中断します。
DeviceName | デバイス名を指定します。

例
cdromd
による
cd0
の管理を中断するには、
次のように入力します。
cdutil -s cd0
メディアをイジェクトせずに
cdromd
による
cd0
の管理を中断するには、次のように入力します。
cdutil -s -k cd0
エラー・メッセージを印刷せずに、
cdromd
による
cd1
の管理を再開するには、次のように入力します。
cdutil -r -q cd1
