目的
nimclient
コマンドは、NIMクライアントからネットワーク・インストレーション・マネージメント（NIM）操作を実行できるようにする。

説明
nimclient
コマンドは、NIM クライアントのワークステーションで NIM リソースを取り出すために使用します。 このコマンドを使用すると、NIM マスター・サーバーでワークステーションをインストールおよびカスタマイズする機能を使用可能にしたり使用不可にしたりできます。
nimclient
コマンドは、利用可能なNIMリソースのリストを生成したり、すでにクライアントに割り当てられているNIMリソースを表示したりするのに使用できる。
nimclient
コマンドに「
-o
フラグを付けると、限定されたNIM操作を実行できる。

構文
NIMマスターのプッシュ権限を有効または無効にするには nimclient { -p } | { -P } NIMマスタープッシュ操作で暗号化認証を有効または無効にするには nimclient { -c } | { -C } NIM環境に関する情報を掲載するには nimclient -l LsnimParameters NIMマスターの日時を設定するには nimclient -d NIMオペレーションを実行するには nimclient -o Operation [ -a Attribute=Value ] ...

オプション
フラグ
表 1. フラグ
項目 | 説明
-a 属性 = 価値 | NIM 操作に情報を渡します。 マスターから 特定の操作に有効な属性のリストを取得するには、' lsnim -q Operation -t Type コマンドを使用する。 クライアントから 特定の操作に有効な属性のリストを取得するには、' nimclient -l -q Operation -t Type コマンドを使用する。
-c | NIM マスター・プッシュ操作の際に SSL 認証を使用可能にします。 注： OpenSSL証明書は、NIMマスター上で「 nimconfig -c コマンドを使用して設定する必要がある。 SSL 証明書は、 nimclient -c が実行されるときに、NIM マスターからコピーされます。
-C | SSL 認証を使用不可にし、NIM マスター・プッシュ操作の際に標準の nimsh セキュリティーを使用します。
-d | クライアントの日時をマスターの日時に設定します。
-e | デュアル・スタック・モードをサポートするように NIM クライアント環境を構成します。これは、単一のインターフェース定義による IPv4 および IPv6 プロトコルの実装を意味します。 注： デュアルスタック環境を設定する前に、「 autoconf6 コマンドを実行し、「 ndpd-host デーモンを起動する。
-l Lsnimパラメータ | 指定した ' lsnim パラメータを使用して、マスター上で ' lsnim コマンドを実行する。 このオプションで使用するすべてのパラメータは、「 lsnim コマンドの構文規則に従わなければならない。 一部の「 lsnim 構文では、NIMオブジェクト名を使用する必要がある。 ご使用のマシンの NIM 名は、 /etc/niminfo ファイルで調べてください。 注記: から 7.3AIX®、テクノロジーレベル3において、NIMオブジェクトタイプ向けに新しい customer オブジェクトタイプが導入されます。 NIM customer オブジェクトタイプの導入に伴い、` nimclient -l command`は現在の customer オブジェクトグループに属するリソースのみを表示します。 NIMオブジェクトタイプの詳細については、コマンド nim ページのフラグ -t を参照してください。

-o Operation | 指定された操作を行います。 以下は可能な操作である： allocate リソースを割り当てて使用できるようにします。 bos_inst BOS インストールを実行します。 change オブジェクトの属性を変更します。 check NIM オブジェクトの状況を検査します。 cust ソフトウェアのカスタマイズを実行します。 deallocate リソースの割り当てを解除します。 diag この操作により、マシンは診断イメージをブートできるようになる。 maint_boot この操作により、マシンをメンテナンスモードで起動できるようになる。 reset オブジェクトの NIM 状態をリセットします。 showres NIM リソースの内容を表示します。
-p | -p フラグは、NIMマスターがコマンドをプッシュできるようにする。
-P | コマンドをプッシュするためのNIMマスターの権限を削除する。 注: マスターは、 -F フラグを使用してこの制限を変更できます。
注：
この
nimclient -l -POt
standalone
コマンドの出力には、NIMマスターがスタンドアロンのNIMオブジェクトに対して実行できる操作が表示されます。 クライアントは、この
nimclient -l -POt
standalone
コマンドで指定されたすべての操作を実行できません。 クライアントは、この
nimclient -o <Operation>
コマンドを使用して、有効な操作の限定されたセットを実行できます。 コマンド
nimclient --?
を使用すると、有効な操作の一覧を確認できます。
