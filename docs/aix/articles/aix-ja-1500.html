目的
1 つのピア・ドメインから 1 つ以上のノードをオフラインにします。

説明
stoprpnode
コマンドは、ピア・ドメインからオンライン・ノードをオフラインにします。 ピア・ドメインは、コマンドを実行するオンラインの
ピア・ドメインにより決定されます。 このコマンドは、目的のピア・ドメインに対してオ
ンラインとなっているノードから実行する必要があります。
Cluster-Aware AIX® (CAA) クラスターが構成されている場合、CAA 環境のピア・ドメイン操作が存在し、CAA クラスターの存続期間中はオンラインであるため、アクションは実行されません。
-f
フラグは、ノードをオフラインにする要求のサブシステムによる拒否をオーバーライドするために使用する必要があります。 ディスクが共有されている場合など、ノード・リソースが使用中
の場合は、サブシステムが要求をリジェクトすることがあります。 この状況で
-f
フラグを指定すると、リソースの状態に関係なくノードをオフラインにする必要があることをサブシステムに示します。
このコマンドで複数の
node_name
パラメーターを
使用して複数のノードをオフラインにしようとすると、このコマンドを実行中の
ノードがリストに入っている場合、そのノードが最後にオフラインになります。

構文
stoprpnode [ -f ] [ -h ] [ -w [-s 秒 ] [ -TV ] node_name1 [ node_name2 ...] stoprpnode -F { file_name | "–" } [ -f ] [ -h ] [ -w [-s Seconds ] [ -TV ]

オプション
フラグ
-f
サブシステムがそうでなければ受諾しない場合でも、サブシステムに停止要求を
受諾するように強制します。
--F
{
ファイル名
|
"-"
}
file_name
からノード名のリストを読み取ります。 ファイルの行ごとに 1 つのノード名がスキャンされます。 ポンド記号 (
#
) は、行の残りの部分 (または
#
が 1 桁目にある場合は行全体) がコメントであることを示します。
-F "-"
を使用して、入力ファイルとして
STDIN
を指定します。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。
-s
フラグを
-w
フラグと一緒に使用する場合に、コマンドが完了する前に、指定されたノードがすべてオフラインになるのを待つ時間を秒数で指定します。 待ち時間がその秒数を超えると、コマンドは戻りますが、オフライン操作は継続します。 デフォルト値は 300 秒 (5 分) です。 指定されたノードがすべてオフラインになるまでコマンドが戻ってはならないことを指定するには 0 を使用します (待ち状態でタイムアウトなし)。
-T
コマンドのトレース・メッセージを標準エラーに書き込みます。 これは、ソフトウェア保守部門専用の機能です。
-V
コマンドの詳細メッセージを標準出力に書き込みます。
-w
コマンドが完了する前に、指定されたノードがすべてオフラインになるのを待ちます。 待ち時間を秒単位で指定するには、
-s
フラグを使用します。

例
これらの例では、
nodeA
および
nodeB
は、
ApplDomain
に対してオンラインです。
nodeB
をオフラインにするには、
nodeA
で次のコマンドを実行します。
stoprpnode nodeB
nodeB
をオフラインにし、オフライン要求を強制するには、
nodeA
で次のコマンドを実行します。
stoprpnode -f nodeB
