目的

マルチパス入出力 (MPIO) ストレージ・デバイスに関する情報を表示します。

構文

lsmpio [ -l デバイス名］ [ -o ]

lsmpio-S [ -l デバイス名］ [ -d ]

lsmpio-z [ -l デバイス名 ]

lsmpio-q [ -l デバイス名 ]

lsmpio -a [ -r ] [ -e ] [ -z ] [ -f ]

lsmpio -h

説明

lsmpio コマンドは、 AIX® MPIO ストレージ・デバイスに関する情報を表示します。 このコマンドは、 lsmpio コマンド・サポートが有効になっているパス制御モジュール (PCM) によって制御される AIX MPIO ストレージ・デバイスに対してのみ使用できます。 一部の AIX® MPIO ストレージ・デバイスは、lsmpio コマンド照会をサポートしていません。 ただし、すべての AIX MPIO ストレージ・デバイスは Path operational status 照会をサポートします。

lsmpio コマンドは、以下のタイプの情報を表示します。
  • Path operational status
  • Additional NVMe extended status
  • Path statistics
  • Device inquiry data
  • Parent adapter information
Path operational status

lsmpio コマンドをフラグなしで、または -l フラグを指定して実行すると、パス操作状況を表示できます。

# lsmpio
name   path_id status  path_status     parent connection
===============================================================================
hdisk1234  0   Enabled Opt,Rsv         fscsi0 500a098186a7d4ca,0008000000000000
hdisk1234  1   Enabled Non             fscsi0 500a098196a7d4ca,0008000000000000
hdisk1234  2   Enabled Opt,Sel         fscsi1 500a098186a7d4ca,0008000000000000
hdisk1234  3   Enabled Non             fscsi1 500a098196a7d4ca,0008000000000000

出力は、次に示すような lspath コマンドの実行によって表示される出力に似ています。

lspath -F "path_id status parent connection"
status 列の有効な値は、 Enabled、 Disabled、 Failed、または Missingです。 拡張 path_status フィールドには、より詳細なパス状況を示す、3 文字の状況の省略語が 1 つ以上含まれている場合があります。
注: すべての拡張 path_status フィールドがすべての MPIO ストレージ・デバイスに適用できるわけではありません。 一部の path_status 値は、ストレージ域ネットワーク (SNA) ファブリックが SAN 輻輳に関する通知をサポートしている場合にのみ表示されます。
path_status フィールドに指定できる値は、以下のとおりです。
Opt
MPIO ディスク・パスが最適化パスであることを示します。 この値は、複数のコントローラーがあるデバイスの優先コントローラーに接続されている MPIO ディスク・パスを示します。 PCM は、可能な場合は常に、入出力操作に優先 MPIO ディスク・パスの 1 つを選択します。
Non
MPIO ディスク・パスが最適化されていないパスであることを示します。 優先 MPIO ディスク・パスを持つデバイスでは、このパスは優先パスと見なされません。 PCM は、すべての優先パスが失敗しない限り、このパスを入出力操作用に選択することを避けます。
Chg
ストレージ・ターゲット上で MPIO ディスクのアクセス特性が変更されていることを示します。 この状態は、パスが新しい状態に移行するまで一時的なものです。
Los
MPIO ディスク・パスがデータへのアクセスを永続的に失い、ホストで使用できなくなったことを示します。 ストレージ・ターゲットに問題がないかどうかを評価または診断する必要があります。
Sby
MPIO ディスク・パスがスタンバイ・パスであることを示します。 MPIO ディスク・パスが Sby 状態の場合、そのディスク・パスを入出力操作に使用することはできません。 ストレージ・デバイスでのデバイス依存操作により、MPIO ディスク・パスの状態を Opt または Non のいずれかの状態に変更できます。その後、MPIO ディスク・パスを入出力操作に使用できます。
NAv
MPIO ディスク・パスが使用不可であることを示します。 MPIO ディスク・パスが NAv 状態の場合、そのディスク・パスを入出力操作に使用することはできません。 ストレージ・デバイスでのデバイス依存操作により、MPIO ディスク・パスの状態を Opt または Non のいずれかの状態に変更できます。その後、MPIO ディスク・パスを入出力操作に使用できます。
Trn
MPIO ディスク・パスが 2 つの有効な状態間で切り替え中であることを示します。 MPIO ディスク・パスが Trn 状態の場合、そのディスク・パスを入出力操作に使用することはできません。 ディスク・パスの状態が Trn 状態から別の状態に自動的に変更されます。 MPIO ディスク・パスは、長期間 Trn 状態にすることはできません。 ただし、 AIX オペレーティング・システムは、パス状況の変更を即時に検出しない場合があります。
Act
アクティブ・コントローラーとパッシブ・コントローラーがあるデバイスで、MPIO ディスク・パスがアクティブ・パスであることを示します。 PCM は、このようなデバイスでは、入出力操作用にアクティブ MPIO ディスク・パスを選択します。
Pas
アクティブ・コントローラーとパッシブ・コントローラーがあるデバイスで、MPIO ディスク・パスがパッシブ・パスであることを示します。 PCM は、パッシブ・パスの選択を避けます。
Sel
lsmpio コマンドの実行時に、MPIO ディスク・パスが入出力操作用に選択されていることを示します。
Rsv
MPIO ディスク・パスで予期しない予約競合が発生したことを示します。 この値は、同じディスクにアクセスする複数のホストでの使用法エラーまたは構成エラーを示している可能性があります。
Fai
MPIO ディスク・パスで障害が発生したことを示します。 パスのパス状況値が Enabled であっても、拡張パス状況値が Faiである可能性があります。 このシナリオは、この MPIO ディスク・パスで送信された操作は失敗しているが、 AIX MPIO がパスに Failedのマークを付けなかったことを示しています。 AIX MPIO は、すべての MPIO ディスク・パスでエラーが発生している場合でも、デバイスへの 1 つのパスを Enabled 状態のままにすることがあります。
Deg
MPIO ディスク・パスが機能低下状態にあることを示します。 このシナリオは、MPIO ディスク・パスが入出力操作に使用されていたことを示しています。 それらの操作でエラーが発生したため、PCM がパスの使用を一時的に回避しています。 他のエラーが、MPIO ディスク・パスの障害の原因になっている可能性があります。
EEH
これは、MPIO ディスク・パスで使用されているファイバー・チャネル・アダプターで拡張エラー処理 (EEH) イベントが発生していることを示しています。 入出力操作に MPIO ディスク・パスを使用しているファイバー・チャネル・アダプターで EEH エラーが発生すると、EEH イベントによって PCM は一時的に MPIO ディスク・パスを回避します。 状況として EEH を持つ MPIO ディスク・パスは、EEH イベント発生中に MPIO ディスクパスで入出力操作がブロックされるため機能低下とみなされます。 パス選択アルゴリズムでは、EEH パス状況よりも Deg パス状況が優先され、RSV などの使用不可パス状況よりも EEH パス状況が優先されます。 ファイバー・チャネル・アダプターがオンラインに戻り、入出力操作を再開すると、パス状況が EEH から Degに変わり、MPIO ディスク・パスで入出力操作が再開されます。
Clo
MPIO ディスク・パスがクローズされていたことを示します。 デバイスに接続されているすべての MPIO ディスク・パスがクローズされている場合、そのデバイスはクローズされていると見なされます。 一部の MPIO ディスク・パスのみがクローズしている場合は、前回デバイスがオープンされたときに、それらのパスでエラーが発生した可能性があります。 AIX MPIO は、デバイス・パスが開くまで、クローズされたパスを定期的にリカバリーしようとします。
PFa
リモート・ポートに障害があることを示します。 PCM が、MPIO ディスク・パスによって使用されているリモート・ポートが SAN ファブリックの一部ではなくなったことを示すイベントを受け取ると、PCM はパスに障害のあるパスのマークを付けます。 リモート・ポートが SAN ファブリックに再結合すると、PCM は PFa 状態をクリアします。
PCn
MPIO ディスク・パスで使用されているリモート・ポートに対するネットワーク・トラフィック輻輳を SAN ファブリックが報告したことを示します。 ネットワーク・トラフィック輻輳のない他の MPIO ディスク・パスが MPIO デバイスで使用可能な場合、PCM はこの MPIO ディスク・パスを使用しません。 SAN ファブリックが最近のネットワーク・トラフィック輻輳イベントを報告していない場合、PCM は自動的に PCn 状態をクリアします。
PDg
リモート・ポートの機能低下を示します。 リモート・ポートへの MPIO ディスク・パスがアクティブのままであっても、機能低下したポートでは多数のエラーが発生している可能性があります。 このような機能低下したポートはデータを処理できません。 PCM はこのようなディスク・パスを避けます。 ポートの劣化状況をクリアするには、まずポートが属するスイッチ上の劣化ポートを無効にしてから、そのポートを有効にする必要があります。 パス上で PDg 状態が繰り返し発生する場合は、SAN ハードウェアの問題を識別するためにパスで使用されているポートとファイバーを調べてください。
LCn
AIX アダプターとの間で大量のデータが送受信されているため、 AIX アダプターに関連付けられているリンクが輻輳していることを示します。 リンク輻輳のない他の MPIO ディスク・パスが使用可能な場合、PCM はこのような MPIO ディスク・パスは避けます。 SAN ファブリックが最近のリンク輻輳イベントを報告していない場合、PCM は自動的に LCn 状態をクリアします。
Deferred
現在開いているディスクへの新しく追加されたパスを示します。 内部制限のため、MPIO ディスク・パスをオープンして即時に使用することができません。 ただし、ディスク・パスは、ディスクの再オープン時にオープンして使用することができます。

Path statistics

-S フラグにオプションの -d フラグを指定すると、 lsmpio コマンドは通常または詳細なパス統計情報を表示します。 オプションの -l フラグは、1 つの MPIO ストレージ・デバイスのみの統計を含むように表示を制限します。 統計には、入出力操作のために MPIO ディスク・パスが選択された回数、MPIO ディスク・パスで発生したエラーの数、および MPIO ディスク・パスで障害が発生した回数が含まれます。 詳細統計情報では、障害回数は障害タイプ別の回数に分類されています。

Device inquiry data

lsmpio コマンドの -q フラグを使用すると、 AIX MPIO は、接続されているデバイスに関する情報を取得して表示するために Small Computer System Interface (SCSI) コマンドを使用してデバイスを照会します。 照会される各デバイスは SCSI コマンドを使用してオープンおよび照会されるため、多数のデバイスに対してこの操作を実行すると時間がかかることがあります。

Parent adapter information

-a フラグにオプションの -r フラグを指定すると、 lsmpio コマンドは、 AIX MPIO ストレージ・デバイスによって使用されるファイバー・チャネル・アダプターに関する情報を表示します。 この情報には、ファイバー・チャネル・アダプターの worldwide name や MPIO ディスク・パスの現在の状態など、ローカル・アダプター ID に関する詳細が (取得可能な場合は) 含まれます。 -r フラグは、ファイバー・チャネル・アダプターによってアクセスされるリモート・ポートに関する情報を追加します。

-z フラグを使用して、すべての統計情報をゼロにリセットすることができます。

-l ディスク名 デバイスを指定します。 このフラグが含まれる場合、コマンドは単一のデバイス上で作動します。 このフラグを省略すると、コマンドはすべての AIX MPIO デバイス上で作動します。 このフラグは、要約パス状況の場合に単独で使用することも、 -q、 -S、または -z フラグと一緒に使用することもできます。
-o AIX ディスク・ドライバーが、指定されたマルチパス入出力 (MPIO) ディスクに関連付けられている MPIO すべてにアクセスしようと試みることを示します。 この試みには、MPIO ディスクが最後にクローズされたときに「障害」とマークされた MPIO パスへのアクセスが含まれます。 このフラグによって、MPIO パスに関する最新のステータスが返されます。
重要: 失敗した MPIO ディスク・パスにアクセスしようとすると、 lsmpio コマンドの応答時間が遅くなる可能性があります。 この応答時間は、いくつかの要因 (影響を受ける MPIO ディスクの数や、lsmpio コマンドの有効範囲など) に応じて、数秒から数分遅れます。
-q デバイス情報を照会します。 このコマンドは、標準の SCSI コマンドを使用して、デバイスの情報を照会します。 返される正確な情報は、デバイス・タイプによって異なります。
-r リモート・ポートの情報を表示します。 このフラグは、アダプターによってアクセスされるリモート・ポートに関する情報を表示するために、 -a フラグと一緒に使用されます。 返される情報は、アダプターで使用されているネットワーク・プロトコルによって異なる場合があります。
-S 1 つまたはすべてのデバイスの統計を表示します。 このフラグは、パスの使用およびパスのエラーに関する基本的なカウンターを表示します。 このフラグと一緒に -d フラグを使用すると、より詳細な統計情報が表示されます。
-z すべての統計をリセットします。 このフラグを使用すると、PCM がすべての統計カウンターをリセットしてゼロに戻します。
注: -z フラグを -a フラグと一緒に使用して、アダプター・エラー件数および fpin エラー件数をリセットすることができます。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限と特権の詳細については、セキュリティの 特権コマンドデータベースを参照してください。 このコマンドに関連する特権と権限のリストについては、'lssecattrコマンドまたは'getcmdattrサブコマンドを参照のこと。

例

  1. hdisk1234 デバイスに関する要約情報を表示するには、次のコマンドを入力します。
    lsmpio -l hdisk1234

    以下のいずれかの出力のような出力がシステムから表示されます。

    • name   path_id status  path_status      parent connection
===============================================================================
hdisk1234  0   Enabled Opt,Rsv          fscsi0 500a098186a7d4ca,0008000000000000
hdisk1234  1   Enabled Non              fscsi0 500a098196a7d4ca,0008000000000000
hdisk1234  2   Enabled Opt,Sel,EEH      fscsi1 500a098186a7d4ca,0008000000000000
hdisk1234  3   Enabled Non              fscsi1 500a098196a7d4ca,0008000000000000

      この例では、パス 0 は最適化されていますが、パスを使用不可にする予約済み (Rsv) としてマークされています。 この場合、使用不可の Rsv 状態より EEH 状態が優先されるため、入出力操作にはパス 2 が選択されます。 さらに、パス 0 は Rsv 状態のためにすでに回避されているため、Deg 状態にはならないと考えられます。 パス 2 によって使用されるアダプターが EEH エラーのためにリブートしているため、入出力要求が満たされない可能性があります。

hdisk1234  3   Enabled Non             fscsi1 500a098196a7d4ca,0008000000000000

hdisk1234  5   Enabled Non             fscsi2 500a098196b7d4ca,0008000000000000
