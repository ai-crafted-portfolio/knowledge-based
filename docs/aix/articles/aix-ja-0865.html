目的
マニュアル・ページのタイプセットを行います。

説明
mant
コマンドは、マニュアル・ページ・マクロ (
man
マクロ・パッケージ) を使用してマニュアル・ページをタイプセットします。
File
パラメーターには
mant
コマンドで処理するファイルを指定します。 ファイルはすべてのフラグの後に表示します。 ファイル名が指定されないと、
mant
コマンドはフラグのリストを出力します。
File
パラメーターに
-
(負符号) を指定すると、標準入力が読み取られます。
mant
コマンドには、
tbl
コマンド、
cw
コマンド、
eqn
コマンドによるプリプロセスを指定するフラグがあります。
troff
コマンドからのフラグは
troffFlags
パラメーターで指定できます。
入力にストリングのみで構成される
troff
コマンドのコメント行が含まれている場合
'\" x
(単一引用符、円記号、二重引用符、
x
)。ここで、
x
は、
c
、
e
、および
t
の 3 つの文字の任意の組み合わせで、二重引用符と t の間には 1 つの文字スペースがあります。
x
入力は、コマンド行オプションに関係なく、それぞれ
cw
コマンド、
eqn
コマンド、および
tbl
コマンドの適切な組み合わせによって処理されます。
“

troff

-o

mant

-

-o

mant
コマンドは
troff
コマンドとは異なり、
次のフラグ、環境変数、またはデフォルト設定に従って、
その出力を自動的に特定のポストプロセッサーにパイピングします (特にそうしないように要求されない限り)。
項目 | 説明
-Z | ポストプロセッサーを使用しないことを示します。
-T 名前 | Name 変数で指定されたプリンター用に出力を準備します。
タイプ・セット | システム環境に特定のプリンターを指定します。
デフォルト | ibm3816 に送信します。
次のリストにないフラグは、
troff

コマンドかマクロ・パッケージかのどちらか適切な方に渡されます。 すべてのフラグはファイル名の指定より前に表示しなければなりません。

構文
マント [ -M (M) メディア ] [ -a 値 ] [ 「-c」 ] [ -e (E) ] [ T ] [ -z ] [ -T (T) 名前 ] [ troffFlags ] [ ファイル ... | - ]

オプション
フラグ
すべてのフラグは、ファイル名より前に指定されていなければなりません。
項目 | 説明
-a | troff コマンドの -a フラグを呼び出します。
-c | cw コマンドで入力ファイルをプリプロセスします。
-e | eqn コマンドで入力ファイルをプリプロセスします。
-M メディア | 用紙上のイメージ可能領域の大きさを判別するために、用紙サイズを指定します。 Media 変数で有効な値は以下のとおりです。 A4 用紙サイズ 8.3 X 11.7 インチ (210 X 297 mm) を指定します。 A5 用紙サイズ 5.83 X 8.27 インチ (148 X 210 mm) を指定します。 B5 用紙サイズ 6.9 X 9.8 インチ (176 X 250 mm) を指定します。 EXEC 用紙サイズ 7.25 × 10.5 インチ (184.2 × 266.7 mm) を指定します。 LEGAL 用紙サイズ 8.5 X 14 インチ (215.9 X 355.6 mm) を指定します。 LETTER 用紙サイズ 8.5 X 11 インチ (215.9 X 279.4 mm) を指定します。 これはデフォルト値です。 “ 注: Media 変数では大文字小文字の区別はありません。 ”
-t | tbl コマンドで入力ファイルをプリプロセスします。
-Z | ポストプロセッサーを使わずに出力を準備します。
-T 名前 | 指定のプリンターへの出力を準備します。 使用可能な Name 変数は次のとおりです。 ibm3812 3812 Pageprinter II ibm3816 3816 Pageprinter hplj (hplj) Hewlett-Packard LaserJet II ibm5587G 5587-G01 漢字プリンター・マルチバイト言語サポート PSC PostScript。 X100 AIXwindows が表示されます。
- | 入力を標準入力から強制的に読み取ります。
