目的
デバイススタンザの名前を表示します。

説明
デフォルトでは、'
lsquedev
コマンドは、'
/etc/qconfig
ファイルからキュー・スタンザ の名前とそれに関連する属性を表示する。
プリンタ AIX サブシステムの拡張機能が無効化されている場合、この
lsquedev
コマンドはキュースタンザ名と関連
/etc/qconfig.bin
属性をファイルから表示します。 調整可能な
printer_scalability
パラメータの詳細については、
その他の調整可能なパラメータ
ページの該当
printer_scalability
セクションを参照してください。

構文
lsquedev [ -c ] -q Name -d Name

オプション
フラグ
表 1. フラグ
項目 | 説明
-c | システム管理インターフェイスツール（SMIT）で使用するために、コロン形式で出力を表示します。
-d Name | 表示されるデバイス・スタンザの Name 変数を指定します。
-q Name | 表示されるデバイススタンザを含むキューの Name 変数を指定します。

例
lp0
キューのデバイス・スタンザ '
dlp0
を表示するには、以下のコマンドを入力する：
lsquedev -q lp0 -d dlp0
以下のようなリストが表示される：
dlp0:
FILE = /dev/lp0
BACKEND = /usr/lib/lpd/piobe
lp0
キューのデバイス・スタンザ '
dlp0
をコロン形式で表示するには、 以下のコマンドを入力する：
lsquedev -c -q lp0 -d dlp0
以下のようなリストが表示される：
file:access:feed:header:trailer:backend:align
dlp0:/dev/lp0:read:never:never:never:/usr/lib/lpd/piobe:TRUE
