目的
システム上の BNU ファイル転送アクティビティーに関する情報を提供します。

説明
基本ネットワーク・ユーティリティー (BNU) の
uulog
コマンドは、
uucico
デーモンと
uuxqt
デーモンのアクティビティー内容が入っているログ・ファイルの内容を表示します。 各ログ・ファイルは、ローカル・システムが
uucp
コマンド、
uuto
コマンド、
uux
コマンドを使って各リモート・システムと通信するために作成されます。
uulog
コマンドは、ユーザーまたはシステムからの
uucp
、
uuto
、
uux
のコマンド要求の要約を表示するときに使用します。 これらのトランザクションはすべて、
/var/spool/uucp/.Log
ディレクトリーをログに記録します。 それらのファイルには
DaemonName
/
SystemName
という名前が付けられます。
ここで、
DaemonName
というディレクトリー名は関連するデーモンを表し、
SystemName
というファイル名はデーモンが接続するリモート・システムを表します。
UUCP
および
ウート
コマンドは、
ウシコ
デーモンを呼び出します。
ウシコ
デーモンのアクティビティーは、
/var/spool/uucp/.Log/uucico
ディレクトリー内の
SystemName
ファイルに記録されます。
uux
コマンドは
uuxqt
デーモンを呼び出します。
uuxqt
アクティビティーは、
/var/spool/uucp/.Log/uuxqt
ディレクトリーの
SystemName
ファイルに記録されます。
上記の各ログ・ファイルは、
uulog
コマンドを直接発行することにより検査できます。 しかし、ユーザーは BNU プログラムを使ってこれらの一時ログ・ファイルを 1 次ログ・ファイルに自動的に追加して検査することもできます。 これは
ログ・ファイルの圧縮
と呼ばれ、シェル・スクリプトである
uudemon.cleanu
コマンドによって処理されます。

構文
uulog [ -x ] [ - 番号 ] [ -f システム | -s システム ]

オプション
フラグ
項目 | 説明
-f システム | 指定された System 変数のファイル転送ログに -f フラグを指定して tail コマンドを発行し、ログ・ファイルの終わりを表示します。 ファイル表示を終ってプロンプト状態に戻るには、割り込みキーを押します。
-s システム | 指定されたシステムに関連するコピー ( uucico デーモン) 要求の要約を表示します。 制約事項: システム名には ASCII 文字以外は使用できません。 -f フラグと -s フラグは一緒に使用できません。
-x | 指定されたシステムの uuxqt デーモン・ログ・ファイルを表示します。
- 数値 | ファイルの最終行を表示します。 行数は Number 変数で指定します。 (これらの行を表示するために、 uulog コマンドは、指定された行数に対して -f フラグを指定した tail コマンドを発行します。)

例
システムの
uucico
ログ・ファイルを表示するには、以下のようにします。
hera
次のように入力します。
uulog
-s
hera
