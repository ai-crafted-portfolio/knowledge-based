目的
監査ログからのイベント・モニター情報をリストします。

説明
lsevent
コマンドは、監査ログからイベント・モニター情報をリストします。 監査ログには、モニターされたイベントおよび条件、ならびにその結果として実行された応答が含まれます。 この情報により、システム管理者はイベントの処理状況を見ることができます。
lsevent
コマンドは、RSCT イベント応答リソース・マネージャー (ERRM) によって記録された監査ログからの情報のみをリストします。
lsevent
を使用すると、
lsaudrec
コマンドを使用する場合と同様に、ERRM 監査ログ・テンプレートに関する詳細情報を知らなくても、監査ログ情報をリストすることができます。
デフォルトでは、オプションとオペランドを使用せずに、
lsevent
コマンドは監査ログに記録されたイベントをリストします。 これらのイベントは、発生したモニター・イベントを記述します。 特定の条件に対するイベントをリストするには、条件名を指定します。
応答情報は、単独でリストすることも、イベント情報と共にリストすることもできます。 応答は、条件またはイベントの発生に基づいて実行されます。 応答についての情報には、実行された時刻、応答スクリプトの内容、戻りコード、予期される戻りコード、標準エラー出力、および標準出力が含まれています。 標準出力および予期される戻りコードを表示するには、
mkresponse
または
chresponse
によってそれを記録するように応答リソースを定義する必要があります。 応答情報のみをリストするには、
-r
フラグを使用します。 リストされる応答の数を制限するために、オプションで 1 つ以上の応答名を指定することができます。
条件に関するイベント情報および応答情報をリストするには、
-R
フラグおよび
-A
フラグを条件名とともに使用できます。
-R
および
-A
を使用しない場合、条件が指定されると、その条件のイベントがリストされます。 条件に対する応答をリストするには、
-R
を指定します。 それらの応答に対する出力を制限するには、1 つ以上の応答名を指定できます。 イベントと応答をリストするには、
-A
を指定します。 1 つ以上の応答名を指定して、
-A
の応答出力を制限することもできます。
-R
、
-A
、または
-r
フラグを指定せずに条件と少なくとも 1 つの応答を指定すると、
-R
が想定されます。
リストされるイベントのタイプは、
-e

フラグを使用して制御できます。 ある条件に対し、イベント、リアーム・イベント、およびエラー・イベントをリストすることができます。
-w
フラグを使用して、特定のノードで発生したイベントをリストすることができます。
-w
フラグは、イベントのリストで使用される場合に意味を持ちます。
-i
フラグを指定すると、状況情報が表示されます。 条件をリストする際、状況情報には、条件が登録および登録解除されたとき、およびイベント・エラーが発生するときの表示が含まれます。 応答情報の場合、状況情報は、応答が実行されようとしていることを表示します。
コマンド出力を制限する時間を指定する必要がある場合は、
-B
および
-E
フラグを使用します。 デフォルトでは、
lsevent
は指定されたフラグに従ってすべての監査ログ項目をリストしますが、特定の期間に関心がある場合は、開始時刻または終了時刻を指定することができます。 時刻形式については、以下で説明します。
-O
フラグは、監査ログの検索を最新のレコードに制限するために使用されます。
-O
フラグで使用される値は、指定された他の
lsevent
基準で検索される最新レコードの数を決定します。 例えば、
lsevent -O 1000
を使用すると、
lsevent
は監査ログ内の最新の 1000 個のレコードでイベントを検索します。
-a
または
-n
が使用されている場合、
-O
は使用できません。
システムにクラスター・システム・マネージメント (CSM) がインストールされている場合は、CSM 定義のノード・グループをノード名の値として使用して、複数のノードを参照できます。 CSM ノード・グループの処理および CSM
nodegrp
コマンドの使用については、「
CSM: Administration Guide
」および「
CSM: Command and Technical Reference
」を参照してください。

例
発生したイベントについての情報をリストするには、次のように入力します。
lsevent
Condition1
という名前の条件のイベント情報をリストするには、次のように入力します。
lsevent Condition1
イベント応答情報をリストするには、次のように入力します。
lsevent -r
Response1
という名前の応答のイベント応答情報をリストするには、次のように入力します。
lsevent -r Response1
出力を保存するように定義されている
Response1
という名前のイベント応答の出力を表示するには、次のように入力します。
lsevent -r Response1
最新の 1000 個の監査ログ・レコードで見つかったイベントを表示するには、次のように入力します。
lsevent -O 1000
Condition1
という名前の条件のリアーム・イベント情報をリストするには、次のように入力します。
lsevent -e r Condition1
