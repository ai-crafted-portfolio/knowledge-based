目的

共通オペレーティング・システム・イメージ (COSI) を除去します。

構文

Rmcosi [「-f」] [-v (V)] コSI

説明

rmcosi コマンドは、 mkcosi コマンドで作成された共通オペレーティング・システム・イメージ (COSI) を除去します。 除去する共通イメージがシン・サーバーによって使用されている場合、強制フラグ (-f) が指定されていない限り、操作は失敗します。 -f フラグは、COSI を削除できるように、共通イメージを使用するシン・サーバー・セッションを終了します。 このコマンドは、システム上に存在する bos.sysmgt.nim.master ファイルセットに依存します。

フラグ

項目
説明
-f 共通イメージの除去を強制実行します。 共通イメージがシン・サーバーによって使用されている場合は、 シン・サーバーはオフラインにされ、その結果、共通イメージの除去が可能となります。
-v rmcosi コマンドの実行時に詳細デバッグ出力を有効にします。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

セキュリティー

アクセス制御: rmcosi コマンドを実行するには、root 権限が必要です。

例

  1. cosi1 という名前の共通イメージを除去するには、次のように入力します。
    rmcosi cosi1

場所

/usr/sbin/rmcosi

ファイル

項目
説明
/etc/niminfo NIM により使用される変数が入っています。
