目的
基本ネットワーク・ユーティリティー (BNU) のリモート・コマンド要求を実行します。

説明
基本ネットワーク・ユーティリティー (BNU)
uuxqt
デーモンは、
指定されたリモート・システム上のコマンドを実行します。
各ネットワーク・システム上の
uuxqt
デーモンは、定期的にスプール・ディレクトリーでリモート
execute
(
X.*
) を検索します。 ファイルのみ。 これらのファイルは、
uux
コマンドへの応答として、
uucico
デーモンによってディレクトリーに送られます。
X.*
が検出された場合 ファイルの場合、
uuxqt
デーモンは各ファイルを検査して、以下のことを確認します。
必要なすべての
データ
(
D. *
) ファイルが使用可能です。
要求側システムには、データ・ファイルにアクセスして要求されたコマンドを実行するために必要な許可があります。
“
注:
uuxqt
デーモンは、
/etc/uucp/Permissions
ファイルを使用して、ファイルのアクセス可能性およびコマンド実行許可を検証します。
”
データ・ファイルが存在し、要求システムに適切な許可が設置されていれば、
uuxqt
デーモンはこのコマンドを実行します。
“
注:
uuxqt
コマンドは通常、
uudemon.hour
コマンド、シェル・プロシージャーから実行され、コマンド行からは入力されません。
uuxqt
コマンドをコマンド・ラインから実行するには、root ユーザー権限がなければなりません。
”

構文
ユークト [ -e ] [ -s システム名 ] [ -x デバッグレベル ]

オプション
フラグ
項目 | 説明
-e | ファイルの拡張を可能にします。
-s システム名 | 接続するリモート・システムを指定します。 uuxqt コマンドを手作業で始動するときにだけ使用します。 uuxqt コマンドが自動的に始動されると、システム名は内部的に供給されます。 “ 注: システム名には ASCII 文字以外は使用できません。 ”
-x デバッグレベル | デバッグ情報をローカル・システムの画面に表示します。 DebugLevel 変数は、0 から 9 までの 1 桁の数字で、デフォルトは 5 です。 DebugLevel 変数が高いほど、デバッグ情報の詳細が示されます。

例
デバッグのために
uuxqt
デーモンを始動するには、以下のように入力します。
/usr/sbin/uucp/uuxqt
-s
venus
-x
7
これは、リモート・システムに接続するようにコマンドに指示します。
venus
連絡先に関するかなり詳細な情報を提供します。
