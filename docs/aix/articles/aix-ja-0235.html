目的
システムの現在のドメイン・ネームを変更します。

説明
chypdom
コマンドは、システムのドメイン・ネームを変更します。
DomainName
パラメーターは、システムの新しいドメイン・ネームを指定します。
このコマンドは、System Management Interface Tool (SMIT)
smit chypdom
高速パスを使用しても実行できます。

構文
/usr/sbin/chypdom [ i | -b | -n ]。 DomainName

オプション
フラグ
項目 | 説明
-I | ドメイン・ネームを /etc/rc.nfs ファイルで変更することを指定します。 このフラグによって、次にシステムを再始動したときにドメイン・ネームが変更されます。
-B | ドメイン・ネームをすぐに変更する必要があり、その変更内容を反映するように /etc/rc.nfs ファイルを更新することを指定します。
-N | ドメイン・ネームをすぐに変更することを指定します。 /etc/rc.nfs ファイルは変更されません。 システムのドメイン・ネームを変更するために domainname コマンドが実行されます。

例
/etc/rc.nfs
ファイルを変更して、ドメイン名を次のように設定します。
mydomain
次回のシステム再始動時に、次のように入力します。
chypdom -I mydomain
