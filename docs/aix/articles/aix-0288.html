目的

メッセージを作成します。

構文

競合 [ +フォルダー ] [ -draftfolder +フォルダー | -nodraftfolder フォルダー ] [  メッセージ |  -draftmessage メッセージ ] [ -ファイル ファイル ] [  -エディター 編集者 | -noedit (編集不可) ] [  -形式 FormFile ] [  -使用 | -マウス ] [ -nowhatnowproc (処理なし) |  -whatnowproc (whatnowproc) プログラム ]

説明

comp コマンドは、メッセージの作成と修正を行うためのエディターを始動します。 comp コマンドは、ヘッダー・テンプレート /etc/mh/components ファイルを提供します。 デフォルトでは、指定されたエディターは UserMhDirectory/draft ファイルを作成します。 draft ファイルが既に存在する場合、comp コマンドは既存のファイルの置き換えまたは使用を許可するかどうかについて、プロンプトを表示します。 許可についてのプロンプトを表示しないで既存の draft ファイルを編集するには、-use フラグを指定します。

エディターを始動すると、各メッセージ・ヘッダー・フィールドに値を入力するように促されます。 comp コマンドは、ヘッダー・フィールド用に、UserMhDirectory/components ファイル内の定義を使用します。 このファイルが存在しない場合、/etc/mh/components ファイルが使われます。 代わりのヘッダー・フォーマットを指定するために、-form または +Folder フラグを使うことができます。

エディターを終了するには Ctrl-D シーケンスを使います。 エディターを終了すると、 comp コマンドは次のように応答します。What now?できます。 このプロンプトから、 whatnow サブコマンドのいずれかを指定することができます。 サブコマンドのリストを参照するときは、Enter を押してください。 これらのサブコマンドを使って、引き続きメッセージを構成したり、 メッセージの配置を指示したり、または comp コマンドの処理を終了することができます。

“注: 送信時にメッセージを識別できるように、 メッセージのヘッダーと本文の間にダッシュだけの行またはブランク行を 1 行入れておく必要があります。”

既存のドラフト・メッセージを指定する場合、 -file、-draftfolder、 および -draftmessage フラグを使用します。 -draftfolder +Folder フラグの後に Message パラメーターを付けると、 -draftmessage フラグを指定したのと同じことになります。 必要に応じて、デフォルトを定義することができます。Draft-Folder:メッセージ・ハンドラー (MH) $HOME/.mh_profile ファイル内のエントリー。

フラグ

項目
説明
-draftfolder +フォルダー ドラフト・メッセージを含むフォルダーを識別します。 メッセージがこのフラグで指定されていない場合、デフォルト・メッセージは new になります。
-draftmessage メッセージ ドラフト・メッセージを識別します。 -draftfolder +Folder フラグの後に Message 変数を指定することは、 -draftmessage フラグを指定することと同じです。
-editor エディター メッセージを構成するための初期エディターを指定します。 -editor フラグを指定しない場合、 comp コマンドは、以下によって指定されたデフォルト・エディターを選択します。Editor:$HOME/.mh_profile ファイル内のエントリー。
-file ファイル 指定されたファイルにドラフト・メッセージを入れます。 File 変数の絶対パス名を指定しないと、comp コマンドはユーザーの MH ディレクトリーにファイルを入れます。 ファイルが指定されると、comp コマンドはドラフトを後処理するように促します。
+フォルダー・メッセージ 指定されたフォルダー内のファイルからヘッダー情報を使用します。 フォルダーを指定しておいてメッセージを指定しなかったときは、comp コマンドは現行メッセージをデフォルトとして使用します。
-フォーム FormFile FormFile 変数で指定されたヘッダー・フィールドを使用します。 comp コマンドは FormFile 内の各行をフォーマット文字列として扱います。
-help これは、コマンド構文、使用可能なスイッチ (トグル)、およびバージョン情報をリストします。

“注: MH の場合は、このフラグ名を省略することはできません。”
Message メッセージを指定します。 メッセージを指定するには、次の参照を使用します。
Number
メッセージ番号。
cur または 。 (ピリオド)
現行メッセージ。 これはデフォルトです。
first
フォルダー内の最初のメッセージ
last
フォルダー内の最後のメッセージ
次へ
現行メッセージの次のメッセージ
prev
現行メッセージの直前のメッセージ。
-ノドラフトフォルダー ドラフトを UserMhDirectory/draft ファイルに入れます。 これはデフォルトです。
-noedit (編集しない) 初期編集を抑制します。 このフラグを指定すると、以下を受け取ります。What now?できます。
-マウス 新しいメッセージを作成します。
-ナウハットナウプロック エディターおよびエディターとの対話を防止します。What now?できます。
-使用 既存のメッセージ・ドラフトの構成を続けます。
-whatnowproc プログラム 指定されたプログラムを始動し、構成タスクを簡易化します。 whatnow コマンドを Program 変数の値として指定すると、 comp コマンドは内部 whatnow プロシージャーを開始します。 whatnowというファイル名のプログラムの代わりに使用します。

セキュリティー

RBAC ユーザーへの注意: このコマンドは特権命令を実行できます。 特権命令を実行できるのは特権ユーザーのみです。 権限および特権について詳しくは、「セキュリティー」の『特権コマンド・データベース』を参照してください。 このコマンドに関連した特権および権限のリストについては、lssecattr コマンドまたは getcmdattr サブコマンドの項を参照してください。

プロファイル・エントリー

以下のエントリーが UserMhDirectory/.mh_profile ファイルに入力されます。

項目
説明
Draft-Folder: ドラフトを入れるデフォルトのフォルダーを設定します。
Editor: デフォルトの初期エディターを設定します。
fileproc: メッセージをリファイルするプログラムを指定します。
Msg-Protect: 新しいメッセージ・ファイル用の保護レベルを設定します。
Path: ユーザーの MH ディレクトリーを指定します。
whatnowproc: プロンプトを出すために使用するプログラムを指定します。What now? という質問プロンプトを表示するときに使用するプログラムを指定します。

例

  1. 新しいメッセージを構成するには、以下のように入力します。
    comp
    システムは、メッセージ・フィールドに情報を入力するように促します。 フィールド入力を省略するには Enter キーを押します。 ヘッダー情報を入力してから、メッセージ本文のテキストを入力します。

    メッセージの構成が終わり、エディターを終了するには、Ctrl-D シーケンスを押します。 画面に次のプロンプトが表示されます。

    What now?
    Enter キーを押すと whatnow サブコマンドのリストが表示されます。 メッセージを送信する場合は、以下の後に send サブコマンドを入力します。What now?できます。
  2. 新規メッセージを作成するには、vi次のように入力します。
    comp  -editor vi
  3. メッセージを使用してメッセージを作成するには8合計のschedules次のように入力します。
    comp  +schedules 8  -use
  4. メッセージの下書きを使用してメッセージを作成するには、以下のようにします。/home/mike/partsファイル、入力:
    comp  -file /home/mike/parts
    システムはファイルを後処理するようにプロンプトを表示します。 オプションをリストするには、Enter キーを押します。 適切なオプションを選択してください。

項目
説明
UserMhDirectory/コンポーネント ユーザーのデフォルト・メッセージ形式を指定します。 (そのフォーマットが既に存在するときは、システムのデフォルト・メッセージ形式が無効になります。)
UserMhDirectory/ドラフト 現行のドラフト・メッセージが入っています。
$HOME/.mh_profile ユーザーの MH プロファイルを指定します。
/etc/mh/components システムのデフォルト・メッセージ形式を識別します。
/usr/bin/comp comp コマンドが入っています。
