目的
指定したリソース・クラス内でリソースをリフレッシュします。

説明
refrsrc
コマンドは、指定されたリソース・クラス内のリソースをリフレッシュします。 このコマンドは、オペレーティング・システム・コマンド (例えば、
mkfs
) によって構成が変更される可能性がある場合に、Resource Monitoring and Control (RMC) サブシステムがリソースの新規インスタンスを検出するように強制するために使用します。
このコマンドを使用して、RMC サブシステムにリソース・クラス内のリソースの構成を要求します。 要求は、
実際にはリンクされたリソース・マネージャーが実行します。
指定したリソース・クラス内でリソースをモニターするアプリケーションはどれでも、
構成が更新されたとのイベントを受け取ります。

構文
refrsrc [ -h ][ -TV リソースクラス

オプション
フラグ
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。
-T
コマンドのトレース・メッセージを標準エラーに書き込みます。 ソフトウェア・サービスの編成の使用の場合のみです。
-V
コマンドの詳細メッセージを標準出力に書き込みます。

例
IBM
.FileSystem クラスのリソースの構成を更新するには、次のように入力します：
refrsrc IBM.FileSystem
