目的
仮想共有ディスクを使用可能にします。

説明
preparevsd
コマンドは、指定した仮想共有ディスクを停止状態から
延期状態にします。 仮想共有ディスクは使用可能となります。 オープン要求、クローズ要求は
受け入れられますが、読み取りおよび書き込み要求は仮想共有ディスクが活動状態になるまで
保留されます。 読み取りおよび書き込み要求が延期状態である場合は、このコマンドは
その要求を延期状態のままにしておきます。
このコマンドは、System Management Interface Tool (SMIT) を使用して実行できます。 SMIT を使用するには、以下のように入力します。
smit vsd_mgmt
さらに、
Prepare a Virtual Shared Disk
オプションを選択します。
通常の環境では、このコマンドを発行してはなりません。 リカバリー可能仮想共有ディスク・サブシステムは
このコマンドを使用して、制御された方法により共有ディスクを管理します。 このコマンドを発行すると、結果は予測不能になります。

構文
preparevsd {-a | vsd_name…}

オプション
フラグ
-a
停止状態にあるすべての仮想共有ディスクが使用可能となるように指定します。

例
仮想共有ディスク
vsd1vg1n1
を、停止状態から延期状態に
するには、次のように入力します。
preparevsd vsd1vg1n1
