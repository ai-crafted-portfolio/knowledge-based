目的

ネットワーク情報サービス (国家情報院) サーバーで 国家情報院 マップをセットアップします。

構文

NIS マスター・サーバーで NIS をセットアップするには

/usr/sbin/ypinit [ -o ] [ -n ] [ -q ] -m [ WorkerName ... ]

NIS ワーカー・サーバーで NIS をセットアップするには

/usr/sbin/ypinit -s MasterName

説明

初期化 コマンドは、 ネットワーク情報サービス (国家情報院) マスター・サーバーまたは 国家情報院 ワーカー・サーバー上に 国家情報院 マップをセットアップします。 ypinit コマンドを使うことができるのは root ユーザー権限を持つユーザーのみです。

デフォルトでは ypinit コマンドは、作成されるマップの入力ファイルとして ASCII システム・ファイルを使います。

フラグ

表 1. フラグ
項目
説明
- M [ WorkerName...］ ローカル・ホストが 国家情報院 マスターになることを示します。 -Q (Q) フラグを使用する場合は、 -m (M) フラグの後に、 国家情報院 ワーカー・サーバーになるマシンの名前を指定できます。
-n ypinit コマンドが、エラーを見つけても中断されないことを示します。
-o 現行 国家情報院 ドメインの既存のマップを上書きできるようにします。
-q ypinit コマンドが、入力プロンプトの代わりにコマンド・ラインから引数を取得することを示します。
-s MasterName MasterName パラメーターで指定したサーバー・ワークステーションから NIS マップをコピーします。

例

  1. すべての 国家情報院 マップのマスターとして機能する 国家情報院 マスター・サーバーをセットアップするには、コマンド行に以下のコマンドを入力します。
    ypinit -m
    このコマンドは、/var/yp/Makefile ファイル内の命令に従う make プロシージャーを呼び出します。
  2. 国家情報院 ワーカー・サーバーをセットアップするには、次のように入力します。
    ypinit -s zorro
    この例では、 初期化 コマンドは、以下の名前の 国家情報院 サーバーからワークステーションに 国家情報院 マップをコピーします。zorroワークステーションを 国家情報院 ワーカー・サーバーにします。
  3. 入力を求めるプロンプトを出さずに 国家情報院 マスター・サーバーをセットアップするには、次のように入力します。
    ypinit -o -n -q -m worker
    注: システムが以前に NIS マスター・サーバーとして構成されていた場合は、 ypinitを実行する前に、ディレクトリー /var/yp/bindingが除去されていることを確認してください。 古い情報が /var/yp/bindingに保管されていると、 NIS マスター・サーバーの構成中にエラーが発生する可能性があります。

ファイル

表 2. ファイル
項目
説明
/etc/bootparams ディスクレス・クライアントがブートに使用できるクライアントをリストします。
/etc/passwd コンピューターにログインするための許可を持つ各ユーザー用のエントリーが入っています。
/etc/group コンピューターにログインすることが認められている各ユーザー・グループ用のエントリーが入っています。
/etc/hosts ネットワーク上の各ホストのエントリーが入っています。
/var/yp/Makefile 国家情報院 マップを作成するための規則が含まれています。
/etc/networks DARPA インターネット内の各ネットワークの名前が入っています。
/etc/netmasks IP 標準サブネットのインプリメントに使用するネットワーク・マスクをリストします。
/etc/netid コンピューター、ホスト、およびグループの識別情報が入っています。
/etc/rpc RPC プログラム用のマップ情報が入っています。
/etc/services インターネットを通して使用可能な各サーバー用のエントリーが入っています。
/etc/protocols ローカル・ホスト上で使われるインターネット・プロトコルを定義します。
/etc/netgroup ネットワーク上の各ユーザー・グループに関する情報が入っています。
/etc/ethers インターネット・ネットワーク上のホストのイーサネット・アドレスが入っています。
/etc/publickey 国家情報院 マップの公開鍵または秘密鍵が含まれます。
