目的
システム管理者を補助して、セキュリティー構成を設定します。

説明
aixpert
コマンドは、さまざまなシステム構成設定を設定して、必要なセキュリティー・レベルを使用可能にします。
-l
フラグ・セットのみを指定して
aixpert
を実行すると、ユーザーが設定を構成することなく、セキュリティー設定が迅速に実装されます。 例えば、
aixpert -l high
を実行すると、すべての高水準セキュリティー設定が自動的にシステムに適用されます。 ただし、
-n -o
filename
オプションを指定して
aixpert -l
を実行すると、
filename
パラメーターによって指定されたファイルにセキュリティー設定が保存されます。 その後、
-f
フラグは新しい構成を適用します。
最初に選択した後で、その選択済みセキュリティー・レベルに関連したすべてのセキュリティー構成オプションを示すメニューが表示されます。 これらのオプションは、全体または個別に (オフまたはオンを切り替えて) 受け入れることができます。 2 次的な変更を行った後も、
aixpert
は引き続きセキュリティー設定をコンピューター・システムに適用します。
注:
ソフトウェアのインストールや更新など、主要なシステムの変更後には、
aixpert
を再実行することをお勧めします。
aixpert
の再実行時に特定のセキュリティー構成項目が選択解除されると、その構成項目はスキップされます。
aixpert
コマンドの一部のプロファイルには、動的 IP セキュリティー (IPSec) フィルター・ルールを作成して、指定された期間存在する、shun ポート・ルールがあります。 これらの IPSec フィルター・ルールは、ソース・ホストの特定ポートから到着するすべてのパケットを拒否します。 フラグメント化されたパケットが宛先ホストに到着すると、ソース・ポートおよび宛先ポートにかかわりなく、ソース IP、宛先 IP、およびプロトコルに基づいて、拒否フィルター・ルールがフラグメントに適用されます。
これは、IP フラグメントにはポート詳細が含まれていないためです。 したがって、これらの拒否ルールは、指定されたソースからの指定されたプロトコルについて、すべてのソース・ポートから宛先で受信されたすべてのフラグメントをすべてのポートでドロップします。
指定されたソースからの IP フラグメントが宛先で許可される必要がある場合は、
aixpert
ルールの適用後、適切な
genfilt
ルールがそのソース用に追加されなければなりません。
genfilt

ルールが有効になるように、この新規ルールを
aixpert
ルールの上に追加する必要があります。 そのようなルールを追加すると、ソースからの IP フラグメント攻撃に対して宛先が脆弱になるおそれがあります。 そのため、そのようなルールの追加には注意が必要です。 IPSec フィルターを使用したフラグメントの処理について詳しくは、
genfilt
のマニュアル・ページを参照してください。

構文
aixpert -l h | high | m | medium | l | low | d | default | s | sox-cobit [ -n -o ファイル名 ] [ -a -o ファイル名 ] [ -p ] aixpert -c [ -P ] プロファイル名 [ -r ] [ -R ] aixpert -u [ -p ] aixpert -d aixpert [ -f ファイル名］ [ -a -o ファイル名］ [ -p ] aixpert -t aixpert -c -P プロファイル名

オプション
フラグ
項目 | 説明
-a | 関連付けられたレベル・セキュリティー・オプションを持つ設定は、 -o フラグで指定されたファイルに簡略ファイル形式で書き込まれます。 -a オプションを指定する場合は、 -o オプションも指定する必要があります。
-c | 前に適用された規則のセットに照らし合わせてセキュリティー設定を検査します。 規則についての検査が失敗した場合は、その規則の前のバージョンも検査されます。 このプロセスは検査がパスするまで、または /etc/security/aixpert/core/appliedaixpert.xml ファイル内にある失敗した規則のすべてのインスタンスが検査されるまで継続されます。
-f | 提供された filename 内のセキュリティー設定を適用します。 例えば、次のコマンドは、 すべての高水準セキュリティー・オプションを /etc/security/aixpert/core/hls.xml ファイルに書き込みます。 aixpert -l h -n -o /etc/security/aixpert/core/hls.xml 不要なオプションを除去した後で、次のコマンドを使用すると、これらのセキュリティー設定を適用することができます。 aixpert -f /etc/security/aixpert/core/hls.xml -f オプションを指定すると、 appliedaixpert.xml ファイルをシステムからシステムへ安全に転送し適用することによって、 セキュリティー設定を整合性のとれた状態でシステムからシステムへ適用できるようになります。 正常に適用されたルールはすべて /etc/security/aixpert/core/appliedaixpert.xml ファイルに書き込まれ、 対応する「元に戻す」アクションのルールは /etc/security/aixpert/core/undo.xml ファイルに書き込まれます。

-l | システムのセキュリティー設定を、このオプションで指定するレベルに設定します。 このフラグには次のオプションがあります。 h|high 高水準のセキュリティー・オプションを指定します。 m|medium 中間レベルのセキュリティー・オプションを指定します。 l|low 低水準のセキュリティー・オプションを指定します。 d|default AIX 標準レベルのセキュリティー・オプションを指定します。 s|sox-cobit SOX-COBIT 最良事例レベルのセキュリティー・オプションを指定します。 -l フラグと -n フラグの両方を指定すると、 セキュリティー設定はシステムに実装されず、 -o フラグで指定したファイルに書き込まれるのみとなります。 正常に適用されたルールはすべて /etc/security/aixpert/core/appliedaixpert.xml ファイルに書き込まれ、 対応する「元に戻す」アクションのルールは /etc/security/aixpert/core/undo.xml ファイルに書き込まれます。 注意: D | デフォルト オプションを使用すると、このオプションは、 アイクスペルト コマンドを使用して以前に設定した、または独立して設定した、構成済みのセキュリティー設定を上書きし、システムを従来のオープン構成に復元することができます。
-n | 関連付けられたレベル・セキュリティー・オプションを持つ設定は、 -o フラグで指定されたファイルに書き込まれます。 -n オプションを使用する場合は、 -o オプションも指定する必要があります。
-o | セキュリティー出力を filename が指し示すファイルに保管します。 この出力ファイルには、セキュリティー上の予防措置として root に設定された、読み取りおよび書き込みアクセス権があります。 このファイルは、望ましくないアクセスに対して保護されていなければなりません。
-p | 詳細出力を使用して、セキュリティー・ルールの出力結果が表示されるように指定します。 監査の設定 オプションがオンの場合に -p オプションを使用すると、 処理済みのルールが、監査サブシステムのログに記録されます。 このオプションは、 -l 、 -u 、 -c 、 および -f のいずれのオプションとも一緒に使用できます。

-P | プロファイル名を入力として受け入れます。 このオプションは、 -c オプションと一緒に使用されます。 -c オプションを -P オプションと一緒に使用すると、パス済みのプロファイルとのシステムの互換性を検査することができます。
-r | システムの既存の設定を報告します。 出力は、セキュリティーまたはコンプライアンスの監査レポートで使用するためのものです。 レポートは、各設定、設定が規制のコンプライアンス要件とどのように関係しているか、およびチェックが合格したか失敗したかを記述します。
-R | -r フラグと同じ出力を生成しますが、構成設定を実装するために使用された各スクリプトまたは各プログラムに関する記述も付加します。
-t | システムで適用されるプロファイルのタイプを表示します。
-u | 適用済みのセキュリティー設定を元に戻します。
-d | 文書型定義 (DTD) を表示します。

例
高水準のセキュリティー・オプションをすべて出力ファイルに書き込むには、次のコマンドを使用します。
aixpert -l high -n -o /etc/security/aixpert/plugin/myPreferredSettings.xml
このコマンドを完了すると、出力ファイルを編集したり、特定のセキュリティー・ロールを標準 xml コメント・ストリングで囲んでコメント化したりすることができます (
<--
はコメントを開始し、
-\>
はコメントを閉じます)。
構成ファイルからセキュリティー設定を適用するには、次のコマンドを使用します。
aixpert -f /etc/security/aixpert/plugin/myPreferredSettings.xml
システムに適用済みのセキュリティー設定を検査したり、
失敗したルールを監査サブシステムのログに記録したりするには、次のコマンドを使用します。
aixpert –c -p
