目的
初期化
コマンドを実行し、
国家情報院
デーモンを始動してコントローラー・サーバーを構成します。

説明
システムのドメイン・ネームが現在設定されている場合、
mkmaster
コマンドは
初期化
コマンドを呼び出して、現行ドメインの
国家情報院
マップを作成します。
ypinit
コマンドが正常終了した後、
mkmaster
コマンドは、
ypserv
コマンド、
yppasswdd
コマンド、
ypupdated
コマンド、
ypbind
コマンドに対して
/etc/rc.nfs
ファイル内の各エントリーからコメント文字を除去します。
このコマンドは、System Management Interface Tool (SMIT)
smit mkmaster
高速パスを使用して実行することができます。

構文
/usr/sbin/mkmaster [ -s HostName [ , HostName ... ] ]。[ -O | -o ] [ -E | -e ] [ -P | -p ] [ -U | -u ] [ -C | -c ] [ -I | -B | -N ]

オプション
フラグ
項目 | 説明
- s HostName [ , ホスト名 ... ] | これは、このコントローラー・サーバーに対するワーカー・ホスト名を指定します。 このようなワーカー・ホストは、コントローラー・サーバーの構成後に構成されなければなりません。 mkmaster コマンドは、このリストに現行ホストを自動的に追加します。
-O | このドメイン用の既存のマップを上書きします。
-o | このドメインに対する既存マップを上書きしないようにします。 このフラグはデフォルトです。
-E | 新しいマップの作成中にエラーが発生した場合、以降のアクションを行わないようにします。 このフラグは、 ypinit コマンドと mkmaster コマンドの両方に対して真です。 このフラグはデフォルトです。
-e | エラーが発生する場合、 ypinit コマンドおよび mkmaster コマンドを終了しません。
-P | ypserv デーモンと共に yppasswdd デーモンを始動します。
-p | yppasswdd デーモンの始動を抑制します。 このフラグはデフォルトです。
-U | ypserv デーモンと共に ypupdated デーモンを始動します。
-u | ypupdated デーモンの始動を抑制します。 このフラグはデフォルトです。
-C | ypserv デーモンと共に ypbind デーモンを始動します。 このフラグはデフォルトです。
-c | ypbind デーモンの始動を抑制します。
-I | 次のシステム再始動で適切なデーモンを始動するために /etc/rc.nfs ファイルを変更するように、 mkmaster コマンドに指示します。 このコマンドを呼び出すと、 ypinit コマンドが実行されます。
-B | ypinit コマンドを実行し、 /etc/rc.nfs ファイルのエントリーからコメント文字を除去し、デーモンを始動します。 このフラグはシステム・デフォルトです。
-N | ypinit コマンドを実行し、 /etc/rc.nfs ファイルを変更せずに適切なデーモンを始動します。

例
初期化
コマンドを実行するには、現行ドメインの既存のマップを上書きし、
host1
および
host3
ワーカー・サーバーの場合:
mkmaster -s host1,host3 -O -p -u -B
このコマンドは
yppasswdd
デーモンまたは
ypupdated
デーモンを始動しません。
