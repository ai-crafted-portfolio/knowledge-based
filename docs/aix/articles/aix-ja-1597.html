目的
Trusted Platform Module (TPM) のバージョンと製造元に関する情報を報告します。

説明
tpm_version
コマンドは、システム TPM のバージョンと製造元情報を報告します。 報告される情報は、製造元に固有です。

構文
tpm_version [ -h ] [ - [ なし | エラー | 情報 | デバッグ ] ] [ -v (V) ]

オプション
フラグ
項目 | 説明
-h (または -- help ) | コマンド使用方法の情報を表示します。
-l (または --log ) [ none | error | info | debug ] | ロギング・レベルを指定のとおり none、error、info、または debug に設定します。
-v (または -- version ) | コマンドのバージョン情報を表示します。
