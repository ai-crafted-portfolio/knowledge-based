目的

ディスケットへのコピーと、ディスケットからのコピーを行います。

構文

flcopy [ -f デバイス ] [ -h | -r ] [ -t Number ]

説明

flcopy コマンドは、ディスケット ( /dev/rfd0としてオープン) を現行ディレクトリーに作成された floppy という名前のファイルにコピーしてから、次のメッセージを印刷します。Change floppy, hit return when done次に、 flcopy コマンドは floppy ファイルをディスケットにコピーします。 フラグ -f、-h、-r、-tNumber を使用して、flcopy コマンドの動作を変更できます。

注: flcopy コマンドを使用して、あるディスケットから別のサイズのディスケットにデータをコピーすることはできません。

フラグ

項目
説明
-f デバイス /dev/rfd0 以外のドライブが指定できます。
-h flcopy コマンドに現行ディレクトリー内の floppy ファイルをオープンさせ、/dev/rfd0 にコピーさせます。
-r ディスケットを現行ディレクトリー内の flcopy ファイルにコピーした後で終了するよう floppy コマンドに命令します。
-t 数値 Number で指定した数のトラックをコピーします。 常にディスケットの最初のトラックからコピーされます。

終了状況

このコマンドは、以下の終了値を戻します。

項目
説明
0 正常終了。
>0 エラーが発生しました。

例

  1. /dev/rfd1 を現行ディレクトリーの floppy ファイルにコピーするには、次のように入力します。
    flcopy -f/dev/rfd1 -r
  2. ディスケットの最初の 100 トラックをコピーするには、次のように入力します。
    flcopy -f/dev/rfd1 -t100

ファイル

項目
説明
/usr/sbin/flcopy flcopy コマンドが入っています。
