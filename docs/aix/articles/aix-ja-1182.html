目的
troff
中間形式を PostScript 形式に変換します。

説明
psc
コマンドおよび
psdit
コマンドは、デバイスに依存しない
troff
によって作成されたファイルを、 PostScript プリンターで印刷するために PostScript 形式に変換します。 ファイルを指定しないと、標準入力が使用されます。 PostScript ファイルが標準出力に送信されます。
注:
psc
および
psdit
コマンドの入力は、対応する
-Tpsc
オプション (
troff
または
pic
コマンドなど) を使用して準備する必要があります。
psc
コマンドおよび
psdit
コマンドは、フォント・ファイル (
/usr/lib/font/devpsc/R
) 内のプリンター・コード・フィールドを変更することによって作成された外字を処理できます。 変更されたフィールドには、二重引用符で囲まれたストリングが含まれています。 このストリングには、
\b
(円記号 (¥) b) と、それに続いて、重ね打ちによって新規文字に構成される標準フォントからの文字のシーケンスが含まれます。
psc
コマンドおよび
psdit
コマンドを使用すると、
troff
コマンドで、生成された PostScript ファイルに任意の PostScript コードを組み込むことができます。
psc
および
psdit
コマンドは、
troff
中間ファイル・フォーマットの未定義の
%
(パーセント) コマンドを認識して、未加工の PostScript コードの開始を出力ファイル内にそのまま配置するようにシグナル通知します。 生成される PostScript 出力には、
%
(パーセント記号) と
.
(ピリオド) を含む行との間のすべてのもの (ただし、それを含まない) が配置されます。
この PostScript 出力は、
troff
コマンド調整システムからも、生成された PostScript 出力の状態からも隔離されません。 ただし、希望するならユーザーが分離できるように、2 つの機能がプロローグで定義されます。
PB
(ピクチャー開始) 関数は、 PostScript 保管操作を実行し、 PostScript 座標系をページ上の現在位置に関する
troff
の概念に変換し、座標系軸のスケールと方向を標準の PostScript 72 単位/インチに変更します。
PE
(ピクチャー終了) マクロは、この保護された環境を終了させます。
このような組み込み PostScript コードを
troff

中間ファイルに取り込むには、いくつかの方法を使用できます。 例えば、
troff
コマンドの
.sy
、
\!
、および
.cf
サブコマンドは、以下の例を使用して、別個の印刷可能な文書の PostScript 言語記述を組み込みます。 この例では、次に示すように、
showpage
演算子を再定義して、
mypic.ps
を組み込んでいます。
standard troff input
\&
.fl
\!%PB
\!/showpage{}def
.fl
.sy cat mypic.ps
\!PE
\!.
more standard troff input
psdit
コマンドと
enscript
コマンドに対する各種メディア・サイズを含む情報は、ファイル
/usr/lib/ps/MediaSizes
に入っています。
MediaSizes
ファイル内の各エントリーに必要な情報は、 PostScript プリンター記述 (
PPD
) ファイルから入手できます。このファイルは、 TranScriptで使用される PostScript プリンターに一致します。
PPD
ファイルは、Adobe Systems Incorporated から入手できます。
PPD
ファイルから抽出された測定値は、ポイント単位です。 プリンターのポイントは、1 インチの
1/72
です。
ASCII
*
(アスタリスク) で始まる
MediaSizes
ファイル内の行は、コマンド行で指定されたメディア・サイズ名を
enscript
コマンドおよび
psdit
コマンドと突き合わせる際に無視されます。
MediaSizes
ファイルの各エントリーには、8 つか 9 つのフィールドが含まれます。 すべてのエントリーについて、最初の 8 フィールドは必要です。 9 番目のフィールドはオプションです。 フィールドはホワイト・スペースで区切られます。 各エントリーのフィールドは、次のとおりです。
フィールド名 | 説明
EntryName | enscript コマンドまたは psdit コマンドの -M オプションで指定されたメディア名と突き合わせるための文字ストリング。
MediaWidth | ポイント単位のメディアの幅。
MediaDepth | ポイント単位のメディアの深さ。
ImageableLLX | ポイント単位のイメージ可能な下部 left-hand コーナー x 座標。

ImageableLLY | ポイント単位のイメージ可能な lower left-hand コーナー Y 座標。
ImageableURX | ポイント単位のイメージ可能な upper right-hand コーナー x 座標。
ImageableURY | ポイント単位のイメージ可能な upper right-hand コーナー Y 座標。
PageRegionName | 特定のプリンターがイメージ可能域のサイズを識別するための PostScript シーケンス。
PaperTrayName | 特定のプリンターが特定の用紙またはメディア・トレイを選択するための PostScript シーケンス。 このフィールドはオプションです。
注:
シーケンスは、
PageRegionName
フィールドと
PaperTrayName
フィールドの両方で、複数の PostScript 演算子または単語にすることができます。 このようなシーケンスを指定するには、ASCII " (二重引用符) を使用してシーケンス全体を区切ります。
以下に示すのは、
MediaSizes
ファイルのフィールド・エントリーの例です。

構文
{ psc | psdit } [ -f1 CodeSet:Font ] [ -FFontDirectory ] [ -MMediaName ] [ -pPrologue ] [ -oList ] [ File ]

オプション
フラグ
-f1
コードセット
:
フォント
表 2. フラグ
項目 | 説明
-F FontDirectory | デフォルトの代わりに FontDirectory からフォント情報を取ります。
-M MediaName | 紙のイメージ可能区域の量を決定するのに使用されるメディア名を指定します。 提供される名前は、 MediaSizes ファイルのエントリーと一致します。 例えば、 -M legal はイメージ可能区域としてリーガル・サイズの紙を要求します。 このオプションを使用しない場合、デフォルトのサイズはレターサイズで、幅 8.5 インチで深さ 11.0 インチになります。
-p プロローグ | デフォルトの PostScript プロローグの代わりに Prologue の内容を使用します。
-o List | 番号がコンマで区切られたリストに指定されているページを印刷します。 そのリストは、フォーマット N1 - N2 で単一番号と範囲を含み、ここで N1 と N2 はページ番号を表します。 N1 が欠落している場合は、範囲が最も小さい番号のページから始まることを意味します。 N2 が欠落している場合は、範囲が最も大きい番号のページで終わることを意味します。

例
次の例は等価です。
pic -Tpsc File | troff -Tpsc | psc
pic -Tpsc File | troff -Tpsc | psdit
