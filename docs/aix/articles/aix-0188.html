目的

Common Operating System Image (COSI) を管理します。

構文

ソフトウェアのインストール:

チコシ I -s ソース [「-f」ファイルセット | -b インストール・バンドル | -F (R) 修正 | -B フィックス・バンドル] [「-c」] [-R] [-v (V)] コSI

ソフトウェアの更新:

チコシ -ウー -s ソース [「-f」ファイルセット | -b インストール・バンドル | -F (R) 修正 | -B フィックス・バンドル] [「-c」] [-R] [-v (V)] コSI

ソフトウェアのリジェクト:

チコシ -j (J) [「-f」ファイルセット | -b インストール・バンドル | -F (R) 修正 | -B フィックス・バンドル] [-R] [-v (V)] コSI

ソフトウェアの除去:

チコシ - {「-f」ファイルセット | -b インストール・バンドル | -F (R) 修正 | -B フィックス・バンドル} [-R] [-v (V)] コSI

ソフトウェアの除去:

チコシ -ウー [「-f」ファイルセット | -b インストール・バンドル | -F (R) 修正 | -B フィックス・バンドル] [-R] [-v (V)] コSI

説明

chcosi コマンドは、 mkcosi コマンドから作成された共通オペレーティング・システム・イメージ (COSI) を管理します。 管理タスクには、共通イメージ上のソフトウェアのインストール、更新、リジェクト、除去、およびコミットが含まれます。

共通イメージ上のソフトウェアのインストールおよび更新の場合、必須の Source パラメーターは、コマンドがインストール可能イメージを入手する場所を指定します。 特定のインストール可能イメージは、 -f、 -b、 -F、 -B フラグおよびパラメーターから取られます。 インストール、更新、リジェクト、およびコミットの操作では、 -f、 -b、 -F、 -B の各フラグおよびパラメーターが指定されていない場合、操作はすべて想定値を使用します。 したがって、操作がインストールまたは更新の場合、ソースからのすべてのイメージがその操作で使用されます。 操作がリジェクトまたはコミットの場合、すべてのソフトウェアがコミットされるか、または共通イメージからリジェクトされます。 -c フラグがインストール操作または更新操作で指定されている場合、ソフトウェアは適用される代わりにコミットされます。 管理対象の共通イメージがシン・サーバーによって使用中の場合、クローンが共通イメージから作成され、管理操作はクローン・イメージ上で実行されます。 複製の命名規則は、元の共通イメージ名に接尾部 _X{count}を付けたものです。ここで、 count は、共通イメージが複製されるたびに増分される数値です。

chcosi コマンドは、システム上に存在する bos.sysmgt.nim.master ファイルセットに依存します。 mkcosi コマンドを最初に実行して管理用の共通イメージを作成しないと、このコマンドの実行は失敗します。

フラグ

項目
説明
-b installp_bundle 共通イメージに対して実行する installp_bundle NIM リソースを指定します。
-B フィックスバンドル 共通イメージに対して実行する fix_bundle NIM リソースを指定します。
-c 共通イメージ上でインストールまたは更新されるソフトウェアをコミット状態にすることを指定します。
-f ファイル・セット ファイルセットのリストを指定し、共通イメージに対して実行されるようにします。
-F フィックス 修正のリストを指定し、共通イメージに対して実行されるようにします。
-i インストール対象のソフトウェアを指定します。
-j リジェクト対象のソフトウェアを指定します。
-r 除去対象のソフトウェアを指定します。
-R 必要条件ソフトウェアに適用される操作を指定します。
-s ソース 共通イメージ管理のソースを指定します。 ソースは、 lpp_source、インストール可能メディアを持つデバイス、インストール可能イメージのディレクトリー、またはインストール可能イメージのリモート・ロケーションにすることができます。
-u 更新またはコミット対象のソフトウェアを指定します。
-v chcosi コマンドの実行時に詳細デバッグ出力を有効にします。

終了状況

項目
説明
0 コマンドは正常に完了しました。
>0 エラーが発生しました。

セキュリティー

アクセス制御: chcosi コマンドを実行するには、root 権限が必要です。

例

  1. CD-ROM から cosi1という名前の共通イメージに csm.core ソフトウェアをインストールするには、次のように入力します。
    chcosi -i -s cd0 -f csm.core cosi1
    csm.core ファイルセットが cosi1 共通イメージにインストールされ、ファイルセットが APPLIED 状態に置かれます。
