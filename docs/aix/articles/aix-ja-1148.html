目的
システムのメール別名を表示します。

説明
praliases
コマンドは、特定の順序なしに、行ごとに、システムの現行別名を表示します。 特別な内部
@:@
別名が表示されます (存在する場合)。

構文
praliases [ -C ファイル ] [ -f ファイル ] [ key ]

オプション
フラグ
項目 | 説明
-C ファイル | デフォルトの sendmail 構成ファイルではなく、指定された sendmail 構成ファイルを読み取ります。
-f ファイル | sendmail ファイルの構成済み別名ファイルではなく、指定されたファイルを読み取ります。
key | コマンド・ラインで 1 つ以上のキーが指定されている場合、そのキーに一致するエントリーを表示します。
注:
praliases
コマンドは、エラーが発生すると、正常終了時に
0
で終了し、
>0
で終了します。
