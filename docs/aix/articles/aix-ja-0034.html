目的
Active Memory Expansion Planning and Advisory Tool
amepat
は、Active Memory Expansion (AME) 情報を報告し、統計は、既存のワークロードでの Active Memory Expansion の使用を計画する際に役立つアドバイザリー・レポートも提供します。

説明
Active Memory Expansion Planning and Advisory Tool
amepat
は、以下の 2 つの主要な機能を提供します。
ワークロード計画-
amepat
を実行して、Active Memory Expansion からメリットを得られるワークロードを判別することができます。また、ワークロードに対して可能な Active Memory Expansion 構成のリストを提供することもできます。
モニター-Active Memory Expansion が使用可能になっている場合、
amepat
ツールを使用して、ワークロードおよび Active Memory Expansion のパフォーマンス統計をモニターすることができます。
amepat
は、次の 2 つの異なるモードで開始することができます。
記録
モードでは、
amepat
はシステム構成とさまざまなパフォーマンス統計をユーザー指定の記録ファイルに記録します。
「レポート作成」
モードでは、
amepat
コマンドは、リアルタイムで、またはユーザー指定の記録ファイルから収集されたシステム構成およびパフォーマンス統計を分析して、ワークロード使用状況および計画レポートを生成します。
注：
このツールは、
AIXバージョン6.1の 6100-04 テクノロジー・レベル
-SP2
リリース以降で利用可能です。
ワークロード・プランニング
既存のワークロードに Active Memory Expansion を使用することを検討する際に、
amepat
を使用して、ワークロードに可能な Active Memory Expansion 構成に関するガイダンスを提供することができます。
amepat
が、Active Memory Expansion を使用していない既存のワークロードと並行して実行される場合、
amepat
は、ユーザーが構成可能なワークロード期間にわたって、メモリー使用量、メモリー参照パターン、およびデータ圧縮性をモニターします。 次に、このツールは、ワークロードに対して可能な Active Memory Expansion 構成のリストを含むレポートを生成します。 このツールには、さまざまな Active Memory Expansion 構成に対するプロセッサー使用率の影響の見積もりが含まれています。
この
amepat
コマンドは
、 AIX

、 6.1、およびそれ以降のバージョンでサポートされているすべてのバージョンの IBM® Power® サーバーで実行できます。
amepat
を実行してワークロード計画を立てるときには、主要な考慮事項が 2 つあります。その 2 つとは、ツールの実行時刻とツールの実行期間です。 ツールから最良の結果を得るには、ワークロードのピーク使用率の間にツールを実行する必要があります。 それにより、ツールは必ずワークロードの使用率のピークとメモリー使用量の情報を取り込むことができます。
amepat
を使用してワークロード計画用のレポートを生成するためには、
amepat
の開始時にモニター期間を指定する必要があります。
Active Memory Expansion をまだ使用していないワークロードで
amepat
を使用するだけでなく、Active Memory Expansion が既に使用可能になっている LPAR でも
amepat
を実行できます。 このモードで使用すると、
amepat
は、ワークロードに対して考えられる他の Active Memory Expansion 構成のレポートを提供します。
注:
amepat
では、ワークロード計画を実行するために特権アクセスが必要です。 必要な特権なしでユーザーがツールを開始すると、ワークロード計画機能は使用不可になります (
-N
フラグは暗黙的にオンになります)。
モニター
amepat
は (ワークロード計画機能を使用不可にして)、
プロセッサーおよびメモリー使用率統計のモニターに使用することもできます。 このモニター機能を使用すると、
amepat
はプロセッサーおよびメモリーの使用率統計を収集するだけで、ワークロード計画のレポートを生成するために必要な追加データを収集しません。 したがって、Active Memory Expansion モデリングおよびアドバイザリー・レポートは生成されません。
amepat
が期間または間隔を指定せずに開始されると、
amepat
はデフォルトで機能のみをモニターし、
amepat
は LPAR のメモリー、プロセッサー使用率のスナップショットを報告します。
amepat
期間を指定して開始し、
-N
フラグを使用してモニターのみの機能で実行することができます。
-N
フラグはこのツールのワークロード計画機能を使用不可にするため、ワークロード計画のためのデータ収集プロセスとレポート作成が使用不可になります。
注:
記録モードとレポート・モードは、どちらも
-N

フラグを使用して開始できます。
-N
フラグは、Active Memory Expansion が使用可能なマシンと使用不可のマシンの両方でサポートされます。

推奨
この推奨は、現在実行中のワークロードに最適な利点を提供する Active Memory Expansion 構成に関する詳細を提供します。
推奨は、ワークロードのモニター期間中の動作に基づいて純粋に行われるため、提供される推奨はガイダンスとしてのみ使用できます。 実際の統計は、ワークロードのリアルタイムの実際の動作を基に変化する可能性があります。
注:
Active Memory Expansion Modeled Statistics and Recommendation は、ワークロード計画に使用されます。
-N

AIX® 7.3以降、デフォルトでは、アクティブメモリ拡張機能は、システム構成に基づいて最適なページサイズモードを選択します。 デフォルトで、

オプションを使用して、
amepat
コマンドが実行されているプロセッサー実装以降のプロセッサーをモデル化できます。
amepat
コマンドは、モデル化の動作を変更するときに役立つ特定フラグ (
-e
フラグなど) について最小値と最大値を指定します。 指定された値は、
amepat
コマンドによる推奨値と見なされます。
amepat
コマンドは、実行中にコマンドによって決定された許容範囲内に値がない場合、これらの値をオーバーライドします。

例
Active Memory Expansion モニターのみのレポートを表示するには、次のように入力します。
amepat
8 分間のサンプリング間隔と 2 サンプルを使用して 16 分間のワークロードをモニターするには、ワークロード計画のレポートを生成します。次のように入力します。
amepat 8 2
16 分間の期間にわたってワークロードをモニターし、 1.5 から 3 の間のモデル化されたメモリー拡張係数を持つワークロード計画の Active Memory Expansion レポートを 0.5 増分係数で生成するには、次のように入力します。
amepat –e 1.50:3.00:0.5 16
16 分間の期間にわたってワークロードをモニターし、ワークロード計画用の Active Memory Expansion レポートを生成し、モデル化された AME プロセッサー使用率を 30% にキャッピングするには、次のように入力します。
amepat –c 30 16
16 分間の期間、ワークロードをモニターし、1000 MB のモデル化されたメモリー・ゲインを開始して、ワークロード計画用の Active Memory Expansion レポートを生成するには、次のように入力します。
amepat –m 1000 16
16 分間の期間にわたってワークロードをモニターし、最小非圧縮プール・サイズ 2000 MB をモデル化することによってワークロード計画用の Active Memory Expansion レポートを生成するには、次のように入力します。
amepat –u 2000 16
amepat
の記録モードを使用して記録ファイルを生成し、各種フィルターを使用してレポートを生成するには、次のように入力します。
60 分の期間のレコード。
amepat -R myrecord_amepat 60
注:
記録モードは、それ自体をバックグラウンド・プロセスに切り替えます。
ワークロード計画用のレポートを生成する
amepat -P myrecord_amepat
モデル化されたメモリー拡張係数の範囲が 2 から 4 の間で、 0.5 の差分係数を使用して、ワークロード計画のレポートを生成します。
amepat -e 2.0:4.0:0.5 -P myrecord_amepat
モニター・レポートのみを生成
amepat -N -P myrecord_amepat

ワークロード計画機能を使用不可にして 30 分間システムをモニターするには、次のように入力します。
amepat -N 30
ワークロードを 60 分間の期間モニターし、プロセッサー実装 P8 にモデル化するには、次のコマンドを入力します。
amepat –O proc=P8 60
