目的
キーワード検索でコマンドを見つけます。

説明
アポス
コマンドは、
キーワード
パラメーターによって指定されたキーワード
S
のいずれかがタイトルに含まれているマニュアル・セクションを表示します。
apropos
コマンドは各ワードを別々のワードと見なし、大文字と小文字を区別しません。 他のワードの一部となっているワードも表示されます。 例えば、次の単語を検索するとします。
compile
アポス
コマンドは、そのワードのすべてのインスタンスも検出します。
compiler
.キーワードを含むデータベースは
/usr/share/man/whatisで
、最初に
catman -w
コマンドで生成する必要がある。
apropos
コマンドの出力が名前とセクション番号で始まっている場合は、
man
Section Title
を入力できます。 例えば、
アポス
コマンドの出力が以下のようになっているとします。
printf(3)
、次のように入力できます。
man 3 printf
printf
サブルーチンのマニュアル・ページを取得します。
apropos
コマンドは、
-k

man

man

”

構文
apropos [ -M PathName ] キーワード ...

オプション
フラグ
項目 | 説明
-M PathName | 代替検索パスを指定します。 検索パスはコロンで区切られたディレクトリーのリストで、 PathName パラメーターで指定します。

例
単語が含まれているマニュアル・セクションを検索するには、以下のようにします。
password
タイトルに次のように入力します。
apropos password
単語が含まれているマニュアル・セクションを検索するには、以下のようにします。
editor
タイトルに次のように入力します。
apropos editor
