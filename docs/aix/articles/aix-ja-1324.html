目的
クライアント・マシンまたはサーバー・マシンで印刷サービスの構成を解除します。

説明
rmprtsv
高水準コマンドは、クライアント・マシンまたはサーバー・マシンで印刷サービスの構成解除を行います。
クライアント用の印刷サービスの構成解除を行うために、
rmprtsv
コマンドは、
rmque
および
rmquedev
コマンドをコールし、
クライアントのスプール・キューを使用不可にして、
/etc/qconfig
ファイル内の該当するエントリーを除去します。
サーバー用の印刷サービスの構成解除を行うために、
rmprtsv
コマンドは以下のプロシージャーを実行します。
stopsrc
コマンドを呼び出し、
lpd
サーバーおよび
qdaemon
サーバーを非活動化します。
ruser
低レベル・コマンドを呼び出し、プリント・サーバー上のリモート・ユーザーを構成解除します。
rmque
および
rmquedev
コマンドを呼び出し、スプーラーとそのデバイス・キューを構成解除します。 そして、サーバーの
/usr/lib/lpd/qconfig
ファイル内の該当するエントリーを削除します。

構文
rmprtsv { -c | -s } [ -T | -U | -A ] [ -h " ホスト名... " | -H FileName ] [ -q " QEntry. .. " ] [ -q QEntry -v 「 デバイス名... 」

オプション
フラグ
項目 | 説明
-A | 指定されたエントリーを /etc/qconfig ファイルから除去しますが、 印刷サービスを完全に構成解除するわけではありません。
-c | クライアント・マシン用の印刷サービスの構成解除を行います。 -q フラグは、 -c フラグと一緒に使用します。
-H FileName | 印刷サービス用に構成されるホスト名のリストが入っているファイルの名前を指定します。
- h " ホスト名 ... " | 印刷サービスを使えないリモート・ホスト名のリストを指定します。 キューイング・システムでは、マルチバイトのホスト名をサポートしていないことに注意してください。
- q " QEntry ... " | /etc/qconfig ファイルから除去したいエントリーのリストを指定します。
-s | サーバー・マシン用の印刷サービスの構成解除を行います。 -h 、 -H 、 および -q フラグは、 -s フラグと一緒に使用する必要があります。
-T | 印刷サービスを停止しますが、印刷サービスの完全な構成解除を行うわけではありません。
-U | 指定されたリモート・ユーザーを印刷サーバーで除去しますが、印刷サービスの完全な構成解除を行うわけではありません。
-v " デバイス名... " | qconfig ファイル上のデバイス・スタンザ名のリストを指定します。 -q QEntry フラグとともに使用してください。
