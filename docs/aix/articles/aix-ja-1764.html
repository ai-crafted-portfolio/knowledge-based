目的
NFS/TFTP でアクセスするフォント・ディレクトリーをフォント・パスに追加します。

説明
x_add_nfs_fpe
コマンドは、選択したネットワーク・タイプ名のフォント・パスにフォント・パス・エレメントを追加
します。 このフォント・ディレクトリーには、ネットワーク・ファイルシステム (NFS) またはトリビアル・ファイル転送プロトコル (TFTP) を使ってアクセスします。
項目 | 説明
Host | フォント・ディレクトリーにアクセスするためのシステム名を指定します。
directory | フォントが入っているディレクトリーへの絶対パスを指定します。
メソッド (method) | 次のいずれかを指定 nfs または tftp フォントにアクセスするために使用されます。
位置 | このエレメントを挿入するフォント・パス内の位置を指定します。
TypeName | ネットワーク・タイプの名前を指定します。 ネットワーク・タイプごとに、1 つ以上のフォント・パス・エレメントからなるフォント・パスがあります。 フォント・パス要素が追加されるネットワーク・タイプの名前を指定するか, あるいは次の指定によってフォント・パス要素をすべてのネットワーク・タイプ名に追加することを選択してください。 All フォント・パス・エレメントが追加された場合 All ネットワーク・タイプの場合は、各フォント・パスの末尾に配置されます。

構文
x_add_nfs_fpe ホスト・ディレクトリー・メソッド位置 TypeName

例
フォントを追加するには
/usr/lib/X11/fonts/100dpi
ネットワーク・タイプに
x_st_mgr.ether
次のように入力します。
x_add_nfs_fpe cedar /usr/lib/X11/fonts/100dpi nfs Last \ x_st_mgr.ether
このフォント・パス・エレメント
/usr/lib/X11/fonts/100dpi
ネットワーク・タイプのフォント・パスの末尾に追加されます。
x_st_mgr.ether
フォント・ディレクトリーはホスト上にあります。
cedar
これには、 NFSを使用してアクセスします。
