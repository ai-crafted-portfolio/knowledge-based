目的
ディスク使用状況とクォータを表示します。

説明
quota
コマンドは、ディスク使用量と割り当て量を表示します。 デフォルトでは、または
-u
フラグを使用すると、ユーザー・クォータのみが表示されます。
quota
コマンドは、
/etc/filesystems
ファイルにリストされているすべてのファイルシステムの割り当て量を報告します。
quota
コマンドがゼロ以外の状況で終了した場合、1 つ以上のファイル・システムが割り当て量を超えています。
root ユーザーは、オプションの User パラメーターを指定して
-u
フラグを使用し、他のユーザーの制限を表示することができます。 root ユーザー権限を持たないユーザーは、オプションの Group パラメーターを指定した
-g
フラグを使用して、自分がメンバーであるグループの制限を表示できます。
注:
JFS ファイル・システムでは、特定のユーザーが割り当て量を持っているファイル・システム内にそのユーザーがファイルを持っていない場合、このコマンドは以下のように表示します。
quota:
none
表示されます。 ユーザーの実際の割り当て量は、ユーザーがファイル・システムにファイルを持っている場合、または
-v
フラグが指定されている場合に表示されます。 JFS2 の場合、すべてのケースでユーザーの実際のクォータが表示されます。
JFS2 システムでは、root ユーザーはクォータによって制限を受けることがないため、root ユーザーの限界は常にゼロ (無制限) として表示されます。
rpc.rquotad プロトコルは、NFS のグループ・クォータをサポートしていません。 このため、このプロトコルは
NFS に対するグループ・クォータ情報を戻しません。

構文
割り当て量 [ -u [ User ]] [ -g [ グループ ]] [ -v | -q ]

オプション
フラグ
項目 | 説明
-g | ユーザーのグループのクォータを表示します。
-u | ユーザーのクォータを表示します。 このフラグはデフォルトのオプションです。
-v | ストレージが割り当てられていないときのファイルシステム上のクォータを表示します。
-q | 使用量がクォータを超えているファイルシステムについての情報のみを示す簡潔なメッセ ージを表示します。 注: -q フラグは -v フラグよりも優先されます。

例
割り当て量をユーザーとして表示するには
keith
、タイプ:
quota
シス
テムは、次の情報を表示します。
User quotas for user keith (uid 502):
Filesystem blocks quota limit grace Files quota limit grace
/u 20 55 60 20 60 65
ユーザーの root ユーザーとして割り当て量を表示するには、以下のようにします。
davec
、タイプ:
quota -u davec
シス
テムは、次の情報を表示します。
User quotas for user davec (uid 2702):
Filesystem blocks quota limit grace files quota limit grace
/u 48 50 60 7 60 60
