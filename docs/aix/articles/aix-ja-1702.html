目的
ファイルをリモート・ホストに送信します。

説明
uusend
コマンドは、リモート・システム上の所定の位置にファイルを送信します。 リモート・システムはローカル・システムと直接接続されている必要はありませんが、
2 つのシステムは UUCP リンクのチェーンで接続されていなければなりません。
また、チェーン内の各システム上では
uusend
コマンドが使用できなければなりません。
システムのチェーンは、
System
[
!
によって指定されます。
システム ...
] パラメーター。ファイルの転送先の各リモート・システムを! で区切ってリストします。 (感嘆符) で区切ってリストします。
!
表記を、
Remotefile
パラメーターは、チェーン内の最後のシステムに到達したときにファイルが保管される名前を指定します。
“
注:
システム名と感嘆符の間、または最後の感嘆符とリモート・ファイル名の間にはスペースを入れないでください。
”
SourceFile
パラメーターには、
ローカル・システム上のファイルの名前を指定します。
-
(ハイフン) を使用した場合には、
uusend
コマンドは標準入力を使用します。

構文
uusend [ -m モード ] [ -r ] ソース・ファイル システム [ ! システム ...] ! RemoteFile

オプション
フラグ
項目 | 説明
-m モード | リモート・システム上のファイルのモードを、指定された 8 進数で取り込むことを指定します。 このフラグを指定しないと、入力ファイルのモードが使用されます。
-r | uucico デーモンの始動を抑制します。 このデーモンはシステム間でファイルを転送します。 デフォルトでは uucico デーモンを始動します。
上記のフラグは、チェーン内の次のリモート・システムにファイルを転送するときに、
主として
uusend
コマンドで内部的に使用されます。

例
ファイルのあるシステムから別のシステムに送信するには、以下のように入力します。
uusend /etc/motd nostromo!gandalf!~nuucp
について
/etc/motd
ファイル
システムに送信される
nostromo
その後、システムに
gandalf
、および以下に配置されます。
nuucp
のホーム・ディレクトリー
/var/spool/uucppublic/nuucp
、ここで、
nuucp
BNU のログイン ID です。
