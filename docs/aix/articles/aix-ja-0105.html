目的
両方向 (BIDI) モードで端末をエミュレートします。

説明
bterm
コマンドは、
IBM
3151、VT220、HFT、その他のターミナルをエミュレートする。 ASCII 端末上では BIDI モードで動作します。 このコマンドは、任意の BIDI アプリケーションを実行できる BIDI シェルを作成します。
bterm
コマンドを同じコマンド内で再帰的に開始することはできません。
キーボード・マッピングと文字の対称的スワッピングを決定するマップは、
-maps
フラグで指定します。 その他の BIDI の動作は、
bterm
コマンドで使用可能なフラグを使用するか、デフォルトのファイル内で設定することによって指定できます。 この種の動作には、デフォルトのテキスト・モード、デフォルトの画面方向、アラビア文字の字形のデフォルト・モード、数字のデフォルトの形状、対称的スワッピング・モードを使用可能にするかどうか、自動プッシュ・モードを使用可能にするかどうか、などがあります。 フラグを使って指定した動作は、デフォルトのファイルで設定されている動作よりも優先されます。
デフォルトのファイルは、次の順序で検索されます。
。BIDI-デフォルトの
ファイルがホーム・ディレクトリーで検索されます。
ファイルが見つからない場合、
bterm
コマンドは
/usr/lib/nls/bidi/$LANG/app-defaults
ファイル内で
BTerm
リソース・ファイルを検索します。

構文
BTERM [ -マップ マップ ] [ -ヘルプ ] [ -キーワード ] [ -ノビディ ] [ -対称 ] [ -自動プッシュ ] [ -または 方向 ] [ -テキスト TextType ] [ -nss NumShape ] [ -CSD CharShape ] [ -tail ] [ -非ヌル ]

オプション
フラグ
項目 | 説明
-自動プッシュ | ビジュアル・テキスト・モードで自動プッシュ・モードを使用可能にします。
-csd CharShape | アラビア文字の形状を指定します。 CharShape 変数には、次のいずれかのオプションを指定できます。 AUTOMATIC isolated (ビジュアル・テキスト・モードのみ) initial (ビジュアル・テキスト・モードのみ) middle (ビジュアル・テキスト・モードのみ) final (ビジュアル・テキスト・モードのみ) passthru デフォルトは automatic 成形です。
-help | 使用可能なパラメーターとその構文を表示します。
キーワード | デフォルトのファイル内で使用可能なキーワードを表示します。
-maps マップ | キーボード・マッピングと文字の対称的スワッピングに使用するマップを指定します。 言語ごとに異なるマップがあり、 Map 変数に使用可能なオプションは /usr/lib/nls/bidi/maps ディレクトリーに入っています。 環境変数 BIDIPATH を次のように指定する必要があります。 export BIDIPATH=/usr/lib/nls/bidi
-ノビディ | BIDI モードを使用不可にします。
-nonulls (非ヌル) | ヌルではなくスペースを使用して画面を初期化します。
-エヌエス NumShape | 数字の形状を指定します。 NumShape 変数には、次のいずれかのオプションを指定します。 bilingual hindi arabic passthru デフォルトは bilingual です。
または Orientation | 画面方向を指定します。 Orientation 変数には LTR または RTL を指定します。 デフォルトは LTR です。
対称 (-symmetric) | 対称的スワッピング・モードを使用可能にします。
-テール | アラビア語の文字「seen」、「sheen」、「sad」、および「dad」を、1 つのセルではなく 2 つのセルに書き込みます。
-テキスト TextType | データ・ストリームのタイプを指定します。 TextType 変数には、 implicit または visual を指定します。 デフォルトは implicit です。
