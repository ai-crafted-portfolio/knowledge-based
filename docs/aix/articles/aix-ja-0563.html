目的
リソース・モニターのアンロックと始動を行います。

説明
イベント管理デーモンが 2 時間の間隔内に 3 回試行してもリソース・モニターを正常に開始できない場合、またはデーモンが 2 時間の間隔内にリソース・モニターのインスタンスに
n
回正常に接続した場合は、以下のようになります。 リソース・モニターは
“
ロック
”
され、リソース・モニターの開始や、リソース・モニターのインスタンスへの接続はこれ以上試行されません。
n
は、 HACMP/ES クラスター内の
3
です。 障害の原因が判別され、問題が修正されると、
haemunlkrm
コマンドを使用してリソース・モニターをアンロックし、リソース・モニターの開始またはリソース・モニター・インスタンスへの接続を試みることができます。
lssrc
コマンドによって表示されるイベント・マネージャー・デーモンの状況は、リソース・モニターがロックされているかどうかを示します。

構文
haemunlkrm -s サブシス名 -a レズモン名

オプション
フラグ
--s
サブシス名
イベント管理サブシステムの名前を指定します。 ノードでは、
subsys_name
は
emsvcs
です。 このフラグとパラメーターは指定しなければなりません。
--a
resmon_name
アンロックおよび始動するリソース・モニターの名前を指定します。

例
この例はノード上のリソース・モニターをアンロックしようとするものです。
lssrc
コマンドの出力に、プログラム・リソース・モニター
IBM.PSSP.harmpd
がロックされていることが示されている場合は、リソース・モニターの開始を妨げている状態を訂正し、次のように入力します。
haemunlkrm -s emsvcs -a IBM.PSSP.harmpd
