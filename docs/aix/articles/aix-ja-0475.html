目的
ファイルまたは標準入力にあるすべての First Failure Data Capture (FFDC) 障害 ID を見つけ、
表示します。 複数のファイルを指定することができます。

説明
このコマンドは、First Failure Data Capture (FFDC) 障害 ID の引数としてリストされているすべてのファイルをスキャンします。 ファイル名が引数として指定されていない場合、このコマンドは、FFDC 障害 ID の標準入力を調べます。 FFDC 障害 ID が検出された場合、
fcfilter
は、その ID を独自の行に標準出力に表示します。
fcfilter
は、標準エラー・デバイスを介して子プロセスによって返された FFDC 障害 ID を抽出するためにスクリプトで使用できます。
fcfilter
が入力で複数の FFDC 障害 ID を検出した場合、このコマンドは、検出されたすべての FFDC 障害 ID を別々の出力行に表示します。

構文
fcfilter [ file_name ] [. . . ]

例
FFDC 障害 ID は、右から左に読み取られる
base-64
値によって表されます。 各ドットは先行ゼロを表します。 コマンド
mycmd
の実行
によって生成されたすべての FFDC 障害 ID のリストを入手するには、次のようにします。
mycmd 2> /tmp/errout
fcfilter /tmp/errout
/.00...JMr4r.p9E.xRXQ7....................
/.00...JMr4r.pMx.xRXQ7....................
親スクリプト内の子プロセスから FFDC 障害 ID を取得するには、スクリプトで以下のように
fcfilter
コマンドを使用できます。
RESULTS=$(mychild 2> /tmp/errout)
if (($? != 0)) # mychild ended in failure, get FFDC ID
then
cat /tmp/errout │ fcfilter │ read FIRST_FFDCID
else
rm -f /tmp/errout
fi
