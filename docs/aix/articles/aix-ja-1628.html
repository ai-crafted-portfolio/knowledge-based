目的
すべてのチューナブル・パラメーターをデフォルト値にリセットします。

説明
tundefault
コマンドは、すべてのチューニング・コマンド (
ioo
、
vmo
、
schedo
、
no
、
nfso
、および
raso
) を
-D
フラグ付きで開始します。 これは、
-r
が指定されていない限り、
Bosboot
と
Reboot
タイプのパラメー タ、およびデフォルト値よりも大きな値に設定された
Incremental
タイプのパラメータを除 く、すべての
AIX
調整可能パラメータをデフォルト値にリセットする。 パラメーターを変更できない場合は、エラー・メッセージが
表示されます。

構文
チューニング・デフォルト [ - [ -K (K) ] | P- ]

オプション
フラグ
項目 | 説明
-K | 次のライブ・アップデート操作まで、チューナブル・パラメーターのデフォルト値へのリセット操作を据え置きます。 -r フラグが指定されると、 tundefault コマンドは、 nextboot ファイルおよび nextliveupdate ファイルに指定されたチューナブル・パラメーターをすべて、そのデフォルト値にリセットします。 -r フラグは、 /etc/tunables/nextboot ファイルのスタンザを消去し、必要に応じて、 bosboot 操作を実行するよう指示し、変更内容を適用するにはリブート操作が必要であることを示す警告メッセージを表示します。 -K フラグは、 /etc/tunables/nextliveupdate ファイルのスタンザとチューナブル・パラメーターのデフォルト値を nextliveupdate ファイルに追加します。 この更新済み nextliveupdate ファイルは、次のライブ・アップデート操作に使用されます。
-p | 変更内容を永続的にします。すべてのチューナブル・パラメーターをデフォルト値にリセット し、 /etc/tunables/nextboot ファイルを更新します。
-r | デフォルト値へのリセットを次のリブートまで据え置きます。 これにより /etc/tunables/nextboot ファイルのスタンザが消去されて、必要に応じて bosboot を提案し、リブートが必要なことを警告するメッセージを表示します。

例
すべてのチューナブル・パラメーターを永続的にそのデフォルト値にリセットするには、次のコマンドを入力します。
tundefault -p
チューニング・コマンドを起動するときに、すべてのコマンドに
-Dp
フラグ
が付きます。 これにより、すべてのチューナブル・パラメーターをデフォルト値にリセットし
ます。 さらに、
/etc/tunables/nextboot
ファイルを更新し
ます。 このコマンドは、すべてのチューナブル・パラメーターを完全に永続的にデフォルト値にリセ
ットします。
すべてのチューナブル・パラメーターの設定を次のリブートまで据え置くには、次のコマンドを入力します。
tundefault -r
このコマンドは、
-Dr
フラグを付けてすべてのチューニング・コマンドを呼び出します。 これにより、
/etc/tunables/nextboot
ファイルの
スタンザを消去し、必要に応じて、
bosboot
を提案し、
変更内容を有効にするにはリブートが必要なことを警告します。
すべてのチューナブル・パラメーターの設定を次のリブートおよび次のライブ・アップデート操作まで据え置くには、次のコマンドを入力します。
tundefault -r -K
このコマンドは、
-DrK
フラグを付けてすべてのチューニング・コマンドを呼び出します。 このコマンドは、
/etc/tunables/nextboot
ファイルのスタンザを消去し、必要に応じて、
bosboot
操作を提案し、変更内容を有効にするにはリブートが必要なことを警告します。 また、次のライブ・アップデート操作のためのチューナブル・パラメーターにデフォルト以外の値が設定されていた場合、このコマンドは、スタンザとデフォルト値を
/etc/tunables/nextliveupdate
ファイルに追加します。
