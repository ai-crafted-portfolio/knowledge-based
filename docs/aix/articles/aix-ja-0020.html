目的
1 つ以上のノードをピア・ドメイン定義に追加します。

説明
addrpnode
コマンドを実行する前に:
適切なセキュリティー環境をセットアップするには、
ピア・ドメインに追加する各ノードで
preprpnode
コマンドを実行します。
addrpnode
コマンドは、指定されたノードを、
addrpnode
コマンドが実行されるオンライン・ピア・ドメインに追加します。 このコマンドは、それらの新規ノードが追加されるピア・ドメインに対してオンラインになっているノードで実行しなければなりません。 1 つのノードを複数のピア・ドメインに定義できますが、オンラインにできるのは、1 つのピア・ドメインのみです。 ピア・ドメインに 1 つ以上のノードを追加するためには、半数を上回るノードがオンラインでなければなりません。
ノードの 1 つにエラーが発生しても
addrpnode
コマンドの継続を可能にするには、
-c
フラグを使用します。
addrpnode
コマンドは、
追加されたノードをピア・ドメインでオンラインにしません。 これを行うには、
startrpnode
コマンドを使用します。

構文
addrpnode [-c] [-h] [-TV] node_name1 [node_name2 ...] addrpnode [-c] { -f │ -F { file_name │ "-" } } [-h] [-TV] [-M] addrpnode [-c] [-h] [-TV] node_name1 [@host_name1] [node_name2 [@host_name2] …]

オプション
フラグ
-c
少なくとも 1 つのノードをピア・ドメインに追加できる間は、コマンドの処理を続行します。
デフォルトでは、いずれかのノードで
addrpnode
コマンドが失敗すると、すべてのノードで失敗します。
-c
フラグを指定するとこの動作がオーバーライドされ、
addrpnode
コマンドは 1 つのノードで失敗しても残りのノードで実行されます。
-f
|
-F
{
ファイル名
|
"-"
}
ファイルまたは標準入力からノード名を読み取ることを指定します。
ファイルからノード名を読み取るには、

file_name
または
-F
file_name

-f "-"
または
-F "-"

STDIN

注:
1 行につき 1 つのノード名を指定します。 コマンドは、ノード名の左側のブランク文字があっても無視します。
番号記号 (#) を使用して、行の残りの部分 (または # が 1 桁目にある場合は行全体) がコメントであることを示します。
デフォルトでは、
file_name
にリストされるノードはすべて、以下のようになります。
グループ・サービスのグループ・リーダー候補ですか?
クォーラム決定に使用されます。
ピア・ドメイン・タイ・ブレーカー・メカニズムにアクセスできます。
ノード特性をカスタマイズするには、アットマーク (@) 制御文字を使用し、その後で以下の特殊文字のうち 1 つ以上を付けます。
P | p
ノードがグループ・サービスのグループ・リーダー候補であることを指定します。
Q | q
ノードがクォーラム・ノードであることを指定します。
B｜b
ノードがピア・ドメイン・タイ・ブレーカー・メカニズムにアクセスすることを指定します。
B
または
b
は、クォーラム・ノードにのみ指定できます。
!
ノードが特定の特性を持っていないことを指定します。 例えば、
!Q
は、ノードがクォーラム・ノードでないことを指定します。
ノードの特性をカスタマイズする場合、以下を考慮してください (ここで
x
は
P
、
Q
、または
B

1 行につき 1 つの
@
制御文字のみを使用し、その後にノード名の直後およびコメントの前に 1 つ以上の特殊文字を続けます。
ノードには
!QB
を指定しないでください。指定すると、エラーになります。
ノード番号を使用する場合は、ノード名の後でコメントの前にそれを追加してください。 ノード番号は、ノード特性の指定の前にも後ろにも付けることができます。

!x

x

-h
コマンドの使用方法の文を標準出力に書き込みます。
-M
新しいノードのセキュリティー・コンプライアンス・モードがドメインと一致しているかどうかを検証します。 モードが一致しない場合、ノードは追加されません。
-M
オプションが指定されておらず、ノードがドメインと互換性のある鍵タイプを使用している場合、ノードが追加され、その準拠モードがドメインと一致するように更新されます。
-T
標準エラーにコマンドのトレース・メッセージを書き込みます。 これはソフトウェア・サービス組織専用です。
-V
コマンドの詳細メッセージを標準出力に書き込みます。
