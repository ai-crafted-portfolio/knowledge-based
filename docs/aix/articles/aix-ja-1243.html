目的
論理ボリュームの特定のミラー・コピーを読み取ります。

構文
readlvcopy -d 年 装置 [ 「-c」 コピー | -C コピー | -b | P- ミラー・プール ] [ N ブロック数 (number_of_blocks) ] [ - 出力ファイル ] [ -s スキップ ] [ -S (S) シーク ]

オプション
フラグ
項目 | 説明
-d デバイス | 読み取り元の論理ボリューム特殊デバイス・ファイル
-c コピー | 読み取り元の要求されたミラー・コピー。 データの 1 番目のコピー、2 番目のコピー、 3 番目のコピーに有効な値は、1、2、または 3。 データは、論理区画に期間切れというマークが付けられている場合でも読み取られます。 デフォルトは、データの 1 番目のコピーです。
-C コピー | 読み取り元の要求されたミラー・コピー。 データの 1 番目のコピー、2 番目のコピー、 3 番目のコピーに有効な値は、1、2、または 3。 期間切れの論理区画は読み取られません。
-b | オンライン・バックアップのマークが付けられたミラー・コピーを読み取ります。
N ブロック数 (number_of_blocks) | 読み取る 128K ブロックの数。
-o 出力ファイル | 宛先ファイル。 デフォルトは stdout です。
-p ミラー・プール | 指定されたミラー・プールに関連付けられているデータのコピーから読み取ります。 データは、論理区画に期間切れというマークが付けられている場合でも読み取られます。 デフォルトは、データの 1 番目のコピーです。 指定されたミラー・プールがボリューム・グループに存在しない場合、 readlvcopy コマンドは失敗します。
-s スキップ | device にスキップする 128K ブロックの数。
-S (S) シーク | outfile にシークする 128K ブロックの数。

例
デバイス
/dev/rlv00
の、
mp1
ミラー・プールに関連付けられているコピーからデータの最初の 128 KB ブロックを読み取るには、次のコマンドを実行します。
readlvcopy -d /dev/rlv00 -p mp1 -n 1
