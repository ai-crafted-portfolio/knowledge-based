目的
プラットフォーム (ハードウェアおよびファームウェア) ダンプ関連のアクションを実行します。

説明
platform_dump
コマンドは、
POWER5
プラットフォームのハードウェアおよびファームウェアの問題判別をサポートします。 このコマンドを使用すれば、オペレーティング・システムがファームウェア関連およびハードウェア関連のダンプを保管できるようになります。 このコマンドは、保守権限が使用可能にされた区画でのみサポートされます (Hardware Management Console
(HMC) 管理対象システムは除外)。 HMC 管理対象システムでは、このダンプは HMC に送られます。
platform_dump
コマンドは通常、基本インストールや dumpcheck などのオペレーティング・システム機能によって実行されます。 プラットフォーム・ダンプには以下のものが含まれます。
ハードウェア状態
hypervisor 状態
FSP (Flexible Service Processor) 状態情報
プラットフォーム・ダンプ・ファイルのディスク・スペースは、
platform_dump
コマンドを使用して予約されます。 専用の論理ボリューム、
/dev/fwdump
、

/var/adm/ras/platform

fwdump_dev

fwdump_dir

AIX

platform_dump

区画がサービス区画として指定されている場合に限られます。 プラットフォーム・ダンプのために事前に十分なスペースを割り振ることができるように、プラットフォーム・ダンプの可能な最大サイズが
AIX

構文
platform_dump { -c | -d | -e | -f fstype | -F フラグ | -l | -q | -S | -s seq_no } [ -L ] [ -N フラグ ]

オプション
フラグ
項目 | 説明
-c | 見積もられたプラットフォーム・ダンプ・サイズ (ファームウェアによって示される)、 およびプラットフォーム・ダンプ用に割り当てられたディスク・スペースの検査を 実行します。 見積もりサイズが割り振られたスペース以下の場合は、0 を戻します。 見積もりサイズが割り振りスペースより大きい場合は、1 を戻します。
-d | プラットフォーム・ダンプ用に予約されたファイルシステム・スペースを削除し、 他の使用目的のために解放します。 予約済みディスク・スペースに既存のダンプ・ファイルがある場合は、失われることになります。
-e | プラットフォーム・ダンプが発生した場合にこれを保管するための、 ディスク・スペースの見積もりを提供します。 このオプションは、この見積もりを提供するために ファームウェアと対話します。 ユーザーは、このスペース情報を基に、 プラットフォーム・ダンプを保管するために十分なディスク・スペースを 割り当てる必要があります。 出力される値は、バイト単位での必要サイズになります。
-f fstype | プラットフォーム・ダンプ用に、システム上に十分なディスク・スペースを予約します。 -f オプションは、プラットフォーム・ダンプ専用のファイル・システムを作成します (存在しない場合)。 既にファイルシステムが存在し、サイズが十分ではない場合は、ファイルシステム・サイズが 増やされます。 fstype は有効なファイルシステム・タイプであることが必要です。 ファイル・システムが既に存在する場合は、 any 指定できます。
-F フラグ | プラットフォーム・ダンプを使用可能または使用不可にします。 フラグが 0 であればプラットフォーム・ダンプは使用不可であり、1 であれば プラットフォーム・ダンプは使用可能です。
-l | プラットフォーム・ダンプの現行構成をリストします。
-L | 出力を表示するだけでなく、ログに記録するように platform_dump に指示します。 これは、 -e オプションによって出力されるサイズには適用されません。
-N フラグ | プラットフォーム・ダンプの圧縮を有効または無効にする。 フラグ・ パラメーターが0の場合、プラットフォーム・ダンプ圧縮は無効になり、 フラグ・ パラメーターが1の場合、プラットフォーム・ダンプ圧縮は有効になる。

-q | プラットフォームがプラットフォーム・ダンプをサポートするかしないか、検査します。 プラットフォーム・ダンプがサポートされる場合は 0 が戻されます。
-s seq_no | ダンプ通知イベントで識別されたものと同じファームウェアから、 プラットフォーム・ダンプを保管します。 シーケンス番号 は、 AIX エラー・ログ・ファイルに保管されているダンプ通知イベントのシーケンス番号を示します。 このシーケンス番号は、詳細なデータ領域を解析し、 ファームウェアからダンプ・データを入手するのに必要なダンプ・タグとダンプ情報を入手するために、 このコマンドによって使用されます。
-S | データのスキャンをサポートするシステムに、スキャン・ダンプを保管します。 このオプションを指定すると、コマンドはスキャン・ダンプが存在するかどうかを検査し、存在する場合は、既存のスキャン・ダンプ・インターフェースを使用してファームウェアから scandump データを読み取って保存します。

例
プラットフォーム・ダンプ・サイズの見積もりを入手するには、次のように入力します。
platform_dump -e
これにより、見積もられたプラットフォーム・ダンプ・サイズがバイト単位で報告されます。
