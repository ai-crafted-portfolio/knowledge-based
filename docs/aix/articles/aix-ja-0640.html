目的
IP セキュリティー・サブシステム内のトレース・バッファーの内容をリストします。

説明
IP セキュリティー・サブシステムは、問題があった場合のデバッグに役立てるため、メモリー常駐のトレース・バッファーを保守しています。 バッファーの内容 (固定数の最新のトレース・メッセージ) は、システム・ダンプ内に保管され、このコマンドを引数を指定せずに実行するとリストされます。

構文
ipsectrcbuf [ -l { 0 | 1 | 2 }]

オプション
フラグ
項目 | 説明
-l | IP セキュリティーのトレース・レベルをセットします。 デフォルトでは、9 個の IP セキュリティーのトレース・フックのうち、IPSEC_ERROR トレース・メッセージだけがバッファーに書き込まれます。 他のトレース・フックを使用可能にする、または使用不可にするには、 -l フラグに次のいずれかの値を使用します。 0 IPSEC_ERROR トレース・メッセージだけがバッファーに書かれます。 これはデフォルトです。 1 IPSEC_ERROR トレース・メッセージの他に、IPSEC_FILTER、IPSEC_CAPSUL、 IPSEC_CRYPTO、IPSEC_TUNNEL がバッファーに書かれます。 ※2 すべての IP セキュリティー・トレース・メッセージがバッファーに書かれます (つまり、 レベル 1 のメッセージに加えて、IPSEC_FILTER_INFO、IPSEC_CAPSUL_INFO、 IPSEC_CRYPTO_INFO、および IPSEC_TUNNEL_INFO が含まれます)。
