目的
キー・キャッシュのディスク・バージョンを作成または置換します。

説明
ctscachgen
コマンドは、キー・キャッシュを生成し、完成したキャッシュを
file-name
で指定されたディスク上のファイルに保管します。 このファイルは、後で
libct_skc
ライブラリー・インターフェースを介してアプリケーションによって使用および更新することができます。
フラグを使用すると、
ctmsskf
コマンドによって対称鍵タイプに使用されるニーモニックを使用して、生成される鍵のタイプを指定できます。 また、このキャッシュで使用可能なキーの暗号化に使用するキー値も指定できます。 デフォルトでは、これらのキーは暗号化されません。 さらに、ファイルに保管するキーの数も指定できます。
file-name
に指定されたファイルが存在する場合、現在の内容がコマンド・ラインに指定されたフラグと一致しない場合でも、このファイルは上書きされます。

構文
ctscachgen -c ファイル名 [ -f ] [ -i │ -n enc-key-name │ -k enc-key-value -t 鍵タイプ │ -q ] [ -m key-gen-method ] [ -s キャッシュ・サイズ ] [ -h ]

オプション
フラグ
-
ファイル名
キー・キャッシュ・ファイルの名前を指定します。 現行ディレクトリーへの絶対パスまたは相対パスのどちらでも指定できます。
-f
コマンドに対し、呼び出し側に上書きの確認を求めずに、既存のキー・キャッシュ・ファイルを同名で上書きするように指示します。
-i
-c
フラグで指定されたキー・キャッシュ・ファイルに関する情報を表示します。 表示される情報には、キャッシュ・ファイルのバージョン、読み取りカウント、キャッシュ内のキーの数、キャッシュ内のキーのタイプ、そしてそれらのキーが事前暗号キーによって暗号化されるかどうかが含まれます。 このフラグは、
-n
、
-k
、
-t
、または
-q
フラグと一緒に使用することはできません。
-
エンコード・キー名
暗号化タイプが指定されたキーを含むファイルの名前を指定します。 このフラグは、
-i
、
-k
、
-t
、または
-q
フラグと一緒に使用することはできません。
-
キー・エンコード値
事前暗号化鍵として使用される鍵値を 16 進形式 (例えば、
6fe45d20a
) で指定します。 デフォルトでは、事前暗号キーの値は使用されません。 このフラグは、
-t
フラグと一緒に使用する必要があります。
-i
、
-n
、または
-q
フラグと一緒に使用することはできません。
--t
キータイプ
-k
オプションで指定された暗号鍵のタイプを提供します。 有効な鍵タイプは、
3des_md5
、
aes256_md5
、
des_cbc
、
des_md5
、
rsa512_sha
、および
rsa1024_sha
です。 このフラグは、
-k
フラグと一緒に使用する必要があります。
-i
、
-n
、または
-q
フラグと一緒に使用することはできません。
-q
コマンドに対し、ディスク・キー・キャッシュ・ファイル内のセッション鍵を事前暗号化するために使用する暗号キーとして、ホストの HBA 秘密鍵を使用するように指示します。 このフラグは、
-i
、
-k
、
-t
、または
-n
フラグと一緒に使用することはできません。
-
キー・ジェネ・メソッド
セッション鍵生成方式を指定します。 有効な値は、
3des_md5
、
aes256_md5
、および
des_md5
です。 このフラグを指定しない場合、セッション鍵を生成するためのデフォルトの方法は
des_md5
です。
-
キャッシュサイズ

ディスク・キー・キャッシュ・ファイルのサイズをキャッシュ内のキーの数で指定します。 このフラグを指定しなければ、デフォルトのキャッシュ・サイズは 128 個のキーになります。
-h
コマンドの使用ステートメント (使用法) を標準出力に書き込みます。

例
鍵ファイル
/my_key_file
に含まれている鍵を表示するには、次のように入力します。
ctmsskf -l -f /my_key_file
バージョン 9 の鍵を鍵ファイル
/my_key_file
から表示するには、次のように入力します。
ctmsskf -l -v 9 -f /my_key_file
鍵ファイル
/my_key_file
に鍵を追加するには、次のように入力します。
ctmsskf -a -t des_cbc -f /my_key_file -k 16_digit_value
鍵ファイル
/my_key_file
から鍵を削除するには、次のように入力します。
ctmsskf -d -f /my_key_file -v 10
鍵ファイル
/my_key_file
内のすべての非アクティブ鍵を削除するには、次のように入力します。
ctmsskf -d -f /my_key_file
