目的
接続時間レコードを表示します。

説明
ac
コマンドは、すべてのユーザーの合計接続時間または指定のユーザーの接続時間を表示します。 レコードは、現行の
wtmp
データ・ファイルの存続期間中にログインしたユーザーをベースにしています。
init
、ログイン・プログラムは接続時間の記録を作成し、
/var/adm/wtmp
ファイルが存在する場合は、そのファイルに収集される。 root ユーザーまたは
Application Development Manager
グループのメンバーは、初期レコード長が 0 (ゼロ) の
/var/adm/wtmp
ファイルを作成します。
/var/adm/wtmp
ファイルがいっぱいにならないように、定期的に記録を処理しなければならない。
/var/adm/wtmp
ファイルが作成されない場合、以下のエラーメッセージが返される：
No /var/adm/wtmp
/var/adm/wtmp
ファイルがいっぱいになると、別の
wtmp
ファイルが作成される。
-w
フラグでファイルを指定すれば、
wtmp
ファイルを印刷できる。

構文
/usr/sbin/acct/ac [ -d ] [ -p ] [ -wFile ] [ User... ]

オプション
フラグ
表 1. フラグ
項目 | 説明
-d | 午前零時から翌日の午前零時までの、毎日の表示出力を作成します。
-p | 個々のログインごとに、接続時間の合計を表示します。 -p フラグを指定しない場合は、期間の合計が印刷される。
-w ファイル | /var/adm/wtmp ファイル以外の wtmp ファイルを指定します。

例
以下のコマンドを入力すると、現在の
wtmp
データファイルの有効期間中にログインしたユーザーの接続時間が印刷されます：
/usr/sbin/acct/ac
次のコマンドを入力すると、現在の
wtmp
データファイルに記録されている、ユーザー
smithと
jonesの
合計接続時間がプリントアウトされる：
/usr/sbin/acct/ac smith jones
次のコマンドを入力すると、現在の
wtmp
データファイルに記録されている、
smithと
jonesの
両ユーザーの接続時間小計がプリントアウトされます：
/usr/sbin/acct/ac -p smith jones
