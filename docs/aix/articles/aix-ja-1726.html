目的
ノードまたは一連のノードの仮想共有ディスク情報を除去します。

説明
このコマンドは、ノードまたは一連のノードに対し、仮想共有ディスクのデータを除去するために使用します。
vsdelnode
コマンドは、もはや仮想共有ディスクではない、
リスト化されたノードを作成するので、仮想共有ディスクはノードからアクセスされる
ことはありません。 このコマンドは、グローバル・ボリューム・グループ用のサーバーである
すべてのノードに対して失敗します。
System Management Interface Tool (SMIT) を使用して、
vsdelnode
コマンドを実行できます。 SMIT を使用するには、以下のように入力します。
smit delete_vsd
さらに、「
仮想共有ディスク・ノードの除去 (Delete Virtual Shared Disk Node)
」情報オプションを選択します。

構文
vsdelnode node_number ...

オプション
フラグ
-g
特定ノード上で定義されたすべての仮想共有ディスクを表すボリューム・グループに対して、
グローバル・ボリューム・グループ名を指定します。
-p
グローバル・ボリューム・グループに対する 1 次サーバー・ノード番号を指定します。
-b
グローバル・ボリューム・グループに対する 2 次ノード番号を指定します。
-b
フラグを指定しない場合は、2 次ノード定義は除去されます。
-o
EIO エラーでリカバリーしない場合は
0
、EIO エラーでリカバリーする場合は
1
として指定します。

例
ノード
3
および
6
の仮想共有ディスクのノード情報を削除するには、
次のように入力します。
vsdelnode 3 6
