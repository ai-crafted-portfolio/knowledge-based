目的
AIX® オペレーティング・システムのトラステッド・インストールおよび更新のためのデジタル署名ポリシー・オプションの値を変更します。

説明
リリース
IBM® AIX 7.2 (テクノロジー・レベル 4 適用)
以降、
installp
形式で提供される AIX オペレーティング・システムのソフトウェア・パッケージはデジタル署名されています。 インストール・プロセスでは、ソフトウェア・パッケージのデジタル署名が検査され、デジタル署名ポリシーに基づいて処理が行われます。
chsignpolicy
コマンドを使用して、デジタル署名ポリシーを変更することができます。
digital signature policy
オプションの適切な値を設定することにより、インストールまたはアップグレードに使用されるソフトウェア・パッケージが、 IBMによって出荷された後に変更されていないことを確認できます。
注:
デジタル署名ポリシー設定は、オペレーティング・システムのインストール中には行われません。 インストール後に確実にシステムが稼働するように、まずオペレーティング・システムのインストールを完了する必要があります。
ソフトウェア・パッケージのトラステッド・インストールを機能させるには、
IBM AIX 7.2 (テクノロジー・レベル 4)
以降をシステムに正常にインストールする必要があります。

構文
chsignpolicy [-R] chsignpolicy [-p] chsignpolicy [-s low|medium|high|none]

オプション
フラグ
-R
これは、デジタル署名ポリシーの値をリストします。
-p
これは、現行デジタル署名ポリシーの設定を出力します。
-s
これは、今後のインストール操作に関するデジタル署名ポリシーを設定します。 このフラグには以下のいずれかの値を指定する必要があります。
なし
これは、インストールまたは更新されようとしているソフトウェア・パッケージのデジタル署名を AIX オペレーティング・システムが検査しないように指示します。 この値がデフォルト設定です。
低
AIX オペレーティング・システムが、インストールまたは更新するソフトウェア・パッケージの署名を検査するよう指示します。 署名検査が失敗すると、インストール・プロセスは警告メッセージを表示しますが、インストールは続行されます。
次の例のような警告メッセージが表示されます。
INFO: Package <full path to package name> failed signature verification.
中
これは、インストールまたは更新されようとしているソフトウェア・パッケージのデジタル署名を AIX オペレーティング・システムが検査するように指示します。 署名検査が失敗すると、インストール・プロセスは、インストールを続行するかどうかを確認するプロンプトを出します。 署名検査に失敗したファイルセットごとにインストールを確認する必要があります。 そうでないと、ソフトウェア・パッケージが正常にインストールされません。
警告メッセージは、次の例のようなものになります。
WARNING: Package <full path to package name> failed signature verification. Continue? (y/n)
高
これは、インストールまたは更新されようとしているソフトウェア・パッケージのデジタル署名を AIX オペレーティング・システムが検査するように指示します。 デジタル署名検査が失敗すると、ソフトウェア・パッケージのインストールは失敗します。
失敗メッセージは、次の例のようなものになります。
FAILURE: Package <full path to package name> failed signature verification.

例
デジタル署名ポリシーを
low
に設定するには、次のコマンドを実行します。
chsignpolicy -s low
署名のないソフトウェア・パッケージがインストールされると、次のメッセージがインストール・ログに記録されますが、ソフトウェア・パッケージは正常にインストールされます。
INFO: Package <full path to package name> failed signature verification.
現在のデジタル署名ポリシーを表示するには、次のコマンドを実行します。
chsignpolicy -p
次の例に示すような出力が表示されます。
#signpolicy
low
使用可能なデジタル署名ポリシーを表示するには、次のコマンドを実行します。
chsignpolicy -R
次の例に示すような出力が表示されます。
none
low
medium
high
